### 探究｜合計のぶれが、計算より大きいのはなぜか

1人あたり期待値1.1個・標準偏差0.7個の商品。来店300人の日の合計は、客どうしが独立なら期待値330個・標準偏差約12個のはず。ところが記録を見ると、日ごとの合計は計算の2倍くらいぶれている（架空）。どう考えるか。

下の「検証に使う」のラボの「n 人の合計」で、人数と1人あたりの数を変え、計算上のぶれを確かめる。そのうえで、計算と記録が合わない理由を自分で立てる。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること**：客どうしが独立で、1人あたりの分布が日によらず同じなら、合計の標準偏差は約12個になる。記録のぶれがその約2倍なら、この前提のどれかが成り立っていない。前提が崩れる形は2つある：客どうしが同じ向きに動く（正の相関）か、日によって1人あたりの分布そのものが変わる（混ざり）。

**解釈の例1**：家族連れやまとめ買いの客が多く、同じ組の客が同じように買う。日によって家族連れの割合が違うので、合計が大きくぶれる。

**解釈の例2**：天気や近所の行事で、その日の客全員の買い方がそろって変わる。雨の日はみんな少なめ、行事の日はみんな多め。1人1人は独立に見えても、共通の要因が全員を動かしている。

どちらかを決めるのは、統計だけではできない。レシートを家族連れかどうかで分ける、天気や行事の日で分ける（層別する）と、どちらがぶれの元かを確かめられる。
:::

### 課題A｜自分の売場の「1人あたり分布カード」を作る

POSのレシートから、ある商品（またはカテゴリ）を1人が何個買ったかを数え、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 確率分布 | 0個・1個・2個…の割合（合計1） |
| 期待値 | 1人あたりの個数（値×割合の合計） |
| 標準偏差 | 1人ごとのぶれ |
| 合計の見込み | 来店数×期待値 と、そのぶれ √来店数×標準偏差 |

### 課題B｜発注量を決める

**問い**　1人あたり期待値1.1個・標準偏差0.7個の商品で、来店300人の日に何個用意するか。決め方と、その根拠になる数を書く。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：合計の期待値は330個、標準偏差は約12.1個（客どうしが独立と仮定）。330個ちょうどだと、足りない日が半分くらいある。期待値＋標準偏差の何倍を足すかで、欠品の起きやすさが決まる（2倍なら約354個）。

**必要な数**：欠品したときの損（売り逃し）と、余ったときの損（廃棄・値引き）の大きさ。損の大きい方を避けるように余裕を決める。

**小さな例で検証**：ラボの「n 人の合計」で人数を変え、標準偏差が人数ほどには増えないことを確かめる。

**成り立たない条件と、その先の判断**：来店数そのものも日によってぶれる。雨の日にまとめて客が減るように客どうしが独立でないと、合計のぶれは計算より大きい。
:::

### 課題C｜キャンペーンのくじの期待値を設計する

「1等1000円・2等100円」のようなくじで、1枚あたりの景品の期待値が予算（例：1枚20円）に収まるように、当たりの確率を決める。決めた確率で期待値と標準偏差を出し、1日の配布枚数から景品の合計の見込みとぶれを書く。

### 振り返りの観点（任意）

自分で振り返るときに使う。点数や到達の基準にはしない。

| 観点 | 見ること |
| --- | --- |
| 問い | 見込み（期待値）とぶれ（標準偏差）のどちらを知りたいかが明確か |
| 仮定 | 確率の出どころ、独立の仮定を書いたか |
| 方法 | 表に列を足す、和・変換の公式を使い分けたか |
| 検証 | 小さな例やラボで確かめたか |
| 切り分け | 統計で言えること（前提のもとの見込みとぶれ）と、言えないこと（なぜ前提が崩れたか）を分けたか |
