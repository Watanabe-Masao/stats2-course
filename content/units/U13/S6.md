### 課題A｜自分の売場の「1人あたり分布カード」を作る

POSのレシートから、ある商品（またはカテゴリ）を1人が何個買ったかを数え、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 確率分布 | 0個・1個・2個…の割合（合計1） |
| 期待値 | 1人あたりの個数（値×割合の合計） |
| 標準偏差 | 1人ごとのぶれ |
| 合計の見込み | 来店数×期待値 と、そのぶれ √来店数×標準偏差 |

### 課題B｜発注量を決める

**問い**　1人あたり期待値1.1個・標準偏差0.7個の商品で、来店300人の日に何個用意するか。決め方と、その根拠になる数を書く。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：合計の期待値は330個、標準偏差は約12.1個（客どうしが独立と仮定）。330個ちょうどだと、足りない日が半分くらいある。期待値＋標準偏差の何倍を足すかで、欠品の起きやすさが決まる（2倍なら約354個）。

**必要な数**：欠品したときの損（売り逃し）と、余ったときの損（廃棄・値引き）の大きさ。損の大きい方を避けるように余裕を決める。

**小さな例で検証**：ラボの「n 人の合計」で人数を変え、標準偏差が人数ほどには増えないことを確かめる。

**限界**：来店数そのものも日によってぶれる。雨の日にまとめて客が減るように客どうしが独立でないと、合計のぶれは計算より大きい。
:::

### 課題C｜キャンペーンのくじの期待値を設計する

「1等1000円・2等100円」のようなくじで、1枚あたりの景品の期待値が予算（例：1枚20円）に収まるように、当たりの確率を決める。決めた確率で期待値と標準偏差を出し、1日の配布枚数から景品の合計の見込みとぶれを書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 見込み（期待値）とぶれ（標準偏差）のどちらを知りたいかが明確か |
| 仮定 | 確率の出どころ、独立の仮定を書いたか |
| 方法 | 表に列を足す、和・変換の公式を使い分けたか |
| 検証 | 小さな例やラボで確かめたか |
| 限界 | 独立でないときのぶれ、確率の見込みのずれを書いたか |
