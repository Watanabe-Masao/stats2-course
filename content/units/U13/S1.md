### 0｜入口の問い

::: task
1人の客が買う個数の平均は1.1個。明日の来店は300人の見込みなので、ちょうど330個を用意する。この決め方で足りるか。何を確かめればよいか。
:::

^ まだ答えなくてよい。「平均してどれだけ」（期待値）と「どれくらいぶれるか」（分散・標準偏差）を確率の一覧から出せるようになるのが初学のゴール。

### 2｜意味をつかむ：問題文の言葉で式を選ぶ　{{power:P3}}

結果によって値が変わる数（1人の客が買う個数など）を**確率変数** X、どの値がどれくらい出やすいかの一覧を**確率分布**という。前提チェック1の「人数の割合」を「確率」に置き換えたものが期待値になる。

::: ask 「1回（1人）あたり平均どれだけ？」
→ **期待値**：値×確率を全部足す。
:::

::: ask 「どれくらいばらつく？読みにくさは？」
→ **分散・標準偏差**：期待値からのずれの2乗を、確率で重みを付けて平均する。
:::

::: ask 単価を掛けた・固定額を足した（Y＝aX＋b）
→ **E(aX＋b)＝aE(X)＋b、V(aX＋b)＝a²V(X)**。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
E(X)=\sum_x x\,P(X=x),\qquad V(X)=E(X^2)-\{E(X)\}^2
$$

| 記号 | 意味（買う個数の例） |
| --- | --- |
| X | 1人の客が買う個数（確率変数） |
| P(X＝x) | x 個買う確率（合計は1） |
| E(X) | 1人あたりの期待値（分布の重心） |
| E(X²) | 個数の2乗の期待値 |
| V(X)・√V(X) | 分散・標準偏差（期待値からのぶれ） |

**式を言葉で読む**：期待値は「値×確率」を全部足したもの。分散は本来「(値−期待値)²×確率」の合計だが、計算は「2乗の期待値−期待値の2乗」が速い。標準偏差は分散の平方根で、元の単位（個）に戻る。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　ある売場で、1人の客が買う個数 X の確率は次のとおり。1人あたり平均何個買うか。また分散・標準偏差はいくらか。

| 買う個数 x | 確率 P(X＝x) |
| --- | --- |
| 0個 | 0.2 |
| 1個 | 0.5 |
| 2個 | 0.3 |

**表に列を足して計算する**

| x | x×確率 | x²×確率 |
| --- | --- | --- |
| 0 | 0 | 0 |
| 1 | 0.5 | 0.5 |
| 2 | 0.6 | 1.2 |
| **合計** | **1.1** | **1.7** |

1. **期待値**　E(X)＝**1.1個**
2. **2乗の期待値**　E(X²)＝1.7
3. **分散**　V(X)＝1.7−1.1²＝1.7−1.21＝**0.49**
4. **標準偏差**　√0.49＝**0.7個**

{{lab:LAB-expect@s1-dist}}

::: key
期待値は「確率で重み付けした平均」。100人来ればおよそ110個売れる見込み。1人あたりは1.1個から±0.7個くらいぶれる。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-expect@s1-var}}

1. **予想**：ラボの課題カードで、売場B（0個 0.45、2個 0.55）の分散を入れる。
2. **操作**：結果を見たら、「値」を「0・1・2」に戻し、1個の確率を増やしていく。
3. **観察**：期待値が同じでも、分散が大きくなるのは確率がどこに集まるときか。
4. **説明**：「□に確率が集まると分散が大きくなった。なぜなら□」を1文で書く。
5. **ラボなしで**：売場B（0個 0.45、2個 0.55）の期待値・E(X²)・分散を表に列を足して出す。

::: toggle 答え（書いてから開く）
- **観察**：期待値から離れた値（0個と2個）に確率が集まるほど分散は大きく、期待値の近く（1個）に集まるほど小さい。
- **説明の例**：「期待値は同じ1.1個でも、0個と2個に分かれると分散が0.49から0.99に大きくなった。分散は期待値からのずれの2乗を平均したもので、どの客も1.1個から約1個離れているから」
- **ラボなしで**：E(X)＝2×0.55＝1.1、E(X²)＝4×0.55＝2.2、V＝2.2−1.21＝**0.99**。平均が同じでも、値が平均から離れているほど分散は大きい。
:::
