### なぜ？｜分散はなぜ「2乗」の平均なのか

例題A（0個 0.2・1個 0.5・2個 0.3）で、期待値1.1からのずれ −1.1・−0.1・0.9 を確率で重み付けして足すと、0.2×(−1.1)＋0.5×(−0.1)＋0.3×0.9＝0 になる。ずれをそのまま平均すると、どんな分布でも0になり、散らばりを測れない。

向きを消すだけなら絶対値でもよい。それでも2乗を使うのは、**独立な量を足したとき、分散はそのまま足せる**（V(X＋Y)＝V(X)＋V(Y)）からである。300人分の合計のぶれを1人分から組み立てられるのは、2乗で測っているおかげ。絶対値の平均では、この足し算が成り立たない。

### 1つの数で何が消えるか

期待値1.1個は「1人あたりの見込み」としては便利だが、**0個の客が2割いる**ことは消える。1.1個を買う客は1人もいない。標準偏差0.7個を足しても、「0個・1個・2個のどれが多いか」は戻らない。

発注には期待値と標準偏差で足りても、「買わない2割の客に何を勧めるか」を考えるには、分布そのもの（確率の一覧）に戻る必要がある。

### 本当に？｜客どうしが独立でないと、合計のぶれはどう揺れるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

300人の合計の標準偏差は、客どうしが独立なら √300×0.7≒12.1個。ところが家族連れのように、同じ組の客が同じように買う（正の相関がある）と、合計のぶれは大きくなる。どの2人の間にも相関0.01という小さなつながりがあるだけで、合計の標準偏差は約24.2個と、独立のときの約2倍になる。

1人あたりの期待値と標準偏差は同じままでも、**つながり方**で合計のぶれは大きく変わる。合計の公式 √n×σ は「独立」という前提の上にだけ立っている。

### ほかでは？｜つながり

- 1人あたりの平均は、人数を増やすほど期待値1.1個に近づく（大数の法則。平均のぶれは 0.7÷√n）→ {{unit:U19}}
- 共分散を標準偏差で割ってそろえると相関係数 → {{unit:U28}}
- 0か1の量を n 回足すと二項分布。期待値 np・分散 np(1−p) は、この単元の「和の期待値・独立なら和の分散」から出る → {{unit:U14}}
- 無相関でも独立でない例：X が −1・0・1 を1/3ずつ、Y＝X² なら共分散は0なのに、Y は X で決まる。共分散は直線的な関係しか見ていない
- 連続な量では、確率の一覧の代わりに確率密度を使い、Σ が積分になる。考え方（重み付きの平均・重心）は同じ → {{unit:U16}}

### 説明してみる

::: task
「1人あたり平均1.1個なので、300人なら330個用意すれば足りる」という説明のどこが足りないか。期待値・標準偏差・独立の3つの言葉を使って説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
330個は合計の**期待値**で、実際の合計は日によってぶれる。客どうしが独立なら、ぶれの目安（**標準偏差**）は約12個なので、330個ちょうどでは半分くらいの日で足りない。さらに、家族連れのまとめ買いや天気のように客が同じ向きに動く要因があると、**独立**の前提が崩れ、ぶれはもっと大きくなる。何個用意するかは、足りないときの損と余ったときの損を比べて決める（統計の外の判断）。
:::
