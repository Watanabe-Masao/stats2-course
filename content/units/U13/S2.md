**お手本：X−Y の分散も「足す」理由**

- **条件**：X と Y が独立なとき
- **対象と結論**：X−Y の分散は V(X)＋V(Y) で、引き算にはならない
- **根拠**：分散はずれの2乗の平均で、−Y のずれも2乗すると正になり、V(−Y)＝(−1)²V(Y)＝V(Y) だから。両方のばらつきが重なって大きくなる
- **成り立たない場合**：独立でない（共分散が0でない）ときは −2Cov(X,Y) の項が付く

::: toggle つなげると（お手本の文）
「X と Y が独立なら、X−Y の分散は V(X)＋V(Y) になる。−Y のずれも2乗すれば正になり、V(−Y)＝V(Y) なので、両方のばらつきが足し合わされるからである。ただし独立でないときは、共分散の項 −2Cov(X,Y) を加える。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「1人あたり平均1.1個買うので、ほとんどの客が1個か2個買います。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 期待値は重み付き平均で、個々の客の典型的な値とは限らない。
- この分布では20%の客が0個。売場Bなら1個買う客は0人。

**言い直しの例**

「1人あたりの期待値は1.1個で、100人来ればおよそ110個売れる見込みである。ただし20%の客は何も買わず、標準偏差は0.7個なので、個々の客の買う数はばらつく。」
:::

::: toggle 取り違えやすい言葉
- **「期待値」と「平均（標本平均）」**：期待値＝確率分布から計算する理論上の平均／標本平均＝実際のデータから計算する平均
- **「無相関」と「独立」**：無相関＝共分散が0（直線的な関係がない）／独立＝どんな関係もない。独立なら無相関だが、無相関でも独立とは限らない
- **「E(X²)」と「{E(X)}²」**：E(X²)＝2乗してから期待値（1.7）／{E(X)}²＝期待値を2乗（1.21）。差が分散
:::

### 式の早見

| 求めるもの | 式 |
| --- | --- |
| 期待値 | Σ x P(X＝x) |
| 分散 | E(X²)−{E(X)}² |
| 1次変換 | E(aX＋b)＝aE(X)＋b、V(aX＋b)＝a²V(X) |
| 和の期待値 | E(X＋Y)＝E(X)＋E(Y)（独立でなくてもよい） |
| 和・差の分散 | V(X)＋V(Y)±2Cov(X,Y) |
| 共分散 | E(XY)−E(X)E(Y) |
