### 0｜入口の問い

::: task
チラシAを50人に配ると30人が買い、Bでは50人中20人が買った。チラシの種類と購入には関係があるのか。数値ではなく「買った／買わない」という**カテゴリーの件数**しかないとき、どう判断するか。来店客が曜日によって偏っているかを、件数だけで調べるにはどうするか。
:::

^ まだ答えなくてよい。件数の表から「独立（関係がない）なら何件になるはずか」（期待度数）を作り、ずれを χ² にまとめて判断できるようになるのが初学のゴール。

### 2｜意味をつかむ：「独立ならこうなるはず」とのずれ　{{power:P3}}

::: ask 期待度数とは？
→ H₀（独立、または決めた比率どおり）が正しいときに、**各セルに入るはずの件数**。独立なら P(行)×P(列)×総数＝**行計×列計÷総計**。適合度なら**総数×決めた比率**。
:::

::: ask χ² は何を測る？
→ 観測度数 O と期待度数 E のずれを、セルごとに (O−E)²÷E にして足したもの。ずれが大きいほど χ² は大きい。H₀ のもとでは自由度 (行−1)(列−1)（適合度なら区分の数−1）の χ² 分布に近い。上側の点を超えたら H₀ を棄却する。
:::

::: ask 表をどう見る？
→ **帯グラフ**で行ごとの割合を100%の横帯にして並べる。独立なら、どの行も全体と同じ割合になり、帯の区切りがそろう。区切りがずれているほど χ² が大きい。棄却しても「関連がある」まで。どちらが原因かは言えない。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
E_{ij}=\frac{(\text{行計})\times(\text{列計})}{\text{総計}}\qquad \chi^2=\sum\frac{(O-E)^2}{E}
$$

| チラシ／購入 | あり | なし |
| --- | --- | --- |
| A（計50） | 30 | 20 |
| B（計50） | 20 | 30 |

^ 列計は「あり」50・「なし」50、総計100。

| 記号 | 意味（例題の数） |
| --- | --- |
| O | 実際の件数：30・20・20・30 |
| 行合計・列合計 | 50・50（チラシ）、50・50（購入） |
| E | 行合計×列合計÷総数＝50×50÷100＝25 |
| 自由度 | (2−1)×(2−1)＝1 |

**式を言葉で読む**：分子は「独立ならこうなるはず」からのずれの2乗、分母でセルの大きさをそろえる。2×2 の表では、1つのセルが決まると残りは行計・列計から決まるので、自由度は1。

| 検定 | 期待度数 | 自由度 |
| --- | --- | --- |
| 独立性 | 行計×列計÷総計 | (行−1)(列−1) |
| 適合度 | 総数×決めた比率 | 区分の数−1−推定した母数 |

```txt
独立性：E＝行計×列計÷総計、自由度＝(行の数−1)(列の数−1)
適合度：E＝総数×比率、自由度＝区分の数−1−データから推定した母数の数
χ²＝Σ(O−E)²÷E を上側の点（自由度1で3.841）と比べる
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　チラシA・Bを各50人に配り、購入の有無を集計した（上の表）。チラシの種類と購入は独立か（5%）。（自由度1の χ² の上側5%点は3.841）

1. 仮説：H₀：チラシと購入は独立、H₁：関連がある
2. 期待度数：50×50÷100＝**25**（4セルとも）
3. 各セル：(30−25)²÷25＝1、(20−25)²÷25＝1 … → χ²＝1＋1＋1＋1＝**4**、自由度1
4. 4＞3.841（p≒**0.046**）→ **独立の仮説を棄却**
5. 結論：「チラシの種類と購入には関連がある（有意水準5%）」。購入率はA60%・B40%

{{lab:LAB-chisq@s1-indep}}

::: warn
χ² には割合ではなく**件数**を入れる。期待度数が小さい（目安5未満）セルがあると近似が粗い。棄却しても「チラシが購入の原因」とまでは言えない。
:::

::: key
どちら向きの関連かは、行ごとの割合（帯グラフ）で見る。Aの購入率60%、Bは40%。この表の χ²＝4 は、2つの比率の差の z（{{unit:U26}}：p̄＝0.5、SE＝0.1、z＝2）の2乗と同じ。
:::

**適合度の例**　2つの区分を50対50 と決め、100件の観測が60と40だった。期待度数は50・50、χ²＝100÷50＋100÷50＝**4**、自由度1。3.841 を超えるので「50対50 どおり」を棄却する（p≒0.046）。

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-chisq@s1-half}}

1. **予想**：ラボの課題カードで、例題Aと同じ割合（A60%・B40%）のまま人数を各25人にした表の χ² を予想する。
2. **操作**：結果を見たら、表を各50人（30・20・20・30）、各500人（300・200・200・300）にする。
3. **観察**：帯グラフの形、期待度数、χ² と p 値はどう変わるか。
4. **説明**：「割合が同じでも件数を k 倍にすると、χ² は□。なぜなら□」を1文で書く。
5. **ラボなしで**：各25人（15・10・10・15）の期待度数と χ² を出す。

::: toggle 答え（書いてから開く）
- **観察**：帯グラフはどれも同じ形（A60%・B40%）。χ² は各25人で2、各50人で4、各500人で40。期待度数は12.5・25・250 と人数に比例する。
- **説明の例**：「割合が同じでも件数を k 倍にすると、χ² も k 倍になる。O−E が k 倍、E が k 倍なので、(O−E)²÷E が k 倍になるから」
- **ラボなしで**：E＝25×25÷50＝**12.5**、χ²＝(2.5²÷12.5)×4＝**2**。3.841 に届かないので棄却しない。
:::
