### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}

**お手本：独立性の検定で期待度数を「行計×列計÷総計」にする理由**

- **条件**：2つの分類が独立（H₀）だと仮定するとき
- **対象と結論**：各セルの期待度数は 行計×列計÷総計 になる
- **根拠**：独立なら P(行かつ列)＝P(行)×P(列) で、それぞれを行計÷総計・列計÷総計で見積もり、総計を掛けるから
- **成り立たない場合**：同じ人を2回数えた表（対応がある）や、期待度数が5未満のセルが多い表では、この χ² 検定は使えない

::: toggle つなげると（お手本の文）
「2つの分類が独立だと仮定すると、各セルの期待度数は行計×列計÷総計になる。独立なら P(行かつ列)＝P(行)×P(列) で、それぞれを行計÷総計・列計÷総計で見積もって総計を掛けるからである。ただし同じ人を2回数えた表や、期待度数が5未満のセルが多い表では、この検定は使えない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「表を%に直して χ² を計算したら8になったので、関連があります。チラシAを配ると購入が増えることが証明されました。2×2 の表のセルは4つなので、自由度は3です。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- χ² は件数で計算する。%にすると件数の多さが変わり、χ² も変わる（例題Aの件数では χ²＝4）。
- 棄却しても「関連がある」まで。Aが購入の原因とは言えない。
- 2×2 の表の自由度は (2−1)×(2−1)＝1。セルの数−1 ではない。

**言い直しの例**

「件数の表から期待度数25を作ると χ²＝4、自由度1 で3.841 を超えるので、チラシの種類と購入には関連があると言える（有意水準5%）。購入率はA60%・B40%。ただしAが購入の原因とまでは言えない。」
:::

::: toggle 取り違えやすい言葉
- **「観測度数」と「期待度数」**：実際の件数と、H₀ のもとで入るはずの件数
- **「独立性」と「適合度」**：2つの分類の関係か、1つの分類が決めた比率どおりか
- **「件数」と「割合」**：χ² は件数で計算する
- **「関連」と「因果」**：独立を棄却しても、どちらが原因かは言えない
- **「自由度」と「セルの数−1」**：独立性は (行−1)(列−1)
:::

### χ² 検定の早見

| 検定 | 期待度数・自由度 |
| --- | --- |
| 独立性 | 行計×列計÷総計・(行−1)(列−1) |
| 適合度 | 総数×比率・区分の数−1−推定した母数 |

^ よく使う上側5%点：自由度1は3.841、2は5.991、3は7.815、4は9.488。期待度数は目安として5以上。
