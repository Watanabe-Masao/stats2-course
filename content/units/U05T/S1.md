### 2｜意味をつかむ：何を知りたいかで計算を選ぶ　{{power:P3}}

時間の順番があるデータ（時系列）では、「増えた・減った」を言う前に、何を知りたいかを決める。

::: ask 前の時点からどれだけ増えた？
→ **増減率**（T1）。基準は「前の時点」で毎回変わる。重ねるときは**倍率を掛ける**。
:::

::: ask 毎期平均で何%ずつ増えた？
→ **幾何平均による平均成長率**（T2）。倍率を掛けて、期間の数の累乗根をとる。
:::

::: ask 細かい上下をならして傾向を見たい
→ **移動平均**（T3）。前後（または過去）の数点を平均する。
:::

| 知りたいこと | 使う計算 |
| --- | --- |
| 前からの変化 | 増減率（倍率） |
| 毎期の平均の伸び | 平均成長率（幾何平均） |
| 上下をならした傾向 | 移動平均 |

### 3｜式の構造を読む　{{power:P1}}

$$
r_t=\frac{x_t-x_{t-1}}{x_{t-1}},\qquad I_t=100\,\frac{x_t}{x_0},\qquad \bar r=\left(\prod_{j=1}^{m}a_j\right)^{1/m}-1,\qquad M_t=\frac{x_{t-1}+x_t+x_{t+1}}{3}
$$

| 記号 | 意味（いちごの例） |
| --- | --- |
| rₜ | 増減率。分母は前の時点 xₜ₋₁ |
| Iₜ | 指数。最初の時点 x₀ を100とした値 |
| aⱼ・m | 各期の倍率と期間の数（3時点なら2期間） |
| Mₜ | 中央3点移動平均（前・当・後の平均） |

**式を言葉で読む**：増減率の分母は毎回「直前の値」なので、率どうしは足せない。倍率 1＋r に直せば、続けて起きた変化は掛け算で重なる。平均成長率は「同じ倍率を m 回掛けて、実際の最後の値になる倍率」。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　入口のいちご（80→100→90パック）で、全体の増減率と、80を100とする指数を求めよ。

1. 80→100：倍率 100÷80＝**1.25**（25%増、基準は80）
2. 100→90：倍率 90÷100＝**0.90**（10%減、基準は100）
3. 全体の倍率：1.25×0.90＝1.125 → **12.5%増**（15%ではない）
4. 80を100とする指数：100 → 125 → 112.5

^ ＋20%→−20% で元に戻らないことも確かめる。累計の増減率＝(1＋r₁)(1＋r₂)−1。

::: key
増減率は分母（基準）が毎回違うので**足せない**。「20%増は1.2倍、20%減は0.8倍」と倍率に直して掛ける。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-ts@s1-growth}}

1. **予想**：ラボの課題カードで、4期（＋25%、−10%、＋20%、−20%）の平均成長率を入れる。
2. **操作**：結果を見たら、4つの率を −／＋ で動かす。期間の数を2・3にも変える。
3. **観察**：実際の線と、幾何平均の線・算術平均の線は、最後の値でどうなったか。
4. **説明**：「平均成長率に幾何平均を使うのは、□が掛け算で重なり、□を再現できるのが幾何平均だから」を1文で書く。
5. **ラボなしで**：＋50%、−50% の2期間の平均成長率は？（√0.75≒0.866）

::: toggle 答え（書いてから開く）
- **観察**：どんな率にしても、最後の値が実際と一致するのは幾何平均の線だけ。算術平均の線は、率がばらつくほど実際より上にずれる（＋25%、−10%、＋20%、−20% なら 115.87 と 108）。
- **説明の例**：「平均成長率に幾何平均を使うのは、成長は倍率が掛け算で重なり、最後の値を再現できるのが幾何平均だから」
- **ラボなしで**：倍率 1.5×0.5＝0.75、√0.75≒0.866 なので**約−13.4%**。算術平均の0%ではない（実際は75%に減っている）。
:::
