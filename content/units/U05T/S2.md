**お手本：成長率の平均に幾何平均を使う理由**

- **条件**：毎期の増減率から「平均して毎期何%ずつ増えたか」を求めるとき
- **対象と結論**：増減率の算術平均ではなく、倍率の幾何平均から1を引いた値を使う
- **根拠**：成長は倍率が次々に掛かるので、同じ倍率を期間数だけ掛けて実際の最終値を再現できるのは幾何平均だから
- **成り立たない場合**：途中で値が0や負になると倍率を作れないので、この式は使えない

::: toggle つなげると（お手本の文）
「毎期の平均成長率を求めるときは、増減率を足して割るのではなく、倍率の幾何平均から1を引く。成長は倍率が掛け算で重なるので、最終値を再現できるのは幾何平均だからである。ただし途中で値が0や負になる場合は使えない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「昨年は30%増、今年は30%減だったので、2年前と同じ売上に戻りました。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 30%増と30%減は基準が違う（2年目の基準は増えた後の値）。
- 倍率で 1.3×0.7＝0.91 なので、元より9%少ない。

**言い直しの例**

「昨年30%増、今年30%減なので、2年前と比べた倍率は 1.3×0.7＝0.91 となり、売上は2年前より9%少ない。減少率は増えた後の売上を基準にするため、同じ30%でも金額は大きい。」
:::

::: toggle 取り違えやすい言葉
- **増減率とポイント**：増減率＝前の値を基準にした変化の割合（10%→12% は20%増）／ポイント＝割合どうしの差（10%→12% は2ポイント増）
- **指数と実数**：指数125＝基準の1.25倍という意味／125個という意味ではない
- **トレンドと予測**：トレンド＝過去の持続的な傾向／移動平均の線を延ばしても、将来の予測になるとは限らない
:::
