### なぜ？｜なぜ率がばらつくと、算術平均は実際より大きく出るのか

初学では、率の算術平均で増やした線が、実際の最後の値より上にずれるのを見た。そのずれは、どこから来るのか。

2つの版は、どちらも率の算術平均が＋10%。＋10%・＋10% と ＋30%・−10% で、最後の値と幾何平均の平均成長率を読み、最後の値の差がどこから来るかを、倍率を平均の1.1からのずれで書いて考える。

::: toggle 動かしてから開く
＋10%・＋10% は 100 → 110 → 121。＋30%・−10% は 100 → 130 → 117 で、4 だけ少ない。

2つの倍率を、平均の 1.1 からのずれで書くと 1.3＝1.1＋0.2、0.9＝1.1−0.2。掛けると (1.1＋0.2)(1.1−0.2)＝1.1²−0.2²＝1.21−0.04＝1.17。平均からのずれの2乗（0.2²）だけ、累計倍率が小さくなる。幾何平均は √1.17≒1.0817 で、平均成長率は約8.17%。

2期では、平均からのずれは必ず＋と−で同じ大きさになり、ちょうどずれの2乗だけ小さくなる。期間が多いときも、累計の倍率は、およそ「ずれの2乗の和÷（2×平均の倍率の2乗）」の割合だけ小さくなるので、率の算術平均で増やした線は、実際の値より上にずれる。ずれがないとき（毎期同じ率）だけ、2つの平均は一致する。ずれの2乗を平均したものが、ばらつきの物差しの分散（{{unit:U07}}）につながる。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

最初と最後が同じなら、平均成長率は同じになる（復習で見たこと）。では、平均成長率が同じ2つの店は、同じだけ売ったと言えるか。2つの版で、ある店の売上（最初＝100）が ＋50% のあと −20% だった場合と、−20% のあと ＋50% だった場合の、最後の値と平均成長率を読む。途中の値は倍率から計算し、2期の売上の合計を比べる。

::: toggle 動かしてから開く
＋50%・−20% は 100 → 150 → 120。−20%・＋50% は 100 → 80 → 120。最後はどちらも120で、平均成長率はどちらも √1.2−1≒9.54%。倍率は掛ける順番を入れ替えても積が変わらないので、平均成長率は途中の通り方を表さない。

2期の売上を足すと、150＋120＝270 と 80＋120＝200 で、店に入った売上は大きく違う。「平均9.54%ずつ伸びた」という1つの数からは、**途中にどこを通ったか**と、その間に売った量が消える。在庫や人の手配は、途中の150と80で決まる。平均成長率で比べるときは、何を知りたいか（最後の水準か、途中を合わせた量か）を決め、途中の値の並びも添える。
:::

### 本当に？｜ラグ7が高ければ、曜日の波なのか

転用では、曜日の波があればラグ7 が、となりのラグより飛び出して高くなり、傾向だけならラグ1 から順にゆっくり下がるのを見た。では、ラグ7 が飛び出していなければ、曜日の波はないと言えるか。ラボの版は、曜日の波も右上がりの傾向も、どちらも大きく入れた日販。ラグ6・7・8 の棒を比べる。

::: toggle 動かしてから開く
曜日の波は入っているのに、ラグ7 はとなりのラグ6 とほとんど同じ高さで、飛び出さない。波の分は、ラグ5〜7 の辺りが少し持ち上がる形でしか残らない。

なぜか。自己相関は、ずれの積の和を、系列全体のずれの2乗の和（全体のばらつき）で割った値。傾向が大きいと、56日の始めと終わりの差が大きく、全体のばらつきの大半を傾向が占める。曜日の波が作る「7日ずらすと似る」分は、その大きな分母で割られて小さくなり、傾向が作る「どのラグでも正」の上に、わずかな持ち上がりとして乗るだけになる。傾向のつまみを小さく（たとえば3に）すると、ラグ7 がまた飛び出す。

「ラグ7 が飛び出していない」は「曜日の波がない」ではない。棒の並びは傾向と波が重なった結果で、傾向が波より大きいときは、波の形が見えにくい。傾向がありそうなときは、先に傾向を取り除いてから見直す（前の日との差をとる方法がある。下の「ほかでは？」）。
:::

### ほかでは？｜つながり

- **ずれの2乗の平均**：分散と標準偏差（{{unit:U07}}）
- **幾何平均と算術平均・中央値**：代表値の選び方（{{unit:U06}}）
- **ずらした自分との相関**：相関係数と散布図（{{unit:U28}}）
- **掛け算を足し算に直す**：倍率の対数をとると、掛け算が足し算になる（log1.25＋log0.9＝log1.125）。対数の差で表した成長率は、足して累計でき、その算術平均を元に戻すと幾何平均になる
- **傾向を取り除く**：前の日との差（xₜ−xₜ₋₁）をとった系列で自己相関を見ると、直線の傾向は消える
- **時間の順に並んだ誤差**：回帰の残差に自己相関が残っていないか（{{unit:U29}}）
