### 探究｜前年同月比8%増は、何が増えたのか

ある店の今年3月の売上は 4,320万円で、前年3月の 4,000万円から8%増えた。本部の担当者は「来店客が8%増えた」と書いた。聞き取ると、次のことが分かった。
- 今年の3月は土日が10日・平日が21日、前年の3月は土日が9日・平日が22日（祝日は土日に数えた）
- 前年の1日あたりの売上は、土日がおよそ200万円、平日がおよそ100万円
- 1月から多くの商品の値段を上げ、前年の売れ方で重みをつけると、平均で3%の値上げになる
- 3月20日に、近くの競合店が閉店した

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 前年同月比8%に、何が混ざっているかを書く
2. ラボの「寄与度」で、曜日の数が違うだけで、売上が何%変わるかを確かめる（A を土日、B を平日とみる）
3. 曜日の数と値上げを考えたあとに残る伸びを計算し、置いた仮定を書く
4. 統計で言えることと言えないことを分ける
5. 残る伸びの理由の読み方（2つ以上）を書く
6. 来年から、どの数で報告するかを決める（下の課題）

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（曜日の分は、前年の1日あたりの売上〔土日200万円・平日100万円〕を今年の曜日の並びに当てはめて見積もり、値上げで買う量は変わらなかったとみて）**：前年の3月は 9×200＋22×100＝4,000万円。前年の1日あたりの売上を今年の曜日の並びに当てはめると 10×200＋21×100＝4,100万円で、曜日の数が違うだけで2.5%増える（寄与度は土日＋5ポイント、平日−2.5ポイント）。さらに値段が3%上がると 4,100×1.03＝4,223万円。実際は 4,320万円なので、残る伸びは 4,320÷4,223≒1.023 で、約2.3%。これは、1日あたりの売上の水準が、曜日と値上げの分を除いても前年より上がった分。

**この数だけでは言えないこと**：残る約2.3%が来店客の増加かどうか。売上は「客数×1人あたりの買い物」なので、2.3%は客数の伸びとも、1人あたりの買う量の伸びとも読める。見積もりの仮定（土日と平日の1日あたりの売上の比が前年のまま、値上げで買う量は変わらない）が崩れれば、残る伸びも変わる。「来店客が8%増えた」は、曜日の数と値上げの分を客の増加と取り違えている。

**解釈の例**：
- 3月20日に競合店が閉まり、その客が移ってきた。そうなら、伸びは3月の後半に集まっているはず
- 3月は暖かく、春物が早く動いた。客数は変わらず、1人あたりの買う量が増えた
- 本当は伸びていない。値上げしても買う量がほとんど減らなかった、祝日の日の売上が土日ほどではなかったなど、見積もりの仮定のずれが約2.3%として残った

どれが当たるかは、月の合計の売上だけからは決められない。

**統計の外で決めること**：本部が知りたいのが「客が増えたか」なら、売上ではなく客数（レシートの枚数）を見る。値上げの影響をどう見積もるか（買う量が減ったか）は、売場の手応えも合わせて決める。
:::

### 課題｜来年から何で報告するか

**問い**　来年から、月ごとの「伸び」を本部にどう報告するか。

- **ア**：売上の前年同月比に、曜日の数の違いで説明できる分（今年なら2.5%）を書き添える
- **イ**：売上ではなく、客数（レシートの枚数）の前年同曜日比（同じ曜日どうしの1日あたりの比べ方）で報告する
- **ウ**：3月20日の前と後で分け、それぞれの客数の前年同曜日比を報告する

**判断の材料**：レシートの枚数は POS にあり、曜日ごとに集計し直すのに半日かかる。前年の同じ曜日の数字は、4週前までしか集計したものがない。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（POS の記録が正しいとみて）**：ア は今の報告の形を変えずに、曜日の数の分を切り分けられるが、値上げの分と、客数と1人あたりの違いは混ざったまま。イ は値上げの影響を直接は受けない客数（値上げで来店が減れば、客数に出る）で、曜日もそろえて比べるので、「客が増えたか」に近い数になる。ただし1人あたりの買い物の変化は見えなくなる。ウ は競合店の閉店の前と後を分けるので、閉店の後だけ客数が伸びていれば、移ってきた客の読み方に近づく。ただし後半は12日しかなく、天気など、その12日だけの事情で数が動きやすい。

**統計の外で決めること**：報告の目的で選ぶ。客の動きを知りたいなら イ を基本にし、今月だけは ウ で閉店の前後を見る。イ・ウ は曜日ごとの集計し直しに半日かかり、前年は4週前までしか集計がないので、前年3月の分は先に集計し直しておく必要がある。売上の目標を管理するなら ア の書き添えを続ける。どれを選んでも、比べた期間の曜日の数と、値上げの時期を報告に書く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 前年同月比の伸びのうち、何が増えたのかを問いにしたか |
| 仮定 | 1日あたりの売上や値上げの効き方について、置いた仮定を書いたか |
| 方法 | 曜日の数と値上げの分を、掛け算で順に取り除いたか |
| 検証 | ラボの寄与度で、曜日の数だけで変わる分を確かめたか |
| 切り分け | 言えること（残る伸びは約2.3%）と、言えないこと（客数か1人あたりか）を分けたか |
| 解釈 | 残る伸びの読み方を2つ以上並べ、次に見る数を書いたか |
