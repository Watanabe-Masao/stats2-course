### 課題A｜自分の店の「伸び方カード」を作る

自分の職場の月別データ（売上・客数など）を13か月分以上集め、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 前月比と前年同月比 | どちらで判断するか、その理由 |
| 平均成長率 | 何期間で、幾何平均でいくつか |
| 移動平均 | 窓と置く位置（中央・後方）とその理由 |
| 寄与度 | どの部門が全体の伸びに効いたか |
| 言えないこと | この数字だけでは分からないこと |

### 課題B｜日販の「見る窓」を決める

**問い**　日販の傾向を毎朝確かめたい。移動平均の窓（何日）と置く位置（中央・後方）を決め、その弱点も書く。

::: toggle 1つの考え方の例（自分で決めてから開く）
**決め方**：曜日の波（7日周期）を消したいので窓は7日。毎朝最新日まで見たいので後方7日平均。

**小さな例で検証**：ラボの「移動平均」で日販4週間を3点と7点で比べる。3点では曜日の上下が残り、7点では傾向だけが残る。後方にすると最新日まで計算できるが、線が3日分遅れる。

**弱点**：急な変化（大型連休・競合店の開店）には3日遅れて反応する。祝日で曜日の並びが崩れる週は、7日でも波が残る。変化を早く知りたい日は、前年同曜日比も合わせて見る。
:::

### 課題C｜全体の伸びを部門に分ける表を作る

先月と今月の部門別売上（3部門以上）で、全体の増減率と各部門の寄与度の表を作る。寄与度の合計が全体の増減率と一致することを確かめ、部門自体の増減率との違いを1文で書く。

### 課題D｜他の分野で「平均の伸び」を調べる

人口・物価・投資の値動きなどから、5年以上の系列を1つ選ぶ。年ごとの増減率、算術平均、幾何平均を計算し、最後の値を再現するのはどちらかを確かめる。差が大きくなる条件（率のばらつき）を書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何の伸び・何の傾向を知りたいかが明確か |
| 仮定 | 基準（分母）と期間の数を明示したか |
| 方法 | 倍率・幾何平均・移動平均・寄与度を目的に合わせて選んだか |
| 検証 | 小さな例やラボで確かめたか |
| 限界 | その数字で言えないことを書いたか |
