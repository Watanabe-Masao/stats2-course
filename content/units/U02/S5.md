### なぜ？｜なぜ (Σx)² は Σx² より大きいのか

初学の正方形で、一辺は x₁＋x₂＋x₃、面積は (Σx)²。対角の3つの正方形が Σx² で、残りの白い長方形は x₁x₂ のような2つの値の積。白い長方形は、どの組（1と2、1と3、2と3）も2枚ずつあるので、

(Σx)²＝Σx²＋2×（どの2つの組の積も1回ずつ足した和）

2, 4, 6 なら、組の積の和は 2×4＋2×6＋4×6＝44 で、144＝56＋2×44。値がどれも正なら、白い部分は正なので (Σx)² の方が大きい。2乗してから足すか、足してから2乗するかの違いは、この「組の積」を入れるかどうかの違い。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

表計算や電卓では、データの代わりに n・Σx・Σx² の3つの数だけを持っておき、平均（Σx÷n）と偏差平方和（Σx²−n x̄²）を出すことがある。この3つの数からは、**1つずつの値の並び方**が消える。

2, 2, 8, 8 と 2, 4, 4, 10 は、n＝4・Σx＝20・Σx²＝136 がどれも同じ。だから平均（5）も偏差平方和（36）も同じになる。けれども、前者は「2の日と8の日が半々」、後者は「ふつうは2〜4で、1日だけ10」で、ばらつき方の形は違う。ラボで2つを並べ、同じ数と違う見た目を確かめる。

### 本当に？｜値に負の数があると

「(Σx)² は Σx² より大きい」は、値がどれも正（または0）だという前提に立っている。前年からの売上の差（＋3万円・−3万円）のように、負の値が混ざると崩れる。

＋3 と −3 なら、Σx²＝9＋9＝18、(Σx)²＝0²＝0 で、(Σx)² の方が小さい。組の積 3×(−3)＝−9 が負なので、白い部分が引き算になる。

それでも、偏差平方和 Σx²−(Σx)²÷n は負にならない（ここでは 18−0÷2＝18）。偏差を2乗して足した値なので、どんな値でも0以上。値の向き（正負）で崩れるのは (Σx)² と Σx² の大小で、ばらつきの大きさは崩れない。

### ほかでは？｜つながり

- **分散の計算の近道**：偏差平方和＝Σx²−n x̄² から分散を出す（{{unit:U07}}）
- **2つの変数の積の和**：Σxy と ΣxΣy の違いは、共分散・相関で使う（{{unit:U29}}）
- **掛け算を足し算に**：倍率を重ねた結果を対数で足し算に直す見方（{{unit:U05T}}）

### 説明してみる

::: task
3日分の売上を円で表計算に入れた：100,000,001・100,000,002・100,000,003 円。偏差平方和を「Σx²−n x̄²」の式で計算させると 0 になった。偏差を1つずつ2乗して足すと 2 になる（偏差は −1, 0, 1）。数学では2つの式は等しいのに、なぜ答えが違ったのかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（表計算が、多くの電卓・プログラムと同じく、約16桁までしか数を覚えないとみて）**：Σx² は約3×10¹⁶ で、n x̄² もほぼ同じ大きさ。この2つの差は 2 しかないが、16桁を超える大きさの数の下の桁は丸められて消える。大きな数どうしの引き算で、残るはずの小さな差が消えた（桁落ち）。偏差を先に出す式は、引き算を先にして小さな数（−1, 0, 1）にしてから2乗するので、丸めの影響を受けない。

**解釈の例**：
- 値の大きさに比べて、ばらつきがとても小さいデータ（売上が億円で、差が数円）では、近道の式は使えない
- 値から大きな基準（100,000,000 円）を先に引いておけば、近道の式でも正しく計算できる（偏差平方和は、全部の値から同じ数を引いても変わらない）

**統計の外で決めること**：表計算で分散を出すときは、近道の式を自分で書かず、偏差から計算する関数（VAR など）を使う。どの式で計算したかを、報告の表の下に書いておく。
:::
