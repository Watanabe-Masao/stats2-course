### なぜ？｜(Σx)² は、Σx² の何倍まで大きくなれるか

初学で見たとおり、値がどれも正なら (Σx)² は Σx² より大きい。では、どこまで大きくなれるか。値がどれも0以上なら、

Σx² ≦ (Σx)² ≦ n×Σx²

右の等号は、全部の値が同じとき。n×Σx² と (Σx)² の差を計算すると、ちょうど n×偏差平方和 になる。1, 3, 8 なら、Σx²＝74、(Σx)²＝144、n×Σx²＝222。222−144＝78 で、偏差平方和 26 の3倍。

だから「(Σx)² が n×Σx² にどれだけ届かないか」は、値がどれだけばらついているかを表している。ばらつきが0（全部同じ値）なら届き、ばらつくほど離れる。Σx と Σx² の2つから偏差平方和が出せるのは、このため。

### 1つの数で何が消えるか

**複雑さを説明する型**　{{shared:complex_pattern}}
:::

Σ は「全部足す」だけで、**足す順番**を見ない。だから Σx・Σx² からは、値がどの順に並んでいたかが消える。

3日間の販売数が 3, 5, 9（伸びている）でも 9, 5, 3（落ちている）でも、Σx・Σx²・平均・偏差平方和は全部同じ。ラボの2つの版で、同じになる数を確かめる。伸びているか落ちているかは、日の順に並べて見ないと分からない（変化を読むのは {{unit:U05T}}）。

### 本当に？｜値に負の数があると

「(Σx)² は Σx² 以上」は、値がどれも0以上だという前提に立っている（正の値が2つ以上あれば、Σx² より大きい）。前年からの売上の差（＋3万円・−3万円）のように、負の値が混ざると崩れる。

＋3 と −3 なら、Σx²＝9＋9＝18、(Σx)²＝0²＝0 で、(Σx)² の方が小さい。組の積 3×(−3)＝−9 が負なので、対角以外の長方形が引き算になる。

それでも、偏差平方和 Σx²−(Σx)²÷n は負にならない（ここでは 18−0÷2＝18）。偏差を2乗して足した値なので、どんな値でも0以上。負の値で崩れるのは (Σx)² と Σx² の大小で、ばらつきの大きさは崩れない。

### ほかでは？｜つながり

- **分散の計算の近道**：偏差平方和＝Σx²−n x̄² から分散を出す（{{unit:U07}}）
- **積の和**：Σxy と ΣxΣy の違いは、共分散・相関で使う（{{unit:U28}}）
- **重みをつけた平均**：合計÷合計で平均を出す（{{unit:U06}}）
- **順番を見る**：値の並び（時系列）から変化を読む（{{unit:U05T}}）

### 説明してみる

::: task
3つの商品の単価と売れた個数は、A が100円・30個、B が200円・20個、C が300円・10個だった。担当者は「単価の平均は200円、売れた個数は合わせて60個なので、売上は 200×60＝12,000円」と計算した。実際の売上は10,000円だった。どこに無理があるかを、Σ の計算ルールで説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（3つの商品の単価と個数の記録が正しいとみて）**：売上は1つずつの単価×個数を足した Σ(単価×個数)＝100×30＋200×20＋300×10＝10,000円。担当者の計算は (単価の平均)×(個数の合計)＝(Σ単価÷3)×Σ個数 で、Σ の外に積を出している。Σ は足し算なら分けられるが、積は分けられない。2つが等しいのは、単価と個数が関係なく並んでいるとき（ちょうど打ち消し合うとき）だけ。ここでは安い商品ほど多く売れていて、単価の平均が売れた1個あたりの単価（10,000÷60≒167円）より高く出た。

**解釈の例**：
- 安い商品ほど手に取りやすく、多く売れた
- 高い商品の棚が入口から遠く、目に入りにくかった

**統計の外で決めること**：売上や平均単価を出すときは、1つずつの単価×個数を足してから割る。「単価の平均」と「売れた1個あたりの単価」は別の数として名前を付けて報告する。
:::
