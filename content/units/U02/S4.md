### 同じ構造の場面：記号を書き下してから計算する

| 場面 | 書き下すと |
| --- | --- |
| 平均 Σx÷n | 全部足して個数で割る |
| 分散 Σ(x−x̄)²÷n | 偏差を2乗して足し、個数で割る |
| 組合せ n!÷(r!(n−r)!) | 並べ方を、同じ組の並べ方で割る |
| 期待値 Σx×p(x) | 値×確率を全部足す |
| 回帰 Σ(y−a−bx)² | 予測とのずれを2乗して足す |

^ 統計の式の Σ・階乗は、どれも「書き下すと足し算・掛け算」。平均・分散は {{unit:U06}}・{{unit:U07}}、組合せは {{unit:U09}}、期待値は {{unit:U13}}、回帰は {{unit:U29}}。

::: toggle 読み取りの例
- **n＝5・r＝2**：順列 5×4＝20、組合せ 20÷2!＝10。同じ2人の組を、並べ方2通りで重ねて数えていた分を割る。
- **r＝n**：順列は n!、組合せは1。0!＝1 と決めておくと、n!÷(n!×0!)＝1 と式が合う。
- **関数 f(x)**：a は「x を1増やしたときの増え方」、b は「x＝0 のときの値」。
:::

### 仕事の場面で

- 表計算ソフトの SUM は Σ、SUMSQ は Σx²、PRODUCT は Π、FACT は n!、COMBIN は nCr。式をそのまま関数に置き換えられる。
- SUM(…)^2 と SUMSQ(…) は別の値。分散を自分の式で出すときは、どちらを使うかを確かめる。
- 「1日目から n 日目までの合計」を Σ で書いておくと、日数が変わっても同じ式で計算できる。
