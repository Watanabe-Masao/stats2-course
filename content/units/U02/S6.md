### 探究｜7つの商品の並べ方を、全部試せるか

新しい棚に7つの商品を1列に並べる。どの並べ方がいちばん売れるかを確かめたい。試せるのは、3店で4週間ずつ、1店1週間に1つの並べ方で、合わせて12通りまで。店長は「全部の並べ方を試して、いちばん売れたものにしよう」と言った。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 7つの商品の並べ方は全部で何通りか（階乗）。12通りと比べる
2. 「売上に効くのは何か」の仮定を置くと、試す数がどう減るかを数える
   - 仮定ア：いちばん左（入口側）に置いた商品だけが効く
   - 仮定イ：7つを上の段3つ・下の段4つに分けたとき、上の段にどの3つが入るかだけが効く（段の中の順は効かない）
3. どの仮定なら12通りに収まるか。収まらない仮定ではどうするか
4. 試した結果から言えることと、仮定の外にあるので言えないことを分ける
5. 結果の読み方（2つ以上）を書き、次に何を試すかを決める（下の課題）

{{lab:LAB-sigma@s6-free}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（数え方として）**：並べ方は 7!＝5,040 通りで、12通りの420倍。全部は試せない。仮定アなら、いちばん左に置く商品を選ぶだけなので7通りで、12通りに収まる。仮定イなら、上の段の3つの選び方 ₇C₃＝35 通りで、収まらない。

**仮定を置いて言えること（仮定アが正しく、ほかの条件が週ごとにそろうとみて）**：7通りを試せば、いちばん左にどの商品を置くとよいかは比べられる。ただし1つの並べ方は1店1週間ずつなので、週や店の違い（天気・客数）も売上に入る（比べ方は {{unit:U32}}）。

**この結果だけでは言えないこと**：仮定アで試すと、いちばん左以外の並びは試した7通りでたまたま決まったまま。2番目以降の並びが効いていても、それは見えない。「いちばん売れた並べ方」は、5,040 通りの中のいちばんではなく、試した7通りの中のいちばん。

**解釈の例（左に商品Cを置いた週がいちばん売れたとき）**：
- 商品Cは目立つ位置にあると手に取られやすい商品で、入口側に置くのが効いた
- 商品Cの週は、たまたま2番目に置いた商品との組み合わせがよかった。左だけが効くという仮定アが外れていた
- 商品Cの週は、近くで催しがあって客数が多かった。並べ方とは関係ない

どの読み方が当たるかは、この12週の数だけからは決められない。

**統計の外で決めること**：どの仮定で試すかは、売場の経験（客はどこから見るか）で決める。仮定を置いたことと、試していない並び方があることを、結果の報告に書く。
:::

### 課題｜次の12週で何を試すか

**問い**　仮定アで7通りを試し、商品Cを左に置いたときがいちばん売れた。残りの5週を何に使うか。

- **ア**：商品Cを左に固定し、2番目に置く商品を5通り試す
- **イ**：いちばん売れた並べ方（Cが左）と、いちばん売れなかった並べ方を、店と週を入れ替えて繰り返す
- **ウ**：仮定イに切り替え、上の段の組み合わせを35通りのうち5通りだけ試す

**判断の材料**：1つの並べ方を1店1週間で試すと、週や店の違いも売上に入る。棚の入れ替えには1回2時間かかる。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（数え方として）**：ア は「左はC」を前提に、次の位置を調べる。前提が正しければ、少しずつよい並べ方に近づける。イ は、同じ並べ方を違う店・週で繰り返すので、「Cが左の週が売れた」のが並べ方のせいか、週や店のせいかを分けやすくなる。ウ は35通りのうち5通りしか試せず、選んだ5通りの中のいちばんしか分からない。

**統計の外で決めること**：今の結果が週や店のたまたまかもしれないなら、まず イ で確かめてから ア に進む。どれを選んでも、試した並べ方と置いた仮定を、記録に残す。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何を確かめたいか（どの並べ方がよいか）と、試せる数を書いたか |
| 仮定 | 売上に効くものの仮定を書き、仮定ごとに試す数を数えたか |
| 方法 | 試せる数に収まる仮定を選び、その理由を書いたか |
| 検証 | ラボで階乗・組合せの数を確かめたか |
| 切り分け | 言えること（試した中のいちばん）と、言えないこと（試していない並べ方・仮定の外）を分けたか |
| 解釈 | いちばん売れた理由の読み方を2つ以上並べ、次に試すことを書いたか |
