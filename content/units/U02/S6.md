### 探究｜12枠で、どの仮定を置いて並べ方を試すか

新しい棚に7つの商品を1列に並べる。どの並べ方がよく売れるかを確かめたい。試せるのは、3店で4週間ずつ、1店1週間に1つの並べ方で、合わせて12枠（1枠＝1店の1週間）まで。

並べ方の数は、売上に何が効くとみるか（仮定）で変わる。

| 売上に効くとみるもの | 試す並べ方の数 |
| --- | --- |
| 7つの並び全部 | 7!＝5,040 通り |
| 仮定ア：いちばん左（入口側）の1つだけ | 7 通り |
| 仮定イ：左から3つにどれが入るかだけ（3つの中の順は効かない） | ₇C₃＝35 通り |

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 12枠に収まる仮定はどれか。収まらない仮定は、試すと何が足りなくなるか
2. 仮定アを選ぶと、何を確かめないことになるか（いちばん左以外の並び）。仮定イを選ぶと何を確かめないか
3. 試した結果の「いちばん売れた並べ方」は、何の中のいちばんかを書く
4. いちばん売れた理由の読み方（2つ以上）を書く
5. 次に何を試すかを決める（下の課題）

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（1枠に1つの並べ方を、3店×4週の12枠で試すとみて）**：並べ方全部（5,040 通り）は12枠の420倍で、試せない。仮定アの7通りは収まり、5枠が残る。仮定イの35通りは収まらず、35通りのうち12通りしか試せない。

**仮定を選ぶと、確かめないことになるもの**：仮定アでは、いちばん左以外の6つの並びは、試した7枠でたまたま決まったまま。2番目以降の並びが効いていても、それは見えない。仮定イでは、左から3つの中の順と、残りの4つの並びを確かめない。

**この結果だけでは言えないこと（店・週による違いがなく、週ごとの偶然のぶれが小さいとみても）**：仮定アで試して「商品C を左に置いた枠がいちばん売れた」としても、それは試した7通りの中のいちばんで、5,040 通りの中のいちばんではない。1つの並べ方を1枠ずつしか試さないので、偶然のぶれの大きさも分からない。

**解釈の例（商品C を左に置いた枠がいちばん売れたとき）**：
- 商品C は目立つ位置にあると手に取られやすい商品で、入口側に置くのが効いた
- 商品C の枠は、たまたま2番目に置いた商品との組み合わせがよかった。左の1つだけが効くという仮定アが外れていた
- 商品C の枠は、その店・その週に客が多かった。並べ方とは関係ない（店・週の違いの分け方は {{unit:U32}}）

どの読み方が当たるかは、この12枠の売上だけからは決められない。

**統計の外で決めること**：どの仮定を置くかは、売場の経験（客はどこから見るか）で決める。置いた仮定と、試していない並べ方があることを、結果の報告に書く。
:::

### 課題｜残りの5枠で、何を試すか

**問い**　仮定アで7通りを試し、商品C を左に置いたときがいちばん売れた。残りの5枠を何に使うか。

- **ア**：商品C を左に固定し、2番目に置く商品を調べる（残りの6つから選ぶので6通り。5枠に収まらない）
- **イ**：仮定イに切り替え、左から3つの組み合わせを、35通りのうち5通りだけ試す
- **ウ**：仮定を「左から2つの組（順も効く）」に変え、試す数を数え直す（₇P₂＝42 通り）

**判断の材料**：棚の入れ替えには1回2時間かかる。12枠の残りは5枠。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（残りが5枠で、1枠に1つの並べ方を試すとみて）**：ア は6通りで5枠に収まらないので、2番目の候補を1つ外す。外した候補については何も言えない。イ は35通りのうち5通りしか試せず、選んだ5通りの中のいちばんしか分からない。ウ は42通りで、5枠では1割強しか試せない。仮定を細かくするほど試す数が増え、同じ枠数で確かめられる割合が下がる。

**統計の外で決めること**：「左の1つが効く」という見込みが強いなら ア で、外す候補を売場の経験で決める。入れ替えの手間（1回2時間）が5回で10時間になることも、枠を使うかどうかの判断に入れる。どれを選んでも、試した並べ方と置いた仮定を記録に残す。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何を確かめたいかと、試せる枠の数を書いたか |
| 仮定 | 売上に効くものの仮定を置き、仮定ごとに試す数を数えたか |
| 方法 | 枠に収まる仮定を選び、その仮定で確かめないことを書いたか |
| 検証 | ラボで階乗・順列・組合せの数を確かめたか |
| 切り分け | 言えること（試した中のいちばん）と、言えないこと（試していない並べ方・仮定の外）を分けたか |
| 解釈 | いちばん売れた理由の読み方を2つ以上並べ、次に試すことを書いたか |
