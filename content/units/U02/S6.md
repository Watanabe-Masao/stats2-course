### 課題A｜自分の表計算シートを Σ で読む

職場で使っている表計算シートから、合計・平均・比率の式を3つ選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 元の式 | セルの式（SUM・AVERAGE など） |
| Σで書くと | 何から何まで、何を足すか |
| 書き下すと | 小さな例（3行）で足し算に |
| 注意 | 2乗・割り算の順番、空のセルの扱い |

### 課題B｜分散の計算を2通りで確かめる

**問い**　1週間の日販7個から分散を計算する。「偏差を2乗して足す」方法と「Σx²−n x̄²」の方法の両方で計算し、一致するか、どちらが計算しやすいかを決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**決め方**：手で計算するなら、平均が整数のときは偏差の方法、平均が小数のときは Σx² の方法が楽なことが多い。

**小さな例で検証**：ラボの「Σを書き下す」で 2, 4, 6 を入れ、偏差平方和8と 56−3×4²＝8 が一致することを確かめる。値を変えても一致する。

**弱点**：値が大きく（例えば売上が百万円単位で）ばらつきが小さいとき、Σx² と n x̄² がほとんど同じ大きさになり、引き算で桁が落ちて誤差が出やすい。コンピュータでも偏差の方法の方が安全。
:::

### 課題C｜組合せの数で「全部試せるか」を判断する

商品10品から3品を選ぶ組合せ、20品から5品を選ぶ組合せの数を求め、全部の組合せを試せるかを判断する。試せないときの代わりの方法も書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何を計算したいかが明確か |
| 仮定 | 足す範囲・データの個数を確かめたか |
| 方法 | 書き下し・ルールでの変形を使ったか |
| 検証 | 小さな例やラボで確かめたか |
| 切り分け | 桁落ち・巨大な数など、計算の限界を書いたか |
