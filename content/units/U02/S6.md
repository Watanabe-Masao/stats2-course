### 探究｜12枠で、どの仮定を置いて載せ方を試すか

週に1回配るチラシに、7つの商品を上から順に載せる。どの載せ方がよく売れるかを確かめたい。試せるのは、3店で4週間ずつ、1店1週間に1つの載せ方で、合わせて12枠（1枠＝1店の1週間）まで。

載せ方の数は、売上に何が効くとみるか（仮定）で変わる。

| 売上に効くとみるもの | 試す載せ方の数 |
| --- | --- |
| 7つの順番全部 | 7!＝5,040 通り |
| 仮定ア：いちばん上（表紙）の1つだけ | 7 通り |
| 仮定イ：上から3つにどれが入るかだけ（3つの中の順は効かない） | ₇C₃＝35 通り |

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 12枠に収まる仮定はどれか。収まらない仮定は、試すと何が足りなくなるか
2. 仮定アを選ぶと、何を確かめないことになるか（いちばん上以外の順番）。仮定イを選ぶと何を確かめないか
3. 試した結果の「いちばん売れた載せ方」は、何の中のいちばんかを書く
4. いちばん売れた理由の読み方（2つ以上）を書く
5. 次に何を試すかを決める（下の課題）

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（1枠に1つの載せ方を、3店×4週の12枠で試すとみて）**：載せ方全部（5,040 通り）は12枠の420倍で、試せない。仮定アの7通りは収まり、5枠が残る。仮定イの35通りは収まらず、35通りのうち12通りしか試せない。

**仮定を選ぶと、確かめないことになるもの**：仮定アでは、いちばん上以外の6つの順番は、試した7枠でたまたま決まったまま。2番目以降の順番が効いていても、それは見えない。仮定イでは、上から3つの中の順と、残りの4つの順番を確かめない。

**この結果だけでは言えないこと（店・週による違いがないとみても）**：仮定アで試して「商品C をいちばん上に載せた枠がいちばん売れた」としても、それは試した7通りの中のいちばんで、5,040 通りの中のいちばんではない。1つの載せ方を1枠ずつしか試さないので、偶然のぶれが小さいという前提そのものを確かめられない。

**解釈の例（商品C をいちばん上に載せた枠がいちばん売れたとき）**：
- 商品C は表紙にあると目に留まりやすい商品で、いちばん上に載せるのが効いた
- 商品C の枠は、たまたま2番目に載せた商品との組み合わせがよかった。いちばん上の1つだけが効くという仮定アが外れていた
- 商品C の枠は、その店・その週に客が多かった。載せ方とは関係ない（店・週の違いの分け方は {{unit:U32}}）

どの読み方が当たるかは、この12枠の売上だけからは決められない。

**統計の外で決めること**：どの仮定を置くかは、チラシの経験（客はどこまで読むか）で決める。置いた仮定と、試していない載せ方があることを、結果の報告に書く。
:::

### 課題｜残りの5枠で、何を試すか

**問い**　仮定アで7通りを試し、商品C をいちばん上に載せたときがいちばん売れた。残りの5枠を何に使うか。

- **ア**：商品C をいちばん上に固定し、2番目に載せる商品を調べる（残りの6つから選ぶので6通り。C の枠で2番目に載せた1通り（例：商品D）は済んでいるので、残りの5通りが5枠にちょうど収まる）
- **イ**：仮定イに切り替え、上から3つの組み合わせを、35通りのうち5通りだけ試す
- **ウ**：仮定を「上から2つの組（順も効く）」に変え、試す数を数え直す（₇P₂＝42 通り。最初の7枠で7通りには当たっている）

**判断の材料**：チラシの作り直しには1回2時間かかる。12枠の残りは5枠。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（残りが5枠で、1枠に1つの載せ方を試すとみて）**：ア は5枠に収まるが、済んでいた1通り（C の枠）だけは最初の7枠の中の別の店・週で、残りの5通りと店・週がそろわない。2番目の6通りを同じ条件で比べたいなら、6通りとも新しく試す必要があり、5枠では1つ足りない。イ は35通りのうち5通りしか試せず、選んだ5通りの中のいちばんしか分からない。ウ は42通りで、済んだ7通りと合わせても12通りで、3割に届かない。仮定を細かくするほど試す数が増え、同じ枠数で確かめられる割合が下がる。

**統計の外で決めること**：「いちばん上の1つが効く」という見込みが強いなら ア で、C の枠だけ店・週が違うことを報告に書く。作り直しの手間（1回2時間）が5回で10時間になることも、枠を使うかどうかの判断に入れる。どれを選んでも、試した載せ方と置いた仮定を記録に残す。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何を確かめたいかと、試せる枠の数を書いたか |
| 仮定 | 売上に効くものの仮定を置き、仮定ごとに試す数を数えたか |
| 方法 | 枠に収まる仮定を選び、その仮定で確かめないことを書いたか |
| 検証 | ラボで階乗・順列・組合せの数を確かめたか |
| 切り分け | 言えること（試した中のいちばん）と、言えないこと（試していない載せ方・仮定の外）を分けたか |
| 解釈 | いちばん売れた理由の読み方を2つ以上並べ、次に試すことを書いたか |
