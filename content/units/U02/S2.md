### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：偏差の合計が0になる理由**

- **条件**：平均 x̄ を、そのデータ自身から計算したとき
- **対象と結論**：偏差の合計 Σ(xᵢ−x̄) は必ず0になる
- **根拠**：Σ(xᵢ−x̄)＝Σxᵢ−n×x̄ で、n×x̄＝Σxᵢ だから
- **成り立たない場合**：x̄ ではない別の値（例えば母平均 μ）との差を足すと、一般に0にならない

::: toggle つなげると（お手本の文）
「データ自身の平均からの偏差を合計すると、必ず0になる。Σ(xᵢ−x̄)＝Σxᵢ−n×x̄ で、平均の定義から n×x̄＝Σxᵢ だからである。ただし平均以外の値との差を足した場合は0になるとは限らない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「Σx² は、合計を2乗したものです。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 「合計を2乗」は (Σx)²。Σx² は各値を2乗してから足す。

**言い直しの例**

「Σx² は、各データを2乗してから合計したものである。合計してから2乗する (Σx)² とは違う。2, 4, 6 なら Σx²＝56、(Σx)²＝144。」
:::

::: toggle 取り違えやすい言葉
- **「添字」と「掛け算」**：xᵢ＝i 番目のデータ（添字）／2x＝2 と x の掛け算
- **「Σ」と「Π」**：Σ＝全部足す（平均・分散）／Π＝全部掛ける（成長率の幾何平均・独立な確率の積）
- **f(x) と f×x**：f(x)＝x を入れたときの出力／括弧は掛け算ではない
:::
