### 2｜意味をつかむ：記号を見たら書き下す　{{power:P3}}

統計の式の記号は、長い足し算・掛け算を短く書くための約束。まず具体的な数で書き下す。

::: ask Σ が出てきた
→ 「i＝1 から n まで、中身を全部**足す**」。
:::

::: ask n! が出てきた
→ 「n から 1 まで全部**掛ける**」（4!＝4×3×2×1＝24）。
:::

::: ask xᵢ や f(x) が出てきた
→ xᵢ は「**i 番目**のデータ」、f(x) は「x を入れたときの出力」。どちらも掛け算ではない。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i,\qquad n!=n\times(n-1)\times\cdots\times1
$$

| 記号 | 読み方（2, 4, 6 の例） |
| --- | --- |
| i | 何番目か（1, 2, 3） |
| xᵢ | i 番目の値（x₁＝2, x₂＝4, x₃＝6） |
| n | データの個数（3） |
| Σxᵢ | 2＋4＋6＝12 |

**式を言葉で読む**：Σ の下の i＝1 が「どこから」、上の n が「どこまで」、右の xᵢ が「何を足すか」。平均は「全部足して個数で割る」。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　入口の販売数 2, 4, 6 個。Σxᵢ、Σxᵢ²、(Σxᵢ)²、平均、偏差平方和を求めよ。

| xᵢ | xᵢ² | (xᵢ−x̄)² |
| --- | --- | --- |
| 2 | 4 | 4 |
| 4 | 16 | 0 |
| 6 | 36 | 4 |
| **12** | **56** | **8** |

1. Σxᵢ＝**12** → 平均 x̄＝12÷3＝**4**
2. Σxᵢ²＝4＋16＋36＝**56**（2乗してから足す）
3. (Σxᵢ)²＝12²＝**144**（足してから2乗）
4. 偏差平方和 Σ(xᵢ−x̄)²＝4＋0＋4＝**8**

{{lab:LAB-sigma@s1-sum}}

::: key
Σの中で**先に何をするか**を見る。56 と 144 のように、順番で答えが変わる。偏差の合計は必ず0なので、散らばりは2乗してから足す（{{unit:U07}} で使う）。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-sigma@s1-dev}}

1. **予想**：ラボの課題カードで、3, 5, 10 の偏差の合計を入れる。
2. **操作**：結果を見たら、値や個数を −／＋ で動かす。
3. **観察**：偏差の合計はどう変わるか。(Σx)² の正方形のうち、色の部分（Σx²）と灰色の部分はどう変わるか。
4. **説明**：「値をどう動かしても偏差の合計は□。なぜなら□」を1文で書く。
5. **ラボなしで**：1, 2, 9 の平均と、偏差を3つ書き、合計を確かめる。

::: toggle 答え（書いてから開く）
- **観察**：偏差の合計はいつも0。値を1つ大きくすると、(Σx)² の正方形は Σx² の小さな正方形の合計より速く大きくなる（灰色の部分も広がる）。
- **説明の例**：「値をどう動かしても偏差の合計は0。平均は全部足して個数で割った値なので、n×x̄＝Σx となり、Σ(x−x̄)＝Σx−n×x̄＝0 だから」
- **ラボなしで**：平均 12÷3＝**4**、偏差 −3, −2, 5、合計 **0**。
:::
