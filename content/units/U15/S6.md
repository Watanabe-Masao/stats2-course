### 課題A｜レジの応援基準を作る

POSの時刻データから、15分ごとの来店（会計）人数を数え、次を作る。

| 項目 | 書くこと |
| --- | --- |
| λ | 時間帯ごとの15分あたりの平均人数 |
| 確率 | 「k 人以上」の確率（ポアソン分布で計算） |
| 基準 | 何人以上で応援を呼ぶか、その確率（呼ぶ頻度） |
| 確かめ | 実際の人数の平均と分散が近いか |

### 課題B｜抜き取り検査で使う分布を決める

**問い**　入荷した箱から何個か抜き取って不良を数える。箱の大きさと抜き取る数によって、超幾何分布と二項分布のどちらで計算するかを決め、見逃す確率を出す。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：戻さずに抜くので本来は超幾何分布。箱の中身 N に比べて抜く数 n が小さい（目安として n が N の1割以下）なら、二項分布でもほぼ同じになる。20個の箱から4個なら差が出るので超幾何で計算する。

**小さな例で検証**：ラボの「戻さず取り出す」で N＝20・K＝2・n＝4 と N＝200・K＝20・n＝4 を比べ、二項分布との差を見る。

**成り立たない条件と、その先の判断**：不良が箱の上の方にかたまっているなど、どの個体も同じように選ばれる前提が崩れると、どちらの分布でも見逃しを小さく見積もる。
:::

### 課題C｜クレームが「いつもより多い」の判断基準

1週間のクレーム件数の平均を λ とし、何件以上なら「いつもより多い」と判断するかを、ポアソン分布で k 件以上の確率が5%を下回る k として決める。過去の週の件数で、平均と分散が近いか（ポアソン分布で考えてよいか）も確かめる。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何を固定し、何を数えるかが明確か |
| 仮定 | 独立・率が一定・戻すかどうかを書いたか |
| 方法 | 分布を選び、λ を区間に合わせたか |
| 検証 | 実データの平均・分散やラボで確かめたか |
| 切り分け | 時間帯による違い、まとめて起きる場合を書いたか |
