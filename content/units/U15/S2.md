### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：問い合わせ件数にポアソン分布を使う理由**

- **条件**：問い合わせが互いに独立に、一定の平均率で起きるとき
- **対象と結論**：一定時間の問い合わせ件数は、平均 λ のポアソン分布で表せる
- **根拠**：時間を細かく区切ると、各瞬間に1件起きるかどうかの小さな確率の試行が非常に多く並んだもの（n大・p小の二項分布）とみなせるから
- **成り立たない場合**：時間帯で平均率が大きく変わる、または1件が次の件を呼ぶ（まとめて来る）ときは当てはまりにくい

::: toggle つなげると（お手本の文）
「問い合わせが独立に一定の平均率で起きるなら、一定時間の件数はポアソン分布で表せる。時間を細かく区切ると、小さな確率の試行がたくさん並んだ二項分布とみなせるからである。ただし時間帯で率が変わったり、まとめて起きたりする場合は当てはまりにくい。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「1時間に平均2件なので、30分でも平均2件です。1時間に3件以上来ることはめったにありません。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- λ は区間の長さに比例する。30分なら平均1件。
- 3件以上の確率は約32%で、「めったにない」とは言えない。

**言い直しの例**

「1時間に平均2件なら、30分では平均1件である。1時間に3件以上来る確率は約32%あり、3回に1回ほどは起きるので、その時間帯の人員を考えておく必要がある。」
:::

::: toggle 取り違えやすい言葉
- **「二項分布」と「ポアソン分布」**：二項＝回数 n が決まっていて、成功回数に上限 n がある／ポアソン＝区間を決めて数え、件数に上限がない
- **「試行回数」と「失敗回数」**：幾何分布は「成功した回も含めた試行回数」で数える流儀と、「失敗の回数」で数える流儀がある。平均の式が 1/p と (1−p)/p でずれるので、問題文の定義を確かめる
- **「二項分布」と「超幾何分布」**：二項＝毎回同じ確率（戻す）／超幾何＝戻さずに引き、残りの割合が変わる
:::

### 分布の早見

| 分布 | 固定する量 → 数えるもの |
| --- | --- |
| 二項 | 試行回数 n → 成功回数 |
| ポアソン | 時間・面積などの区間 → 発生件数 |
| 幾何 | 成功1回 → そこまでの試行回数 |
| 負の二項 | 成功 r 回 → そこまでの試行回数 |
| 超幾何 | 母集団の構成と抽出数 → 戻さず引いた成功数 |
