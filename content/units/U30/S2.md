**お手本：重回帰の売価の係数 −1 の意味**

- **条件**：8店の売価 x₁・客数 x₂・販売数 y で重回帰し、ŷ＝40−x₁＋3x₂ を得たとき
- **対象と結論**：売価の係数 −1 は「客数が同じ店どうしでは、売価が1高い店は販売数が平均1少ない」関係を表す
- **根拠**：重回帰の係数は、ほかの説明変数を一定にしたときの y の変化を表すから。売価だけの単回帰（＋1.38）には、売価と一緒に動く客数の効果が混ざっている
- **成り立たない場合**：観察データなので値上げの因果の効果とは限らない。t≒−1.27 で、8店では0と区別できない。売価8〜13 の外では言えない

::: toggle つなげると（お手本の文）
「8店の売価・客数・販売数で重回帰し ŷ＝40−x₁＋3x₂ を得たとき、売価の係数 −1 は、客数が同じ店どうしでは売価が1高い店は販売数が平均1少ない関係を表す。重回帰の係数はほかの説明変数を一定にしたときの変化を表し、売価だけの単回帰には客数の効果が混ざるからである。ただし観察データなので値上げの因果の効果とは限らず、8店では0と区別できない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「変数を5つに増やしたら R² が0.60 から0.65 に上がったので、5つのモデルの方が良いです。F 検定が有意だったので、5つの変数はどれも効いています。週末ダミーの係数が4 なので、週末は平日より平均で4 売れます。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 変数を足すと R² は下がらない。数の違うモデルは自由度調整済み R² で比べる（n＝20 なら A 0.553、B 0.525 で A が上）。
- F はモデル全体の検定。どの変数が効いているかは係数ごとの t で見る。
- ダミーの係数は「ほかの変数をそろえた差」。単純な平均の差とは違う。

**言い直しの例**

「自由度調整済み R² は2変数のモデルの方が高いので、2変数のモデルを選ぶ。F 検定はモデル全体が役に立つことを示すだけで、個々の変数は t で確かめる。週末ダミーの係数4 は、同じ客数で比べたときの週末と平日の差。」
:::

::: toggle 取り違えやすい言葉
- **「単回帰の傾き」と「重回帰の係数」**：そろえている条件が違う。重回帰はほかの変数を一定にしたとき
- **「標準偏差」と「係数の標準誤差」**：データのばらつきか、係数の推定値のぶれか
- **「R²」と「自由度調整済み R²」**：変数を足すと前者は下がらない。後者は割引で下がることがある
- **「F 検定」と「t 検定」**：モデル全体（係数はすべて0か）と、1つの係数（その係数は0か）
- **「ダミーの係数」と「平均の差」**：ほかの変数をそろえた差か、そろえない差か
:::

### 回帰の出力表の早見

| 欄 | 読み方 |
| --- | --- |
| 係数 | ほかの変数を一定にしたときの変化 |
| 標準誤差 | 係数のぶれの目安 |
| t（係数÷標準誤差） | 自由度 n−k−1 の t の点と比べる |
| R²・調整済み R² | 説明できた割合（変数の数で割引） |
| F | モデル全体（自由度 k, n−k−1） |

^ ダミー変数は、区分の数より1つ少なく入れる（基準の区分は入れない）。
