### なぜ？｜説明変数どうしの相関が強いと、なぜ係数が1つずつではばらつくのか

ラボは、本当の係数がどちらも1 の同じ仕組みから、標本を40回取り直し、そのたびの (b₁, b₂) を点で打つ。x₁ と x₂ の相関を0・0.5・0.95 と上げて、点の並び方がどう変わるかと、b₁ のばらつき・b₁＋b₂ のばらつきを読む。ラボのまとめの文を読む前に、なぜそうなるのかを自分の言葉で書いてから開く。

::: toggle 動かしてから開く
相関が0 なら、点は (1, 1) のまわりに丸く散らばる。相関が0.95 になると、点は右下がりの細長い帯に並び、b₁ だけ・b₂ だけで見ると大きくばらつき、符号が逆の回も出る。ところが b₁＋b₂ のばらつきは、相関0 のときより、むしろ小さくなる。

x₁ と x₂ がほとんど一緒に動くデータでは、y が増えたのが x₁ のせいか x₂ のせいかを、データから分けにくい。「x₁ も x₂ も1 大きいところでは、y が平均2 大きい」ことははっきり分かるので、b₁＋b₂ は標本が変わっても2 の近くにそろう。ところが、その2 を b₁ と b₂ にどう分けるかは、2つが別々に動いたわずかな点だけで決まり、標本ごとに大きく揺れる。だから点は「b₁＋b₂＝2」の線に沿って、右下がりに並ぶ。
:::

### 本当に？｜「客数を一定にして、売価だけを変えたら」は、データで確かめられるか

重回帰の係数は「客数が同じ店どうしで比べると、売価が1 高い店は販売数が平均 b₁ 違う」と読み、さらに「客数はそのままで売価だけを変えたら」と読みたくなる。例題Aの8店（S1 の「8店のデータ」）を見ると、売価の高い店ほど客数も多い。ラボで、売価13・客数3 の店の販売数を予測させ、その組み合わせに近い店がデータにあるかを見る。

::: toggle 動かしてから開く
予測値は ŷ＝40−13＋3×3＝36。ところが8店には、売価13 の店は客数7 しかなく、客数3 の店は売価8 しかない。「売価が高くて客数が少ない店」は1つもない。式は、売価と客数の組み合わせを足し算でつないで、データにない角の値まで出してしまう。

1つずつの説明変数は観測した範囲の中でも、組み合わせが範囲の外なら外挿（{{unit:U29}}）と同じ。係数を「ほかを一定にして1つだけ変えたら」と読めるのは、式の形（1次で足し算）が、データのない組み合わせでも成り立つとみたときだけ。説明変数どうしの相関が強いほど、データのない組み合わせは広くなる。さらに観察データでは、式に入れていない要因が売価と一緒に動いている分も係数に入りうるので、式の形が正しくても「売価を変えたらこうなる」とは限らない（S1 の注意）。
:::

### ほかでは？｜つながり

- **ほかの変数と一緒に動く分を除いた相関**：偏相関係数（{{unit:U28}}）。重回帰の係数も、ほかの説明変数と直線的に一緒に動く分を除いた傾き
- **1つの説明変数の回帰**：単回帰と平均への回帰（{{unit:U29}}）
- **平方和を自由度で割って比べる**：分散分析（{{unit:U32}}）
- **何をそろえれば効果と言えるか**：無作為化と交絡（{{unit:U32}}）
- **平均の効果1つで消えるもの（交互作用）**：二元配置の交互作用（{{unit:U32}} の発展）

### 説明してみる

::: task
担当者が、10日分の売上を、説明変数9つ（気温・客数・チラシ枚数と、月曜を基準にした曜日のダミー6つ）で重回帰したところ、R²＝1 になった。担当者は「9つの指標で売上を完全に説明できた」と書いた。なぜ R²＝1 になったのかと、この報告のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（10日の記録が正しいとみて）**：係数は切片と合わせて10個で、データは10日。10個の係数を動かせば、10日の売上をちょうど通る式が（説明変数の値が1次独立なら）いつでも作れる。残差は全部0 で SSE＝0、R²＝1 になるのは、どんなでたらめな9つの数を入れても同じ。残差の自由度は 10−9−1＝0 で、自由度調整済み決定係数も、残差の平均平方も定まらない。この R²＝1 は、9つの指標と売上の関係について何も言っていない。

**解釈の例**：
- 売上が本当に客数と曜日で決まっていて、この式は仕組みに近い。ただし10日では、その見立てとたまたま合わせた式を区別できない
- 10日の中に特売の日や雨の日があり、その日の売上を、どれかの曜日のダミーやチラシの係数が引き受けている

どちらかは、この10日の数字だけからは決められない。

**統計の外で決めること**：どの変数に、売上に効くと考える筋道があるか。データの数に対して説明変数をいくつまで使えるかは、残差の自由度から統計の側で言える（自由度が0 では何も言えない）。
:::
