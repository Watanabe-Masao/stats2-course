### 探究｜キャンペーンの係数に、どの説明変数を並べるか

ある店の10日の記録。キャンペーン C（ある日1・ない日0）、週末 W（週末1・平日0）、客数 N（百人）、売上 y（万円）。

| C・W・客数 | 売上 |
| --- | --- |
| 0・0・4.8 | 24.5 |
| 0・0・5.1 | 25.0 |
| 0・0・5.3 | 26.5 |
| 0・0・4.9 | 25.5 |
| 0・0・4.9 | 23.5 |
| 1・0・5.8 | 28.0 |
| 0・1・6.4 | 32.5 |
| 1・1・7.1 | 34.0 |
| 1・1・7.2 | 35.0 |
| 1・1・6.9 | 33.5 |

本部のメモ：「キャンペーンの日は、ない日より売上が平均6.4万円多い。キャンペーンの日を増やす」。この差を重回帰で確かめるとき、キャンペーン C と並べる説明変数を何にするかで、C の係数は何の差になるのか。

1. 表とメモから、確かめたいことを自分で問いにする（例：キャンペーンの日は、ほかに何が違う日か）
2. 上のラボ（C と週末 W）で、C だけの単回帰の傾きと、W を並べた重回帰の C の係数を読む
3. 下のラボ（C と客数 N）で、N を並べた重回帰の C の係数を読む
4. 3つの数が、それぞれ何と何の差かを言葉にする
5. 統計で言えることと言えないことを分け、差の読み方を2つ以上書く

::: toggle 聞き取りで分かったこと（自分の問いを書いてから開く）
- キャンペーンの日は、本部が2週間前に決め、週末に多く置いてきた
- キャンペーンの日は値引きをしている
- キャンペーンの目的は、新しい客を呼ぶこと
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（10日の記録が正しいとみて）**：
- C だけの単回帰の傾きは約6.4（t 約3.1、自由度8）で、キャンペーンのある日とない日の売上の平均の差そのもの。キャンペーンの日は4日中3日が週末で、ない日は6日中1日だけが週末
- 週末 W を並べると、C の係数は約2.4（t 約3.0、自由度7）。週末と直線的に一緒に動く分を除いたあとの差で、C の差が週末と平日で同じとみる式での値。実際には、平日どうしの差は約3.0（キャンペーンのある平日1日 対 ない平日5日）、週末どうしの差は約1.7（キャンペーンのある週末3日 対 ない週末1日）で、2.4 はこの2つをならした値。どちらの差も、相手が1日しかない比べに頼っている
- 客数 N を並べると、C の係数は約 −1.3。客数と直線的に一緒に動く分まで除いたあとの差で、推定値は負だが、t は約 −1.9（自由度7）で0 と区別できない。キャンペーンの日の客数は5.8〜7.2 百人、ない日は4.8〜5.3 百人と6.4 百人で、重なるのはない日の1日だけ。この係数は、客数の直線を重ならない所まで伸ばした当てはめに頼る

同じ C の係数が、並べた変数で 6.4・2.4・−1.3 と変わる。どれが正しいかではなく、何と一緒に動く分を除いた差かが違う。

**解釈の例**：
- 本部は、もともと客の多い週末に重ねてキャンペーンを置いてきた。メモの「平均6.4 多い」は、売れる日に置いたことの表れ
- 週末のほかにキャンペーンの日の決め方と売上の両方に関わるものがなく、客数がキャンペーンの結果だとみれば、キャンペーンは客を呼んで売上を増やしたが、同じ客数の日と比べると売上は増えていない（値引きで1人あたりの買い物が減ったとも読める）
- 客数はキャンペーンと関係なく天気や行事で決まっていて、キャンペーンの日がたまたま客の多い日に重なった。そうなら、キャンペーンが売上を増やしたとは言えない

どれかは、この10日の数字だけからは決められない。

**統計の外で決めること**：メモの「日を増やす」を、その日の売上で判断するか、目的（新しい客を呼ぶ）で判断するか。
:::

### 課題｜「キャンペーンの効果」として報告する係数を選ぶ

**問い**　本部への報告に、キャンペーンの効果として1つの係数を載せる。どれを載せるか。

- **ア**：C だけの単回帰の傾き
- **イ**：週末 W を並べた重回帰の C の係数
- **ウ**：客数 N を並べた重回帰の C の係数

**判断の材料**：上の「聞き取りで分かったこと」の3つ（日の決め方・値引き・目的）。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（記録が正しいとみて）**：ア は、キャンペーンの日に週末が多い分まで含んだ差。イ は、週末と直線的に一緒に動く分を除いた差で、平日の差と週末の差をならした値。頼る日が少ない（キャンペーンのある平日1日と、ない週末1日）。ウ は、さらに客数と直線的に一緒に動く分も除いた差で、客数がほとんど重ならないので直線の当てはめに頼り、0 とも区別できない。

**統計の外で決めること**：キャンペーンの日は本部が2週間前に決めたので、その日の客数がキャンペーンを決めたのではない。客数はキャンペーンのあとに来るもので、目的（新しい客を呼ぶ）の通り道だとみれば、「効果」を見るのに客数は並べない。週末はキャンペーンの日の決め方と売上の両方に関わるので、並べて除く。この見立てなら イ を載せる。値引きで1人あたりの買い物が減る分も、イ には効果の一部として入る。ただし、週末のほかに日の決め方と売上の両方に関わるもの（月末・行事）がないとみたときの話で、頼る日も少ない。どれを載せても、式に何を並べた係数かを書き添える。キャンペーンの日をくじで決めれば、週末への偏りそのものをなくせる（{{unit:U32}}）。
:::
