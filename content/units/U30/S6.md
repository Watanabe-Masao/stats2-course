### 探究｜キャンペーンの係数に、どの説明変数を並べるか

ある店の10日の記録。キャンペーン C（ある日1・ない日0）、週末 W（週末1・平日0）、客数 N（人）、売上 y（万円）。

| C・W・客数 | 売上 |
| --- | --- |
| 0・0・480 | 24.5 |
| 0・0・510 | 25.0 |
| 0・0・530 | 26.5 |
| 0・0・490 | 25.5 |
| 0・0・490 | 23.5 |
| 1・0・580 | 28.0 |
| 0・1・640 | 32.5 |
| 1・1・710 | 34.0 |
| 1・1・720 | 35.0 |
| 1・1・690 | 33.5 |

本部のメモ：「キャンペーンの日は、ない日より売上が平均6.4万円多い。キャンペーンの日を増やす」。この差を重回帰で確かめるとき、キャンペーン C と並べる説明変数を何にするかで、C の係数は何の差になるのか。

- キャンペーンの日は値引きをしている
- キャンペーンの目的は、新しい客を呼ぶこと

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（10日の記録が正しいとみて）**：
- C だけの単回帰の傾きは約6.4 で、キャンペーンのある日とない日の売上の平均の差そのもの。キャンペーンの日は4日中3日が週末で、ない日は6日中1日だけが週末
- 週末 W を並べると、C の係数は約2.4。週末と一緒に動く分を除いた、「週末どうし・平日どうし」をならした差
- 客数 N を並べると、C の係数は約 −1.3 で負になる。客数と一緒に動く分まで除いた、「同じ客数の日どうし」の差で、キャンペーンの日は同じ客数なら売上が少し少ない
- 10日しかないので、どの係数も標準誤差が大きい。ラボの t で、0 と区別できるかも見る

同じ C の係数が、並べた変数で 6.4・2.4・−1.3 と変わる。どれが正しいかではなく、何をそろえた差かが違う。

**解釈の例**：
- キャンペーンは客を呼んで売上を少し増やしているが、値引きで1人あたりの買い物は少し減っている（W を並べた係数が正、N を並べた係数が負）
- 週末に置いたキャンペーンの日は、もともと客の多い日で、メモの6.4 の大半は週末と平日の違い
- 10日のうちキャンペーンのある平日は1日だけで、W を並べた係数2.4 は、その1日にかなり頼っている

**統計の外で決めること**：メモの「日を増やす」を、その日の売上で判断するか、目的（新しい客を呼ぶ）で判断するか。
:::

### 課題｜「キャンペーンの効果」として報告する係数を選ぶ

**問い**　本部への報告に、キャンペーンの効果として1つの係数を載せる。どれを載せるか。

- **ア**：C だけの単回帰の傾き（約6.4）
- **イ**：週末 W を並べた重回帰の C の係数（約2.4）
- **ウ**：客数 N を並べた重回帰の C の係数（約 −1.3）

**判断の材料**：キャンペーンは本部が2週間前に決め、週末に多く置いてきた。キャンペーンの目的は、新しい客を呼ぶこと。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（記録が正しいとみて）**：ア は、キャンペーンの日に週末が多い分まで含んだ差。イ は、週末と一緒に動く分を除いた差で、キャンペーンが客を呼んだ分も、値引きの分も含む。ウ は、客数と一緒に動く分まで除いた差で、キャンペーンが客を呼んだ分が消え、同じ客数の日どうしの差だけが残る。

**統計の外で決めること**：キャンペーンの日の決め方と売上の両方に関わるもの（週末）は、並べて除く。キャンペーンが動かした結果（客数）は、目的（客を呼ぶ）の通り道なので、「効果」を見るなら並べない。この見立てなら イ を載せる。ただし、週末のほかにキャンペーンの日の決め方と売上の両方に関わるもの（月末・行事）がないとみたときの話で、10日では標準誤差も大きい。どれを載せても、式に何を並べた係数かを書き添える。キャンペーンの日をくじで決めれば、週末への偏りそのものをなくせる（{{unit:U32}}）。
:::
