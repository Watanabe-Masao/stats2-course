### 探究｜キャンペーンの効果は、何をそろえれば言えるか

2店の120日分の日販（架空）がある。キャンペーンの日は売上が高いが、キャンペーンは週末に多い。重回帰なら「週末・天気・店を一定にしたときのキャンペーンの係数」を出せる。では、何をそろえれば「キャンペーンの効果」と言えるのか。

{{lab:LAB-explore@s6-adjust}}

はじめは「平日だけ」に絞ってキャンペーンの有無を比べている。絞り方を「週末だけ」「A店だけ」「特別な日を除く」に変え、分け方を天気や店にも変える。クロス集計で、キャンペーンがどの条件に偏っているかも見る。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること**：全部の日で比べたキャンペーンの差は、平日だけ・週末だけに絞ると小さくなる。キャンペーンの日は週末に偏っている。絞って比べると、群ごとの日数が少なくなり、差の確かさは下がる。重回帰で週末・天気・店をそろえた係数は、こうした「そろえた比べ方」を1つの式でまとめたものになる。

**解釈の例1**：週末・天気・店をそろえた差が小さいなら、キャンペーンの効果は小さい。そろえる条件が多いほど、効果の見積もりは正しくなる。

**解釈の例2**：そろえる条件を増やすほど正しくなるとは限らない。たとえばキャンペーンが客数を増やし、その結果売上が増えるなら、客数までそろえるとキャンペーンの効果の一部を消してしまう。何をそろえるべきかは、何が何に影響するかという筋道（データの外の知識）で決まる。

どの変数をそろえるかで係数の意味は変わる。統計は「そろえたらこうなる」までを示す。何をそろえるべきかは統計の外で考え、そのうえで、キャンペーンの日を無作為に決める比べ方（{{unit:U32}}）で確かめる道もある。
:::

### 課題A｜売上の要因を重回帰で説明する

自分の売場の数字（客数・客単価・気温・曜日など）で、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 変数 | y と説明変数、区分はダミー変数にする |
| 係数 | 何を一定にしたときの係数か、t と区間 |
| 全体 | R²・自由度調整済み R²・F |
| 使える範囲 | 観測した範囲、説明変数どうしの相関 |

### 課題B｜変数を入れる・入れないを決める

**問い**　客数とレシート件数（相関0.95）、気温、週末ダミーの候補がある。売上の重回帰に、どれを入れるか決めたい。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：目的を先に決める。予測が目的なら、調整済み R² や別の期間での当たり方で選ぶ。要因の説明が目的なら、相関の強い客数とレシート件数はどちらか一方にする。入れる理由を説明できない変数は、調整済み R² が少し上がっても入れない。

**小さな例で検証**：ラボの「多重共線性」で相関を0.95 にし、b₁ と b₂ が1つずつではぶれることを見る。「変数を足す」で、でたらめな変数を足すと調整済み R² が下がることを見る。

**成り立たない条件と、その先の判断**：観察データの係数は、入れる変数の組み合わせで変わる。「どれが本当の原因か」は統計だけでは決まらず、売場で何が起きているかの知識や、施策を小さく試した結果で判断する。
:::

### 課題C｜出力表を読み手に渡す

重回帰の出力表（係数・標準誤差・t・p・R²・調整済み R²・F・n）を、統計に詳しくない人に渡す1枚の説明を書く。「係数は何をそろえた数か」「どれくらい確かか」「どこまで使えるか（範囲）」「何は言えないか（因果）」を必ず入れる。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何を何で説明するか、目的（予測か説明か）が明確か |
| 仮定 | 入れた変数・範囲・説明変数どうしの相関を書いたか |
| 方法 | 係数を条件付きで読み、t・F・調整済み R² を使い分けたか |
| 検証 | ラボで係数の揺れや変数の足し方を確かめたか |
| 切り分け | 統計で言えること（そろえた差）と、何をそろえるべきかの判断を分けたか |
