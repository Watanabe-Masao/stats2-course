### 探究｜キャンペーンの効果は、何をそろえれば言えるか

本部の分析メモ：「2店の120日で、キャンペーンの日は売上の平均が36.0万円、ない日は30.7万円。キャンペーンで売上が5.3万円増える。来期はキャンペーンの日を増やす」。

{{lab:LAB-explore@s6-adjust}}

「分ける」をキャンペーンにして、「絞る」を全部の日・平日だけ・週末だけと変え、表の売上の平均を読む。「見る値」を客数・客単価に替えても読む。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. メモのどの言葉を確かめるかを、自分で問いにする（例：5.3万円は何と何の差か）
2. ラボで、キャンペーンのある日・ない日の売上の平均を、全部の日・平日だけ・週末だけで読む
3. 同じ分け方で、客数と客単価の平均も読む
4. 重回帰で「キャンペーンの係数」を出すなら、ほかにどの説明変数を入れるかを考える（下の課題）
5. 統計で言えることと言えないことを分け、差の読み方を2つ以上書く

::: toggle 聞き取りで分かったこと（自分の問いを書いてから開く）
- キャンペーンは本部が2週間前に決める。62日のうち40日は週末
- キャンペーンの日は値引きをしている
- キャンペーンの目的は、新しい客を呼ぶこと
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（120日の記録が正しいとみて）**：
- 売上の平均（キャンペーンあり／なし）は、全部の日で 36.0／30.7、平日だけで 29.0／29.0、週末だけで 40.0／39.6。平日どうし・週末どうしで比べると、差はほとんどない
- キャンペーンの日は62日中40日が週末で、ない日の多くは平日。全部の日の差5.3 の大半は、週末と平日の違い（週末はもともと売れる）
- 客数の平均は、キャンペーンの日が平日で約16人、週末で約42人多い。客単価は、平日で約16円、週末で約27円低い。客は増えたが、1人あたりの買い物は減り、売上としてはほとんど相殺されている

重回帰でいえば、週末ダミーを入れない式のキャンペーンの係数は、週末の分まで含んだ5.3 に近い値になり、週末ダミーを入れると、その分が除かれて小さくなる。何を入れたかで、係数が何の差かが変わる。

**解釈の例**：
- キャンペーンは客を呼んでいるが、値引きで客単価が下がり、売上はほとんど増えていない
- キャンペーンを、もともと売れる週末に多く置いてきた。メモの5.3 は、置いた日の違いを見ている
- 呼んだ新しい客が、次の週以降に来るようになっているなら、その日の売上だけでは効き目は測れない

どれが当たるかは、この120日の数字だけからは決められない（3つ目は、その日の売上の記録には出てこない）。

**統計の外で決めること**：キャンペーンの目的を、その日の売上に置くか、客数や次の来店に置くか。
:::

### 課題｜キャンペーンの重回帰に、どの説明変数を入れるか

**問い**　売上を目的変数、キャンペーンのダミーを説明変数にした重回帰で、キャンペーンの係数を「効果」として報告する。ほかに何を入れるか。

- **ア**：週末ダミーと店のダミー
- **イ**：ア に加えて、客数
- **ウ**：ア に加えて、天気（雨のダミー）

**判断の材料**：キャンペーンは本部が2週間前に決める（その日の天気は分からない）。キャンペーンの目的は、新しい客を呼ぶこと。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（記録が正しいとみて）**：ア は、キャンペーンの日に偏っていた週末と店の分を除いた差。イ は、さらに客数と直線的に一緒に動く分も除くので、キャンペーンが客を呼んだ分まで消え、残るのは「同じ客数なら」の差で、値引きで客単価が下がった分（負の向き）に近くなる。ウ は、天気がキャンペーンの決め方と無関係（2週間前に決める）なら、キャンペーンの係数はほとんど変わらず、天気で揺れた分だけ残差が小さくなって、係数の標準誤差が小さくなる。

**統計の外で決めること**：何を入れるかは、何が何に効くかの筋道で決める。キャンペーンの前から決まっていて、キャンペーンと売上の両方に関わる週末・店は入れる。キャンペーンが動かした結果である客数は、目的（客を呼ぶ）の通り道なので、「効果」を見るなら入れない。どちらでも、式に何を入れて何をそろえた係数かを、報告に書く。キャンペーンの日を本部がくじで決めれば、週末への偏りそのものをなくせる（{{unit:U32}}）。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 自分の問いが、5.3 が何と何の差かを確かめるものになっていたか |
| 仮定 | キャンペーンの日の決め方（週末に多い・天気は知らない）を、読み方の前に書いたか |
| 方法 | 平日どうし・週末どうしで比べ、客数と客単価にも分けたか |
| 検証 | ラボで絞り方を変えると差がどう変わるかを確かめたか |
| 切り分け | 言えること（そろえた比べ方での差）と、言えないこと（次の来店への効き目・何をそろえるべきか）を分けたか |
| 解釈 | 差の読み方を2つ以上並べ、入れる説明変数とその理由を書いたか |
