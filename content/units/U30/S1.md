### 2｜意味をつかむ：ほかの変数をそろえて読む　{{power:P3}}

::: ask 重回帰の係数は何を表す？
→ ŷ＝b₀＋b₁x₁＋b₂x₂ の b₁ は「**x₂ を一定にしたとき**、x₁ が1多いと y が平均して b₁ 違う」という関係。x₁ だけの単回帰の傾きには、x₁ と一緒に動く x₂ の効果が混ざっているので、重回帰の係数とは符号まで違うことがある。
:::

::: ask その係数はどれくらい確か？
→ 係数を**標準誤差**（標本を取り直したときの係数のぶれの目安）で割った t＝係数÷標準誤差 を、自由度 n−k−1（k は切片を除く説明変数の数）の t 分布と比べる。「係数＝0」を棄却できれば、その変数は役に立っていると言える。95%信頼区間は 係数±t の点×標準誤差。
:::

::: ask モデル全体ではどうか？
→ y のばらつき SST を、回帰で説明できた SSR と残った SSE に分ける。R²＝SSR÷SST は説明できた割合。変数を足すと R² は下がらないので、比べるときは**自由度調整済み R²**＝1−(1−R²)×(n−1)÷(n−k−1) を使う。平方和を自由度で割った**平均平方**の比 F で「係数はすべて0」をまとめて検定する。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
\hat y=b_0+b_1x_1+b_2x_2,\qquad t=\frac{b_j}{SE(b_j)},\qquad F=\frac{SSR/k}{SSE/(n-k-1)}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| b₁ | 客数を一定にしたときの売価の係数（−1） |
| SE(b₁) | b₁ のぶれの目安（0.787） |
| n・k | 8店・説明変数2つ → 自由度5 |
| R²・調整済み | 説明できた割合とその割引 |

**式を言葉で読む**：t は「係数が、そのぶれの何倍の大きさか」。F は「説明できた変動を変数1つあたりにした量が、残った変動の1自由度あたりの何倍か」。どちらも「信号÷雑音」の形。

| 何を見る？ | 指標 | 問い |
| --- | --- | --- |
| 各係数 | t（係数÷SE） | その変数の係数は0と言えるか |
| モデル全体 | F | 説明変数のどれかは役に立つか |
| 当てはまり | R²・調整済み R² | どれだけ説明できたか |

```txt
重回帰：ŷ＝b₀＋b₁x₁＋…＋b_kx_k（最小二乗で求める）
係数の t：t＝b_j÷SE(b_j)、自由度 n−k−1
平方和：SST＝SSR＋SSE、R²＝SSR÷SST＝1−SSE÷SST
調整済み R²＝1−(1−R²)×(n−1)÷(n−k−1)
平均平方：回帰 SSR÷k、残差 SSE÷(n−k−1)、F＝その比（自由度 k, n−k−1）
ダミー変数：週末なら D＝1、平日なら0（基準の平日は入れない）
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　8店の売価 x₁・客数 x₂・販売数 y で重回帰すると、次の出力になった。① 売価の係数を読め。② 売価だけの単回帰の傾きは＋1.38 だった。符号が違うのはなぜか。③ 各係数の t を、t(5) の0.975点2.571 と比べよ。④ 売価10・客数4 の店の予測値と、実際の販売数44 との残差は？

| 項目 | 係数（標準誤差） |
| --- | --- |
| 切片 | 40 |
| 売価 x₁ | −1（0.787） |
| 客数 x₂ | 3（0.892） |

^ R²＝0.844、自由度調整済み R²＝0.781（n＝8、k＝2）。

1. ŷ＝40−x₁＋3x₂。売価の係数 **−1** は「客数を一定にしたとき、売価が1高い店は販売数が平均1少ない」
2. 売価の高い店は客数も多い（x₁ と x₂ の相関0.90）。単回帰の傾き＋1.38 には客数の効果が混ざり、符号まで逆になる
3. 自由度 8−2−1＝5。売価：t＝−1÷0.787≒**−1.27**（|t|＜2.571 で0と言えない）。客数：t＝3÷0.892≒**3.36**（2.571 を超える）
4. ŷ＝40−10＋3×4＝**42**、残差＝44−42＝**2**

{{lab:LAB-mreg@s1-coef}}

::: warn
単回帰の傾きと重回帰の係数は、そろえている条件が違う。どちらかが誤りなのではない。売価の係数が −1 でも、観察データなので「値上げすれば1減る」という因果の効果とは限らない。
:::

::: key
重回帰の係数は「ほかの変数を一定にしたとき」と、条件を付けて読む。係数は t で確かさを見る。8店ほどでは、売価の効果は0と区別できない。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-mreg@s1-dummy}}

1. **予想**：ラボの課題カードで、週末のダミー変数 D の係数を予想する（週末の平均は平日より10多い）。
2. **操作**：結果を見たら、週末の点（橙）を1つずつ上下に動かす。次に「交互作用を入れる」を切り替える。
3. **観察**：D の係数と、単純な平均の差は、どう違って動くか。交互作用を入れると2本の直線はどうなるか。
4. **説明**：「D の係数は平均の差10 より小さい。なぜなら□」を1文で書く。
5. **ラボなしで**：ŷ＝10＋2x＋6D で、客数5 の平日と週末の予測を出す。

::: toggle 答え（書いてから開く）
- **観察**：D の係数は6、平均の差は10。週末の点を上げると両方とも上がるが、平均の差の方が大きく動くことがある。交互作用を入れると2本の直線の傾きが別々になり、「週末の差」は客数によって変わる。
- **説明の例**：「D の係数は平均の差10 より小さい。週末は客数も平均2多く、その客数の違い（傾き2×2＝4）が平均の差に混ざっていて、D の係数はそれを除いた同じ客数での差だから」
- **ラボなしで**：平日 10＋10＝**20**、週末 10＋10＋6＝**26**。差は D の係数の6。
:::
