### 探究｜購入率の分母は、どうやって数えたか

2つの店の先月の購入率を比べる報告が上がってきた。X店は20%、Y店は30%。担当者は「Y店の方が10ポイント高い。X店は売場づくりを見直すべき」と書いた。聞き取ると、次のことが分かった。
- 分子は、どちらの店も購入の件数（レシートの枚数）で、どちらも300枚
- X店の分母は、入口のセンサーが入る向きの通過を数えた1,500回。店員が入るのも、いったん出て戻った客も数える
- Y店の分母は、入口のカメラが、その日のうちの同じ人を1回と数えた人数の1か月分で1,000人

**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 2つの購入率の分子と分母を、言葉で書く（何を何で割ったか。単位はそろっているか）
2. X店の分母1,500回には、来店した人でない数がどれだけ入りうるかを考える
3. X店の分母を Y店と同じ数え方（人）にしたら、購入率は上がるか下がるか。どこまで言えるか
4. 「X店の方が購入率が低い」と言えるかを、分母の数え方と分けて書く
5. 購入率の違いについての解釈（2つ以上）を分ける
6. 次に2店を比べるとき、何をそろえるかを書く（下の課題）

**統計で言えること（分子・分母の記録に数え漏れがないとみて）**：X店は 300÷1,500＝20%、Y店は 300÷1,000＝30%。ただし2つは違う割合で、X店は「入る通過1回あたりのレシート」、Y店は「来た人（その日1回）1人あたりのレシート」。分母の単位が違うので、この2つの差（10ポイント）は比べられない。

**数え方をそろえたら**：X店の入る通過には、店員と出て戻った客も入るので、来た人の数は1,500 以下。人で割ったX店の購入率は20%以上で、上限はこの数からは決まらない。たとえば通過が1人あたり平均1.5回なら、来た人は1,000人で、Y店と同じ30%。

**この数だけでは言えないこと**：X店の売場づくりが Y店より劣るかどうか。分母の数え方の違いだけで、10ポイントの差は消えうるし、逆になりうる。また Y店も、分子はレシート（家族で1枚のこともある）、分母は人なので、「1人あたり」と言い切れない。

**解釈の例**：
- X店の入口は駐車場と店内を行き来しやすく、出入りが多い。センサーの回数が来店客数より大きく出て、購入率が低く見えている
- X店は本当に購入率が低い。通りがかりに入って何も買わない客が多い立地
- Y店は家族連れが多く、家族で1枚のレシートなのに分母は人数で数えるので、Y店の購入率は低めに出ている。そろえると差はもっと大きいかもしれない

どの読み方が当たるかは、この報告の数だけからは決められない。

**統計の外で決めること・確かめること**：2店を比べる前に、来店客数の数え方をそろえる。X店で1日だけ、入口で人の数を手で数えてセンサーの回数と比べ、何倍になっているかを確かめる。売場の見直しは、そろえた数で比べてから決める。
:::

### 課題｜来店客数の数え方を決める

**問い**　全店の購入率を毎月比べる。分母の「来店客数」を、次のどれで数えるか。

- **ア**：入口センサーの通過回数（全店にある。出入りと店員も数える）
- **イ**：カメラで同じ人を1回と数えた人数（Y店など一部の店だけにある）
- **ウ**：毎月1日だけ、入口で人を手で数え、センサーの回数との比を出して、その月の通過回数に掛ける

**判断の材料**：カメラを全店に付けるには費用がかかる。手で数えるのは1店で1日に1人の作業。店の入口の形（出入りのしやすさ）は店ごとに違う。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（1日の比が、その月のほかの日にも当てはまるとみたとき）**：ア は全店で同じ方法だが、店ごとに「通過1回あたりの人数」が違うと、店どうしの購入率は比べられない。イ は分母の意味がいちばんはっきりするが、全店ではそろわない。ウ は、店ごとに通過回数を人数に直す比を出すので、店どうしを比べやすくなる。ただし1日の比が、その月のほかの日にも当てはまるとみている。

**統計の外で決めること**：費用と手間を比べて決める。すぐに始めるなら ウ で、比を出した日と、その日が月のふつうの日かを報告に書く。カメラを付けた店から順に イ に移る。どれにしても、報告には分母を何で数えたか（通過か人か）を書く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 2つの割合の分子と分母を、言葉で書いたか |
| 仮定 | 分母を何で数えたか（通過か人か）と、分子の単位が2店でそろっているかを書いたか |
| 方法 | 分母の数え方をそろえたとき、割合がどちら向きに動くかを考えたか |
| 検証 | ラボで、分母を変えたときの割合を確かめたか |
| 切り分け | 計算で言えること（それぞれの割合の値）と、言えないこと（どちらの店の売場が良いか）を分けたか |
| 解釈 | 割合の違いの読み方を2つ以上並べ、次に確かめることを書いたか |
