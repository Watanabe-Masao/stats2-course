### 探究｜購入率の分母は、どうやって数えたか

2つの店の先月の購入率を比べる報告が上がってきた。X店は20%、Y店は30%。担当者は「Y店の方が10ポイント高い。X店は売場づくりを見直すべき」と書いた。聞き取ると、次のことが分かった。
- 購入者の数は、どちらの店もレシートの枚数で数え、どちらも300人
- X店の来店客数（分母）は、入口のセンサーが人の通過を数えた1,500回。出入りのたびに数え、店員の出入りも入る
- Y店の来店客数（分母）は、入口のカメラが同じ人を1回と数えた1,000人

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 2つの購入率の分子と分母を、言葉で書く（何を何で割ったか）
2. X店の分母1,500回には、来店客でない数がどれだけ入りうるかを考える
3. X店の分母を Y店と同じ数え方にしたら、購入率はどの範囲になりうるかを計算する
4. 「X店の方が購入率が低い」と言えるかを、分母の数え方と分けて書く
5. 購入率の違いについての解釈（2つ以上）を分ける
6. 次に2店を比べるとき、何をそろえるかを書く（下の課題）

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**計算で言えること**：X店は 300÷1,500＝20%、Y店は 300÷1,000＝30%。ただし2つは違う割合で、X店は「入口の通過1回あたりの購入」、Y店は「来店した人1人あたりの購入」。分母の数え方が違うので、この2つの差（10ポイント）は比べられない。

**数え方をそろえたら**：X店の1,500回のうち、もし客1人が平均1.5回通過していたなら、来店客は1,000人で、購入率は Y店と同じ30%。通過が1人1回ずつなら20%のまま。X店の本当の購入率は、通過の数え方しだいで20%〜30%（あるいはそれ以上）のどこにでもなりうる。

**この数だけでは言えないこと**：X店の売場づくりが Y店より劣るかどうか。分母の数え方の違いだけで、10ポイントの差は消えうる。

**解釈の例**：
- X店の入口は駐車場と店内を行き来しやすく、出入りが多い。センサーの回数が来店客数より大きく出て、購入率が低く見えている
- X店は本当に購入率が低い。通りがかりに入って何も買わない客が多い立地
- X店の店員は荷物の出し入れで入口を何度も通り、その分が分母に入っている

どの読み方が当たるかは、この報告の数だけからは決められない。

**統計の外で決めること・確かめること**：2店を比べる前に、来店客数の数え方をそろえる。X店で1日だけ、入口で人の数を手で数えてセンサーの回数と比べ、何倍になっているかを確かめる。売場の見直しは、そろえた数で比べてから決める。
:::

### 課題｜来店客数の数え方を決める

**問い**　全店の購入率を毎月比べる。分母の「来店客数」を、次のどれで数えるか。

- **ア**：入口センサーの通過回数（全店にある。出入りと店員も数える）
- **イ**：カメラで同じ人を1回と数えた人数（Y店など一部の店だけにある）
- **ウ**：毎月1日だけ、入口で人を手で数え、センサーの回数との比を出して、その月の通過回数に掛ける

**判断の材料**：カメラを全店に付けるには費用がかかる。手で数えるのは1店で1日に1人の作業。店の入口の形（出入りのしやすさ）は店ごとに違う。

::: toggle 1つの考え方の例（自分で決めてから開く）
**計算で言えること**：ア は全店で同じ方法だが、店ごとに「通過1回あたりの人数」が違うと、店どうしの購入率は比べられない。イ は分母の意味がいちばんはっきりするが、全店ではそろわない。ウ は、店ごとに通過回数を人数に直す比を出すので、店どうしを比べやすくなる。ただし1日の比が、その月のほかの日にも当てはまるとみている。

**統計の外で決めること**：費用と手間を比べて決める。すぐに始めるなら ウ で、比を出した日と、その日が月のふつうの日かを報告に書く。カメラを付けた店から順に イ に移る。どれにしても、報告には分子（レシート枚数）と分母（何をどう数えたか）を並べる。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 2つの割合の分子と分母を、言葉で書いたか |
| 仮定 | 分母の数え方（何を1と数えるか）が2店でそろっているかを書いたか |
| 方法 | 分母の数え方を変えたときに、割合がどの範囲になりうるかを計算したか |
| 検証 | ラボで、分母を変えたときの割合を確かめたか |
| 切り分け | 計算で言えること（それぞれの割合の値）と、言えないこと（どちらの店の売場が良いか）を分けたか |
| 解釈 | 割合の違いの読み方を2つ以上並べ、次に確かめることを書いたか |
