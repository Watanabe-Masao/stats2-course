### 課題A｜自分の店の「割合カード」を作る

自分の職場の数字（購入率・粗利率・前年比など）を3つ選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 割合 | 何の何%か（分子と分母を言葉で） |
| 件数 | 分子・分母の実際の数 |
| 変化 | 前と比べてポイントか%か |
| 言えないこと | その割合だけでは分からないこと |

### 課題B｜値上げと値下げの計画を確かめる

**問い**　「来月10%値上げ、売れ行きが落ちたら翌月10%値下げで元に戻す」という計画を確かめる。売価・客数・売上がどう変わるかを考え、計画の言い方を直す。

::: toggle 1つの考え方の例（自分で決めてから開く）
**確かめ方**：売価は 1.1×0.9＝0.99 で元の99%。元に戻すには約9.1%（1÷1.1−1）下げる必要がある。

**小さな例で検証**：ラボの「増減を重ねる」で 1,000円・＋10%・−10% を入れ、990円になることを確かめる。2回目を−9%にすると1,001円で、ほぼ戻る。

**弱点**：売上＝売価×客数なので、客数の変化（前年比）も掛けないと売上の変化は分からない。値上げ中に客数が減ると、売価が戻っても客数が戻るとは限らない。
:::

### 課題C｜割合の報告の仕方を決める

会議で割合を報告するときのルール（分母の書き方・ポイントと%・件数の添え方）を5行以内で決め、過去の報告資料1枚で試す。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何の何%かが明確か |
| 仮定 | 基準量・期間・件数を確かめたか |
| 方法 | 倍率で重ねる、差と比を使い分けたか |
| 検証 | 小さな例やラボで確かめたか |
| 限界 | 割合だけで言えないことを書いたか |
