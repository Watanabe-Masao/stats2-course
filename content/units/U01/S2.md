### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：20%上げて20%下げても戻らない理由**

- **条件**：ある値を20%上げ、その後20%下げるとき
- **対象と結論**：結果は元の値より4%小さくなる
- **根拠**：下げるときの基準は上げた後の値（元の1.2倍）なので、倍率で 1.2×0.8＝0.96 になるから
- **成り立たない場合**：「元の値の20%分」を足して引く（基準を固定する）なら元に戻る

::: toggle つなげると（お手本の文）
「20%上げてから20%下げると、元の値の96%になる。下げるときの基準は上げた後の大きい値なので、倍率は 1.2×0.8＝0.96 だからである。ただし両方とも元の値を基準にするなら元に戻る。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「購入率が10%から12%になったので、2%改善しました。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 「2%」だと、10%の2%（＝0.2ポイント）と誤解される。
- 差なら「ポイント」、相対的な変化なら「20%」。

**言い直しの例**

「購入率が10%から12%になり、2ポイント改善した。元の購入率に対しては20%の改善である。」
:::

::: toggle 取り違えやすい言葉
- **「%」と「ポイント」**：%（相対的な変化）＝10%→12% は20%増／ポイント（差）＝10%→12% は2ポイント増
- **「原価率」と「値入率」**：原価率＝原価÷売価／値入率＝利益÷売価（売価基準）。利益÷原価（原価基準）をマークアップ率と呼ぶこともあり、基準の取り方は場面で違うので必ず確かめる
- **前年比と増減率**：前年比120%＝20%増、前年比80%＝20%減
:::

- [ ] 増減を重ねるとき倍率を掛けた
- [ ] % とポイントを区別した
