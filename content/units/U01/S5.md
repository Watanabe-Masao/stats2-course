- 「増減を重ねる」で、10%増を2回重ねると全体で何%増になるかを読む。2回目の率を動かして、足し算とどれだけずれるかを見る（なぜ？）

### なぜ？｜なぜ増減は足さずに掛けるのか

「10%増」は、そのときの値を基準にした割合。1回目の10%増で 1,000 が 1,100 になると、2回目の10%増の基準は 1,100 で、増える量は110。だから10%増を2回重ねると 1.1×1.1＝1.21 で21%増になり、10＋10＝20%増より少し大きい。

増減の率は、毎回基準が入れ替わる割合なので、倍率にして掛ける。足し算で近似できるのは、率が小さいときだけ（1%増を2回なら 1.0201 で、2.01%増。20%増を2回なら 1.44 で、44%増）。倍率の対数をとると、掛け算が足し算になる。何回分かの増減を「1回あたり」にならすときは、倍率の幾何平均を使う（{{unit:U05T}}）。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「購入率20%」という1つの数からは、**分子と分母の大きさ**が消える。A店は来店客10人中2人、B店は1,000人中200人で、どちらも20%。

翌月、A店の購入者が1人増えて10人中3人になると、購入率は30%で、10ポイント増（前を基準にすると50%増）。B店で同じ10ポイント増になるには、購入者が100人増える必要がある。分母が小さい割合は、1人の違いで大きく動く。割合を報告するときは、分子と分母の数を並べる（揺れの大きさを数で言うのは {{unit:U22}}）。

### 本当に？｜部分で勝っても、合わせると負ける

「平日も週末も A店の方が購入率が高いなら、合わせても A店の方が高い」と考えたくなる。この前提は、2つの店で平日と週末の客の割合が同じなら成り立つが、違うと崩れる。

| 店 | 平日 | 週末 |
| --- | --- | --- |
| A店 | 100人中18人（18%） | 200人中10人（5%） |
| B店 | 300人中50人（約16.7%） | 50人中2人（4%） |

平日も週末も A店の方が高いのに、合わせると A店は300人中28人（約9.3%）、B店は350人中52人（約14.9%）で、B店の方が高い。A店は購入率の低い週末の客が多く、B店は購入率の高い平日の客が多い。合わせた割合は、部分の割合を客数で重みをつけた平均なので、重みの違いで順位が入れ替わる（シンプソンのパラドックス）。割合は分子・分母といっしょに、どの部分を合わせたかを記録する。

### ほかでは？｜つながり

- **平均成長率**：増減の率をならすのは倍率の幾何平均（{{unit:U05T}}）
- **条件付き確率**：部分ごとの割合と全体の割合（{{unit:U11}}）
- **合わせた表の関連**：2つの店を合わせたクロス集計表で、関連の解釈が変わる（{{unit:U27}}）
- **比べ方**：ほかの要因が両方に効くときの比べ方（{{unit:U32}}）

### 説明してみる

::: task
ある商品の売上が、3か月続けて前月比 +50%、−50%、±0% だった。担当者は「3か月の前月比の平均は (50−50＋0)÷3＝0% なので、3か月前と同じ売上に戻った」と報告した。この報告のどこに無理があるかを説明し、3か月をならした「1か月あたりの変化」を言い直す。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**計算で言えること**：前月比は毎月基準が入れ替わる割合なので、倍率で掛ける。1.5×0.5×1.0＝0.75 で、3か月前の75%。戻っておらず、25%減っている。1か月あたりにならすなら、0.75 の3乗根で約0.909、つまり毎月約9.1%減と同じ（倍率の幾何平均）。前月比の % をそのまま足して平均すると、上がった月の基準（小さい値）と下がった月の基準（大きい値）の違いが消える。

**解釈の例**：
- 担当者は「上がった分と下がった分が同じ大きさなら打ち消し合う」と考えた。量（円）なら打ち消し合うが、率は基準が違うので打ち消さない
- 1か月目の+50%は特売、2か月目の−50%は特売の反動。この2か月は1つの出来事として見る方が実態に近い

**統計の外で決めること**：報告では、前月比の並びと、3か月前と比べた倍率（75%）の両方を書く。特売のような出来事があった月は、その理由も添える。
:::
