### 0｜入口の問い

::: task
原価800円の商品。店長は「原価が売価の80%になるように値付けして」と言った。新人は 800×1.2＝960円 と付けた。さらに店長は「来週20%値上げして、翌週20%値下げすれば元の売価に戻る」と言った。この2つの言い方のどこを確かめればよいか。
:::

^ まだ答えなくてよい。「何の何%か」を先に言い、増減を倍率で重ねられるようになるのが初学のゴール。

### 1｜前提チェック（2分）

::: toggle 3問だけ確かめる（答えも中にある）
1. 0.2 を%で言うと？ → 20%
2. 3÷4 は何%？ → 0.75＝75%
3. 3x＝15 のとき x は？ → 両辺を3で割って 5

1・2が不安なら、具体的な数（パック数・円）に置き換えて「何個中何個か」から考え直す。3が不安なら、この単元の初学6の式の変形から先に読む。
:::

### 2｜意味をつかむ：まず「何の」を探す　{{power:P3}}

割合はいつも「何かを基準にした比」。基準（分母）を取り違えると、計算が合っていても答えが違う。

::: ask 「〇〇の何%」と書いてある
→ **〇〇が分母（基準量）**。
:::

::: ask 「何%増えた／減った」と書いてある
→ **倍率**に直す（20%増＝1.2倍、20%減＝0.8倍）。続けて増減するときは倍率を掛け続ける。
:::

::: ask 割合どうしの変化を言いたい（10%→12%）
→ 差なら**ポイント**（2ポイント増）、前を基準にした変化なら**%**（20%増）。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
\text{割合}=\frac{\text{部分}}{\text{基準量}}\quad\Longrightarrow\quad \text{基準量}=\frac{\text{部分}}{\text{割合}},\qquad \text{部分}=\text{基準量}\times\text{割合}
$$

| 表現 | 意味 |
| --- | --- |
| 30パック中6パック | 6÷30＝0.2＝20% |
| 20%増 | 1.2倍 |
| 20%減 | 0.8倍 |
| 10%→12% | 2ポイント増（相対的には20%増） |

**式を言葉で読む**：分母の基準量が「全体」、分子の部分が「そのうちいくつか」。3つのうち2つが分かれば、残りの1つは式を変形して求められる。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　入口の商品（原価800円）。原価が「売価の80%」になるように売価を決める。売価はいくらか。また、その売価を20%上げた後に20%下げるといくらか。

1. 「売価**の**80%が原価」→ 基準量は売価 P：0.8×P＝800
2. 両辺を0.8で割る：P＝800÷0.8＝**1,000円**
3. 20%上げる：1,000×1.2＝1,200円
4. そこから20%下げる：1,200×0.8＝**960円**（元に戻らない）

{{lab:LAB-ratio@s1-base}}

::: key
800×1.2＝960円 としてしまうのは「原価の120%」で、基準が違う。割合を読むときは、**まず分母が何かを確かめる**。下げるときの基準は上げた後の1,200円なので、増減を重ねるときは倍率を掛け続ける。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-ratio@s1-chain}}

1. **予想**：ラボの課題カードで、1,000円を20%上げてから20%下げたときの全体の増減率を入れる。
2. **操作**：結果を見たら、1回目・2回目の率を −／＋ で動かす。
3. **観察**：2回目を何%にすると元に戻るか（くわしくの「元に戻す率」）。1回目と2回目を入れ替えると結果は変わるか。
4. **説明**：「＋20%→−20% にすると □ で、元より□少なくなった。なぜなら□」を1文で書く。
5. **ラボなしで**：25%上げてから20%下げると、元の何倍か。

::: toggle 答え（書いてから開く）
- **観察**：＋20%の後に元に戻すには約16.7%下げればよい（1÷1.2−1）。順番を入れ替えても（−20%→＋20%）倍率は 0.8×1.2＝0.96 で同じ。
- **説明の例**：「＋20%→−20% にすると 1.2×0.8＝0.96 で、元より4%少なくなった。下げるときの基準は上げた後の大きい値だから」
- **ラボなしで**：1.25×0.8＝**1倍**。元に戻る。
:::
