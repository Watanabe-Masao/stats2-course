### 探究｜効果が「見えない」のは、効果がないからか

陳列替えの前後4週間ずつで、8店それぞれの1日平均の売上の差（後−前、万円）を出した。都心の4店は 7・6・8・5、郊外の4店は −1・0・−2・1。8店まとめて t 検定（{{unit:U25}}）をした本部は、「陳列替えに効果はなかった」とまとめたい。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 8店まとめた t の値と自由度を出し、t(7) の両側5%の点 2.365 と比べる
2. 小さな例で検証する：ラボの「t 値を計算」で、8店まとめた場合と、都心の4店だけの場合を入れて比べる（s は 0.5 刻みなので、近い値の 4 と 1.5 で入れる。t は約2.12・約8.7 で、点との位置関係は同じ）
3. 統計で言えることと、店で差が分かれる理由についての解釈（2つ以上）を分けて書く
4. まとめを書く前に、次に確かめる記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること**：8店の差の標準偏差は約 3.93万円、標準誤差は 3.93÷√8≒1.39万円、t＝3÷1.39≒2.16（自由度7）で、点 2.365 の内側。8店の差が独立に同じ分布に従うとみると、「平均として差がある」とは言えない。けれども、言えないのは「差がある」ことで、「差がない」ことではない。8店の差は 2つのまとまりに分かれていて、同じ分布という前提そのものが怪しい。都心の4店だけなら差の平均 6.5万円・t≒10.1（自由度3、点 3.182）で、はっきり外側。ただし、この分け方はデータを見てから決めたので、偶然の分かれ目を拾っているおそれがある。

**解釈の例**：
- 陳列替えは、客の多い都心の店でだけ効く（売場の通る客の数で効き方が変わる）
- 都心の店では、同じ時期に陳列替えと関係なく売上が伸びた（季節で通勤の客が増えた・近くの催し・競合店の休業）。前後の比べには、陳列替えをしない店という比べる相手がないので、時期の変化と区別できない

どちらの読み方も、この8店の数だけからは決められない。

**統計の外で決めること・確かめること**：まとめの書き方（「効果がない」ではなく「8店まとめては見分けられない。都心と郊外で分かれている」）。次に確かめるなら、都心の店で陳列替えをしなかった店の同じ時期の売上、催しの記録。陳列替えを都心だけで続けるかは、その確かめと手間で決める。
:::

### 課題A｜施策の効果を t で判断する計画を作る

自分の売場の施策（レイアウト変更・陳列替えなど）について、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 比べるもの | 同じ店の前後の差か、基準の値との差か |
| データ | 店数（または日数）n と、差の標準偏差 s の見込み |
| 基準 | 両側か片側か、t(n−1) のどの点か |
| 判断 | t＝差の平均÷(s÷√n) が点を超えるか |

### 課題B｜「何店あれば見分けられるか」を決める

**問い**　客単価の差2百円を見分けたい。s は8百円くらい。何店のデータがあれば、差2百円で t が基準の点を超えるか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること**：t＝2÷(8÷√n)＝√n÷4。基準の点を約2とすると √n÷4＞2、√n＞8、n＞64。店の差が独立に同じ分布に従い、母標準偏差 σ が本当に約8百円なら、観察した差の平均がちょうど2百円のとき、64店で t が基準に届く。ただし本当の差が2百円でも、標本の差の平均はばらつくので、64店で基準を超えるのは半分ほど（見逃しを減らすには、さらに多くの店が要る。{{unit:U24}}）。16店では、差が 2.131×8÷√16≒4.26百円以上ないと基準を超えない。

**統計の外で決めること**：選び肢は「64店以上のデータが集まるまで待つ」と「16店で見て、4百円以上の差があるときだけ判断する」。待つ手間と、小さな差を見逃す損のどちらを重く見るかで決める。σ の見込みが外れると必要な店数も変わるので、過去のデータで σ の見込みを確かめる。

**小さな例で検証**：ラボの「t 値を計算」で x̄＝52、μ₀＝50、s＝8 にし、n を16・36・64・100 と変えて、t と点の位置を見る。
:::

### 課題C｜ばらつきの変化を調べる

POS から施策の前と後の日別売上を取り出し、それぞれの不偏分散を出す。日別の売上は曜日でまとまって動き、裾が重いこともあるので、独立とみなせるか・外れ値がないかを先に見る。F＝大きい方÷小さい方 を F の上側の点と比べ、ばらつきが変わったかを判断する。曜日の影響（土日だけ大きい）を除いた場合と比べる。

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 平均の話か、ばらつきの話かが明確か |
| 仮定 | 正規分布・独立・同じ分布・σ が分かっているかを書いたか |
| 方法 | 統計量・自由度・両側／片側を正しく決めたか |
| 検証 | ラボや表の点で確かめたか |
| 切り分け | 統計で言えること（基準の内か外か）と、言えないこと（「差がない」・差の理由）を分けたか |
| 解釈 | 差が分かれる理由の読み方を2つ以上並べ、次に確かめる記録を書いたか |
