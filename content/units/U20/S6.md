### 課題A｜施策の効果を t で判断する計画を作る

自分の売場の施策（レイアウト変更・陳列替えなど）について、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 比べるもの | 同じ店の前後の差か、基準の値との差か |
| データ | 店数（または日数）n と、差の標準偏差 s の見込み |
| 基準 | 両側か片側か、t(n−1) のどの点か |
| 判断 | t＝差の平均÷(s÷√n) が点を超えるか |

### 課題B｜「何店あれば見分けられるか」を決める

**問い**　客単価の差2百円を見分けたい。s は8百円くらい。何店のデータがあれば、差2百円で t が基準の点を超えるか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：t＝2÷(8÷√n)＝√n÷4。基準の点を約2とすると √n÷4＞2、√n＞8、n＞64。約64店以上あれば、差2百円で基準を超える。16店では、差が 2.131×8÷√16≒4.26百円以上ないと基準を超えない。

**小さな例で検証**：ラボの「t 値を計算」で x̄＝52、μ₀＝50、s＝8 にし、n を16・36・64・100 と変えて、t と点の位置を見る。

**成り立たない条件と、その先の判断**：s の見込みが外れると必要な店数も変わる。店ごとに条件が違う（独立でない・同じ分布でない）と、t の前提が崩れる。
:::

### 課題C｜ばらつきの変化を調べる

POS から施策の前と後の日別売上を取り出し、それぞれの不偏分散を出す。F＝大きい方÷小さい方 を F の上側の点と比べ、ばらつきが変わったかを判断する。曜日の影響（土日だけ大きい）を除いた場合と比べる。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 平均の話か、ばらつきの話かが明確か |
| 仮定 | 正規分布・独立・σ が分かっているかを書いたか |
| 方法 | 統計量・自由度・両側／片側を正しく決めたか |
| 検証 | ラボや表の点で確かめたか |
| 切り分け | 少ない n・歪み・店ごとの条件の違いを書いたか |
