### 0｜入口の問い

::: task
新レイアウトにした16店で、客単価の平均は52百円、データから計算した標準偏差 s は8百円だった。従来の平均は50百円。2百円の差は偶然の範囲か。標準化（{{unit:U16}}）で σ÷√n で割りたいが、母集団の標準偏差 σ は分からない。s を代わりに入れてよいか。そのとき基準は1.96のままでよいか。
:::

^ まだ答えなくてよい。σ の代わりに s を使う平均は t 分布、ばらつきそのものは χ²分布、2つのばらつきの比は F 分布。何を調べるかから分布と自由度を決め、確率点と比べられるようになるのが初学のゴール。

### 2｜意味をつかむ：何で割るかで分布が決まる　{{power:P3}}

::: ask σ が分かっていれば？
→ z＝(x̄−μ₀)÷(σ÷√n) は標準正規分布に従う。両側5%の基準は1.96。
:::

::: ask σ が分からず、s を代わりに使うと？
→ t＝(x̄−μ₀)÷(s÷√n) は、母集団が正規分布なら自由度 n−1 の **t 分布**に従う。s も標本ごとにぶれるので、z より裾が厚く、基準の点は1.96より大きい。n が大きいと標準正規分布に近づく。
:::

::: ask 平均ではなく、ばらつき（分散）を調べたいときは？
→ Q＝(n−1)s²÷σ² が自由度 n−1 の **カイ二乗分布 χ²** に従う。2つのばらつきを比べるなら、比 F＝s₁²÷s₂² が自由度 (n₁−1, n₂−1) の **F 分布**に従う（2つの母分散が等しいとき）。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
T=\frac{\bar x-\mu_0}{s/\sqrt n}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| x̄・μ₀ | 16店の平均52・従来の平均50 |
| s | データから計算した標準偏差8（不偏分散の平方根） |
| s÷√n | 平均の標準誤差 8÷4＝2 |
| n−1 | 自由度15（t の点を引く行） |

**式を言葉で読む**：分子は「差」、分母は「平均のぶれの目安（標準誤差）」。t＝1 は「差が標準誤差1つ分」。σ の代わりに s を使った分だけ、基準の点を t 分布の表から引く。

| 調べたいもの | 統計量と分布 |
| --- | --- |
| 平均（σ が分かる） | z：標準正規 |
| 平均（σ が分からない） | t：t(n−1) |
| 分散 | (n−1)s²÷σ²：χ²(n−1) |
| 2つの分散の比 | s₁²÷s₂²：F(n₁−1, n₂−1) |

```txt
Z=(X̄−μ)/(σ/√n) ~ 標準正規
T=(X̄−μ)/(s/√n) ~ t(n−1)
Q=(n−1)s²/σ² ~ χ²(n−1)
独立な2群で (s₁²/σ₁²)/(s₂²/σ₂²) ~ F(n₁−1, n₂−1)
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　新レイアウトの16店で客単価の平均は52百円、s は8百円。従来の平均は50百円。t の値と自由度を求め、両側5%の基準と比べよ。

1. SE＝8÷√16＝8÷4＝**2**
2. t＝(52−50)÷2＝**1**、自由度 16−1＝**15**
3. 両側5%の点：t(15) の左側累積0.975の点（上側2.5%点）＝**2.131**（正規なら1.96）
4. |1|＜2.131 → 差は偶然の範囲内と判断する

{{lab:LAB-tcf@s1-t}}

::: warn
分母に s＝8 をそのまま入れて t＝0.25 としない。分母は平均のぶれ s÷√n。確率点は「左側累積」で書く：t(15) の0.975点＝上側2.5%点＝2.131。
:::

::: key
2百円の差は標準誤差（2百円）のちょうど1つ分。16店ではこの程度の差は偶然でも十分起こる。σ を知らずに s を使うので、基準は1.96ではなく t(15) の2.131。差を見分けたいなら n を増やす（n を4倍の64店にすると SE は8÷8＝1で半分）。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

1. **予想**：ラボの課題カードで、5店（自由度4）のデータで t を使うときの両側5%の点を、正規の1.96と比べて予想する。
2. **操作**：結果を見たら、自由度を 1 → 4 → 15 → 30 → 120 と変える。「片側（上側）」にも切り替える。
3. **観察**：t 分布の曲線と標準正規の破線の差、t の点の大きさは、自由度でどう変わるか。

::: toggle 答え（書いてから開く）
- **観察**：自由度1では裾がとても厚く、点は12.706。4で2.776、15で2.131、30で2.042、120で1.980と、1.96に近づく。片側5%では1.645の代わりに t の0.95点を使う（自由度20なら1.725）。
