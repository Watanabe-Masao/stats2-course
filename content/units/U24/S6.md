### 探究｜「有意差なし」を、どう読むか

新しい陳列を16店で試した。1店あたりの1日の客単価は、試す前の基準より平均62円上がった。過去の記録から、店ごとの客単価の揺れは σ＝240円とみる。両側5%の z 検定では z≒1.03、p≒0.30 で、基準と違うとは言えなかった。本部は「陳列の効果はなかった。やめる」とまとめたい。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 何を知りたかったのかを書く（効果があるかないかか、どれくらいの大きさか）
2. 仮定を書く：16店は独立か、σ＝240円という見込みは今も合っているか
3. 下のラボの「検出力と過誤」で、この16店の検定が、効果100円をどれくらいの確率で見つけられたかを見る
4. 統計で言えることと、効果が見えなかった理由についての解釈（2つ以上）を分ける
5. やめるかを決める前に、次に確かめる記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（この16店について）**：平均の上がり方は62円。

**16店が独立で、σ＝240円が合っているとみたら言えること**：
- 標準誤差は 240÷√16＝60円。z＝62÷60≒1.03、p≒0.30 で、両側5%では「基準と違うとは言えない」
- 効果の95%信頼区間は 62±1.96×60、約 −56〜180円で、0 も 100円も含む。「効果がない」とも「100円の効果がある」とも決められない
- この16店の検定で、効果が100円あったときに見つけられる確率（検出力）は約0.38。6割以上の確率で見逃す。検出力0.8 に要る店数の目安は 46店

**この数だけでは言えないこと**：陳列の効果があるのかないのか。

**解釈の例**：
- 店ごとの客単価の揺れ（σ＝240円）が大きく、62円の上がりはその揺れに埋もれている。16店では見分けるのに店が足りない。この数の生まれ方として、一番素直な読み方
- 陳列の効き方が店によって違う。広い売場の店では上がり、狭い店では変わらないので、16店の平均では薄まる
- 試した期間が短く、客が新しい陳列に慣れる前の数を見ている。慣れると効き方が変わりうる

どの読み方が当たるかは、この16店の数だけからは決められない。

**統計の外で決めること・確かめること**：「効果はなかった」とは書かず、「16店では見分けられなかった。区間は −56〜180円」と書く。やめるか続けるかは、陳列の費用と、100円の効果があった場合の売上の見込みで決める。次に確かめるなら、店を46店ほどに増やすか、売場の広さで店を分けて上がり方を比べる。
:::

### 課題A｜検定の計画書を作る

自分の売場の施策について、調べる前に次を書く。

| 項目 | 書くこと |
| --- | --- |
| 仮説 | H₀（変化なし）と H₁（何を示したいか）、両側か片側か |
| 有意水準 | α を何%にするか、その理由（誤って棄却する損と、見逃す損） |
| 人数 | 見つけたい差 Δ と σ から、検出力0.8 に必要な n |
| 判断に使う指標 | どの指標で判断するかを1〜2個に絞る。ほかの指標は参考として書く |

### 課題B｜有意水準を決める

**問い**　新しい陳列を全店に広げるかを、試した店の検定で決める。有意水準を5%にするか1%にするか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**選び肢**：①有意水準5%。②有意水準1%。

**統計で言えること**：同じ店数なら、1%にすると効果がないのに広げてしまう誤り（第1種の過誤）は減るが、効果があるのに見逃す誤り（第2種の過誤）は増える。両方を減らすには、店数を増やす。

**統計の外で決めること**：広げる費用が大きく、外れたときの損が大きいなら1%。見逃して売上を逃す損の方が大きいなら5%。どちらの損が大きいかは、統計ではなく、費用と売上の見込みで決める。決めた有意水準は、データを見る前に計画書に書く。
:::
