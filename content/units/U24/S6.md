### 課題A｜検定の計画書を作る

自分の売場の施策について、調べる前に次を書く。

| 項目 | 書くこと |
| --- | --- |
| 仮説 | H₀（変化なし）と H₁（何を示したいか）、両側か片側か |
| 有意水準 | α を何%にするか、その理由 |
| 人数 | 見つけたい差 Δ と σ から、検出力0.8 に必要な n |
| 報告 | 結論の文の形と、区間・検定の回数の書き方 |

### 課題B｜「有意差なし」の報告を書き直す

**問い**　16店で試した施策が「有意差なし（p＝0.30）」だった。上司への報告をどう書くか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：「効果がなかった」とは書かない。「16店では、客単価が変わったとは言えなかった（p＝0.30）。差の95%信頼区間は◯〜◯円で、効果がある可能性も残る。この店数では100円の差を見つける確率（検出力）が約27%しかない」と書き、次に何店で試すかを提案する。

**小さな例で検証**：ラボの「検出力と過誤」で σ＝300、μ₁−μ₀＝100、n＝16 と n＝71 を比べる。

**成り立たない条件と、その先の判断**：σ の見込みが外れると必要な店数も変わる。店ごとの条件の違いが大きいと、店数を増やしてもばらつきが減りにくい。
:::

### 課題C｜指標を絞る

キャンペーンの評価で見る指標（客単価、客数、購入率、満足度…）を書き出し、本当に判断に使う1〜2個を先に決める。多くの指標を比べるなら、α÷k で判断する場合の α を計算する。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | H₀・H₁・両側／片側を調べる前に決めたか |
| 仮定 | 無作為・独立・σ が分かるかを書いたか |
| 方法 | α と必要な人数を理由つきで決めたか |
| 検証 | ラボで検出力や多重検定を確かめたか |
| 切り分け | 有意と大きさの違い、見逃しの可能性を書いたか |
