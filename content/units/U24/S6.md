### 探究｜「p＝0.03 で効いた」報告の中身を切り分ける

ポイント2倍キャンペーンを25店で行った。担当者の報告は「キャンペーン中の1人あたりの購入点数が前年の同じ時期より増え、検定で p＝0.03。効果があった」。聞き取ると、次のことが分かった。
- 調べる指標は、購入点数・客単価・来店回数の3つを見て、いちばんはっきり差が出た購入点数を選んだ
- 増えたのを見てから、「増えたかだけを見る」右片側の検定にした（両側なら p＝0.06）
- 比べる相手は前年の同じ時期で、キャンペーンをしなかった店はない

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 報告の中で、データを見る前に決めたことと、見たあとで決めたことを分ける
2. 仮定を書く：25店は独立か、前年の同じ時期が「キャンペーンがなかったら」の代わりになるか
3. データを見る前に決めていたらどうなったかを考える（指標を1つに決め、両側で検定していたら）
4. 統計で言えることと、増えた理由についての解釈（2つ以上）を分ける
5. 全店に広げるかを決める前に、次に確かめる記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（この25店の、報告どおりの計算について）**：購入点数の右片側の p＝0.03、両側なら p＝0.06。

**指標・向きを、データを見る前に1つずつ決めていたとみたら言えること**：両側の p＝0.06 で、5%では「前年と違う」とは言えない。報告の p＝0.03 は、3つの指標から1つを選び、向きを後から選んだあとの数で、そのまま5%と比べられない。キャンペーンに効果がなくても、3つの指標を独立とみて、それぞれ有利な向きを選んで片側5%で検定すれば、どれか1つが有意になる割合は 1−0.9³≒0.27 で、5%よりずっと大きい。

**この数だけでは言えないこと**：キャンペーンが購入点数を増やしたかどうか。前年と比べた差には、キャンペーン以外の1年間の変化も入っている。25店の選び方が分からないので、ほかの店に広げて言えるかも分からない。

**解釈の例**：
- キャンペーンに効果はほとんどなく、3つの指標と2つの向きの中から、偶然いちばん差の出た組み合わせを拾った。報告の作られ方からすると、一番素直な読み方
- ポイント2倍で、ついで買いが少し増えた。効果は小さく、25店では揺れと見分けにくい
- 前年からの1年間で、品ぞろえの見直しや近くの競合店の閉店があり、キャンペーンと関係なく購入点数が増えた

どの読み方が当たるかは、この報告の数だけからは決められない。

**統計の外で決めること・確かめること**：今の報告だけで全店に広げる判断はしない。次は、指標（購入点数）と両側の検定をデータを見る前に計画書に書き、キャンペーンをする店としない店をくじで分けて（{{unit:U32}}）、同じ期間で比べる。広げるかは、その結果と、ポイントの費用で決める。
:::

### 課題A｜検定の計画書を作る

自分の売場の施策について、調べる前に次を書く。

| 項目 | 書くこと |
| --- | --- |
| 仮説 | H₀（変化なし）と H₁（何を示したいか）、両側か片側か |
| 有意水準 | α を何%にするか、その理由（誤って棄却する損と、見逃す損） |
| 人数 | 見つけたい差 Δ と σ をどこから取るか（過去の記録・試しの調査）と、その取り方で必要な n がどう変わるか |
| 判断に使う指標 | どの指標で判断するかを1〜2個に絞る。ほかの指標は参考として書く |

### 課題B｜有意水準を決める

**問い**　ポイントのキャンペーンを全店に広げるかを、25店で試した検定で決める。有意水準を5%にするか1%にするか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**判断の材料**：客単価の揺れ σ は240円とみる。見つけたい差は1人100円。25店なら標準誤差は 240÷√25＝48円。全店に広げる費用は大きく、一度広げると簡単にはやめられない。

**統計で言えること**：差が本当に100円なら、両側5%の検定で見つけられる確率（検出力）は約0.55、両側1%なら約0.31。1%にすると、効果がないのに広げてしまう誤りは減るが、効果があるのに見逃す誤りは半分近くから7割近くに増える。

**統計の外で決めること**：広げる費用と、100円の効果があったときの売上の見込みを比べる。外れたときの損が大きいなら1%にし、見逃しが増える分は店数を増やして補う。見逃して売上を逃す損の方が大きいなら5%。決めた有意水準は、データを見る前に計画書に書く。
:::
