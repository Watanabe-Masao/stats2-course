### 0｜入口の問い

::: task
従来の客単価の平均は100百円、標準偏差は10百円。新しい施策のあと25人を調べると、平均は104.4百円だった。「4.4百円上がったので施策は効いた」と言ってよいか。客をたまたま選んだだけでも、これくらいの差は出るのではないか。どこからが「偶然では説明しにくい差」なのか。
:::

^ まだ答えなくてよい。「差がない」と仮定したときに今回の結果がどれくらい珍しいか（p 値）で判断する手順と、判断の誤り（2種類の過誤）・検出力を言えるようになるのが初学のゴール。

### 1｜前提チェック（2分）

::: toggle 3問だけ確かめる（答えも中にある）
1. σ＝10、n＝25 の平均の標準誤差は？ → 10÷√25＝2
2. 平均100・標準誤差2 のとき、x̄＝104.4 を標準化すると？ → (104.4−100)÷2＝2.2
3. 標準正規分布で P(Z≧2.2) は？（Φ(2.2)＝0.9861）→ 1−0.9861＝0.0139

1が不安なら {{unit:U18}}、2と3が不安なら {{unit:U16}} の初学へ。終わったらここへ戻る。
:::

### 2｜意味をつかむ：「差がない」と仮定して珍しさを測る　{{power:P3}}

::: ask 何を仮定して、何を調べる？
→ 否定したい主張を**帰無仮説 H₀**（μ＝100、変化なし）、示したい主張を**対立仮説 H₁**（μ≠100）とする。H₀ が正しいと仮定して、今回の結果がどれくらい珍しいかを調べる。
:::

::: ask p 値とは？
→ H₀ が正しいとしたときに、**今回以上に極端な結果が出る確率**。p 値が**有意水準 α**（ふつう5%）以下なら「H₀ のもとでは珍しすぎる」として H₀ を棄却する。p 値は「H₀ が正しい確率」ではない。
:::

::: ask 判断はどう間違える？
→ 正しい H₀ を棄却するのが**第1種の過誤**（確率 α）、誤った H₀ を棄却しないのが**第2種の過誤**（確率 β）。本当に差があるときに見つけられる確率 1−β が**検出力**。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
z=\frac{\bar x-\mu_0}{\sigma/\sqrt n}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| H₀：μ＝μ₀ | 「変化していない」：μ＝100 |
| H₁：μ≠μ₀ | 「上でも下でも変化」→ 両側 |
| x̄・σ・n | 25人の平均104.4・分かっている標準偏差10・25人 |
| α | 有意水準0.05（両側なので左右に2.5%ずつ） |

**式を言葉で読む**：分子は「H₀ からのずれ」、分母は「偶然のぶれの目安（標準誤差）」。z＝2.2 は「偶然のぶれの2.2倍ずれている」。両側なら、±2.2 より外側の面積の合計が p 値。

| 実際／判断 | 棄却する | 棄却しない |
| --- | --- | --- |
| H₀ が正しい | 第1種の過誤（α） | 正しい |
| H₀ が誤り | 正しい（検出力 1−β） | 第2種の過誤（β） |

```txt
手順：① 仮説と α・両側／片側を先に決める → ② 検定統計量を計算 → ③ p 値（または棄却域）で判断 → ④ 結論を言葉にする
第1種の過誤：P(棄却 | H₀ が正しい)＝α
第2種の過誤：β＝P(棄却しない | 本当の値 μ₁)
検出力＝1−β
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　従来の平均客単価は100百円・標準偏差10百円。新施策後に25人を調べると平均104.4百円だった。上がっても下がっても「変化した」とみなす（両側）。有意水準5%で検定せよ。（Φ(2.2)＝0.9861）

1. 仮説：H₀：μ＝100、H₁：μ≠100、α＝0.05
2. SE＝10÷√25＝2 → z＝(104.4−100)÷2＝**2.2**
3. p 値＝2×P(Z≧2.2)＝2×0.0139＝**0.028**
4. p＝0.028≦0.05（|z|＝2.2＞1.96）→ **H₀ を棄却**
5. 結論：「客単価は変化したと判断できる（有意水準5%）」

{{lab:LAB-test@s1-z}}

::: warn
p＝0.028 は「H₀ が正しい確率が2.8%」ではない。棄却できなかったときは「差がないと証明」ではなく「差があるとは言えない」。
:::

::: key
統計的に有意でも、4.4百円の差が実務的に大きいかは別に判断する。検定は「偶然で説明できるか」を見るもので、効果の大きさは区間推定（{{unit:U22}}）で示す。この例の95%信頼区間は 104.4±3.92＝100.48〜108.32 で、100 を含まない（検定の結論と一致）。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-test@s1-power}}

1. **予想**：ラボの課題カードで、本当の平均が104のとき、25人の検定で差を見つけられる確率（検出力）を予想する。
2. **操作**：結果を見たら、n を 25 → 50 → 100 と変える。次に α を 5% → 1% に変える。
3. **観察**：検出力と β は、n と α でどう変わるか。
4. **説明**：「α を小さくすると、第1種の過誤は□、第2種の過誤は□。なぜなら□」を1文で書く。
5. **ラボなしで**：n＝100 のとき、本当の z の中心（(104−100)÷(10÷√100)）を出す。

::: toggle 答え（書いてから開く）
- **観察**：n＝25 で検出力は約0.52（半分は見逃す）。n＝50 で約0.81、n＝100 で約0.98。α を1%にすると n＝25 の検出力は約0.28 に下がる。
- **説明の例**：「α を小さくすると、第1種の過誤は減るが、第2種の過誤は増える。棄却の境目が外へ動くので、本当に差があっても境目を超えにくくなるから」
- **ラボなしで**：SE＝1、中心は **4**。境目1.96を大きく超えるので、ほとんど見逃さない。
:::

::: summary
1. H₀ が正しいと仮定し、今回以上に極端な結果が出る確率（p 値）を求める。p≦α なら H₀ を棄却。α と両側／片側は先に決める。
2. p 値は H₀ が正しい確率ではない。棄却しないときは「差があるとは言えない」で、「差がない」の証明ではない。
3. 第1種の過誤（α）と第2種の過誤（β）はトレードオフ。検出力 1−β は n・差・σ・α で決まる。
:::
