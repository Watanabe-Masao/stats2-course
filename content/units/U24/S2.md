### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：p＝0.028 で H₀ を棄却したことの意味**

- **条件**：H₀：μ＝100、両側、α＝0.05 を先に決め、25人の平均から z＝2.2 を得たとき
- **対象と結論**：p＝0.028≦0.05 なので H₀ を棄却し、「客単価は変化した」と判断する
- **根拠**：H₀ が正しければ、今回以上にずれた平均が出る確率は2.8%しかなく、偶然では説明しにくいから
- **成り立たない場合**：p 値は H₀ が正しい確率ではない。また、この判断は5%の確率で誤る（第1種の過誤）。σ が分からない・無作為でないなら z 検定の前提が崩れる

::: toggle つなげると（お手本の文）
「H₀：μ＝100・両側・α＝0.05 を先に決めて z＝2.2 を得たとき、p＝0.028 が0.05 以下なので H₀ を棄却し、客単価は変化したと判断する。H₀ が正しければ今回以上にずれた平均が出る確率は2.8%しかなく、偶然では説明しにくいからである。ただし p 値は H₀ が正しい確率ではなく、この判断は5%の確率で誤りうる。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「p 値が0.20だったので、施策の効果がないことが証明されました。前回は p＝0.03 だったので、施策が効いている確率は97%です。結果を見たら上がっていたので、片側検定に変えました。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 棄却しないのは「差があるとは言えない」。効果がないことの証明ではない（検出力が低いだけかもしれない）。
- p 値は H₀ のもとでのデータの珍しさ。「効いている確率」ではない。
- 片側か両側かは、データを見る前に決める。後から変えると第1種の過誤が増える。

**言い直しの例**

「p＝0.20 は5%より大きいので、効果があるとは言えない。ただし人数が少なく検出力が低ければ、本当の効果を見逃している可能性がある。片側か両側かは、調べる前に決めた方で判断する。」
:::

::: toggle 取り違えやすい言葉
- **「p 値」と「H₀ が正しい確率」**：p 値は H₀ を正しいと仮定したときのデータの珍しさ
- **「棄却しない」と「差がない」**：棄却しない＝差があるとは言えない。差がないことの証明ではない
- **「第1種の過誤」と「第2種の過誤」**：正しい H₀ を棄却（あわてる）／誤った H₀ を見逃す（ぼんやり）
- **「有意」と「大きい」**：有意＝偶然では説明しにくい。差が実務的に大きいかは別
- **「両側」と「片側」**：どちらかは調べる前に決める
:::

**自己チェック（説明を書いたら）**

- [ ] 仮説・α・両側／片側を先に書いた

- [ ] 棄却しないとき「差があるとは言えない」と書いた
- [ ] 差の大きさ（区間）にも触れた
