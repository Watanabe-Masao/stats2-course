### 探究｜売上は客数で決まるのか

本部の分析メモ：「2店の120日の日販で、売上との相関係数は客数が0.88、客単価が0.53。売上は客数で決まるので、来期は客数を増やす施策に予算を寄せる」。

聞き取ると、次のことが分かった。
- 売上は、客数×客単価で計算している
- A店の42日目は台風、B店の89日目は大口の注文があった
- B店は61日目に改装を終え、そのあと客数が増えた
- 週末とキャンペーン（値引き）の日は、客数が増える。客単価は、週末に少し上がり、キャンペーンの日に少し下がる。値上げはなかった

{{lab:LAB-explore@s6-scatter}}

「図」を散布図にして、「横軸」を客数・客単価に切り替え、「絞る」で店ごと・特別な日を除くを選ぶ。平均と標準偏差は、「見る値」を客数・客単価に替え、「分ける」を店にして、表で読む。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. メモのどの言葉を確かめるかを、自分で問いにする（例：客数が多い日には何が起きているか）
2. ラボで、売上と客数、売上と客単価の r を、全部の日・店ごと・特別な日を除くで読む
3. 店ごとに、客数と客単価の平均に対するばらつき（変動係数。{{unit:U07}}）を比べる
4. 統計で言えることと言えないことを分ける
5. 2つの r の差の読み方を、2つ以上書く

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（120日の記録が正しいとみて）**：
- 全部の日では、売上との r は客数0.88・客単価0.53。特別な日の2日を除くと、客数0.97・客単価0.37。客単価の r の一部は、大口注文の1日が作っていた
- 特別な日を除いて店ごとに見ると、売上との r は、A店が客数0.96・客単価0.50、B店が客数0.98・客単価0.49。2店を合わせた客単価の r（0.37）は、どちらの店より小さい。A店は客数が多く客単価が低い店なので、2店を合わせると、客数の多い日と客単価の高い日がずれて見える
- 特別な日を除くと、客数の変動係数は A店 約0.18（平均約664人・標準偏差約120人）、B店 約0.21（約551人・約116人）。客単価は A店 約0.06（約518円・約29円）、B店 約0.05（約531円・約27円）。どちらの店でも、客数の方が客単価より3〜4倍大きく揺れている。B店の客数の揺れには、改装の前後の段差も入っている

売上は客数×客単価なので、日々の売上の揺れは、2つの部分の揺れを合わせたもの。2つの部分がほぼ別々に揺れるなら、揺れの大きい部分ほど売上と一緒に動き、売上との r が大きくなる（ここでは週末に両方が少し上がるので、客数と客単価の r は店の中で0.2〜0.3 ほどある）。r の差が言っているのは「今の120日では、売上の上下の多くが客数の上下から来ている」ことで、「客数を増やす方が売上を増やしやすい」ことではない。もう一方が変わらないとすれば、客数を1% 増やしても、客単価を1% 上げても、売上はどちらも約1% 増える。どちらが動かしやすいかは、r からは分からない。

**解釈の例**：
- 客数は週末・天気・キャンペーン・改装で大きく揺れ、客単価はあまり動かない。日々の売上の上下を説明するなら、客数を見るのが筋が通る
- 客単価が動かないのは、この120日に値上げも品ぞろえの大きな変更もしていないから。売り方を変えれば客単価も揺れ、r の大小は入れ替わりうる。r は今の売り方の結果で、動かせる余地を表してはいない
- 大口注文を日々の売上の記録に入れるかどうかは、記録の決め方しだい。法人の注文を別の記録にしている店なら、客単価の r はもっと小さく出る

**統計の外で決めること**：予算をどちらに寄せるかは、客数と客単価をそれぞれ1% 動かすのに、どれだけの費用と手間がかかるか、片方を動かすともう片方がどう動くか（値上げで客が減るか）で決める。
:::

### 課題｜会議の資料に、どの数を1つ載せるか

**問い**　来期の予算配分の会議で、「売上の上下は客数と客単価のどちらから来ているか」を示す数を、資料に1つだけ載せる。どれを載せるか。

- **ア**：売上との相関係数（客数と客単価の2つ）
- **イ**：客数と客単価の変動係数（揺れの大きさそのもの）
- **ウ**：客数と客単価を、それぞれ1% 動かした店の過去の例と、そのときにかかった費用

**判断の材料**：会議は年に1回で、2店の120日の記録と、過去の施策の記録（チラシ・値上げ）がある。特別な日は年に数日あり、B店は改装の前後で客数が違う。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（日販の記録が正しいとみて）**：ア の r は、部分の揺れの大きさと、部分どうしの動き方の両方で決まる。特別な日が1日入る、店を合わせるだけでも値が動き、何が r を作ったかは r からは分からない。イ は「どちらが大きく揺れているか」を直接示す。ただし2店を合わせた値には店の差が、B店の値には改装の段差が入るので、店ごと・改装の前後で分けて出す。ア・イ のどちらも、今の120日の揺れの出どころを言うだけで、どちらを動かせば売上が増えるかは言わない。ウ は会議の問い（予算をどちらに寄せるか）に近いが、相関や変動係数ではなく、施策の記録から出す数で、ほかの条件が同じだったかを確かめないと比べられない。

**統計の外で決めること**：会議で決めたいのが「日々の売上の上下の説明」なら イ、「予算をどちらの施策に寄せるか」なら ウ を軸にし、イ を添える。ア を載せるなら、売上＝客数×客単価で、r の大小が部分の揺れの大きさで決まることを注に書く。
:::
