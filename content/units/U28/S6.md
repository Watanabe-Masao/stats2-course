### 探究｜客数が多い日は売上も多い。では何が売上を決めているのか

2店の120日分の日販（架空）で、売上と客数・客単価・日付の散布図を描く。店で色分けし、全体の相関と店ごとの相関を比べる。

{{lab:LAB-explore@s6-scatter}}

「図」を散布図にして、「横軸」と分け方・絞り方を切り替える。赤い点（特別な日）が相関にどう効くかも見る。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること**：売上と客数には強い正の相関がある。売上と客単価の相関は弱い。店ごとに分けると相関の強さが変わる。特別な日の1点が、相関係数を動かす。

**解釈の例1**：売上は主に客数で決まるので、客数を増やす施策（集客）を優先する。

**解釈の例2**：売上＝客数×客単価なので、客数と売上の相関が強いのは計算の上で当然に近い。何が客数を動かしているか（週末・天気・改装）を見ないと、施策は決められない。

相関の強さは統計で言える。どの数を「原因」として動かすかは、式の成り立ちや現場の知識と合わせて判断する。
:::

### 課題A｜売場の指標の関係を調べる

自分の売場の2つの指標（例：気温と来店者数、陳列の数と売上）について、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 散布図 | 点を打ち、形（直線・曲線・外れ値・群）を書く |
| 数値 | 共分散と相関係数 r |
| 落とし穴 | 共通の原因・範囲・外れ値の候補 |
| 結論 | 相関の向きと強さ、因果と言えない理由 |

### 課題B｜擬相関を見抜く

**問い**　「雨の日の多い月ほど、傘と温かい飲み物がよく売れる。傘と温かい飲み物の売上には強い相関がある」。この相関をどう確かめ、どう報告するか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：雨や気温が両方の売上に効く共通の原因と考えられる。月を「雨の多さ」や「気温」で分けて（層別して）、同じ条件の月どうしで傘と飲み物の相関を見る。または気温の影響を取り除いた偏相関を出す。

**小さな例で検証**：ラボの「層別と擬相関」で、群の中心の差 d を0 から8 まで動かし、群の中の r は0 のまま、合わせた r だけが上がることを見る。

**成り立たない条件と、その先の判断**：測っていない共通の原因は取り除けない。月のデータは数が少なく、1か月の特別な行事で r が動く。
:::

### 課題C｜外れ値の扱いを決める

1店だけ規模の違う店があるとき、その店を含めた r と除いた r を並べ、どちらで判断するか、報告にどう書くかを決める。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | どの2つの量の関係を見るかが明確か |
| 仮定 | 直線的な関係か、共通の原因を書いたか |
| 方法 | 散布図・r・層別や偏相関を使ったか |
| 検証 | ラボで外れ値・層・範囲を動かして確かめたか |
| 切り分け | 因果と言えないこと、データの少なさを書いたか |
