### 探究｜売上は客数で決まるのか

本部の分析メモ：「2店の120日の日販で、売上との相関係数は客数が0.88、客単価が0.53。売上は客数で決まるので、来期は客数を増やす施策に予算を寄せる」。

聞き取ると、次のことが分かった。
- 売上は、客数×客単価で計算している
- A店の42日目は台風、B店の89日目は大口の注文があった
- 2店とも、この120日に値上げや品ぞろえの大きな変更はなかった

「図」を散布図にして、「横軸」を客数・客単価に切り替え、「絞る」で店ごと・特別な日を除くを選ぶ。表で、客数と客単価の平均と標準偏差も読む。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. メモのどこを確かめるかを、自分で問いにする（例：何について「決まる」と言っているか・どの日が r を作っているか）
2. ラボで、売上と客数、売上と客単価の r を、全部の日・店ごと・特別な日を除くで読む
3. 客数と客単価の、平均に対するばらつき（変動係数。{{unit:U07}}）を比べる
4. 統計で言えることと言えないことを分ける
5. 2つの r の差の読み方を、2つ以上書く

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（120日の記録が正しいとみて）**：全部の日では、売上との r は客数0.88・客単価0.53。特別な日の2日を除くと、客数0.97・客単価0.38 になり、客単価の r の一部は大口注文の1日が作っていた。特別な日を除くと、客数の変動係数は約0.21（平均約608人・標準偏差約130人）、客単価は約0.05（平均約524円・標準偏差約28円）で、客数の方が4倍ほど大きく揺れている。

売上は客数×客単価なので、日々の売上の揺れは、2つの部分の揺れを合わせたもの。揺れの大きい部分ほど、売上と一緒に動き、売上との r が大きくなる。r の差が言っているのは「今の120日では、売上の上下の多くが客数の上下から来ている」ことで、「客数を増やす方が売上を増やしやすい」ことではない。客数を1% 増やしても、客単価を1% 上げても、売上はどちらも約1% 増える。どちらが動かしやすいかは、r からは分からない。

**解釈の例**：
- 客数は週末・天気・キャンペーンで大きく揺れ、客単価はほとんど動かない。日々の売上の上下を説明するなら、客数を見るのが筋が通る
- 客単価が動かないのは、この120日に値付けも品ぞろえも変えていないから。売り方を変えれば客単価も揺れ、r の大小は入れ替わりうる。r は今の売り方の結果で、動かせる余地を表してはいない
- 客単価の r は、記録の側の1日（大口注文）で大きく出ていた。特別な日をどう扱うかで、r の順位までは変わらなくても、差の大きさは変わる

**統計の外で決めること**：予算をどちらに寄せるかは、客数と客単価をそれぞれ1% 動かすのに、どれだけの費用と手間がかかるかで決める。
:::

### 課題｜本部の画面に、売上の動きの理由をどう出すか

**問い**　店長が毎朝見るスマホの画面に、前の週から売上が動いた理由として何を出すか。

- **ア**：売上と客数・客単価の相関係数を、月ごとの表で出す
- **イ**：売上の前の週からの増減率を、客数の増減と客単価の増減の寄与に分けて出す（{{unit:U05T}} の寄与度）
- **ウ**：売上と客数の散布図に、特別な日の点を印を変えて出す

**判断の材料**：画面に入るのは図か表が1つほど。特別な日は月に数日ある。店長は、その週の売り方（チラシ・陳列）を決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（日販の記録が正しいとみて）**：ア の r は、ひと月の日々の上下がどちらの部分から来たかをまとめるが、どの週に何が起きたかは消える。特別な日が1日入るだけで値が動く。イ は、その週の売上の動きを、客数と客単価の分に分けて足し算で示せる。ただし、分けた分がなぜ動いたか（天気か・チラシか）は、寄与からは分からない。ウ は、ふだんの日の並びと、特別な日の外れ方を一目で見られるが、前の週との比べは読みにくい。

**統計の外で決めること**：店長がその週の売り方を決めるなら、イ の寄与が直接使える。本部が売り方の違う店どうしを比べるなら、ア の r を店ごとに並べる意味がある。どれを選んでも、売上＝客数×客単価で、r の大小が部分の揺れの大きさで決まることを、画面の見出しか注に書く。
:::
