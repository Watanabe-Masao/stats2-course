::: toggle 答え（言ってから開く）
1. 右上（x も y も平均より大）と左下（どちらも小）。
2. 共分散＝偏差の積の和÷(n−1)。r＝共分散÷(s_x×s_y)。共分散は単位で変わり、r は −1〜1 で単位によらない。
3. 曲線の関係（r≒0 でも関係がある）、傾きの大きさ、因果（擬相関）。外れ値・層・範囲でも r は変わる。
:::

### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：r＝0.9 から言えること**

- **条件**：5週間の広告回数と来店者数の散布図がほぼ直線に並び、r＝0.9 のとき
- **対象と結論**：2つの量には強い正の直線関係がある
- **根拠**：偏差の積がほとんど＋（右上・左下）で、その和を x と y の散らばりで割ると1 に近いから
- **成り立たない場合**：広告を増やせば来店が増える（因果）とまでは言えない。季節のような共通の原因、外れ値、5週という少なさで r は変わる

::: toggle つなげると（お手本の文）
「広告回数と来店者数の散布図がほぼ直線に並び r＝0.9 のとき、2つの量には強い正の直線関係がある。偏差の積がほとんど右上と左下で＋になり、その和を x と y の散らばりで割ると1 に近いからである。ただし広告が来店の原因とまでは言えず、季節などの共通の原因や外れ値、データの少なさで r は変わりうる。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「気温とアイスの売上の相関は0.8、気温とプールの事故の相関も0.8 でした。アイスの売上と事故の相関も高いので、アイスを売ると事故が増えます。単位を千円にしたら共分散が小さくなったので、関係も弱くなりました。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- アイスと事故の相関は、気温という共通の原因による擬相関。気温をそろえて（層別・偏相関）見る。
- 共分散は単位で変わる。関係の強さは r で比べ、r は単位で変わらない。

**言い直しの例**

「アイスの売上と事故の相関は、どちらも気温が高い日に増えることによる見かけの相関と考えられる。同じ気温の日どうしで比べるか、気温の影響を取り除いた偏相関で確かめる。単位を変えても相関係数は変わらないので、関係の強さは相関係数で比べる。」
:::

::: toggle 取り違えやすい言葉
- **「共分散」と「相関係数」**：共分散は単位つきで大きさに上限がない。相関係数は −1〜1
- **「相関」と「因果」**：一緒に動くことと、一方が他方を動かすことは別
- **「r が大きい」と「傾きが大きい」**：r は直線へのそろい方。傾きは回帰で見る
- **「r＝0」と「関係がない」**：r＝0 は直線的な関係がないだけ
- **「擬相関」と「偏相関」**：共通の原因で生まれた見かけの相関／第3の変数を取り除いたあとの相関
:::

### 相関の早見

| 見ること | 読み方 |
| --- | --- |
| 偏差の積の符号 | 右上・左下が＋、左上・右下が− |
| 共分散 | 単位つき。単位を変えると ac 倍 |
| 相関係数 r | −1〜1。直線へのそろい方 |
| 落とし穴 | 曲線・外れ値・層・範囲・因果 |

^ r の目安：0.7 以上で強い正、0.4〜0.7 で中程度、−0.2〜0.2 で直線的な関係はほぼない。
