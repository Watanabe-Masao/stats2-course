### 2｜意味をつかむ：平均の十字で4つに分ける　{{power:P3}}

::: ask 散布図のどこを見る？
→ x の平均と y の平均に線を引き、**十字で4つに分ける**。右上（x も y も平均より大）と左下（どちらも小）は偏差の積が＋、左上と右下は−。点を角にした長方形を描くと、＋の長方形が多いほど「一緒に増える」関係。
:::

::: ask 共分散と相関係数の違いは？
→ **共分散** s_xy は偏差の積の平均（n−1 で割る）。単位を変えると値が変わる（円を千円にすると1000分の1）。**相関係数** r は共分散を x と y の標準偏差で割ったもので、単位が消えて必ず −1〜1。直線に近いほど ±1 に近い。
:::

::: ask r で分からないことは？
→ r は**直線的な**関係の強さ。曲線の関係では r≒0 になりうる。傾きの大きさでもない。1つの外れ値、性質の違う群が混ざること（層）、観測した範囲の狭さで大きく変わる。そして**相関は因果ではない**。気温のような共通の原因があると、見かけの相関（擬相関）が出る。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
r=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum(x_i-\bar x)^2}\sqrt{\sum(y_i-\bar y)^2}}=\frac{s_{xy}}{s_x s_y}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| (x_i, y_i) | 各週の（広告回数, 来店者数） |
| x̄・ȳ | 広告回数の平均3、来店者数の平均5 |
| 分子 | 偏差の積の和9（同じ向きなら＋） |
| 分母 | 偏差平方和の平方根の積 → 単位が消える |

**式を言葉で読む**：分子は散布図の長方形の「＋の面積の合計−−の面積の合計」。分母は x と y それぞれの散らばりの大きさ。割ることで単位も散らばりの大きさも消え、−1〜1 の「直線へのそろい方」だけが残る。

| r の値 | 読み方の目安 |
| --- | --- |
| 0.7〜1 | 強い正の相関 |
| 0.4〜0.7 | 中程度の正の相関 |
| −0.2〜0.2 | 直線的な関係はほぼない |
| −1〜−0.7 | 強い負の相関 |

```txt
共分散：s_xy＝Σ(x_i−x̄)(y_i−ȳ)/(n−1)
相関係数：r＝s_xy/(s_x s_y)（−1≦r≦1）
単位を変える：x→ax＋b、y→cy なら共分散は ac 倍、r は ac＞0 なら同じ
偏相関：r_xy・z＝(r_xy−r_xz r_yz)/√((1−r_xz²)(1−r_yz²))
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　5週間の広告回数 x と来店者数 y（百人）は、(1,3)(2,5)(3,4)(4,6)(5,7)。共分散と相関係数を求めよ。

1. 平均：x̄＝15÷5＝**3**、ȳ＝25÷5＝**5**
2. x の偏差：−2, −1, 0, 1, 2　y の偏差：−2, 0, −1, 1, 2
3. 偏差の積の和＝4＋0＋0＋1＋4＝**9** → 共分散 s_xy＝9÷4＝**2.25**
4. 偏差平方和：x は10、y は10
5. r＝9÷√(10×10)＝**0.9**（強い正の相関）

{{lab:LAB-corr@s1-scatter}}

::: warn
相関は因果ではない（季節が広告と来店の両方を動かしているなら擬相関）。r は傾きの大きさではない。r＝0 でも曲線の関係はありうるので、必ず散布図を見る。
:::

::: key
広告回数と来店者数には強い正の直線関係（r＝0.9）がある。ただし「広告を増やせば来店が増える」と言うには、季節などほかの要因を回帰や実験の計画（{{unit:U29}}〜{{unit:U32}}）で検討する。偏差の積が0の点（x か y が平均ちょうど）は r に効かない。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-corr@s1-outlier}}

1. **予想**：ラボの課題カードで、例題Aの5週目の来店者数が1だったら、相関は正・ほぼ0・負のどれになるかを選ぶ。
2. **操作**：結果を見たら、5週目の点を指で上へ動かし、y を 1 → 4 → 7 → 8 と変える。長方形の色と大きさを見る。
3. **観察**：r と共分散は、1つの点でどれくらい変わるか。右下の長方形（積が−）はどう変わるか。
4. **説明**：「点が5つしかないと、1つの点で r は□。なぜなら□」を1文で書く。
5. **ラボなしで**：5週目が (5,1) のとき、ȳ＝19÷5＝3.8。5週目の偏差の積 (5−3)×(1−3.8) を出す。

::: toggle 答え（書いてから開く）
- **観察**：y＝1 で r≒−0.25（負）、y＝4 で r≒0.42、y＝7 で r＝0.9、y＝8 で r≒0.90（むしろ少し上がる）。右下に大きな−の長方形があると、ほかの＋の長方形を打ち消す。
- **説明の例**：「点が5つしかないと、1つの点で r は大きく変わる。偏差の積の和は点ごとの長方形の足し算で、平均から遠い点ほど長方形が大きく、全体を左右するから」
- **ラボなしで**：2×(−2.8)＝**−5.6**。ほかの4点の積の和（2.6）より大きいので、合計は−3.0 で負になる。
:::

::: summary
1. 散布図を平均の十字で4つに分け、右上・左下（積が＋）が多いほど正の相関。共分散は偏差の積の和÷(n−1)、相関係数 r＝s_xy÷(s_x s_y) は −1〜1。
2. 共分散は単位で変わるが、r は変わらない。r は直線的な関係の強さで、傾きの大きさではない。曲線の関係では r≒0 になりうる。
3. 外れ値・層（群の混ざり）・範囲の狭さで r は大きく変わる。相関は因果ではない（共通の原因による擬相関）。
:::
