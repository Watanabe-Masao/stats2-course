### なぜ？｜なぜ r は −1 と 1 の間に収まるのか

例題Aの5週 (1,3)(2,5)(3,4)(4,6)(5,7) で、ラボの表から x と y の偏差平方和を読み、n で割る標準偏差を出す。各点の x と y を z得点（{{unit:U08}}）にして、z どうしの積を5つ出し、その平均を求める。r と比べる。

::: toggle 計算してから開く
偏差平方和はどちらも10 で、n で割る標準偏差はどちらも √2。z どうしの積は 2, 0, 0, 0.5, 2 で、平均は 4.5÷5＝0.9。r と同じ。r は、x と y をそれぞれ z得点にそろえたときの「z の積の平均」になっている。共分散を標準偏差の積で割るのは、両方を z にそろえてから積を平均するのと同じだから。

z の差の2乗 (z_x−z_y)² の平均は、z_x² の平均1 と z_y² の平均1 から、積の平均の2倍を引いた 2−2r。2乗の平均は0より小さくならないので、2−2r≧0 で r≦1。z_x＋z_y で同じように考えると r≧−1。r＝1 になるのは、どの点でも z_x＝z_y のとき、つまり全部の点が右上がりの1本の直線に乗るときだけ。r が −1〜1 に収まるのは、目盛りの約束ではなく、z にそろえた2つの量のずれ方の決まりから出てくる。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

3店の3日ずつ、合わせて9日の来店者数 x（百人）と売上 y（十万円）は、店1 (1,3)(2,1)(3,2)、店2 (4,6)(5,4)(6,5)、店3 (7,9)(8,7)(9,8)。ラボで、(a) 9日の点の r、(b) 店1 の3日だけの r、(c) 店ごとの平均の3点 (2,2)(5,5)(8,8) の r を読む。

::: toggle 動かしてから開く
(a) 9日では r＝0.85、(b) 店1 の中では r＝−0.5（店2・店3 も同じ並び）、(c) 店の平均では r＝1。同じデータでも、何を1つの点にして打つかで、r は −0.5 から 1 まで動く。

平均にすると、店の中の日ごとのばらつきが消え、店どうしの違いだけが残る。店の平均の r＝1 は「来店者数の多い店は売上も多い」を言うが、「同じ店で来店が多い日は売上も多い」とは言わない（この例では、店の中では逆）。r という1つの数からは、**どの単位で点を打ったか**が消える。r を見るときは、点1つが何（日・店・地域）かを先に確かめ、言いたいことと同じ単位で点を打つ。
:::

### 本当に？｜調べる店の選び方を変えても、r は同じか

r は、データの中の x と y のそろい方を測る。では、どの店を調べるかを変えたとき、r は母集団の r のまま変わらないか。応用では、x の大きい店だけに絞ると r が小さくなりやすいことを見た。今度は逆に、12店のうち広告費 x の真ん中の6店を消し、両端の3店ずつだけを残して r を読む。

::: toggle 動かしてから開く
12店の r は約0.86。両端の6店だけでは約0.94 に上がり、真ん中の6店だけでは約0.61 に下がる。店どうしの関係（どの店の点も同じ並びのまわりにある）は変えていないのに、x の選び方だけで r が動く。

r は x と y の関係だけでなく、**x がどれだけ広く散らばっているか**にもよる。x の端を選んで調べると、x のばらつきが大きくなり、同じ並びのまわりのぶれが相対的に小さく見えて r が上がる。「効果がはっきり出そうな店を選んで調べた」データの r は、全店の r より大きく出やすい。r を比べるときは、x がどう選ばれたか（全部か・端だけか・真ん中だけか）を書き添える。
:::

### ほかでは？｜つながり

- **z にそろえて比べる**：標準化と z得点（{{unit:U08}}）
- **r と傾き**：単回帰の傾きは r に s_y÷s_x を掛けたもの（{{unit:U29}}）
- **和のばらつき**：共分散と和の分散（{{unit:U13}}・{{unit:U07}} の発展）
- **説明変数どうしの相関**：多重共線性（{{unit:U30}}）
- **質的な2つの変数の関わり**：クロス集計と独立性の検定（{{unit:U27}}）

### 説明してみる

::: task
6月の5週の広告回数と来店者数（百人）は (1,3)(2,6)(3,5)(4,4)(5,7) で、r＝0.6 だった。担当者は「どの週も、広告を増やすと来店が増えた。r＝0.6 なので、関係はそこそこ強い」と書いた。z の積を週ごとに分けて、r＝0.6 をどの週が作っているかを確かめ、担当者の文のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（5週の記録が正しいとみて）**：x も y も平均は3 と5、n で割る標準偏差はどちらも √2。週ごとの z の積は 2, −0.5, 0, −0.5, 2 で、5で割った寄与は 0.4, −0.1, 0, −0.1, 0.4。r＝0.6 は、1週目と5週目の2つ（合わせて 0.8）が作り、2週目と4週目はむしろ逆の向き（−0.2）。「どの週も」一緒に増えたわけではない。r は全部の週の寄与を足した1つの数なので、どの週が作ったかは r からは分からない。

**解釈の例（両端の2週について）**：
- 広告の回数そのものが効いて、少ない週と多い週で来店がはっきり違った
- 1週目は月初めの雨、5週目は給料日の後で、広告とは別の理由で来店が少なく・多くなった

どちらかは、5週の数字だけからは決められない。

**統計の外で確かめること**：1週目と5週目に、広告のほかに何があったか（天気・行事・給料日）。週を増やして、両端の2週を除いても同じ向きが残るか。
:::
