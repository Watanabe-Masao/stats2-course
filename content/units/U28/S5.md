### なぜ？｜なぜ r は −1 と 1 の間に収まるのか

例題Aの5週 (1,3)(2,5)(3,4)(4,6)(5,7) で、ラボの表から x と y の偏差平方和を読み、5で割って √ をとり、標準偏差（n で割る形）を出す（ラボに出る s_x・s_y は n−1 で割った値なので、ここでは使わない）。各点の x と y を z得点（{{unit:U08}}）にして、z どうしの積を5つ出し、その平均を求める。r と比べる。

::: toggle 計算してから開く
偏差平方和はどちらも10 で、n で割る標準偏差はどちらも √2。z どうしの積は 2, 0, 0, 0.5, 2 で、平均は 4.5÷5＝0.9。r と同じ。r は、x と y をそれぞれ z得点にそろえたときの「z の積の平均」になっている。共分散を標準偏差の積で割るのは、両方を z にそろえてから積を平均するのと同じだから。

z の差の2乗 (z_x−z_y)² の平均は、z_x² の平均1 と z_y² の平均1 から、積の平均の2倍を引いた 2−2r。2乗の平均は0より小さくならないので、2−2r≧0 で r≦1。z_x＋z_y で同じように考えると r≧−1。r＝1 になるのは、どの点でも z_x＝z_y のとき、つまり全部の点が右上がりの1本の直線に乗るときだけ。r が −1〜1 に収まるのは、目盛りの約束ではなく、z にそろえた2つの量のずれ方の決まりから出てくる。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

3店の3日ずつ、合わせて9日の来店者数 x（百人）と売上 y（十万円）は、店1 (1,2)(2,1)(3,3)、店2 (4,5)(5,4)(6,6)、店3 (7,8)(8,7)(9,9)。ラボで、(a) 9日の点の r、(b) 店1 の3日だけの r、(c) 店ごとの平均の3点 (2,2)(5,5)(8,8) の r を読む。平均の3点の r が店の中の r と違うのはなぜか、平均にすると何が見えなくなるかを1文で書く。

::: toggle 動かしてから開く
(a) 9日では r＝0.95、(b) 店1 の中では r＝0.5（店2・店3 も同じ並び）、(c) 店の平均では r＝1。(a) と (b) の違いは、応用で見た層の混ざり（群の中より合わせた r が大きい）と同じ。ここで見たいのは (c)。

平均にすると、店の中の日ごとのばらつきが消え、店どうしの違いだけが残る。店の平均の r＝1 が言うのは「来店者数の多い店ほど売上も多い」で、「同じ店で来店が多い日ほど売上も多い」の強さ（この例では 0.5）ではない。しかも平均の点は店の数（3つ）しかないので、1つの店の平均が少し動くだけで r は大きく動く。r という1つの数からは、**何を1つの点にしたか（日・店・地域）**が消える。r を見るときは、点1つが何かを先に確かめ、言いたいことと同じ単位で点を打つ。
:::

### 本当に？｜目盛りを変えても、r は変わらないか

応用では、単位を変える（x を a 倍して b を足す）と共分散は変わるが r は変わらないことを見た。では、目盛りの付け方を変えれば、いつでも r は同じか。開店から5か月の月の売上（十万円）は 1, 2, 4, 8, 16 で、毎月2倍になった。ラボで、(月, 売上) の r と、売上を「2を何回掛けたか」（0, 1, 2, 3, 4。2を底にした対数）に直した値で打った (月, 対数) の r を比べる。r が「直線へのそろい方」だとすると、対数に直したときに r が変わるのはなぜかを考えてから開く。

::: toggle 動かしてから開く
(月, 売上) では r≒0.93、(月, 対数) では r＝1。同じ5か月で、関係も同じなのに、売上を対数に直しただけで r が動いた。

目盛りを a 倍して b を足す変え方（円と千円、℃ と ℉）なら、a が正であればどのデータでも r は変わらない（a が負なら符号だけ逆）。この変え方は点の並びの形を変えないので、z にそろえると同じ点になる。対数のように、大きい値ほど縮める変え方は、点の並びの形そのものを変える。倍々に伸びる売上は、そのままでは曲がった並びで、対数に直した値では1本の直線に乗る。r は「その目盛りで見たときの直線へのそろい方」なので、どの目盛りで r を出したかを書き添える。
:::

### ほかでは？｜つながり

- **z にそろえて比べる**：標準化と z得点（{{unit:U08}}）
- **r と傾き**：単回帰の傾きは r に s_y÷s_x を掛けたもの（{{unit:U29}}）
- **和のばらつき**：共分散と和の分散（{{unit:U13}}・{{unit:U07}} の発展）
- **説明変数どうしの相関**：多重共線性（{{unit:U30}}）
- **質的な2つの変数の関わり**：クロス集計と独立性の検定（{{unit:U27}}）
- **分けると向きまで変わる**：条件付き確率と全体の比べ方（{{unit:U11}}）
- **倍々の伸び**：幾何平均と成長率（{{unit:U05T}}）

### 説明してみる

::: task
5店の売場面積 x（百m²）と日販 y（十万円）は、A (1,3)、B (2,6)、C (3,5)、D (4,4)、E (5,7) で、r＝0.6 だった。担当者は「r＝0.6 の正の相関なので、売場が平均より広い店は、日販も平均より多い」と書いた。5店を z得点にして、なぜ？で見た z の差の2乗の平均（2−2r）も使いながら、この文のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（5店の記録が正しいとみて）**：x も y も平均は3 と5、n で割る標準偏差はどちらも √2。5店の (z_x, z_y) は、A (−1.41, −1.41)、B (−0.71, 0.71)、C (0, 0)、D (0.71, −0.71)、E (1.41, 1.41)。D は売場が平均より広いのに日販は平均より少なく、B はその逆。z の差の2乗の平均は 2−2×0.6＝0.8（2乗の平均の平方根で約0.9）。中身は、A・C・E のずれが0 で、B と D が1.41 ずつずれている。r＝0.6 は「平均すると、z の向きがそろう側に寄っている」ことで、1店ずつの向きまでは決めない。r が1 でないかぎり、向きの合わない店は出うる。

**解釈の例（D について）**：
- 売場は広いが、駅から遠いなど、売場の広さとは別の理由で客が少ない
- 改装の途中で、売場の一部を閉めていた

どちらかは、5店の数字だけからは決められない。

**統計の外で確かめること**：D の立地と、その期間の売場の使い方。5店しかないので、r＝0.6 そのものも、店を足すと大きく動きうる。
:::
