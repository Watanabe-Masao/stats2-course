### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：母分散の推定に、n−1 で割る s² を使う理由**

- **条件**：母分散 σ² を、n 個の標本から1つの数で推定するとき
- **対象と結論**：偏差の2乗和を n−1 で割った s² を使うと、取り直したときの平均がちょうど σ² になる（不偏）
- **根拠**：偏差は μ ではなく x̄ から測るので小さく出て、n で割ると平均 (n−1)/n×σ² と小さめになる。n−1 で割るとその分を補えるから
- **成り立たない場合**：不偏なのは s² で、その平方根 s は平均すると σ より小さい。また MSE で比べると、n で割る v の方が小さいこともある

::: toggle つなげると（お手本の文）
「母分散を n 個の標本から推定するとき、偏差の2乗和を n−1 で割った s² を使うと、取り直したときの平均がちょうど σ² になる。偏差は x̄ から測るので小さく出て、n で割ると平均 (n−1)/n×σ² と小さめになるが、n−1 で割るとその分を補えるからである。ただし平方根の s は σ より小さめで、MSE で比べると v の方が小さいこともある。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「不偏分散を使ったので、今回の推定値7は母分散そのものです。アンケートは1万人に答えてもらったので、偏りの心配はありません。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 不偏は「取り直したときの平均が当たる」という性質で、今回の7が当たっている保証ではない。n＝5 なら推定値は大きく揺れる。
- 人数を増やして小さくなるのはばらつき（SE）。答えた人が偏っていれば、何人集めても偏りは残る（集め方の偏り）。

**言い直しの例**

「不偏分散 s² は、取り直したときの平均が母分散に一致する推定量で、今回の推定値は7だった。ただし1回の推定値は揺れるので、母分散そのものとは言えない。アンケートは1万人の回答でばらつきは小さいが、答えたい人だけが答えているなら偏りは残る。」
:::

::: toggle 取り違えやすい言葉
- **「推定量」と「推定値」**：推定量はルール（x̄）、推定値はその数（5件）
- **「不偏性」と「一致性」**：不偏＝平均すると当たる（n は固定）／一致＝n を大きくすると近づく
- **「偏り」と「ばらつき」**：偏り＝分布の中心のずれ、ばらつき＝分布の広がり。n を増やして減るのはばらつき
- **「s²」と「s」**：s² は σ² に不偏、s は σ より小さめ（不偏でない）
- **「標本の大きさ」と「集め方」**：n を大きくしても、集め方の偏り（自己選択・名簿の偏り）は消えない
:::
