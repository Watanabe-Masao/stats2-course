### なぜ？｜なぜ MSE は「分散＋偏り²」に分かれるのか

推定値 θ̂ から母数 θ までのずれを、「θ̂ の平均 E[θ̂] からのずれ」と「E[θ̂] と θ のずれ」の2つに分ける。2乗して平均すると、まん中の掛け算の項は平均0で消え、E[(θ̂−θ)²]＝E[(θ̂−E[θ̂])²]＋(E[θ̂]−θ)²、つまり MSE＝分散＋偏り² になる。的の図でいえば、点の散らばりと、点の集まりの中心のずれを足したもの。

だから、偏りを0にするのが MSE を最小にするとは限らない。正規母集団の分散を推定するとき、偏差の2乗和を n−1 で割る s² は偏り0、n で割る v は少し小さめに偏るが、散らばりも小さい。σ²＝10・n＝5 なら、MSE は s² が50、v が36。割る数を n＋1 にすると約33.3まで下がる。偏りを少し受け入れて散らばりを減らす方が、1回の推定の外れ方は小さくなる。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「MSE は v の方が小さい」という1つの数の比べからは、**外れ方の内訳（散らばりか、いつも同じ向きのずれか）**が消えている。σ²＝10・n＝5 で、v の MSE 36 は分散32と偏り²4（毎回、平均して2小さく出る）、s² の MSE 50 は全部が分散。

1回だけ推定するなら v の方が外れにくい。けれども、20店それぞれで5日分から分散を推定し、20店の推定値を平均して「店のふだんのばらつき」とするなら、話が逆になる。散らばりは平均すると20分の1に縮むが、いつも同じ向きのずれは平均しても縮まない。20店の平均の MSE は、v で 4＋32÷20＝5.6、s² で 50÷20＝2.5。推定値をそのまま使うのか、何度も足し合わせて使うのかで、良い推定量が変わる。n を50にすると、MSE は s² が約4.08、v が約3.96 で、差はほとんどなくなる。

### 本当に？｜独立でないと、s² は不偏でなくなる

s² が σ² に不偏なのは、n 個が独立に同じ分布から取られるとき。売上の日のように、取った日に共通の要因（その月の天気・近くの催し）が全部の日を同じ向きに動かすと、この前提が崩れる。

各日の値を「全部の日に共通の部分」と「日ごとの部分」の和とみて、共通の部分が分散のうち割合 ρ を占めるとする。偏差は各日の値から x̄ を引くので、共通の部分は引き算で消え、s² は日ごとの部分しか捉えない。E[s²]＝σ²(1−ρ) になり、σ²＝10・ρ＝0.3 なら、平均して7しか出ない。この偏りは n を増やしても消えない。

x̄ の側はもっと揺れる。n＝10 なら x̄ の分散は σ²(1＋(n−1)ρ)÷n＝3.7 なのに、s²÷n は平均して0.7で、約5分の1。標準誤差を s÷√n で出すと、推定の精度を実際よりずっと高く見積もる。データがどう生まれたか（日の間に共通の要因がないか）を確かめずに、式だけを当てはめない。

### ほかでは？｜つながり

- **一致性と大数の法則**：標本平均が母平均に一致することは、大数の法則（{{unit:U19}}）そのもの
- **n−1 と自由度**：s² の割る数 n−1 は、t 分布や χ² 分布の自由度（{{unit:U20}}）と同じ数。偏差の和がいつも0なので、自由に動けるのが n−1 個分
- **偏りと区間**：信頼区間（{{unit:U22}}）は、偏りのない推定量の標準誤差で幅を決める。推定量が偏っていると、区間は母数を外す側にずれる
- **有限母集団修正**：戻さずに取ると、母集団に比べて n が大きいほど x̄ のばらつきが小さくなる（{{unit:U17}} の発展）
- **最尤推定**（1級）：正規母集団の分散の最尤推定量は n で割る v。不偏ではないが一致性があり、n が大きいときは最も効率がよい

### 説明してみる

::: task
毎月、来店客に満足かどうかのアンケートを取っている。回答数を200から2000に増やすと、回答者の満足率の標準誤差は小さくなった。ところが、全員に聞いた調査では満足率は約50%なのに、アンケートの満足率は約75%のまま近づかない。満足の人は6割が答え、不満の人は2割しか答えないことが分かっている。回答を増やしても近づかないのはなぜかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
回答数を増やすと、推定値は「ある値」に近づいていく。その値は、回答する人の中の満足率 0.5×0.6÷(0.5×0.6＋0.5×0.2)＝0.75 で、知りたい満足率0.5ではない。回答数を増やして小さくなるのは SE（散らばり）だけで、集め方で生まれた偏り0.25は残る。MSE＝SE²＋偏り² のうち、偏り²の分は n では減らせない。

つまり、この推定量は「回答者の満足率」には一致するが、「客全体の満足率」には一致しない。近づけるには、回答数を増やすのではなく、回答率をそろえる（無作為に選んだ人に何度も頼む・回答の手間を減らす）か、満足かどうかで回答率が違うことを見込んで補正する。
:::
