### なぜ？｜なぜ MSE は「分散＋偏り²」に分かれるのか

推定値 θ̂ から母数 θ までのずれを、「θ̂ の平均 E[θ̂] からのずれ」と「E[θ̂] と θ のずれ」の2つに分ける。2乗して平均すると、まん中の掛け算の項は平均0で消え、E[(θ̂−θ)²]＝E[(θ̂−E[θ̂])²]＋(E[θ̂]−θ)²、つまり MSE＝分散＋偏り² になる。的の図でいえば、点の散らばりと、点の集まりの中心のずれを足したもの。

だから、偏りを0にするのが MSE を最小にするとは限らない。正規母集団の分散を推定するとき、偏差の2乗和を n−1 で割る s² は偏り0、n で割る v は少し小さめに偏るが、散らばりも小さい。σ²＝10・n＝5 なら、MSE は s² が50、v が36。割る数を n＋1 にすると約33.3まで下がる。この場面（正規母集団・n＝5）では、偏りを少し受け入れて散らばりを減らす方が、1回の推定の外れ方は小さくなる。n を50にすると、MSE は s² が約4.08、v が約3.96 で、差はほとんどなくなる。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「MSE は v の方が小さい」という1つの数の比べからは、**外れ方の内訳（散らばりか、いつも同じ向きのずれか）**が消えている。σ²＝10・n＝5 で、v の MSE 36 は分散32と偏り²4（毎回、平均して2小さく出る）、s² の MSE 50 は全部が分散。

内訳の2つは、推定値を足し合わせたときの振る舞いが違う。20店それぞれで5日分から分散を推定し、20店の推定値を平均するとする。20店の母分散がどれも σ²＝10 で、店どうしが独立なら、散らばりは平均すると20分の1に縮むが、いつも同じ向きのずれは平均しても縮まない。20店の平均の MSE は、v で 4＋32÷20＝5.6、s² で 50÷20＝2.5 と、大小が入れ替わる。足し合わせるほど、MSE の中で偏り²の占める割合が大きくなる。

### 本当に？｜独立でないと、s² は不偏でなくなる

s² が σ² に不偏なのは、n 個が独立に同じ分布から取られるとき。売上の日のように、取った日々に共通の要因（その月の天気・近くの催し）が全部の日を同じ向きに動かすと、この前提が崩れる。

各日の値を「その月の全部の日に共通の部分」と「日ごとの部分」の和とみる。σ² は、月をまたいで見た1日の売上の分散で、共通の部分がそのうち割合 ρ を占めるとする。1か月の中の n 日から s² を出すと、偏差は各日の値から x̄ を引くので、共通の部分は引き算で消え、s² は日ごとの部分しか捉えない。E[s²]＝σ²(1−ρ) になり、σ²＝10・ρ＝0.3 なら、平均して7しか出ない。この偏りは、同じ月の中で n を増やしても消えない。

x̄ の側はもっと揺れる。n＝10 なら x̄ の分散は σ²(1＋(n−1)ρ)÷n＝3.7 なのに、s²÷n は平均して0.7で、約5分の1。標準誤差を s÷√n で出すと、推定の精度を実際よりずっと高く見積もる。データがどう生まれたか（日の間に共通の要因がないか）を確かめずに、式だけを当てはめない。

### ほかでは？｜つながり

- **一致性と大数の法則**：標本平均が母平均に一致することは、大数の法則（{{unit:U19}}）そのもの
- **n−1 と自由度**：s² の割る数 n−1 は、t 分布や χ² 分布の自由度（{{unit:U20}}）と同じ数。偏差の和がいつも0なので、自由に動けるのが n−1 個分
- **偏りと区間**：信頼区間（{{unit:U22}}）は、推定値を中心に標準誤差で幅を取る。推定量の偏りが n を増やしても縮まない（集め方の偏りなど）と、中心がずれたまま幅が狭くなり、区間は母数を外しやすくなる（偏りが 1/n のように幅より速く縮むなら、外れにくくなっていく）
- **有限母集団修正**：戻さずに取ると、母集団に比べて n が大きいほど x̄ のばらつきが小さくなる（{{unit:U17}} の発展）
- **最尤推定**（1級）：正規母集団の分散の最尤推定量は n で割る v。不偏ではないが一致性がある

### 説明してみる

::: task
来店客の平均滞在時間を知りたい。毎日決まった時刻に、そのとき店内にいる客を数人ずつ選び、帰るときに滞在時間を記録してもらう。来店客の半分は10分、半分は30分いることが、出口の記録から分かっている（平均20分）。この方法で集めた滞在時間の平均は、何日続けても約25分に近づき、20分に近づかない。人数を増やしても近づかないのはなぜか、この推定値は何に一致しているのかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
決まった時刻に店内にいる客は、来店客から同じ確率で選ばれていない。30分いる客は10分の客の3倍長く店内にいるので、声をかける時刻に店内にいる確率も3倍になる。店内にいる客のうち、30分の客は 30÷(10＋30)＝0.75、10分の客は0.25を占め、平均は 0.25×10＋0.75×30＝25分。

人数を増やすと、推定値は確かに1つの値に近づく。けれども、それは「ある時刻に店内にいる客の滞在時間の平均」25分で、「来店客の滞在時間の平均」20分ではない。一致性は、推定量が何に近づくかを言う性質で、それが知りたいものかどうかは、データの取り方で決まる。来店客の平均を知りたいなら、出口で帰る客を選ぶか、店内で選んだ客の滞在時間の逆数で重みをつける。
:::
