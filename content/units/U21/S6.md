### 課題A｜推定値の報告書を作る

自分の売場のデータ（日別の売上・客数など）で、次をまとめる。

| 項目 | 書くこと |
| --- | --- |
| 推定するもの | 母平均・母分散・母比率のどれか、母集団は何か |
| 推定値 | x̄・s²（n−1 で割る）・p̂ と、n |
| 外れうる幅 | 標準誤差 s÷√n や √(p̂(1−p̂)÷n) |
| 集め方 | いつ・どこの・だれのデータか、偏りの心配 |

### 課題B｜平均で推定するか、中央値で推定するか

**問い**　日別売上で「ふだんの1日の売上」を推定したい。セールの日の大きな値が混ざるとき、平均と中央値のどちらを使うかを決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：5日の売上が 10, 11, 12, 13, 54 万円なら、平均20万円・中央値12万円。セールの1日で平均が大きく動く。「ふだんの日」が知りたいなら中央値、「期間の合計の見込み」が知りたいなら平均、と目的で決める。

**小さな例で検証**：ラボの「推定値を計算」で、54 を 14 に変えたときと比べ、平均と中央値がどれだけ動くかを見る。「推定量を比べる」で、正規分布なら平均の方が MSE が小さいことも確かめる。

**成り立たない条件と、その先の判断**：外れ値のない正規分布に近いデータでは、平均の方が有効（ばらつきが小さい）。外れ値を除くかどうかは、理由を書いてから決める。
:::

### 課題C｜アンケートの偏りを見積もる

回答率が「満足の人」と「不満の人」でどれくらい違いそうかを仮に置き、ラボの「集め方の偏り」で回答者の満足率がどこに落ち着くかを見る。回答率をそろえる工夫（全員に聞く・回答の手間を減らす・無作為に選んだ人に何度も頼む）を書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何の母数を、どの母集団について推定するかが明確か |
| 仮定 | 独立・同じ分布・集め方の偏りを書いたか |
| 方法 | 推定量（n か n−1 か、平均か中央値か）を理由つきで選んだか |
| 検証 | ラボや別の計算で確かめたか |
| 切り分け | 1回の推定値は揺れること、集め方の偏りを書いたか |
