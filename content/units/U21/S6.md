### 探究｜「ふだんの1日の売上」を、何で推定するか

ある店の20日分の売上（万円）は、日の順に 10, 11, 12, 13, 14, 11, 40, 12, 13, 12, 11, 10, 14, 45, 13, 12, 11, 12, 13, 50。40・45・50 の3日はセールの日。本部は、来月の人員と仕入れを決めるために「この店の1日の売上の推定値」を1つ出してほしいと言っている。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 何を推定したいのかを、使い道ごとに書き出す（人員を決める日々の売上か、仕入れを決める月の合計か）
2. 小さな例で検証する：ラボの「推定値を計算」に20日を入れ、平均・中央値・s を読む。次にセールの3日を除いた17日で同じものを読む
3. 統計で言えることと、セールの日の扱いについての解釈（2つ以上）を分けて書く
4. 推定値を1つ出す前に、次に確かめる記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること**：20日の平均は16.95万円、中央値は12万円、s は約12.2万円。平均は20日の合計339万円を20で割った数なので、「期間の合計の見込み」には平均が合う。一方、20日のうち17日は16.95万円より下で、平均は「ふだんの日」の売上を表していない。セールの3日を除いた17日なら、平均12万円・s は約1.22万円で、日ごとの散らばりは小さい。20日をまとめて独立に同じ分布から出たとみると、平均の標準誤差は s÷√20≒2.74万円になるが、セールの日が店の計画で決まっているなら、20日は同じ分布から出ていない。この標準誤差は、そのとき意味を持たない。

**解釈の例**：
- セールの日は別の仕組みで生まれる日で、ふだんの日（12万円前後）とセールの日（45万円前後）を分けて推定するのが筋。来月のセールの日数が分かれば、合計は両方から組み立てられる
- セールが前後の日の客を前借りしている。そうなら、ふだんの日の12万円も「セールがある月のふだんの日」の値で、セールをやめた月にはもっと高くなりうる
- 3日の大きな値は、セールではなく、その日の別の要因（近くの催し・給料日）が重なった結果。そうなら、セールの効果は3日の売上より小さい

どの読み方が当たるかは、この20日の数だけからは決められない。

**統計の外で決めること・確かめること**：推定値を1つにまとめるかどうか。人員を決めるなら「ふだんの日12万円・セールの日は別」と2つで渡し、仕入れの合計なら来月のセールの日数を聞いてから組み立てる。次に確かめるなら、セールの前後の日の売上と、セールのない月の同じ曜日の売上。
:::

### 課題A｜推定値の報告書を作る

自分の売場のデータ（日別の売上・客数など）で、次をまとめる。

| 項目 | 書くこと |
| --- | --- |
| 推定するもの | 母平均・母分散・母比率のどれか、母集団は何か |
| 推定値 | x̄・s²（n−1 で割る）・p̂ と、n |
| 外れうる幅 | 標準誤差 s÷√n や √(p̂(1−p̂)÷n) |
| 集め方 | いつ・どこの・だれのデータか、日の間に共通の要因や偏りがないか |

### 課題B｜何日分あれば足りるかを決める

**問い**　ふだんの日の売上の標準偏差は約3万円。1日の平均売上を、標準誤差0.5万円以内で推定したい。何日分のデータが要るか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること**：日々の売上が独立に同じ分布から出るとみると、SE＝3÷√n。3÷√n≦0.5 から √n≧6、n≧36。36日分で SE は0.5万円になる。ただし、これは散らばりの分だけで、集め方の偏り（セールの日だけ多く取る・天気のよい日だけ取る）は日数を増やしても減らない。

**統計の外で決めること**：36日を待つか、少ない日数で幅の広い推定値を使うか。日の間に共通の要因（季節）があると、実際の幅は s÷√n より広い。

**小さな例で検証**：ラボの「推定量を比べる」で σ＝3 にし、n を9・36 にして、標本平均の SE が1から0.5に縮むのを見る。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何の母数を、どの母集団について、何のために推定するかが明確か |
| 仮定 | 独立・同じ分布・集め方の偏りを書いたか |
| 方法 | 推定量（n か n−1 か、平均か中央値か）を使い道から選んだか |
| 検証 | ラボや別の計算で確かめたか |
| 切り分け | 統計で言えること（推定値と SE）と、言えないこと（大きな値の理由・SE が意味を持たない場合）を分けたか |
| 解釈 | 大きな値の読み方を2つ以上並べ、次に確かめる記録を書いたか |
