### 探究｜「ふだんの1日の売上」を、何で推定するか

ある店の20日分の売上（万円）は、日の順に 10, 11, 12, 13, 14, 11, 40, 12, 13, 12, 11, 10, 14, 45, 13, 12, 11, 12, 13, 50。40・45・50 の3日はセールの日。本部は、来月の人員と仕入れを決めるために「この店の1日の売上の推定値」を1つ出してほしいと言っている。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 何を推定したいのかを、使い道ごとに書き出す（人員を決める日々の売上か、仕入れを決める月の合計か）
2. 仮定を書く：20日を独立に同じ分布から出たとみてよいか。セールの日は同じ仕組みで生まれた日か
3. 推定量を選ぶ：平均か中央値か、20日をまとめるか分けるかを、1の使い道から選ぶ
4. 小さな例で検証する：下のラボの「推定値を計算」に20日を入れ、平均・中央値・s を読む。次にセールの3日を除いた17日で同じものを読む
5. 統計で言えることと、セールの日についての解釈（2つ以上）を分け、次に確かめる記録を書く

{{lab:LAB-est@s6-free}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（この20日について）**：20日の平均は16.95万円、中央値は12万円、s は約12.2万円。平均は20日の合計339万円を20で割った数なので、この20日の合計を言い直したものになっている。一方、20日のうち17日は16.95万円より下で、平均は「ふだんの日」の売上を表していない。セールの3日を除いた17日なら、平均12万円・s は約1.22万円で、日ごとの散らばりは小さい。

**同じ仕組みが来月も続くとみたら言えること**：ふだんの日は12万円前後、セールの日は45万円前後とみて、来月の合計はセールの日数から組み立てられる。20日をまとめて独立に同じ分布から出たとみると、平均の標準誤差は s÷√20≒2.74万円になるが、セールの日が店の計画で決まっているなら、20日は同じ分布から出ていない。この標準誤差は、そのとき意味を持たない。

**この数だけでは言えないこと**：セールの日がなぜ大きいのか、来月も同じ仕組みが続くのか。

**解釈の例**：
- 値引きや告知で、ふだんは来ない客が来る。セールの日は、ふだんの日とは別の仕組み（集客の違い）で生まれた日で、だから売上が3倍以上になる。この20日の中では一番素直な読み方
- セールが前後の日の客を前借りしている。セールを知った客が買い物をセールの日まで待つので、セールの日が増え、ふだんの日が減る。そうなら、ふだんの日の12万円も「セールがある月のふだんの日」の値で、セールのない月にはもっと高くなりうる
- セールを、給料日や近くの催しの日に合わせて置いている。もともと客の多い日に重なるので、3日の売上の高さのうち、セールそのものの効き目は一部だけ

どの読み方が当たるかは、この20日の数だけからは決められない。

**統計の外で決めること・確かめること**：推定値を1つにまとめるかどうか。人員を決めるなら「ふだんの日12万円・セールの日は別」と2つで渡し、仕入れの合計なら来月のセールの日数を聞いてから組み立てる。次に確かめるなら、セールの前後の日の売上、セールのない月の同じ曜日の売上、セールの日の催し・給料日との重なり。
:::

### 課題A｜推定値の報告書を作る

自分の売場のデータ（日別の売上・客数など）で、次をまとめる。

| 項目 | 書くこと |
| --- | --- |
| 推定するもの | 母平均・母分散・母比率のどれか、母集団は何か |
| 推定値 | x̄・s²（n−1 で割る）・p̂ と、n |
| 外れうる幅 | 標準誤差 s÷√n や √(p̂(1−p̂)÷n) |
| 集め方 | いつ・どこの・だれのデータか、日の間に共通の要因や偏りがないか |

### 課題B｜s をどの日から推定するかで、必要な日数が変わる

**問い**　来月、ふだんの日の平均売上を、標準誤差0.5万円以内で推定したい。必要な日数は n≧(s÷0.5)² で見積もる。この s を、上の探究の20日全部から取るか、セールの日を除いた17日から取るかで、必要な日数はどう変わるか。どちらを採るかは何で決まるか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること**：17日の s（約1.22）なら (s÷0.5)²≒6.0 で、6日。20日の s（約12.2）なら (s÷0.5)²≒600 で、601日。どちらも、日々の売上が独立に同じ分布から出るとみたときの数で、散らばりの分だけ。集め方の偏り（天気のよい日だけ取る）は日数を増やしても減らない。

**統計の外で決めること**：推定したいのが「ふだんの日」なら、セールの日はその母集団に入らないので、17日の s を使う方が筋が通る。セールの日も含めた「どの日でも」の平均なら20日の s を使うが、そのときは600日を超える日数が要り、それより先に「セールの日を分けて推定する」方を考える。どちらの母集団を推定するかは、統計ではなく使い道で決まる。

**小さな例で検証**：17日の s で n＝6 にすると、SE＝1.22÷√6≒0.50万円になる。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何の母数を、どの母集団について、何のために推定するかが明確か |
| 仮定 | 独立・同じ分布・集め方の偏りを書いたか |
| 方法 | 推定量（n か n−1 か、平均か中央値か）を使い道から選んだか |
| 検証 | ラボや別の計算で確かめたか |
| 切り分け | 統計で言えること（推定値と SE）と、言えないこと（大きな値の理由・SE が意味を持たない場合）を分けたか |
| 解釈 | 大きな値の読み方を2つ以上並べ、次に確かめる記録を書いたか |
