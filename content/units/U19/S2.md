### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}

**お手本：二項分布の確率を正規分布で求めてよい理由**

- **条件**：応募者 n が多く、np と n(1−p) がどちらも十分大きいとき
- **対象と結論**：当選者数 X の確率は、平均 np・標準偏差 √(np(1−p)) の正規分布で近似できる
- **根拠**：X は「当選＝1・落選＝0」を n 人分足したもので、中心極限定理により、足した数の分布は n が大きいと正規分布に近づくから
- **成り立たない場合**：p が0や1に近く np が小さいと、分布が強く歪んで近似がずれる

::: toggle つなげると（お手本の文）
「応募者が多く、np と n(1−p) が十分大きければ、当選者数の確率は平均 np・標準偏差 √(np(1−p)) の正規分布で近似できる。当選者数は0か1の値を n 人分足したもので、中心極限定理により正規分布に近づくからである。ただし p が0や1に近く np が小さい場合は、分布が歪んで近似がずれる。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「大数の法則があるので、データを30個以上集めれば、どんなデータも正規分布になります。コインで表が5回続いたら、次は裏が出やすくなります。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 正規分布に近づくのは「平均の分布」で、データ1個ずつの分布ではない。これは中心極限定理。
- n＝30 で十分かは母集団の歪みによる。一律の基準ではない。
- コインは毎回独立で、表が続いても次の確率は0.5。割合が0.5に近づくのは、多くの回で薄まるから。

**言い直しの例**

「独立に取った標本の平均は、n が大きいと正規分布に近づく（中心極限定理）。どれくらいの n で十分かは、母集団の歪みによる。コインの表の割合は回数を重ねると0.5に近づく（大数の法則）が、1回ごとの確率は表が続いても0.5のままである。」
:::

::: toggle 取り違えやすい言葉
- **「大数の法則」と「中心極限定理」**：大数の法則＝平均の値が μ に近づく／中心極限定理＝平均の分布の形が正規分布に近づく
- **「母集団の分布」と「平均の分布」**：正規に近づくのは平均の分布。母集団（1個ずつの値）の形は変わらない
- **「k 以下」と「k 以上」の連続修正**：以下は k＋0.5、以上は k−0.5。「未満」「超える」は整数をずらしてから考える（k 未満＝k−1 以下）
- **「上限」と「確率」**：チェビシェフの 1÷k² は「これ以下」という保証で、実際の確率ではない
:::
