### 判断の手順（毎回これを書く）　{{power:P3}}

1. **何の確率か**：平均（割合）が μ に近いかなら大数の法則と SE、平均や回数が「k 以上」になる確率なら中心極限定理で正規近似
2. **近似してよいか**：二項なら np と n(1−p) がどちらも十分大きいか（10以上が目安）。平均なら母集団の歪みと n の大きさ。独立か
3. **連続修正の向き**：回数（とびとびの値）を正規で近似するときは、以下は k＋0.5、以上は k−0.5、a〜b は a−0.5〜b＋0.5。図に棒を描いて確かめる

### 似た場面を見分ける

「当選者が55人以下」は二項の正規近似（連続修正あり）、「25人の平均待ち時間が6分を超える」は中心極限定理で x̄ を正規近似（連続量なので修正なし）、「回数を重ねると割合が0.3に近づく」は大数の法則。「40人中の返品が0件」は np が小さく、正規近似は向かない。

### 使えない例と比べる　{{power:P3}}

- n＝30 以上ならどんなデータも正規分布 → ✕。正規に近づくのは平均の分布で、必要な n は母集団の歪みによる。
- 表が続いたので次は裏が出やすい → ✕。毎回独立。割合が近づくのは回数で薄まるから。
- np＝2 の二項分布に正規近似を使う → ✕。分布が歪んでずれる。正確に計算するかポアソン近似（{{unit:U15}}）。
- 「k 以上」の連続修正で k＋0.5 を使う → ✕。k の棒の左端 k−0.5 から数える。
- チェビシェフの上限 1/4 を「25%起きる」と読む → ✕。上限は保証で、正規なら約5%。

### この先で使う

中心極限定理があるので、母集団の形が分からなくても、n が大きければ x̄ や p̂ を正規分布で扱える。これが平均・割合の信頼区間（{{unit:U22}}）と検定（{{unit:U25}}・{{unit:U26}}）の土台になる。σ が分からず n が小さいときは t 分布（{{unit:U20}}）を使う。
