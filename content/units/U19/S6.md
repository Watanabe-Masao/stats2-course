### 課題A｜キャンペーンの用意数を決める

過去のキャンペーンの応募者数と当選率（または利用率）から、次を作る。

| 項目 | 書くこと |
| --- | --- |
| n・p | 見込みの応募者数と当選率 |
| 平均・標準偏差 | np と √(np(1−p)) |
| 目標 | 足りなくなる確率を何%以下にするか |
| 用意数 | 連続修正ありの正規近似で求めた k |

### 課題B｜「最初の何人で判断するか」を決める

**問い**　新商品の試食で、購入率が20%を超えるかを判断したい。最初の何人の結果を見れば判断してよいかを決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：購入率が本当に0.2のとき、割合のずれの目安は √(0.16÷n)。±2SE を ±5ポイントに収めたいなら SE＝0.025、n＝0.16÷0.025²＝256人。それより前の割合は、偶然で±5ポイント以上動く。

**小さな例で検証**：ラボの「大数の法則」で p＝0.2 にし、N を50・256・1000 と変えて、割合の線が帯の中で落ち着く様子を見る。「別の乱数で引き直す」で何度か試す。

**限界**：試食に来る客は時間帯で違う（独立でない・同じ分布でない）。午前だけの256人では、1日全体の購入率とは言えない。
:::

### 課題C｜平均購入額を正規で扱ってよいかを確かめる

POS から1客ごとの購入額を取り出し、ヒストグラムで歪みを見る。1日の客数 n で x̄ の歪度（歪度÷√n）を出し、0.5 より小さければ正規近似を使う、などの自分の基準を決める。大口客を除いた場合と比べる。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 平均の値の話か、確率（分布の形）の話かが明確か |
| 仮定 | 独立・同じ分布・分散が有限を書いたか |
| 方法 | 正規近似の平均・標準偏差と連続修正を正しく使ったか |
| 検証 | 正確な二項やシミュレーションと比べたか |
| 限界 | np が小さい・強い歪み・大口客の影響を書いたか |
