### 探究｜当選者の数が、計算よりばらつく。どう読むか

当選率 0.1 のキャンペーンに毎回およそ 1000人が応募する。二項分布で考えると、当選者の数は平均 100人・標準偏差 √90≒9.5人で、賞品を 116個用意すれば足りなくなる確率は5%以下のはず（{{stage:S4}} の計算）。ところが過去の 10回を見ると、当選者の数の標準偏差は 18人ほどあり、10回のうち3回は 116個では足りなかった。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 二項分布で計算した標準偏差と、過去の実際の標準偏差を比べ、二項分布のどの前提（独立・同じ確率）が合っていない可能性があるかを書く
2. 小さな例で検証する：ラボの「二項の正規近似」で n＝1000・p＝0.1 の幅を見て、実際の 18人と比べる
3. 統計で言えることと、ばらつきが大きい理由についての解釈（2つ以上）を分けて書く
4. 用意数を決める前に、次に確かめる記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること**：二項分布（1000人がそれぞれ独立に、同じ確率 0.1 で当たる）なら、当選者の数の標準偏差は約 9.5人。実際は 18人で、約 1.9倍。10回分の記録なので 18人そのものにも幅はあるが、2倍近い差は、二項分布の前提のどれかが合っていないことを示している。116個は二項分布の前提の下で出した数で、その前提が崩れていれば、足りなくなる確率は5%よりずっと大きい（標準偏差 18人で正規近似すると、5%以下にするには約 130個）。

**解釈の例**：
- 当たり方が独立でない：同じ家族や職場が何人分もまとめて応募し、当たり外れがまとまって動く
- 回ごとに当選の確率が違う：商品によって当選の決まり方が違う・応募の多い日に絞る、などで p が 0.1 で一定ではない

どちらも二項分布より大きなばらつきを生むので、ばらつきの大きさだけからはどちらかを決められない。

**統計の外で決めること・確かめること**：用意数を 116個にするか 130個にするか（余った賞品の費用と、足りなかったときの信用のどちらを重く見るか）。次に確かめるなら、応募者の住所・名義の重なりと、回ごとの当選の決め方の記録。
:::

### 課題A｜キャンペーンの用意数を決める

過去のキャンペーンの応募者数と当選率（または利用率）から、次を作る。

| 項目 | 書くこと |
| --- | --- |
| n・p | 見込みの応募者数と当選率 |
| 平均・標準偏差 | np と √(np(1−p)) |
| 目標 | 足りなくなる確率を何%以下にするか |
| 用意数 | 連続修正ありの正規近似で求めた k |

### 課題B｜「最初の何人で判断するか」を決める

**問い**　新商品の試食で、購入率が20%を超えるかを判断したい。最初の何人の結果を見れば判断してよいかを決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること**：購入率が本当に 0.2 で客が独立なら、割合のずれの目安は √(0.16÷n)。±2SE を ±5ポイントに収めたいなら SE＝0.025、n＝0.16÷0.025²＝256人。それより少ない人数の割合は、偶然で ±5ポイント以上動きうる。試食に来る客は時間帯で違う（独立でない・同じ分布でない）ので、午前だけの 256人では1日全体の購入率とは言えない。

**統計の外で決めること**：選び肢は「256人まで待つ（判断は遅いが ±5ポイントに収まる）」と「100人で一度見る（早いが ±8ポイント動きうる）」。判断が遅れる損と、誤って判断する損のどちらを重く見るかで決める。

**小さな例で検証**：ラボの「大数の法則」で p＝0.2 にし、N を50・256・1000 と変えて、割合の線が帯の中で落ち着く様子を見る。「別の乱数で引き直す」で何度か試す。
:::

### 課題C｜平均購入額を正規で扱ってよいかを確かめる

POS から1客ごとの購入額を取り出し、ヒストグラムで歪みを見る。1日の客数 n で x̄ の歪度（歪度÷√n）を出し、0.5 より小さければ正規近似を使う、などの自分の基準を決める。大口客を除いた場合と比べる。

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 平均の値の話か、確率（分布の形・ばらつき）の話かが明確か |
| 仮定 | 独立・同じ分布・分散が有限を書いたか |
| 方法 | 正規近似の平均・標準偏差と連続修正を正しく使ったか |
| 検証 | 正確な二項や過去の記録・シミュレーションと比べたか |
| 切り分け | 統計で言えること（前提の下での確率・前提が合っていないこと）と、言えないこと（なぜ合っていないか）を分けたか |
| 解釈 | ばらつきの理由の読み方を2つ以上並べ、次に確かめる記録を書いたか |
