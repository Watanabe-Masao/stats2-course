### 0｜入口の問い

::: task
当選率0.5のキャンペーンに100人が応募する。賞品を55個用意すれば足りるか。「平均は50人なので55個あれば大丈夫」という案が出た。足りなくなる確率はどれくらいか。二項分布の確率を56個足すのは大変だが、ほかに方法はあるか。
:::

^ まだ答えなくてよい。「平均が近づく」（大数の法則）と「平均の分布の形が正規に近づく」（中心極限定理）を分け、二項分布の確率を正規分布で近似できるようになるのが初学のゴール。

### 2｜意味をつかむ：2つの「近づく」を分ける　{{power:P3}}

::: ask 何回も試すと、割合（平均）はどうなる？
→ **大数の法則**：標本平均の**値**が母平均 μ（割合なら p）に近づく。ずれの目安 SE は √n に反比例して小さくなる。
:::

::: ask 平均の分布の「形」はどうなる？
→ **中心極限定理**：母集団の形が偏っていても、n が大きいと x̄ の**分布の形**が正規分布 N(μ, σ²/n) に近づく。だから x̄ の確率を正規分布の表で求められる。
:::

::: ask 二項分布にも使える？
→ 使える。二項の回数 X は「当たり＝1・はずれ＝0」の合計なので、n が大きいと N(np, np(1−p)) で近似できる。棒の幅の半分 0.5 をずらす**連続修正**を付ける。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
Z=\frac{(k+0.5)-np}{\sqrt{np(1-p)}}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| n・p | 応募者100人・当選率0.5 |
| np・√(np(1−p)) | 二項の平均50・標準偏差5 |
| k＋0.5 | 「k 以下」は棒の右端まで含める（連続修正） |

**式を言葉で読む**：二項の棒は「k を中心に幅1」の長方形。「55人以下」は55の棒の右端55.5までの面積で、正規曲線の 55.5 以下の面積で近似する。

| 聞かれ方 | 連続修正 |
| --- | --- |
| k 以下 | k＋0.5 以下 |
| k 以上 | k−0.5 以上 |
| a〜b | a−0.5〜b＋0.5 |

```txt
√n(X̄−μ)/σ → 標準正規の分布（σ>0）
Bin(n,p) ≈ N(np,np(1−p))
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　キャンペーンの当選率は0.5。100人が応募したとき、当選者が55人以下になる確率を正規近似で求めよ。

1. 平均 np＝100×0.5＝50、標準偏差＝√(100×0.5×0.5)＝5
2. 条件確認：np＝50、n(1−p)＝50 ともに十分大きい
3. 連続修正：X≦55 → Y≦55.5
4. z＝(55.5−50)÷5＝**1.1**
5. Φ(1.1)＝**0.8643**（正確な二項計算でも0.8644）

{{lab:LAB-clt@s1-bin}}

::: key
約86%の確率で当選は55人以内。賞品を55個用意すると、約14%の確率で足りなくなる。大数の法則は平均の**値**が μ に近づくこと、中心極限定理は平均の**分布の形**が正規に近づくこと。「n＝30 なら何でも正規」という一律のルールはない。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-clt@s1-clt}}

1. **予想**：ラボの課題カードで、右に長い裾の待ち時間から取った30人の平均の分布の形を選ぶ。
2. **操作**：結果を見たら、n を 1 → 5 → 30 → 100 と変える。次に母集団を「山が2つ」「0か1」に変える。
3. **観察**：x̄ の分布の形・中心・幅は、n でどう変わるか。
4. **説明**：「n を大きくすると x̄ の分布は□になった。なぜなら□」を1文で書く。
5. **ラボなしで**：待ち時間（平均5分・標準偏差5分）の100人平均の SE と、x̄ の歪度（2÷√n）を出す。

::: toggle 答え（書いてから開く）
- **観察**：n＝1 は母集団そのままの右に長い形。n を増やすと中心は5のまま、幅は σ÷√n で細くなり、形は正規曲線に重なっていく。山が2つの母集団でも、n が大きいと x̄ は山1つになる。
- **説明の例**：「n を大きくすると x̄ の分布は左右対称の正規分布に近づいた。たくさんの値を平均すると、極端な値どうしが打ち消し合い、歪みが √n で割った分だけ小さくなるから」
- **ラボなしで**：SE＝5÷√100＝**0.5分**、歪度＝2÷10＝**0.2**。
:::
