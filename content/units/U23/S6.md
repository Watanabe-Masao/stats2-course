### 探究｜どれと比べるかで、施策の効果が変わる

新しい陳列を8店で始め、別の8店では始めなかった。どちらも、始める前の4週間と後の4週間で、1日の平均売上（万円）を店ごとに出した。陳列を変えた8店は、後−前の差が平均2.4・差の標準偏差1.6。変えなかった8店は、差が平均1.6・差の標準偏差1.6。後の4週間だけで比べると、変えた8店の平均は52.4、変えなかった8店は50.0（どちらも店の間の標準偏差は約9）。本部は「陳列の効果」を区間つきで知りたい。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 何と何を比べると「陳列の効果」になるのかを書く（変えた店の前と後か、変えた店と変えなかった店か、その両方か）
2. 仮定を書く：店どうしは独立か、変えた店と変えなかった店は、陳列のほかの点（地域・時期）でそろっているか
3. 下のラボで、比べ方ごとに区間を作る（対応あり：変えた8店、変えなかった8店。平均の差：後の4週間だけ、差どうし）
4. 統計で言えることと、比べ方で結論が変わる理由についての解釈（2つ以上）を分ける
5. 続けるかを決める前に、次に確かめる記録を書く

{{lab:LAB-two@s6-free}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（この16店の、この8週間について）**：変えた8店は前より平均2.4、変えなかった8店も平均1.6上がった。

**店が独立で、差が正規分布に近いとみたら言えること（比べ方ごと）**：
- 変えた8店の前後（対応あり）：差の平均の95%信頼区間は約 1.06〜3.74 で、0を含まない。「変えた店では売上が上がった」とは言える
- 変えなかった8店の前後：約 0.26〜2.94 で、こちらも0を含まない。陳列と関係なく、売上が上がる何かがあった
- 差どうしの差（2.4−1.6＝0.8。ウェルチ）：約 −0.92〜2.52 で、0を含む。「変えなかった店より多く上がった」とまでは言えない
- 後の4週間だけの差（52.4−50.0＝2.4）：約 −7.25〜12.05 と広く、0を含む。店の大きさの違いがばらつきに残り、ほとんど何も言えない

**この数だけでは言えないこと**：陳列そのものの効果がどれくらいか。変えた店と変えなかった店が陳列のほかの点でそろっているかは、この数からは分からない。

**解釈の例**：
- 8週間の間に、季節や地域の催しで、どの店も売上が1.6ほど上がった。変えた店の2.4のうち、陳列の分はその残りの0.8ほどで、その0.8も偶然の揺れと区別できない。この16店の数の生まれ方として、一番素直な読み方
- 陳列を変える店に、もともと伸びている店（売場の担当が熱心な店）を選んだ。伸びる店を選んだ分だけ、変えた店の上がり方が大きく見える。このときは、0.8 にも選び方の分が入っている
- 陳列を変えた店の近くの客が、変えなかった店にも流れて、変えなかった店の売上も押し上げた。このときは、差どうしの差が陳列の効果を小さく見せている

どの読み方が当たるかは、この16店の数だけからは決められない。

**統計の外で決めること・確かめること**：「変えた店で2.4上がった」だけを報告しない。比べ方と区間を並べて出す。次に確かめるなら、変える店をどう選んだか、8週間の催しの記録、近い店どうしの客の流れ。続けるかどうかは、陳列の手間と、上がり方が0.8前後かもしれないことを合わせて決める。店をくじで分ける方法は {{unit:U32}}。
:::

### 課題A｜施策の効果を区間で報告する

自分の売場の施策について、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 比べ方 | 同じ店の前後（対応あり）か、施策をした店としない店（独立）か、その両方か |
| 区間 | D̄ ± t×s_D÷√n、またはウェルチの区間 |
| 結論 | 区間が0を含むか、差はどれくらいか |
| 前提 | 店の選び方、前後や2群で施策のほかに違うこと（季節・曜日・客層） |

### 課題B｜新しいレジで、ばらつきが変わったかを見る

**問い**　新しいレジに替えて、1回の処理時間のばらつきが変わったかを、旧と新の分散の比の区間で見たい。何回ずつ測るか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**選び肢**：①旧と新を10回ずつ測る。②60回ずつ測る。

**統計で言えること**：それぞれ独立に正規分布に従うとみると、分散の比 R の95%信頼区間は、①で R÷4.026〜R×4.026、②で R÷1.674〜R×1.674（F の点。自由度9と59）。分散で2倍（標準偏差で約1.4倍）の違いが出たとき、①の区間は約 0.50〜8.05 で1を含み、②は約 1.19〜3.35 で1を含まない。10回ずつでは、分散が2倍になっても見分けられない。

**統計の外で決めること**：測る手間と、ばらつきが増えたのを見逃す損のどちらを重く見るか。旧と新で、測る時間帯（混む時間かどうか）をそろえないと、レジの違いと時間帯の違いが混ざる。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何と何を比べると知りたい効果になるかが明確か |
| 仮定 | 対応の有無・独立・正規分布・2群が施策のほかにそろっているかを書いたか |
| 方法 | 対応あり／ウェルチ／比率の差／F・χ² を、比べ方に合わせて選んだか |
| 検証 | ラボや別の計算で確かめたか |
| 切り分け | 統計で言えること（比べ方ごとの区間）と、言えないこと（施策のほかの違いとの区別）を分けたか |
| 解釈 | 比べ方で結論が変わる理由の読み方を2つ以上並べ、次に確かめる記録を書いたか |
