### 課題A｜施策の効果を区間で報告する

自分の売場の施策について、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 比べ方 | 同じ店の前後（対応あり）か、施策をした店としない店（独立）か |
| 区間 | D̄ ± t×s_D÷√n、またはウェルチの区間 |
| 結論 | 区間が0を含むか、差はどれくらいか |
| 前提 | 店の選び方、前後で他に変わったこと（季節など） |

### 課題B｜2つのキャンペーンを比べる

**問い**　キャンペーンAとBの購入率を比べて、どちらを続けるかを決めたい。どう比べ、どう報告するか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：同じ期間に、無作為に分けた客にAとBを見せる。購入率の差 p̂_A−p̂_B の95%区間を作る。区間が0を含まず、差の下限でも費用に見合うならAを続ける。0を含むなら、人数を増やすか、別の基準（費用・手間）で決める。

**小さな例で検証**：ラボの「比率の差」で、各200人・60人と40人の区間（約0.016〜0.184）を見る。人数を各800人にすると幅は半分になる。

**限界**：AとBで客層や曜日が違うと、差はキャンペーン以外の理由かもしれない（無作為に割り当てる実験の設計は {{unit:U32}}）。区間はばらつきの幅で、偏りは直さない。
:::

### 課題C｜ばらつきの安定を評価する

製造や作業の時間を10回、20回、50回と測り、母分散の区間がどれだけ狭くなるかを見る。「ばらつきが基準の2倍以内」と言うのに何回の測定が要るかを決める。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何の区間（差・比・分散）かが明確か |
| 仮定 | 対応の有無・独立・正規分布・等分散を書いたか |
| 方法 | 対応あり／ウェルチ／比率の差／F・χ² を正しく選んだか |
| 検証 | ラボや別の計算で確かめたか |
| 限界 | 客層・季節など、区間に入らない違いを書いたか |
