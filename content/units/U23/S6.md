### 探究｜平日のキャンペーンと土日のキャンペーン

キャンペーンA は平日に、キャンペーンB は土日に、それぞれ4週間行った。A を見た平日の客600人のうち90人（0.15）、B を見た土日の客400人のうち84人（0.21）が買った。担当者は「B の方が効く。来月から B に切り替えたい」と言っている。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 何を比べたいのかを書く（キャンペーンの違いか、平日と土日の客の違いか）
2. 仮定を書く：A を見た客と B を見た客は、キャンペーン以外の点で同じとみてよいか
3. 下のラボの「比率の差」で、購入率の差の95%信頼区間を出す
4. 統計で言えることと、差が生まれた理由についての解釈（2つ以上）を分ける
5. 切り替えを決める前に、次に確かめる記録を書く

{{lab:LAB-two@s6-free}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（この4週間の、見た客について）**：A を見た平日の客の購入率は0.15、B を見た土日の客は0.21。

**それぞれの客が、平日の客全体・土日の客全体から無作為に選ばれたとみたら言えること**：購入率の差（A−B）の95%信頼区間は −0.06±1.96×√(0.15×0.85÷600＋0.21×0.79÷400)、約 −0.109〜−0.011 で、0を含まない。「B を見た土日の客」の方が「A を見た平日の客」より購入率が高い、とまでは言える。

**この数だけでは言えないこと**：差がキャンペーンの違いから来たのか、平日と土日の客の違いから来たのか。曜日とキャンペーンが重なっているので、この2つは区間をいくら狭くしても分けられない。

**解釈の例**：
- 土日の客は、家族でまとめ買いに来る人が多い。もともと買う気で来ているので、どんなキャンペーンでも購入率が高く出る。だから差の大部分は曜日の違い。この2つの数の生まれ方として、一番素直な読み方
- B の見せ方（大きな売場・試食つき）が、A よりも客の目に留まりやすい。だから同じ客に見せても B の方が買われる。差はキャンペーンの違い
- 土日は来店客が多く、売場の前を通る人のうち、立ち止まって見る人の割合が平日と違う。「見た客」の数え方が平日と土日でそろっていなければ、分母が違うものを比べている

どの読み方が当たるかは、この2つの数だけからは決められない。

**統計の外で決めること・確かめること**：今の数だけでは、B に切り替える理由として弱い。次に確かめるなら、同じ曜日に A と B を客ごと（またはレジごと）に無作為に割り当てて比べる（{{unit:U32}}）。それまでに分かることとして、キャンペーンをしていない週の平日と土日の購入率の差を、過去の記録から出す。
:::

### 課題A｜施策の効果を区間で報告する

自分の売場の施策について、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 比べ方 | 同じ店の前後（対応あり）か、施策をした店としない店（独立）か |
| 区間 | D̄ ± t×s_D÷√n、またはウェルチの区間 |
| 結論 | 区間が0を含むか、差はどれくらいか |
| 前提 | 店の選び方、前後や2群で施策のほかに違うこと（季節・曜日・客層） |

### 課題B｜ばらつきの評価に何回の測定を使うか

**問い**　レジ1回の処理時間のばらつきが、基準より大きくなっていないかを毎月確かめたい。1か月に何回測って、どう報告するか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**選び肢**：①毎月10回だけ測る。②毎月50回測る。

**統計で言えること**：母分散の95%信頼区間の上限÷下限は、①で約7.0倍、②で約2.2倍（χ² の点の比。母集団が正規分布のとき）。10回では区間がとても広く、ばらつきが2倍程度変わっても見分けにくい。

**統計の外で決めること**：測る手間と、ばらつきの増えを見逃す損のどちらを重く見るか。測る日や時間帯をそろえないと、混む時間の測定が多い月だけばらつきが大きく出る。報告には、区間と回数と、いつ測ったかを一緒に書く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何と何の差（比）を、だれについて知りたいかが明確か |
| 仮定 | 対応の有無・独立・正規分布・2群が施策のほかにそろっているかを書いたか |
| 方法 | 対応あり／ウェルチ／比率の差／F・χ² を正しく選んだか |
| 検証 | ラボや別の計算で確かめたか |
| 切り分け | 統計で言えること（区間）と、言えないこと（曜日・客層など重なった要因との区別）を分けたか |
| 解釈 | 差が生まれた理由の読み方を2つ以上並べ、次に確かめる記録を書いたか |
