### 0｜入口の問い

::: task
袋詰めを10回測ると、重さの不偏分散は s²＝4（g²）だった。本当のばらつき（母分散）はどれくらいの範囲か。新レイアウトにした同じ16店で、前後の売上の差は平均3万円。この差はどこまで確かか。2つのキャンペーンの購入率の差や、2店のばらつきの違いは、どう区間にするか。
:::

^ まだ答えなくてよい。平均1つの区間（{{unit:U22}}）から広げて、母分散・平均の差・比率の差・分散の比の区間を、「何の区間か」で分布と形を選んで作れるようになるのが初学のゴール。

### 2｜意味をつかむ：何の区間かで形が変わる　{{power:P3}}

::: ask 母分散の区間は、平均の区間と何が違う？
→ (n−1)s²÷σ² が χ²(n−1) に従うことを使う。χ² は右に長く左右対称でないので、区間は「s² ± 誤差幅」の形にならない。(n−1)s² を**大きい方の点で割ると下限**、小さい方の点で割ると上限。
:::

::: ask 2つの平均の差は、まず何を決める？
→ **独立か、対応ありか**。同じ店の前後のように対応があれば、1組ごとの差 D を作って D̄ の1標本の t 区間にする。別々の2群なら x̄₁−x̄₂ ± t × √(s₁²÷n₁＋s₂²÷n₂)（ウェルチ）、または等分散を仮定して分散を合わせる。
:::

::: ask 比率の差や分散の比は？
→ 比率の差は p̂₁−p̂₂ ± z × √(p̂₁(1−p̂₁)÷n₁＋p̂₂(1−p̂₂)÷n₂)。分散の比は R＝s₁²÷s₂² を F の点で割る。差の区間が**0を含むか**、比の区間が**1を含むか**で、「違いがあると言えるか」を読む。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
\frac{(n-1)s^2}{\chi^2_{0.975}(n-1)}\le\sigma^2\le\frac{(n-1)s^2}{\chi^2_{0.025}(n-1)}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| n | 袋詰めの回数10 → 自由度9 |
| s² | 不偏分散4 |
| χ²₀.₉₇₅ | 大きい方の点19.023 → **下限**の分母 |
| χ²₀.₀₂₅ | 小さい方の点2.700 → **上限**の分母 |

**式を言葉で読む**：分子はどちらも (n−1)s²。大きい数で割れば小さくなるので、大きい点で割った方が下限。区間の中で s² は真ん中になく、下限に近い側に寄る。

| 推定したいもの | 中心 | 分布 |
| --- | --- | --- |
| 母分散 | s² | χ²(n−1)・左右非対称 |
| 平均の差（独立） | x̄₁−x̄₂ | t（ウェルチなど） |
| 平均の差（対応あり） | 差の平均 D̄ | t(n−1) |
| 分散の比 | s₁²÷s₂² | F |
| 比率の差 | p̂₁−p̂₂ | 正規近似 |

```txt
母分散：[(n−1)s²/χ²の0.975点, (n−1)s²/χ²の0.025点]
対応あり：D̄ ± t(n−1) × s_D/√n
独立（ウェルチ）：(x̄₁−x̄₂) ± t × √(s₁²/n₁＋s₂²/n₂)
比率の差：(p̂₁−p̂₂) ± z × √(p̂₁(1−p̂₁)/n₁＋p̂₂(1−p̂₂)/n₂)
分散の比：[R/Fの0.975点, R/Fの0.025点]、R＝s₁²/s₂²
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　① 袋詰め作業10回の重さの不偏分散は s²＝4（g²）。χ²(9) の左累積0.025点は2.700、0.975点は19.023。母分散の95%信頼区間を求めよ。② 同じ16店で施策の前後の売上を比べると、差 D の平均は3万円、差の標準偏差は4万円。差の平均の95%信頼区間を求めよ（t(15) の0.975点は2.131）。

1. ① (n−1)s²＝9×4＝**36**
2. 下限＝36÷19.023＝**1.892**、上限＝36÷2.700＝**13.333**
3. 標準偏差の区間にするなら平方根：約 **1.38〜3.65 g**
4. ② SE＝4÷√16＝1、3±2.131×1 → **0.869〜5.131**（0を含まない）

::: warn
大きい点で割ると小さい値になる → 下限。分母を逆にすると上限と下限が入れ替わる。母分散の区間は「s²±◯」の形では作れない。同じ店の前後を、別々の2群として計算しない。
:::

::: key
10回だけではばらつきの推定はかなり不確か（分散で約2〜13、7倍の幅）。安定性を評価するなら回数を増やす。施策の差は0.869〜5.131万円で0を含まないので、前後で差があると言える。対応ありなので、店ごとの大きさの違いは差を取ったときに消えている。
:::

::: toggle 答え（書いてから開く）
- **観察**：ウェルチは SE≒1.90・自由度≒23.3 で、区間は約1.08〜8.92（0を含まない）。等分散を仮定すると、合わせた分散が44.7 になり SE≒2.59、区間は約 −0.30〜10.30（0を含む）。s₂ を2にすると2つの方法の差はほとんどなくなる。

::: summary

:::
