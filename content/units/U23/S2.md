**お手本：同じ店の前後を比べるとき、差 D を作って区間を作る理由**

- **条件**：同じ16店について、施策の前と後の売上があるとき
- **対象と結論**：1店ごとの差 D を1つのデータとみて、D̄ ± t(15)×s_D÷√16 で区間を作る
- **根拠**：店の大きさの違いは前後で共通なので、差を取ると消える。独立な2群として扱うと、その違いがばらつきに入って区間が広くなりすぎる
- **成り立たない場合**：前と後で別の店を選んでいる（対応がない）なら、独立2群の区間を使う

::: toggle つなげると（お手本の文）
「同じ16店の施策前後を比べるときは、1店ごとの差 D を1つのデータとみて D̄ ± t(15)×s_D÷√16 で区間を作る。店の大きさの違いは前後で共通なので差を取ると消え、独立な2群として扱うとその違いがばらつきに入り区間が広くなりすぎるからである。ただし前と後で別の店を選んだ場合は対応がないので、独立2群の区間を使う。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「s²＝4 なので、母分散の区間は 4±1.96×SE で作りました。2つの店の購入率の区間がそれぞれ少し重なっているので、2店の購入率に差はありません。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 母分散の区間は χ² を使い、(n−1)s² を χ² の点で割る。左右対称な「±」の形にはならない。
- 2つの区間が重なっていても、差の区間が0を含まないことはある。差について言うなら、p̂₁−p̂₂ の区間を作る。

**言い直しの例**

「母分散の区間は、(n−1)s² を χ²(n−1) の0.975点で割った値から0.025点で割った値まで（n＝10 なら1.89〜13.33）。2店の購入率の差は、p̂₁−p̂₂ ± 1.96×√(p̂₁(1−p̂₁)÷n₁＋p̂₂(1−p̂₂)÷n₂) の区間を作り、0を含むかで判断する。」
:::

::: toggle 取り違えやすい言葉
- **「独立2群」と「対応あり」**：別々の店（人）か、同じ店（人）の前後か。対応ありは差を取る
- **「ウェルチ」と「等分散」**：ウェルチは各群の s² をそのまま使う。等分散は2群の s² を合わせる（ばらつきが同じときだけ）
- **「母分散の区間」と「母標準偏差の区間」**：標準偏差の区間は、分散の区間の両端の平方根
- **「区間が重なる」と「差の区間が0を含む」**：別々の区間の重なりでは判断しない。差の区間を作る
- **「F(n₁−1, n₂−1)」の順**：分子の自由度が先
:::

### 区間の早見

| 区間 | 作り方 |
| --- | --- |
| 母分散 | (n−1)s²÷χ²の点（大きい点で下限） |
| 対応ありの差 | D̄ ± t(n−1) × s_D÷√n |
| 独立の差（ウェルチ） | (x̄₁−x̄₂) ± t × √(s₁²÷n₁＋s₂²÷n₂) |
| 比率の差 | (p̂₁−p̂₂) ± 1.96 × √(各群の p̂(1−p̂)÷n の和) |
| 分散の比 | R÷F の点（大きい点で下限） |
