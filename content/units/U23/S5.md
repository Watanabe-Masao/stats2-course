### なぜ？｜なぜ組の差をとると、ばらつきが小さくなるのか

店ごとの売上を「店に共通の大きさ」と「その日その日の揺れ」の和とみる。施策の前 X と後 Y の差 D＝X−Y をとると、店に共通の大きさは引き算で消え、揺れの分だけが残る。式では、V(X−Y)＝V(X)＋V(Y)−2Cov(X, Y)。前と後の相関を ρ、どちらの分散も σ² とすると、V(D)＝2σ²(1−ρ)。

σ＝10 で、店に共通の大きさが分散のほとんど（ρ＝0.98）なら、V(D)＝2×100×0.02＝4、差の標準偏差は2まで小さくなる。逆に ρ＝0（店に共通の部分がない）なら、V(D)＝200 で、差の標準偏差は約14.1。組にすることで得をするのは、組の2つの値に正の相関があるとき。相関が0に近いか負なら、差のばらつきは小さくならず、自由度が n−1 に減る分だけ損をする。10店なら、相関が0.14ほどを超えれば組にした方が区間は狭い。

### 1つの数で何が消えるか

**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「差の平均の95%信頼区間は 1.57〜4.43」という1つの区間からは、**店ごとの差がどれだけばらついているか**が消えている。10店の差の平均が3・差の標準偏差が2なら、差の平均の区間はこれだけ狭い。けれども、店ごとの差が正規分布に近いとみると、店の差はおよそ 3±2×2、つまり −1〜7 に広がっていて、差がマイナスの（施策で下がった）店も約7%ある。

区間が狭くなるのは、10店分の平均をとって、平均のばらつき（標準誤差）が 2÷√10 に縮むから。店1つ1つの差は縮まない。「平均で上がった」と「どの店でも上がった」は別のことで、区間が言っているのは前の方だけ。

### 本当に？｜差に外れ値が1つあると

区間 D̄±t×S_D÷√n は、差が正規分布に近いことを前提にしている。10店の差（万円）が 1, 2, 2, 3, 3, 3, 4, 4, 5, 25 で、最後の1店だけ大きな工事の再開と重なったとする。この1店を含めると、差の平均は5.2・差の標準偏差は約7.05で、区間は約 0.16〜10.24。除いた9店なら、平均3・標準偏差は約1.22で、区間は約 2.06〜3.94。

1店が平均を2.2も動かし、標準偏差を約6倍にして、区間を5倍以上に広げている。中央値はどちらも3で動かない。外れ値を除くかどうかは統計では決められず、その店で何が起きたかで決める。除いたなら、除いた理由と、含めた場合の結果も一緒に書く。

### ほかでは？｜つながり

- **区間と検定**：差の95%区間が0を含まないことと、対応のある t 検定・ウェルチの t 検定で、両側5%で差がないと棄却されることは同じ（{{unit:U25}}）
- **比率の差の区間と検定の SE**：区間では各群の p̂ で SE を作るが、差がないことを検定するとき（{{unit:U26}}）は、差がないとして2群を合わせた比率で SE を作る。区間は「差がどれくらいか」、検定は「差がないとしたら珍しいか」を見る
- **相関係数の区間**：r を z＝0.5 log((1＋r)÷(1−r)) に変換すると正規分布に近づくので、z で区間を作って元に戻す（フィッシャーの z 変換。相関そのものは {{unit:U28}}）
- **実験の設計**：組にする（同じ店の前後）か、無作為に2群に分けるかは、データを取る前に決める（{{unit:U32}}）

### 説明してみる

::: task
店A（30日、標準偏差2）と店B（6日、標準偏差10）の平均の差を、ウェルチの方法で区間にする。自由度は 30＋6−2＝34 ではなく、約5.1 になる。なぜ自由度は、人数の少ない店B の 6−1＝5 に近くなるのかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
差の標準誤差の2乗は、A の分 s₁²÷n₁＝4÷30≒0.13 と、B の分 s₂²÷n₂＝100÷6≒16.7 の和で、ほとんどが B の分。標準誤差の揺れも、ほぼ B の分散の推定の揺れで決まる。B の分散は6日分のデータから推定するので、その推定には自由度5の分の不確かさしかない。だから、標準誤差を推定値で置き換えたときの t の裾の厚さも、自由度5くらいの t 分布に近い。

A の30日分をいくら増やしても、標準誤差のうち A の分がもともと小さいので、自由度はほとんど増えない。ウェルチの自由度の式は、2つの群の分散の推定が、標準誤差のどれだけを占めるかで重みをつけて、自由度を合わせたもの。等分散を仮定すると、合わせた分散が人数の多い A の小さなばらつきに引っぱられて標準誤差が約1.90 と小さくなり（ウェルチでは約4.10）、自由度34の小さな t の点と重なって、区間が狭すぎる。
:::
