### なぜ？｜なぜ組の差をとると、ばらつきが小さくなるのか

店ごとの売上を「店に共通の大きさ」と「その日その日の揺れ」の和とみる。施策の前 X と後 Y の差 D＝Y−X（後−前）をとると、店に共通の大きさは引き算で消え、揺れの分だけが残る。式では、V(Y−X)＝V(X)＋V(Y)−2Cov(X, Y)。前と後の相関を ρ、どちらの分散も σ² とすると、V(D)＝2σ²(1−ρ)。

σ＝10 で、店に共通の大きさが分散のほとんど（ρ＝0.98）なら、V(D)＝2×100×0.02＝4、差の標準偏差は2まで小さくなる。逆に ρ＝0（店に共通の部分がない）なら、V(D)＝200 で、差の標準偏差は約14.1。組にすることで得をするのは、組の2つの値に正の相関があるとき。相関が0なら差のばらつきは2群と同じで、自由度が n−1 に減る分だけ損をする。負の相関なら、差のばらつきは 2σ² よりも大きくなり、損はもっと大きい。10店なら、相関が0.14ほどを超えれば組にした方が区間は狭い。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「差の平均の95%信頼区間は 1.55〜3.45」という1つの区間からは、**店ごとの差がどれだけばらついているか**が消えている。12店の差の平均が2.5・差の標準偏差が1.5なら、差の平均の区間はこれだけ狭い。けれども、12店の差の標準偏差1.5が店全体の値に近く、店ごとの差が正規分布に近いとみると、店の差はおよそ 2.5±2×1.5、つまり −0.5〜5.5 に広がっていて、差がマイナスの店も約5%ある。そのマイナスが施策で下がったからなのか、その期間の売上の揺れなのかは、差の数だけでは分けられない（「なぜ？」で見たとおり、差には揺れの分も入っている）。

区間が狭くなるのは、12店分の平均をとって、平均のばらつき（標準誤差）が 1.5÷√12 に縮むから。店1つ1つの差は縮まない。「平均で上がった」と「どの店でも上がった」は別のことで、区間が言っているのは前の方だけ。

### 本当に？｜差に外れ値が1つあると

区間 D̄±t×S_D÷√n は、差が正規分布に近いことを前提にしている。10店の差（万円）が 1, 2, 2, 3, 3, 3, 4, 4, 5, 25 で、最後の1店だけ大きな工事の再開と重なったとする。この1店を含めると、差の平均は5.2・差の標準偏差は約7.05で、区間は約 0.16〜10.24。除いた9店なら、平均3・標準偏差は約1.22で、区間は約 2.06〜3.94。

1店が平均を2.2も動かし、標準偏差を約6倍にして、区間を5倍以上に広げている。中央値はどちらも3で動かない。外れ値を除くかどうかは統計では決められず、その店で何が起きたかで決める。除いたなら、除いた理由と、含めた場合の結果も一緒に書く。

### ほかでは？｜つながり

- **区間と検定**：差の95%区間が0を含まないことと、対応のある t 検定・ウェルチの t 検定で、両側5%で差がないと棄却されることは同じ（{{unit:U25}}）。ウェルチの自由度の決まり方もそこで扱う
- **比率の差の区間と検定の SE**：区間では各群の p̂ で SE を作るが、差がないことを検定するとき（{{unit:U26}}）は、差がないとして2群を合わせた比率で SE を作る。区間は「差がどれくらいか」、検定は「差がないとしたら珍しいか」を見る
- **相関係数の区間**：r を z＝0.5 log((1＋r)÷(1−r)) に変換すると正規分布に近づくので、z で区間を作って元に戻す（フィッシャーの z 変換。相関そのものは {{unit:U28}}）
- **実験の設計**：組にする（同じ店の前後）か、無作為に2群に分けるかは、データを取る前に決める（{{unit:U32}}）

### 説明してみる

::: task
キャンペーン A と B の購入率の差を調べる。最初は A・B とも200人ずつで、どちらも購入率は約0.2、差の95%信頼区間の誤差幅は約0.078。担当者は「A の人数だけを10倍の2000人にすれば、誤差幅は大きく縮むはず」と考えた。実際には約0.058 にしかならず、A を何人にしても約0.055 より下がらない。なぜかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
差の標準誤差の2乗は、A の分 p̂_A(1−p̂_A)÷n_A と、B の分 p̂_B(1−p̂_B)÷n_B の和。A の人数を増やして縮むのは A の分だけで、B の分 0.16÷200＝0.0008 はそのまま残る。A を何人にしても、標準誤差は √0.0008≒0.0283 より小さくならず、誤差幅は 1.96×0.0283≒0.055 で下げ止まる。差のばらつきは、2つの群の揺れが足し合わさって決まるので、片方だけを確かにしても、もう片方の揺れが残る。

この例のように2群の購入率が同じくらいなら、同じ合計の人数では、2群に半分ずつ分けた方が誤差幅は小さい（合わせて2200人なら、1100人ずつで約0.033、2000人と200人では約0.058）。どちらの群に人数を割くかは、データを取る前に、2つの群の揺れ（購入率の見込み）から決める。
:::
