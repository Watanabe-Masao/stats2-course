### 0｜入口の問い

::: task
100人を調べた客単価の平均は50百円だった（σ＝10百円は過去の記録から分かっている）。「全体の平均も50百円」と報告すると、別の100人なら51や49になるかもしれない。どれくらいの幅をつけて言えばよいか。400人中80人が買った「購入率20%」も、どこからどこまでなら信用できるか。
:::

^ まだ答えなくてよい。点推定（{{unit:U21}}）に「どれくらい外れうるか」の幅を添え、「推定値 ± 確率点 × 標準誤差」で区間を作り、95%の意味を正しく言えるようになるのが初学のゴール。

### 1｜前提チェック（2分）

::: toggle 3問だけ確かめる（答えも中にある）
1. σ＝10、n＝100 の平均の標準誤差は？ → 10÷√100＝1
2. p̂＝0.2、n＝400 の比率の標準誤差は？ → √(0.2×0.8÷400)＝√0.0004＝0.02
3. 標準正規分布で、両側合わせて95%が入る範囲の点は？ → ±1.96

1と2が不安なら {{unit:U18}}、3が不安なら {{unit:U16}} の初学へ。終わったらここへ戻る。
:::

### 2｜意味をつかむ：区間は「作り方」に95%がつく　{{power:P3}}

::: ask 区間推定とは？
→ 点推定に「どれくらい外れうるか」を添えて、**推定値 ± 確率点 × 標準誤差** の形で幅をつけて推定すること。標準誤差が小さい（n が大きい）ほど幅は狭い。
:::

::: ask 「95%信頼区間」の95%とは？
→ 同じ作り方で何度も標本を取り直して区間を作ると、そのうち95%の区間が母数を含む、という**作り方の性質**。母数 μ は動かない。動くのは区間の方。できあがった1本の区間は、μ を含むか含まないかのどちらか。
:::

::: ask σ が分からないとき、割合のときは？
→ σ が分からなければ s で標準誤差を作り、確率点は t(n−1)（{{unit:U20}}）。割合は p̂ ± z×√(p̂(1−p̂)÷n)（n が大きいときの近似）。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
\bar x\pm z_{0.975}\frac{\sigma}{\sqrt n}\qquad \hat p\pm z_{0.975}\sqrt{\frac{\hat p(1-\hat p)}{n}}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| x̄・p̂ | 標本の平均50・標本の比率 80÷400＝0.2 |
| σ | 分かっている母標準偏差10（分からなければ s と t） |
| n | 調べた人数 100・400 |
| z₀.₉₇₅ | 95%なので1.96（90%なら1.645、99%なら2.576） |

**式を言葉で読む**：形はいつも「推定値 ± 確率点 × SE」。「推定値」に「誤差幅＝確率点×標準誤差」を足し引きする。誤差幅は、信頼係数を上げると確率点が大きくなって広がり、n を増やすと標準誤差が √n に反比例して狭まる。

| 変えると | 幅は |
| --- | --- |
| n を4倍 | 約半分 |
| 95%→99% | 広がる（1.96→2.576） |
| σ が大きい | 広がる |

```txt
平均（σ が分かる）：x̄ ± z × σ/√n
平均（σ が分からない）：x̄ ± t(n−1) × s/√n
割合：p̂ ± z × √(p̂(1−p̂)/n)
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　① 客単価の母標準偏差は10百円と分かっている。100人を調べた平均が50百円のとき、母平均の95%信頼区間は？ ② 400人中80人が購入したとき、購入率の95%信頼区間は？

1. ① SE＝10÷√100＝1 → 誤差幅 1.96×1＝1.96
2. 50±1.96 → **48.04〜51.96**
3. ② p̂＝0.2、SE＝√(0.2×0.8÷400)＝0.02 → 誤差幅 1.96×0.02＝0.0392
4. 0.2±0.0392 → **0.1608〜0.2392**（丸めて 0.161〜0.239、約16%〜24%）

{{lab:LAB-ci@s1-mean}}

::: warn
「μ が95%の確率でこの区間に入る」ではない（μ は動かない）。「個々の客の95%がこの範囲」でもない。区間は母平均についての幅。
:::

::: key
「客単価の母平均は48〜52百円程度と推定される（95%信頼区間）」と読む。誤差幅を半分（約1百円）にしたいなら、調査人数は4倍の400人が要る。購入率は16%〜24%ほどの幅があり、「20%ちょうど」とは言えない。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-ci@s1-cover}}

1. **予想**：ラボの課題カードで、同じ作り方で95%信頼区間を1000回作るとき、μ を含む区間の割合を選ぶ。
2. **操作**：結果を見たら、信頼係数を 90% → 99% に変える。次に「s を使って z（誤り）」にして、n を 5 → 25 → 100 と変える。
3. **観察**：区間の長さと、μ を外す本数はどう変わるか。
4. **説明**：「信頼係数を上げると区間は□、μ を外す割合は□。なぜなら□」を1文で書く。
5. **ラボなしで**：σ＝10、n＝25 のとき、95%と99%の誤差幅を出す。

::: toggle 答え（書いてから開く）
- **観察**：90%では区間が短く、外す本数が増える（約10%）。99%では区間が長く、外すのは約1%。「s を使って z」にすると、n＝5 では含む割合が9割を下回るほどに落ちる。n＝100 では s が σ に近く、ほぼ95%に戻る。
- **説明の例**：「信頼係数を上げると区間は長くなり、μ を外す割合は減る。確率点が1.96から2.576へ大きくなり、誤差幅が広がるから」
- **ラボなしで**：SE＝10÷√25＝2。95%は 1.96×2＝**3.92**、99%は 2.576×2＝**5.152**。
:::
