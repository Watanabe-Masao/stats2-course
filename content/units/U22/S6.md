### 探究｜2つの調べ方で、満足率の区間がずれた

同じ月に、同じ店の満足率を2つの方法で調べた。レジ横のタブレットで答えた400人のうち320人が「満足」（0.80）。会員から無作為に選んで郵送で頼み、返ってきた100人のうち62人が「満足」（0.62）。本部は「この店の満足率」を区間つきで1つ報告してほしいと言っている。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 何の満足率を、だれについて知りたいのかを書く（来店客全体か、会員か）
2. 仮定を書く：それぞれの回答者が、知りたい人たちから無作為に選ばれたとみてよいか
3. 下のラボの「割合の区間」で、2つの調べ方の95%信頼区間を出す
4. 統計で言えることと、2つがずれる理由についての解釈（2つ以上）を分ける
5. 報告を1つにまとめる前に、次に確かめる記録を書く

{{lab:LAB-ci@s6-free}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（回答した人について）**：タブレットで押した400人の満足率は0.80、郵送で返した100人は0.62。

**郵送：返した人が、頼んだ会員から無作為に選ばれたとみたら言えること**：会員の満足率の95%信頼区間は約 0.525〜0.715。ただし、返すかどうかが満足かどうかと関係していれば、この区間は「返した人たち」についての幅にしかならない。

**タブレット：押した客が、その月の来店客から無作為に選ばれたとみたら言えること**：来店客の満足率の95%信頼区間は約 0.761〜0.839。ただし、押す客を無作為に選んだ仕組みはないので、この見方には根拠がない。

**2つが同じ満足率を推定しているとみたら言えること**：差0.18の95%信頼区間は 0.18±1.96×√(0.8×0.2÷400＋0.62×0.38÷100)、約 0.077〜0.283 で、0を含まない。同じ満足率を2つの方法で推定しただけ、とみるのは無理がある。どちらの区間の幅も、選ばれ方の偶然の揺れだけを表し、だれが答えたかの違いは入らない。

**この数だけでは言えないこと**：どちらが「この店の満足率」に近いのか。

**解釈の例**：
- 2つは別の人たちを調べている。郵送の相手は会員で、会員には、もう店に来なくなった人も入っている。来なくなった理由に不満があれば、会員の満足率は低く出る。タブレットは、その月に来た客だけ。だから郵送の方が低い。この2つの数の生まれ方として、一番素直な読み方
- 答える人の選ばれ方が違う。タブレットは、レジで気分よく会計を終えた客ほど押しやすく、不満の客は急いで帰るので押さない。だから満足の割合が高く出る。郵送は、言いたいことのある人ほど返す。だから不満の割合が高く出る
- 尋ねる場面が違う。店員の前のタブレットでは「満足」を押しやすく、家で答える郵送では率直に書きやすい。同じ人でも答えが変わる

どの読み方が当たるかは、この2つの数だけからは決められない。

**統計の外で決めること・確かめること**：報告は「調べ方で 0.62 と 0.80 にずれた。どちらの区間も、だれが答えたかの偏りを含まない」と、2つを並べて出す。次に確かめるなら、郵送で頼んだ会員のうち最近来店した人の割合、頼んだ人数と返ってきた割合、タブレットを押した客の割合、同じ客に両方で聞いたときの答えの違い。
:::

### 課題A｜満足度調査の人数と集め方を決める

来年の店頭アンケートについて、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 知りたいもの | だれの満足率（割合）か、平均点か |
| 許せる誤差幅 | ±何ポイントなら判断に使えるか |
| 必要な人数 | z²p(1−p)÷d²（p が分からなければ0.5）を切り上げ |
| 集め方 | 無作為に選ぶ方法、回答率を上げる工夫、答えない人の偏りの見込み |

::: toggle 1つの考え方の例（自分で決めてから開く）
**選び肢**：①店頭で、時間帯を決めて来店客を無作為に選んで聞く（300人）。②レシートの QR から答えてもらう（1000人集まる見込み）。

**統計で言えること**：満足率が0.7くらいなら、誤差幅は ①で約 1.96×√(0.21÷300)≒0.052、②で約0.028。偶然の揺れだけなら②の方が狭い。

**統計の外で決めること**：②は答える人を選んでいない（答えたい人だけ）ので、その偏りは人数を増やしても減らない。①は幅が広いが、だれに聞くかを決めて選んでいる。どちらを採るかは、偶然の揺れと選ばれ方の偏りのどちらを心配するか、手間はどれだけかけられるかで決める。
:::

### 課題B｜区間つきの報告書を作る

**問い**　今月の客単価と満足率を、上司に「幅つき」で報告する。何を一緒に書けば、読む人が区間を正しく読めるか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**報告に添えること**：区間・信頼係数・n・作り方（σ が分からないので t、割合は近似の式）を一緒に書く。たとえば「客単価の平均は□〜□円（95%信頼区間、25日、t を使用）」。

**区間に入らないものとして書き添えること**：区間は選ばれ方の偶然の揺れの幅で、集め方の偏り（答えたい人だけ）や、日による違い（曜日・天気）は含まない。それらがあれば、区間より大きくずれうることを、何が心配かと一緒に書く。

**小さな例で検証**：ラボの「平均の区間」と「割合の区間」に自分の数を入れて確かめる。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | だれの、何の母数の区間かが明確か |
| 仮定 | 無作為・独立・n の大きさ・σ が分かるかを書いたか |
| 方法 | z と t、割合の式、必要な n を正しく使ったか |
| 検証 | ラボや別の計算で確かめたか |
| 切り分け | 統計で言えること（区間）と、言えないこと（だれが答えたかの偏り・どちらが母集団に近いか）を分けたか |
| 解釈 | 2つがずれる読み方を2つ以上並べ、次に確かめる記録を書いたか |
