### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}

**お手本：「母平均の95%信頼区間は48.04〜51.96」の意味**

- **条件**：σ が分かっていて、100人を無作為に選び、x̄ ± 1.96×σ÷√n で区間を作ったとき
- **対象と結論**：この作り方で何度も区間を作れば、そのうち95%が母平均 μ を含む。今回の48.04〜51.96 はその1本
- **根拠**：x̄ は μ を中心に標準誤差1でばらつき、μ から1.96SE 以内に入る確率が95%だから。x̄ がその範囲に入れば、区間は μ を含む
- **成り立たない場合**：σ を知らずに s を使ったのに1.96を使う、無作為に選んでいない、n が小さく母集団が強く歪んでいる、などのときは95%にならない

::: toggle つなげると（お手本の文）
「σ が分かっていて100人を無作為に選び、x̄ ± 1.96×σ÷√n で区間を作るとき、この作り方で何度も作れば95%の区間が母平均を含み、48.04〜51.96 はそのうちの1本である。x̄ が μ から1.96SE 以内に入る確率が95%で、そのとき区間が μ を含むからである。ただし s を使ったのに1.96を使う場合や、無作為に選んでいない場合は95%にならない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「母平均が48〜52に入る確率は95%です。つまり客の95%は客単価が48〜52百円です。もっと正確にしたいので、99%信頼区間にして区間を狭くします。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- μ は動かないので「μ が入る確率」ではない。95%は区間の作り方の性質。
- 区間は母平均についての幅で、1人1人の客単価の範囲ではない（個々の値はもっと広く散らばる）。
- 99%にすると区間は**広く**なる。狭くしたいなら n を増やす。

**言い直しの例**

「同じ作り方で区間を何度も作ると、95%が母平均を含む。今回の区間は48〜52百円で、母平均はこのあたりと推定される。これは客単価の平均についての幅で、1人1人の値の範囲ではない。99%にすると区間は広がるので、狭くしたいなら調べる人数を増やす。」
:::

::: toggle 取り違えやすい言葉
- **「信頼区間」と「個々の値の範囲」**：信頼区間は母平均（母比率）の幅。個々の値の95%が入る範囲は x̄±1.96s でずっと広い
- **「95%の確率で μ が入る」と「95%の区間が μ を含む」**：μ は動かない。確率がつくのは作り方
- **「信頼係数を上げる」と「区間を狭くする」**：信頼係数を上げると区間は広がる。狭くするのは n
- **「標準偏差」と「標準誤差」**：区間の幅は標準誤差（σ÷√n）で決まる
- **「z」と「t」**：σ を知らず s を使うなら t(n−1) の点
:::

**自己チェック（説明を書いたら）**

- [ ] 95%を「作り方の性質」として書いた
- [ ] 母平均の区間で、個々の値の範囲ではないと書いた
- [ ] σ が分かるか（z か t か）を確かめた
- [ ] 無作為・独立の前提に触れた

### 区間の式の早見

| 区間 | 式 |
| --- | --- |
| 平均（σ が分かる） | x̄ ± z × σ÷√n |
| 平均（σ が分からない） | x̄ ± t(n−1) × s÷√n |
| 割合 | p̂ ± z × √(p̂(1−p̂)÷n) |
| 必要な n（平均） | (zσ÷d)² を切り上げ |
| 必要な n（割合） | z²p(1−p)÷d²（p 不明なら0.5） |
