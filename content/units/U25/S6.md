### 探究｜30日ずつ比べた「研修の効果」は、何を何個比べたのか

接客研修を A 店で行い、B 店では行わなかった。研修のあとの30日ずつの客単価は、A 店が平均1250円・s＝120円、B 店が平均1150円・s＝120円。担当者はウェルチの t 検定で t≒3.23・p≒0.002 を出し、「研修で客単価が100円上がった」と報告した。聞き取ると、次のことが分かった。
- 研修をする店は、店長が手を挙げた A 店に決めた
- 研修の前の30日も、A 店は平均1220円、B 店は平均1160円だった（s はどちらも120円）
- 研修をしていないほかの10店の客単価の平均は、店どうしで標準偏差50円くらいばらついている

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. この t 検定が「1個」と数えたものは何か（日か、店か）。研修を受けたのは何個か
2. 仮定を書く：30日は独立か、研修のほかに2店で違うもの（場所・客層・店長）は何か
3. 研修の前の同じ2店の差を、同じ形の t で比べる
4. 研修のない店どうしでも、ふだんどれくらいの差が出るかと比べる
5. 統計で言えることと、差が出た理由についての解釈（2つ以上）を分ける
6. 研修を広げるかを決める前に、次に確かめる比べ方を書く

{{lab:LAB-ttest@s6-free}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（この2店の、この60日について）**：研修のあとの30日では、A 店の日の客単価の平均は B 店より100円高く、SE≒31.0円、t≒3.23、p≒0.002。この2店のこの期間について、「平均が同じ」とは言いにくい。

**この t が比べたもの**：1個と数えたのは「日」。けれども研修を受けたのは A 店の1店だけで、30日は同じ店の中の日。t が小さくした揺れは「同じ店の中の日ごとの揺れ」で、「研修をした店としない店の違い」の揺れではない。研修の効果を比べるなら、1個は「店」で、ここでは1店と1店しかない。

**研修の前と比べると**：研修の前の30日でも、A 店は B 店より60円高かった（t≒1.94、p≒0.058）。研修のあとの100円のうち、60円くらいは研修の前からあった2店の違いかもしれない。

**店どうしのふだんの差と比べると**：研修のない店の平均が標準偏差50円でばらつくなら、2店を選んだときの平均の差は、標準偏差 50×√2≒70.7円くらいで揺れる。100円はその約1.41倍で、研修がなくても店どうしでときどき出る大きさ。

**この数だけでは言えないこと**：研修が客単価を上げたかどうか。A 店は店長が手を挙げた店で、もともと伸びている店・客層の違う店かもしれない。

**解釈の例**：
- 研修に効果があり、研修の前からの差60円に、研修の分の40円くらいが上乗せされた
- 研修に効果はほとんどなく、手を挙げた店長の店がもともと伸びていた（研修の前の差と、期間の中の伸び）
- 研修のあとに A 店の近くで客層の変わる出来事（近くの店の開店・閉店）があった

どの読み方が当たるかは、この2店の数だけからは決められない。

**統計の外で決めること・確かめること**：この結果だけで全店に研修を広げる判断はしない。次は、研修をする店をくじで決め（例：10店を5店と5店に分ける。{{unit:U32}}）、店ごとの研修の前後の差を1個と数えて、研修をした5店としない5店の t 検定で比べる。広げるかは、その結果と研修の費用で決める。
:::

### 課題B｜「対応あり」と「別々の2群」の違いを示す

**問い**　上司から「前後の店を2群にして t 検定したら有意差なしだった。施策は効いていない」と報告が来た。どう返すか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：同じ店の前後なら対応あり。1店ごとの差を取り直して、差の t 検定をする。店ごとの売上の違いが大きいと、2群として計算した SE は大きくなり、差を見逃しやすい。結果は「差の平均◯、95%信頼区間◯〜◯、p＝◯」で返す。

**小さな例で検証**：ラボの「対応あり」で、同じ8店の差の平均3・差の標準偏差2.4（t≒3.54）と、「2群」で前後を別々の8店（平均53・50、s＝10）として入れた場合（t＝0.6）を比べる。

**成り立たない条件と、その先の判断**：前後で季節や客数も変わっていると、差は施策以外の理由かもしれない。施策をしない店も同じ期間に測ると、比べやすくなる（{{unit:U32}}）。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何と何を比べるか、何を「1個」と数えるかを決めたか |
| 仮定 | 独立・正規・ばらつきの違い・店の選び方を書いたか |
| 方法 | 1標本・差の t・ウェルチを理由つきで選んだか |
| 検証 | ラボや別の計算で確かめたか |
| 切り分け | 統計で言えること（この店・この期間の差）と、言えないこと（研修の効果・ほかの店に広げて言えるか）を分けたか |
| 解釈 | 差が出た理由の読み方を2つ以上並べ、次に確かめる比べ方を書いたか |
