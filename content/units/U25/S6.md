### 課題A｜施策の比べ方を設計する

自分の売場の施策について、調べる前に次を書く。

| 項目 | 書くこと |
| --- | --- |
| 比べ方 | 同じ店の前後（対応あり）か、施策をした店としない店（別々の2群）か |
| 仮説 | H₀・H₁、両側か片側か、α |
| 検定 | 差の t、ウェルチの t のどれか、その理由 |
| 報告 | 結論の文、差の大きさ（区間）、前提（正規・独立・店の選び方） |

### 課題B｜「対応あり」と「別々の2群」の違いを示す

**問い**　上司から「前後の店を2群にして t 検定したら有意差なしだった。施策は効いていない」と報告が来た。どう返すか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：同じ店の前後なら対応あり。1店ごとの差を取り直して、差の t 検定をする。店ごとの売上の違いが大きいと、2群として計算した SE は大きくなり、差を見逃しやすい。結果は「差の平均◯、95%信頼区間◯〜◯、p＝◯」で返す。

**小さな例で検証**：ラボの「対応あり」で、同じ8店の差の平均3・差の標準偏差2.4（t≒3.54）と、「2群」で前後を別々の8店（平均53・50、s＝10）として入れた場合（t＝0.6）を比べる。

**成り立たない条件と、その先の判断**：前後で季節や客数も変わっていると、差は施策以外の理由かもしれない。施策をしない店も同じ期間に測ると、比べやすくなる（{{unit:U32}}）。
:::

### 課題C｜検定の前にデータを見る

自分の売場の日別データで、外れ値（大型の注文、休業日など）を書き出し、外れ値を含めた場合と除いた場合で t と p 値がどう変わるかを比べる。除く理由は、結果を見る前に決めて書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何と何を比べるか、データの取り方が明確か |
| 仮定 | 正規分布・独立・対応の有無・ばらつきの違いを書いたか |
| 方法 | 1標本・差の t・ウェルチを理由つきで選んだか |
| 検証 | ラボや別の計算で確かめたか |
| 切り分け | 季節・外れ値・店の選び方など、検定に入らない違いを書いたか |
