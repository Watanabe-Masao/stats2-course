### 探究｜30日ずつ比べた「研修の効果」は、何を何個比べたのか

接客研修を A 店で行い、B 店では行わなかった。研修のあとの30日ずつの客単価は、A 店が平均1250円・s＝120円、B 店が平均1150円・s＝120円。

担当者はウェルチの t 検定で t≒3.23・p≒0.002 を出し、「研修で客単価が100円上がった」と報告した。聞き取ると、次のことが分かった。
- 研修をする店は、店長が手を挙げた A 店に決めた
- 研修の前の30日も、A 店は平均1220円、B 店は平均1160円だった（s はどちらも120円）
- 研修をしていないほかの10店の、30日ずつの客単価の平均は、店どうしで標準偏差50円くらいばらついている

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. この t が「1個」と数えたもの（t の n に入れたもの）は何か。日か、店か。研修を受けたのは何個か
2. 仮定を書く：30日は互いに独立か（曜日や天気で似た日が続かないか）。研修のほかに、2店で違うもの（場所・客層・店長）は何か
3. 研修の前の30日でも、同じように日を1個と数えて t を出す。研修をしていないのに、t はどれくらい出るか
4. 研修のない店どうしでも、30日ずつの平均にどれくらいの差が出るかと比べる
5. 統計で言えることと、差が出た理由についての解釈（2つ以上）を分ける
6. 研修を広げるかを決める前に、次に確かめる比べ方を書く

**統計で言えること（30日の値が互いに独立で、日の客単価が正規分布に近いとみたとき）**：研修のあとの30日では、A 店の日の客単価の平均は B 店より100円高く、SE≒31.0円、t≒3.23、p≒0.002。この2店のこの期間について、日の平均が同じとは考えにくい。日どうしが似ていれば（つながりがあれば）、SE は小さく見積もられていて、p はもっと大きい。

**この t が比べたもの**：t の n に入れたのは「日」。t の分母（SE≒31円）が測ったのは、同じ店の中の日ごとの揺れだけ。研修を受けたのは A 店の1店だけで、「研修をした店としない店の違い」の揺れは、分母のどこにも入っていない。店を1個と数えると n は1と1で、s が出せず、t は作れない。

**研修の前の30日と比べると**：研修をしていない前の30日でも、日を1個と数えた t は約1.94（p≒0.058）出る。日の t には、2店がもともと違うこと（店どうしの違い）が、揺れではなく差として入る。

**店どうしのふだんの差と比べると**：研修のない店の30日平均が標準偏差50円でばらつき、A 店・B 店もその中から選んだ2店とみると、2店の平均の差は標準偏差 50×√2≒70.7円くらいで揺れる。100円はその約1.41倍で、研修がなくても店どうしでときどき出る大きさ。

**この数だけでは言えないこと**：研修が客単価を上げたかどうか。比べられるのは「A 店と B 店の違い」で、そのうちどれだけが研修かは、1店と1店からは分けられない。

**解釈の例**：
- 研修に効果があり、A 店の客単価が上がった
- 研修に効果はほとんどなく、A 店と B 店はもともと客層が違う。前の期間の差と、この期間の差は、どちらも店どうしのふだんの差の範囲
- B 店の側で何かが起き（近くに競合店ができた、など）、B 店の客単価が下がった。ただし研修の前の1160円から1150円への10円は、30日の平均の揺れ（SE≒22円）の範囲で、これだけでは言えない

どの読み方が当たるかは、この2店の数だけからは決められない。

**統計の外で決めること・確かめること**：この結果だけで全店に研修を広げる判断はしない。研修の効果を比べるなら、研修を受ける単位（店）を複数そろえ、店を1個と数える。下の課題で、次の試しの組み方を決める。
:::

### 課題｜次の試しで増やすのは、日か店か

**問い**　研修の効果を確かめ直す。予算で、研修できるのはあと5店まで。次のどれで比べるか。

| 組み方 | 中身 |
| --- | --- |
| ア | A 店と B 店のまま、60日ずつに延ばす |
| イ | 10店をくじで5店と5店に分け、5店で研修する。店ごとの「研修のあと−前」の差を1個と数えて、2群の t で比べる |
| ウ | 研修をした A 店の前と後だけを、日を1個と数えて比べる |

**判断の材料**：店どうしの30日平均のばらつきは標準偏差50円くらい。同じ店の前後の差は、店の違いが消えるので、店どうしのばらつきより小さい。研修の費用は1店ごとにかかる。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること**：ア は日を増やすだけで、店は1と1のまま。t は大きくなるが、研修と「A 店であること」は分けられない。ウ は店の違いは消えるが、前後の差には研修以外の変化（季節・近くの店の出来事）も入り、比べる相手がない。イ は研修を受ける単位（店）を5個ずつにし、くじで分けるので、研修以外の店の違いは、くじの揺れの範囲で、どちらの群にも偏りなく散る（5店ずつでは、1回ごとの偏りは残る。{{unit:U32}}）。店ごとの前後の差を使うので、店どうしの違いも引ける。

**イ の弱いところ**：5店ずつでは自由度が小さく、t の境目は外側に動く。研修の効果が店どうしのばらつきに比べて小さいと、見つけにくい。

**統計の外で決めること**：イ を選ぶなら、調べる前に、比べる指標（客単価）・期間・両側か片側か・α を書く。研修を広げるかは、その結果と、研修の費用・効果の見込みで決める。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何と何を比べるか、何を「1個」と数えるかを決めたか |
| 仮定 | 日が独立か・正規に近いか・2店で研修のほかに違うものを書いたか |
| 方法 | 数える単位を、研修を受けたもの（店）に合わせたか |
| 検証 | ラボで、研修の前の期間の t も確かめたか |
| 切り分け | 統計で言えること（この2店・この期間の差）と、言えないこと（研修の効果・ほかの店に広げて言えるか）を分けたか |
| 解釈 | 差が出た理由の読み方を2つ以上並べ、次に確かめる比べ方を書いたか |
