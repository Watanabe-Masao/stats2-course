### なぜ？｜なぜウェルチの自由度は、ばらつきが大きく日数の少ない群に引っぱられるのか

ウェルチの t の分母は √(s₁²÷n₁＋s₂²÷n₂)。店A（30日・s＝2）と店B（6日・s＝10）なら、A の分は 4÷30≒0.13、B の分は 100÷6≒16.7 で、分母のほとんどが B の分になる。

B の s は6日分から出したので、それ自体が大きく揺れる。分母がほぼ B の s で決まるので、t の裾の厚さも「6日分の s で割った t」、つまり自由度5の t 分布に近くなる。ウェルチの自由度が約5.1 になるのはこのため。A の日数を増やしても、分母の中の A の分はもともと小さいので、自由度は5に近づくだけでほとんど変わらない。

等分散を仮定すると、合わせた分散が日数の多い A の小さなばらつきに引っぱられる。分母は約1.90（ウェルチでは約4.10）と小さく、自由度も34 と大きく取るので、差を言いすぎる側にずれる。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

2群の日数が同じ n で、s も同じなら、t＝(差÷s)×√(n÷2)。t は「差が s の何倍か」と「日数」の掛け算なので、**1つの t からは、差が大きいのか、日数が多いのかが消える**。

たとえば、差÷s が0.2 で200日ずつのときと、差÷s が1 で8日ずつのときは、どちらも t＝2.0 になる。p 値は自由度が違うので少し違う（約0.046 と約0.065）が、中身はまるで違う。前者は「ふだんの揺れに比べてわずかな差を、たくさんの日数で見つけた」、後者は「揺れの大きさほどの差を、少ない日数で見た」。報告では t と p 値だけでなく、差の大きさ（区間。{{unit:U23}}）と、差がふだんの揺れの何倍かを並べる。

### 本当に？｜客単価が右に歪んでいるとき、少ない日数の群で t を使うと

t 検定は、各群が正規分布に近いことを前提にしている。客単価は、たまの大口の注文で右に長く伸びることが多い。新しい店の6日分と、前からの店の30日分を、ウェルチの t 検定（両側5%）で比べるとする。

2店の客単価が同じ右に歪んだ分布（対数正規分布）に従い、平均の差が本当に0 だとしても、計算機で何度も起こしてみると、棄却する割合は約10%で、5%の約2倍になる。しかも、棄却するのはほとんどが「新しい店の方が低い」という向きになる。

6日分には大口の日が入らないことが多い。すると新しい店の平均は低めに出て、同時に s も小さめに出る。分子が下にずれた日に分母も小さくなるので、t は下に大きく振れる。正規分布なら平均と s は独立に揺れるが、歪んだ分布では平均と s がいっしょに動く。少ない日数の群では、この影響が残る。

### 説明してみる

::: task
2つの仕入れ先から届く箱の重さを比べた。仕入れ先X は30箱で平均が基準より4.5g 重く s＝10g、仕入れ先Y は6箱で平均が基準どおり s＝2g。等分散を仮定した t 検定では差は有意でなく（t≒1.09）、ウェルチでは有意（t≒2.25、p≒0.03）だった。担当者は「方法を変えたら有意になった。ウェルチは差を出しやすい方法だ」と言った。「なぜ？」の店A・店B では、等分散の方法の方が差を言いすぎた。ここでは向きが逆になったのはなぜか。担当者の言い分のどこに無理があるかも説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（各仕入れ先の箱が互いに独立で、重さが正規分布に近いとみて）**：等分散の方法は、2群のばらつきを合わせて1つの s² にする。日数（箱数）の多い X の大きなばらつき（s＝10）が合わせた分散を決め、それを箱数の少ない Y の分にも当てるので、Y の分の揺れを大きく見積もる。SE は約4.14（ウェルチは約2.00）と大きくなり、差を見逃す側にずれる。「なぜ？」とは、多い群と少ない群のどちらのばらつきが大きいかが逆なので、ずれる向きも逆になる。ウェルチはどちらの場合も、群ごとの s をそのまま使う。

**担当者の言い分について**：ウェルチは差を出しやすい方法ではなく、ずれのない側の方法。ただし、2つの方法を試して有意になった方を選ぶと、それ自体で誤って棄却する割合が増える。どちらを使うかは、データを見る前に決める。

**解釈の例**：
- X の箱は本当に重めで、詰め方か計量の設定が違う
- X は30箱の中に重い箱がいくつか混じっていて（s が大きい）、平均がそれに引っぱられた。ほとんどの箱は基準どおり

どちらの読み方かは、X の箱の重さの並び（ヒストグラム）を見て確かめる。
:::
