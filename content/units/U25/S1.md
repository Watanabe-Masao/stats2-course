### 0｜入口の問い

::: task
新しい陳列を入れた16店の売上指数の平均は104、標準偏差 s は8。基準は100。前の単元のように z＝(104−100)÷(8÷√16)＝2 として1.96 と比べてよいか。σ は分からず、16店のデータから出した s を使っている。同じ店の前後を比べるときや、別々の2店を比べるときは、何が変わるのか。
:::

^ まだ答えなくてよい。σ が分からないときは t 分布を使い、データの取り方（基準と比べる・同じ対象の前後・別々の2群）で検定を選べるようになるのが初学のゴール。

::: toggle 3問だけ確かめる（答えも中にある）

2. 検定で p 値が0.05 以下なら？ → H₀ を棄却する（両側5%）
3. 同じ店の前後の差の区間は、何を1つのデータにして作る？ → 1店ごとの差 D

### 2｜意味をつかむ：σ の代わりに s を使うと t になる　{{power:P3}}

::: ask なぜ z ではなく t を使う？
→ σ が分からないので、データの標準偏差 s で代わりにする。s も標本ごとにぶれるので、t＝(x̄−μ₀)÷(s÷√n) は正規分布より裾の重い**自由度 n−1 の t 分布**に従う。境目は1.96 より外側になる。
:::

::: ask 同じ店の前後を比べるときは？
→ **対応あり**。1店ごとの差 D を1つのデータにして、「差の平均＝0」を1標本の t 検定で調べる（自由度 n−1）。店の大きさの違いは差を取ると消える。
:::

::: ask 別々の2群を比べるときは？
→ 平均の差 x̄₁−x̄₂ を、標準誤差 √(s₁²÷n₁＋s₂²÷n₂) で割る（**ウェルチの t 検定**）。ばらつきが同じと分かっているときだけ、2群の s² を合わせる方法（等分散）も使える。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
t=\frac{\bar x-\mu_0}{s/\sqrt n}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| x̄ | 16店の平均104 |
| μ₀ | 基準100（H₀：μ＝100） |
| s | データの標準偏差8（σ が分からない） |
| n | 16店 → 自由度15 |

**式を言葉で読む**：分子は「基準からのずれ」、分母は「平均のぶれの目安（s で見積もった標準誤差）」。形は z と同じだが、分母も標本で変わるので、比べる相手は t(n−1) の点。

| データの取り方 | 検定 | 自由度 |
| --- | --- | --- |
| 1つの集団と基準値 | 1標本の t | n−1 |
| 同じ対象の前後 | 差 D の1標本の t | n−1 |
| 別々の2群 | ウェルチの t | 近似の式 |
| 別々の2群（等分散） | 合わせた分散の t | n₁＋n₂−2 |

```txt
1標本：t＝(x̄−μ₀)/(s/√n)、自由度 n−1
対応あり：t＝D̄/(s_D/√n)、自由度 n−1
ウェルチ：t＝(x̄₁−x̄₂)/√(s₁²/n₁＋s₂²/n₂)
等分散：s²＝{(n₁−1)s₁²＋(n₂−1)s₂²}/(n₁＋n₂−2)、t＝(x̄₁−x̄₂)/√(s²(1/n₁＋1/n₂))、自由度 n₁＋n₂−2
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　新しい陳列を入れた16店の売上指数の平均は104、標準偏差 s は8。基準は100。両側5%で「基準と異なる」と言えるか。（t(15) の0.975点は2.131）

1. 仮説：H₀：μ＝100、H₁：μ≠100、α＝0.05
2. SE＝8÷√16＝**2** → t＝(104−100)÷2＝**2.0**、自由度15
3. 両側5%の境目 t₀.₉₇₅(15)＝**2.131**
4. |2.0|＜2.131 → **H₀ を棄却しない**（p≒0.064）
5. 結論：「16店では、平均が100と異なるとは言えない（有意水準5%）」

::: warn
σ が分からないのに1.96 と比べない（正規なら p≒0.046 で棄却してしまう）。同じ店の前後のデータを、別々の2群として計算しない。
:::

::: key
t＝2 でも、16店では「偶然でも起こりうるずれ」の範囲に入る。効果がないと示されたわけではないので、店数を増やして確かめる道がある。σ を s で代わりにした分、少ないデータでは慎重に判断する。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-ttest@s1-df}}

1. **予想**：ラボの課題カードで、16店（自由度15）の両側5%の境目を予想する。
2. **操作**：結果を見たら、x̄＝104・s＝8 のまま n を 16 → 5 → 30 → 100 と変える。
3. **観察**：境目と p 値は、n でどう変わるか。点線（標準正規）と実線（t）の裾を見比べる。
4. **説明**：「n が小さいと t の境目は□。なぜなら□」を1文で書く。
5. **ラボなしで**：n＝25 なら SE と t はいくつか。t(24) の0.975点2.064 と比べて判断する。

::: toggle 答え（書いてから開く）
- **観察**：境目は n＝16 で2.131、n＝5 で2.776、n＝30 で2.045、n＝100 で1.984。n が増えるほど1.96 に近づき、t 分布の裾も正規に重なる。
- **説明の例**：「n が小さいと t の境目は外へ動く。s 自体がぶれるので、たまたま s が小さく出て t が大きくなることも多く、裾が重くなるから」
- **ラボなしで**：SE＝8÷5＝1.6、t＝4÷1.6＝**2.5**＞2.064 で棄却（p≒0.020）。同じ平均と s でも、店数が多ければ差を言える。
:::
