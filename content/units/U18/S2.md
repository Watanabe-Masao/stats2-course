**お手本：36個の平均のぶれが2gになる理由**

- **条件**：1個の重さが平均50g・標準偏差12gで、36個が互いに独立なとき
- **対象と結論**：36個の平均重量は、取り直すと平均50gのまわりで標準偏差（SE）2g ほどぶれる
- **根拠**：独立なら合計の分散は 36×12²、平均は合計を36で割るので分散は 12²÷36、標準偏差は 12÷√36＝2 になるから
- **成り立たない場合**：同じ製造ロットの品ばかりで重さが似ている（独立でない）ときは、ぶれは σ÷√n より大きくなる

::: toggle つなげると（お手本の文）
「1個の重さが平均50g・標準偏差12gで、36個が独立なら、36個の平均は50gのまわりで約2gぶれる。合計の分散が36倍になり、平均にするとそれを36²で割るので、標準偏差は 12÷√36＝2g になるからである。ただし同じロットの品ばかりで独立でない場合は、ぶれはこれより大きい。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「商品を36個集めて量ったら、標準偏差が2gになりました。36個も集めると、商品の重さのばらつきは12gから2gに小さくなります。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 1個ずつの重さのばらつき（標準偏差12g）は、何個集めても変わらない。
- 小さくなるのは「36個の平均」のぶれ（標準誤差2g）。

**言い直しの例**

「1個ずつの重さの標準偏差は12gのままである。36個の平均重量は、取り直すたびに50gのまわりで約2gぶれる（標準誤差）。平均は1個より安定しているが、商品のばらつきが小さくなったわけではない。」
:::

::: toggle 取り違えやすい言葉
- **「標準偏差」と「標準誤差」**：標準偏差＝データ1個ずつのばらつき／標準誤差＝平均や比率など統計量のぶれ（σ÷√n）
- **「分散 σ²/n」と「標準誤差 σ/√n」**：n を4倍にすると、分散は1/4、標準誤差は1/2
- **「標本分散 v（n で割る）」と「不偏分散 s²（n−1 で割る）」**：母分散の推定には s² を使う。v は平均して (n−1)/n×σ² で小さめ
- **「標本の大きさ n」と「取り直す回数」**：SE の n は1回の標本に入れる個数。取り直す回数ではない
:::
