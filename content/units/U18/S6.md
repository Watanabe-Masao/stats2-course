### 課題A｜客単価の「ぶれの物差し」を作る

POS から1か月分の客ごとの購入額を取り出し、次を作る。

| 項目 | 書くこと |
| --- | --- |
| σ | 1客の購入額の標準偏差（n−1 で割る） |
| SE | 曜日ごとの平均客数での σ÷√客数 |
| 目安 | 前日比の差が SE の何倍なら「変化」とみるか |
| 確かめ | 実際の日々の客単価の標準偏差と SE が近いか |

### 課題B｜アンケートの人数を決める

**問い**　新商品の「また買う」率を ±5ポイント程度の精度で知りたい。何人に聞けばよいか。聞く人の選び方も決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：±5ポイントを ±2SE とみると SE＝0.025。p が分からないので p＝0.5 で n＝0.25÷0.025²＝400人。過去の似た商品で p＝0.2 くらいと分かっていれば 0.16÷0.025²＝256人で足りる。

**小さな例で検証**：ラボの「比率のぶれ」で p と目標の SE を動かし、必要な人数がどう変わるかを見る。

**成り立たない条件と、その先の判断**：試食した客の中から聞くと、試食しない客の意見は入らない（{{unit:U17}} の抽出枠）。同じ家族が何人も答えると独立でなくなり、ぶれは計算より大きい。
:::

### 課題C｜抜き取り検査の個数を決める

内容量の標準偏差を過去のデータから出し、「平均が表示を2g下回ったら気づきたい」とき、何袋の平均で見ればよいかを、SE と z（{{unit:U16}}）を使って決める。空振り（正常なのに調整）の確率も書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 1つの値のばらつきか、平均・比率のぶれかが明確か |
| 仮定 | 独立・σ（または p）の出どころを書いたか |
| 方法 | SE を √n で計算し、必要な n を逆算したか |
| 検証 | 実データの日々のぶれやラボで確かめたか |
| 切り分け | 独立でない場合・偏った選び方の場合を書いたか |
