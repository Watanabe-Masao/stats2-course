### 探究｜満足率が 62% から 68% に上がった。施策の効果と言えるか

売場の改装のあと、来店客アンケートの「満足」の割合が、改装前の月の 62% から改装後の月の 68% に上がった。どちらの月も、来店客から 150 人に聞いている。店長は「改装で満足が 6 ポイント上がった」と報告したい。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. それぞれの月の満足率の標準誤差を出し、6 ポイントの差が、聞き直したら変わりうる大きさと比べてどのくらいかを見る
2. 小さな例で検証する：ラボの「比率のばらつき」で p と人数を2つの月の値にし、±2SE の幅を見比べる
3. 統計で言えることと、差の理由についての解釈（2つ以上）を分けて書く
4. 報告の前に、次に確かめる記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること**：聞いた 150 人が来店客から独立に選んだ人とみなすと、満足率の標準誤差は改装前 √(0.62×0.38÷150)≒0.040、改装後 √(0.68×0.32÷150)≒0.038。2つの月が独立なら、差の標準誤差は √(0.040²＋0.038²)≒0.055（差の分散は分散の和、{{unit:U13}}）。6 ポイントの差は標準誤差の約 1.1 倍で、改装の前後で客の満足が同じでも、聞く 150 人の選び方の偶然だけで普通に起こる大きさ。差がないとも言えない。ここまでは「聞いた人が独立に選ばれた」という前提の下の話で、同じ時間帯にまとめて聞いたなら、標準誤差はこれより大きい。

**解釈の例**：
- 改装で売場が見やすくなり、満足が本当に上がった。その大きさが、150 人では偶然と見分けられないだけ
- 改装後の月は休日が多く、休日に来る客（もともと満足しやすい客層）の割合が増えた。客の混ざり方が変わっただけで、同じ客層どうしでは変わっていない

どちらに近いかは、全体の満足率1つからは決められない。

**統計の外で決めること・確かめること**：報告で 6 ポイントをどう書くか（標準誤差と、偶然でも起こる大きさであることを添えるか）。次に確かめるなら、平日・休日に分けた満足率と、聞いた時間帯の記録。
:::

### 課題A｜客単価の「ばらつきの物差し」を作る

POS から1か月分の客ごとの購入額を取り出し、次を作る。

| 項目 | 書くこと |
| --- | --- |
| σ | 1客の購入額の標準偏差（n−1 で割る） |
| SE | 曜日ごとの平均客数での σ÷√客数 |
| 目安 | 前日比の差が SE の何倍なら「変化」とみるか |
| 確かめ | 実際の日々の客単価の標準偏差と SE が近いか |

### 課題B｜アンケートの人数を決める

**問い**　新商品の「また買う」率を ±5ポイント程度の精度で知りたい。何人に聞けばよいか。聞く人の選び方も決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：±5ポイントを ±2SE とみると SE＝0.025。p が分からないので p＝0.5 で n＝0.25÷0.025²＝400人。過去の似た商品で p＝0.2 くらいと分かっていれば 0.16÷0.025²＝256人で足りる。

**小さな例で検証**：ラボの「比率のばらつき」で p と目標の SE を動かし、必要な人数がどう変わるかを見る。

**成り立たない条件と、その先の判断**：試食した客の中から聞くと、試食しない客の意見は入らない（{{unit:U17}} の抽出枠）。同じ家族が何人も答えると独立でなくなり、ばらつきは計算より大きい。
:::

### 課題C｜抜き取り検査の個数を決める

内容量の標準偏差を過去のデータから出し、「平均が表示を2g下回ったら気づきたい」とき、何袋の平均で見ればよいかを、SE と z（{{unit:U16}}）を使って決める。空振り（正常なのに調整）の確率も書く。

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 1つの値のばらつきか、平均・比率のばらつきかが明確か |
| 仮定 | 独立・σ（または p）の出どころを書いたか |
| 方法 | SE を √n で計算し、差や必要な n を出したか |
| 検証 | 実データの日々のばらつきやラボで確かめたか |
| 切り分け | 統計で言えること（偶然で起こりうる大きさか）と、言えないこと（差の理由）を分けたか |
| 解釈 | 差の理由の読み方を2つ以上並べ、次に確かめる記録を書いたか |
