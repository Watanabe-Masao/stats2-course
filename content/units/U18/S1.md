::: task
商品1個の重さは平均50g・標準偏差12g。「36個の平均を測ったら51gだった。平均50gより1gも重いので、機械がずれている」という報告が来た。1gのずれは大きいのか。何と比べれば判断できるか。
:::

^ まだ答えなくてよい。n 個の平均や比率が、取り直すたびにどれくらいぶれるか（標準誤差）を出し、1個ずつのばらつき（標準偏差）と区別できるようになるのが初学のゴール。

### 2｜意味をつかむ：2つの「ばらつき」を分ける　{{power:P3}}

::: ask 1個1個の重さはどれくらいばらつく？
→ **標準偏差 σ**（12g）。何個集めても、1個ずつのばらつきは変わらない。
:::

::: ask n 個の平均は、取り直すとどれくらいぶれる？
→ **標準誤差 SE＝σ÷√n**。36個の平均なら 12÷6＝2g。平均すると大きい値と小さい値が打ち消し合うので、ぶれは小さくなる。
:::

::: ask 平均の分布の中心はどこ？
→ **μ のまま**。E(x̄)＝μ。n を増やすと中心は動かず、幅だけが細くなる。このように、標本を取り直したときの統計量の分布を**標本分布**という（{{unit:U17}} で全部並べたもの）。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
E(\bar X)=\mu,\qquad V(\bar X)=\frac{\sigma^2}{n},\qquad SE(\bar X)=\frac{\sigma}{\sqrt n},\qquad SE(\hat p)=\sqrt{\frac{p(1-p)}{n}}
$$

| 記号 | 意味 |
| --- | --- |
| σ | 1個ずつのばらつき（標準偏差） |
| n | 平均をとる個数（独立に取る） |
| SE | 平均や比率という**統計量**の標準偏差 |
| p | 母集団の比率（購入率など） |

**式を言葉で読む**：独立なら合計の分散は nσ²（{{unit:U13}}）。平均は合計を n で割るので、分散は n² で割って σ²÷n。√をとると σ÷√n。比率 p̂ は「買った＝1・買わない＝0」の平均で、1人の分散が p(1−p) なので、p̂ の分散は p(1−p)÷n。

```txt
E(X̄)=μ、Var(X̄)=σ²/n、SE(X̄)=σ/√n
E(p̂)=p、Var(p̂)=p(1−p)/n
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　商品1個の重さは平均50g・標準偏差12g。① 9個の平均重量の SE は？　② 36個なら SE は？　③ 来店客の購入率が p＝0.2 のとき、100人で調べた購入率 p̂ の SE は？

1. ① 12÷√9＝12÷3＝**4g**
2. ② 12÷√36＝12÷6＝**2g**（n を4倍にすると SE は1/2）
3. ③ √(0.2×0.8÷100)＝√0.0016＝**0.04**（4ポイント）

{{lab:LAB-xbar@s1-se}}

| n | σ＝12 のときの SE |
| --- | --- |
| 9 | 4 |
| 36 | 2 |
| 144 | 1 |

::: key
SD（標準偏差）＝データ1個1個のばらつきで、12g のまま。SE（標準誤差）＝平均のぶれで、n で小さくなる。「36個集めたら商品のばらつきが2gになった」ではない。精度を2倍にしたければ n は4倍要る（√n で効く）。比率の SE 0.04 は、購入率20%の調査が ±8ポイント程度ぶれうる目安。
:::

^ 入口の問いなら、36個の平均の SE は2g。1gのずれは SE の半分で、偶然でも普通に起こる。「機械がずれた」とは言えない。

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-xbar@s1-unb}}

1. **予想**：ラボの課題カードで、n で割る分散 v を9通り平均した値を入れる。
2. **操作**：結果を見たら、n を3・4に増やす。次に母集団の値を「2,4,9」などに変える。
3. **観察**：v の平均と s² の平均は、σ² と比べてどうなるか。
4. **説明**：「n で割ると□になった。なぜなら□」を1文で書く。
5. **ラボなしで**：1・3・5 から戻しながら2個取る9通りのうち、(1,5) の v と s² を計算する。

::: toggle 答え（書いてから開く）
- **観察**：v の平均はいつも (n−1)/n×σ² で σ² より小さい（n＝2 で半分、n＝4 で3/4）。s² の平均はいつも σ² に一致する。
- **説明の例**：「n で割ると σ² の半分になった。標本の中の偏差は x̄ から測っていて、μ から測るより小さく出るから。n−1 で割るとちょうど補える」
- **ラボなしで**：x̄＝3、偏差の2乗和は 4＋4＝8。v＝8÷2＝**4**、s²＝8÷1＝**8**。
:::

::: summary
1. 標本平均の期待値は μ、分散は σ²÷n、標準誤差は σ÷√n。n を4倍で SE は半分。
2. 標準偏差（1個ずつのばらつき）と標準誤差（平均のぶれ）を区別する。比率の SE は √(p(1−p)÷n)。

:::
