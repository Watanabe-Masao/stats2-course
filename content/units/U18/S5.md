「不偏分散」で n を2→3→4と変え、v の平均が (n−1)/n×σ² になることを確かめる（発展1）。「平均のぶれ」で「200回取り直す」を押し、取り直した x̄ の標準偏差が SE に近いことを見る（発展2）。

### 発展1｜なぜ n−1 で割るのか

偏差の2乗和 Σ(Xᵢ−x̄)² は、x̄ が標本そのものの真ん中なので、μ から測った Σ(Xᵢ−μ)² より必ず小さいか等しい。期待値を計算すると E[Σ(Xᵢ−x̄)²]＝(n−1)σ² になる（差の分 n×V(x̄)＝σ² だけ減る）。だから n−1 で割ると期待値がちょうど σ²。「自由度 n−1」は、x̄ を使った分だけ自由に動ける偏差が1つ減ることを表す（{{unit:U20}}）。

### 発展2｜シミュレーションで確かめる

理論の SE＝σ÷√n は、「無限に取り直したときの x̄ の標準偏差」。ラボの「200回取り直す」は実際に200回取り直した x̄ の標準偏差で、理論の値の近くに来るが、ぴったりではない（200回分のぶれがある）。取り直す回数を増やすほど理論の値に近づく（大数の法則、{{unit:U19}}）。

### 発展3｜正規母集団での特別な性質

母集団が正規分布なら、x̄ は n によらずちょうど正規分布 N(μ, σ²/n) に従い、(n−1)s²/σ² はカイ二乗分布 χ²(n−1) に従う（{{unit:U20}}）。さらに x̄ と s² は独立になる。この「独立」は正規分布に特有の性質で、一般の母集団では成り立たない。

### 発展4｜比率は平均の一種

「買った＝1・買わない＝0」のベルヌーイ変数 X（{{unit:U14}}）の平均は p、分散は p(1−p)。n 人の平均 p̂ はふつうの標本平均なので、E(p̂)＝p、V(p̂)＝p(1−p)÷n が平均の式からそのまま出る。二項分布 B(n, p) の X を n で割ったものが p̂ で、分散 np(1−p) を n² で割っても同じ。
