### {{icon:lab}} 使うラボ

「不偏分散」の標本の表で、x̄ が母平均 μ から離れた標本ほど、n で割った v が小さく出ているかを見る（1・3・5 なら μ＝3）。「平均のばらつき」で n を変えて「200回取り直す」を押し、取り直した x̄ の標準偏差と SE のずれを見る（ラボは200回で、種は決まっている）。予測して当てる場ではない。動かして、なぜそうなるかを自分の言葉で説明する。

### なぜ？｜なぜ n−1 で割るのか

偏差の2乗和 Σ(Xᵢ−x̄)² は、x̄ が標本そのものの真ん中なので、μ から測った Σ(Xᵢ−μ)² より必ず小さいか等しい。差はちょうど n(x̄−μ)² で、x̄ が μ から離れた標本ほど大きく減る。期待値を計算すると E[Σ(Xᵢ−x̄)²]＝(n−1)σ² になる（μ から測った和の期待値 nσ² から、n×V(x̄)＝σ² だけ減る）。だから n−1 で割ると期待値がちょうど σ²。「自由度 n−1」は、x̄ を使った分だけ自由に動ける偏差が1つ減ることを表す（{{unit:U20}}）。

^ この計算を確かめる問題は、2級の範囲なので {{stage:S3}} に置いた。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「平均 50g・標準誤差 2g」という書き方からは、**1個1個のばらつき**（標準偏差 12g）が消えている。標準誤差は平均のばらつきなので、何個集めて平均したか（n）で小さくなる。報告やグラフのひげが標準誤差だと、1個ずつの重さはずっと広く散らばっているのに、商品がそろっているように見える。

逆に「標準偏差 12g」だけでは、平均をどれだけ当てにできるかが消えている。どちらの数を見せるかは、知りたいのが「1個の重さ」か「平均の重さ」かで決める。

### 本当に？｜値どうしが似ていると、σ÷√n は小さすぎる

σ÷√n は、n 個の値が独立という前提で作る。けれども同じ日の客は、天気やセールで購入額がそろって動く。20日間、1日20人ずつ（合わせて400人）の購入額を集め、1人の標準偏差が 1500 円なら、独立とみた客単価の標準誤差は 1500÷√400＝75 円。

同じ日の2人の購入額が少しだけ似ている（相関 0.05：同じ日なら、そろって高め・低めに出やすい）とする。日どうしは独立とする。1日20人の合計の分散は、1人ずつの分 20σ² に、同じ日の 20×19 組の似ている分 20×19×0.05σ² が加わり、20σ²×(1＋19×0.05) になる。だから平均の分散は 1＋(20−1)×0.05＝1.95 倍（標準誤差は √1.95≒1.40 倍で約 105 円）。1つ1つの相関は小さくても、同じまとまりの中の組の数が多いので効く。だから「400人」という数だけでは平均の当てにできる度合いは決まらず、どう集めたか（まとまりの大きさと、その中の似かた）で変わる。

### ほかでは？｜つながり

- **シミュレーション**：ラボの「200回取り直す」は、実際に200回取り直した x̄ の標準偏差。200回分のばらつきがあるので、SE とぴったりは一致しない（ずれはおよそ SE の1割前後）。取り直す回数を増やすほど、ずれは小さくなる（大数の法則、{{unit:U19}}。ラボの回数は200回で固定）
- **正規母集団**：母集団が正規分布なら、x̄ は n によらずちょうど正規分布 N(μ, σ²/n) に従い、(n−1)s²/σ² はカイ二乗分布 χ²(n−1) に従う（{{unit:U20}}）。さらに x̄ と s² は独立になる。この独立は正規分布に特有の性質で、一般の母集団では成り立たない
- **標本調査の設計**：上のまとまりの効き方は、集落抽出（{{unit:U31}}）で必要な人数を見積もるときに使う

### 説明してみる

::: task
ある店は、客単価（1日の平均購入額）の標準誤差を 1500÷√(1日の客数 900)＝50 円と計算し、前日より 100 円下がった日に「標準誤差の2倍。偶然では起きにくい」と警告を出している。この警告の出し方を、独立の前提と比べる相手の言葉で検討する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること**：前日との差を見るなら、比べる2日の客単価がどちらもばらつく。2日が独立なら、差の標準誤差は √(50²＋50²)≒71 円で、100 円は約 1.4 倍。客が独立という前提の下でも、偶然で普通に起こる大きさ。さらに同じ日の客の購入額が天気やセールでそろって動くなら、1日の客単価の標準誤差は 50 円より大きく、100 円はもっと起こりやすい。

**解釈の例**：
- 客の買い方が本当に変わった（値上げで買い控えた・まとめ買いが減った）
- その日に共通の事情（雨・前日がセール日）で、客がそろって少なめに買った。客の買い方そのものは変わっていない

**統計の外で決めること**：警告の基準をどこに置くか。見逃し（本当の変化に気づかない）と空振り（偶然の変化で警告する）のどちらを避けたいかで決まる。
:::
