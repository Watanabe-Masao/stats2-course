### {{icon:lab}} 使うラボ

「不偏分散」で n を2→3→4と変え、n で割った分散 v の平均と σ² の比を自分で計算して、n とどう関係するかを見る。「平均のばらつき」で「200回取り直す」を押し、取り直した x̄ の標準偏差と SE を比べる。取り直しを何度押しても、ぴったりは一致しない理由も考える。予測して当てる場ではない。動かして、なぜそうなるかを自分の言葉で説明する。

### なぜ？｜なぜ n−1 で割るのか

偏差の2乗和 Σ(Xᵢ−x̄)² は、x̄ が標本そのものの真ん中なので、μ から測った Σ(Xᵢ−μ)² より必ず小さいか等しい。期待値を計算すると E[Σ(Xᵢ−x̄)²]＝(n−1)σ² になる（μ から測った和の期待値 nσ² から、n×V(x̄)＝σ² だけ減る）。だから n−1 で割ると期待値がちょうど σ²。「自由度 n−1」は、x̄ を使った分だけ自由に動ける偏差が1つ減ることを表す（{{unit:U20}}）。

^ この計算を確かめる問題は、2級の範囲なので {{stage:S3}} に置いた。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「平均 50g・標準誤差 2g」という書き方からは、**1個1個のばらつき**（標準偏差 12g）が消えている。標準誤差は平均のばらつきなので、何個集めて平均したか（n）で小さくなる。報告やグラフのひげが標準誤差だと、1個ずつの重さはずっと広く散らばっているのに、商品がそろっているように見える。

逆に「標準偏差 12g」だけでは、平均をどれだけ当てにできるかが消えている。どちらの数を見せるかは、知りたいのが「1個の重さ」か「平均の重さ」かで決める。

### 本当に？｜値どうしが似ていると、σ÷√n は小さすぎる

σ÷√n は、n 個の値が独立という前提で作る。けれども同じ日の客は、天気やセールで購入額がそろって動く。20日間、1日20人ずつ（合わせて400人）の購入額を集め、1人の標準偏差が 1500 円なら、独立とみた客単価の標準誤差は 1500÷√400＝75 円。

同じ日の2人の購入額の相関が 0.05 と小さくても、1日20人のまとまりで集めると、平均の分散は 1＋(20−1)×0.05＝1.95 倍になる（標準誤差は √1.95≒1.40 倍で約 105 円）。1つ1つの相関は小さくても、同じまとまりの中の組の数が多いので効く。だから「400人」という数だけでは平均の当てにできる度合いは決まらず、どう集めたか（まとまりの大きさと、その中の似かた）で変わる。

### ほかでは？｜つながり

- **シミュレーション**：ラボの「200回取り直す」は、実際に200回取り直した x̄ の標準偏差。理論の SE の近くに来るが、200回分のばらつきがあるのでぴったりではない。回数を増やすほど近づく（大数の法則、{{unit:U19}}）
- **正規母集団**：母集団が正規分布なら、x̄ は n によらずちょうど正規分布 N(μ, σ²/n) に従い、(n−1)s²/σ² はカイ二乗分布 χ²(n−1) に従う（{{unit:U20}}）。さらに x̄ と s² は独立になる。この独立は正規分布に特有の性質で、一般の母集団では成り立たない
- **比率は平均の一種**：「買った＝1・買わない＝0」の平均が p̂。1人の分散が p(1−p) なので、V(p̂)＝p(1−p)÷n が平均の式からそのまま出る。二項分布 B(n, p) の X を n で割ったものが p̂（{{unit:U14}}）
- **標本調査の設計**：上のまとまりの効き方は、集落抽出（{{unit:U31}}）で必要な人数を見積もるときに使う

### 説明してみる

::: task
新しい充填機の検査で、1000袋の内容量の平均が 500.0g、その標準誤差が 0.1g だった。報告書に「この機械なら、1袋の内容量は 500g から ±0.2g ほどに収まる」と書いてある。この説明を、標準偏差と標準誤差の言葉で検討する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること**：0.1g は 1000袋の平均のばらつき（標準誤差）で、1袋のばらつきではない。1袋ずつが独立なら、1袋の標準偏差は 0.1×√1000≒3.16g で、1袋の内容量はおよそ ±6.3g（±2標準偏差）に散らばる。±0.2g は、1袋ではなく「1000袋の平均」についての目安。

**解釈の例**：
- 書いた人が「ロット全体で見た量の管理」（平均がずれていないか）を伝えたかったなら、数の読み方は合っていて、「1袋の」という言葉だけが誤り
- 「1袋ずつのそろい方」を伝えたかったなら、使う数を取り違えていて、そろい方は報告より約30倍粗い

**統計の外で決めること**：報告の目的（平均の管理か、1袋の規格か）と、1袋の規格の下限（表示量を下回る袋をどこまで許すか）。
:::
