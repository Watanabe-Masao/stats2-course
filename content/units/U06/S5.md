### なぜ？｜なぜ平均は外れ値に寄り、中央値は寄らないのか

初学では、最大の値を大きくすると平均だけが動くのを見た。では、平均と中央値は、それぞれ何を基準に「真ん中」を決めているのか。

データ全体を1つの数 c で代表させるとき、ずれの測り方を2通り考える。ずれの2乗の和 Σ(x−c)² と、ずれの大きさの和 Σ|x−c|。1, 2, 2, 3, 22 で、c を平均（6）にしたときと中央値（2）にしたときの、2つの和を計算して比べる。

::: toggle 動かしてから開く
ずれの2乗の和は、c＝6 で 25＋16＋16＋9＋256＝322、c＝2 で 1＋0＋0＋1＋400＝402。ずれの大きさの和は、c＝2 で 1＋0＋0＋1＋20＝22、c＝6 で 5＋4＋4＋3＋16＝32。

ずれの2乗の和をいちばん小さくする c が平均、ずれの大きさの和をいちばん小さくする c が中央値になる。2乗は大きなずれをとくに重く数えるので（22 のずれ 20 は 400 になる）、2乗の和を小さくしようとする平均は、22 の側へ寄っていく。ずれの大きさの和では 22 も「20」としか数えないので、中央値は、左右に同じ個数が残る位置から動かない。

平均か中央値かは、「大きなずれをどれだけ重く見るか」の選び方でもある。ずれの2乗の和は、分散（{{unit:U07}}）や、回帰の最小二乗法（{{unit:U29}}）の考え方につながる。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

両端の値を一定の割合ずつ除いてから平均する**トリム平均**は、外れ値に強い。10人の購入額の 10%トリム平均を読み、除かれる2人がだれで、その2人の購入額が10人の合計のどれだけを占めるかを計算する。

::: toggle 動かしてから開く
10%トリム平均は、いちばん少ない1千円の客と、いちばん多い17千円の客を除いた8人の平均で、22÷8＝2.75千円。平均（4千円）より中央値（2.5千円）に近い。

除かれた17千円の客は、10人の合計40千円の 17÷40＝42.5% を1人で買っている。トリム平均という1つの数からは、**売上の4割を作る1人の客**が消える。「ふだんの客」を言うには向くが、売上や仕入れを考えるときは、端の客こそ大事なことがある。外れ値に強い数を選ぶときは、何を捨てたかも書き添える。
:::

### 本当に？｜中央値は、外れ値に強いから安定しているのか

中央値は外れ値に引っ張られない、と初学で見た。では、中央値はいつも、平均より動きにくいのか。2つの版で、9日の売上（平日5日は20万円台、イベントの4日は60万円台）と、平日の1日がイベントの日に入れ替わった9日の、平均と中央値を比べる。

::: toggle 動かしてから開く
もとの9日は、平均 356÷9≒39.6万円、中央値は5番目の24万円。平日の23万円の1日がイベントの日（60万円）に入れ替わると、平均は 393÷9≒43.7万円で約4万円上がるだけなのに、中央値は5番目が60万円になり、24万円から60万円へ跳ぶ。

値が平日とイベントの2つのかたまりに分かれていて、真ん中の位置がかたまりの境目にあると、1日の入れ替わりで、真ん中がもう一方のかたまりへ移る。中央値が外れ値に強いのは、真ん中の位置の周りに値が詰まっているとき。かたまりが2つあるデータでは、中央値は小さな入れ替わりで大きく跳び、平均の方が動きが小さい。先にヒストグラムや点の並びで、かたまりがいくつあるかを見る。
:::

### ほかでは？｜つながり

- **ずれの2乗**：分散と標準偏差（{{unit:U07}}）、最小二乗法（{{unit:U29}}）
- **重みを確率にした平均**：期待値（{{unit:U13}}）
- **倍率の平均**：幾何平均（{{unit:U05T}}）。同じ距離を進む速さの平均は調和平均（算術平均 ≧ 幾何平均 ≧ 調和平均。2と8なら 5 ≧ 4 ≧ 3.2）
- **割合の位置の値**：分位点の決め方の違い（この単元の応用、{{unit:U05}} の四分位数）
