### 探究｜「○分以内にお届け」に、どの数を書くか

ネットスーパーを始めた店で、先週の配達20件の、注文から届くまでの時間（分）を並べると、25, 28, 30, 30, 32, 33, 35, 35, 36, 38, 40, 40, 42, 45, 48, 50, 55, 60, 75, 95 だった。チラシに「ご注文から○分以内にお届け」と書きたい。担当者は「平均を書けばよい」と言った。聞き取ると、次のことが分かった。
- 20件のうち、川向こうの地区への配達が4件あり、それが55・60・75・95分の4件だった
- 配達の車は1台で、注文が重なった時間は、まとめて回った
- 先週は雨の日が1日あった

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. ラボで平均と中央値を読み、90% の位置の値を自分で計算する
2. それぞれの数を「○分以内」に書いたとき、20件のうち何件が約束を破るかを数える
3. 長くかかった配達の理由の読み方（2つ以上）を書く
4. 統計で言えることと言えないことを分ける
5. チラシに何を書くかを決める（下の課題）

{{lab:LAB-center@s6-deliv}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（先週の20件が、記録どおりの時間だったとみて）**：平均は 872÷20＝43.6分、中央値は 10番目と11番目の (38＋40)÷2＝39分。90% の位置は 1＋0.9×19＝18.1番目で、60＋0.1×(75−60)＝61.5分。「43.6分以内」と書くと20件中7件、「39分以内」なら10件、「61.5分以内」なら2件が約束を破る。どの数も、先週の20件の中で何割が収まったかを表している。

**この20件だけでは言えないこと**：来週も同じ割合で収まるか。20件は少なく、90% の位置の値は、いちばん長い数件（75分・95分）の間で決まっている。川向こうの4件は全部55分以上で、地区の違いが長い側の裾を作っているかもしれないが、注文の重なりや雨の日とも重なっていて、20件からは分けられない。

**解釈の例**：
- 川向こうの地区は、橋を渡るので道のりが長い。地区ごとに約束を分けるべき
- 長くかかった4件は、注文が重なってまとめて回ったときで、地区はたまたま重なっただけ
- 95分の1件は雨の日の配達で、ふだんは起こらない

どれが当たるかは、20件の時間だけからは決められない。

**統計の外で決めること**：約束を何割の客に守るか（9割か、ほぼ全員か）は、店が決めること。守れなかったときに客がどう感じるか、チラシの数字がどれだけ客を呼ぶかで決める。
:::

### 課題｜チラシに何を書くか

**問い**　来月のチラシに書く「お届けの目安」を決める。

- **ア**：「平均44分でお届け」と書く
- **イ**：「60分以内にお届け（9割の目安）」と書く
- **ウ**：地区で分け、「川こちらは45分以内、川向こうは90分以内」と書く

**判断の材料**：約束の時間を過ぎたら、次回使える300円の券を渡す決まりにしたい。先週の注文は20件で、来月は1日10件ほどに増える見込み。川向こうの地区の注文は、これまで全体の2割ほど。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（先週の20件の時間の並びが、来月も変わらないとみて）**：ア の平均は、20件中7件（35%）が上回っていて、「平均で届く」と読んだ客の3人に1人ほどは待たされる。イ の60分は、20件中2件（10%）が上回った。ウ は、川こちらの16件では最長50分で、45分を超えたのは2件（48分・50分）。川向こうの4件では、90分を超えたのは95分の1件。ただし地区ごとの件数は少なく、来月1日10件に増えて注文の重なりが多くなれば、どの数も長くなりうる。

**統計の外で決めること**：券を渡す件数を抑えたいなら イ。分かりやすさと客を呼ぶ力を重く見るなら ア だが、「平均」と書くと約束と受け取られやすい。地区の違いが本当にあると見るなら ウ。どれを選んでも、来月の配達時間を記録し続け、約束を破った割合を毎月確かめる。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 「○分以内」が、何割の客に守る約束かを問いにしたか |
| 仮定 | 先週の20件の並びが来月も続く、という仮定を書いたか |
| 方法 | 平均・中央値・90% の位置の値を出し、上回る件数を数えたか |
| 検証 | ラボで平均と中央値を読み、90% の位置を自分で計算したか |
| 切り分け | 言えること（先週の20件で収まった割合）と、言えないこと（来週も同じか・長い理由）を分けたか |
| 解釈 | 長くかかった理由の読み方を2つ以上並べ、約束の決め方を書いたか |
