### 課題A｜自分の店の「代表値カード」を作る

自分の職場の1日分のレシート（50件以上）の購入額を集め、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 分布の形 | ヒストグラムを描き、裾の向きと外れ値 |
| 3つの代表値 | 平均・中央値・最頻値の価格帯 |
| 使い分け | 報告・予算・売れ筋に、どれを使うか |
| 言えないこと | この数字だけでは分からないこと |

### 課題B｜全店の平均客単価の出し方を決める

**問い**　店ごとの客数と売上から、全店の平均客単価を毎月出したい。計算の手順と、よくある間違いを防ぐ方法を決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**決め方**：全店の売上合計÷全店の客数で出す（客数で重み付けした平均と同じ）。各店の客単価を足して店の数で割る「単純平均」は使わない。

**小さな例で検証**：ラボの「重み付き平均」で、客数の少ない店の平均を大きく動かしてみる。単純平均は大きく動くが、重み付き平均は少ししか動かない。客数が同じ2店のときだけ両者が一致する。

**弱点**：客数の多い店の動きに全体が引っ張られる。店ごとの違いを見たいときは、店別の客単価と中央値も並べて見る。
:::

### 課題C｜裾の長いデータで報告する値を決める

来店間隔・滞在時間・待ち時間など、右に裾が長いデータを1つ選ぶ。平均・中央値・90%点を出し、会議で「典型的な値」として報告する値とその理由、平均を併記する場面を書く。

### 課題D｜「平均の種類」を選ぶ表を作る

量・倍率・速さ・単価など、平均をとる場面を5つ以上集める。それぞれで算術・幾何・調和・重み付きのどれを使うかと、「何を合計すると意味があるか」を1行で書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何を伝えるための代表値かが明確か |
| 仮定 | 分布の形と件数（重み）を確かめたか |
| 方法 | 平均・中央値・最頻値・重み付き平均を目的に合わせて選んだか |
| 検証 | 小さな例やラボで確かめたか |
| 限界 | その代表値で言えないことを書いたか |
