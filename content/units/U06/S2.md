::: toggle 答え（言ってから開く）
1. 小さい順に並べ、真ん中の2つの平均をとる。
2. 平均＞中央値になりやすい（大きい値に平均が引っ張られる）。

### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：裾の長い分布で中央値を選ぶ理由**

- **条件**：分布が右に裾が長い（少数の大きい値がある）とき
- **対象と結論**：平均は中央値より大きくなり、典型的な値としては中央値が適している
- **根拠**：平均は全ての値の合計を使うので大きい値に引っ張られるが、中央値は順番の真ん中なので端の値の大きさに影響されにくいから
- **成り立たない場合**：合計や総額（売上見込み・予算）を知りたいときは、平均×件数が必要なので平均を使う

::: toggle つなげると（お手本の文）
「右に裾が長い分布では、平均が中央値より大きくなるので、典型的な値は中央値で伝えるのがよい。平均は合計を使うため大きな値に引っ張られるが、中央値は順番の真ん中なので影響を受けにくいからである。ただし総額を見積もるときは平均を使う。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「平均年収が600万円なので、社員の多くは600万円くらいもらっています。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 年収は右に裾が長いことが多く、少数の高い年収が平均を引き上げる。
- 「多くの人」を言いたいなら、中央値や最頻値を確かめる必要がある。

**言い直しの例**

「平均年収は600万円である。ただし年収の分布は右に裾が長いことが多いので、平均は一部の高い年収に引き上げられている可能性がある。典型的な社員の年収を知るには中央値を確かめる。」
:::

::: toggle 取り違えやすい言葉
- **平均と中央値**：平均＝合計を件数で均した値（合計を保つ）／中央値＝小さい順の真ん中（半数ずつに分ける位置）
- **単純平均と重み付き平均**：単純平均＝値をそのまま平均（店舗の平均を店の数で割る）／重み付き平均＝件数などで重み付け（全客の平均）
- **算術平均と幾何平均**：算術平均＝足して割る（量の平均）／幾何平均＝掛けて累乗根（倍率・成長率の平均。{{unit:U05T}}）
:::

**自己チェック（説明を書いたら）**

- [ ] 分布の形（対称か、裾が長いか）に触れた
