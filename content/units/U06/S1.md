### 2｜意味をつかむ：何を伝えたいかで代表値を選ぶ　{{power:P3}}

たくさんの数を1つの数で言うときの値を**代表値**という。どれを使うかは、何を伝えたいかで決める。

::: ask 合計を均したい（売上見込み・予算・1人あたり）
→ **平均**。合計÷件数。件数を掛けると合計に戻る。
:::

::: ask 典型的な1人・1日を言いたい（裾が長い・外れ値がある）
→ **中央値**。小さい順に並べた真ん中の値。
:::

::: ask 一番よく出る値・売れ筋を知りたい（サイズ・価格帯）
→ **最頻値**。最も多く出る値。
:::

| 代表値 | 外れ値の影響 |
| --- | --- |
| 平均（合計÷件数） | 大きい |
| 中央値（小さい順の真ん中） | 小さい |
| 最頻値（最も多く出る値） | 小さい |

^ 中央値は件数が偶数なら真ん中2つの平均。最頻値は複数あったり、どの値も1回ずつで決まらなかったりすることもある。

### 3｜式の構造を読む　{{power:P1}}

$$
\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i,\qquad \bar{x}_w=\frac{\sum_i w_i x_i}{\sum_i w_i}
$$

| 記号 | 意味（購入額の例） |
| --- | --- |
| xᵢ・n | i 番目の客の購入額と、客の数（10人） |
| Σxᵢ | 全員の購入額の合計（40千円） |
| x̄ | 平均（合計÷人数） |
| wᵢ | 重み。グループの人数・個数など |

**式を言葉で読む**：平均は「全部足して件数で割る」ので、どの値も同じ重さで効く。大きい値が1つあると、その分だけ平均が動く。重み付き平均は「グループごとの合計を足して、全体の件数で割る」。中央値は式ではなく**順番**で決まる（n が奇数なら (n＋1)/2 番目）。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　入口の10人の購入額 1, 1, 2, 2, 2, 3, 3, 4, 5, 17（千円）の平均・中央値・最頻値を求めよ。

1. **平均**：合計40÷10人＝**4千円**
2. **中央値**：10人（偶数）なので、5番目（2）と6番目（3）の平均 → **2.5千円**
3. **最頻値**：3人いる2 → **2千円**
4. 4千円より少ない客は10人中7人。17千円の1人が平均を右に引っ張っている。

{{lab:LAB-center@s1-mm}}

::: key
「典型的な客」は2〜3千円（中央値・最頻値）。一方、10人分の売上見込みは平均×人数＝40千円。**目的によって正しい代表値が変わる**。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-center@s1-move}}

1. **予想**：ラボの課題カードで、17千円が40千円だったときの平均を入れる。
2. **操作**：結果を見たら、最大の値を −／＋ で小さく・大きく動かす。
3. **観察**：平均と中央値は、それぞれどれだけ動いたか。
4. **説明**：「最大の値を動かすと□は大きく動くが、□はほとんど動かない。なぜなら□」を1文で書く。
5. **ラボなしで**：17千円が7千円だったら、平均と中央値はいくつか。

::: toggle 答え（書いてから開く）
- **観察**：最大の値を40千円にすると平均は6.3千円まで上がるが、中央値は2.5千円のまま。最大の値がどれだけ大きくなっても、中央値は5番目と6番目の値しか見ていないので動かない。
- **説明の例**：「最大の値を動かすと平均は大きく動くが、中央値はほとんど動かない。平均は合計を使うので端の値の大きさに引っ張られ、中央値は順番の真ん中なので端の値に影響されにくいから」
- **ラボなしで**：合計は 40−17＋7＝30 なので平均は**3千円**。中央値は**2.5千円**で変わらない。
:::
