### なぜ？｜なぜずれを「2乗」して足すのか

偏差はそのまま足すと0になるので、符号を消す必要がある。符号を消すだけなら、ずれの大きさ（絶対値）を足してもよいはず。それでも2乗の和を使うのはなぜか。

売場A（8〜12個、平均10）と売場C（18〜22個、平均20）の5日ずつを合わせた10日（平均15）で、ラボの偏差平方和を読む。売場ごとの偏差平方和を足した値と比べ、足りない分がどこから来るかを考える。

::: toggle 動かしてから開く
売場A の偏差平方和は10、売場C も10。合わせた10日の偏差平方和は270 で、10＋10＝20 より250 多い。その250は、売場の平均と全体の平均のずれの2乗を、売場の日数だけ足したもの。5×(10−15)²＋5×(20−15)²＝125＋125＝250。

全体の偏差平方和＝売場の中のずれの2乗の和（20）＋売場の平均どうしのずれの2乗の和（250）と、ちょうど足し算で分かれる。ずれの大きさの和ではこうはならない。全体の和は 25＋25＝50 なのに、売場の中の和（6＋6＝12）と平均どうしの分（5×5＋5×5＝50）を足すと62 で、合わない。

2乗の和は、ばらつきを「どこから来た分か」に分けられる。だから分散が、ばらつきの物差しの中心になる。この分け方は、分散分析（{{unit:U32}}）や決定係数（{{unit:U29}}）の土台になる。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

標準偏差という1つの数は、ばらつきを全部まとめて「±何個」と言う。そこからは、**ばらつきのうち、前もって分かる分と分からない分の区別**が消える。ラボで、平日4日（9, 10, 10, 11）と土日4日（19, 20, 20, 21）の8日の分散と標準偏差を読み、なぜ？の分け方で、平日の中・土日の中のばらつきと、平日と土日の差の分に分ける。

::: toggle 動かしてから開く
8日の平均は15、偏差平方和は204、n で割る分散は25.5、標準偏差は約5.05個。「毎日±5個ほどばらつく」と読める。

分けると、平日の中の偏差平方和は2、土日の中も2、平日と土日の平均の差の分が 4×(10−15)²＋4×(20−15)²＝200。204のうち200は、平日か土日かで決まる分。曜日が分かれば、残るばらつきは 4÷8＝0.5、標準偏差でおよそ0.71個しかない。

発注の担当者にとって、平日か土日かは前もって分かる。標準偏差の5.05個は、分かっている曜日の差と、本当に読めない揺れを1つにまとめた数で、「毎日±5個読めない」という意味ではない。
:::

### 本当に？｜n−1 で割れば、母分散を当てられるのか

不偏分散は、n−1 で割ることで、標本を取り直したときの平均が母分散に一致する（応用で見たこと）。それは、標本を母集団から無作為に選んだときの話。

ある月の日販が、1日目の101個から毎日1個ずつ増えて、30日目に130個になったとする。30日全部の不偏分散は77.5。ところが、続いた5日（11〜15日目の111〜115個）を標本にすると、不偏分散は2.5 しかない。続いた日は互いに近い値なので、n−1 で割っても、月全体のばらつきにはまったく届かない。

n−1 の補正が直すのは、標本の平均を使うことで生じる、決まった割合の小ささだけ。選び方の偏り（続いた日だけを選ぶ）や、日どうしが似ていること（傾向・曜日の波）から来る小ささは直さない。日ごとのデータでばらつきを推し量るときは、どの日を選んだかを先に確かめる（日どうしの似かたは {{unit:U05T}} の自己相関）。

### ほかでは？｜つながり

- **2乗の和を分ける**：分散分析（{{unit:U32}}）、決定係数（{{unit:U29}}）
- **標本の分散の偏り**：不偏分散と不偏性（{{unit:U21}}）
- **ばらつきの物差しで外れを測る**：標準化と z（{{unit:U08}}）
- **2乗しないばらつき**：ずれの大きさの平均（平均絶対偏差）。外れ値に強いが、上のように分けることはできない

### 説明してみる

::: task
ある店の日販の標準偏差が、先月（28日）の8個から、今月（28日）は12個に増えた。担当者は「今月は売れ方が不安定になった」と書いた。今月は特売日が3日あり、その3日は通常日の平均より30個ほど多く売れた。特売日を除いた25日の標準偏差は8個で、先月とほぼ同じだった。担当者の読み方のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（日販の記録が正しいとみて）**：標準偏差の増えた分は、特売日と通常日の差（前もって分かる分）から来ている。特売日を除いた25日のばらつきは先月と同じ8個ほどで、通常日の売れ方が不安定になったとは、この数からは言えない。28日全体の標準偏差は、通常日の揺れと特売日の差を1つにまとめた数。

**解釈の例（通常日のばらつきが変わらなかったことについて）**：
- 特売日以外の売れ方は、先月と変わらず落ち着いている
- 特売日の前後に買い控えや買いだめがあり、通常日の中でも特売日の近くの日だけ揺れが大きくなっている。25日全体の標準偏差では、それがならされて見えない

どちらかは、日ごとの並びを見ないと決められない。

**統計の外で決めること**：発注の安全在庫に、特売日の差を含めるか。特売日は前もって分かるので、特売日と通常日で別々の見込みを立てる。報告には、「特売日を除くと先月と同じ」と書き添える。
:::
