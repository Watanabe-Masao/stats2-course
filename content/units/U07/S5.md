### なぜ？｜なぜずれを「2乗」して足すのか

偏差はそのまま足すと0になるので、符号を消す必要がある。符号を消すだけなら、ずれの大きさ（絶対値）を足してもよいはず。それでも2乗の和を使うのはなぜか。

売場A（8〜12個、平均10）と売場C（18〜22個、平均20）の5日ずつを合わせた10日（平均15）で、ラボの偏差平方和を読み、売場ごとの偏差平方和を足した値と比べる。差はどこから来るか。

::: toggle 動かしてから開く
売場A の偏差平方和は10、売場C も10。合わせた10日の偏差平方和は270 で、10＋10＝20 より250 多い。{{unit:U06}} の発展で見たとおり、ずれの2乗の和は「平均からのずれ」で測るといちばん小さく、平均から離れた点で測ると、その離れた分の2乗×個数だけ大きくなる。売場A の5日を全体の平均15で測ると 10＋5×(10−15)²＝135、売場C も 10＋5×(20−15)²＝135 で、合わせて270。

だから、全体の偏差平方和＝売場の中のずれの2乗の和（20）＋売場の平均どうしのずれの分（250）と、足し算で分かれる。ずれの大きさの和ではこうはならない。全体の和は 25＋25＝50 なのに、売場の中の和（6＋6＝12）と平均どうしの分（5×5＋5×5＝50）を足すと62 で、合わない。

2乗の和は、ばらつきを「どこから来た分か」に分けられる。だから分散が、ばらつきの物差しの中心になる。この分け方を使ってグループの違いを確かめるのが、分散分析（{{unit:U32}}）。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

標準偏差は、ばらつきの大きさを1つの数で言う。商品X（9, 9, 9, 9, 14個）と商品Y（6, 11, 11, 11, 11個）の平均・分散・標準偏差を読み、偏差の線の並び方を比べる。2つの数が同じとき、何が違っているか。

::: toggle 動かしてから開く
どちらも平均10個、n で割る分散4、不偏分散5 で、数は同じ（標準偏差も、どちらで割っても2つは同じ値）。けれども商品X は、ふだんは9個で、ときどき大きく売れる日（14個）がある。商品Y は、ふだんは11個で、ときどき大きく売れない日（6個）がある。偏差を2乗すると、平均より上か下かの向きが消えるので、標準偏差という1つの数からは、**ばらつきがどちら側に出るか**が消える。

標準偏差で比べるときは、外れがどちら側かを、点の並びや箱ひげ図で見る（向きを数で表す歪度は {{unit:U08}}）。
:::

### 本当に？｜2つの売場を合わせたばらつきは、それぞれのばらつきの和か

全部の値に a を足しても分散は変わらず、b 倍すると b² 倍になる（初学で見たこと）。では、2つの売場の日販を同じ日どうし足した「合計の日販」の分散は、それぞれの分散の和になるか。

売場A（8〜12個、分散2）と売場C（18〜22個、分散2）を同じ日どうし足した5日で、2つの売場が同じ向きに動いたとき（A が多い日は C も多い）と、逆の向きのとき（A が多い日は C が少ない）の分散を読む。

::: toggle 動かしてから開く
同じ向きのときは、合計は 26, 28, 30, 32, 34 で、分散は8。逆の向きのときは、合計は毎日30 で、分散は0。どちらも、2つの分散の和の 2＋2＝4 にならない。

{{fig:FIG-U07-cov}}

同じ向きの5日（A と C の組は (8, 18)(9, 19)(10, 20)(11, 21)(12, 22)）では、平均の点（10, 20）からの偏差の積の平均（共分散）は2 で、合計の分散は 2＋2＋2×2＝8。逆の向きなら長方形はみな負の側に来て、共分散は−2、合計の分散は 2＋2−2×2＝0。

合計の分散は、それぞれの分散の和に、2つが一緒に動く分（共分散の2倍）を足したものになる。同じ向きに動けば大きくなり、逆に動けば打ち消し合う。「各売場の分散を足せば全店の分散になる」は、売場どうしが一緒に動かないときだけ。天気や曜日で全部の売場が同じ向きに動く店では、全店の分散は、売場ごとの分散の和より大きくなる（日どうしが一緒に動くと標本の分散が小さく出る話は {{unit:U21}} の発展にもある）。一緒に動く度合いは、共分散と相関係数（{{unit:U28}}）で測る。
:::

### ほかでは？｜つながり

- **2乗の和を分ける**：分散分析（{{unit:U32}}）、決定係数（{{unit:U29}}）
- **一緒に動く分**：共分散と相関係数（{{unit:U28}}）。確率変数の和の分散（{{unit:U13}}）
- **ばらつきの向き**：歪度（{{unit:U08}}）
- **標本の分散の偏り**：不偏分散と不偏性（{{unit:U21}}）

### 説明してみる

::: task
商品P の8日の販売数は 18, 18, 18, 18, 18, 18, 18, 30 個、商品Q は 21, 21, 21, 21, 21, 21, 21, 9 個。どちらも平均19.5個、標準偏差（n で割る）約3.97個。担当者は「標準偏差が同じなので、どちらも平均＋標準偏差の2倍の約27.4個を毎日並べればよい」と書いた。この決め方のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（8日の記録が正しく、次の日も同じような売れ方をするとみて）**：「平均＋標準偏差の2倍」は、平均からの外れが上にも下にも同じように出る（左右対称な）ことを前提にした目安。P は上にだけ大きく外れ、Q は下にだけ大きく外れていて、どちらも前提に合わない。27.4個を並べると、P は30個売れた日に足りず、8日のうち1日で欠品する。Q は一番多い日でも21個なので欠品はないが、21個売れた日でも6.4個（27.4−21）余り、9個の日は18.4個余る。同じ標準偏差から作った同じ目安が、外れの向きで逆の結果になる。

**解釈の例（外れた日について）**：
- P の30個の日は給料日で、毎月決まって起きる。Q の9個の日は雨の日で、天気しだい
- どちらの外れも、たまたまこの8日に1回入っただけで、ふだんは起きない

どちらの読み方かは、8日の数字だけからは決められない。

**統計の外で決めること**：欠品と売れ残りのどちらを避けたいか。P は外れの日が前もって分かるなら、その日だけ多く並べる。Q は余りが毎日出るので、並べる数を減らし、外れの日の欠品を受け入れるかを決める。
:::
