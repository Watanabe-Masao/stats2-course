### 探究｜変動係数の小さい店は、運営が安定しているのか

本部が、3店の4週間（28日）の日販（個）から変動係数（CV＝標準偏差÷平均）を出し、「CV が小さい店ほど、運営が安定している」として、大型店を表彰することにした。

| 店 | 平均・標準偏差 | CV |
| --- | --- | --- |
| 大型店 | 200個・20個 | 0.10 |
| 小型店 | 20個・5個 | 0.25 |
| 駅前店 | 100個・25個 | 0.25 |

聞き取ると、次のことが分かった。
- 3店とも、特売や欠品はこの4週間になかった
- 駅前店は、土日の日販が平日の2倍近くになる
- 客は1人ずつばらばらに来て、1人が買う個数は3店でほぼ同じ

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. ラボの「変動係数」で、3店の CV を確かめる
2. 客がばらばらに来るだけで生まれるばらつき（下の目安）を、3店で計算して比べる
3. 駅前店のばらつきのうち、曜日で前もって分かる分を考える
4. 統計で言えることと言えないことを分ける
5. 「安定している」の読み方（2つ以上）を書く
6. 表彰に使う数を決める（下の課題）

**目安**：客が1人ずつばらばらに来るなら、日販の標準偏差は、偶然だけでもおよそ √平均 になる（来る人数のばらつき方は {{unit:U15}}）。平均200個なら √200≒14個、平均20個なら √20≒4.5個、平均100個なら10個。

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（日販の記録が正しく、目安の前提〔客がばらばらに来る〕が3店で成り立つとみて）**：CV は大型店0.10、小型店0.25、駅前店0.25。偶然だけで生まれる CV の目安は、√平均÷平均＝1÷√平均 で、大型店 約0.07、小型店 約0.22、駅前店 0.10。小型店の0.25 は、偶然の目安（0.22）とほとんど同じで、偶然以上に揺れているとは言えない。大型店の0.10 は目安の0.07 より大きい。駅前店の0.25 は目安の0.10 よりずっと大きいが、その多くは土日と平日の差で、曜日で前もって分かる分。

**この数だけでは言えないこと**：CV の大小が運営のうまさの差かどうか。平均の小さい店ほど、偶然だけで CV が大きくなる（1÷√平均）。CV が小さいのは、店が大きいからかもしれない。駅前店の CV には、運営と関係のない曜日の差が入っている。

**解釈の例**：
- 大型店は、品ぞろえや人の配置がうまく、本当に揺れが少ない
- 大型店の CV が小さいのは、客の数が多く、偶然の揺れが平均に比べて小さく見えるだけ
- 駅前店は、土日の客を見込んで品をそろえていて、曜日の差は読めている。読めない揺れは小さいかもしれない

どれが当たるかは、3つの CV だけからは決められない。

**統計の外で決めること**：「運営が安定している」を何で測るか。予測できない欠品や売れ残りを減らすことを評価したいのか、売上の大きさを評価したいのかで、使う数が変わる。
:::

### 課題｜表彰に使う数を選ぶ

**問い**　来期から、「安定した運営」の表彰に何を使うか。

- **ア**：CV のまま、ただし店の大きさ（平均の日販）が近い店どうしで比べる
- **イ**：曜日ごとの平均からのずれで標準偏差を出し、偶然の目安（√平均）で割った値で比べる
- **ウ**：日販のばらつきをやめ、欠品した時間と、売れ残って捨てた量で比べる

**判断の材料**：店は全部で40店。曜日ごとの平均を出すには、店ごとに4週間分の集計が要る。欠品の時間は、レジの記録から自動で出せるが、捨てた量は店の手書きの記録しかない。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（日販と記録が正しいとみて）**：ア は、店の大きさで CV が変わる分を減らせるが、曜日の差は残る。イ は、曜日で分かる分を除き、偶然の目安と比べるので、「読めない揺れが偶然より大きいか」に近づく。ただし目安は「客がばらばらに来る」前提に立ち、団体客や天気で客がまとまって動く店では崩れる。ウ は、ばらつきではなく、ばらつきに対応できたか（欠品・廃棄）を直接見る。捨てた量は手書きなので、店によって書き方がそろっていない。

**統計の外で決めること**：表彰で何を伸ばしたいか。発注の腕を評価したいなら ウ が目的に近いが、記録のそろえ方を先に決める必要がある。数だけで比べるなら イ を基本にし、前提が崩れる店（団体客が多い店）は別に見る。どれを選んでも、店の大きさと曜日の差で数が動くことを、表彰の説明に書く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 「安定」を、何のばらつきとして測るかを問いにしたか |
| 仮定 | 客がばらばらに来るという、目安の前提を書いたか |
| 方法 | 偶然の目安と比べ、曜日で分かる分を分けたか |
| 検証 | ラボで3店の CV を確かめたか |
| 切り分け | 言えること（CV と偶然の目安の比べ）と、言えないこと（運営のうまさ）を分けたか |
| 解釈 | CV の読み方を2つ以上並べ、表彰に使う数を書いたか |
