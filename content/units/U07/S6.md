### 探究｜変動係数の小さい店は、運営が安定しているのか

本部が、3店の弁当の4週間（28日）の日販から変動係数（CV＝標準偏差÷平均）を出し、「CV が小さい店ほど、運営が安定している」として、いちばん CV の小さい店を表彰することにした。

| 店 | 弁当の日販の平均・標準偏差 |
| --- | --- |
| 大型店 | 196個・20個 |
| 中型店 | 100個・12個 |
| 小型店 | 25個・6個 |

聞き取ると、次のことが分かった。
- 弁当は、客がたいてい1人1個だけ買う
- この4週間、3店とも弁当が売り切れた日はなかった
- 大型店の近くには会社が多く、会議の日には、まとめて10個、20個と注文が入る

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. ラボの「変動係数」で、3店の CV を出す
2. 客がばらばらに来るだけで生まれるばらつき（下の目安）を、3店で計算する
3. 実際の標準偏差が、目安の何倍かを3店で比べる
4. 統計で言えることと言えないことを分ける
5. 「安定している」の読み方（2つ以上）を書く
6. 表彰に使う数を決める（下の課題）

**目安**：客が1人ずつばらばらに来て、1人が1個ずつ買うなら、日販の標準偏差は、偶然だけでもおよそ √平均 になる（来る人数のばらつき方は {{unit:U15}}）。

**統計で言えること（日販の記録が正しく、目安の前提〔客がばらばらに来て1人1個買う〕が3店で成り立つとみて）**：CV は大型店 20÷196≒0.10、中型店 0.12、小型店 0.24 で、大型店がいちばん小さい。偶然だけの標準偏差の目安は √196＝14個、√100＝10個、√25＝5個で、偶然だけの CV は 約0.07・0.10・0.20。平均の小さい店ほど、偶然だけで CV が大きくなる（1÷√平均）。実際の標準偏差を目安で割ると、大型店 20÷14≒1.43、中型店 1.2、小型店 1.2。偶然を超える揺れは、大型店がいちばん大きい。

**この数だけでは言えないこと**：CV の小ささが運営のうまさかどうか。大型店の CV が小さいのは、客の数が多く、偶然の揺れが平均に比べて小さく見えるから。目安を超える揺れの原因（運営か、客の来方か）も、この数からは分からない。

**解釈の例**：
- 大型店の、目安を超える揺れは、会議の日のまとめ注文。客が「ばらばらに1個ずつ」という前提が崩れていて、運営とは関係ない
- 大型店は、日によって並べる量や売場の人の配置が揺れていて、それが日販の揺れになっている
- 中型店と小型店は、目安とほぼ同じで、読めない揺れはほとんど偶然の分だけ

どれが当たるかは、3店の平均と標準偏差だけからは決められない。

**統計の外で決めること**：「運営が安定している」を何で測るか。売り切れや売れ残りを減らす発注のうまさを評価したいのか、客の来方を含めた売上の落ち着きを評価したいのかで、使う数が変わる。
:::

### 課題｜表彰に使う数を選ぶ

**問い**　来期から、「安定した運営」の表彰に何を使うか。

- **ア**：CV のまま、ただし平均の日販が近い店どうしで比べる
- **イ**：標準偏差を、偶然だけの目安（√平均）で割った値で比べる
- **ウ**：日販のばらつきをやめ、売り切れた時間と、売れ残って捨てた量で比べる

**判断の材料**：店は全部で40店で、平均の日販は20個から200個まで広がる。売り切れた時間はレジの記録から自動で出せるが、捨てた量は店の手書きの記録しかない。売り切れのある店では、日販は売れた数で頭打ちになり、本当に欲しかった数より小さく出る。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（日販と記録が正しいとみて）**：ア は、店の大きさで CV が変わる分を減らせるが、40店を大きさでいくつかの組に分けると、組ごとの店の数が少なくなる。イ は、店の大きさの違いを偶然の目安で消し、「偶然を超えて揺れているか」を比べられる。ただし目安は「客がばらばらに来て1人1個」の前提に立ち、まとめ注文の多い店では大きく出る。また、売り切れのある店では日販が頭打ちになるので、標準偏差が小さく出て、イ でも安定して見える。ウ は、ばらつきそのものではなく、ばらつきに対応できたか（売り切れ・廃棄）を直接見る。捨てた量は手書きなので、店によって書き方がそろっていない。

**統計の外で決めること**：表彰で何を伸ばしたいか。発注のうまさを評価したいなら ウ が目的に近く、捨てた量の記録のそろえ方を先に決める。数だけで比べるなら イ を基本にし、まとめ注文の多い店と売り切れのある店は別に見る。どれを選んでも、店の大きさで CV が変わることを、表彰の説明に書く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 「安定」を、何のばらつきとして測るかを問いにしたか |
| 仮定 | 客がばらばらに来て1人1個買うという、目安の前提を書いたか |
| 方法 | 偶然の目安を出し、実際の標準偏差と比べたか |
| 検証 | ラボで、実際の CV と偶然だけの CV を比べたか |
| 切り分け | 言えること（CV と、目安を超える揺れの大きさ）と、言えないこと（運営のうまさ）を分けたか |
| 解釈 | 揺れの読み方を2つ以上並べ、表彰に使う数を書いたか |
