### 課題A｜自分の店の「ばらつきカード」を作る

自分の職場で、よく売れる商品を5品選び、4週間（28日）の日販を集めて次を作る。

| 項目 | 書くこと |
| --- | --- |
| 平均と標準偏差 | 商品ごとに、n−1 で割るか n で割るかも書く |
| 変動係数 | 並べて、相対的にばらつく商品を見つける |
| 発注への使い方 | 平均＋標準偏差の何倍を見込むか |
| 言えないこと | 曜日の波・特売など、この数字だけでは分からないこと |

### 課題B｜安定している売場を決める

**問い**　2つの売場のどちらが「安定している」かを、本部に数字で説明したい。使う指標と、その指標の弱点を決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**決め方**：平均が同じくらいなら標準偏差、平均が大きく違うなら変動係数で比べる。手元の期間の記述なので n で割ってもよいが、来月の見込みに使うなら n−1 で割った不偏分散から標準偏差を出す。

**小さな例で検証**：ラボの「変動係数」で、平均だけを大きくしてみる。標準偏差が同じでも CV は小さくなり、「相対的には安定」と言える。

**弱点**：外れ値（特売日・天候）が1日あると標準偏差は大きく動く。箱ひげ図や四分位範囲も並べ、外れ値の原因を確かめる。曜日の波は {{unit:U05T}} の移動平均で取り除いてから比べる。
:::

### 課題C｜店舗の売上の偏りを表す

自社または身近な複数店舗（5店以上）の売上を集め、ローレンツ曲線を描いてジニ係数を求める。上位20%の店で売上の何%になるかも書き、偏りが大きい理由を1文で考える。

### 課題D｜「散らばりの指標」を選ぶ表を作る

範囲・四分位範囲・標準偏差・変動係数・ジニ係数について、使える場面、使えない場面、外れ値への強さを1行ずつで書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何の散らばり・何との比較かが明確か |
| 仮定 | 単位・平均の大きさ・記述か推定かを明示したか |
| 方法 | 標準偏差・変動係数・ジニ係数を目的に合わせて選んだか |
| 検証 | 小さな例やラボで確かめたか |
| 切り分け | その指標で言えないこと（外れ値・曜日の波）を書いたか |
