### 0｜入口の問い

::: task
売場Aの5日間の販売数は 8, 9, 10, 11, 12 個、売場Bは 4, 7, 10, 13, 16 個だった。担当者は「どちらも平均10個だから、同じだけ発注すればよい」と言った。この言い方のどこを確かめればよいか。
:::

^ まだ答えなくてよい。「平均のまわりにどれだけ散らばっているか」を数で示し、平均の大きさが違うものとも比べられるようになるのが初学のゴール。

### 2｜意味をつかむ：何を比べたいかで指標を選ぶ　{{power:P3}}

平均が同じでも、毎日の値が平均の近くにまとまる売場と、大きく上下する売場がある。散らばりを1つの数で表す。

::: ask ばらつきの大きさを元の単位で言いたい（「±何個ぶれる」）
→ **標準偏差**。分散の平方根で、単位は元と同じ（個）。
:::

::: ask 平均の大きさが違うものどうしを比べたい（高額商品と低額商品）
→ **変動係数 CV＝標準偏差÷平均**。単位がなくなる。
:::

::: ask 手元のデータを記述したいのか、母集団を推定したいのか
→ 記述なら **n** で割る、推定なら **n−1** で割る（不偏分散）。
:::

{{icon:fig}} **「平均からのずれ」を図で見る**

{{fig:FIG-U07-spread}}

偏差（各値−平均）を足すと必ず0になる。だから**2乗してから足す**。これが偏差平方和で、件数で割ると分散になる。

### 3｜式の構造を読む　{{power:P1}}

$$
v=\frac{1}{n}\sum (x_i-\bar{x})^2\qquad s^2=\frac{1}{n-1}\sum (x_i-\bar{x})^2\qquad CV=\frac{s}{\bar{x}}
$$

| 記号 | 意味（売場Bの例） |
| --- | --- |
| xᵢ−x̄ | 偏差。−6, −3, 0, 3, 6 |
| Σ(xᵢ−x̄)² | 偏差平方和（90） |
| v・s² | n で割る分散・n−1 で割る不偏分散 |
| s・CV | 標準偏差（√s²）・変動係数（s÷x̄） |

**式を言葉で読む**：偏差を2乗すると、平均から遠い値ほど大きく効く。分散は「2乗したずれの平均」なので単位は個²になり、平方根をとった標準偏差で元の単位（個）に戻す。CV は標準偏差を平均で割るので、平均の大きさの違いを消して比べられる。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　売場Bの5日間の販売数は 4, 7, 10, 13, 16 個。n で割る分散 v、不偏分散 s²、標準偏差 s、変動係数を求めよ。

| xᵢ | xᵢ−x̄ | (xᵢ−x̄)² |
| --- | --- | --- |
| 4 | −6 | 36 |
| 7 | −3 | 9 |
| 10 | 0 | 0 |
| 13 | 3 | 9 |
| 16 | 6 | 36 |
| **合計** | 0 | **90** |

1. 平均 x̄＝50÷5＝10
2. 偏差平方和＝**90**
3. n で割る分散 v＝90÷5＝**18**
4. 不偏分散 s²＝90÷4＝**22.5**
5. 標準偏差 s＝√22.5≒**4.74個**、CV＝4.74÷10≒**0.47**

::: key
平均は同じ10個でも、売場Bは±5個ほどぶれるのが普通。発注や在庫は売場Bのほうが余裕が必要。分散の単位は「個²」なので、大きさを語るときは標準偏差を使う。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-spread@s1-scale}}

1. **予想**：ラボの課題カードで、売場Bの販売数を全部2倍にしたときの不偏分散を入れる。
2. **操作**：結果を見たら、b（何倍するか）を3倍・0.5倍に、a（足す数）を10や−5に動かす。
3. **観察**：平均・分散・標準偏差は、b と a でそれぞれどう変わったか。
4. **説明**：「全部を b 倍すると分散は□倍、標準偏差は□倍。a を足しても散らばりが変わらないのは□から」を1文で書く。
5. **ラボなしで**：売場Bの販売数に全部5を足すと、不偏分散はいくつか。

::: toggle 答え（書いてから開く）
- **観察**：2倍で不偏分散は22.5→90（4倍）、標準偏差は4.74→9.49（2倍）。3倍なら分散は9倍の202.5。a を足すと平均だけが a だけずれ、分散と標準偏差は変わらない。
- **説明の例**：「全部を b 倍すると偏差も b 倍になり、2乗するので分散は b² 倍、標準偏差は b 倍。a を足しても全部が同じだけずれるので、平均からのずれ（偏差）は変わらないから」
- **ラボなしで**：5を足すと平均は15になり、偏差は −6, −3, 0, 3, 6 のまま。不偏分散は**22.5**で変わらない。
:::
