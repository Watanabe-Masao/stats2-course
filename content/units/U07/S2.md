**お手本：不偏分散で n−1 で割る理由**

- **条件**：標本から母集団の分散を推定するとき
- **対象と結論**：偏差平方和を n−1 で割った不偏分散を使う
- **根拠**：平均を標本自身から計算するため、偏差の合計が0という制約が1つかかり、自由に動ける偏差は n−1 個になる。n で割ると母分散を平均的に小さく見積もってしまうから
- **成り立たない場合**：手元のデータそのものの散らばりを記述するだけなら、n で割ってよい

::: toggle つなげると（お手本の文）
「標本から母分散を推定するときは、偏差平方和を n−1 で割る。平均を標本から求めるので偏差の合計が0という制約がかかり、n で割ると母分散を平均的に小さく見積もるからである。ただし手元のデータを記述するだけなら n で割る。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「高額商品の売上は標準偏差が大きいので、低額商品より売上が不安定です。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 平均が大きいと、標準偏差も大きくなりやすい。平均の違いを考えていない。
- 「不安定」を比べるなら、変動係数で相対的なばらつきを見る。

**言い直しの例**

「高額商品は標準偏差が大きいが、売上の平均も大きいので、それだけで不安定とは言えない。変動係数（標準偏差÷平均）で比べると、平均に対するばらつきの大きさが分かる。」
:::

::: toggle 取り違えやすい言葉
- **分散と標準偏差**：分散＝偏差の2乗の平均（単位は元の2乗、個²）／標準偏差＝分散の平方根（単位は元と同じ、個）
- **標本分散と不偏分散**：本や流儀により「標本分散」が n で割る場合と n−1 で割る場合がある／試験では式（分母）を見て判断する
- **標準偏差と変動係数**：標準偏差＝絶対的なばらつき（単位あり）／変動係数＝平均に対する相対的なばらつき（単位なし）
:::

### 式の早見

| 求めるもの | 式 |
| --- | --- |
| n で割る分散 | Σ(xᵢ−x̄)²÷n |
| 不偏分散 | Σ(xᵢ−x̄)²÷(n−1) |
| 計算の近道 | Σ(xᵢ−x̄)²＝Σxᵢ²−(Σxᵢ)²÷n |
| 標準偏差 | 分散の平方根 |
| 変動係数 | 標準偏差÷平均 |
