### 2｜意味をつかむ：問題文の言葉で式を選ぶ　{{power:P3}}

{{unit:U11}} では「原因が分かったときの結果の確率」P(結果｜原因) を扱った。この単元はその逆向きで、「結果を見たときの原因の確率」P(原因｜結果) を求める。

::: ask 「〇〇率」「検出率」「誤検出率」の3つが与えられ、逆向きの確率（検出された品が本当に不良である確率）を聞かれる
→ **ベイズの定理**：目当ての経路÷結果が出る全経路。
:::

::: ask 原因が複数あって、結果の起こる確率の合計を聞かれる（工場A・Bを合わせた不良率）
→ **全確率**：原因ごとに「原因の割合×その原因で結果が出る率」を出して足す。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
P(\text{不良}\mid\text{検出})=\frac{P(\text{不良})P(\text{検出}\mid\text{不良})}{P(\text{不良})P(\text{検出}\mid\text{不良})+P(\text{良品})P(\text{検出}\mid\text{良品})}
$$

| 記号 | 意味（検品の例） |
| --- | --- |
| P(不良) | 元の不良率（事前確率） |
| P(検出｜不良) | 不良品が引っかかる率（検出率） |
| P(検出｜良品) | 良品が誤って引っかかる率（誤検出率） |
| 分母 P(検出) | 引っかかる率の合計（全確率） |
| P(不良｜検出) | 引っかかった品のうち不良の割合（事後確率） |

**式を言葉で読む**：分子は「不良で、検出される」経路、分母は「検出される」すべての経路（不良で検出＋良品なのに検出）。結果が出た経路の中で、目当ての原因の経路が占める割合が事後確率。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　不良率2%の商品を検品する。検品は不良品の90%を検出し、良品も5%は誤って検出する。検出された品が本当に不良である確率は？

**1000個で数える**

| 区分（1000個中） | 検出率 | 検出数 |
| --- | --- | --- |
| 不良品 20個 | 90% | 18 |
| 良品 980個 | 5% | 49 |
| 合計 | — | 67 |

**式に当てはめる**

1. 分子：0.02×0.90＝0.018（不良で検出される経路）
2. 分母：0.018＋0.98×0.05＝0.018＋0.049＝0.067（検出される全経路＝**全確率**）
3. 0.018÷0.067＝18÷67≒**0.269（約26.9%）**

{{lab:LAB-prob@s1-bayes}}

::: key
P(検出｜不良)＝90% と P(不良｜検出)＝26.9% は別物。**元の不良率が低いと、検出品の多くは良品の誤検出**になる。「引っかかったら即廃棄」ではなく再検査を挟む判断につながる。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-prob@s1-fpr}}

1. **予想**：ラボの課題カードで、誤検出率を1%に下げたときの事後確率を入れる。
2. **操作**：結果を見たら、「元の割合」を 2% から少しずつ上げる。次に「該当→結果」（検出率）を上げ下げする。
3. **観察**：事後確率を大きく動かすのは、元の割合・検出率・誤検出率のどれか。
4. **説明**：「□を変えると事後確率が大きく変わった。なぜなら□」を1文で書く。
5. **ラボなしで**：例題Aで誤検出率だけ1%にすると、1000個のうち良品の誤検出は何個か。事後確率は約何%か。

::: toggle 答え（書いてから開く）
- **観察**：元の割合と誤検出率で大きく動く。検出率を90%から上げても、事後確率はあまり変わらない。
- **説明の例**：「誤検出率を5%→1%に下げると、事後確率は約27%から約65%に大きく上がった。良品が980個と多いので、誤検出の個数が分母の大部分を占めていたから」
- **ラボなしで**：980×0.01＝**9.8個**。18÷(18＋9.8)≒**64.7%**（約65%）。
:::
