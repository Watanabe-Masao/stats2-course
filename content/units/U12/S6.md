### 課題A｜自分の職場の「1000で数えるカード」を作る

検品・アラート・販促の反応など、「結果を見て原因を判断している」場面を1つ選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 原因と結果 | 何を見て（結果）、何を判断しているか（原因） |
| 3つの割合 | 元の割合、原因あり→結果、原因なし→結果（分からなければ見込み） |
| 1000で数える | 結果が出る個数を2か所から出した表 |
| 事後確率 | 結果が出たもののうち、本当に当てはまる割合 |

### 課題B｜再検査を入れるか決める

**問い**　例題Aの検品（不良率2%・検出率90%・誤検出率5%）で、引っかかった品をすぐ捨てるか、もう一度検品してから捨てるかを決める。決め方と、そのために必要な数を書く。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：1回だけで捨てると、捨てる67個のうち49個は良品。もう一度検品すると、2回とも引っかかった品の不良率は約87%に上がり、捨てる良品は約2.45個まで減る。一方で、1回目で見つかった不良18個のうち約1.8個は2回目で見逃される。

**必要な数**：良品を捨てる損失、不良品を出荷してしまう損失、再検査の手間（1個あたりの費用）。

**小さな例で検証**：ラボの「ベイズ」で「同じ検査を2回」に切り替え、1000個のうち捨てる良品の数を比べる。

**成り立たない条件と、その先の判断**：2回の検品の誤りが独立とは限らない（同じ傷を同じように見落とす）。独立でないと、2回目の効果は計算より小さい。
:::

### 課題C｜「検出率」だけの資料を直す

会議資料や製品の説明から「〇〇を90%見つける」「精度95%」のような数字を1つ探し、「引っかかったもののうち本当に当てはまる割合」と取り違えて使われていないか確かめる。取り違えていたら、どの割合（元の割合・誤検出率）が必要かを書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何を見て何を判断するかが明確か |
| 仮定 | 3つの割合の出どころ、独立の仮定を書いたか |
| 方法 | 1000で数え、全経路を分母にしたか |
| 検証 | 小さな例やラボで確かめたか |
| 切り分け | 割合の見込みのずれ、誤りの独立を書いたか |
