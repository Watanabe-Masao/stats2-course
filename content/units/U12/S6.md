### 探究｜誤検出が多いという苦情。2つの改善案を、何で比べるか

不良率 2%・検出率 90%・誤検出率 5% の検品で、「検出された品の多くが良品で、確認の作業がむだ」という苦情が来た。改善案は2つ。

- 案1：検品の機械を替えて、誤検出率を 5% から 2% に下げる（検出率は 90% のまま）
- 案2：作る工程を見直して、不良率を 2% から 1% に下げる（検品の性能は今のまま）

1. それぞれの案で、1000 個あたりの「検出ありのうち不良の割合」「良品なのに検出される個数」「検品を通り抜ける不良の個数」を数える
2. 統計で言えること（それぞれの数がどう動くか）を、前提と一緒に書く
3. どの数を目的にするかで判断が変わることを、選び肢と判断の材料の形で書く
4. 選ぶ前に、次に確かめる記録を書く

::: toggle 統計で言えることと、決めることを分けた例（自分で考えてから開く）
**統計で言えること**（案1は検出率が 90% のまま、案2は検品の性能が変わらないという前提で、1000 個あたり）：

| | 案1 | 案2 |
| --- | --- | --- |
| 検出ありのうち不良 | 約 48% | 約 15% |
| 良品なのに検出 | 19.6 個 | 49.5 個 |
| 通り抜ける不良 | 2 個 | 1 個 |

今はそれぞれ 約 27%・49 個・2 個。

案1は確認の作業（良品なのに検出）を減らし、通り抜ける不良は変えない。案2は通り抜ける不良を減らし、良品なのに検出はほとんど変えない。案2で事後確率が下がるのは、不良そのものが減ったからで、検品が悪くなったからではない。

**統計の外で決めること**：選び肢は2つ。苦情に応える（確認の作業を減らす）なら案1、お客に届く不良を減らすなら案2。どちらを目的にするかは、作業の手間と届く不良のどちらを重く見るかで決まり、統計では決まらない。判断の材料は、上の3つの数と、機械の入れ替え・工程の見直しにかかる費用。

**次に確かめる記録**：誤検出の原因（品の傷か、機械のくせか。案1で本当に 2% まで下がるか）と、今の通り抜けた不良によるクレームの数。
:::

### 課題A｜自分の職場の「1000で数えるカード」を作る

検品・アラート・販促の反応など、「結果を見て原因を判断している」場面を1つ選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 原因と結果 | 何を見て（結果）、何を判断しているか（原因） |
| 3つの割合 | 元の割合、原因あり→結果、原因なし→結果（分からなければ見込み） |
| 1000で数える | 結果が出る個数を2か所から出した表 |
| 事後確率 | 結果が出たもののうち、本当に当てはまる割合 |

### 課題B｜再検査を入れるか決める

**問い**　例題Aの検品（不良率2%・検出率90%・誤検出率5%）で、引っかかった品をすぐ捨てるか、もう一度検品してから捨てるかを決める。決め方と、そのために必要な数を書く。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：1回だけで捨てると、捨てる67個のうち49個は良品。もう一度検品すると、2回とも引っかかった品の不良率は約87%に上がり、捨てる良品は約2.45個まで減る。一方で、1回目で見つかった不良18個のうち約1.8個は2回目で見逃される。

**必要な数**：良品を捨てる損失、不良品を出荷してしまう損失、再検査の手間（1個あたりの費用）。

**小さな例で検証**：ラボの「ベイズ」で「同じ検査を2回」に切り替え、1000個のうち捨てる良品の数を比べる。

**成り立たない条件と、その先の判断**：2回の検品の誤りが独立とは限らない（同じ傷を同じように見落とす）。独立でないと、2回目の効果は計算より小さい。
:::

### 課題C｜「検出率」だけの資料を直す

会議資料や製品の説明から「〇〇を90%見つける」「精度95%」のような数字を1つ探し、「引っかかったもののうち本当に当てはまる割合」と取り違えて使われていないか確かめる。取り違えていたら、どの割合（元の割合・誤検出率）が必要かを書く。

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何を見て何を判断するかが明確か |
| 仮定 | 3つの割合の出どころ、独立の仮定を書いたか |
| 方法 | 1000で数え、全経路を分母にしたか |
| 検証 | 小さな例やラボで確かめたか |
| 切り分け | 統計で言えること（事後確率がどう動くか）と、統計の外で決めること（何を目的にするか）を分けたか |
