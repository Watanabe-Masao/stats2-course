::: toggle 答え（言ってから開く）
1. 事前：結果を見る前の割合（不良率）。尤度：各原因の下で結果が出る確率（検出率・誤検出率）。事後：結果を見た後の割合。
2. 結果（検出）が起こる確率の合計＝全確率。
3. 全体を1000個などにして区分ごとの個数を出し、結果に当てはまる個数を足して、目当ての個数を割る。
:::

### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：検出率が高くても事後確率が低い理由**

- **条件**：不良率がとても低い（2%）商品を、誤検出のある検品にかけるとき
- **対象と結論**：検出された品が本当に不良である確率は、検出率90%よりずっと低い（約27%）
- **根拠**：良品の数が圧倒的に多いので、誤検出率5%でも良品からの誤検出（49個）が、不良品からの検出（18個）を上回るから
- **成り立たない場合**：不良率が高い、または誤検出率がとても低いときは、事後確率は高くなる

::: toggle つなげると（お手本の文）
「不良率が低い商品では、検出率が90%あっても、検出された品が本当に不良である確率は約27%にとどまる。良品の数が多いため、誤検出率5%でも良品の誤検出が不良品の検出より多くなるからである。ただし不良率が高い場合や誤検出がとても少ない場合は、事後確率は高くなる。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「この検品は不良品の90%を見つけるので、検品で引っかかった品は90%の確率で不良です。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 90% は P(検出｜不良)。聞かれているのは P(不良｜検出) で、向きが逆。
- 元の不良率と良品の誤検出率がないと求められない。

**言い直しの例**

「この検品は不良品の90%を検出する。ただし引っかかった品が本当に不良である確率は、不良率と良品の誤検出率で決まる。不良率2%・誤検出率5%なら約27%で、引っかかった品の多くは良品である。」
:::

::: toggle 取り違えやすい言葉
- **「事前確率」と「事後確率」**：事前＝結果を見る前（不良率2%）／事後＝結果を見た後（検出された品の不良率27%）
- **「検出率（感度）」と「的中率」**：検出率＝不良品のうち検出される割合 P(検出｜不良)／的中率＝検出品のうち本当に不良の割合 P(不良｜検出)
- **「全確率」と「事後確率」**：全確率＝全体のうち結果が出る割合 P(検出)（分母）／事後確率＝結果が出たもののうち目当ての原因の割合
:::

### 式の早見

| 求めるもの | 式 |
| --- | --- |
| 全確率 | P(B)＝Σ P(Aᵢ)P(B｜Aᵢ) |
| ベイズの定理 | P(Aⱼ｜B)＝P(Aⱼ)P(B｜Aⱼ)÷P(B) |
| 前提 | Aᵢ は重ならず、全体を覆う |
| 例題A（1000個） | 18÷(18＋49)＝18÷67≒26.9% |
