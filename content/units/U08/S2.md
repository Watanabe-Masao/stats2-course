### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：z得点で比べる理由**

- **条件**：平均やばらつきが違う2つの集団の値を比べるとき
- **対象と結論**：元の値ではなく z得点で比べると、それぞれの集団の中での位置を公平に比べられる
- **根拠**：平均を引くことで中心をそろえ、標準偏差で割ることでばらつきの物差しをそろえるから
- **成り立たない場合**：分布の形が大きく違う（片方だけ強く歪んでいる）と、同じ z でも珍しさ（割合）は同じとは限らない

::: toggle つなげると（お手本の文）
「平均やばらつきの違う集団の値を比べるときは、z得点にすると集団の中での位置を公平に比べられる。平均を引いて中心をそろえ、標準偏差で割って物差しをそろえるからである。ただし分布の形が大きく違えば、同じ z でも珍しさは同じとは限らない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「データを標準化したので、正規分布として確率を計算できます。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 標準化は平均0・標準偏差1にそろえるだけで、分布の形は変わらない。
- 正規分布の確率を使えるのは、元の分布が正規分布に近いときだけ。

**言い直しの例**

「データを標準化して平均0・標準偏差1にそろえた。元の分布が正規分布に近ければ、標準正規分布表で確率を求められる。歪みが大きい場合は、その確率は当てはまらない。」
:::

::: toggle 取り違えやすい言葉
- **標準化と正規化（正規分布にする）**：標準化＝平均0・標準偏差1にそろえる。形は変わらない／標準化しても正規分布になるわけではない
- **外れ値と誤り**：外れ値＝他から飛び抜けた値／誤り＝入力ミスなど。外れ値の原因の1つにすぎない
- **z得点と指数（基準＝100）**：z得点＝平均と標準偏差で位置を表す／指数＝基準の値を100とした比。ばらつきは考えない（{{unit:U05T}}）
:::

### 指標の早見

| 指標 | 読み方 |
| --- | --- |
| z得点 | 平均から標準偏差いくつ分か。単位なし |
| 歪度 | 正：右に裾が長い／負：左に裾が長い |
| 尖度 | 裾の重さ。正規分布は3（超過尖度なら0） |
| 外れ値の柵 | Q₁−1.5IQR 未満、Q₃＋1.5IQR 超 |
