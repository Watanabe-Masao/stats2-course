### 0｜入口の問い

::: task
店舗Aは日販の平均50万円・標準偏差10万円、店舗Bは平均80万円・標準偏差5万円。ある日、店舗Aは70万円、店舗Bは90万円だった。本部は「平均より20万円も多い店舗Aの方が、10万円多い店舗Bより珍しく良い日だった」と言った。この言い方のどこを確かめればよいか。
:::

^ まだ答えなくてよい。「その店のふだんのばらつき」で差を測り直して、別の集団の値を同じ物差しで比べられるようになるのが初学のゴール。

### 1｜前提チェック（2分）

::: toggle 3問だけ確かめる（答えも中にある）

2. −6÷3 は？ → −2（負の数を正の数で割ると負）
3. 標準偏差は何を表す？ → 平均のまわりの散らばりの大きさ（元の単位）

### 2｜意味をつかむ：こんなときに標準化する　{{power:P3}}

値そのものではなく、「その集団の中でどのあたりにあるか」を言いたいときに標準化する。

::: ask 平均やばらつきが違うものどうしを比べたい（別の店・別の科目）
→ **z得点**。平均を引いて、標準偏差で割る。
:::

::: ask 「どれくらい珍しい値か」を知りたい
→ **|z| の大きさ**。2を超えると珍しい、3を超えるとかなり珍しい目安。
:::

::: ask 分布の左右の偏りや裾の重さを数で表したい
→ **歪度・尖度**。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
z=\frac{x-\mu}{\sigma}
$$

| 記号 | 意味（店舗Aの例） |
| --- | --- |
| x | 調べたい値（70万円） |
| μ | その集団の平均（50万円） |
| σ | その集団の標準偏差（10万円） |
| z | 平均から標準偏差いくつ分か（2） |

**式を言葉で読む**：分子の x−μ は「平均からいくら離れているか」（元の単位）。それを σ で割ると平均から「**標準偏差 σ いくつ分**」離れているかになり、単位が消える。z＝2 なら平均より標準偏差2つ分上、z＝−1 なら1つ分下。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　入口の店舗A（平均50万円・標準偏差10万円）の70万円の日と、店舗B（平均80万円・標準偏差5万円）の90万円の日。その店にとって「珍しく良い日」なのはどちらか。

1. 店舗A：z＝(70−50)÷10＝**2**
2. 店舗B：z＝(90−80)÷5＝**2**
3. どちらも「平均より標準偏差2つ分上」で、**同じくらい珍しい**

{{lab:LAB-z@s1-z}}

::: key
金額の差だけ見るとAの方が「よく伸びた」ように見えるが、その店の普段のばらつきで割ると同じ位置。**標準化は「その集団の中での位置」をそろえる**。ただし分布の形（歪み）は変わらない。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-z@s1-sigma}}

1. **予想**：ラボの課題カードで、標準偏差が20に広がった店の70の z得点を入れる。
2. **操作**：結果を見たら、標準偏差・平均・値をそれぞれ −／＋ で動かす。
3. **観察**：z が大きくなるのはどう動かしたときか、小さくなるのはどう動かしたときか。
4. **説明**：「同じ20の差でも、標準偏差が□ほど z は小さくなる。なぜなら□」を1文で書く。
5. **ラボなしで**：平均80・標準偏差5の店で85万円の日の z は？

::: toggle 答え（書いてから開く）
- **観察**：標準偏差を広げると z は小さくなり（20なら z＝1）、狭めると大きくなる。値を上げるか平均を下げると z は大きくなる。
- **説明の例**：「同じ20の差でも、標準偏差が大きいほど z は小さくなる。ふだんから大きく上下する集団では、20の差はよくあることだから」
- **ラボなしで**：(85−80)÷5＝**1**。平均より標準偏差1つ分上。
:::
