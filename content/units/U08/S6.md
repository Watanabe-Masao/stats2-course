### 探究｜全店が同じ日に z＝2 になった

本部の画面は、各店の日販を、その店の過去28日の平均と標準偏差で標準化した z で表し、全店を1枚の図に重ねている。15日は、4店がそろって z が2前後になった。担当者は「15日は全店で特別なことがあった。全店で同じくらい売れた」と書いた。

| 店（過去28日の平均・標準偏差） | 15日の日販 |
| --- | --- |
| 大型店（250万円・40万円） | 330万円 |
| 中型店（150万円・20万円） | 190万円 |
| 小型店（40万円・5万円） | 50万円 |
| 駅前店（120万円・15万円） | 153万円 |

聞き取ると、次のことが分かった。
- 15日は多くの会社の給料日だった
- 大型店と中型店の近くでは、15日に地域のお祭りがあった
- 4店とも、この28日に特売や欠品はなかった
- 物差しにした15日の前の28日には、前の月の15日（給料日）が入っていない

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 担当者の文のどこを確かめるかを、自分で問いにする（例：何で「同じくらい」と言っているか・なぜそろったか）
2. ラボで4店の z を出し、平均からの金額の差と、平均に対する伸び率も計算する
3. 4店がそろって z＝2 前後になったことから、統計で言えることと言えないことを分ける
4. そろった理由の読み方（2つ以上）を書く
5. 本部の画面に何を出すかを決める（下の課題）

**統計で言えること（各店の過去28日の平均と標準偏差が、その店のふだんを表しているとみて）**：z は大型店・中型店・小型店が2、駅前店が2.2。平均からの金額の差は、大型店80万円・中型店40万円・小型店10万円・駅前店33万円で、合わせて163万円。そのうち大型店が約49% を占める。平均に対する伸び率は、大型店32%・中型店約27%・小型店25%・駅前店27.5%。

「同じくらい」の意味は、指標で変わる。z で見れば、それぞれの店のふだんのばらつきに対して同じ位置。伸び率で見ても、ほぼそろっている。金額で見れば、大型店（80万円）と小型店（10万円）で8倍違う。z の図は店の大きさを消して重ねているので、どの店が全体の伸びを作ったかは見えない。

4店の日販がそれぞれ正規分布に近く、互いに無関係に動くなら、1つの店で z が2以上になるのは約2.3%、4店がそろうのはその4乗で、ほとんど起きない。だから、4店が互いに無関係に動いたとは考えにくい。ただし、4店に同じ理由があったのか、別々の理由が同じ日に重なったのか、記録の側に理由があるのかは、z からは分からない。また、物差しの28日に給料日が入っていないので、z＝2 は「給料日のない28日と比べて」珍しいという意味で、1年を通して珍しいとは限らない。

**解釈の例**：
- 給料日で、どの店にも買い物の客が増えた。4店に共通する理由
- 大型店と中型店はお祭りで伸び、小型店と駅前店は給料日で伸びた。同じ z でも、理由は店で違う
- 記録の側の理由：15日の集計に、前日の夜の売上の一部が混ざった（4店で同じ集計の仕組みを使っている）

どれが当たるかは、15日の4店の z だけからは決められない。

**統計の外で決めること**：本部の画面で、何を見たいか。店ごとの「いつもと違う日」を見つけたいなら z、全社の売上の伸びと、その内訳（どの店が作ったか）を見たいなら金額。
:::

### 課題｜本部の画面に何を出すか

**問い**　本部の毎朝の画面に、各店の日販をどう出すか。

- **ア**：今のまま、z だけを重ねて出す
- **イ**：z の図の横に、各店の平均からの金額の差・伸び率と、全店の伸びに対する割合を並べる
- **ウ**：z の図に、全店の合計の日販を、合計の過去28日の平均と標準偏差で z にした線を1本足す

**判断の材料**：画面はスマホで見るので、1つの図に入れられる線は4本ほど。過去1年分の日販は残っているが、店によっては去年の途中で開店した。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（日販の記録が正しいとみて）**：ア は「いつもと違う日」を店の大きさに関係なく見つけられるが、15日のように、全体の伸び163万円のうち半分を大型店が作ったことが消える。イ は、z でそろった日にも、伸びの内訳が金額で見え、伸び率で「店の大きさに対してどれだけ伸びたか」も見える。ウ は、全社として珍しい日かを1本の線で見られる。ただし合計の標準偏差は、4店の標準偏差（40・20・5・15万円）を足しても、2乗して足しても決まらない。店どうしが一緒に動く日が多いほど大きくなる（分散の和は {{unit:U07}}）。合計の z は、合計の日販の記録から出す。

判断の材料も効く。図に入る線は4本ほどで、今の z の図はすでに4店で4本ある。ウ の線を足すなら、合計の線だけの図に替えるか、図を2枚に分けることになる。1年分の記録を物差しにすれば給料日が入り、毎月の給料日の伸びは「ふつう」に入る。ただし去年の途中で開いた店は物差しの期間がそろわず、開店の前後で合計の日販の物差しも変わる。

**統計の外で決めること**：画面を見る人が何を決めるか。店長に「その店のいつもと違う日」を知らせるなら ア の z、本部が全社の売上とその内訳を管理するなら イ の金額と伸び率、全社で特別な日だったかを見たいなら ウ の線。スマホの画面に入る量に合わせて、z の図と金額の表を分けてもよい。どれを選んでも、z の物差し（どの期間と比べたか）を画面に書く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 自分の問いが、指標の選び方（何で同じと言うか）か、理由の切り分け（なぜそろったか）かを言えたか |
| 仮定 | z の基準（過去28日）が、店のふだんを表すかを確かめたか |
| 方法 | z・金額の差・伸び率を出し、全体の伸び（163万円）の内訳を計算したか |
| 検証 | 物差しの期間を変えたら（給料日を入れたら）z がどう動くかを、小さな例で確かめたか |
| 切り分け | 言えること（4店が無関係に動いたとは考えにくい）と、言えないこと（同じ理由か、別々の理由の重なりか）を分けたか |
| 解釈 | そろった理由の読み方を2つ以上並べ、画面に出すものを書いたか |
