### {{icon:lab}} 使うラボ

「標本を並べる」で n を変え、くわしくの x̄ の標準偏差がどう縮むかを見る。「戻す・戻さない」で N を大きくし、2つの選び方の差がどう消えるかを見る。予測して当てる場ではない。動かして、なぜそうなるかを自分の言葉で説明する。

### なぜ？｜なぜ「くじで選ぶ」と、選び方のばらつきを計算できるのか

人が選ぶと、どの組み合わせがどの確率で選ばれたかが分からない。くじ（乱数）で選ぶと、確率を選ぶ側が決めている。単純無作為抽出なら、5店から2店の選び方10通りがどれも 1/10 なので、x̄ の値の出方（4〜10）をすべて書き出せる。

ここで使っているのは「選ばれ方の確率」で、店の値の分布（正規分布かどうか）ではない。無作為抽出は、データの性質を仮定する代わりに、選び方の偶然を自分で作って計算できる形にする。だから「選び方を確率で決めた」ことが、標本から全体を推し量る根拠になる。

### 1つの数で何が消えるか

「選んだ店の平均 x̄」という1つの数からは、**選び直したらどれだけ変わったか**が消えている。5店（平均7）から2店を選ぶと x̄ は4にも10にもなりうるが、手元の1つの x̄ を見ただけでは、それが7に近い側の値か遠い側の値かは分からない。

もう1つ、「名簿から無作為に選んだ」という言葉からは、**名簿が誰を覆っているか**が消えている。選び方が無作為でも、名簿の外の店や人は選ばれる確率が0で、x̄ のばらつきの計算にも入っていない。

### 本当に？｜戻さずに選ぶと、選ぶたびの独立が崩れる

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

次の単元からの x̄ の散らばりの式（σ÷√n）は、1回ごとの選び方が独立（戻して選ぶ）という前提で作る。けれども調査では、同じ店を2回調べないよう戻さずに選ぶ。戻さずに選ぶと、1店目に大きい値の店が出れば、2店目は残りの小さい値の店から選ぶことになり、2つの値は打ち消し合う向きに動く。その分だけ x̄ の散らばりは小さくなり、σ÷√n に √((N−n)/(N−1)) を掛けた値になる（有限母集団修正）。

N＝5・n＝2 なら √(3/4)≒0.866 倍で、無視できない。n＝N（全数調査）では0になる。N＝10000・n＝100（抽出率0.01）なら √(9900/9999)≒0.995 で、ほとんど1。だから「どちらの式を使うか」は、選び方（戻すか）だけでなく、抽出率で決まる。抽出率が小さい調査では2つの差は消え、2級ではふつう修正を無視する。

^ この計算を確かめる問題は、2級の範囲なので {{stage:S3}} に置いた。

### ほかでは？｜つながり

- **標本分布**：ラボの「標本を並べる」は、小さな母集団で x̄ の標本分布を全部書き出したもの。実際の調査では書き出せないので、標本分布の平均と散らばりを式で求める（{{unit:U18}}）
- **二項分布と超幾何分布**：戻して数えると二項分布、戻さずに数えると超幾何分布（{{unit:U15}}）。N が n より十分大きいと2つはほぼ同じで、上の修正の話と同じ形
- **確率が等しくない抽出**：売上の大きい店ほど選ばれやすくする、地域ごとに選ぶ数を決める（層別抽出、{{unit:U31}}）など、確率は等しくなくてよい。確率が決まっていれば、選ばれにくい要素の結果を重く数える（1÷包含確率 で重み付けする）と、全体の推定が偏らない
- **実験の無作為化**：無作為抽出は「誰に結論を広げられるか」を支え、実験で処理をくじで割り付ける無作為化は「何の効果と言えるか」を支える（{{unit:U32}}）。どちらも確率を選ぶ側が決める点は同じ

### 説明してみる

::: task
ウェブのアンケートに顧客 5000 人が答え、満足度（5段階）の平均は 4.2 だった。報告書に「回答者が 5000 人と多いので、全顧客の満足度もほぼ 4.2 と言える」と書いてある。この説明を、抽出枠・無作為抽出・偏りの言葉で検討する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること**：回答者は自分から答えた人で、誰がどの確率で答えたかが決まっていない。5000 人に増やして小さくなるのは選び方の偶然のばらつきだけで、答えた人と答えなかった人の違いから来るずれ（偏り）は、何人集めても残る。この取り方では、偏りの大きさを見積もることもできない。

**解釈の例**：満足している人ほど答える気になりやすいなら、4.2 は全顧客より高めに出ている。逆に、不満がある人ほど声を上げたくて答えるなら、低めに出ている。どちらの向きもありうるので、5000 人という数は「全顧客もほぼ 4.2」の根拠にならない。

**統計の外で確かめること**：アンケートの案内が誰に届いたか（ウェブを見ない顧客は枠の外）と、回答者の年齢・利用回数を顧客台帳と比べた違い。
:::
