### {{icon:lab}} 使うラボ

「標本を並べる」で、表示される σ（全体の値の標準偏差）から σ÷√n を自分で計算し、表・式の欄の x̄ の標準偏差と比べる。n を1から N まで動かし、2つの差がどう変わるかを見る。「戻す・戻さない」では、名簿の数 N を大きくすると、同じ件を2回選ぶ確率がどう変わるかを見る。予測して当てる場ではない。動かして、なぜそうなるかを自分の言葉で説明する。

### なぜ？｜なぜ「くじで選ぶ」と、選び方のばらつきを計算できるのか

人が選ぶと、どの組み合わせがどの確率で選ばれたかが分からない。くじ（乱数）で選ぶと、確率を選ぶ側が決めている。5店の値 3・5・7・9・11（平均7）から2店を単純無作為抽出するなら、選び方10通りがどれも 1/10 なので、x̄ がどの値をどの確率でとるか（4〜10）をすべて書き出せる。

ここで使っているのは「選ばれ方の確率」で、店の値の分布（正規分布かどうか）ではない。無作為抽出は、データの性質を仮定する代わりに、選び方の偶然を自分で作って計算できる形にする。だから「選び方を確率で決めた」ことが、標本から抽出枠の中の全体を推し量る根拠になる。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「選んだ店の平均 x̄」という1つの数からは、**選び直したらどれだけ変わったか**が消えている。上の5店から2店を選ぶと x̄ は4にも10にもなりうるが、手元の1つの x̄ を見ただけでは、それが7に近い側の値か遠い側の値かは分からない。

もう1つ、「名簿から無作為に選んだ」という言葉からは、**名簿が誰を覆っているか**が消えている。選び方が無作為でも、名簿の外の店や人は選ばれる確率が0で、x̄ の標準偏差の計算にも入っていない。

### 本当に？｜戻さずに選ぶと、選ぶたびの独立が崩れる

x̄ の標準偏差の式 σ÷√n（{{unit:U18}} で学ぶ。σ は全体の値の標準偏差で、全体の数 N で割って出す。上の5店なら √8≒2.83）は、1回ごとの選び方が独立（戻して選ぶ）という前提で作る。けれども調査では、同じ店を2回調べないよう戻さずに選ぶ。戻さずに選ぶと、1店目に大きい値の店が出れば、残りの店の平均は少し小さくなり、2店目は小さめに出やすい。2つの値が打ち消し合う向きに動くので、その分だけ x̄ の標準偏差は小さくなり、σ÷√n に √((N−n)/(N−1)) を掛けた値になる（有限母集団修正）。

N＝5・n＝2 なら √(3/4)≒0.866 倍で、無視できない。n＝N（全数調査）では0になる。N＝10000・n＝100（抽出率0.01）なら √(9900/9999)≒0.995 で、ほとんど1。だから「どちらの式を使うか」は、選び方（戻すか）だけでなく、抽出率で決まる。抽出率が小さい調査では2つの差は消え、2級ではふつう修正を無視する。

^ この計算を確かめる問題は、2級の範囲なので {{stage:S3}} に置いた。

### ほかでは？｜つながり

- **標本分布**：ラボの「標本を並べる」は、小さな母集団で x̄ の標本分布を全部書き出したもの。実際の調査では書き出せないので、標本分布の平均と標準偏差を式で求める（{{unit:U18}}）
- **二項分布と超幾何分布**：戻して数えると二項分布、戻さずに数えると超幾何分布（{{unit:U15}}）。超幾何分布の分散は、二項分布の分散 np(1−p) に同じ (N−n)/(N−1) を掛けた形で、上の修正と同じことが起きている
- **確率が等しくない抽出**：売上の大きい店ほど選ばれやすくする、地域ごとに店の数に比例しない数を割り当てる（層別抽出、{{unit:U31}}）など、確率は等しくなくてよい。確率が決まっていれば、選ばれにくい要素の結果を重く数える（1÷包含確率 で重み付けする）と、全体の推定が偏らない。ただし確率が0の要素（枠の外）は、どう重みを付けても戻せない
- **実験の無作為化**：無作為抽出は「誰に結論を広げられるか」を支え、実験で処理をくじで割り付ける無作為化は「何の効果と言えるか」を支える（{{unit:U32}}）。どちらも確率を選ぶ側が決める点は同じ

### 説明してみる

::: task
ある地区の全40店のうち30店を、戻さずに単純無作為抽出して廃棄率を調べた。報告書は、x̄ の標準偏差を σ÷√30 で見積もっている。この見積もりは、実際の x̄ の標準偏差と比べて大きいか小さいか。修正を使うべきかを、「何に結論を広げたいか」と合わせて検討する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること**：抽出率は 30÷40＝0.75 と大きい。この40店について言うなら、x̄ の標準偏差は σ÷√30 に √((40−30)/(40−1))＝√(10/39)≒0.51 を掛けた値で、報告書の見積もりは約2倍に大きすぎる。選ばなかったのは10店だけなので、x̄ は40店の平均から大きくはずれようがない。

**解釈の例**：
- 結論を「今のこの40店」に広げたいなら、40店が母集団で、修正を使うのが筋。全数に近い調査なので、幅は小さくてよい
- 結論を「この地区で同じやり方をしている店（これから開く店も含む）」の仕組みについて言いたいなら、40店はその仕組みから出た一部とみなし、修正を使わない σ÷√30 で考える読み方もある

**統計の外で決めること**：この調査の結論を、今の40店の管理に使うのか、これからの店の基準づくりに使うのか。どちらの目的かで、使う式が変わる。
:::
