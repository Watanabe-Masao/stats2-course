1. 母集団＝結論を広げたい全体（地域の全店）、抽出枠＝選ぶのに使う名簿（台帳の店）、標本＝枠から選んで調べた一部（10店）。

3. 無作為＝乱数などで、どの組み合わせも同じ確率になるように選ぶ。適当に選ぶと、選ぶ人の好みや手間が入る。

### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：台帳から選んだ10店の結果を「台帳の100店」までしか広げない理由**

- **条件**：台帳の100店から単純無作為抽出で10店を選んだとき
- **対象と結論**：10店の結果から言えるのは台帳の100店について。台帳に載らない新店5店には広げられない
- **根拠**：新店は選ばれる確率が0で、標本に入る可能性がないから。無作為に選んでも、標本を大きくしても、枠の外の情報は入らない
- **成り立たない場合**：新店が台帳の店と同じ性質だと別の根拠（立地・規模が同じなど）で言える場合は、その根拠を添えて広げることはありうる

::: toggle つなげると（お手本の文）
「台帳の100店から単純無作為抽出で10店を選んだなら、結果から言えるのは台帳の100店についてである。台帳に載らない新店5店は選ばれる確率が0で、標本を大きくしてもその情報は入らないからである。ただし新店が台帳の店と同じ性質だと別に示せる場合は、その根拠を添えて広げられることもある。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「店頭で、なるべくいろいろな人に声をかけて100人に聞いたので、無作為に選べています。人数も100人と多いので、市内の全住民の意見と考えてよいです。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 声をかける人を担当者が選んでいるので、無作為ではない（どの人の選ばれる確率も決まっていない）。
- 店頭にいる人が抽出枠で、店に来ない住民は選ばれない。人数を増やしても、この偏りは消えない。

**言い直しの例**

「店頭で担当者が声をかけて選んだ100人は、無作為抽出ではない。来店しない住民は選ばれようがないので、結果は『この店に来た客のうち声をかけやすかった人』の意見であり、市内の全住民の意見とは言えない。」
:::

::: toggle 取り違えやすい言葉
- **「母集団」と「抽出枠」**：母集団＝結論を広げたい範囲／抽出枠＝実際に選ぶときに使った名簿・台帳。ずれた分には広げられない
- **「無作為」と「適当」**：無作為＝乱数などで確率を決めて選ぶ／適当＝選ぶ人の判断が入る
- **「全数調査」と「誤差なし」**：全数調査は選び方による偶然のぶれがないだけで、測り間違い・記入漏れ・未回答の誤りは残る
- **「標本の大きさ n」と「標本の数」**：n は1つの標本に含まれる件数。「標本を10個取る」と言うと、取り直しを10回する意味になる
:::

### 言葉の早見

| 言葉 | 意味 |
| --- | --- |
| 母集団 | 結論を広げたい全体 |
| 抽出枠 | 選ぶときに使う名簿・台帳 |
| 標本・標本の大きさ n | 枠から選んで調べた一部・その件数 |
| 単純無作為抽出 | 大きさ n のどの組み合わせも同じ確率で選ぶ |
| 包含確率（抽出率） | ある1件が標本に入る確率 n÷N |
| 標本分布 | 選び方を変えたときの統計量（x̄ など）の散らばり |
