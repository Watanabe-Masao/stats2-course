### 探究｜返ってきたアンケートだけで、会員の満足をどこまで言えるか

会員名簿から単純無作為抽出で 400 人を選んでアンケートを送り、返ってきたのは 160 人。そのうち「満足」と答えたのは 112 人（70%）。本部は「会員の 70% が満足している」と報告したい。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 選び方（名簿から無作為）と、答えるかどうか（本人が決める）を分けて、どこまでが確率で決まっているかを書く
2. 小さな例で検証する：答えなかった 240 人が全員「満足でない」場合と全員「満足」の場合で、送った 400 人の満足の割合を出す
3. 統計で言えることと、答えなかった人についての解釈（2つ以上）を分けて書く
4. 報告の前に、次に確かめる記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること**：送り先 400 人は名簿から無作為に選んだので、ここまでは選ばれ方の確率が決まっている。答えるかどうかは本人が決めたので、返ってきた 160 人は無作為な標本ではない。

- **送った 400 人について**：答えなかった 240 人が全員「満足でない」なら、満足は 112÷400＝28%。全員「満足」なら (112＋240)÷400＝88%。答えなかった人について何も仮定しなければ、言えるのは「28% から 88% の間」まで
- **名簿の会員全体について**：400 人は名簿から選んだ一部なので、上の幅に、さらに選び方の偶然の幅が加わる（区間の作り方は {{unit:U22}}）
- **名簿に載らない会員**：選ばれる確率が0で、この調査の結論には入らない

70% は、答えた人と答えなかった人が同じなら、という仮定を置いたときの1つの値。

**解釈の例**：
- 不満のある人ほど答える気になりにくい（関わりたくない）なら、答えなかった人には不満の人が多く、その満足は 70% より低い。70% は高めの値
- 不満のある人ほど声を上げたくて答えるなら、答えなかった人の満足は 70% より高い。70% は控えめな値

どちらに近いかは、この 160 人の回答の中からは決められない（答えないことによる偏りは {{unit:U31}}）。

**統計の外で決めること・確かめること**：報告で 70% をどう書くか（幅と、答えた人と答えなかった人が同じという仮定を添えるか）。次に確かめるなら、答えなかった人の一部に電話などで聞き、答えた人と違うかを比べる（ただし少人数では幅が大きく、電話にも答えない人が出る）。
:::

### 課題A｜覆面調査（監査）の対象店を選ぶ手順を作る

| 項目 | 書くこと |
| --- | --- |
| 母集団 | 結論を広げたい店の範囲（時点も） |
| 抽出枠 | 選ぶのに使う一覧と、その漏れ（新店・休業店） |
| 選び方 | 番号の振り方と乱数の使い方、選ばれる確率 n÷N |

### 課題B｜少数の店の平均で判断してよいかを確かめる

自分の地区の店（5〜8店）の実際の値（廃棄率・在庫差異など）を「標本を並べる」に入れ、3店だけ選んだときに x̄ がどれだけばらつくかを見る。「3店の平均で全店の傾向を言う」ことがどのくらい危ないかを、x̄ が基準を超える割合で書く。

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 結論を広げたい範囲（母集団）が明確か |
| 仮定 | 抽出枠とその漏れ、選び方、答えなかった人について置いた仮定を書いたか |
| 方法 | 乱数で選ぶ手順と包含確率を示したか |
| 検証 | 小さな例やラボで、選び方によるばらつきを確かめたか |
| 切り分け | 統計で言えること（選び方で決まる範囲・何も仮定しないときの幅）と、言えないこと（答えなかった人の値）を分けたか |
| 解釈 | 答えなかった人についての読み方を2つ以上並べ、次に確かめる記録を書いたか |
