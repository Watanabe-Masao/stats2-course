### 課題A｜覆面調査（監査）の対象店を選ぶ手順を作る

| 項目 | 書くこと |
| --- | --- |
| 母集団 | 結論を広げたい店の範囲（時点も） |
| 抽出枠 | 選ぶのに使う一覧と、その漏れ（新店・休業店） |
| 選び方 | 番号の振り方と乱数の使い方 |
| 確率 | 各店が選ばれる確率 n÷N |

### 課題B｜顧客アンケートの結論の範囲を決める

**問い**　会員名簿から無作為に選んで送るアンケートで、結論を「全顧客」に広げてよいか。会員でない客との違いをどう確かめるかを決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：抽出枠は会員名簿なので、結論は「会員」まで。会員でない客の割合（レシートのうち会員カードなしの割合など）を出し、その割合が大きければ、非会員にも別の方法（店頭で番号を振って選ぶなど）で聞く。

**小さな例で検証**：ラボの「選ばれる確率」で、名簿の件数と名簿の外の件数を自分の店の値にして、覆う割合を出す。

**成り立たない条件と、その先の判断**：会員の中でも返事をくれる人は偏りうる（未回答の偏り）。選び方が無作為でも、返事の段階で偏りが入る（{{unit:U31}}）。
:::

### 課題C｜少数の店の平均で判断してよいかを確かめる

自分の地区の店（5〜8店）の実際の値（廃棄率・在庫差異など）を「標本を並べる」に入れ、3店だけ選んだときに x̄ がどれだけ散らばるかを見る。「3店の平均で全店の傾向を言う」ことがどのくらい危ないかを、x̄ が基準を超える割合で書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 結論を広げたい範囲（母集団）が明確か |
| 仮定 | 抽出枠とその漏れ、選び方を書いたか |
| 方法 | 乱数で選ぶ手順と包含確率を示したか |
| 検証 | 小さな例やラボで、選び方によるぶれを確かめたか |
| 切り分け | 枠の漏れ・未回答など、無作為でも残る偏りを書いたか |
