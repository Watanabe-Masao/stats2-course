### 0｜入口の問い

::: task
本部が「全105店の売場の満足度」を知りたくて、店舗台帳から10店を選んで調べることにした。ところが台帳には、今月開いた新店5店がまだ載っていない。台帳から無作為に選べば、全105店の結論になるか。何を確かめればよいか。
:::

^ まだ答えなくてよい。「誰に結論を広げたいか（母集団）」と「誰を選べたか（抽出枠）」を分け、単純無作為抽出で各店が選ばれる確率を出せるようになるのが初学のゴール。

### 1｜前提チェック（2分）

::: toggle 3問だけ確かめる（答えも中にある）
1. 「全店の平均」と「調べた10店の平均」、母数はどちら？ → 全店の平均（調べた10店の平均は統計量）
2. 5店から2店を選ぶ組み合わせは何通り？ → ₅C₂＝10通り
3. 10通りがどれも同じ確率なら、1通りの確率は？ → 1/10＝0.1

### 2｜意味をつかむ：3つの集まりを分ける　{{power:P3}}

::: ask 結論を広げたいのは誰？
→ **母集団**。例：地域の全105店。
:::

::: ask 実際に選べるのは誰？
→ **抽出枠**（名簿・台帳）。例：台帳に載る100店。母集団とずれると、ずれた分には結論を広げられない。
:::

::: ask 調べたのは誰？
→ **標本**。抽出枠から選んだ10店。**単純無作為抽出**では、乱数などを使い、大きさ10のどの組み合わせも同じ確率で選ぶ。担当者が「適当に」選ぶことや、希望者を募ることとは違う。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
\pi_i=\frac{n}{N}
$$

| 記号 | 意味 |
| --- | --- |
| π_i | 単位 i（1店・1人）が標本に入る確率（**包含確率**） |
| n | 選ぶ数（標本の大きさ） |
| N | **抽出枠**の数（母集団の数ではない） |

**式を言葉で読む**：N 件から n 件を選ぶ組み合わせは NCn 通りで、単純無作為抽出ではどれも同じ確率。ある1件を含む組み合わせの割合を数えると n÷N になる。n÷N は**抽出率**とも呼ぶ。名簿の外の件はどの組み合わせにも入らないので、確率は0。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　店舗台帳に載っている100店から、10店を単純無作為抽出で調査する。ただし台帳に載っていない新店が5店ある。① 台帳上の各店が選ばれる確率は？　② 新店が選ばれる確率は？　③ 調査結果を「全105店」の結論にしてよいか。

1. ① π＝10/100＝**0.1**（どの店も同じ）
2. ② 台帳に無いので選ばれようがない → **0**
3. ③ 結論を言えるのは「台帳に載る100店」まで。新店5店は別に確かめる必要がある

計算の精密さより先に、「誰に結論を広げたいか（母集団）」と「誰を選べたか（抽出枠）」を書き出す。ずれていれば、その差は無作為化でも、標本を大きくしても埋まらない。n を増やして小さくなるのは、選び方による偶然のぶれだけ。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-srs@s1-enum}}

1. **予想**：ラボの課題カードで、10通りの標本のうち x̄ が6〜8に入る割合を入れる。
2. **操作**：結果を見たら、「選ぶ n」を 3 → 4 → 5 と増やす。
3. **観察**：選び方の数、x̄ の最小・最大、μ±1 に入る割合はどう変わるか。
4. **説明**：「n を増やすと x̄ は□になった。なぜなら□」を1文で書く。
5. **ラボなしで**：n＝4 のとき、5通りの x̄ を全部書き、最小と最大を出す。

::: toggle 答え（書いてから開く）
- **観察**：n＝2 では x̄ が4〜10に散らばり、6〜8に入るのは6割。n＝4 では5通りすべてが6〜8に入る。n＝5 は全数調査で、x̄ はいつも7。
- **説明の例**：「n を増やすと x̄ は μ＝7 の近くに集まった。多くの店の値を平均すると、大きい値と小さい値が打ち消し合うから」
- **ラボなしで**：抜く1店が 3・5・7・9・11 のとき、x̄ は (35−抜く値)÷4 で **8**・7.5・7・6.5・**6**。最小6、最大8。
:::

- 間違えた所と、その理由：
- 次に再開する場所：

::: summary
1. 母集団（広げたい範囲）・抽出枠（選べる範囲）・標本（調べた一部）を分ける。枠の外には結論を広げない。
2. 単純無作為抽出では、どの組み合わせも同じ確率。各単位の包含確率は n÷N（抽出率）。
3. 標本平均 x̄ は選び方で変わる。全部の選び方で平均すると μ に一致し、n を増やすと μ の近くに集まる。
:::
