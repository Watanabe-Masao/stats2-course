**お手本：正規分布で「120人を超える日」の割合を出せる理由**

- **条件**：1日の来店客数が、平均100人・標準偏差10人の正規分布に従うとみなせるとき
- **対象と結論**：120人を超える日の割合は、z＝2 より右の面積で約2.3%になる
- **根拠**：連続の量の確率は曲線の下の面積で、標準化すると標準正規分布の表（Φ）で面積が引けるから
- **成り立たない場合**：曜日やイベントで客数の分布が左右対称でない、山が2つあるなど、正規分布から大きく外れるときは当てはまらない

::: toggle つなげると（お手本の文）
「来店客数が平均100人・標準偏差10人の正規分布に従うなら、120人を超える日は約2.3%である。連続の量の確率は曲線の下の面積で、標準化すれば標準正規分布の表で面積が引けるからである。ただし客数の分布が左右対称でなかったり、山が2つあったりする場合は当てはまらない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「来店客数は N(100, 10²) なので、ちょうど100人になる確率がいちばん高く、その確率はグラフの高さの0.04くらいです。120人を超えるのは、z＝(120−100)÷100＝0.2 なので、だいたい4割の日です。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 曲線の高さは確率ではない。連続の量として扱う限り、ちょうど100人の確率は0で、確率は区間の面積で考える。
- N(100, 10²) の 10² は分散。標準化で割るのは標準偏差10。z＝(120−100)÷10＝2 で、120人を超えるのは約2.3%。

**言い直しの例**

「来店客数が N(100, 10²) に従うなら、確率は区間の面積で考える。120人の z は (120−100)÷10＝2 なので、120人を超える日は 1−Φ(2)≒2.3% で、50日に1日ほどである。」
:::

::: toggle 取り違えやすい言葉
- **「確率密度」と「確率」**：密度＝曲線の高さ（1を超えることもある）／確率＝区間の上の面積（0〜1）
- **「分散」と「標準偏差」**：N(μ, σ²) の2つ目は分散 σ²。標準化で割るのは標準偏差 σ。N(50, 25) なら σ＝5
- **「率 λ」と「平均 1/λ」**：指数分布の λ は1単位あたりの件数（1時間に2件）。待ち時間の平均はその逆数（0.5時間）
- **「Φ(z)」と表の数**：Φ(z) は z 以下の面積。上側確率（z 以上）や「0から z まで」を載せる表もある
:::

**自己チェック（説明を書いたら）**

- [ ] 確率を面積として書いた（高さと区別した）
- [ ] 標準偏差で割って標準化した（分散で割っていない）
- [ ] 表がどの面積を載せているかを確かめた
- [ ] 正規分布とみなせない場合に触れた

| 分布 | 確率・平均・分散 |
| --- | --- |
| 正規 N(μ, σ²) | Φ(z_b)−Φ(z_a)、平均 μ、分散 σ² |
| 一様 U(a, b) | 幅÷(b−a)、平均 (a＋b)/2、分散 (b−a)²/12 |
| 指数（率 λ） | P(X＞t)＝e^(−λt)、平均 1/λ、分散 1/λ² |
