### 課題A｜欠品を抑える発注数を決める

POS の販売数から、商品ごとに次を作る。

| 項目 | 書くこと |
| --- | --- |
| 平均・標準偏差 | 同じ曜日の販売数（数週分）から出す |
| 当てはまり | ヒストグラムが左右対称の山1つに近いか |
| 欠品の目標 | 何%の日まで欠品を許すか（5%・2.5%など） |
| 発注数 | 平均＋z×標準偏差（上側の z） |

### 課題B｜内容量の目標を決める

**問い**　量り売り（または自社の詰め合わせ）で、表示の重さを下回る割合を決めた水準以下にしたい。平均を上げる案と、ばらつきを減らす案のどちらがよいかを、正規分布で比べる。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：下回る割合を2.5%以下にするなら、表示の重さが z＝−1.96 より左にあればよい。平均＝表示＋1.96×標準偏差。標準偏差2gなら表示より約3.9g、1gに減らせば約2g 上乗せで済む。

**小さな例で検証**：ラボの「正規分布の確率」で、表示500g・標準偏差2g のまま平均を502・504 と動かす。次に平均502のまま標準偏差を1に下げ、下回る割合を比べる。

**成り立たない条件と、その先の判断**：実際の重さが左右対称でない（詰め方の癖で片側に長い裾がある）と、正規分布の計算は下回る割合を小さく見積もる。数十個は実測して確かめる。
:::

### 課題C｜待ち時間の目安を決める

レジ（または問い合わせ）の待ち時間を数日分計り、平均を出す。指数分布とみなして「5分を超える割合」を計算し、実測の割合と比べる。時間帯で平均が大きく違うときは、時間帯ごとに分けて計算し直す。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 基準の値と、求めるもの（割合か値か）が明確か |
| 仮定 | 正規・一様・指数のどれとみなしたか、その理由を書いたか |
| 方法 | 標準化し、表の向き（上側か下側か）を確かめたか |
| 検証 | 実データのヒストグラムや実測の割合と比べたか |
| 切り分け | 歪み・山が2つ・率が変わる場合を書いたか |
