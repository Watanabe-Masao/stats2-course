### 0｜入口の問い

::: task
1日の来店客数は平均100人・標準偏差10人。「平均より2割多い120人分の弁当を用意すれば、まず足りる」という案が出た。120人を超える日はどれくらいありそうか。何が分かれば答えられるか。
:::

^ まだ答えなくてよい。重さ・時間・人数のような量が「〇〇以上」「〇〇の間」になる確率を、曲線の下の面積として求められるようになるのが初学のゴール。

### 2｜意味をつかむ：連続の量は「面積」が確率　{{power:P3}}

::: ask 重さ 60.000…g ちょうどになる確率は？
→ **0**。連続の量では1点ちょうどは幅0で、面積も0。確率は「〇〇の間」「〇〇以上」のように区間で考える。
:::

::: ask 曲線の高さ f(x) は確率か？
→ **確率ではない**。高さは「その辺りの込み具合」（確率密度）。区間の上の**面積が確率**で、全体の面積は1。
:::

::: ask 区間の確率はどう出す？
→ x 以下の面積 F(x)＝P(X≦x)（累積分布関数）を使い、**F(b)−F(a)**。正規分布では F の代わりに標準化した Φ(z) の表を引く。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
Z=\frac{X-\mu}{\sigma}\qquad P(a\le X\le b)=\Phi(z_b)-\Phi(z_a)
$$

| 記号 | 意味 |
| --- | --- |
| μ・σ | 平均・標準偏差（N(μ, σ²) の σ² は分散） |
| z_a・z_b | 区間の端 a・b を標準化した値 |
| Φ(z) | 標準正規分布で z 以下になる面積（表で引く） |

**式を言葉で読む**：どんな平均・標準偏差の正規分布も、z＝(値−平均)÷標準偏差 で「平均0・標準偏差1」の標準正規分布にそろえられる。だから表は1枚で足りる。区間の確率は「b 以下の面積」から「a 以下の面積」を引く。

**連続分布の代表3つ**

| 分布 | 使う場面 | 確率の出し方 |
| --- | --- | --- |
| 正規 N(μ, σ²) | 左右対称な量（重さ・点数） | 標準化して Φ の差 |
| 一様 U(a, b) | どこも同じ起きやすさ | 区間の幅÷全体の幅 |
| 指数（率 λ） | 一定の率で起きる事の待ち時間 | t より長く待つ＝e^(−λt) |

```txt
一様 U(a,b)：高さ 1/(b−a)、平均 (a+b)/2、分散 (b−a)²/12
指数（率λ）：P(X>t)=e^(−λt)、平均 1/λ、分散 1/λ²
```

^ 例：U(0, 10) で2〜5の確率は幅3÷10＝0.3。率2/時間の指数分布で1時間を超えて待つ確率は e⁻²≒0.135335。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　1日の来店客数は平均100人・標準偏差10人の正規分布に従う。① 90人以上110人以下の確率　② 120人を超える確率　を求めよ。

1. 標準化：90 → (90−100)÷10＝−1、110 → ＋1
2. 表より Φ(1)＝0.8413、Φ(−1)＝1−0.8413＝0.1587
3. ① 0.8413−0.1587＝**0.6826**（約68%）
4. ② 120 → z＝2。P(Z＞2)＝1−Φ(2)＝1−0.9772＝**0.0228**（約2.3%）

^ 表を5桁で引くと Φ(1)＝0.84134・Φ(−1)＝0.15866 で、①は0.68268（4桁なら0.6827）。引いた表の桁で最後の1桁がずれることがあるが、どちらも正しい。

{{lab:LAB-cont@s1-norm}}

| 平均からの幅 | 入る確率 |
| --- | --- |
| ±1σ | 約68.3% |
| ±1.96σ | 95% |
| ±2σ | 約95.4% |
| ±3σ | 約99.7% |

::: key
確率は曲線の下の面積。正規分布なら「標準化して表を引く」。だいたい3日に2日は90〜110人、120人を超える日は40〜50日に1日程度。ただし実際の客数が正規分布に従うかは、ヒストグラム（{{unit:U05}}）で確かめる。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-cont@s1-band}}

1. **予想**：ラボの課題カードで、80以上120以下（平均±2σ）に入る確率を入れる。
2. **操作**：結果を見たら、σ を5・20 に変え、そのたびに a・b を μ±2σ（σ＝5なら90と110）に合わせ直す。次に a・b を μ±1σ・μ±3σ にする。
3. **観察**：σ を変えても、μ±2σ の内側の確率は変わるか。
4. **説明**：「σ を変えても□だった。なぜなら□」を1文で書く。
5. **ラボなしで**：平均50・標準偏差5 のとき、40以上60以下の確率を z と表で書く。

::: toggle 答え（書いてから開く）
- **観察**：σ を変えても、μ±2σ の内側はいつも約95.4%、μ±1σ は約68.3%、μ±3σ は約99.7%。
- **説明の例**：「σ を5や20に変えても、μ±2σ の内側は約95%のままだった。標準化すると端はいつも z＝±2 になり、確率は z だけで決まるから」
- **ラボなしで**：z は −2 と 2。Φ(2)−Φ(−2)＝0.9772−0.0228＝**0.9544**。
:::
