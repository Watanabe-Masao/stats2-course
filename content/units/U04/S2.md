### 翌日（10分）

**思い出す（何も見ずに）**

- [ ] 4つの尺度を、使える計算が少ない順に言える
- [ ] 間隔尺度と比例尺度の違いを「0」の意味で言える
- [ ] 離散型と連続型の違いを例とともに言える

::: toggle 答え（言ってから開く）
1. 名義 → 順序 → 間隔 → 比例。
2. 間隔尺度の0は「無い」ではない（0℃でも温度はある）ので何倍と言えない。比例尺度の0は「無い」なので何倍と言える。
3. 離散型は数え上げる値（個数・人数）、連続型は途中の値も取れる値（重さ・時間）。
:::

### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：「何倍」と言える条件を説明する**

- **条件**：0が「その量が無い」ことを表すデータ（比例尺度）のとき
- **対象と結論**：2つの値の比（何倍か）に意味がある
- **根拠**：0が共通の出発点なので、単位を変えても（kg→g）比は変わらないから
- **成り立たない場合**：気温℃のように0が任意の位置にある間隔尺度では、単位を変えると比が変わる（℃とKで「何倍」が違う）ので比は意味を持たない

::: toggle つなげると（お手本の文）
「0が『無い』を表す比例尺度のデータなら、何倍と言える。なぜなら0が共通の出発点なので、単位を変えても比が変わらないから。ただし気温℃のような間隔尺度では、単位によって比が変わるので何倍とは言えない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「満足度は1〜5の数字なので量的変数で、平均を出して比べられる。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 数字で記録しても、満足度の元の性質は順序尺度（質的）。
- 平均を使うには「1と2の差」と「4と5の差」が等しいとみなす仮定が必要。

**言い直しの例**

「満足度は1〜5の数字で記録しているが、元は順序尺度の質的変数である。平均を出すなら、各段階の間隔が等しいとみなす仮定を置いていることを明示する。仮定を置かないなら、中央値や各段階の割合で比べる。」
:::

::: toggle 取り違えやすい言葉
- **「数値データ」**：数字で書かれたデータ（店番・郵便番号も含む）／量を表すデータ（量的変数）→ 「数字で書かれている」ことと「量である」ことを分けて言う
- **「平均できる」**：計算はできる（どんな数字でも足して割れる）／意味がある（尺度が間隔以上）→ 説明では「意味のある平均か」を言う
- **「離散」と「整数」**：離散型＝数え上げる量（個数）／整数で表示されているだけ＝体重を「65kg」と丸めても、元は連続型
:::

- [ ] 「計算できる」と「意味がある」を区別した
