### 探究｜店番の図は、名義だから意味がないのか

本部の担当者が、30店の店番（101〜130）を横軸、今月の売上を縦軸にした図を描き、「店番が大きい店ほど売上が少ない」と書いた。店番101〜110 の10店の売上の平均は 3,200万円、121〜130 の10店は 2,100万円だった。別の人が「店番は名義尺度なので、この図には意味がない」と言った。聞き取ると、次のことが分かった。
- 店番は、開店した順に振った（同じ年に5店まとめて開いた年もあれば、次の店まで10年あいたこともある）
- 店番の小さい店には、駅前の古い店が多い
- 店番121〜130 は、ここ5年で開いた郊外の店

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. この店番が、振り方から持っている情報（何を区別し、何の順を表すか）を書く
2. 店番の差（101と111 は10違う）に意味があるかを書く
3. 図から、統計で言えることと言えないことを分ける
4. 「店番が大きいほど売上が少ない」理由の読み方（2つ以上）を書く
5. 次にどのデータを足すかを決める（下の課題）

{{lab:LAB-scale@s6-year}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（30店の今月の売上を同じ集計の仕方で出したとみて）**：店番の小さい10店の平均は 3,200万円、大きい10店は 2,100万円で、この30店では、開店が早い店ほど今月の売上が多い傾向がある。店番は店を区別するラベル（名義）として振ったが、開店した順に振ったので、開店の順（順序）の情報も持っている。「名義だから意味がない」は言い過ぎで、開店の順としてなら読める。

**この図だけでは言えないこと**：店番の差は、開店の間の年数ではない。同じ年に開いた5店は店番が4つ違っても0年、10年あいた2店は店番が1つ違うだけ。だから「店番が10大きいと売上が○万円少ない」のような、差の大きさで読むことはできない（間隔尺度ではない）。開店が早いことが売上を増やした、とも言えない。古い店に駅前が多く、開店の順と立地が重なっている。

**解釈の例**：
- 古い店ほど常連の客が積み重なっていて、売上が多い
- 古い店に駅前が多く、人通りの違いで売上が違う。開店の順そのものは関係ない
- 新しい郊外の店は開いてから日が浅く、まだ地域に知られていない。何年かたてば追いつく

どの読み方が当たるかは、店番と売上の図だけからは決められない。

**統計の外で決めること**：この図を何に使うか（次の店をどこに出すか、今の店の売上の見込みか）。使い道で、足すデータが変わる。
:::

### 課題｜開店の順と立地を分けるデータを選ぶ

**問い**　「店番が大きいほど売上が少ない」の読み方を絞りたい。次の作業で、どのデータを足すか。

- **ア**：店番の代わりに開店年月を入れ、開店からの年数を横軸にして描き直す
- **イ**：店ごとに立地（駅前・郊外）を記録し、立地ごとに開店の順と売上を見る
- **ウ**：開店から5年以内の店だけで、駅前の店と郊外の店の売上を比べる

**判断の材料**：開店年月は台帳にあり、すぐ出せる。立地の区分は本部で決め直す必要があり、1日かかる。開店から5年以内の店のうち、駅前の店は2店しかない。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（店ごとの記録が正しいとみて）**：ア は横軸が開店からの年数になり、0 が「開いたばかり」の比例尺度になるので、「年数が10年長い店ほど」と差で読めるようになる。ただし立地の違いは混ざったまま。イ は立地で分けて、それぞれの中で開店の順と売上を見られる。駅前の店の中でも古い店ほど売上が多ければ、古さの読み方に近づく。ウ は年数をそろえて立地を比べるが、駅前が2店しかないので、その2店の事情（大きさ・競合店）で平均が大きく動く。古さと立地が重なっているので、どれか1つでは分けきれない（重なった要因の分け方は {{unit:U32}}）。

**統計の外で決めること**：次の店をどこに出すかを決めたいなら、立地の比べ方（イ）が要る。今の店の売上の見込みを立てたいなら、ア で開店からの年数を見る。ア は今日できるので、先に描き直し、イ を足すかはそのあとで決めてもよい。どれを選んでも、店番を横軸にした図を報告に使うなら、「店番は開店の順で、差は年数ではない」と書き添える。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 図で何を知りたいか（開店の順か、立地か）を書いたか |
| 仮定 | 店番の振り方から、どの尺度として読むかを決めたか |
| 方法 | 差で読むために、開店からの年数のような 0 のある数を選んだか |
| 検証 | ラボで、年の差は 0 の置き方で変わらず、何倍は変わることを確かめたか |
| 切り分け | 言えること（この30店の、開店の順と売上の傾向）と、言えないこと（差の大きさ・原因）を分けたか |
| 解釈 | 売上が少ない理由の読み方を2つ以上並べ、次に足すデータを書いたか |
