### 課題A｜売場データの「列の辞書」を作る

自分の職場のデータ（POS・発注・勤怠など）から列を8つ選び、次の表を作る。

| 項目 | 書くこと |
| --- | --- |
| 列名 | 例：店番、数量、鮮度ランク |
| 尺度・型 | 名義／順序／間隔／比例、離散／連続 |
| 使ってよい計算 | 数える・中央値・平均・何倍 |
| 合うグラフ | 棒グラフ・ヒストグラムなど |
| してはいけない計算 | 例：店番の合計 |

### 課題B｜満足度アンケートを、集計方法から先に設計する

**問い**　売場の満足度を2店で比べたい。質問と選択肢を作り、**集めた後にどう比べるか**を先に決める。その方法の弱点も書く。

::: toggle 1つの考え方の例（自分で設計してから開く）
**質問と選択肢**：「今日の売場に満足しましたか」とても不満／不満／普通／満足／とても満足の5段階。

**比べ方（先に決める）**：主な指標は「満足」以上の割合（順番しか使わない）。補助として中央値。平均点は「段階の間隔は等しい」と仮定したときの参考値として、仮定を書き添えて出す。

**小さな例で検証**：ラボの「満足度の平均」のA店・B店で試す。1〜5点の平均では B店（3.80）が上、「とても満足」を4.1点にすると A店（3.40）が上になる。一方「満足」以上の割合は A店40%・B店70% で、点のつけ方に関係なく B店が上。主な指標を割合にしておけば、結論が仮定に左右されない。

**弱点**：割合は「普通」と「とても不満」の違いを区別しない。B店は「とても不満」も20%いるので、不満の多さも別に見る（「不満」以下の割合：A店0%、B店30%）。
:::

### 課題C｜自分の職場向けの「尺度判定チェッカー」を作る

4つの質問を、職場の言葉に言い換えた判定表を作る（例：「その番号を足して意味がある？」「0のとき、何も無い？」）。データの列10個で試し、迷った列と、迷った理由を書き足して判定表を直す。

### 課題D｜他の分野で「迷う量」を調べる

偏差値・震度・星の明るさ（等級）・西暦・体温など、どの尺度か迷う量を3つ選ぶ。それぞれ「0は何を表すか」「差は同じ意味か」を調べ、尺度を判定し、判定が分かれる理由を書く。

### {{icon:lab}} 検証に使う

自分の判定や設計を、ラボの4つのモードで確かめる（判定は「尺度を判定」、何倍の扱いは「単位を変える」、アンケートの比べ方は「満足度の平均」、まとめ方は「階級にまとめる」）。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何を比べたいか（目的）が明確か |
| 仮定 | 等間隔などの仮定を明示したか |
| 方法 | 尺度に合った計算・グラフを選んだか |
| 検証 | 小さな例やラボで確かめたか |
| 限界 | その方法で見えないことを書いたか |
