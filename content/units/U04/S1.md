### 0｜入口の問い

::: task
売場の会議で、次の3つの発言が出た。どれが正しく、どれがおかしいか。
- 「今日の最高気温は20℃で、昨日の10℃の2倍暑い」
- 「今月の販売個数は先月の2倍になった」
- 「店番の平均は305なので、うちの地区は305番店あたりが標準だ」
:::

^ まだ答えなくてよい。この3つを理由つきで仕分けられるようになるのが初学のゴール。

### 2｜意味をつかむ：その数字は「どこまで計算してよい数字」か　{{power:P3}}

数字が書いてあっても、どんな計算をしてよいかはデータによって違う。上から順に4つの質問に答え、「はい」になった所で止める。

::: ask 質問1：区別するためのラベルだけ？
→ はい：**名義尺度**（店番、性別、血液型）。使えるのは「同じか、違うか（＝ ≠）」だけ。
:::

::: ask 質問2：順番に意味はあるが、間隔はそろっていない？
→ はい：**順序尺度**（満足度、順位）。大小（＜ ＞）まで使える。
:::

::: ask 質問3：差に同じ意味があるが、0が「無い」ではない？
→ はい：**間隔尺度**（気温℃、西暦）。差（＋ −）まで使える。
:::

::: ask 質問4：0が「無い」を表し、何倍と言える？
→ はい：**比例尺度**（販売個数、重さ、売上）。比（× ÷）まで使える。
:::

{{fig:FIG-U04-scale}}

^ 図の読み方：右の段ほど、意味のある計算が増える。左の2段は質的変数、右の2段は量的変数。「何倍」が言えるのは一番右の段だけ。

名義・順序は**質的変数**、間隔・比例は**量的変数**。量的変数のうち、個数のように数え上げる値は**離散型**、重さや時間のように途中の値も取れる値は**連続型**。

| 種類 | 尺度・型 |
| --- | --- |
| 質的変数 | 名義尺度・順序尺度 |
| 量的変数 | 間隔尺度・比例尺度（それぞれ離散型か連続型） |

### 3｜構造を読む：「0」と「単位」で何倍が決まる　{{power:P1}}

$$
\frac{20\,^{\circ}\mathrm{C}}{10\,^{\circ}\mathrm{C}}=2
\qquad
\frac{293.15\,\mathrm{K}}{283.15\,\mathrm{K}}\approx 1.035
$$

| 見るところ | 意味（気温の例） |
| --- | --- |
| 分子・分母 | 同じ2日の気温を、℃とK（絶対温度）で表した値 |
| ℃の0 | 水が凍る温度。「温度が無い」ではない |
| Kの0 | これ以上下がらない温度（−273.15℃） |
| 比の値 | 単位を変えると 2 → 1.035 に変わる |

**式を言葉で読む**：同じ2日なのに、単位を変えると「何倍」が変わる。0の位置を人が決めた単位（間隔尺度）では、**比は単位の選び方で決まってしまうので意味がない**。重さ（kg→g）のように0が「無い」を表す量なら、単位を変えても比は変わらない。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　次の4つのデータの尺度を判定し、「平均」と「何倍」を使ってよいか答えよ。①店番　②満足度（不満/普通/満足）　③気温（℃）　④販売個数

| データ | 尺度と、平均・何倍 |
| --- | --- |
| ①店番 | 名義。平均✕・何倍✕ |
| ②満足度 | 順序。平均△（等間隔とみなすときだけ）・何倍✕ |
| ③気温℃ | 間隔。平均◯・何倍✕ |
| ④販売個数 | 比例。平均◯・何倍◯ |

1. ①は質問1で「はい」：番号は店を区別するためのラベル。
2. ②は質問2で「はい」：不満＜普通＜満足の順番はあるが、間隔がそろっているとは言えない。
3. ③は質問3で「はい」：10℃と20℃の差は、20℃と30℃の差と同じ意味。ただし0℃は「温度が無い」ではない。
4. ④は質問4で「はい」：0個は「売れていない」。20個は10個の2倍。

::: key
数字が書いてあることと、その計算をしてよいことは別。店番305の平均には意味がなく、20℃は10℃の「2倍暑い」とは言えない（0℃は「温度が無い」ではないから）。
:::

### 5｜実験：予想→操作→観察→説明→ラボなしで解く　{{icon:lab}}

{{lab:LAB-scale@s1-temp}}

1. **予想**：A＝10℃、B＝20℃ を絶対温度（K）で表すと、B÷A は何倍か。ラボの課題カードに入れる（℉ のときと「差」も予想して書いておく）。
2. **操作**：結果を見たら A・B を −／＋ で動かす。次にデータを「重さ」「売上金額」に切り替えて同じことをする。
3. **観察**：B÷A が単位で変わったのはどちらか。差はどうだったか。
4. **説明**：「□尺度では単位を変えると何倍が変わるので、何倍とは言えない。□尺度では変わらない」を1文で書く。
5. **ラボなしで**：「西暦2020年は1010年の2倍」は正しいか。

::: toggle 答え（書いてから開く）
- **観察**：気温は ℃ で 2.000、K で 1.035、℉ で 1.360 と、単位ごとに違う。差は ℃・K で 10、℉ で 18（単位の換算 ×1.8 の分だけ）。重さは kg・g・lb のどれでも 2.000。
- **説明の例**：「間隔尺度では単位を変えると何倍が変わるので、何倍とは言えない。比例尺度では変わらない」
- **ラボなしで**：**正しくない**。西暦は間隔尺度で、西暦0年は「時間が無い」ではない。「2020年は1010年の1010年後」とは言える。
:::
