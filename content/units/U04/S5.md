### なぜ？｜間隔尺度で、比べてよい「比」はあるか

初学では、気温℃の「何倍」は単位で変わるので意味がない、と見た。では、間隔尺度で比べてよい比は1つもないのか。

℃ を ℉ に直す換算は y＝1.8x＋32。B÷A には足し算の＋32 が入るので、単位を変えると変わる。ところが**差**をとると、＋32 は引き算で消え、差は 1.8 倍されるだけになる。だから**差どうしの比**は、どの単位でも同じ。

::: toggle 動かしてから開く
10℃→20℃ の上がり幅は、℃ で 10、℉ で 18。10℃→15℃ の上がり幅は、℃ で 5、℉ で 9。上がり幅の比は、℃ でも ℉ でも 2（18÷9＝10÷5）。K でも 10÷5＝2。

だから間隔尺度でも「今日の上がり幅は、昨日の上がり幅の2倍」とは言える。言えないのは、値そのものの比（20℃は10℃の2倍）。0 の位置を決め直す換算（y＝ax＋b）で変わらない比べ方だけが、そのデータについて意味をもつ。比例尺度では換算が y＝ax だけなので、値そのものの比も変わらない。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

順序のデータでは、平均点は点の付け方で変わるが、中央値や「満足」以上の割合は、順番を保つどんな付け方でも変わらない（初学〜応用で見たこと）。では、変わらない数を選べば、データのことは全部言えたことになるか。

ラボの2店（各100人）は、A店が「普通」60人・「満足」40人、B店が「とても満足」60人・「とても不満」20人・「不満」10人・「満足」10人。中央値は A店が「普通」、B店が「とても満足」。「満足」以上の割合は A店 40%、B店 70%。どちらの数でも B店が上で、点の付け方を動かしても変わらない。

それでも、**B店の100人のうち30人が「不満」以下**だということは、中央値にも「満足」以上の割合にも出てこない。A店は全員が「普通」か「満足」で、不満の客は1人もいない。付け方で変わらない数を選んでも、5段階の分かれ方を1つの数にした時点で、**回答がどう分かれているか**（まとまっているか、両端に分かれているか）が消える。どの数で比べるかは「何を知りたいか」で選び、分かれ方は棒のまま見せる。

### 本当に？｜気温は、いつも間隔尺度か

「気温は間隔尺度なので、何倍とは言えない」は、気温を ℃ や ℉ で記録したときの話。K（絶対温度）の 0 は、これ以上下がらない温度（−273.15℃）で、温度の出発点なので、K で書いた温度は比例尺度。20℃（293.15 K）は 10℃（283.15 K）の約1.035倍、と K の比としては言える。

尺度は、量そのものより、**0 を何に置いて記録したか**で決まる。売場でも、開店時刻（10時・11時）は間隔尺度だが、「開店からの経過時間」（0時間・1時間・2時間）は 0 が「まだ時間が経っていない」なので比例尺度で、「開店2時間後は1時間後の2倍の時間が経った」と言える。

ただし K で比例尺度になっても、「20℃の日は10℃の日より1.035倍暑い」とは言えない。暑さの感じ方は K の比で決まる量ではない。何倍と言えるのは、記録した量（絶対温度）についてだけ。

### ほかでは？｜つながり

- **棒グラフと尺度**：名義・順序は棒グラフ、量はヒストグラム（{{unit:U05}}）。棒の長さは 0 からの量を表す
- **代表値の選び方**：尺度ごとに意味のある代表値（{{unit:U06}}）
- **比を差に変える**：変化率を平均するときの相乗平均（{{unit:U06}}）
- **分かれ方を比べる**：2店の5段階の分かれ方が違うかを確かめる独立性の検定（{{unit:U27}}）
- **カテゴリを式に入れる**：名義の変数を 0 と 1 の列にするダミー変数（{{unit:U30}}）

### 説明してみる

::: task
本部の資料で、A店とB店の今月の平均気温（A店 10℃、B店 20℃）を棒グラフにしたところ、B店の棒がA店の棒のちょうど2倍の長さになった。同じデータを ℉ で描くと、A店 50℉・B店 68℉ で、B店の棒は約1.36倍の長さになる。この棒グラフの描き方のどこに無理があるかを、尺度の言葉で説明する。どう描けばよいかも書く。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（2店の気温を同じ測り方で記録したとみて）**：棒グラフは、0 からの棒の長さで量を表すので、長さの比が「何倍」を主張する。気温 ℃ は間隔尺度で、0℃ は「温度が無い」ではないので、棒の長さの比（2倍）は単位を ℉ に変えると 1.36倍になり、データの性質ではなく単位の選び方で決まっている。単位を変えても変わらないのは差（℃ で 10、℉ で 18。どちらも「A店より B店が10℃分暑い」と同じことを表す）。

**描き方の例**：棒ではなく、縦軸の上の点（または点を結んだ線）で描き、差が読めるようにする。縦軸を 0 から始める必要もない。比べたいのが差なら、「B店は A店より 10℃ 高い」と差を書き添える。

**統計の外で決めること**：何を見せたいか（2店の差か、暑さの感じ方か）。暑さの感じ方を比べたいなら、気温だけでなく湿度なども要り、気温の図だけでは決められない。
:::
