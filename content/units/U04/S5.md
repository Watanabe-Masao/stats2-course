### なぜ？｜間隔尺度で、比べてよい「比」はあるか

初学では、気温℃の「何倍」は単位で変わるので意味がない、と見た。では、間隔尺度で比べてよい比は1つもないのか。

℃ を ℉ に直す換算は y＝1.8x＋32、K に直す換算は y＝x＋273.15。どちらも y＝ax＋b（a＞0）の形で、足し算の b が入るので、値そのものの比 B÷A は単位で変わった。2つの版で、10℃→20℃ と 10℃→15℃ の上がり幅（差 B−A）を、℃・K・℉ で読む。上がり幅どうしの比は、単位で変わるか。

::: toggle 動かしてから開く
10℃→20℃ の上がり幅は、℃ で 10、℉ で 18。10℃→15℃ の上がり幅は、℃ で 5、℉ で 9。上がり幅の比は、℃ でも ℉ でも 2（18÷9＝10÷5）。K でも 10÷5＝2。

差をとると、b は引き算で消え、差は a 倍されるだけになる。だから**差どうしの比**は、どの単位でも同じ。

つまり間隔尺度でも「今日の上がり幅は、昨日の上がり幅の2倍」とは言える。言えないのは、値そのものの比（20℃は10℃の2倍）。0 の位置と目盛りの幅を決め直す換算（y＝ax＋b、a＞0）で変わらない比べ方だけが、そのデータについて意味をもつ。比例尺度では換算が y＝ax だけなので、値そのものの比も変わらない。
:::

### 1つの数で何が消えるか

順序のデータでは、平均点は点の付け方で変わるが、中央値や「満足」以上の割合は、順番を保つどんな付け方でも変わらない（初学〜応用で見たこと）。では、変わらない数を選べば、データのことは全部言えたことになるか。

ラボの2店（各100人）は、A店が「普通」60人・「満足」40人、B店が「とても満足」60人・「とても不満」20人・「不満」10人・「満足」10人。中央値は A店が「普通」、B店が「とても満足」。「満足」以上の割合は A店 40%、B店 70%。どちらの数でも B店が上で、点の付け方を動かしても変わらない。

では、この2つの数で、2店の違いは言い尽くせたか。ラボの棒と、3つの数を見比べる。

::: toggle 動かしてから開く
**B店の100人のうち30人が「不満」以下**だということは、中央値にも「満足」以上の割合にも出てこない。A店は全員が「普通」か「満足」で、不満の客は1人もいない。付け方で変わらない数を選んでも、5段階の分かれ方を1つの数にした時点で、**回答がどう分かれているか**（まとまっているか、両端に分かれているか）が消える。どの数で比べるかは「何を知りたいか」で選び、分かれ方は棒のまま見せる。
:::

### 本当に？｜気温は、いつも間隔尺度か

「気温は間隔尺度なので、何倍とは言えない」は、気温を ℃ や ℉ で記録したときの話（初学やラボの判定で気温を間隔尺度と呼んだのも、℃ で記録したとき）。K（絶対温度）の 0 は、これ以上下がらない温度（−273.15℃）で、温度の出発点なので、K で書いた温度は比例尺度。27℃（300.15 K）は −3℃（270.15 K）の約1.11倍、と K の比としては言える。

尺度は、量そのものより、**0 を何に置いて記録したか**で決まる。売場でも、開店時刻（10時・11時）は間隔尺度だが、「開店からの経過時間」（0時間・1時間・2時間）は 0 が「まだ時間が経っていない」なので比例尺度で、「開店2時間後は1時間後の2倍の時間が経った」と言える。

ただし K で比例尺度になっても、「27℃の日は −3℃の日の1.11倍暑い」とは言えない。暑さの感じ方は K の比で決まる量ではない。何倍と言えるのは、記録した量（絶対温度）についてだけ。

### ほかでは？｜つながり

- **棒グラフと尺度**：名義・順序は棒グラフ、量はヒストグラム（{{unit:U05}}）。棒の長さは 0 からの量を表す
- **代表値の選び方**：尺度ごとに意味のある代表値（{{unit:U06}}）
- **比を差に変える**：変化率を平均するときの相乗平均（{{unit:U06}}）
- **分かれ方を比べる**：2店の5段階の分かれ方が違うかを確かめる独立性の検定（{{unit:U27}}）
- **カテゴリを式に入れる**：名義の変数を 0 と 1 の列にするダミー変数（{{unit:U30}}）

### 説明してみる

::: task
本部の資料で、A店とB店の1月の平均気温（A店 2℃、B店 8℃）を棒グラフにしたところ、B店の棒がA店の棒の4倍の長さになった。同じデータを ℉ で描くと、A店 35.6℉・B店 46.4℉ で、B店の棒は約1.3倍の長さになる。この棒グラフの描き方のどこに無理があるかを、尺度の言葉で説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（2店の気温を同じ測り方で記録したとみて）**：棒グラフは、0 からの棒の長さで量を表すので、長さの比が「何倍」を主張する。気温 ℃ は間隔尺度で、0℃ は「温度が無い」ではないので、棒の長さの比（4倍）は、単位を ℉ に変えると約1.3倍になる。データの性質ではなく、単位の 0 の置き方で決まっている。単位を変えても同じことを表すのは差（℃ で 6、℉ で 10.8。どちらも「B店は A店より 6℃ 高い」）。

**解釈の例（6℃ の差について）**：
- B店は海沿いにあり、冬でも冷え込みにくい
- 2店で温度計の置き場所が違う（B店は日の当たる壁ぎわ）。店の場所の違いではなく、測り方の違い

どちらの読み方かは、この2つの平均気温だけからは決められない。

**統計の外で決めること**：図で何を見せるか。2店の差を見せたいなら、棒ではなく縦軸の上の点で描き（店と店の間は続いていないので線で結ばない）、縦軸を 0 から始める必要もない。「B店は A店より 6℃ 高い」と差を書き添える。測り方の違いを疑うなら、温度計の置き場所を確かめる。
:::
