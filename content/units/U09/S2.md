**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「区別の無い組み合わせで重複が発生し、考慮する場合成立。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 「区別の無い」→ **何を**区別しないのか（選んだ人の順序・役割）がない。
- 「重複が発生」→「同じ人を繰り返し選ぶ」のか「同じ組を重ねて数える」のか分からない。
- 「考慮する」→ **どう**考慮するのか（r! で割る）がない。

**言い直しの例**

「異なる3人から2人を、同じ人を繰り返し選ばず、順序や役割を区別せずに選ぶとき、選び方は ₃C₂ 通りになる。順序を区別した6通りは同じ組を 2!＝2 回ずつ数えているので、2で割って3通りになる。ただし役割を区別するなら6通りのまま。」
:::

::: toggle 意味が2つある言葉（説明で取り違えやすい）
- **重複**：A「同じものを繰り返し選ぶ」／B「同じ結果を重ねて数える」→ どちらか分かる言い方にする
- **順序**：A「選ぶ手順」／B「結果の並び・役割」→ 数え方を決めるのはB
- **1通り**：A「並べ方の1つ」／B「組の1つ」→ 数える前に宣言する
:::

### 公式の早見

| 場面 | 数え方 |
| --- | --- |
| 順番・役割あり、同じものは1回 | ₙPᵣ＝n!÷(n−r)! |
| 順番・役割なし、同じものは1回 | ₙCᵣ＝n!÷{r!(n−r)!} |
| 順番あり、同じものを何度でも | nʳ |
| 順番なし、同じものを何度でも | ₙ₊ᵣ₋₁Cᵣ（発展） |

^ 間違えたら、初学の「2｜意味をつかむ」だけ読み直してから解き直す。
