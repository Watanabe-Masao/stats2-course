### 0｜入口の問い

::: task
店員5人（A〜E）から「レジ担当」と「品出し担当」を1人ずつ選ぶ方法は何通りか。役割を決めずに2人を選ぶだけなら何通りか。
:::

^ まだ解かなくてよい。この問いに答えられるようになるのが初学のゴール。

### 2｜意味をつかむ：何を「1通り」と数えるか　{{power:P3}}

数え始める前に、2つの質問に答える。

::: ask
**質問1：選んだものの順番や役割を区別する？**

区別する → **順列**（P）
区別しない → **組合せ**（C）
:::

::: ask
**質問2：同じものを何度も選べる？**

選べない → P か C
選べる → **重複を許す数え方**（たとえば nʳ）
:::

{{icon:fig}} **図で見る**：5人から2人を選ぶ

| 役割あり（レジ🛒・品出し📦） | 役割なし（ただの2人） |
| --- | --- |
| 🛒A・📦B と 🛒B・📦A は**別** | どちらも **{A, B}** で同じ |
| 🛒A・📦C と 🛒C・📦A は**別** | どちらも **{A, C}** で同じ |
| …全部で20通り | …全部で10通り |

^ 右の1つの組は、左では2回ずつ出てくる。だから 20÷2＝10。

### 3｜式の構造を読む　{{power:P1}}

$$
{}_nP_r=\underbrace{n\times(n-1)\times\cdots}_{r\text{個掛ける}}=\frac{n!}{(n-r)!}\qquad {}_nC_r=\frac{{}_nP_r}{r!}
$$

| 記号 | 意味（5人から2人の例） |
| --- | --- |
| n | 選ぶ元の数（5人） |
| r | 選ぶ数（2人） |
| ₙPᵣ | 1人目5通り×2人目4通り＝20 |
| r! | 1つの組の並べ方の数（2!＝2） |
| ₙCᵣ | 20÷2＝10 |

**式を言葉で読む**：ₙCᵣ＝ₙPᵣ÷r! は「**まず並べて数え、同じ組を重ねて数えた回数で割る**」。

### 4｜例題：補助を少しずつ減らす　{{power:P2}}

**例題A（全部解説）**　入口の問い

1. 役割あり：レジは5人から、品出しは残り4人から → 5×4＝**20通り**
2. 役割なし：「レジA・品出しB」と「レジB・品出しA」は同じ組 {A, B}
3. どの組も 2!＝2 回ずつ数えている → 20÷2＝**10通り**

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-count}}

1. **予想**：4人から3人を選ぶ。役割ありは何通り？ 役割なしは何通り？ 先に書く。
2. **操作**：「並べて数える」で n＝4、r＝3 にし、「表示する」を押す。
3. **観察**：色の帯（同じ組）1本の中に、並べ方がいくつあるか数える。
4. **説明**：「組合せは順列を□で割る。なぜなら□」を1文で書く。
5. **ラボなしで**：5人から3人を、役割なしで選ぶのは何通り？

::: toggle 答え（書いてから開く）
- **予想の答え**：役割あり 4×3×2＝24、役割なし 24÷6＝4
- **観察**：1本の帯に 3!＝6 通り
- **説明の例**：「組合せは順列を 3!＝6 で割る。なぜなら同じ3人の組を、並べ方の数 6 回ずつ重ねて数えているから」
- **ラボなしで**：5×4×3÷3!＝60÷6＝**10通り**
:::
