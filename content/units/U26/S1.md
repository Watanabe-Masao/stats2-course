### 0｜入口の問い

::: task
例年の購入率は20%。今年は100人中30人が買った。「10ポイント上がった」と言ってよいか。A店は100人中20人、B店は100人中30人。同じ10ポイントの差なのに、こちらは偶然かもしれない。袋詰めの重さのばらつきが基準より大きくなったかは、どう確かめるか。
:::

^ まだ答えなくてよい。平均の検定（{{unit:U24}}）と同じ「差がないと仮定したら珍しいか」の手順で、比率・母分散・分散の比を検定できるようになるのが初学のゴール。

::: toggle 3問だけ確かめる（答えも中にある）
1. 100人中30人の比率 p̂ は？ 基準 p₀＝0.2 のとき √(p₀(1−p₀)÷n) は？ → 0.3、√(0.2×0.8÷100)＝0.04
2. 両側5%の z の境目は？ → ±1.96
3. 自由度9の χ² の0.025点と0.975点は？ → 2.700 と 19.023

1が不安なら {{unit:U14}}、2が不安なら {{unit:U24}}、3が不安なら {{unit:U20}} の初学へ。終わったらここへ戻る。

### 2｜意味をつかむ：H₀ の値で SE を作る　{{power:P3}}

::: ask 1つの比率の検定では、SE に何を使う？
→ H₀：p＝p₀ が正しいと仮定して珍しさを測るので、SE も**H₀ の p₀** で作る：√(p₀(1−p₀)÷n)。区間推定（{{unit:U22}}）で観測した p̂ を使うのとは違う。
:::

::: ask 2つの比率の差の検定では？
→ H₀ は「p₁＝p₂（差がない）」。差がないなら2群は同じ比率なので、**2群を合わせた比率 p̄**＝(x₁＋x₂)÷(n₁＋n₂) で SE を作る。区間推定（{{unit:U23}}）は各群の p̂ を使う。
:::

::: ask ばらつきの検定は？
→ 母分散は χ²＝(n−1)s²÷σ₀²（自由度 n−1）、2つの分散の比は F＝s₁²÷s₂²。どちらも右に長い分布なので、両側では左右の点を別々に引く。母集団が正規分布であることが前提。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
z=\frac{\hat p-p_0}{\sqrt{p_0(1-p_0)/n}}\qquad z=\frac{\hat p_1-\hat p_2}{\sqrt{\bar p(1-\bar p)\left(\frac{1}{n_1}+\frac{1}{n_2}\right)}}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| p̂ | 今年の購入率：30÷100＝0.3 |
| p₀ | H₀ で決めた比率0.2（SE にも使う） |
| p̂₁・p̂₂ | A店0.2、B店0.3 |
| p̄ | 合わせた比率：(20＋30)÷(100＋100)＝0.25 |

**式を言葉で読む**：分子は「H₀ からのずれ」、分母は「H₀ が正しいときのぶれ（SE）」。平均の z 検定と同じ形で、SE の中身だけが違う。

| 何を検定？ | 統計量 | 分布 |
| --- | --- | --- |
| 比率（1つ・2つ） | z | 標準正規（近似） |
| 母分散 | (n−1)s²÷σ₀² | χ²(n−1) |
| 分散の比 | s₁²÷s₂² | F(n₁−1, n₂−1) |

```txt
1つの比率：z＝(p̂−p₀)÷√(p₀(1−p₀)/n)
2つの比率：p̄＝(x₁＋x₂)/(n₁＋n₂)、z＝(p̂₁−p̂₂)÷√(p̄(1−p̄)(1/n₁＋1/n₂))
母分散：χ²＝(n−1)s²/σ₀²（自由度 n−1）
分散の比：F＝s₁²/s₂²（自由度 n₁−1, n₂−1）
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　① 例年の購入率は20%。今年100人中30人が購入した。購入率は変わったか（両側5%）。② A店は100人中20人、B店は100人中30人が購入。購入率に差があるか（両側5%）。（Φ(2.5)＝0.9938、Φ(1.63)＝0.9484）

1. ① SE＝√(0.2×0.8÷100)＝**0.04** → z＝(0.3−0.2)÷0.04＝**2.5**
2. |2.5|＞1.96（p＝2×0.0062≒**0.012**）→ H₀ を**棄却**：購入率は変わったと言える
3. ② p̄＝0.25、SE＝√(0.25×0.75×(1÷100＋1÷100))＝**0.0612**
4. z＝(0.2−0.3)÷0.0612＝**−1.63** → |z|＜1.96（p≒0.10）→ H₀ を**棄却しない**

{{lab:LAB-ptest@s1-p1}}

::: warn
検定の SE は H₀ の値（p₀ や p̄）で作る。区間推定（{{unit:U22}}・{{unit:U23}}）の SE は観測した p̂ で作る。同じ「比率の SE」でも中身が違う。
:::

::: key
②は「差がない」ではなく「この人数では差があるとは言えない」。同じ20%と30%でも、各200人なら z≒−2.31 で棄却する（例題C）。
:::

**分散の例**　袋詰めの重さの分散の基準は σ₀²＝9。10回測ると不偏分散は s²＝16。χ²＝9×16÷9＝**16**（自由度9）。両側5%の境目は2.700と19.023で、16 はその間なので**棄却しない**（p≒0.13）。基準の約1.8倍でも、10回では偶然の範囲。2群で s₁²＝16、s₂²＝4（各11個）なら F＝**4**、F(10, 10) の上側2.5%点3.717 を超えるので、ばらつきが違うと言える。

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-ptest@s1-p2}}

1. **予想**：ラボの課題カードで、A店100人中20人・B店100人中30人の差を、両側5%で棄却するかを選ぶ。
2. **操作**：結果を見たら、比率はそのまま（20%と30%）で人数を各200人（40人と60人）、各400人（80人と120人）にする。
3. **観察**：p̄・SE・z・p 値はどう変わるか。「くわしく」で区間推定の SE（各群の p̂）とも比べる。
4. **説明**：「比率の差が同じでも人数を増やすと、z は□。なぜなら□」を1文で書く。
5. **ラボなしで**：各200人のとき、SE＝√(0.25×0.75×(1÷200＋1÷200)) を出す。

::: toggle 答え（書いてから開く）
- **観察**：各100人で SE≒0.0612・z≒−1.63（棄却しない）。各200人で SE≒0.0433・z≒−2.31（棄却する）、各400人で SE≒0.0306・z≒−3.27。p̄ は0.25 のまま。区間推定の SE（各100人で約0.0608）は p̄ の SE とわずかに違う。
- **説明の例**：「比率の差が同じでも人数を増やすと、z は大きくなる。SE が √n に反比例して小さくなり、同じ10ポイントの差が SE の何倍かが増えるから」
- **ラボなしで**：√(0.1875×0.01)＝√0.001875≒**0.0433**。
:::
