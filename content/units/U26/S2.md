### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}

**お手本：2つの比率の差の検定で、合わせた比率 p̄ を使う理由**

- **条件**：H₀「p₁＝p₂（差がない）」を検定するとき
- **対象と結論**：SE は p̄＝(x₁＋x₂)÷(n₁＋n₂) で作る
- **根拠**：検定は H₀ が正しいと仮定して珍しさを測るので、2群が同じ比率を持つとして、その共通の比率を両群のデータから推定する
- **成り立たない場合**：差の大きさを区間で示すときは、H₀ を仮定しないので各群の p̂ で SE を作る

::: toggle つなげると（お手本の文）
「H₀『p₁＝p₂』を検定するときは、SE を2群を合わせた比率 p̄＝(x₁＋x₂)÷(n₁＋n₂) で作る。検定は H₀ が正しいと仮定して珍しさを測るので、2群が同じ比率を持つとして共通の比率を両群から推定するからである。ただし差の大きさを区間で示すときは H₀ を仮定しないので、各群の p̂ で SE を作る。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「今年は100人中30人で p̂＝0.3 なので、SE は √(0.3×0.7÷100) で検定しました。袋詰めの分散の検定は、s をそのまま (n−1)s÷σ₀ に入れて χ² 分布と比べました。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 1つの比率の検定の SE は H₀ の p₀ で作る（p₀＝0.2 なら √(0.2×0.8÷100)＝0.04）。p̂ で作るのは区間推定。
- 母分散の検定は分散で計算する：χ²＝(n−1)s²÷σ₀²。標準偏差のままでは χ² 分布に従わない。

**言い直しの例**

「H₀：p＝0.2 のもとで SE＝√(0.2×0.8÷100)＝0.04 とし、z＝(0.3−0.2)÷0.04＝2.5 で判断する。袋詰めの分散は χ²＝(n−1)s²÷σ₀² を自由度 n−1 の χ² の点と比べる。」
:::

::: toggle 取り違えやすい言葉
- **「検定の SE」と「区間の SE」**：検定は H₀ の値（p₀・p̄）、区間は p̂ で作る
- **「p̄（合わせた比率）」と「p̂₁・p̂₂」**：p̄ は H₀「差がない」のもとでの共通の比率
- **「s」と「s²」**：χ²・F は分散（s²）で計算する
- **「F(n₁−1, n₂−1)」の順**：分子の自由度が先
- **「棄却しない」と「等しい」**：棄却しない＝この人数では差があるとは言えない
:::

### 検定の早見

| 何を検定？ | 統計量（分布） |
| --- | --- |
| 1つの比率 | (p̂−p₀)÷√(p₀(1−p₀)÷n)（正規近似） |
| 2つの比率 | (p̂₁−p̂₂)÷√(p̄(1−p̄)(1÷n₁＋1÷n₂)) |
| 母分散 | (n−1)s²÷σ₀²（χ²(n−1)） |
| 分散の比 | s₁²÷s₂²（F(n₁−1, n₂−1)） |

^ 正規近似の目安：np₀ と n(1−p₀) がどちらも5以上。小さいときは二項分布で直接計算する。
