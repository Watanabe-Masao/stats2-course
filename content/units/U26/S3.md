### 判断の手順（毎回これを書く）　{{power:P3}}

1. **何の検定か**：はい／いいえの割合なら比率（1つか2つか）、ばらつきなら母分散（基準と比べる）か分散の比（2群）
2. **仮説と α・両側／片側**：H₁ が「上がった」「小さくなった」なら片側。データを見る前に決める
3. **統計量**：比率は SE を H₀ の値（p₀・p̄）で作った z。母分散は (n−1)s²÷σ₀²、分散の比は s₁²÷s₂²
4. **前提を確かめる**：比率は np₀・n(1−p₀) が5以上（小さければ二項分布で直接）。χ²・F は正規母集団
5. **判断と結論**：χ²・F は右に長いので、両側なら下側と上側の点を別々に引く。「〜と言える／〜とは言えない」で結ぶ

### 似た場面を見分ける

「購入率が例年の20%と違うか」は1つの比率、「A店とB店の購入率」は2つの比率、「同じ客に2回聞いた賛否」は対応のある比率で独立2群の式は使えない。「内容量のばらつきが基準より大きいか」は母分散（右片側）、「新旧レジのばらつき」は分散の比。30個中数個の不良のように np₀ が小さいときは、正規近似ではなく二項分布で計算する。

### 使えない例と比べる　{{power:P3}}

- 1つの比率の検定で、SE を p̂ で作る → ✕。H₀ の p₀ で作る。
- 2つの比率の差の検定で、各群の p̂ で SE を作る → ✕。H₀「差がない」のもとでは合わせた比率 p̄ を使う。
- np₀ が5より小さいのに正規近似を使う → ✕。二項分布で直接計算する。
- 標準偏差 s をそのまま χ² の式に入れる → ✕。分散 s² で計算する。
- χ² の両側検定で、上側の点だけを見る → ✕。下側の点より小さいときも棄却する。
- 同じ人に2回聞いた賛否を、独立2群の比率の式で検定する → ✕。対応があるので、変わった人の数で考える。

### この先で使う

2つの比率の差の z を2乗すると、2×2 の表の χ² 検定（{{unit:U27}}）の統計量になる。分散の比の F は、3群以上の平均を比べる分散分析（{{unit:U32}}）で使う。
