### 探究｜「不良率が上がった日」が多すぎる

ある工程の不良率の基準は5%。毎日200個を抜き取って検査し、その日の不良率を基準と比べて、右片側5%の検定で「上がった」と出た日に、ラインを止めて点検する決まりにした。

20日続けると、「上がった」の日が4日あった。20日の不良率の平均はちょうど5%で、基準どおり。担当者は「平均は5%なのに、点検が多すぎる。検定がおかしいのではないか」と言う。聞き取ると、次のことが分かった。
- 不良の数は、日によって1個の日もあれば、17個の日もある。日ごとの不良の数の標準偏差は約4.8個
- 材料は数日ごとに別の仕入れのロットに替わる。検査の担当者も日によって替わる

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 毎日の検定が前提にしていること（200個の不良が互いに独立に、同じ確率5%で起きる）を書く
2. その前提が正しければ、20日のうち「上がった」と出る日は何日くらいか
3. その前提が正しければ、日ごとの不良の数の分散はいくつになるか（二項分布の np(1−p)）。実際の分散と比べる
4. 初学の母分散の検定（χ²）の考え方で、日ごとの不良の数のばらつきが、前提から出る大きさより大きいかを調べる
5. 統計で言えることと、ばらつきが大きい理由についての解釈（2つ以上）を分ける
6. 点検の決まりをどう変えるか、次に確かめる記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**毎日の検定の前提**：200個の不良が互いに独立に、どの日も同じ確率5%で起きる。このとき不良の数は二項分布 B(200, 0.05) に従い、検定の SE は √(0.05×0.95÷200)≒0.0154。

**前提が正しければ**：右片側5%なので、「上がった」と出る日は20日で1日くらい（離散なので少し少ない）。日ごとの不良の数の分散は 200×0.05×0.95＝9.5、標準偏差は約3.1個。

**実際のばらつきと比べる（20日が互いに独立で、日ごとの不良の数が正規分布に近いとみて）**：日ごとの不良の数の標準偏差は約4.8個で、分散は約23.0。前提の分散9.5 を基準に χ²＝19×23.04÷9.5≒46.1（自由度19）。上側5%の点30.14 を大きく超える。「日ごとの不良の数は、独立に同じ確率で起きるときより大きくばらついている」と言える。

**統計で言えること**：平均は基準どおりでも、日ごとのばらつきが二項分布の前提より大きい。毎日の検定は、この前提の SE（0.0154）で珍しさを測っているので、ばらつきが大きいぶん「上がった」が出やすい。日ごとの不良率の標準偏差が約0.024 なら、20日のうち約3日は「上がった」と出る。4日はその範囲に近い。

**この数だけでは言えないこと**：なぜばらつきが大きいか。工程が悪くなったとは言えない（平均は5%のまま）。

**解釈の例**：
- 材料のロットごとに不良の出やすさが違う。同じロットの日は不良率が似て、ロットが替わると動く
- 検査の担当者によって、不良と判定する基準が少し違う
- 不良がまとまって起きる（1回の機械のずれで何個も続けて不良になる）ので、200個の不良が独立ではない

どの読み方が当たるかは、この20日の数だけからは決められない。

**統計の外で決めること・確かめること**：毎日の検定の前に、日ごとの記録にロットと担当者を書き、どちらに沿って不良率が動くかを見る。点検の決まりは、前提の SE で測る毎日の検定のままにするか、日ごとの実際のばらつきを使う形にするかを、点検の手間と見逃しの損で決める（下の課題）。
:::

### 課題｜点検の決まりを決める

**問い**　探究の工程で、ラインを止めて点検する決まりを作り直す。次のどれにするか。

| 決まり | 中身 |
| --- | --- |
| ア | 今のまま。その日の不良率を、二項分布の SE（0.0154）で右片側5%の検定にかける |
| イ | 過去の日ごとの不良率の実際の標準偏差（約0.024）で、基準から外れすぎた日だけ止める |
| ウ | ロットが替わった日だけ、そのロットの最初の数日をまとめて検定する |

**判断の材料**：1回の点検で、ラインは2時間止まる。不良率が本当に上がったのを見逃すと、その分の不良品が出荷前の検査まで流れる。ロットの記録は、今は残していない。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること**：ア は、日ごとのばらつきが二項分布より大きい今のままでは、工程が変わらなくても約15%の日に止まる（20日で約3日）。イ は、日ごとのふだんの揺れを基準にするので、止まる日は減るが、そのぶん小さな上がり方は見逃しやすい。ウ は、ばらつきの理由がロットだという読み方が当たっていれば効くが、まだ確かめていない。

**統計の外で決めること**：まずロットと担当者の記録を取り始め、ばらつきの理由を確かめる。それまでは、点検の手間（2時間）と見逃しの損を比べて、ア か イ を選ぶ。どちらにしても、日ごとに検定を繰り返せば、どこかで偶然「上がった」が出る（{{unit:U24}}）ことを、決まりに書いておく。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何と何を比べるか（平均か、ばらつきか）を決めたか |
| 仮定 | 毎日の検定が前提にする独立・同じ確率を書いたか |
| 方法 | 前提から出るばらつきを計算し、実際のばらつきと比べたか |
| 検証 | ラボで、1日の検定とばらつきの検定の両方を確かめたか |
| 切り分け | 統計で言えること（ばらつきが前提より大きい）と、言えないこと（なぜ大きいか・工程が悪くなったか）を分けたか |
| 解釈 | ばらつきが大きい理由の読み方を2つ以上並べ、次に確かめる記録を書いたか |
