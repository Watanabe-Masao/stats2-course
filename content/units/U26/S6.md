### 課題A｜キャンペーン比較の計画を作る

2つの販促（A・B）を比べる計画を、調べる前に次の形で書く。

| 項目 | 書くこと |
| --- | --- |
| 仮説 | H₀（差がない）と H₁、両側か片側か |
| 人数 | 見つけたい差（例：5ポイント）に足りる人数 |
| 方法 | 2つの比率の z 検定と差の区間 |
| 報告 | 有意か、差はどれくらいか、前提 |

### 課題B｜ばらつきの基準を決める

**問い**　袋詰めの重さのばらつきが「基準より大きくなった」ことを、毎週の抜き取り検査で見つけたい。何袋測り、どう判断するか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：基準の分散 σ₀² を過去のデータから決める。毎週 n 袋を測り、χ²＝(n−1)s²÷σ₀² を右片側5%の点と比べる。n が小さいと、分散が基準の1.5倍になっても見逃しやすいので、見逃してよい割合から n を決める。

**小さな例で検証**：ラボの「母分散」で σ₀²＝4、s²＝6（基準の1.5倍）にして、n を10・25・30 と変え、右片側5%で棄却するかを見る。30袋でようやく棄却する。

**成り立たない条件と、その先の判断**：重さが正規分布から外れると、χ² 検定は誤りの確率が α からずれる。毎週検定すると、どこかで偶然「有意」になる（{{unit:U24}} の多重検定）。
:::

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何の検定か、両側か片側かを先に決めたか |
