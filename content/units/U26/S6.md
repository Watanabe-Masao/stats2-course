### 探究｜「新しい機械の方が、ばらつきが小さい」は何と何を比べたのか

袋詰めの機械を、新しい A に替えるかを決めたい。担当者は、試しに借りた A で詰めた袋と、今の B で詰めた袋を20袋ずつ測り、重さの不偏分散を出した。A は1.0、B は2.8（g²）。

F＝2.8÷1.0＝2.8（自由度19, 19）で、両側5%の上側の点2.526 を超える。担当者は「A の方がばらつきが小さいので、A に替える」と報告した。聞き取ると、次のことが分かった。
- A の20袋は、借りた日の午前中に続けて詰めたもの
- B の20袋は、この1か月の検査の記録から、日をばらして20袋を選んだもの
- 袋の重さは、日によって材料の湿り気や室温で少しずつ変わる

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. A の不偏分散1.0 と B の不偏分散2.8 は、それぞれ「どんな揺れ」を含んでいるかを書く（同じ日の中の揺れ・日による違い）
2. F 検定の前提（2つの標本が互いに独立で、袋どうしも独立、それぞれ正規分布に近い）を書く
3. F 検定で言えることを、前提を添えて書く
4. 「A に替えればばらつきが小さくなる」と言うには、何が足りないかを書く
5. ばらつきの違いについての解釈（2つ以上）を分ける
6. A と B を比べ直すなら、どう測るかを書く（下の課題）

{{lab:LAB-ptest@s6-free}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**それぞれが含む揺れ**：A の1.0 は、ある日の午前中の中での袋ごとの揺れだけ。B の2.8 は、袋ごとの揺れに、日による違い（材料・室温）が加わった揺れ（同じ日の中の分散が日に共通の部分を引き算で消す仕組みは {{unit:U21}} の発展）。たとえば2台の袋ごとの揺れがどちらも1.0 で、日による違いの分散が1.8 なら、B は 1.0＋1.8＝2.8 になり、機械の揺れが同じでも F＝2.8 になる。

**統計で言えること（20袋ずつが互いに独立で、重さが正規分布に近いとみて）**：A の「ある日の午前中に詰めた袋」の分散と、B の「1か月から選んだ袋」の分散は、偶然の範囲を超えて違う（F＝2.8、両側5%の点2.526 を超える。p≒0.03）。

**この数だけでは言えないこと**：A の方が機械として揺れが小さいかどうか。2つの分散は、違う揺れを測っている。B も1日の中だけで測れば、1.0 に近いかもしれない。A も1か月使えば、日による違いが加わる。比べたのは「機械の違い」と「測り方の違い」が混ざったもの。

**解釈の例**：
- A は本当に揺れが小さい機械で、1か月使っても B より小さい
- A と B の袋ごとの揺れは同じくらいで、違って見えたのは、B だけに日による違いが入っていたから
- 借りた日は条件がよかった（材料が乾いていた、詰める速さを落とした）ので、A の揺れが小さく出た

どの読み方が当たるかは、この40袋の数だけからは決められない。

**統計の外で決めること**：今の比べ方だけで A に替える判断はしない。A と B を同じ条件で測り直し、その結果と機械の値段・入れ替えの手間で決める。
:::

### 課題｜A と B を比べ直す測り方を決める

**問い**　A を借りられるのは、あと5日。次のどれで比べ直すか。

| 測り方 | 中身 |
| --- | --- |
| ア | 同じ日に A と B を並べて動かし、20袋ずつ測る |
| イ | 5日間、毎日 A と B を4袋ずつ測る（20袋ずつ） |
| ウ | B は今のまま1か月の記録から20袋、A は5日間から20袋 |

**判断の材料**：1日に測れるのは、2台合わせて40袋まで。袋の重さは日によって変わる。替えたあとに困るのは、ふだんの1か月を通したばらつき。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること**：ア は、日による違いをそろえて比べられる（並べる位置・担当者など、同じ日の中で違う条件は残る）。ただ、1日の中の揺れしか比べないので、日による違いに2台がどう反応するかは分からない。イ は、2台とも同じ5日の揺れを含むので、比べる揺れの中身がそろう。ただし同じ日の4袋は似るので、20袋を独立とはみなせず、F の自由度は袋の数より日の数に近い（何を1個と数えるかは {{unit:U25}} の創造）。ウ は、A は5日、B は1か月の揺れで、まだ中身がそろわない。

**統計の外で決めること**：替えたあとに困るのが1か月を通したばらつきなら、イ で比べる（5日では日による違いの一部しか入らないことは、報告に書く）。2台の差を一番はっきり見たいだけなら ア。どれを選んでも、比べる前に、両側か片側か・α を決めておく。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何のばらつきと何のばらつきを比べるかを決めたか |
| 仮定 | 2つの標本が独立・正規分布に近い・同じ揺れを測っているかを書いたか |
| 方法 | 比べる2つの揺れの中身がそろう測り方を選んだか |
| 検証 | ラボで F と境目を確かめたか |
| 切り分け | 統計で言えること（この2つの標本の分散は違う）と、言えないこと（機械の違いか、測り方の違いか）を分けたか |
| 解釈 | ばらつきが違って見えた理由の読み方を2つ以上並べ、比べ直す測り方を書いたか |
