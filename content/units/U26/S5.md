### なぜ？｜なぜ検定は p₀ で SE を作り、区間は p̂ で作るのか

検定が問うのは「H₀ が正しいとしたら、この p̂ はどれくらい珍しいか」。H₀：p＝p₀ を置けば、p̂ の分布は p₀ だけで決まる（二項分布 B(n, p₀) を n で割ったもの）。だから SE も p₀ で作れる。区間推定には決まった p₀ がないので、分からない p の代わりに、手元の p̂ を入れて SE を見積もる。

この入れ替えで、2つの答えが食い違うことがある。50人中5人（p̂＝0.1）を基準 p₀＝0.2 と比べると、検定の SE は約0.0566、z≒−1.77 で、両側5%では棄却しない。p̂ で作る95%区間は約0.017〜0.183 で、0.2 を含まない。

食い違いのもとは、区間の SE に p̂ を入れたこと。p₀ を1つずつ動かして、p₀ で SE を作る検定で棄却されない p₀ を全部集めると、それも1つの95%区間になる（スコア区間。この例では約0.043〜0.214）。この区間は検定と食い違わない。2つの SE は p(1−p) で決まるので、p₀(1−p₀) と p̂(1−p̂) が違うほど離れる。平均の t 検定（{{unit:U25}}）では、検定と区間で同じ s を使うので、こうした食い違いは起きない。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「購入率の差は1ポイント」という1つの数からは、**もとの割合がどれくらいか**が消える。比率の SE には p(1−p) が入るので、同じ1ポイントの差でも、もとの割合で見つけやすさが変わる。

各1000人で比べると、1%と2% の差は SE≒0.0054 で、z の大きさは約1.84。20%と21% の差は SE≒0.0181 で、z の大きさは約0.55。

差はどちらも1ポイントでも、1%と2% は「2倍」、20%と21% は「1.05倍」で、意味もまるで違う。比率の差を報告するときは、ポイントの差だけでなく、もとの割合と、何倍か（比）を並べる。

### 本当に？｜基準の p₀ も、標本から出した値だったら

1つの比率の検定は、基準 p₀ を「分かっている値」として扱い、揺れるのは今年の p̂ だけとみる。けれども「例年の購入率20%」は、去年100人を調べて20人だった、という標本から出した値かもしれない。そのときは、去年の p̂ も今年の p̂ と同じくらい揺れる。

去年も今年も本当の購入率が同じで、どちらも100人ずつなら、今年の p̂ と去年の p̂ の差の揺れは、今年の p̂ だけの揺れの √2 倍になる。それを1つの比率の検定で測ると、z は √2 倍に大きく出る。正規近似が使える人数とみると、両側5%のつもりが、約17%の割合で誤って棄却する。

初学の例題A の①（例年20%、今年100人中30人：p≒0.012）と②（100人中20人と30人：p≒0.10）は、同じ数で結論が分かれる。基準がどう生まれた値か（多くの年の積み重ねか、1回の調査か）で、使う検定が変わる。

### ほかでは？｜つながり

- **σ を分かっているとみる前提**：基準の値を「分かっている」とみると誤って棄却しやすくなるのは、平均の z 検定で σ を小さく見込むときと同じ向き（{{unit:U24}}）
- **正規近似が崩れるとき**：np₀ が小さいと、比率の z の p 値は二項分布の p 値とずれる（{{unit:U19}}。問題は {{stage:S3}}）
- **2×2 の表**：2つの比率の差の z の2乗は、2×2 の表の χ²（{{unit:U27}}）
- **分散の検定と正規性**：母分散の χ² 検定は、正規分布から外れると n を増やしても誤りの割合が戻らない（{{unit:U20}} の発展）

### 説明してみる

::: task
2つの新しい味（A・B）を同じ100人に試してもらい、それぞれ「買いたいか」を聞いた。A は60人、B は40人が「買いたい」と答えた。2つを別々の2群として2つの比率の差の検定をすると z≒2.83 になった。聞き直すと、A だけ「買いたい」が45人、B だけ「買いたい」が25人、両方が15人、どちらでもないが15人だった。同じ人に聞いた比率の比べ方は応用で扱った（答えが変わった人の数で比べる）。応用の例では、別々の2群とみた z は差を見逃しやすかった。この例では、別々の2群とみた z が大きく出すぎている。向きが逆になったのはなぜかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（100人が互いに独立に答えたとみて）**：同じ人に聞いたので、比べるのは A と B で答えが分かれた70人。A の側45人・B の側25人で、変わった人の数で比べる z は約2.39。別々の2群とみた z（約2.83）より小さい。

2つの比率の差の揺れは、2つの答えのつながりで決まる。試食の前と後のように、同じ人の答えがそろいやすい（正のつながり）ときは、差の揺れは別々の2群より小さく、別々の2群とみた z は差を見逃しやすい。この例のように「A が好きな人は B を選ばない」と答えが逆になりやすい（負のつながり）ときは、差の揺れは別々の2群より大きく、別々の2群とみた z は大きく出すぎる。

**解釈の例**：
- 2つを並べて試すと、どちらか1つを選ぶ気持ちになり、片方だけ「買いたい」と答えた
- A と B は好みの分かれる味で、それぞれに好きな客層がいる

**統計の外で確かめること**：どちらの読み方かは、1つずつ別の日に試した人の答えと比べて確かめる。
:::
