### なぜ？｜なぜ検定は p₀ で SE を作り、区間は p̂ で作るのか

検定が問うのは「H₀ が正しいとしたら、この p̂ はどれくらい珍しいか」。H₀：p＝p₀ を置けば、p̂ の分布は p₀ だけで決まる（二項分布 B(n, p₀) を n で割ったもの）。だから SE も p₀ で作れて、作るのが筋になる。区間推定には、決まった p₀ がない。分からない p の代わりに、手元の p̂ を入れて SE を見積もる。

この違いで、2つの答えが食い違うことがある。50人中5人（p̂＝0.1）で、基準 p₀＝0.2 と比べると、検定の SE は √(0.2×0.8÷50)≒0.0566、z≒−1.77 で、両側5%では棄却しない。ところが p̂ で作る95%区間は 0.1±1.96×0.0424、約0.017〜0.183 で、0.2 を含まない。p₀ と p̂ が離れているほど、2つの SE の違いは大きくなる。平均の t 検定（{{unit:U25}}）では、検定と区間で同じ s を使うので、こうした食い違いは起きない。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「購入率の差は1ポイント」という1つの数からは、**もとの割合がどれくらいか**が消える。比率の SE には p(1−p) が入るので、同じ1ポイントの差でも、もとの割合で見つけやすさが変わる。

各1000人で、1%と2%の差は SE≒0.0054、z≒1.84。20%と21% の差は SE≒0.0181、z≒0.55。差はどちらも1ポイントでも、1%と2%は「2倍」、20%と21% は「1.05倍」で、意味もまるで違う。比率の差を報告するときは、ポイントの差だけでなく、もとの割合と、何倍か（比）を並べる。

### 本当に？｜裾の重いデータで、母分散の検定を使うと

母分散の χ² 検定は、母集団が正規分布であることを前提にしている。平均の t 検定は、正規分布から多少外れても、n が大きければ中心極限定理で使える。分散の検定はそうならない。

各袋の重さが独立に、正規分布より裾の重い分布（ラプラス分布）に従い、分散が本当に基準どおりだとしても、計算機で何度も起こしてみると、30袋で両側5%の検定をしたとき、棄却する割合は約19%になる。n を大きくしても5%には戻らず、約21%に近づく。

χ² の分布は、s² の揺れの大きさを「正規分布ならこれくらい」と決め打ちしている。s² の揺れは、データの裾の重さ（とがり）で決まり、裾が重いと s² は正規分布のときより大きく揺れる。n を増やすと揺れは小さくなるが、「正規分布なら」との比は残る。だから分散の検定では、正規性を確かめることが、平均の検定より大事になる。

### ほかでは？｜つながり

- **正規近似が崩れるとき**：np₀ が小さいと、比率の z の p 値は二項分布の p 値とずれる（{{unit:U19}}。問題は {{stage:S3}}）
- **区間と検定**：差の区間（{{unit:U23}}）と差の検定の SE の違い
- **2×2 の表**：2つの比率の差の z の2乗は、2×2 の表の χ²（{{unit:U27}}）
- **平均の検定との違い**：平均の t は正規性から多少外れても使える（{{unit:U25}}）

### 説明してみる

::: task
新しい総菜を試食する前と後で、同じ200人に「買いたいか」を聞いた。試食の前は60人、後は80人が「買いたい」と答えた。担当者は、前と後を別々の2群として2つの比率の差の検定をし、z≒2.10、p≒0.036 とした。聞き直すと、前は「買いたくない」で後に「買いたい」に変わった人が30人、前は「買いたい」で後に「買いたくない」に変わった人が10人だった。この検定のどこに無理があるか。変わった人の数から、何が読めるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること**：2つの比率の差の検定は、2群が互いに独立であることを前提にする。同じ200人に2回聞いているので、前と後の答えは人ごとにつながっていて、独立ではない。前後で答えが変わらなかった160人は、差について何も教えない。差を決めるのは変わった40人だけで、そのうち30人が「買いたい」の側へ変わった。各人が独立に答え、試食に効果がなければ、変わった人はどちらの向きにも半々に分かれるとみると、40人中30人以上が同じ向きになるのは珍しい（両側でも1%未満）。前後のつながりを無視した z は、この比べ方より見逃しやすい。

**解釈の例**：
- 試食で味を知り、買いたくなった人が増えた
- 同じ人に2回聞いたので、「試食させてもらったから」と気をつかって「買いたい」と答えた人がいる。答えと実際に買うかは別

どちらかを確かめるには、試食した人としない人で、実際に買った割合を比べる。
:::
