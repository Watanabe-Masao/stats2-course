### なぜ？｜なぜ検定は p₀ で SE を作り、区間は p̂ で作るのか

検定が問うのは「H₀ が正しいとしたら、この p̂ はどれくらい珍しいか」。H₀：p＝p₀ を置けば、p̂ の分布は p₀ だけで決まる（二項分布 B(n, p₀) を n で割ったもの）。だから SE も p₀ で作れる。区間推定には決まった p₀ がないので、分からない p の代わりに、手元の p̂ を入れて SE を見積もる。

この入れ替えで、2つの答えが食い違うことがある。50人中5人（p̂＝0.1）を基準 p₀＝0.2 と比べると、検定の SE は約0.0566、z≒−1.77 で、両側5%では棄却しない。p̂ で作る95%区間は約0.017〜0.183 で、0.2 を含まない。

食い違いのもとは、区間の SE に p̂ を入れたこと。p₀ を1つずつ動かして、p₀ で SE を作る検定で棄却されない p₀ を全部集めると、それも1つの95%区間になる（スコア区間。{{unit:U22}} のウィルソンの区間）。この区間は検定と食い違わない。ラボで p₀ を動かして、棄却されない範囲を自分で探す。

::: toggle 探した範囲と照らし合わせる
棄却されない p₀ は約0.05〜0.21（スコア区間は約0.043〜0.214）。0.2 を含むので、検定と食い違わない。2つの SE は p(1−p) で決まるので、p₀(1−p₀) と p̂(1−p̂) が等しいとき、つまり p₀＝0.1 と p₀＝0.9 で等しくなる。
:::

平均の t 検定（{{unit:U25}}）では、検定と区間で同じ s を使うので、こうした食い違いは起きない。

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

「購入率の差は1ポイント」という1つの数からは、**もとの割合がどれくらいか**が消える。比率の SE には p(1−p) が入るので、同じ1ポイントの差でも、もとの割合で見つけやすさが変わる。

各1000人で、1%と2% の差と、20%と21% の差の SE と z を、ラボで読んで比べる。p(1−p) は 0.5 に近いほど大きいので、もとの割合が小さい1%と2% の方が SE は小さく、同じ1ポイントの差でも z は大きく出る。

差はどちらも1ポイントでも、1%と2% は「2倍」、20%と21% は「1.05倍」で、意味もまるで違う。比率の差を報告するときは、ポイントの差だけでなく、もとの割合と、何倍か（比）を並べる。

### 本当に？｜基準の p₀ は、何人分の積み重ねか

1つの比率の検定は、基準 p₀ を「分かっている値」として扱い、揺れるのは今年の p̂ だけとみる。けれども「例年の購入率20%」は、何人を調べて出した値だろうか。

去年も今年も本当の購入率が同じで、去年と今年が独立に調べた標本なら、今年の p̂ と基準の差の揺れは、今年の p̂ だけの揺れの √(1＋今年の人数÷基準の人数) 倍になる。1つの比率の検定は、この分を見込まないので、H₀ のもとでの z の揺れがそれだけ大きくなり、誤って棄却しやすい。

- 基準が10年分・1000人の積み重ねなら、倍率は √1.1≒1.05。今年100人で両側5%の検定をしても、誤って棄却する割合は約6%で、ほとんど変わらない
- 基準が去年100人だけの調査なら、倍率は √2≒1.41 で、約17%（正規近似が使える人数とみて）

初学の例題A の①（例年20%、今年100人中30人：p≒0.012）と②（100人中20人と30人：p≒0.10）は、同じ数で結論が分かれた。基準が何人分の積み重ねかで、1つの比率の検定と2つの比率の検定のどちらを使うかが決まる。

### ほかでは？｜つながり

- **σ を分かっているとみる前提**：基準の値を「分かっている」とみると誤って棄却しやすくなるのは、平均の z 検定で σ を小さく見込むときと同じ向き（{{unit:U24}}）
- **同じ人の2つの答えのつながり**：対の差の分散が相関で変わる仕組み（{{unit:U23}} の発展）
- **正規近似が崩れるとき**：np₀ が小さいと、比率の z の p 値は二項分布の p 値とずれる（{{unit:U19}}。問題は {{stage:S3}}）
- **2×2 の表**：2つの比率の差の z の2乗は、2×2 の表の χ²（{{unit:U27}}）
- **分散の検定と正規性**：母分散の χ² 検定は、正規分布から外れると n を増やしても誤りの割合が戻らない（{{unit:U20}} の発展）

### 説明してみる

下の表は、同じ60人・40人になる同時の表の例。

| 両方とも買いたい | A だけ | B だけ |
| --- | --- | --- |
| 0人 | 60人 | 40人 |
| 15人 | 45人 | 25人 |
| 40人 | 20人 | 0人 |

^ 残りはどちらも買いたくない人。

::: task
2つの新しい味（A・B）を同じ100人に試してもらい、それぞれ「買いたいか」を聞いた。A は60人、B は40人が「買いたい」と答えた。担当者は「60%と40% なので、2つの比率の差の検定をすれば十分」と言う。ところが、同じ60人・40人でも、2つの答えの組み方（同時の表）は1つに決まらない（上の表）。同じ人に聞いた2つの比率は、答えが分かれた人の数で比べる：z＝(A だけ−B だけ)÷√(A だけ＋B だけ)。3つの表で z を出し、別々の2群とみた z（どの表でも約2.83）と比べる。60%と40% という2つの比率から、何が消えているかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（100人が互いに独立に答えたとみて）**：答えが分かれた人の数で比べる z は、上から 20÷√100＝2.0、20÷√70≒2.39、20÷√20≒4.47。差（A だけ−B だけ）はどれも20人だが、答えが分かれた人の数が少ないほど、差は揺れでは説明しにくい。別々の2群とみた z は、60人と40人だけで決まるので、3つとも約2.83 で動かない。

60%と40% という2つの比率からは、**同じ人の中で2つの答えがどう組になっているか**が消えている。両方とも買いたい人が多い（答えがそろう）ほど、分かれた人は少なく、比べる力は強くなる。

**解釈の例**：
- 両方とも買いたい人が多い表では、味の好みより「新しい物を試したい」客が多い
- 両方とも買いたい人が0人の表では、2つを並べて、どちらか1つを選ぶ気持ちで答えた

**統計の外で確かめること**：同じ人に2つを聞くときは、2つの比率だけでなく、同時の表を残す。
:::
