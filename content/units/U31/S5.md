### なぜ？｜ネイマン配分は、なぜ標準偏差の2乗（分散）ではなく標準偏差に比例させるのか

ラボは、大きさが同じ2つの層（割合0.5 ずつ）に100人を振り分ける（母集団は十分大きいとする）。層1の標準偏差40、層2の標準偏差10 で、比例配分とネイマン配分の振り分けと標準誤差を読む。次に、「ばらつきの大きい層に多く」をもっと強めて、分散（40²と10²）に比例させて配ったら標準誤差がどうなるかを、ラボの式 √(0.5²×40²÷n₁＋0.5²×10²÷n₂) で自分で計算する。計算してから開く。

::: toggle 計算してから開く
比例配分は50人ずつで、標準誤差は約2.92。ネイマン配分は「層の割合×標準偏差」に比例させて層1に80人・層2に20人で、2.50。分散に比例させると、層1に 100×1600÷(1600＋100)≒94人・層2に6人で、標準誤差は約2.90 と、比例配分とほとんど変わらないところまで戻ってしまう。

層 h の平均のばらつき（分散）は「層の割合²×層の分散÷人数」で、人数を1人足したときに減る量は、人数が増えるほど小さくなる（人数の2乗で割った大きさ）。だから、ばらつきの大きい層に人を寄せすぎると、その層ではもう1人足してもほとんど減らず、人を取られた層の揺れが大きくなる。どの層でも「1人足したときに減る量」がそろうところがいちばん得で、そこを求めると人数は「層の割合×標準偏差」に比例する。分散に比例させると、ばらつきの大きい層に寄せすぎになる。ただし、これは1人を調べる費用がどの層でも同じときの話で、費用が層で違えば、費用の分も配分に入る。
:::

### 1つの数で何が消えるか｜「10店を調べた」

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

ラボは、地域ごとに売上の水準がかなり違う10地域×10店（地域の差1.5）で、10店を調べる。集落（1地域を選んで10店を全部）と単純無作為（100店から10店）の標準誤差を読む。報告にはどちらも「10店を調べた」と書ける。同じ精度を単純無作為で出すには何店あれば足りるかを、標準誤差が店数の平方根に反比例することから見積もる。

::: toggle 動かしてから開く
**何が複雑にしているか**：同じ地域の店は売上の水準が似ているので、1地域の10店を全部調べても、10店のうち9店はほとんど新しい情報を足さない。集落の推定値のばらつきは、どの地域を引いたかでほぼ決まる。ラボでは、集落の標準誤差は単純無作為の約3.2倍。単純無作為で同じ精度を出すのに要る店数は、およそ 10÷3.2²≒1店（100店から選ぶときの修正まで入れると約1.1店）。10店を丸ごと調べても、くじで1店を選ぶのとほとんど変わらない。

**なぜ1つの数では言えないか**：「10店」という数は、選んだ単位（地域）がいくつで、単位の中がどれだけ似ているかを消してしまう。

**どう分けて考えるか**：「調べた数」と「選んだ単位の数」と「単位の中がどれだけ似ているか」に分ける。地域の差を小さくすると、単位の中が似なくなり、要る店数は増える。

**数字とどう向き合うか**：調査の報告で人数や店数を読むときは、何を単位にいくつ選んだかを一緒に確かめる。
:::

### 本当に？｜層化の重みは、いつも正しいか

{{problem:Q-U31-040}}

### ほかでは？｜つながり

- **層の重み付き平均**：重み付きの平均（{{unit:U06}}）
- **単純無作為抽出と名簿**：母集団・標本・無作為抽出（{{unit:U17}}）
- **n を4倍にすると標準誤差が半分**：標本平均の性質（{{unit:U18}}）
- **「偏り」という同じ言葉**：推定量の偏り（{{unit:U21}}）は推定の式から来るずれ、調査の偏りは選び方・答え方・名簿から来るずれ
- **偏りを少し受け入れて、ばらつきを減らす**：平均二乗誤差の内訳（{{unit:U21}} の発展）
- **選ぶときの無作為と、割り付けるときの無作為**：実験計画の無作為化（{{unit:U32}}）

### 説明してみる

::: task
地域→店→客の3段で客を選んだ調査で、10人が答えた。店は売上に比例した確率で選んだので、駅から遠い小さな店（売上が大きな店の91分の1）はめったに選ばれない。選んだ店の中では、どの店でもレシート100枚に1枚の割合で客を選んだので、客1人の選ばれる確率も、大きな店の客の91分の1になる。今回はその小さな店も選ばれ、そこの客1人が答えた。選ばれる確率の逆数で重みを付けると、大きな店の9人の重みは1人50、小さな店の1人の重みは4550 になった。担当者は「選ばれる確率の逆数で重みを付けたので、偏りは直り、結果は正確になった」と書いた。重みが直すものと直さないもの、この報告のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（選ばれる確率が正しく分かり、選ばれた人が全員答えたとみて）**：選ばれる確率の逆数で重みを付けると、選ばれやすさの違いから来る偏りは直る。ところが重みの合計 9×50＋4550＝5000 のうち4550、つまり91% を1人が持つので、重み付きの平均は、ほとんどその1人の答えで決まる。偏りは直っても、選び直すたびに大きく揺れる（ばらつきが大きい）。

**前提を外すと**：重みが直すのは選ばれやすさの違いだけで、選ばれた人が答えなかったことによるずれは直らない。

**解釈の例**：
- その1人は、たまたまその日に来ていた遠くの客で、91% の重みが、その人だけの事情をチェーン全体に広げている
- 駅から遠い小さな店の客には、大きな店の客とは違う不満がまとまってあり、その1人はその声を表している

どちらかは、この10人の答えからは決められない。

**統計の外で決めること**：偏りを直すことと、ばらつきを小さくすることがぶつかるとき、どちらを優先するか。小さな店の客を多めに選ぶように段を設計し直すか、重みに上限を付けるか、小さな店の声を別に報告するかは、調査の目的（全体の水準か、小さな店の声か）と費用で決まる。どれにしても、重みの付け方と、重みの大きい回答があることを報告に書いて、読む人が確かめられるようにする。
:::
