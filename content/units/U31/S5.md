### なぜ？｜ばらつきの大きい層に多く配ると、なぜ全体の推定が安定するのか

ラボは、大きさが同じ2つの層（割合0.5 ずつ）に100人を振り分ける。層1の標準偏差40、層2の標準偏差10 から始め、比例配分とネイマン配分の振り分けと標準誤差を読む。次に2つの標準偏差を同じ値にそろえ、振り分けがどう変わるかを見る。読む前に、なぜそうなるのかを自分の言葉で書いてから開く。

::: toggle 動かしてから開く
比例配分は層の大きさだけで決めるので、50人ずつ。ネイマン配分は「層の大きさ×標準偏差」で決めるので、層1に80人、層2に20人を配る。標準誤差は比例配分で約2.92、ネイマン配分で2.50 と小さくなる。2つの標準偏差をそろえると、ネイマン配分も50人ずつになり、差は消える。

層化の推定値のばらつきは、層ごとの平均のばらつきを、層の割合で重みを付けて足したもの。層の平均のばらつきは「標準偏差÷√人数」なので、標準偏差の大きい層は人数が少ないと平均が大きく揺れ、全体の揺れのほとんどを作る。そこに人を回すと、揺れの大きい所が小さくなる。標準偏差の小さい層は少ない人数でも平均が定まるので、人を減らしても失うものが少ない。だから「人数を層の大きさに比例させる」より、「揺れの大きい所に多く」の方が、同じ100人で全体が安定する。
:::

### 1つの数で何が消えるか｜「回答率45%」

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

ラボの「賛成」を「満足」と読みかえる。本当の満足の割合0.5、満足の人も不満の人も回答率0.45 で始める。全体の回答率は 0.5×0.45＋0.5×0.45＝0.45。次に、満足の人の回答率を0.6、不満の人を0.3 にする。全体の回答率は、やはり 0.5×0.6＋0.5×0.3＝0.45。2つの場面で、集まった答えの満足の割合と偏りを比べる。

::: toggle 動かしてから開く
**何が複雑にしているか**：全体の回答率は2つとも45% で同じ。ところが、はじめの場面では集まった答えの満足の割合が0.5 で偏りは0、あとの場面では約0.667 で偏りは約0.167 になる。

**なぜ1つの数では言えないか**：偏りを決めるのは回答率の高さではなく、満足の人と不満の人で回答率がどれだけ違うか。回答率45% という1つの数は、その違いを消してしまう。回答率が30% でも、満足の人と不満の人で同じなら偏りは0。回答率が90% でも、答えなかった10% がみな不満なら偏りが残る。

**どう分けて考えるか**：「全体でどれだけ答えたか」と「答えた人と答えなかった人で、知りたいことがどれだけ違うか」に分ける。後の方は、答えなかった人の答えがないので、集まった答えだけからは分からない。

**数字とどう向き合うか**：答えなかった人の一部に追加で聞く、全員について分かる記録（来店回数・購入額など）で答えた人と答えなかった人を比べる、など、データの外から確かめる手がかりを探す。それがないうちは、回答率の高さを「偏りが小さい」根拠にしない。
:::

### ほかでは？｜つながり

- **層の重み付き平均**：重み付きの平均（{{unit:U06}}）
- **単純無作為抽出と名簿**：母集団・標本・無作為抽出（{{unit:U17}}）
- **n を4倍にすると標準誤差が半分**：標本平均の性質（{{unit:U18}}）
- **「偏り」という同じ言葉**：推定量の偏り（{{unit:U21}}）は推定の式から来るずれ、調査の偏りは選び方・答え方から来るずれ
- **選ぶときの無作為と、割り付けるときの無作為**：実験計画の無作為化（{{unit:U32}}）

### 説明してみる

::: task
地域→店→客の3段で客を選んだ調査で、10人が答えた。選ばれる確率の逆数で重みを付けると、9人の重みは1、駅から遠い小さな店の1人の重みは91 になった。担当者は「選ばれる確率の逆数で重みを付けたので、偏りは直り、結果は正確になった」と書いた。重みが直すものと直さないもの、この報告のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（選ばれる確率が正しく分かり、選ばれた人が全員答えたとみて）**：選ばれる確率の逆数で重みを付けると、選ばれやすさの違いから来る偏りは直る。ところが重みの合計100 のうち91 を1人が持つので、重み付きの平均は、ほとんどその1人の答えで決まる。重みがみな同じなら10人分の情報があるが、ここでは実質1人分あまりしかない（重みの合計の2乗÷重みの2乗の合計＝100²÷(9＋91²)≒1.2）。偏りは直っても、ばらつきは大きくなる。さらに、重みが直すのは選ばれやすさの違いだけで、選ばれた人が答えなかったことによる偏りは直らない。

**解釈の例**：
- 駅から遠い小さな店の客は、ほかの客とは違う声を持っているので、重い重みは必要。ただし1人では、その声を代表できない
- 小さな店の客をもっと多く選ぶように最初の段を設計し直せば、重みの差は小さくなり、偏りとばらつきを両方抑えられる

**統計の外で決めること**：偏りを直すことと、ばらつきを小さくすることがぶつかるとき、どちらを優先するか。それは調査の目的（全体の水準か、小さな店の声か）と費用で決まる。どちらにしても、重みの付け方と、重みの大きい回答があることを報告に書いて、読む人が確かめられるようにする。
:::
