### 0｜入口の問い

::: task
全100店のうち大規模店は20店、小規模店は80店。各層から10店ずつ調べると、平均売上は大規模200万円、小規模50万円だった。調べた20店をそのまま平均した125万円を「全店の平均」としてよいか。別の調査では、ネットで1万人が答え、80%が賛成だった。人数が多いので信頼できるのか。
:::

^ まだ答えなくてよい。単純無作為抽出（{{unit:U17}}）のほかの選び方（層化・集落・系統・多段）を区別し、選び方に合わせて集計すること、「たまたまのばらつき（標本誤差）」と「調べ方から来るずれ（非標本誤差）」を分けることが初学のゴール。

### 1｜前提チェック（2分）

::: toggle 3問で確認（答えも中にある）
1. 100店から10店を単純無作為抽出するとき、ある1店が選ばれる確率は？ → 10÷100＝0.1
2. 標準偏差 σ の母集団から n 個取ると、標本平均の標準誤差は？ → σ÷√n（n を4倍にすると半分）
3. 割合0.4 の層の平均が150、割合0.6 の層の平均が50 のとき、全体の平均は？ → 0.4×150＋0.6×50＝90

1が不安なら {{unit:U17}}、2が不安なら {{unit:U18}}、3が不安なら {{unit:U06}} の初学へ。終わったらここへ戻る。
:::

### 2｜意味の理解：選び方と、2種類の誤差　{{power:P3}}

::: ask 単純無作為のほかに、どんな選び方がある？
→ **層化抽出**：母集団を重ならない層（大規模店・小規模店など）に分け、**全部の層から**それぞれ選ぶ。**集落抽出**：店や地域などの集まりを**いくつか選び、その中を全部**調べる。**系統抽出**：無作為に決めた開始点から名簿を**一定の間隔**で選ぶ。**多段抽出**：地域→店→客のように**段を重ねて**選ぶ。選ばれる確率が人によって違うときは、1人の答えを「1÷選ばれる確率」人分として数える（選ばれにくい人ほど、多くの人を代表する）。
:::

::: ask 層化と集落は、どちらも「グループに分ける」のでは？
→ 分け方は似ていても逆。層化は**全部の層から少しずつ**取るので、層の違いは誤差に入らない。集落は**いくつかの集まりを丸ごと**取るので、集まりの違いがそのまま誤差に入る。層の中は似ていて層の間が違うときに層化が効き、集まりの中がばらばら（集まりが全体の縮図）のときに集落でも損をしない。
:::

{{fig:FIG-U31-concept}}

^ 図の読み方：10地域×10店の100店を、1行が1地域の格子にした。左の層化はどの行（地域）からも1店ずつ、右の集落は1つの行を丸ごと選ぶ。どちらも10店を調べるが、地域の違いが推定値に入るかどうかが逆になる。

::: ask n を増やせば、どんな誤差も小さくなる？
→ ならない。**標本誤差**は、たまたま選ばれた標本の違いによるばらつきで、n を増やすと小さくなる。**非標本誤差**は、名簿の漏れ（{{unit:U17}}）、無回答や自分から答える人の偏り、設問の誘導、記入ミスなど**調べ方から来るずれ**で、そのうち一定の向きのずれ（偏り）は n を増やしても消えない。
:::

### 3｜式の構造　{{power:P1}}

$$
\bar x_{st}=\sum_h\frac{N_h}{N}\,\bar x_h
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| h | 層の番号：大規模・小規模 |
| N_h | 各層の**母集団**の店数：20店、80店 |
| N | 全店数100 |
| x̄_h | 各層の標本平均：200、50 |

**式を言葉で読む**：層の平均を、母集団で層が占める割合 N_h÷N で重み付けして足す。調べた数（各10店）ではなく、母集団の数（20店・80店）で重みを決めるのがポイント。

| 方法 | 選び方 | 気をつけること |
| --- | --- | --- |
| 層化抽出 | 全部の層から選ぶ | 集計で層の重み |
| 集落抽出 | 集まりを丸ごと | 集まりの中が似ると損 |
| 系統抽出 | 一定の間隔で選ぶ | 名簿の周期と重なる |
| 多段抽出 | 段を重ねて選ぶ | 各段の確率と重み |

| 誤差 | 原因の例 | n を増やすと |
| --- | --- | --- |
| 標本誤差 | たまたまの選ばれ方 | 小さくなる |
| 非標本誤差 | 名簿の漏れ・無回答・誘導 | 一定の向きの部分（偏り）は変わらない |

```txt
層化の集計：x̄_st＝Σ(N_h/N)×x̄_h（調べた数ではなく母集団の数で重み）
多段抽出：選ばれる確率＝各段の確率の積、重み＝1÷確率
総合誤差：√(偏り²＋標準誤差²)（平均二乗誤差（{{unit:U21}}）の平方根。n を増やしても偏りより小さくならない）
```

{{fig:FIG-U31-error}}

^ 図の読み方：集まった割合が本当より10ポイント高くずれる調べ方で、割合が0.5 前後のとき。標準誤差は100人で5、400人で2.5、1600人で1.25、1万人で0.5 ポイントと縮む。総合誤差は11.2・10.3・10.1・10.0 ポイントで、偏りの10 に近づくだけで、それより小さくならない。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　全100店のうち大規模店20店・小規模店80店。各層から10店ずつ調べると、平均売上は大規模200万円、小規模50万円だった。全店の平均売上を推定せよ。

1. 重み：20÷100＝**0.2**、80÷100＝**0.8**（母集団の店数で決める）
2. 0.2×200＋0.8×50＝40＋40＝**80万円**
3. 誤り：調べた20店をそのまま平均すると (200＋50)÷2＝**125** → 大規模店を重く見すぎる

{{lab:LAB-survey@s1-strat}}

::: warn
層化抽出＝**全ての層**から選ぶ。集落抽出＝**いくつかの集団**（店・地域）を選んで中を全部調べる。各層から同じ数を選んだら、集計では母集団の割合で重みを付け直す。
:::

::: key
全店の平均売上は約80万円。層化して重みを正しく付けると、少ない調査数でも店の構成を反映した推定ができる。回答が1万人でも、自分から答えた人だけなら偏りは消えない。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-survey@s1-design}}

1. **予測**：ラボの課題カードで、地域によって売上の水準が違うとき、集落（1地域を全部）の推定値のばらつきが、単純無作為と比べてどうなるかを選ぶ。
2. **操作**：結果を見たら、「格子に描く方法」を切り替え、「もう1回選ぶ」で選ばれる店（枠付きのマス）がどう変わるかを見る。次に地域の差を 1 → 2 → 0 と変える。
3. **観察**：4つのヒストグラムの幅（標準誤差）は、地域の差でどう変わるか。集落の幅はどうなるか。
4. **説明**：「地域の差が大きいと、層化は□、集落は□。なぜなら□」を1文で書く。
5. **ラボなしで**：10地域のそれぞれから無作為に1店ずつ選ぶのは、層化・集落・系統のどれか。1地域を選んで10店全部を調べるのはどれか。

::: toggle 答え（書いてから開く）
- **観察**：地域の差を大きくすると、層化の幅は単純無作為より狭くなり、集落の幅は広くなる。地域の差0 にすると、4つの方法の幅はほぼそろう（どれだけ違うかは、応用の「法則を見つける」で確かめる）。
- **説明の例**：「地域の差が大きいと、層化は精度が上がり、集落は精度が下がる。層化は全部の地域から取るので地域の違いが誤差に入らないが、集落は1つの地域しか見ないので、どの地域を引いたかがそのまま推定値に出るから」
- **ラボなしで**：10地域のそれぞれから無作為に1店ずつ＝**層化**（地域が層）。1地域を全部＝**集落**。
:::
