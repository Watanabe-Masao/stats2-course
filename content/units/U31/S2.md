- [ ] 標本誤差と非標本誤差の違いと、n を増やしたときの変わり方を言える

::: toggle 答え（言ってから開く）
1. 層化＝全部の層から選ぶ。集落＝いくつかの集まりを丸ごと調べる。系統＝無作為な開始点から一定の間隔で選ぶ。多段＝地域→店→客のように段を重ねて選ぶ。
2. 層の平均を、母集団で層が占める割合（N_h÷N）で重み付けして足す。調べた数で割らない。
3. 標本誤差はたまたまの選ばれ方によるぶれで、n を増やすと小さくなる。非標本誤差は名簿の漏れ・無回答・誘導などの偏りで、n を増やしても変わらない。
:::

**お手本：ネットで1万人が答えて80%が賛成、から言えること**

- **条件**：自分から回答した1万人の80%が賛成だったとき
- **対象と結論**：「回答した人の中では賛成が多い」までは言える。全体の賛成率の推定としては使えない
- **根拠**：答える人が自分で選んでいるので、賛成の人ほど答えやすいなどの偏り（非標本誤差）があっても分からない。人数が多いと区間は狭くなるが、偏りは小さくならない
- **成り立たない場合**：名簿から無作為に選び、回答率が賛否で変わらないと確かめられれば、全体の推定として使える。確かめられないときは、データの集め方を変える（無作為に選び直す・答えなかった人に追加で聞く）

::: toggle つなげると（お手本の文）
「自分から回答した1万人の80%が賛成だったとき、言えるのは『回答した人の中では賛成が多い』までで、全体の賛成率の推定としては使えない。答える人が自分で選んでいるので、賛成の人ほど答えやすいといった偏りがあっても分からず、人数を増やしても偏りは小さくならないからである。ただし、名簿から無作為に選び、回答率が賛否で変わらないと確かめられれば、全体の推定として使える。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「大規模店と小規模店から10店ずつ調べた20店の平均売上125万円を、全店の平均として報告しました。回答率は30%と低かったのですが、回答数を増やしたので誤差は小さくなりました。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 各層から同じ数を選んだら、母集団での層の割合で重み付けする（0.2×200＋0.8×50＝80）。
- 回答数を増やして小さくなるのは標本誤差だけ。回答率の低さが問題になるのは、答える人と答えない人で中身が違うとき（非標本誤差）で、これは回答数では消えない。

**言い直しの例**

「全店の平均売上は、大規模店20店・小規模店80店の割合で重み付けして約80万円と推定する。回答数を増やしたので、たまたまの選ばれ方によるぶれは小さくなった。ただし回答率が30%なので、答えた店と答えなかった店で売上の傾向が違えば、その偏りは残る。」
:::

::: toggle 取り違えやすい言葉
- **「層化抽出」と「集落抽出」**：全部の層から少しずつ／いくつかの集まりを丸ごと
- **「標本誤差」と「非標本誤差」**：たまたまのぶれ（n で減る）／調べ方の偏り（n で減らない）
- **「調べた数」と「母集団の数」**：重みは母集団の数（20店・80店）で決める
- **「回答率が低い」と「偏っている」**：回答率が低くても、答える人と答えない人で中身が同じなら偏らない
- **「系統抽出」と「単純無作為抽出」**：系統は間隔で選ぶので、名簿の周期と重なると偏る
:::

### 選び方の早見

| 方法 | 効くとき |
| --- | --- |
| 層化抽出 | 層の中は似ていて、層の間が違う |
| 集落抽出 | 集落が全体の縮図（中がばらばら） |
| 系統抽出 | 名簿の並びに周期がない |
| 多段抽出 | 全体の名簿がない・調べる場所を絞りたい |

^ 誤差の早見：標本誤差は n を増やすと小さくなる。非標本誤差（名簿の漏れ・無回答・自分から答える人の偏り・設問の誘導・記入ミス）は n では消えない。
