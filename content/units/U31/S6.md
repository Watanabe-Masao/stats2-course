### 探究｜3つの「満足の割合」は、それぞれ何を数えた割合か

あるチェーンで、客の満足を3つのやり方で調べた。

| 調べ方 | 答え | 満足の割合 |
| --- | --- | --- |
| 店頭のタブレット（会計のたびに画面に出る） | 2400回 | 82% |
| 電話（会員の名簿から無作為に300人を選んだ） | 180人 | 65% |
| 4店で、ある1日の客全員に聞いた | 420人 | 70% |

タブレットの答えは、会員カードで来店の回数が分かる。

| タブレットの答え | 答えた回数 | 満足の割合 |
| --- | --- | --- |
| 月に8回ほど来る客 | 1600回 | 90% |
| 月に2回ほど来る客 | 800回 | 66% |

本部のメモ：「いちばん多く答えが集まったタブレットの82% を、チェーンの客の満足とする」。3つの数がずれるのはなぜか。それぞれ、何を1つと数えた、どの集まりの割合なのか。

1. 表とメモから、確かめたいことを自分で問いにする（例：タブレットの2400回は、何人の客の答えか）
2. タブレットの答えを、来店ごとから客ごとに直す。月8回の客の答えは8回分、月2回の客の答えは2回分数えられているので、1回の答えに「1÷来店の回数」の重みを付けて満足の割合を出す
3. 上のラボ（「賛成」を「満足」と読みかえる）で、本当の満足を0.65 にしたまま、満足の人の回答率が不満の人の何倍なら、集まった答えが2 で出した割合に近くなるかを探す。その組み合わせが1通りかも見る
4. 電話の65% が、どの集まりについて言える数かを、「選んだ300人」「会員の名簿」「チェーンの客」の段に分けて書く
5. 下のラボで、地域を「店」、店を「客」と読みかえ、1つの単位を丸ごと調べる方法（集落）の推定値のばらつきが、単位の間の違いでどう変わるかを見る
6. 統計で言えることと言えないことを分け、3つの数の読み方を2つ以上書く

::: toggle 聞き取りで分かったこと（自分の問いを書いてから開く）
- タブレットは押さずに帰る客も多い。急いでいる客や不満のある客ほど押さない、と店員は感じている
- 電話は平日の昼にかけた
- 4店は、本部の担当者が通いやすい店を選んだ
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（記録が正しいとみて）**：
- タブレットの82% は、来店1回を1つと数えた割合。よく来る客ほど何度も数えられる。1回の来店で答える割合が客によらないとみて、客ごとに直すと、月8回の客は 1600÷8＝200人分、月2回の客は 800÷2＝400人分で、(200×0.9＋400×0.66)÷600＝0.74。2400回の答えは数え上げなので、標本誤差の区間を付けても、どの集まりの推定にもならない
- 客ごとの74% と電話の65% の差は、本当の満足が0.65 で、満足の人が不満の人の約1.5倍答えやすい（たとえば回答率0.3 と0.2）なら説明がつく。比が同じなら、回答率の高さが違っても同じ割合になる。ただし、本当の満足が0.74 で回答率に差がなくても同じ74% になり、タブレットの答えだけからはどちらか決められない
- 電話の65% は、選んだ300人のうち答えた180人の中の割合。名簿の会員についての推定にするなら、たまたまのばらつきは区間（約58〜72%）で示せるが、答えなかった120人の分は {{unit:U17}} と同じく両端でしか言えない。会員でない客は名簿にいないので、チェーンの客全体には、この数だけでは届かない
- 4店は、選んだ単位が4つ（店）。店ごとの違いが大きければ、420人に聞いても情報は4店分に近い（下のラボの集落）。そのうえ無作為に選んでいないので、区間を作っても、チェーン全体についての区間にはならない。言えるのは「その4店の、その1日の客」まで

3つの数は、同じ「満足の割合」でも、数える単位（来店・会員・ある日の客）と、届く集まりが違う割合。答えの数の多さ（2400回）は、どの集まりの割合かを変えない。

**解釈の例**：
- 満足している客ほどよく来るので、来店ごとの82% は常連の声に寄っている。客ごとの74% との差の大半は、それで説明できる
- 平日の昼に電話に出られる会員は、家にいる時間の長い客で、店の使い方がほかの客と違う。65% も、チェーンの客の満足とは向きの分からないずれがありうる
- 担当者が通いやすい4店は、本部の目が届き、店の運営が整っている。70% は、ほかの店より高めに出ているかもしれない

**統計の外で決めること**：メモの「チェーンの客の満足」に、どの数をどんな断り書きで使うか。それは報告で何をしたいかで決まる。
:::

### 課題｜本部に報告する「満足の割合」を選ぶ

**問い**　本部への報告に、満足の割合として1つを載せる。どれを載せるか。

- **ア**：タブレットの満足の割合（来店ごと）
- **イ**：電話で答えた人の満足の割合（標本誤差の区間を添える）
- **ウ**：タブレットの答えを、来店の回数で客ごとに直した満足の割合

**判断の材料**：報告の目的は、去年と比べて満足が上がったか下がったかを見ること。去年も同じやり方の電話（会員の名簿から無作為に300人、平日の昼）で、185人が答え、満足は126人だった。タブレットは今年入れたばかりで、去年の数はない。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（記録が正しいとみて）**：ア は来店ごとの数え上げで、よく来る客の声に寄る。ウ は答えた客ごとに直した割合だが、答えるかどうかを客が決めるので、どの集まりの推定にもならない。どちらも去年の数がなく、比べられない。イ の今年65% と去年68%（126÷185）の差3ポイントは、2つの年の標本を別々に無作為に選んだとみると、たまたまのばらつきを合わせた95% の幅（約±10ポイント）の中にある。答えない人による偏りが2つの年で同じ大きさなら、差には偏りが入らない。

**統計の外で決めること**：目的が去年との比較なので、去年と同じやり方で取った イ を載せる。回答率が60% と約62% で近いことを手がかりに、答えない人による偏りが去年と同じとみる。ただし、それは見立てで、偏りそのものは消えていない。報告には「会員の名簿から無作為に選んだ300人のうち答えた180人の中で65%、去年は68%、差はたまたまの範囲」と書き、会員でない客と答えなかった人の分は入っていないことを添える。ア・ウ は、来年もタブレットを続けて、同じ数え方どうしで比べる材料にする。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 自分の問いが、メモのどの言葉（「いちばん多く」「チェーンの客」）を確かめるものかを言えたか |
| 仮定 | 来店ごとに答える割合や、答える人と答えない人の違いの見立てを、数を読む前に書いたか |
| 方法 | 来店ごとを客ごとに直す重み・回答率の比・単位の数を、それぞれ計算したり動かしたりしたか |
| 検証 | 同じ74% が、違う回答率の組み合わせからも出ることを確かめたか |
| 切り分け | 言えること（何を数えた割合か・どの集まりまで届くか）と、言えないこと（答えなかった人・名簿にない客の満足）を分けたか |
| 解釈 | 3つの数の読み方を2つ以上並べ、報告する数とその理由を書いたか |
