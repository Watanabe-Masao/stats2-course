### 探究｜その調査の数字は、誰の声なのか

チェーン全体の客の満足度を知りたい。手元にある方法は、店頭のタブレットに自分から答えてもらう（数は多い）、レシートで無作為に選んだ客に電話する（数は少なく費用がかかる）、店を選んでその日の客全員に聞く（店を絞れて安い）の3つ。どれを、どう組み合わせるか。

{{lab:LAB-survey@s6-free}}

「消えない偏り」で回答率の違いと人数を、「抽出法を比べる」で店の違いの大きさを、「配分の仕方」で層への振り分けを動かす。決まった手順はない。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること**：自分から答える方法は、人数を増やしても、答える人と答えない人の違いによる偏りが残る。無作為に選んだ電話調査は、人数が少ないので標本誤差（区間の幅）は大きいが、回答率が賛否で同じなら偏らない。店を絞る方法は、店ごとの満足度の違いが大きいほど精度が下がる。

**解釈の例1**：数の多いタブレットの結果は「答えた人の傾向」として使い、全体の満足度は少人数でも無作為の電話調査で推定する。2つの差が大きければ、タブレットに答える人の偏りの手がかりになる。

**解釈の例2**：店ごとの改善に使うのが目的なら、全体の推定の精度より、各店で同じ聞き方を続けて変化を追うほうが役に立つ。偏りがあっても、同じ偏りが続くなら「前より良くなったか」は読める。

どちらを選ぶかは、調査の目的（全体の水準を知りたいのか、店ごとの変化を追いたいのか）と費用で決まり、統計だけでは決まらない。
:::

### 課題A｜自分の職場の調査を設計する

自分の職場で知りたいこと（客の満足度、商品の認知度など）を1つ選び、調べる前に次を書く。

| 項目 | 書くこと |
| --- | --- |
| 母集団と名簿 | 誰の声か、名簿から漏れる人はいるか |
| 選び方 | 層化・集落・系統・多段のどれか、その理由 |
| 集計 | 重みの付け方 |
| 偏り | 答えない人は誰か、それを確かめる方法 |

### 課題B｜「回答率30%」の調査をどう読むか

**問い**　本部から「回答率30%、満足80%」という店内調査の結果が届いた。この数字をどう読み、何を確かめるか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：回答率30%そのものではなく、答えた30%と答えなかった70%で満足度が違うかが問題になる。答えなかった人の一部に追加で聞く、来店回数や購入額など全員について分かる記録で、答えた人と答えなかった人を比べる。

**小さな例で検証**：ラボの「消えない偏り」で、満足の人の回答率と不満の人の回答率を変え、集まった割合が本当の割合とどれだけずれるかを見る。回答率が同じなら、30%でも偏りは0。

**成り立たない条件と、その先の判断**：答えなかった人の意見は、追加で聞かない限り分からない。追加調査の費用をかけるかどうか、結果をどこまで信じて施策を決めるかは、統計の外の判断になる。報告では「回答者の中では満足80%」と範囲を限って書く。
:::

### 課題C｜系統抽出の周期を探す

レジの記録から「50人おき」に客を選ぶとき、時間帯・曜日・レジの番号など、選ぶ間隔と重なりそうな周期を書き出し、それを避ける選び方を考える。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 誰の声を知りたいか（母集団）が明確か |
| 仮定 | 名簿の漏れ・回答の集まり方を書いたか |
| 方法 | 選び方と集計の重みを理由つきで決めたか |
| 検証 | ラボで偏りや精度を動かして確かめたか |
| 切り分け | 統計で言えることと、目的・費用による判断を分けたか |
