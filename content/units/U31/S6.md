### 探究｜3つの「満足の割合」は、それぞれ誰の満足か

あるチェーンで、客の満足を3つのやり方で調べた。

| 調べ方 | 答えた人 | 満足の割合 |
| --- | --- | --- |
| 店頭のタブレット（会計のあと自分から） | 2400人 | 82% |
| 電話（客の名簿から無作為に300人を選んだ） | 180人 | 65% |
| 4店で、ある1日の客全員に聞いた | 420人 | 70% |

本部のメモ：「いちばん多くの人が答えたタブレットの82% を、チェーン全体の満足とする」。3つの数がずれるのはなぜか。どの数が、誰の満足を表しているのか。

1. 表とメモから、確かめたいことを自分で問いにする（例：タブレットに答える人と答えない人は、同じような客か）
2. 上のラボ（「賛成」を「満足」と読みかえる）で、本当の満足を0.65、満足の人と不満の人の回答率を同じにして始める。回答率の差をどれだけ付けると、集まった答えが0.82 近くになるかを探す。答えが1通りに決まるかも見る
3. 電話で答えなかった人の数を出し、その人たちが全員満足・全員不満のときの満足の割合を両端として計算する
4. 下のラボで、地域の差を変えながら、1つの地域を全部調べる方法（集落）の推定値のばらつきを見る
5. 統計で言えることと言えないことを分け、3つの数の読み方を2つ以上書く

::: toggle 聞き取りで分かったこと（自分の問いを書いてから開く）
- タブレットは会計のあとに画面に出る。急いでいる客や、不満のある客は押さずに帰ることが多い、と店員は感じている
- 電話は平日の昼にかけた
- 4店は、本部の担当者が通いやすい店を選んだ。4店とも駅前の大きな店
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（記録が正しいとみて）**：
- タブレットは2400人なので、標本誤差は小さい（95%区間の半幅は約1.5ポイント）。ところが答えるかどうかを客が決めるので、区間は「答えた人」の範囲でしか意味を持たない。本当の満足が0.65 でも、満足の人の回答率0.5・不満の人0.2 なら、集まった答えは約0.82 になる。本当の満足が0.82 で回答率に差がなくても、同じ0.82 になる。どちらなのかは、タブレットの答えだけからは決められない
- 電話は300人を無作為に選んだが、答えたのは180人（回答率60%）。答えた人の中の満足は117人で65%、標本誤差の95%区間は約58〜72%。答えなかった120人については何も分からないので、全員不満なら117÷300＝39%、全員満足なら237÷300＝79%。何も仮定しないと、言えるのは39〜79% の範囲まで
- 4店は無作為に選んでいないので、標本誤差を計算しても、チェーン全体についての区間にはならない。420人に聞いても、店の違いが大きければ、情報は「4つの店」の分しかない（下のラボの集落のばらつき）。言えるのは「その4店の、その1日の客」まで

3つの数は、同じ「満足の割合」でも、違う人の集まりの割合。数の大きさ（2400人）は、どの集まりの割合かを変えない。

**解釈の例**：
- 不満のある客ほどタブレットを押さずに帰るとみれば、82% と65% の差の大半は、答える人の偏りで説明できる
- 電話も平日の昼で、その時間に電話に出られる客に偏る。65% も全体の満足とは限らず、偏りの向きは分からない
- 駅前の大きな店は品ぞろえが多く、満足が高めに出やすい。70% は、大きな店の客の満足に近い

**統計の外で決めること**：メモの「チェーン全体の満足」に、どの数をどんな断り書きで使うか。それは報告で何をしたいかで決まる。
:::

### 課題｜本部に報告する「満足の割合」を選ぶ

**問い**　本部への報告に、満足の割合として1つを載せる。どれを載せるか。

- **ア**：タブレットの満足の割合
- **イ**：電話で答えた人の満足の割合（標本誤差の区間を添える）
- **ウ**：電話で答えなかった人を、全員満足・全員不満の両端にとった範囲

**判断の材料**：報告の目的は、去年と比べて満足が上がったか下がったかを見ること。去年も同じやり方の電話（名簿から無作為に300人、平日の昼）で、186人が答え（回答率62%）、満足は68% だった。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（記録が正しいとみて）**：ア は答えることを自分で選んだ人の割合で、去年の数とは調べ方が違うので、並べても差の意味が分からない。イ は無作為に選んだ人のうち答えた人の割合で、たまたまのばらつきは区間で示せるが、答えなかった人による偏りは区間に入らない。ウ は答えなかった人について何も仮定しない範囲で、39〜79% と広く、去年の68% はその中に入るので、上がったか下がったかには何も言えない。イ の今年65% と去年68% の差3ポイントは、2つの年のたまたまのばらつきを合わせた95% の幅（約±10ポイント）の中にある。

**統計の外で決めること**：目的が去年との比較なので、去年と同じやり方で取った イ を載せる。回答率が60% と62% で近く、答えない人の偏りが去年と同じ向き・同じ大きさだとみれば、偏りは引き算で消え、差だけが読める。ただし、それは見立てで、偏りそのものは消えていない。報告には「無作為に選んだ300人のうち答えた180人の中で65%、去年は68%、差はたまたまの範囲」と書き、答えなかった人を両端にとった範囲（ウ）を断り書きに添える。去年と今年で答えない人が変わったと疑うなら、答えなかった人の一部に追加で聞く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 自分の問いが、メモのどの言葉（「いちばん多くの人」「チェーン全体」）を確かめるものかを言えたか |
| 仮定 | 答える人と答えない人がどう違うかの見立てを、数を読む前に書いたか |
| 方法 | 回答率の差・答えなかった人の両端・店の違いを、それぞれ動かしたり計算したりしたか |
| 検証 | 同じ0.82 が、違う回答率の組み合わせからも出ることを確かめたか |
| 切り分け | 言えること（どの集まりの割合か・区間・両端）と、言えないこと（答えなかった人の満足）を分けたか |
| 解釈 | 3つの数の読み方を2つ以上並べ、報告する数とその理由を書いたか |
