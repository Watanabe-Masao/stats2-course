### 探究｜断った店の代わりに入れた店は、何を変えたか

本部が、全40店（大規模10店・小規模30店）の客の満足を調べた。計画は、層ごとにくじで大規模2店・小規模6店を選び、各店で来店客30人に聞くこと。くじで選んだ大規模の A 店は「忙しい」と断ったので、本部は近くの小規模の Z 店で代わりに30人に聞いた。

| 店（層） | 満足（30人中） |
| --- | --- |
| B（大規模） | 18 |
| C（小規模） | 24 |
| D（小規模） | 22 |
| E（小規模） | 25 |
| F（小規模） | 23 |
| G（小規模） | 26 |
| H（小規模） | 24 |
| Z（小規模。A の代わり） | 28 |

本部のメモ：「240人中190人が満足、約79%。8店・240人に聞いたので、全店の満足は約79% と言える」。この79% は、計画した調査の結果と何が違うのか。断った店があるとき、何をどう報告すればよいか。

1. 表とメモから、確かめたいことを自分で問いにする（例：Z 店を入れたことで、何が計画と変わったか）
2. 240人のうち大規模店の客は何人か。計画では何人だったか。母集団で大規模店が占める割合と比べる
3. Z 店を外し、計画した層の重み（店の数の割合）で全店の満足を出す。上のラボで、大規模店の割合を計画の値から小さくしていくと、推定がどう動くかを見る
4. 大規模の層の満足が、何店の値から来ているかを数える。その層の店ごとのばらつきは、この表から分かるか
5. 統計で言えることと言えないことを分け、断った店の扱い方を2つ以上書く

::: toggle 聞き取りで分かったこと（自分の問いを書いてから開く）
- A 店は駅前でいちばん混む大規模店。断った理由は「レジが混んでいて、客に声をかける人手がない」
- Z 店は本部の隣にあり、本部の人がよく立ち寄る
- 大規模店は、小規模店より品ぞろえが多いが、レジの待ち時間が長い
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（表の数が正しいとみて）**：
- 240人のうち大規模店の客は B 店の30人だけで、8分の1（0.125）。計画では60人で4分の1、母集団の店の数の割合（10÷40＝0.25）と同じだった。Z 店を入れたことで、満足の低い大規模の層が半分の重みになり、小規模の層が重くなった。79% は、計画した重みの推定ではない
- Z 店を外し、計画の重みで出すと、0.25×60%＋0.75×80%＝75%（小規模の6店は144÷180＝80%、大規模は B 店の18÷30＝60%）。ただし、大規模の層の60% は B 店1店だけから来ていて、大規模店どうしがどれだけ違うかは、この表からは分からない。層の推定のばらつきも見積もれない
- 小規模の6店の満足は22〜26人で、店による違いは小さい。小規模の層の80% は、くじで選んだ6店から来ている
- Z 店はくじで選んでいないので、その28人を、どの層のどの店の代わりとしても数えられない

**解釈の例**：
- A 店は B 店と同じような大規模店で、断った理由は満足と関係ない。そうなら、計画の重みの75% が全店の満足に近い
- A 店はレジがいちばん混む店で、満足は B 店より低い。そうなら、全店の満足は75% よりさらに低い
- Z 店は本部の人がよく立ち寄るので、店の運営が整い、満足が高めに出ている。メモの79% は、その分も上に引かれている

どれかは、この8店の数字だけからは決められない。

**統計の外で決めること**：断った店に、日や聞き方を変えて頼み直すか。頼み直せないとき、断った店をどう扱って報告するか。
:::

### 課題｜断った店の扱いを決めて報告する

**問い**　本部の経営会議に、全店の満足を1つの数で報告する。次のどれにするか。

- **ア**：Z 店を含めた240人をそのまま数える
- **イ**：Z 店を外し、計画の重み（大規模0.25・小規模0.75）で、大規模の層は B 店の値を使う
- **ウ**：大規模の層は1店しかなく分からないとして、小規模の層の満足だけを報告する

**判断の材料**：上の「聞き取りで分かったこと」と、大規模店がチェーンの売上の6割を占めること。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（表の数が正しいとみて）**：ア は Z 店を入れて大規模の層を半分の重みにしたので、計画した重みの推定ではなく、くじで選んでいない店も入る。イ は計画の重みに合うが、大規模の層は B 店1店に頼り、その層のばらつきは見積もれない。ウ は言えることだけを言うが、全店の満足にはならない。

**統計の外で決めること**：大規模店は売上の6割を占め、店の数では4分の1でも、会議で見たいのは大規模店を抜いた数ではないとみて、ウ は選ばない。ア は、満足の高めに出やすい Z 店を入れ、大規模の層を軽くするので選ばない。イ を「75%（大規模の層は1店の値。A 店は断った）」と書いて載せる。A 店がいちばん混む店であることから、大規模の層は B 店より低い向きの見立てもあり、全店の満足は75% より低いかもしれないと添える。会議のあとで、A 店に日を変えて頼み直すか、断った店を前もって決めた順の次の大規模店に替える決まりを作るかを提案する。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 自分の問いが、メモのどの言葉（「8店・240人」「全店の満足」）を確かめるものかを言えたか |
| 仮定 | 断った店が、断らなかった店と似ているかどうかの見立てを、数を読む前に書いたか |
| 方法 | 層ごとの人数を計画と比べ、計画の重みで出し直したか |
| 検証 | ラボで大規模店の割合を小さくしたとき、推定がどう動くかを確かめたか |
| 切り分け | 言えること（計画の重みの推定・1店に頼る層）と、言えないこと（断った店の満足）を分けたか |
| 解釈 | 断った店の満足の見立てを2つ以上並べ、報告する数とその理由を書いたか |
