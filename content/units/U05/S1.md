### 0｜入口の問い

::: task
20日分の売上（万円）が手元にある。店長が「平均は27.6万円だから、だいたい毎日27万円くらい売れている」と言った。この20個の数字を、どうまとめて見れば、この言い方が合っているか確かめられるか。

12, 15, 18, 19, 21, 22, 22, 24, 25, 26, 27, 28, 29, 30, 31, 33, 35, 38, 42, 55
:::

^ まだ答えなくてよい。この20個を表と図にまとめ、「どこに集まり、どちらに裾が伸び、飛び抜けた日はあるか」を言えるようになるのが初学のゴール。

### 1｜前提チェック（2分）

::: toggle 3問だけ確かめる（答えも中にある）
1. 6, 2, 9, 4 を小さい順に並べ、真ん中の2つの平均を求めよ → 2, 4, 6, 9 で (4＋6)÷2＝5
2. 20日のうち9日は何%？ → 45%
3. 売上（万円）は何尺度か → 比例尺度（量的変数。平均も何倍も使える）

1・2が不安なら {{unit:U01}}、3が不安なら {{unit:U04}} の初学へ。終わったらここへ戻る。
:::

### 2｜意味をつかむ：何を知りたいかで、まとめ方を選ぶ　{{power:P3}}

20個の数字をそのまま眺めても、全体の様子は見えない。知りたいことに合わせて、まとめ方を選ぶ。

::: ask 分布の「形」を見たい（どこに集まり、どちらに裾が伸びるか）
→ **度数分布表**と**ヒストグラム**。値を階級（区間）に分けて数え、棒をすき間なく並べる。
:::

::: ask 真ん中と散らばり・飛び抜けた値を、手早く比べたい（店舗別・月別など）
→ **箱ひげ図**。小さい順に並べて4等分する位置の値（四分位数）で描く。
:::

::: ask データが少なく、1つ1つの値も残したい
→ **幹葉図**（12, 15, 21 なら「1｜2 5」「2｜1」）。十の位を幹、一の位を葉にする。
:::

| 知りたいこと | まとめ方 |
| --- | --- |
| 形（集まり方・裾・山の数） | 度数分布表・ヒストグラム |
| 真ん中・散らばり・外れ値の比較 | 箱ひげ図 |

### 3｜式の構造を読む：箱の長さと「柵」　{{power:P1}}

$$
IQR=Q_3-Q_1,\qquad \text{柵}=Q_1-1.5\,IQR,\ \ Q_3+1.5\,IQR
$$

| 記号 | 意味（20日の売上の例） |
| --- | --- |
| Q₁・Q₂・Q₃ | 小さい順に並べて4等分する位置の値（Q₂が中央値） |
| IQR | 四分位範囲＝真ん中50%の幅（箱の長さ） |
| 柵 | 箱の端から IQR の1.5倍だけ離れた線。外側の値が外れ値候補 |

**式を言葉で読む**：「真ん中の半分がどれだけ広がっているか（IQR）」を物差しにして、その1.5倍よりさらに外にある値を「飛び抜けている」とみなす。物差しが真ん中の半分なので、飛び抜けた値そのものには左右されない。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　入口の20日分の売上で、度数分布表を作り、四分位数・四分位範囲・外れ値の柵を求めよ。

| 階級（万円） | 度数 | 相対度数（累積） |
| --- | --- | --- |
| 10以上20未満 | 4 | 0.20（0.20） |
| 20〜30 | 9 | 0.45（0.65） |
| 30〜40 | 5 | 0.25（0.90） |
| 40〜50 | 1 | 0.05（0.95） |
| 50〜60 | 1 | 0.05（1.00） |

^ 相対度数＝度数÷20。かっこ内の累積相対度数は上から足していった値。

1. 中央値 Q₂＝10番目と11番目の平均＝(26＋27)÷2＝**26.5**
2. Q₁＝下半分10個の真ん中＝(21＋22)÷2＝**21.5**
3. Q₃＝上半分10個の真ん中＝(31＋33)÷2＝**32**
4. IQR＝32−21.5＝**10.5**、1.5×IQR＝15.75
5. 柵は 21.5−15.75＝5.75 と 32＋15.75＝47.75 → **55は外れ値候補**。ひげは柵の内側の最大値 42 まで伸ばす。

^ 図の読み方：上のヒストグラムは「どこに何日あるか」。20万円台の棒がいちばん高く、右（大きい側）に低い棒が続く。下の箱ひげ図の箱は真ん中の半分（10日分）、太線が中央値、○が外れ値候補の55。

::: key
売上は20万円台に集まり、右（大きい側）に裾が伸びている。55万円の日は「誤り」と決めつけず、理由（イベントなど）を確かめる。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-dist@s1-box}}

1. **予想**：ラボの課題カードで、最大の55万円を大きくしたとき、平均と中央値のどちらが大きく動くかを選ぶ。
2. **操作**：結果を見たら、最大値を −／＋ で 42〜110 の間で動かす。箱・柵・○（外れ値候補）がどう変わるかも見る。
3. **観察**：平均（▲）と中央値（太線）は、それぞれどう動いたか。55がいくつ以下になると外れ値候補でなくなったか。
4. **説明**：「平均は□ので外れ値に引っ張られるが、中央値は□ので動かない」を1文で書く。
5. **ラボなしで**：20日の売上で、最大の55を65に直すと、中央値とIQRは変わるか。

::: toggle 答え（書いてから開く）
- **観察**：最大値を大きくすると平均（▲）だけが右へ動き、中央値（太線）と箱は動かない。上の柵は47.75なので、最大値が47.75以下になると外れ値候補でなくなる。
- **説明の例**：「平均は全部の値を足して割るので外れ値に引っ張られるが、中央値は真ん中の順位の値なので端の値が変わっても動かない」
- **ラボなしで**：**変わらない**。中央値は10番目と11番目、IQRはQ₁とQ₃（5〜6番目と15〜16番目）で決まり、20番目の値は使わない。
:::

**統計図に慣れる**：同じ20日の売上を、点・ヒストグラム・箱ひげ図で縦に並べる。点を指で左右に動かし、どの図のどこが動くか、どの数が変わるかを見る。端の点と真ん中の点で、動き方を比べる。
