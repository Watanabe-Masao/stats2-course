### 探究｜待ち時間のヒストグラムの、とがった柱

ある店で、レジの待ち時間を1か月記録した。手書きの記録140件を幅1分のヒストグラムにすると、5分・10分・15分・20分の柱だけが飛び抜けて高い。140件のうち70件が5の倍数の分だった。本部の担当者は「客は5分おきにまとまって並ぶ」と書いた。聞き取ると、次のことが分かった。
- 手書きの記録は、店員がレジの横の時計（分の目盛りだけ）を見て、分単位で書いた
- 混んでいる時間は、何人か分をあとでまとめて書いた
- 月の途中から、8台のうち2台のレジで自動計測（秒まで測って、分に切り捨てる）を始めた。自動計測の60件では、5の倍数の分は9件だった

:::

1. 5の倍数の柱が高いのは、待ち時間そのものか、記録の仕方か。読み方を2つ以上書く
2. ラボで手書きの140件を幅1分と幅5分で描き、それぞれで何が見え、何が消えるかを書く
3. 手書きの140件と自動計測の60件を比べるとき、何に気をつけるかを書く
4. 統計で言えることと言えないことを分ける
5. 「待ち時間5分以内の客の割合」を報告するとき、どう数えるかを決める（下の課題）

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（記録された値をそのまま数えて）**：手書きの140件は、半分（70件）が5の倍数の分に集まっている。待ち時間がなめらかに散らばっていれば、1分ごとの値のうち5の倍数はおよそ5つに1つで、自動計測の60件でも 9件（15%）。手書きの記録は、5の倍数に大きく偏っている。

**幅を変えると**：幅1分では、5の倍数の柱のとがりが見える。幅5分にすると柱のとがりは消えてなめらかに見えるが、5分・10分・15分の値はどれも「以上・未満」の境目の右の階級（5〜10 など）に入る。本当は4分や6分だった客が「5分」と書かれていれば、その一部は 0〜5 の階級に入るはずだった。なめらかに見えるだけで、偏りが消えたわけではない。

**比べるときに気をつけること**：140件と60件は個数が違うので、相対度数で比べる。自動計測の2台は、混む時間帯に使うレジか、空いているレジかで、待ち時間そのものが違いうる。2つの記録の違いには、記録の仕方の違いと、レジの違いの両方が入っている。

**解釈の例**：
- 店員が時計を見て「だいたい5分」「だいたい10分」と丸めて書いた
- 混む時間にあとでまとめて書いたので、覚えている長さを切りのよい数で書いた
- 5分おきに客がまとまって来る理由（バスの到着など）が本当にある

どれが当たるかは、手書きの記録だけからは決められない。

**統計の外で決めること**：待ち時間の目標（「5分以内」など）を決めるのは店。境目が5分ちょうどだと、手書きの「5分」の30件をどちらに数えるかで、割合が大きく変わる。
:::

### 課題｜「5分以内の客の割合」をどう出すか

**問い**　手書きの140件で、5分より短い客は36件（約26%）、5分ちょうどと書かれた客を入れると66件（約47%）になる。本部に「5分以内の客の割合」を報告したい。次の1か月で、どうするか。

- **ア**：8台全部のレジに自動計測を入れ、秒までの記録で数える
- **イ**：手書きを続け、「5分」と書かれた値の扱いを決めて（たとえば半分を5分以内に数える）報告する
- **ウ**：1週間、自動計測のある2台で手書きも同時に続け、同じ客の2つの記録を突き合わせる

**判断の材料**：自動計測は1台10万円。2台で1週間あれば、同じ客の記録が100件ほど集まる見込み。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（記録のとおりに数えて）**：イ は、「5分」の30件の扱い方を決めた分だけ、26% から 47% の間のどこかの値になる。どの扱いが正しいかを、手書きの記録の中だけで確かめる方法はない。ウ は、同じ客の手書きと自動計測を突き合わせるので、「5分」と書かれた客が本当は何分だったかの分かれ方が分かり、イ の扱いを決める根拠になる。ただし2台のレジでの丸めの癖が、ほかのレジの店員でも同じとは限らない。ア は記録の丸めをなくせるが、費用が 80万円（8台×10万円）かかり、入れる前の記録とは比べにくくなる。

**統計の外で決めること**：報告の目的で選ぶ。目標の5分を守れているかを今月の会議で示したいなら、イ で 26%〜47% の幅のまま報告し、「5分」の扱いを書き添える。来月から正しく測りたいなら、ウ で丸めの癖を確かめてから、ア を入れるかを決める。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 柱のとがりが、待ち時間の性質か、記録の仕方かを問いにしたか |
| 仮定 | 待ち時間が5の倍数に集まる理由がないなら、という比べる基準を置いたか |
| 方法 | 幅を変えて描き、境目の値がどの階級に入るかを確かめたか |
| 検証 | ラボで、手書きと自動計測を同じ幅で比べたか |
| 切り分け | 言えること（記録が5の倍数に偏る）と、言えないこと（本当の待ち時間の分布）を分けたか |
| 解釈 | とがりの読み方を2つ以上並べ、次に取るデータを書いたか |
