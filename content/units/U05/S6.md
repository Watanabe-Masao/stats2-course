### 探究｜キャンペーンは効いたのか

2店の120日分の日販（架空）がある。キャンペーンをした日は、しなかった日より売上の平均が高い。「だからキャンペーンは効いている」と言えるか。

{{lab:LAB-explore@s6-camp}}

見る値（売上・客数・客単価）、分け方（キャンペーン・平日／週末・天気・店・前半／後半）、絞り方、図を自分で選んで動かす。決まった手順はない。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること**：全部の日で比べると、キャンペーンの日の売上の平均は高い。ところが平日だけ・週末だけに絞ると、差はずっと小さくなる。キャンペーンの日は週末に多い。客単価は、キャンペーンの日の方がやや低い。

**解釈の例1**：差の大部分は「週末だから」で、キャンペーン自体の効果は小さい。客単価が下がっているので、値引きで客数は増えても売上はあまり増えていない。

**解釈の例2**：週末にキャンペーンをすること自体が店の方針で、週末の客を逃さない効果がある。この120日のデータには、キャンペーンをしなかった週末との比べ方に限りがあり、効果は小さく見えているだけかもしれない。

どちらの解釈を選ぶかは、統計だけでは決まらない。費用、現場の手応え、競合の動きなども合わせて判断する。確かめたいなら、平日と週末それぞれで、キャンペーンをする日を無作為に決めて比べる（{{unit:U32}}）。
:::

### 課題A｜自分の店の「日販の見取り図」を作る

自分の職場のデータ（日販・客数・客単価など）を20日分以上集め、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 度数分布表 | 階級の幅とその理由 |
| ヒストグラム | 山の数・裾の向き |
| 箱ひげ図 | Q₁・中央値・Q₃・柵・外れ値候補 |
| 外れ値候補の理由 | イベント・天候・入力ミスなど |
| 言えないこと | この図だけでは分からないこと |

### 課題B｜階級の幅を決めるルールを作る

**問い**　売場で使うヒストグラムの「階級の幅」を、毎回迷わず決めたい。自分のルールを作り、その弱点も書く。

::: toggle 1つの考え方の例（自分で作ってから開く）
**ルール**：①データの範囲（最大−最小）を見る ②スタージェスの公式で階級の数の目安を出す（20日なら5個前後）③範囲÷階級の数を、切りのよい幅（5・10・20）に丸める。

**小さな例で検証**：ラボの「度数分布」で20日の売上を幅5・10・20で描く。幅5では25〜30がいちばん高く、幅10では20〜30がいちばん高い。幅20では山がつぶれ、右の裾が見えにくい。幅10が「形」と「裾」の両方を見やすい。

**弱点**：二山のデータでは、幅が広いと山が1つにつぶれる。データが少ないと、どの幅でもでこぼこになる。迷ったら2通りの幅で描いて比べる。
:::

### 課題C｜外れ値の扱い手順書を作る

外れ値候補が見つかったときの手順（判定の基準 → 理由の確認 → 残すか直すかの判断 → 記録）を、自分の職場向けに5行で書く。過去のデータで2回試し、迷った所を書き足して直す。

### 課題D｜他の分野で「分布の形」を調べる

所得・地震の大きさ・待ち時間・テストの点など、分布の形が特徴的なものを2つ選ぶ。それぞれの形（裾の向き・山の数）と、その形になる理由、平均と中央値のどちらで代表させるのがよいかを書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何を知りたいか（形・比較・外れ値）が明確か |
| 仮定 | 階級の幅や四分位数の定義を明示したか |
| 方法 | 知りたいことに合う図と数を選んだか |
| 検証 | 小さな例やラボで確かめたか |
| 切り分け | その図で見えないことを書いたか |
| 解釈 | 統計で言えることと自分の解釈を分け、解釈を確かめる次のデータを考えたか |
