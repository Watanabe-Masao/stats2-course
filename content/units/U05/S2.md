**お手本：外れ値の判断を説明する**

- **条件**：Q₁−1.5×IQR 未満、または Q₃＋1.5×IQR を超える値があるとき
- **対象と結論**：その値は「外れ値候補」として扱う
- **根拠**：真ん中50%の幅（IQR）の1.5倍よりも、さらに外側に離れていて、他の大多数から飛び抜けているから
- **成り立たない場合**：この基準は目安で、外れ値候補でも正しい値のことがある（イベント日など）。誤りと決めつけて削らず、理由を確認する

::: toggle つなげると（お手本の文）
「Q₃＋1.5×IQR を超える値は外れ値候補として扱う。真ん中50%の幅の1.5倍よりさらに外側にあり、他から飛び抜けているからである。ただしこれは目安で、正しい値のこともあるので、理由を確かめずに削除しない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「A店とB店は箱ひげ図の真ん中の線が同じなので、売上の分布は同じです。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 「真ん中の線」は中央値。中央値が同じでも、箱の幅（IQR）やひげの長さ（散らばり・裾）は違うことがある。
- 山の数は箱ひげ図からは分からない。

**言い直しの例**

「A店とB店は中央値が同じなので、売上の真ん中の水準は同じである。ただし箱の幅やひげの長さを比べないと、散らばりや裾の伸び方が同じかは分からない。山の数まで確かめるにはヒストグラムを見る。」
:::

::: toggle 取り違えやすい言葉
- **度数・相対度数・累積度数**：度数＝その階級に入る個数（9日）／相対度数＝全体に対する割合（9÷20＝0.45）／累積度数＝小さい階級からの合計（30万円未満は13日）
- **ヒストグラムと棒グラフ**：ヒストグラム＝量的データ。棒をすき間なく並べ、**面積**が度数を表す／棒グラフ＝質的データ。棒の**高さ**が度数を表し、並べる順番は自由
- **外れ値と誤った値**：外れ値＝他から飛び抜けた値（統計的な目安で判定）／誤った値＝入力ミスなど。外れ値がすべて誤りとは限らない
:::

### 図の早見

| 図 | 向いている使い方 |
| --- | --- |
| ヒストグラム | 量的データの分布の形 |
| 箱ひげ図 | 中央値・散らばり・外れ値を複数グループで比較 |
| 幹葉図 | 少ないデータで、個々の値も残す |
| 棒グラフ | 質的データ（カテゴリ）の度数 |
| 累積度数グラフ | 「○以下が何%」を読む |
