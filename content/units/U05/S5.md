### なぜ？｜なぜ柱の高さを「相対度数÷幅」にするのか

初学では、幅の違う階級が混ざるとき、高さを度数÷幅にした。では、幅がそろっているときも、高さを度数のままにせず「相対度数÷幅」にする意味はあるか。20日の売上を、幅10万円と幅5万円で描いた2つの図を重ねて比べることを考える。

2つの版の表で、20〜30 万円の辺りの階級の度数と相対度数を読む。高さを度数にしたとき、相対度数÷幅にしたとき、2つの図の柱はそれぞれどう並ぶか。

::: toggle 動かしてから開く
幅10万円では、20〜30 が9日（相対度数 0.45）。幅5万円では、20〜25 が4日（0.20）、25〜30 が5日（0.25）。

高さを度数にすると、幅5の柱（4・5）は幅10の柱（9）の約半分の高さになり、重ねると別の形に見える。高さを相対度数÷幅にすると、幅10の柱は 0.45÷10＝0.045、幅5の柱は 0.20÷5＝0.04 と 0.25÷5＝0.05 で、幅10の柱の高さの上下に、幅5の2本が並ぶ。

どちらの図も、柱の面積（高さ×幅）は相対度数で、全部を足すと1になる。だから、幅の違う図も、個数の違うデータ（20日と1年）も、同じ縦軸の上に重ねて形を比べられる。データを増やして幅を細かくしていくと、柱の上の端はなめらかな曲線に近づく。面積が割合を表すこの曲線が、確率密度の考え方（{{unit:U16}}）につながる。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

箱ひげ図は5つの数で描く。「Q₁＝50」「中央値＝53.5」という数からは、**何個の値から求めたか**が消える。8日のデータで描いた箱も、120日のデータで描いた箱も、同じ見た目の箱になる。

2つの版で、8日の来店客数と20日の売上の、どちらも2番目に小さい値を7だけ大きくする。中央値と Q₁ の動き方を比べる。

::: toggle 動かしてから開く
8日の来店客数で 49 を 56 にすると、並べ直した値は 47, 51, 52, 55, 56, 58, 60, 120。中央値は 53.5 から 55.5 に、Q₁ は 50 から 51.5 に動く。20日の売上で 15 を 22 にすると、中央値は 26.5 のまま、Q₁ は 21.5 から 22 に動くだけ。

四分位数は、並べた位置で隣り合う2つの値で決まる。値が少ないと、隣どうしの間が広く、1つの値が入れ替わるだけで中央値や箱の端が大きく動く。箱の見た目は同じでも、8日の箱は「次の8日で大きく変わりうる箱」。箱ひげ図を並べて比べるときは、それぞれ何個の値から描いたかを添えるか、値の点を重ねて描く。
:::

### 本当に？｜柵の外に値がなければ、飛び抜けた値はないのか

外れ値の柵は、IQR（真ん中の半分の広がり）を物差しにするので、飛び抜けた値自身には引っ張られない、と初学で見た。これは、飛び抜けた値が少ないことを前提にしている。

20日の売上で、上の5日（31より大きい 33・35・38・42・55）がどれもセールの日で、どれも 55 万円だったとする。並べると、15番目が 31、16番目が 55 になり、Q₃ は (31＋55)÷2＝43 に上がる。Q₁ は 21.5 のままなので、IQR＝21.5、上の柵は 43＋1.5×21.5＝75.25。55 の5日は、どれも柵の内側に入り、外れ値ではなくなる。

飛び抜けた値が全体の4分の1ほどになると、Q₃ そのものが飛び抜けた値の側に入り込み、物差し（IQR）が伸びて、柵が外へ逃げる。「柵の外に値がない」は「飛び抜けた日がない」ではない。セールの日のように、性質の違う日がまとまって入っているときは、先にヒストグラムで山が2つないかを見る。

ヒストグラムの側にも、同じ形の前提がある。階級の数の目安は、1つの山を前提にしている。

### ほかでは？｜つながり

- **面積が割合を表す曲線**：確率密度（{{unit:U16}}）
- **代表値の選び方**：平均と中央値、分位点（{{unit:U06}}）
- **値の順番を見る**：時系列の折れ線（{{unit:U05T}}）
- **もう1つの外れ値の目安**：平均から標準偏差の何倍離れているか（{{unit:U08}}）

### 説明してみる

::: task
A店は30日分の日販を幅5万円の階級で、B店は90日分の日販を幅10万円の階級で、どちらも縦軸を度数にしたヒストグラムに描き、横に並べた。本部の担当者は「A店の柱はどれも B店の柱よりずっと低いので、A店はどの売上の日も少ない」と報告した。この読み方のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（2店とも、日販を同じ集計の仕方で出したとみて）**：縦軸が度数のとき、柱の高さは「その階級の日数」で、日数の合計（30日と90日）と階級の幅（5と10）で大きさが変わる。2店の形が同じでも、A店の柱は日数で3分の1、幅で2分の1、合わせておよそ6分の1の高さになる。柱が低いのは、日数と幅の選び方のせいで、売上の大小を表していない。2店の形を比べるなら、高さを相対度数÷幅にそろえる。売上が多い日の割合を比べるなら、同じ区切り（たとえば「40万円以上」）の相対度数で比べる。

**解釈の例（そろえて描いても、A店の分布が左に寄っていたとき）**：
- A店は売場が小さく、どの日も客数が少ない
- A店の30日は、売上の少ない季節（2月など）の30日で、B店の90日は年末を含む。比べている期間が違う

どちらの読み方かは、この2つの図だけからは決められない。

**統計の外で確かめること**：2店で、比べる期間をそろえられるか。そろえられないなら、期間の違いを報告に書く。
:::
