### なぜ？｜なぜ柱の高さを「相対度数÷幅」にするのか

初学では、幅の違う階級が混ざるとき、高さを度数÷幅にした。では、幅がそろっているときも、高さを「相対度数÷幅」にする意味はあるか。同じ店の20日分と1年分（365日）の売上を、どちらも幅10万円で描き、1つの縦軸の上に重ねて形を比べることを考える。

2つの版の表で、各階級の度数と相対度数を読む。高さを度数にしたとき、相対度数÷幅にしたとき、2つの図の柱はそれぞれどう並ぶか。

::: toggle 動かしてから開く
高さを度数にすると、20〜30 の柱は20日で 9、1年で 135。20日の柱は、1年の柱の15分の1ほどの高さしかなく、同じ縦軸の上ではほとんど見えない。

高さを相対度数÷幅にすると、20日は 0.02・0.045・0.025・0.005・0.005、1年は 0.007・0.037・0.041・0.012・0.003（10〜20 から 50〜60 まで）。同じ大きさの柱になり、20日では 20〜30 がいちばん高く、1年では 30〜40 がわずかに高いという、形の違いが比べられる。

どちらの図も、柱の面積（高さ×幅）は相対度数で、全部を足すと1になる。だから、個数の違うデータも、幅の違う図も、同じ縦軸の上で形を比べられる。同じ仕組みで値が生まれ続けるとみて、データを増やし幅を細かくしていくと、柱の上の端はなめらかな曲線に近づいていく。面積が割合を表すこの曲線が、確率密度の考え方（{{unit:U16}}）につながる（値が分単位に丸めて記録されていると、幅を細かくしてもなめらかにはならない。創造の待ち時間がその例）。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

箱ひげ図は5つの数で描く。「Q₁＝50」「中央値＝53.5」という数からは、**何個の値から求めたか**が消える。8日のデータで描いた箱も、120日のデータで描いた箱も、同じ見た目の箱になる。

2つの版で、8日の来店客数と20日の売上の、どちらも2番目に小さい値を7だけ大きくする。中央値と Q₁ の動き方を比べる。

::: toggle 動かしてから開く
8日の来店客数で 49 を 56 にすると、並べ直した値は 47, 51, 52, 55, 56, 58, 60, 120。中央値は 53.5 から 55.5 に、Q₁ は 50 から 51.5 に動く。20日の売上で 15 を 22 にすると、中央値は 26.5 のまま、Q₁ は 21.5 から 22 に動くだけ。

違いは順位で読める。8日では、中央値は4番目と5番目の値の平均。49 は 56 になって 51・52・55 を追い越し、2番目から5番目に上がって、中央値の位置をまたいだ。20日では、中央値は10番目と11番目の平均で、15 は 22 になっても7番目までしか上がらず、中央値の位置をまたがない。

値が少ないと、中央値や箱の端の位置まで、下から数えて数段しかない。だから、1つの値が少し動いただけで、その位置をまたぎ、箱が動く。箱の見た目は同じでも、8日の箱は1つの値の違いで形を変えやすい。箱ひげ図を並べて比べるときは、それぞれ何個の値から描いたかを添えるか、値の点を重ねて描く。
:::

### 本当に？｜柵の外に値がなければ、飛び抜けた値はないのか

外れ値の柵は、IQR（真ん中の半分の広がり）を物差しにするので、飛び抜けた値自身には引っ張られない、と初学で見た。20日の売上の上の5日（33・35・38・42・55）がどれもセールの日で、どれも 55 万円だったら、どうなるか。ラボで大きいほうから1つずつ 55 に動かし、動かすたびに Q₃・上の柵・外れ値の点を見る。

::: toggle 動かしてから開く
42・38・35 を 55 にするまでは、Q₃ は 32、上の柵は 47.75 のままで、55 の点が2つ、3つ、4つと増えていく。最後に 33 を 55 にすると、16番目の値が 55 になり、Q₃ は (31＋55)÷2＝43 に上がる。IQR は 43−21.5＝21.5、上の柵は 43＋1.5×21.5＝75.25 に広がり、外れ値の点は4つから0になる。

飛び抜けた値が全体の4分の1ほどになると、Q₃ そのものが飛び抜けた値の側に入り込み、物差し（IQR）が伸びて、柵が外へ逃げる。「柵の外に値がない」は「飛び抜けた日がない」ではない。セールの日のように性質の違う日がまとまって入っているときは、先にヒストグラムで山が2つないかを見る。
:::

ヒストグラムの側にも、同じ形の前提がある。階級の数の目安は、1つの山を前提にしている。

### ほかでは？｜つながり

- **面積が割合を表す曲線**：確率密度（{{unit:U16}}）
- **代表値の選び方**：平均と中央値、分位点（{{unit:U06}}）
- **値の順番を見る**：時系列の折れ線（{{unit:U05T}}）
- **もう1つの外れ値の目安**：平均から標準偏差の何倍離れているか（{{unit:U08}}）

### 説明してみる

::: task
5店舗の日販の箱ひげ図を並べた資料で、先月開いた D店だけは8日分から描いてあり、ほかの4店は120日分から描いてある。D店の箱がいちばん短かったので、本部の担当者は「D店は日販がいちばん安定している」と書いた。この読み方のどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（5店とも、日販を同じ集計の仕方で出したとみて）**：箱の長さ（IQR）は、D店では8つの値のうちの4つ（2番目と3番目、6番目と7番目）だけで決まる。値が少ないと、1つ2つの値の違いで箱の端が数段先の値に移り、箱が短くも長くもなる。この8日で箱が短かったことは言えるが、それが D店のふつうの日の広がりかは、箱の見た目からは言えない。

**解釈の例（D店の箱が短いことについて）**：
- D店は住宅街の店で、どの日も同じような客が来て、本当に日販がそろっている
- 8日がどれも開店直後の平日で、週末やセールの日がまだ入っていない。比べている日の中身が、ほかの4店と違う

どちらの読み方かは、この8日の箱だけからは決められない。

**統計の外で確かめること**：8日がどの曜日だったか。資料には、各店の箱が何日分から描いてあるかを添え、D店は日数がそろってから比べ直す。
:::
