::: task
会員の80%がリピーター（月2回以上来店）だった。本部の資料には「リピーターの80%は会員なので、リピーターを増やすには会員を増やせばよい」と書いてある。この言い方のどこを確かめればよいか。
:::

^ まだ答えなくてよい。「〇〇の中で」の〇〇が分母になること、条件で割合が変わるかで独立を判定することができるようになるのが初学のゴール。

### 1｜前提チェック（2分）

::: toggle 3問だけ確かめる（答えも中にある）
1. 雨の日の客40人のうち12人が傘を買った。割合は？ → 12÷40＝0.3（分母は雨の日の客）
2. 2/5×1/2 は？ → 1/5
3. P(A)＝0.5、P(B)＝0.4、P(A∩B)＝0.2 のとき P(A∪B) は？ → 0.7

### 2｜意味をつかむ：問題文の言葉で式を選ぶ　{{power:P3}}

条件が付くと、比べる「世界」が狭くなる。「雨の日の客の中で」なら、雨の日の客全体が新しい分母になる。

::: ask 「〇〇だと分かったうえで」「〇〇の中で」と書いてある
→ **条件付き確率**。〇〇が分母になる。
:::

::: ask 「戻さずに引く」「続けて起こる」と書いてある
→ **乗法定理**：確率を順に掛け継ぐ。2回目の確率は1回目のあとの状態で決まる。
:::

::: ask 「一方が他方に影響するか」を知りたい
→ **独立の判定**：条件を付けても確率が変わらないか（P(A｜B)＝P(A)）、または P(A∩B)＝P(A)P(B) かを確かめる。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
P(A\mid B)=\frac{P(A\cap B)}{P(B)}\quad\Longleftrightarrow\quad P(A\cap B)=P(B)\,P(A\mid B)
$$

| 記号 | 意味（雨の日の傘の例） |
| --- | --- |
| P(A｜B) | B（雨）の中で A（傘を買う）割合 |
| P(A∩B) | 全体の中で、雨の日で傘を買った割合 |
| P(B) | 全体の中で雨の日の客の割合（新しい分母） |
| 独立 | P(A｜B)＝P(A)：雨でも晴れでも買う割合が同じ |

**式を言葉で読む**：縦棒「｜」の右が条件（分母の世界）、左が数えるもの。両方起きる割合を、条件の割合で割ると「条件の中での割合」になる。式を変形すると、続けて起こる確率は「先に起きる確率×そのあとの条件付き確率」と掛け継げる。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　赤2個・青3個の袋から、戻さずに2回引く。① 1回目が赤だったとき、2回目も赤の確率は？　② 2回とも赤の確率は？

1. ① 1回目赤の後、残りは赤1・青3 → P(2回目赤｜1回目赤)＝**1/4**
2. ② P(2回とも赤)＝2/5×1/4＝**1/10**
3. 比較：毎回戻すなら 2/5×2/5＝4/25（1回目が2回目に影響しない＝独立）

:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-prob@s1-table}}

1. **予想**：ラボの課題カードで、晴れの日の客が傘を買う割合を入れる。
2. **操作**：結果を見たら、表の人数を −／＋ で動かす。晴れの日に傘を買う人を増やしていく。
3. **観察**：雨の日の割合と晴れの日の割合が同じになるのはどんなときか。そのとき全体の割合はどうなるか。
4. **説明**：「雨の日と晴れの日の購入率を同じにすると□になった。なぜなら□」を1文で書く。
5. **ラボなしで**：晴れの日の客60人のうち何人が傘を買えば、雨の日（40人中12人）と同じ割合になるか。

::: toggle 答え（書いてから開く）
- **観察**：晴れの日に傘を買う人を18人にすると、雨の日 12÷40＝30%、晴れの日 18÷60＝30% で同じになり、全体も30%になる。
- **説明の例**：「雨の日と晴れの日の購入率を同じにすると、P(購入｜雨)＝P(購入) になり独立になった。天気が分かっても、買う確率の見込みが変わらないから」
- **ラボなしで**：60×0.3＝**18人**。
:::
