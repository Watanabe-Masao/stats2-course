### 課題A｜自分の売場の「条件別カード」を作る

POSや会員データから、条件（天気・曜日・会員・提示など）を1つ選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 表 | 条件あり／なし × 購入あり／なし の人数 |
| 条件付きの率 | P(購入｜条件あり)、P(購入｜条件なし) |
| 逆向きの率 | P(条件あり｜購入) と、その意味 |
| 言えないこと | 条件が購入の原因と言えるか |

### 課題B｜抽選販売の順番は公平か

**問い**　限定品を抽選で販売する。番号札を順に引いてもらう方法で、先に来た客と後に来た客で当たりやすさは違うか。説明の文と、確かめ方を決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：前の人の結果が分かっているときは確率が変わる（当たりが出たら残りの当たりが減る）。しかし、前の人の結果を知らない段階では、何番目に引いても当たる確率は「当たりの本数÷全部の本数」で同じ。

**小さな例で検証**：ラボの「袋から2回」で赤2・青8・戻さないにすると、条件なしの2回目が赤の確率は 2/10 で1回目と同じ。

**限界**：途中で当たりが出切ったら抽選を打ち切る、のようにルールが変わると公平さは崩れる。客に結果を見せながら引く場合は、後の客の期待が変わる。
:::

### 課題C｜「購入者の何%が〇〇」の資料を直す

会議資料から「購入者のうち〇〇が何%」という数字を1つ探し、「〇〇のうち購入者が何%」と取り違えて使われていないか確かめる。取り違えていたら、どの分母の数が必要かを書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何の中での割合を知りたいかが明確か |
| 仮定 | 独立・戻す／戻さないの仮定を書いたか |
| 方法 | 分母を変える、掛け継ぐを使い分けたか |
| 検証 | 小さな例やラボで確かめたか |
| 限界 | 因果と言えないこと、標本の偶然を書いたか |
