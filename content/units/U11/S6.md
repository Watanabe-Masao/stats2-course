### 探究｜試食をした客の方が買っている。試食をすすめれば売れるか

ある日の売場で、試食をした客 50 人中 25 人（50%）、試食をしなかった客 150 人中 45 人（30%）が商品を買った。「試食をすすめれば売れる」と言ってよいか。

1. 条件付きの割合 P(購入｜試食あり)・P(購入｜試食なし) を出し、独立かどうかを確かめる
2. 統計で言えること（この日の客で、試食の有無と購入が関係していたか）と、言えないこと（試食が購入の原因か）を分ける
3. 関係の読み方を2つ以上考える
4. どちらかを確かめるために、次にどんな集め方をするかを書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること**：P(購入｜試食あり)＝0.5、P(購入｜試食なし)＝0.3 で、全体の購入率 70÷200＝0.35 とも違う。この日の客では、試食の有無と購入は独立ではなかった（1日分の人数なので、偶然の幅は残る）。

**解釈の例1**：試食が効いた。食べて味が分かった客が買った。

**解釈の例2**：もともと買う気のある客ほど試食をした（自分で選んで試食した）。この場合、試食をすすめても、買う気のない客の購入率は上がらない。

**統計の外で確かめること**：試食をすすめる時間帯をくじで決め（{{unit:U32}}）、すすめた時間とすすめなかった時間の購入率を比べる。客が自分で選ぶ形をやめると、2つの読み方を分けられる。
:::

### 課題A｜自分の売場の「条件別カード」を作る

POSや会員データから、条件（天気・曜日・会員・提示など）を1つ選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 表 | 条件あり／なし × 購入あり／なし の人数 |
| 条件付きの率 | P(購入｜条件あり)、P(購入｜条件なし) |
| 逆向きの率 | P(条件あり｜購入) と、その意味 |
| 言えないこと | 条件が購入の原因と言えるか |

### 課題B｜抽選販売の順番は公平か

**問い**　限定品を抽選で販売する。番号札を順に引いてもらう方法で、先に来た客と後に来た客で当たりやすさは違うか。説明の文と、確かめ方を決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：前の人の結果が分かっているときは確率が変わる（当たりが出たら残りの当たりが減る）。しかし、前の人の結果を知らない段階では、何番目に引いても当たる確率は「当たりの本数÷全部の本数」で同じ。

**小さな例で検証**：ラボの「袋から2回」で赤2・青8・戻さないにすると、条件なしの2回目が赤の確率は 2/10 で1回目と同じ。

**成り立たない条件と、その先の判断**：引いた札とは別に、途中で当たりの札を足したり抜いたりする（くじの中身を途中で変える）と、公平さは崩れる。客に結果を見せながら引く場合は、後の客が当たる確率の見込み（条件付き確率）が変わる。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 何の中での割合を知りたいかが明確か |
| 仮定 | 独立・戻す／戻さないの仮定を書いたか |
| 方法 | 分母を変える、掛け継ぐを使い分けたか |
| 検証 | 小さな例やラボで確かめたか |
| 切り分け | 統計で言えること（条件付きの割合・独立かどうか）と、言えないこと（原因か・偶然の幅）を分けたか |
