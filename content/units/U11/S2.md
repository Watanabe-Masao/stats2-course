### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：戻さずに引くと独立でない理由**

- **条件**：袋から玉を戻さずに続けて引くとき
- **対象と結論**：1回目と2回目の結果は独立ではない
- **根拠**：1回目に何を引いたかで、袋に残る玉の構成が変わり、2回目の確率が変わるから（赤2青3なら、1回目赤の後は1/4、青の後は2/4）
- **成り立たない場合**：毎回戻す（復元抽出）なら袋の中身は変わらないので独立。袋の中がとても多いときも、ほぼ独立とみなせる

::: toggle つなげると（お手本の文）
「戻さずに引くと、1回目と2回目の結果は独立ではない。1回目に何を引いたかで残りの構成が変わり、2回目の確率が変わるからである。ただし毎回戻すなら中身が変わらないので独立になる。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「会員の80%がリピーターなので、リピーターの80%は会員です。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- P(リピーター｜会員)＝0.8 から P(会員｜リピーター) は分からない。分母が違う。
- 会員の割合や、非会員のリピーター率が必要。

**言い直しの例**

「会員のうち80%がリピーターである。リピーターのうち会員が何%かは、会員の割合と非会員のリピーター率が分からないと求められない（{{unit:U12}} のベイズの定理で求める）。」
:::

::: toggle 取り違えやすい言葉
- **「P(A｜B)」と「P(B｜A)」**：P(購入｜来店)＝来店した人のうち購入した割合／P(来店｜購入)＝購入した人のうち来店した割合（通販がある店なら1ではない）。分母が違うので、一般に値は違う
- **「条件付き確率」と「同時確率」**：条件付き＝Bの中でのAの割合 P(A｜B)／同時＝全体の中でAとBが両方起きる割合 P(A∩B)
- **「独立」と「排反」**：独立＝影響しない／排反＝同時に起きない（{{unit:U10}}）
:::
