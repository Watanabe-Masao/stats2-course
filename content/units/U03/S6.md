### 課題A｜「数字の出どころカード」を作る

職場でよく見る数字（日販・廃棄率・客単価・満足度など）を1つ選び、次のカードを作る。

| 項目 | 書くこと |
| --- | --- |
| 知りたい全体 | 母集団（対象・期間・定義） |
| 実際のデータ | 標本か全数か、どう選ばれたか |
| 偏りの可能性 | 名簿の漏れ・自分から回答・選ぶ基準 |
| 言えること | この数字から言えること |
| 言えないこと | この数字だけでは言えないこと |

### 課題B｜偏りを見つける質問リストを作る

報告書や会議資料の数字を見たときに使う「確かめる質問」を5つ作る。実際の資料3つに当てはめて、質問が役に立ったか、足りない質問は何かを書き足す。

### 課題C｜10店で全店の平均を推し量る方法を設計する

**問い**　全100店（大型30・中型50・小型20）の平均廃棄率を、10店だけ調べて推し量りたい。偏りを小さくする選び方を設計し、その方法の弱点を書く。

::: toggle 1つの考え方の例（自分で設計してから開く）
**単純な無作為**：店番号を乱数で10個選ぶ。偏りはないが、たまたま大型店ばかりになることもある。

**層に分けて無作為（層別抽出）**：規模ごとの割合に合わせて、大型3店・中型5店・小型2店を、それぞれの中から無作為に選ぶ（10×30%＝3、10×50%＝5、10×20%＝2）。規模で廃棄率が違うなら、単純な無作為よりばらつきが小さくなる。

**弱点**：規模以外の違い（立地・客層）は層に入っていない。選ばれた店が協力を断ると、そこから偏りが入る。

**検証**：ラボの「無作為に取る」で、n＝10 の x̄ がどのくらい散らばるかを見て、層に分ける意味を考える。詳しくは {{unit:U31}}。
:::

### 課題D｜他の分野のたとえを作って限界を確かめる

「料理の味見は無作為抽出に似ている」のように、自分の興味のある分野（スポーツ・音楽・物流など）から「一部で全体を知る」たとえを作る。そのたとえが**成り立たなくなる場面**も1つ書く（例：味見の前にかき混ぜられない料理）。

### {{icon:lab}} 検証に使う

自分の設計や考え方を、ラボの3つのモードで確かめる（無作為なら μ のまわりに集まるか、偏りがあればどちらにずれるか）。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 知りたい全体（母集団）が明確か |
| 仮定 | 選び方と、偏りが入りうる所を明示したか |
| 方法 | なぜその選び方かを説明したか |
| 検証 | 小さな例やラボで確かめたか |
| 限界 | その方法で言えないことを書いたか |
