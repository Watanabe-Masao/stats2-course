### 探究｜全数のデータなのに、知りたいことが分からない

ある店で新しい総菜を発売して1か月。店の POS の記録（応用の Q-U03-004 と同じく全数）から、その月の全取引のうち新しい総菜が入っていた取引の割合を出した。全3万件中900件で、3%。担当者は「標本ではなく全数なので、誤差はない。地域の人のうち3%しかこの総菜を欲しがっていないので、発売をやめる」と書いた。聞き取ると、次のことが分かった。
- 新しい総菜は、1か月ずっと1日30個並べ、毎日昼ごろに売り切れていた
- 店に来る客の半分以上は、週に何度も来る常連
- 地域には、この店に来ていない住民も多い

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 3% は、どの母集団の、どの母数かを書く
2. 担当者が知りたいのは、どの母集団の、どの母数かを書く
3. 1日30個・30日で、取引の割合は最大でいくつになりうるかを計算し、3% と比べる
4. 3% から言えることと、言えないことを分ける
5. 3% と「欲しい人の割合」が違う理由の読み方（2つ以上）を書く
6. 知りたいことに近づくには、どんなデータを取るかを決める（下の課題）

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（POS の記録に数え漏れがないとみて）**：この月のこの店の全取引 3万件のうち、新しい総菜が入っていた取引は 900件で、3%。これは「この月のこの店の取引」という母集団の割合（母数）で、全部を数えたので、標本を選び直したときのぶれはない。

**数の上限**：1日30個・30日で、並べたのは900個。全部売れて、1件に1個ずつなら、新しい総菜が入る取引は最大900件で、3%。つまり 3% は、並べた数で決まる上限そのもの。欲しい人がもっと多くても、3% より上にはなりえなかった。

**この数だけでは言えないこと**：地域の人のうち何%がこの総菜を欲しがっているか。全数だからといって、知りたい母集団の母数が分かったことにはならない（取引と人の違いは {{unit:U01}} の創造と同じ形）。

**解釈の例**：
- 毎日昼に売り切れていたので、午後に来た客は欲しくても買えなかった。欲しい人の割合は3%より多い
- 1人の客が何度も来れば、取引の数にその人が何回も入る。この総菜を買うのが常連でない人なら、取引あたりの割合は「1か月に1回でも買った人の割合」より低く出ることがある
- この店に来ていない住民は、もっと欲しがっているかもしれないし、まったく欲しがっていないかもしれない。この記録からは分からない

**統計の外で決めること**：発売をやめるかを決める前に、並べる数を増やした月の記録を取り、知りたい母集団（地域の人、来店客の人）に合うデータを足す。
:::

### 課題｜知りたいことに近づくデータを選ぶ

**問い**　「地域の人のうち、新しい総菜を欲しい人の割合」に近づきたい。次の1か月で、どのデータを取るか。

- **ア**：並べる数を1日60個に増やして、同じように POS の取引の割合を出す
- **イ**：店頭で、来た客にくじで声をかけて、欲しいかどうかを聞く（1日20回）
- **ウ**：購入した地域の名簿（世帯ごとに1人の名前が載る）から無作為に500人を選び、郵送で聞く

**判断の材料**：郵送の調査は1人あたり200円かかり、返ってくるのは半分くらいと見込む。店頭の声かけは1日1人の作業。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（それぞれの取り方のとおりに集めたとみて）**：ア は売り切れの上限を上げられるが、母集団は「来た客の取引」のまま。イ はくじで声をかけるので、選ばれるのは「来店1回」で、常連ほど選ばれやすい。「今月もう聞かれたか」で重複を外しても、来店回数の多い人ほど1度は声をかけられやすい偏りは残る。人の割合に近づけるには、聞いた人に月の来店回数も聞き、その逆数で重みをつける（{{unit:U21}}）。ウ は母集団を「名簿に載った世帯の代表1人」にできるが、返ってくるのは250人くらいで、返さなかった人が欲しい人と違えば偏る（{{unit:U17}}）。

**統計の外で決めること**：ウ は費用 10万円（500人×200円）がかかる。発売を続けるかの判断に要るのが店の売上なら ア（取引の割合）と イ（来店1回あたりの人気）で足りる。来た客（人）の中での人気を知りたいなら、イ に来店回数の重みを付ける。新しい客を呼べるかを知りたいなら ウ が要る。どれを選んでも、推し量れる母集団を報告に書く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 知りたい母集団と母数を、言葉で書いたか |
| 仮定 | 手元のデータの母集団（取引・来た客）と、知りたい母集団のずれを書いたか |
| 方法 | 数の上限（並べた数）を計算し、知りたい母集団に合うデータの取り方を選んだか |
| 検証 | ラボで、名簿の全部を調べても μ に届かないことを確かめたか |
| 切り分け | 言えること（この店この月の取引の割合）と、言えないこと（地域の人の割合）を分けたか |
| 解釈 | 3% の読み方を2つ以上並べ、次に取るデータを書いたか |
