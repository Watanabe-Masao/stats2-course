### 探究｜全数のデータなのに、知りたいことが分からない

新しい総菜を発売して1か月。本部は POS の記録から、その月の全取引のうち新しい総菜が入っていた取引の割合を出した。全30万件中9,000件で、3%。担当者は「標本ではなく全数なので、誤差はない。地域の人のうち3%しかこの総菜を欲しがっていないので、発売をやめる」と書いた。聞き取ると、次のことが分かった。
- 新しい総菜は、発売から2週間は1日10個しか並べず、昼過ぎには売り切れていた
- 店に来る客の半分以上は、週に何度も来る常連
- 地域には、この店に来ていない住民も多い

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 3% は、どの母集団の、どの母数か（何を何で割ったか）を書く
2. 担当者が知りたいのは、どの母集団の、どの母数かを書く
3. 2つの母集団のずれ（取引と人、来た客と地域の住民）を書く
4. 3% から言えることと、言えないことを分ける
5. 3% が低く出た理由の読み方（2つ以上）を書く
6. 知りたいことに近づくには、どんなデータを取るかを決める（下の課題）

{{lab:LAB-sample@s6-free}}

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること（POS の記録に数え漏れがないとみて）**：この月の全取引 30万件のうち、新しい総菜が入っていた取引は 9,000件で、3%。これは「この月のこの店の取引」という母集団の割合（母数）で、全部を数えたので、標本を選び直したときのぶれはない。

**知りたいこととのずれ**：担当者が知りたいのは「地域の人のうち、この総菜を欲しい人の割合」。母集団が違う（取引と人、来た客と地域の住民）。さらに、欲しい人の割合と、実際に買った取引の割合も違う（並べた数が少なく、売り切れたあとに来た人は買えない）。

**この数だけでは言えないこと**：地域の人のうち何%がこの総菜を欲しがっているか。全数だからといって、知りたい母集団の母数が分かったことにはならない。

**解釈の例**：
- 並べた数が少なく、昼過ぎに売り切れていたので、欲しくても買えなかった客が多い。3% は欲しい人の割合より低く出ている
- 常連は何度も来るので、取引の数には常連の買い物が何回も入る。常連が買わない商品だと、取引あたりの割合は低く出る
- 地域の人のうち、この店に来ていない人は、もっと欲しがっているかもしれないし、まったく欲しがっていないかもしれない。この記録からは分からない

どの読み方が当たるかは、この POS の数だけからは決められない。

**統計の外で決めること**：発売をやめるかを決める前に、知りたい母集団（地域の人、来店客の人）に合うデータを取る。並べる数を増やした月の記録と比べる。
:::

### 課題｜知りたいことに近づくデータを選ぶ

**問い**　「地域の人のうち、新しい総菜を欲しい人の割合」に近づきたい。次の1か月で、どのデータを取るか。

- **ア**：並べる数を1日40個に増やして、同じように POS の取引の割合を出す
- **イ**：店頭で、来た客にくじで声をかけて、欲しいかどうかを聞く（1日20人）
- **ウ**：地域の住民名簿から無作為に500世帯を選び、郵送で聞く

**判断の材料**：郵送の調査は費用がかかり、返ってくるのは半分くらいと見込む。店頭の声かけは1日1人の作業。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（それぞれの取り方のとおりに集めたとみて）**：ア は売り切れの影響を減らせるが、母集団は「来た客の取引」のまま。イ は母集団を「来た客（人）」にできるが、地域の住民にはならない。くじで選べば、来た客の割合を推し量れる。ウ は母集団を「地域の住民」にできるが、返ってこない半分が欲しい人と違えば、偏る（{{unit:U17}}）。

**統計の外で決めること**：発売を続けるかの判断に要るのが「来た客の中での人気」なら イ（と ア）で足りる。新しい客を呼べるかを知りたいなら ウ が要る。どれを選んでも、推し量れる母集団を報告に書く。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 知りたい母集団と母数を、言葉で書いたか |
| 仮定 | 手元のデータの母集団（取引・来た客）と、知りたい母集団のずれを書いたか |
| 方法 | 知りたい母集団に合うデータの取り方を選んだか |
| 検証 | ラボで、選び方で x̄ の真ん中がずれることを確かめたか |
| 切り分け | 言えること（この店この月の取引の割合）と、言えないこと（地域の人の割合）を分けたか |
| 解釈 | 3% の読み方を2つ以上並べ、次に取るデータを書いたか |
