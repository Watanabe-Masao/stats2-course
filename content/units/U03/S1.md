### 2｜意味をつかむ：その数字は「全体」のものか「一部」のものか　{{power:P3}}

統計の問題では、計算の前に2つを確かめる。

::: ask
**質問1：本当に知りたいのは、どの集まり全体？**

→ それが**母集団**。その全体の本当の値（平均など）が**母数**。決まっているが、ふつうは分からない。
:::

::: ask
**質問2：実際に調べたのは、どの一部？ どう選んだ？**

→ それが**標本**。標本から計算した値（平均など）が**統計量**。取り直すたびに変わる。選び方が偏ると、全体の推測が崩れる。
:::

{{fig:FIG-U03-population}}

^ 図の読み方：μ は左（全体）の側にあって見えない。私たちが計算できるのは右（標本）の x̄ だけ。矢印「推測」が統計の仕事。

| 全体の側 | 調べた一部の側 |
| --- | --- |
| 母集団（大きさ N） | 標本（大きさ n） |
| 母数：母平均 μ（未知・固定） | 統計量：標本平均 x̄（計算できる・取り直すと変わる） |

### 3｜式の構造を読む　{{power:P1}}

$$
\mu=\frac{1}{N}\sum_{i=1}^{N}x_i\qquad\qquad \bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i
$$

| 記号 | 意味（入口の問いの例） |
| --- | --- |
| N | 母集団の大きさ（100店） |
| n | 標本の大きさ（10店） |
| μ | 全100店の平均＝母数（分からない） |
| x̄ | 10店の平均＝統計量（2.4%） |

**式を言葉で読む**：どちらも「足して個数で割る」。**全体で割れば母数、調べた一部で割れば統計量**。式の形は同じでも、何について計算したかで意味が変わる。

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　入口の問い

1. **知りたい全体は？** → 全100店舗＝**母集団**（N＝100）
2. **実際に調べたのは？** → 協力してくれた10店舗＝**標本**（n＝10）
3. **2.4% はどちらから計算した？** → 10店舗から＝**統計量 x̄**
4. 全100店舗の本当の平均廃棄率＝**母数 μ**（分からない）
5. しかも「協力してくれた店」は自分から手を挙げた店。廃棄の少ない店ほど協力しやすければ、2.4% は低めに偏っているかもしれない。

{{fig:FIG-U03-exA}}

::: key
2.4% は「全店の平均」ではなく「全店の平均を**推測する材料**」。どのくらい前後するかは {{unit:U22}}（信頼区間）で求める。選び方が偏っていれば、前後の幅以前に推測そのものがずれる。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-sample@s1-rand}}

1. **予想**：ラボの課題カードで、x̄ が毎回同じか変わるかを選ぶ。変わるなら、どのあたりに集まるかも先に書く。
2. **操作**：「10回続けて」を何度か押す。次に「μ（本当の平均）を見る」にチェックを入れる。最後に n を100にして押す。
3. **観察**：x̄ の点はどう散らばったか。μ の線との位置関係は。n＝100 のときは。
4. **説明**：「x̄ は□なので、1回の値をそのまま全体の値とは言えない。ただし無作為に選べば□」を1文で書く。
5. **ラボなしで**：同じ方法で選び直したら、x̄ が 2.4% から 2.7% に変わった。全店の本当の平均（μ）は変わったか。

::: toggle 答え（書いてから開く）
- **観察**：x̄ は毎回変わり、μ（このラボでは 2.54%）のまわりに散らばる。n＝100 は全店を調べる全数調査なので、x̄ は毎回 μ と一致する。
- **説明の例**：「x̄ は標本を取り直すたびに変わるので、1回の値をそのまま全体の値とは言えない。ただし無作為に選べば、x̄ は μ のまわりにばらつく」
- **ラボなしで**：**変わっていない**。μ は全店で決まった値（固定）で、変わったのは標本と統計量 x̄ だけ。
:::
