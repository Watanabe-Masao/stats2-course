### 同じ構造の場面：一部から全体を推し量る

| 場面 | 母集団 → 標本 | 偏りが入る所 |
| --- | --- | --- |
| 全店の廃棄率 | 全店 → 調べた店 | 協力的な店だけを選ぶ |
| 品目の値入率 | 全品目 → 売れ筋上位 | 売れ筋だけを選ぶ |
| 品質検査 | ロット全体 → 抜き取った製品 | 上の段の箱だけ抜き取る |
| 視聴率調査 | 全世帯 → 調査世帯 | 調査を引き受けた世帯の特徴 |
| 生き物の数 | 池の全部の魚 → 捕まえた魚 | 捕まりやすい魚だけが捕まる |
| 料理の味見 | 鍋全体 → スプーン1杯 | かき混ぜずに表面だけすくう |

^ どの場面でも「全体のどこからでも同じように選ばれるか」が推測の成否を決める。料理の味見で鍋をかき混ぜるのは、無作為抽出と同じ役割。

「名簿の漏れ」と「自分から回答」を順に動かし、上の表のどの場面がどちらの偏りに当たるかを考える。

::: toggle 対応の例
- **名簿の漏れ（抽出枠）**：品質検査で上の段だけ抜き取る、アプリ会員だけに送るアンケート
- **自分から回答**：協力的な店だけ、口コミ、調査を引き受けた世帯
- **選ぶ基準そのものが結果と関係**：売れ筋上位だけ（値入率と売れ行きが関係していれば偏る）
:::

### 売場の場面で

- 全店の数字を知りたいのに、協力的な数店だけのデータで判断していないかを、数字を見る前に確かめる。
- 「クレームが多い商品」は、クレームを書く客が多い商品かもしれない。件数は「不満の大きさ」ではなく「不満を書いた人の数」。
- 新店の数字が本部の集計に入っていない（名簿の漏れ）と、全店平均は既存店に偏る。
