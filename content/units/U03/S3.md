### 判断の手順（毎回これを書く）　{{power:P3}}

1. **知りたい全体は何か**（対象・期間・定義まで）
2. **実際に調べたのは何か、どう選ばれたか**（無作為か、自分から手を挙げたか、名簿に漏れはないか）
3. **その数字は母数か統計量か**、そして偏りの可能性はあるか

### データから結論までの流れ（PPDAC）

数字を見る前に、どの段階で偏りが入りうるかを確かめる。

| 段階 | 内容 |
| --- | --- |
| 問題（Problem） | 何を知りたいか（新売場で廃棄率は下がるか） |
| 計画（Plan） | 誰を・いつ・どう測るか、比較の相手と分母を決める |
| データ（Data） | 集める。欠測や定義の違いを記録する |
| 分析（Analysis） | 率・ばらつき・差を計算する |
| 結論（Conclusion） | 分かったことと、まだ言えないことを分けて書く |

### 使えない例と比べる　{{power:P3}}

- 回答数が多ければ代表性がある → ✕。自分から答えた人だけなら、何千人でも偏る。
- 公的統計なら何とでも比べてよい → ✕。対象・用語の定義・時点・集計単位を確認する。
- 統計ソフトで計算すれば正しい → ✕。集め方の偏りは計算では直らない。
- 全数調査の値も推測が必要 → ✕。知りたい全体を全部調べたなら、その値は母数そのもの（ただし測り方の誤りは残りうる）。

### この先で使う

この単元の「母数は未知・統計量は取り直すと変わる」が、推定と検定の土台になる。{{unit:U17}}で「標本の選び方と、標本平均がどれくらい変わるか」、{{unit:U22}}で「母平均はどの範囲か（信頼区間）」、{{unit:U31}}で「調査の設計」を学ぶ。
