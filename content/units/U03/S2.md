### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：統計量で母数を推測できる理由**

- **条件**：母集団から**偏りのない方法（無作為）**で標本を選んだとき
- **対象と結論**：標本平均 x̄ は母平均 μ を推測する材料として使える
- **根拠**：無作為に選べば、標本の中身が特定の方向に偏らず、x̄ は μ のまわりにばらつくから
- **成り立たない場合**：自分から回答した人だけ、台帳に載った店だけなど、選ばれ方が偏ると、標本を大きくしても x̄ は μ からずれたままになる

::: toggle つなげると（お手本の文）
「母集団から無作為に標本を選んだとき、標本平均は母平均を推測する材料として使える。なぜなら選び方に偏りがなければ、標本平均は母平均のまわりにばらつくから。ただし選ばれ方が偏っていると、標本を大きくしてもずれは消えない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「10店舗調べて平均2.4%だったので、全店の廃棄率は2.4%です。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 2.4% は標本（10店舗）の統計量で、母数（全店の平均）そのものではない。
- 選び方（無作為か）に触れていない。
- どのくらい前後しうるかを言っていない。

**言い直しの例**

「無作為に選んだ10店舗の平均廃棄率は2.4%だった。これは全100店舗の平均廃棄率を推測する材料で、全店の平均は2.4%前後と考えられる。どのくらい前後するかは信頼区間で示す必要がある。協力してくれた店だけを選んだのなら、偏っている可能性も書き添える。」
:::

::: toggle 取り違えやすい言葉
- **標本**：統計の標本＝実際に調べたデータの集まり（10店舗）／標本空間＝確率の試行で起こりうる結果の全部（サイコロなら1〜6）→ 名前が似ているだけで別の言葉
- **平均**：母平均 μ＝全体の本当の平均（未知）／標本平均 x̄＝調べた一部の平均（計算できる）→ 説明では必ずどちらの平均か言う
- **データがある**：数字が手元にある、ということと、知りたい問いに答えられる、ということは別。対象・期間・定義が問いに合っているかを確かめる
:::

### 記号の早見

| 母数（母集団） | 統計量（標本） |
| --- | --- |
| 母平均 μ | 標本平均 x̄ |
| 母分散 σ² | 不偏分散 s² |
| 母比率 p | 標本比率 p̂ |
| 大きさ N | 大きさ n |

^ ギリシャ文字は母数、上に記号（¯ ^）が付いたら統計量、と読める。
