### 課題A｜自分の売場の「併買カード」を作る

レシート（またはPOS）から、よく一緒に買われる2品を選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| P(A)・P(B) | それぞれを買った客の割合 |
| P(A∩B) | 両方買った客の割合 |
| どちらか | P(A∪B) と、どちらも買わない割合 |
| 言えないこと | この数だけでは分からないこと（理由・順番） |

### 課題B｜販促の「1回以上届く確率」を見積もる

**問い**　チラシ・アプリ通知・店頭POPの3つで同じ特売を知らせる。それぞれで客に届く確率を仮定し、「少なくとも1つで知る客の割合」を見積もる。仮定と限界も決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**決め方**：届く確率をチラシ30%、通知20%、POP50%と置き、3つが独立なら「どれでも知らない」＝0.7×0.8×0.5＝0.28、少なくとも1つで知る＝0.72。

**小さな例で検証**：ラボの「少なくとも1回」で、確率が同じ場合（例えば各1/2を3回）に 1−(1/2)³ になることを確かめる。

**限界**：チラシを読む客ほどアプリも見る、のように独立でないと、少なくとも1つで知る割合は 0.72 より小さくなる（同じ客に重なって届く）。重なりを調べるには、客ごとの記録が要る。
:::

### 課題C｜「または」の集計ミスを探す

過去の会議資料から、2つの割合を足して「どちらか」の割合としている所を探し、重なりを引いて直す。重なりのデータがない場合は、取れる範囲（最小〜最大）で示す。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 求める部分（または・かつ・少なくとも）が明確か |
| 仮定 | 等確率・独立などの仮定を書いたか |
| 方法 | 重なりを引く、反対側から求めるを使い分けたか |
| 検証 | 小さな例やラボで確かめたか |
| 限界 | 重なりが分からない・独立でない場合を書いたか |
