### 探究｜重なりが分からない「どちらか」を、どう報告するか

来店客のうち会員が 30%、クーポンを使う人が 25% と分かっている。両方に当てはまる人の割合は記録がない。「会員かクーポン利用者の少なくとも一方」は何%か、報告の書き方を決める。

1. 重なりが取りうる範囲から、「どちらか」の割合の範囲を出す
2. 範囲のどこにいそうかを、重なりが生まれる仕組みから考える
3. 統計で言えること（範囲）と、言えないこと（範囲のどこか）を分ける
4. 読み方を2つ以上考え、どちらかを確かめるために次に集める記録を書く

::: toggle 統計で言えることと、解釈を分けた例（自分で考えてから開く）
**統計で言えること**：重なりは 0% から 25%（小さい方）まで取りうるので、「どちらか」は 30%＋25%−（重なり）で **30%〜55%**。この2つの割合だけでは、これより狭くは言えない。

**解釈の例1**：クーポンを会員アプリで配っているなら、クーポン利用者のほとんどが会員で、重なりは 25% に近い。「どちらか」は 30% に近い。

**解釈の例2**：クーポンが新規客向けのチラシなら、会員はあまり使わず、重なりは 0% に近い。「どちらか」は 55% に近い。

**統計の外で確かめること**：会員番号つきのレシートで、クーポンを使った客のうち会員の割合を数える（1週間分でも重なりの見当がつく）。
:::

### 課題A｜自分の売場の「併買カード」を作る

レシート（またはPOS）から、よく一緒に買われる2品を選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| P(A)・P(B) | それぞれを買った客の割合 |
| P(A∩B) | 両方買った客の割合 |
| どちらか | P(A∪B) と、どちらも買わない割合 |
| 言えないこと | この数だけでは分からないこと（理由・順番） |

### 課題B｜販促の「1回以上届く確率」を見積もる

**問い**　チラシ・アプリ通知・店頭POPの3つで同じ特売を知らせる。それぞれで客に届く確率を仮定し、「少なくとも1つで知る客の割合」を見積もる。仮定と限界も決める。

::: toggle 1つの考え方の例（自分で決めてから開く）
**決め方**：届く確率をチラシ30%、通知20%、POP50%と置き、3つが独立なら「どれでも知らない」＝0.7×0.8×0.5＝0.28、少なくとも1つで知る＝0.72。

**小さな例で検証**：ラボの「少なくとも1回」で、確率が同じ場合（例えば各1/2を3回）に 1−(1/2)³ になることを確かめる。

**成り立たない条件と、その先の判断**：チラシを読む客ほどアプリも見る、のように独立でないと、少なくとも1つで知る割合は 0.72 より小さくなる（同じ客に重なって届く）。重なりを調べるには、客ごとの記録が要る。
:::

### 課題C｜「または」の集計ミスを探す

過去の会議資料から、2つの割合を足して「どちらか」の割合としている所を探し、重なりを引いて直す。重なりのデータがない場合は、取れる範囲（最小〜最大）で示す。
