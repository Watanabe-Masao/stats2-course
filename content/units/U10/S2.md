### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}
:::

**お手本：「または」で重なりを引く理由**

- **条件**：「AまたはB」の確率を求めるとき
- **対象と結論**：P(A) と P(B) を足して、P(A∩B) を1回引く
- **根拠**：AとBの両方に入る結果は、P(A) にも P(B) にも含まれ、2回数えられているから
- **成り立たない場合**：AとBが排反（重なりがない）なら引く必要はなく、そのまま足せる

::: toggle つなげると（お手本の文）
「AまたはBの確率は、P(A) と P(B) を足してから、両方に入る部分 P(A∩B) を1回引いて求める。重なりの部分は P(A) と P(B) の両方で数えられ、2回数えられているからである。ただし排反なら重なりがないので、そのまま足せばよい。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「AとBは排反なので独立です。だから P(A∩B)＝P(A)×P(B) で計算できます。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 排反なら P(A∩B)＝0。P(A)，P(B) がどちらも正なら P(A)×P(B)＞0 なので独立ではない。

**言い直しの例**

「AとBは排反なので、同時に起きる確率 P(A∩B) は0である。P(A) と P(B) がどちらも正なら P(A)×P(B) は0にならないので、AとBは独立ではない。」
:::

::: toggle 取り違えやすい言葉
- **「排反」と「独立」**：排反＝同時に起きない（重なりが0）／独立＝片方が起きても、もう片方の確率が変わらない。確率が正の2つの事象が排反なら、独立ではない（片方が起きると、もう片方は確率0になるから）
- **「または」と「かつ」**：または（∪）＝少なくとも一方が起きる／かつ（∩）＝両方が起きる
- **「どちらでもない」と「一方だけ」**：どちらでもない＝1−P(A∪B)／一方だけ＝P(A∪B)−P(A∩B)
:::
