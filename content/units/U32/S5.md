### なぜ？｜群の平均以外を真ん中にしても、全体の平方和は群間と群内に分かれるか

ラボの表で、全体の平方和（各店の値と全体の平均のずれの2乗の合計）と、群間の平方和＋群内の平方和を比べる。データを替えても、平均のずれ・群の中のばらつきを何倍にしても、くり返しを増やしても、2つは同じか。次に、例題Aの A 群（1, 3）の真ん中を、群の平均2 ではなく3 にして、群間と群内にあたる2つの和を手で計算し、全体の平方和と比べる。そのうえで、ラボではなぜいつも同じになるのかを、1つの店の値 x について「x − 全体の平均 ＝（x − 群の平均）＋（群の平均 − 全体の平均）」と分けたところから、自分の言葉で書いてから開く。

::: toggle 書いてから開く
どのデータでも、全体の平方和は群間の平方和と群内の平方和の和にちょうどなる。

1つの値のずれを2つに分けて2乗すると、(x−群の平均)²＋(群の平均−全体の平均)²＋2×(x−群の平均)×(群の平均−全体の平均) の3つの項になる。最後の項を1つの群の中で足すと、(群の平均−全体の平均) はその群のどの店でも同じなので外にくくり出せ、残るのは (x−群の平均) の群の中の合計。群の平均からのずれは、群の中で足すと必ず0 になる（平均の定義そのもの）。だから掛け合わせの項は群ごとに消え、残った2つが群内と群間になる。

A 群の真ん中を3 にすると、群内にあたる和は (1−3)²＋(3−3)²＝4、群間にあたる和は 2×(3−4)²＝2 で、合わせて6。ところが A 群の2店の全体の平方和への寄与は (1−4)²＋(3−4)²＝10 で、6 と合わない。真ん中を群の平均と違う値にすると、ずれの合計が0 にならず、掛け合わせの項（ここでは 2×(−2＋0)×(−1)＝4）が残る。なお自由度は、数え方として N−1＝(a−1)＋(N−a) と分かれる。この「ちょうど分かれる」性質があるので、群間と群内の平均平方を比べる F が作れる。
:::

### 本当に？｜くじで割り当てれば、群の差は施策の効果と言えるか

隣り合う2店を組にした10組で、組ごとにくじで1店に新しい陳列を入れた。陳列には客を新しく呼ぶ力はなく、陳列の店に、隣の陳列なしの店から客が移るだけだったとする。陳列の店は、陳列をしなかった場合より1店あたり売上が3 増え、隣の店は3 減った（組の2店は、陳列がなければ売上が同じくらいだったとする）。くじで割り当てたこの実験で、陳列の群となしの群の差は、何と何を比べた差になっているか。それは「チェーンに陳列を入れたときの効果」と言えるかを、説明してから開く。

::: toggle 説明してから開く
群の差は、陳列をしなかった場合と比べて 3−(−3)＝6 になる。ところが20店の合計は 3×10−3×10＝0 で、チェーン全体では売上は増えていない。

くじで割り当てると、割り当ての前に決まっている店の性質（規模・立地）は群と無関係になる。けれども、くじが保証するのはそこまでで、「どの店の売上も、その店自身が陳列をしたかどうかだけで決まる（ほかの店の割り当てに左右されない）」ことは、別の前提として置いている。隣の店から客が移ると、この前提が崩れ、陳列なしの群の売上まで陳列の影響を受ける。差の6 は、陳列の店が増えた分と、隣の店が減った分を足した値で、どちらも全店に陳列を入れれば起きない。

確かめるには、客が行き来しないほど離れた店どうしで比べる、地域ごとにまとめてくじを引く（地域の全店に入れるか入れないか）などで、群どうしの行き来を断つ。地域ごとにくじを引くと、くじで割り当てる単位は地域になり、比べる数は地域の数まで減る。
:::

### ほかでは？｜つながり

- **2群なら、等分散の t の2乗が F**：2標本の t 検定（{{unit:U25}}）。等分散を仮定しないウェルチの t もある
- **何回も検定すると、どれかが偶然有意になる**：第1種の過誤（{{unit:U24}}）
- **調べる人を選ぶくじ**：無作為抽出と層化抽出（{{unit:U31}}）。局所管理（規模の組でくじ）は、層化と同じ形
- **観察データで、ほかの変数が同じ値どうしで比べる**：重回帰（{{unit:U30}}）と層別（{{unit:U28}}）。くじで割り当てられないときの手

### 説明してみる

::: task
次の実験で、3つの陳列案を12店で比べる。担当者は「今の陳列の C 案は店が多いので8店、新しい A 案・B 案は2店ずつ」と割り振る案を出した。新しい案は、売場の広さや担当者によって効き方が大きく変わりそうだという。この割り振りで分散分析をすると何に気をつける必要があるかと、どう割り振ればよいかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（店どうしが独立とみて）**：群内の平均平方は、3つの群の群内の平方和を合わせて、群内の自由度 12−3＝9 で割る。そのうち7 は C 案の8店から来るので、群内の平均平方は、散らばりの小さそうな C 案に引き寄せられる。新しい案の群の平均は2店ずつで、散らばりの大きい店から求めるので本当はもっと揺れるのに、F の分母はその揺れを小さく見積もる。母平均がすべて等しくても、F は境目を超えやすくなる。分散分析の「どの群も分散が同じ」という前提が崩れても、店の数が群でそろっていれば、この影響は小さい。3案を4店ずつにすれば、散らばりが群で違っても、判断はずれにくい。また、F の棄却で言えるのは「少なくとも1組の母平均が違う」までで、2店ずつの A 案と B 案の比べは、いちばん根拠の弱い組になる。散らばりが群で違うことは、群ごとの散らばりを並べて示し、違いを許す比べ方（{{unit:U25}} のウェルチの考え方）でも確かめられる。

**解釈の例**：
- C 案を8店にしたいのは、今の陳列を変えたくない店が多いからで、店の数の偏りは、実験への協力のしやすさの偏りでもある
- 新しい案の効き方が店で違うなら、それ自体が知りたいことで、2店ずつではその違いが見えない

**統計の外で決めること**：今の陳列を続けたい店の都合と、比べやすさ（4店ずつ）のどちらを優先するか。どちらにしても、割り振りはくじで決め、店の都合で選ばない。
:::
