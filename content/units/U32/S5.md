### なぜ？｜全体の平方和は、なぜ群間と群内にちょうど分かれるのか

ラボの表で、全体の平方和と、群間の平方和＋群内の平方和を比べる。データを替えても、平均のずれ・群の中のばらつきを何倍にしても、くり返しを増やしても、2つは同じか。同じになるわけを、1つの店の値 x について「x − 全体の平均 ＝（x − 群の平均）＋（群の平均 − 全体の平均）」と分けたところから、自分の言葉で書いてから開く。

::: toggle 書いてから開く
どのデータでも、全体の平方和は群間の平方和と群内の平方和の和にちょうどなる。

1つの値のずれを2つに分けて2乗すると、(x−群の平均)²＋(群の平均−全体の平均)²＋2×(x−群の平均)×(群の平均−全体の平均) の3つの項になる。最後の項を1つの群の中で足すと、(群の平均−全体の平均) はその群のどの店でも同じなので外にくくり出せ、残るのは (x−群の平均) の群の中の合計。群の平均からのずれは、群の中で足すと必ず0 になる（平均の定義そのもの）。だから掛け合わせの項は群ごとに消え、残った2つが群内と群間になる。

群の平均の代わりに別の値（たとえば群の中央値）を真ん中にすると、ずれの合計が0 にならず、掛け合わせの項が残って、ちょうど分かれない。自由度も同じように、全体の N−1 が群間の a−1 と群内の N−a に分かれる。この「ちょうど分かれる」性質があるので、群間と群内の平均平方を比べる F が作れる。
:::

### 本当に？｜くじで割り当てれば、群の差は施策の効果と言えるか

隣り合う2店を組にした10組で、組ごとにくじで1店に新しい陳列を入れた。陳列には客を新しく呼ぶ力はなく、陳列の店に、隣の陳列なしの店から客が移るだけだったとする。陳列の店は1店あたり売上が3 増え、隣の店は3 減った。くじで割り当てたこの実験で、陳列の群となしの群の差はいくつになり、それは「チェーンに陳列を入れたときの効果」と言えるか。考えてから開く。

::: toggle 考えてから開く
群の差は 3−(−3)＝6。ところが20店の合計は 3×10−3×10＝0 で、チェーン全体では売上は増えていない。

くじで割り当てると、割り当ての前に決まっている店の性質（規模・立地）は群と無関係になる。けれども、くじが保証するのはそこまでで、「どの店の売上も、その店自身が陳列をしたかどうかだけで決まる（ほかの店の割り当てに左右されない）」ことは、別の前提として置いている。隣の店から客が移ると、この前提が崩れ、陳列なしの群の売上まで陳列の影響を受ける。差の6 は、陳列の店が増えた分と、隣の店が減った分を足した値で、どちらも全店に陳列を入れれば起きない。

確かめるには、客が行き来しないほど離れた店どうしで比べる、地域ごとにまとめてくじを引く（地域の全店に入れるか入れないか）などで、群どうしの行き来を断つ。
:::

### ほかでは？｜つながり

- **2群なら F は t の2乗**：2標本の t 検定（{{unit:U25}}）
- **何回も検定すると、どれかが偶然有意になる**：第1種の過誤（{{unit:U24}}）
- **調べる人を選ぶくじ**：無作為抽出と層化抽出（{{unit:U31}}）。局所管理（規模の組でくじ）は、層化と同じ形
- **観察データで、ほかの変数が同じ値どうしで比べる**：重回帰（{{unit:U30}}）と層別（{{unit:U28}}）。くじで割り当てられないときの手

### 説明してみる

::: task
5つの陳列案を各4店にくじで割り当てて試した。分散分析で棄却したので、担当者は平均がいちばん高かった C 案（平均＋6）を採用し、「全店に入れれば1店あたり平均6 増える」と見積もった。この見積もりのどこに無理があるかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（くじで割り当て、店どうしが独立で、分散分析の前提が成り立つとみて）**：棄却して言えるのは「5案のうち少なくとも1組の母平均が違う」まで。C 案がいちばん良いとも、ほかのどの案より良いとも、まだ言っていない（組ごとに比べるなら、比べる組の数を考えて調整する）。さらに、5つの平均の中から「いちばん高い」ものを選ぶと、その平均は、選んだという事実のせいで、本当の効果より高めに出やすい。5案の本当の効果がどれも同じでも、各4店の平均はたまたまばらつき、いちばん高い案の平均は真ん中より上に出るから。選んだ案の平均＋6 は、その案の効果の見積もりとしては上に偏りうる。

**解釈の例**：
- C 案は本当にいちばん売れる案だが、＋6 にはたまたまの上ぶれが含まれ、全店に入れると伸びは＋6 より小さい
- 上位の2〜3案の本当の効果はほとんど同じで、C 案が選ばれたのは4店のたまたまの組み合わせ

どちらかは、この20店の数字だけからは決められない。

**統計の外で決めること**：C 案を今すぐ全店に入れるか、上位の案だけを新しい店で、比べる組を前もって決めて試し直してから決めるか。試し直す費用と、遅れて入れる損のどちらを重く見るかで決まる。
:::
