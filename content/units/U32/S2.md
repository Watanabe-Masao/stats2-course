**お手本：施策を店にくじで割り当てる理由**

- **条件**：規模の違う店で、施策の効果を比べるとき
- **対象と結論**：どの店にどの施策をするかは、くじで決める（無作為化）
- **根拠**：担当者が選ぶと、売上の高い店や乗り気な店に施策が偏り、その違いが効果に混ざる（交絡）。くじなら、規模などの違いが施策と無関係になる
- **成り立たない場合**：店の数が少ないと、くじでも偶然偏ることがある。規模の近い店どうしで組にしてくじを引く（局所管理）、割り当て後に偏りを確かめる

::: toggle つなげると（お手本の文）
「規模の違う店で施策の効果を比べるときは、どの店にどの施策をするかをくじで決める。担当者が選ぶと売上の高い店などに施策が偏り、その違いが効果に混ざるが、くじなら規模などの違いが施策と無関係になるからである。ただし店の数が少ないとくじでも偶然偏ることがあるので、規模の近い店どうしで組にしてくじを引く。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「3つの施策を、各2店で試しました。A と B、A と C、B と C の t 検定を3回して、A と C だけ5%で有意でした。B 案は有意差がなかったので、A 案と同じ効果です。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- 3群を比べるなら、まず分散分析の F で「すべての平均が等しい」を検定する。t 検定を3回くり返すと、偶然の有意が増える。
- 「有意差がなかった」は「同じ効果」の証明ではない。各2店では差を見逃しやすい。

**言い直しの例**

「3施策（各2店）の平均の差を一元配置の分散分析で調べると F＝4 で、F(2, 3) の点9.552 に届かず、平均に差があるとは言えなかった。各2店と少ないので、店を増やして確かめる。どの組が違うかを見るときは、検定の回数を考えて判断の基準を厳しくする。」
:::

::: toggle 取り違えやすい言葉
- **「分散分析」と「分散の検定」**：分散分析が調べるのは平均の差。群の分散が等しいことは前提
- **「群間」と「群内」**：群の平均のずれ／同じ群の中のばらつき
- **「平方和」と「平均平方」**：平均平方＝平方和÷自由度
- **「交絡」と「偶然のばらつき」**：交絡は比べたいもの以外の違いが混ざる偏り。くじで防ぐ。偶然のばらつきは反復でつかむ
- **「店」と「日」**：くじで割り当てた単位（店）が1つのデータ。同じ店の毎日を別の店として数えない
:::

### 分散分析表の早見

| 変動 | 平方和 | 自由度 |
| --- | --- | --- |
| 群間 | Σ nᵢ(x̄ᵢ−x̄)² | a−1 |
| 群内 | ΣΣ(xᵢⱼ−x̄ᵢ)² | N−a |
| 全体 | 群間＋群内 | N−1 |

^ 平均平方＝平方和÷自由度、F＝群間の平均平方÷群内の平均平方。F(a−1, N−a) の上側の点と比べる。
