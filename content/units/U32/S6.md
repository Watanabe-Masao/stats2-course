### 探究｜観察データから言えることと、実験で確かめること

2店の120日分の日販（架空）では、キャンペーンをした日の売上が高い。ただしキャンペーンは週末に多い。このデータから何が言えるか。キャンペーンの効果を本当に確かめるなら、どの日にキャンペーンをするかをどう決めるか。

分け方（キャンペーン・平日／週末・天気・店）、絞り方、図（箱ひげ図・クロス集計）を切り替える。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること**：キャンペーンをした日の売上の平均は高い。しかしキャンペーンは週末に偏っていて（クロス集計）、平日だけ・週末だけで比べると差は小さい。このデータは、店が自分で日を選んだ観察データなので、差のどこまでがキャンペーンの効果かは決められない。

**解釈の例1**：効果は小さいと見て、まず平日と週末それぞれで、キャンペーンをする日をくじで決める実験を1か月行う。週末のキャンペーンは続けたまま、平日だけで試す。

**解釈の例2**：週末の売上を逃したくないので、週末のキャンペーンは止めない。代わりに、2店のうち片方の店だけで週末のキャンペーンを休む週をくじで決め、店の違いは前後の比較でならす。

どちらも筋は通る。どこまで売上を犠牲にして確かめるか、店の都合をどう扱うかは、統計の外で決める。統計が答えるのは、決めた割り当ての下で「効果はどれくらいか、どれくらい確かか」。
:::

### 課題A｜施策の比べ方を設計する

自分の売場で試したい施策を1つ選び、試す前に次を書く。

| 項目 | 書くこと |
| --- | --- |
| 比べるもの | 施策の案（水準）と、測る数（売上・数量など） |
| 単位 | くじで割り当てる単位（店・日・売場） |
| 割り当て | くじの引き方、似た単位どうしの組（局所管理） |
| 判断 | 分散分析や t 検定、比べる組の数 |
| 統計の外 | 採用の基準（費用・手間・店の都合） |

### 課題B｜観察データの比較を報告する

**問い**　「新しいレジを入れた店は、入れていない店より客数が多い」という報告が来た。どう返すか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：新しいレジは客数の多い店から入れた可能性がある（交絡）。入れる前の客数をそろえて比べる、規模の近い店どうしで比べる、これから入れる店をくじで決めて前後を比べる、のどれができるかを確かめる。

**小さな例で検証**：ラボの「割り当て方」で「大きい店を選ぶ」にし、本当の効果 τ を0 にしても、推定の平均が大きく出ることを見る。

**成り立たない条件と、その先の判断**：入れる店をくじで決められないこともある（設備の都合）。そのときは、比べ方の限りを書いたうえで、導入の判断は費用や現場の声で決める。
:::

### 課題C｜比べた組の数を決める

5つの売場の陳列を比べるとき、どの組を比べたいかを先に決める（全部の組か、新しい案と今の案だけか）。比べる組の数と、そのときの判断の基準を書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何と何を比べ、何を確かめたいかが明確か |
| 仮定 | 割り当てた単位・独立・等しいばらつきを書いたか |
| 方法 | 無作為化・反復・局所管理をどう使うかを決めたか |
| 検証 | ラボや小さな例で割り当て方を確かめたか |
| 切り分け | 統計で答えることと、採用の判断（統計の外）を分けたか |
