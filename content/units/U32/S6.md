### 探究｜規模の組でくじを引いた実験を、組を無視して分散分析すると

12店を規模で4つの組（小・中・大・特大）に分け、各組の3店に、陳列 A（今の陳列）・B・C をくじで割り当てた（局所管理）。1か月の売上の伸び（万円）は次のとおり。

| 規模の組 | A・B・C |
| --- | --- |
| 小 | 10・12・13 |
| 中 | 20・21・24 |
| 大 | 30・33・34 |
| 特大 | 40・42・45 |

本部のメモ：「3案の4店ずつで一元配置の分散分析をすると F は約0.09 で、有意でなかった。陳列を変えても売上の伸びは変わらない」。この F は何と何を比べた数か。組でくじを引いた実験から、何が言えるのか。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}

1. 表とメモから、確かめたいことを自分で問いにする（例：群の中のばらつきには、何が入っているか）
2. 上のラボで、一元配置の群間と群内の平方和を読む。群内の平方和が大きいのはなぜか、表の並びと見比べる
3. 規模の組ごとに、B−A と C−A を計算する。4つの組で、差の向きと大きさはそろっているか
4. 組の違いを除くと、F がどう変わるかを考える（2級の範囲の外。考えてから例を開く）
5. 統計で言えることと言えないことを分け、結果の読み方を2つ以上書く

::: toggle 聞き取りで分かったこと（自分の問いを書いてから開く）
- C 案は、棚を作り替えて通路側に商品を出す陳列。作り替えに1店あたり手間がかかる
- 陳列を入れたのは、各店の売場担当者。どの案になったかは、担当者も知っていた
- 本部は、規模によらず全店で同じ陳列にしたい
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（12店の伸びが正しく、店どうしが独立とみて）**：
- 一元配置の分散分析では、群の平均は A 25・B 27・C 29 で、群間の平方和は32（自由度2）。群内の平方和は1584（自由度9）と大きく、F＝(32÷2)÷(1584÷9)≒0.09。群内には、陳列と関係のない規模の違い（組の平均で約12〜42）がそのまま入っている
- 組ごとの差は、B−A が 2・1・3・2（平均2）、C−A が 3・4・4・5（平均4）。4つの組すべてで、B も C も A より伸びが大きい
- 規模の組の違いを除いて比べる分析（乱塊法の分散分析。2級の範囲の外）では、組の平方和約1581.3（自由度3）を群内から外し、残りの平方和約2.67（自由度6）で割る。陳列の効果が組によらず同じとみる式で、F＝(32÷2)÷(2.67÷6)≒36 となり、F(2, 6) の上側5%点5.14 を大きく超える
- 組でくじを引いたので、規模の違いは陳列と無関係に割り当たっている。組の違いを除いて比べるのは、実験の設計（局所管理）に合った読み方

同じ12店から、F≒0.09 と F≒36 が出る。違いは、規模の違いを「偶然のばらつき」に数えるか、除くか。

**解釈の例**：
- C 案は規模によらず効き、伸びを4万円ほど増やす。全店に入れる候補になる
- C−A は小さい組で3、特大の組で5 と、規模が大きいほど少し大きい。陳列の効果は「何万円」ではなく、店の売上に比例するのかもしれない
- どの案かを担当者が知っていたので、新しい案の店で担当者が売場に力を入れた分も、差に入っているかもしれない

どれかは、この12店の数字だけからは決められない。

**統計の外で決めること**：C 案の作り替えの手間に見合う伸びと言えるか。全店で同じ陳列にするか、規模で変えるか。
:::

### 課題｜本部への報告に、どの結果を載せるか

**問い**　本部への報告に、陳列の効果について1つの結果を載せる。どれを載せるか。

- **ア**：一元配置の分散分析の結果
- **イ**：規模の組ごとの差（B−A・C−A）と、組の違いを除いて比べた結果
- **ウ**：組ごとの差を、組の売上の大きさに対する割合にした結果

**判断の材料**：上の「聞き取りで分かったこと」の3つ（C 案の手間・担当者が案を知っていた・全店で同じ陳列にしたい）。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（伸びが正しく、店どうしが独立とみて）**：ア は、規模の違いまで偶然のばらつきに数えた比べ方で、組でくじを引いた設計に合っていない。イ は設計に合い、4つの組すべてで同じ向きの差がある。組の違いを除いた F は、陳列の効果が組によらず同じとみる式での値。ウ は、効果が売上に比例するとみる見立ての上の数で、4組では比例かどうかを確かめきれない。

**統計の外で決めること**：本部が全店で同じ陳列にしたいので、規模ごとの割合より、全店に共通の差が分かる イ を載せる。C−A の平均4 と、4組とも正であることを書き、C 案の手間と比べる材料にする。ただし、担当者が案を知っていたので、差の一部は担当者の力の入れ方かもしれないと添える。次に試すときは、陳列を入れる人と売上を数える人を分け、どの案かを売場に伝えずに入れられないかを検討する。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 自分の問いが、メモのどの言葉（「有意でなかった」「変わらない」）を確かめるものかを言えたか |
| 仮定 | 群の中のばらつきに何が入るか、効果が組によらず同じかの見立てを、計算の前に書いたか |
| 方法 | 組ごとの差を計算し、一元配置の平方和と並べたか |
| 検証 | ラボで群間と群内の平方和を読み、組の違いがどちらに入っているかを確かめたか |
| 切り分け | 言えること（どの比べ方で何が言えるか）と、言えないこと（担当者の力の入れ方の分）を分けたか |
| 解釈 | 結果の読み方を2つ以上並べ、報告する結果とその理由を書いたか |
