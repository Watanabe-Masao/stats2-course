### 0｜入口の問い

::: task
売場の施策 A を春、B を夏、C を秋に、1店で順に試した。C の数量がいちばん多かった。C がいちばんよい施策だと言えるか。3つの施策を同時に比べたいとき、どの店にどの施策を割り当て、どう判断すればよいか。
:::

^ まだ答えなくてよい。計算の前に比べ方を設計し（無作為化・反復・局所管理）、3つ以上の群の平均の差を分散分析の F で判断できるようになるのが初学のゴール。

### 2｜意味をつかむ：比べ方を先に決める　{{power:P3}}

::: ask 入口の問いの何がまずい？
→ 施策と季節が一緒に変わっている。C の効果と秋の効果を分けられない。比べたいもの以外の違いが結果に混ざることを**交絡**という。計算の前に、比べ方を設計して交絡を防ぐ。
:::

::: ask どう設計する？（フィッシャーの3原則）
→ **無作為化**：どの店にどの施策をするかをくじで決め、偏った選び方を防ぐ。**反復**：各施策を独立した複数の店で試し、偶然のばらつきの大きさをつかむ。**局所管理（ブロック化）**：規模の近い店どうしをまとめ、その中で施策をくじで割り当てる。
:::

::: ask 3つ以上の平均は、どう比べる？
→ 全体の変動を「群の平均のずれ（群間）」と「群の中のばらつき（群内）」に分け、F＝群間の平均平方÷群内の平均平方 を F 分布の点と比べる（**一元配置の分散分析**）。名前は「分散」だが、調べるのは平均の差。2群ずつ t 検定をくり返すと、偶然の有意が増える。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
F=\frac{SS_B/(a-1)}{SS_W/(N-a)}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| a | 群（施策）の数：3 |
| N | 全部の店の数：6 |
| SS_B | 群間の平方和：群の平均が全体の平均からどれだけ離れるか |
| SS_W | 群内の平方和：各店が自分の群の平均からどれだけ離れるか |

**式を言葉で読む**：分子は「群の平均のずれ」、分母は「群の中の偶然のばらつき」。それぞれ平方和を自由度で割った**平均平方**どうしの比。すべての群の母平均が同じなら F は1 の近くになり、平均がずれるほど大きくなる。

| 変動 | 平方和 | 自由度 |
| --- | --- | --- |
| 群間 | SS_B＝Σ nᵢ(x̄ᵢ−x̄)² | a−1 |
| 群内 | SS_W＝ΣΣ(xᵢⱼ−x̄ᵢ)² | N−a |
| 全体 | SS_B＋SS_W | N−1 |

```txt
群間の平方和：各群の店の数 ×（群の平均 − 全体の平均）² の合計
群内の平方和：各店の値 − その群の平均 の2乗の合計
平均平方：平方和 ÷ 自由度、F＝群間の平均平方 ÷ 群内の平均平方
H₀：すべての群の母平均が等しい　H₁：少なくとも1組が異なる
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　3つの売場施策を各2店にくじで割り当てた。数量の増加は A：1, 3　B：3, 5　C：5, 7。施策で平均に差があるかを有意水準5%で判断せよ（F(2, 3) の上側5%点は9.552）。

1. 群の平均 2・4・6、全体の平均 (1＋3＋3＋5＋5＋7)÷6＝**4**
2. 群間：2×(2−4)²＋2×(4−4)²＋2×(6−4)²＝**16**（自由度2）
3. 群内：各群 (−1)²＋1²＝2 が3群で **6**（自由度3）。全体の平方和22＝16＋6
4. 平均平方 16÷2＝8、6÷3＝2 → F＝8÷2＝**4**
5. 4＜9.552 → **棄却しない**（p≒0.14）

{{lab:LAB-doe@s1-anova}}

::: warn
A対B・A対C・B対C と t 検定を3回くり返さない（偶然の有意が増える）。棄却しなくても「3施策は同じ」と示されたわけではない。1店で毎日数えた3日分を、独立した3店として数えない。
:::

::: key
平均は2→4→6 と並んでいても、各2店では偶然のばらつきの範囲を超えるとは言えない。同じ値の店を各4店に増やすと、群内の自由度が3から9 に増えて F＝12 になり、棄却する。差を見つけるには「反復」が要る。
:::

**割り当て方の例**　規模の違う20店で、本当は売上を3増やす施策を試す。施策を「大きい店から10店」に割り当てると、大きい店はもともと売上が高いので、推定した効果に規模の差が混ざる（交絡）。くじで割り当てると混ざらない。

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-doe@s1-exp}}

1. **予想**：ラボの課題カードで、規模の近い2店ずつの組でくじを引くと、推定した効果のばらつきは「くじで半分」と比べてどうなるかを選ぶ。
2. **操作**：結果を見たら、割り当て方を「くじで半分」「大きい店を選ぶ」に切り替え、本当の効果 τ も0・3・6 と変える。
3. **観察**：推定の平均（偏り）と、ヒストグラムの幅（ばらつき）は、割り当て方でどう変わるか。
4. **説明**：「くじで割り当てると偏りは□。組にしてくじを引くと、ばらつきが□。なぜなら□」を1文で書く。
5. **ラボなしで**：大きい店を選ぶ割り当てで、τ を0 にしたら推定の平均はどうなるか。

::: toggle 答え（書いてから開く）
- **観察**：大きい店を選ぶと、推定の平均は本当の効果より大きく外れる（偏りあり）。くじで割り当てると平均は本当の効果に近い（偏りなし）が、ヒストグラムの幅は広い。組にしてくじを引くと、偏りなしで幅もせまい。
- **説明の例**：「くじで割り当てると、規模の差が施策と無関係になるので偏りは消える。規模の近い店どうしで比べると、規模の差がばらつきとしても入らないので、ばらつきが小さくなるから」
- **ラボなしで**：効果がなくても、大きい店の売上の高さがそのまま「効果」に見える。施策に効果がないのに、あるように見えてしまう。
:::
