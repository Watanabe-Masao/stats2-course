「二項分布 B(n, p)」で正規分布を重ね、n と p を動かして近似が合う範囲を見る。「ベルヌーイと np」で分散 p(1−p) が p＝0.5 で最大になることを確かめる。予測して当てる場ではない。動かして、なぜそうなるかを自分の言葉で説明する。

### なぜ？｜分散 p(1−p) は、なぜ p＝0.5 で最大なのか

1回の結果の分散 p(1−p) は、p＝0.5 で0.25と最大になり、p が0や1に近づくと0に近づく。「半々の出来事がいちばん読みにくい」。ほぼ必ず起きる（または起きない）ことは、結果が読めるのでばらつかない。割合を調べる調査で、必要な人数を見積もるときに p＝0.5 を使うのはこのため（{{unit:U22}}）。

n 回分の分散 np(1−p) は、1回分の p(1−p) を n 回足したもの。足せるのは各回が独立だから（{{unit:U13}}）。

### 1つの数で何が消えるか

購入率25%の売場に4人なら、平均は np＝1人。けれども「平均1人」からは、**0人の日が約32%もある**ことが見えない（0.75⁴≒0.316）。3日に1日くらいは1人も買わない。平均が同じ1人でも、10人で購入率10%なら0人の確率は約35%と、また違う。平均だけで売場の手応えを判断すると、「0人の日」に驚くことになる。

### 本当に？｜独立・確率一定が崩れると、何が変わるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

二項分布は「各回が独立」「確率が毎回同じ」を前提にしている。崩れ方によって、分散は二項分布より**大きくも小さくも**なる。

- **独立でない**：4人が2組の夫婦で、組ごとに一緒に買う・買わないを決めるとする。購入率は25%のままで平均も1人のままだが、2人単位で動くので、分散は 4×2×0.25×0.75＝1.5 と、二項分布の 0.75 の2倍になる。買う人数は0人・2人・4人のどれかになり、1人や3人は起きない
- **確率が人で違う**：4人の購入率が 5%・5%・45%・45% なら、平均は同じ1人だが、分散は 0.59 と二項分布の 0.75 より小さくなる。人ごとの購入率の差が大きいほど、分散は小さくなる（全員が0%か100%なら分散は0）

独立でない場合も、向きは1つではない。一緒に動けば分散は大きくなり、取り合う（1人が買うと別の人が買いにくい）なら小さくなる。

平均だけを見ていると、どちらも「平均1人」で区別がつかない。ばらつきを見ると、前提のどれが崩れているかの手がかりになる。

### ほかでは？｜つながり

- n が大きいと、二項分布は平均 np・分散 np(1−p) の正規分布に近い形になる（目安は np と n(1−p) がどちらも5〜10以上）。棒は整数の位置にあり、幅1の棒を曲線で近似するので、境目を0.5ずらす（連続修正）→ {{unit:U16}}
- n が大きく p が小さい（たとえば n＝1000、p＝0.002）ときは、平均 λ＝np のポアソン分布で近似できる。めったに起きないことが、たくさんの機会のうち何回起きるか、という形 → {{unit:U15}}
- 袋から戻さずに引くと、引いた結果によって残りの割合が変わるので二項分布ではなく超幾何分布になる。分散は二項分布の np(1−p) に (N−n)/(N−1)（N は袋の中の総数）を掛けた値になり、2個以上引くとその分だけ小さい。袋が大きく引く数が少なければ、この係数は1に近く、二項分布とほぼ同じ → {{unit:U15}}

^ 正規近似の計算を確かめる問題は、2級の範囲なので {{stage:S3}} に置いた。

::: toggle 1つの考え方の例（自分で書いてから開く）
二項分布 B(20, 0.1) なら平均2人・分散1.8で、0人も6人も起こりうる（0人は約12%）。1つの店の結果だけでは、二項分布かどうかは決められない。ただ、多くの店の結果のばらつきが分散1.8より明らかに大きいなら、**確率一定**と**独立**の少なくとも一方が崩れている。店ごとに客層が違って利用率が違う（確率一定でない）、友人どうしで一緒に使う（独立でない）などが考えられる。店ごとに利用率が違うと、店ごとの利用数は二項分布より大きくばらつく（1店の中で人ごとに確率が違うと小さくなるのとは逆）。どの読み方が当たっているかは、店の客層や配り方を調べて確かめる（統計の外の情報）。
:::
