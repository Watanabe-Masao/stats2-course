### 課題A｜自分の売場の「二項分布チェック」を作る

クーポン・試食・声かけなど「n 人のうち何人が〜するか」の場面を1つ選び、次を作る。

| 項目 | 書くこと |
| --- | --- |
| n と p | 人数（回数）と、1人あたりの確率の出どころ |
| 4つの条件 | 回数固定・2通り・確率一定・独立をそれぞれ確かめた結果 |
| 平均と外れ | 平均 np、0人の確率、k 人以上の確率 |
| 崩れる場合 | 独立でない・確率が人で違う例 |

### 課題B｜抜き取り検査の基準を決める

**問い**　不良率が2%を超えたら出荷を止めたい。何個抜き取り、何個以上の不良で止めるかを決める。決め方と、そのために必要な数を書く。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：不良率2%のとき、50個抜き取って1個以上見つかる確率は 1−0.98⁵⁰≒64%。止めるべきでないとき（不良率が十分低いとき）に止めてしまう確率と、止めるべきとき（不良率が高いとき）に見逃す確率の両方を、二項分布で計算して比べる。

**必要な数**：抜き取る手間（1個あたり）、良いロットを止める損、悪いロットを出す損。

**小さな例で検証**：ラボの「二項分布 B(n, p)」で n と k を変え、p＝0.02 と p＝0.1 のそれぞれで「k 個以上」の確率を比べる。

**成り立たない条件と、その先の判断**：不良が特定の箱にかたまっていると、独立の前提が崩れる。抜き取る場所を散らす。
:::

### 課題C｜予約の受けすぎ（オーバーブッキング）を考える

席の数より少し多く予約を受けると、空席は減るが、来店が席を上回ることがある。席数・予約数・来店率を決め、席を超える確率と平均の空席数を二項分布で出し、何人まで受けるかを書く。

### 評価の観点

| 観点 | 見ること |
| --- | --- |
| 問い | 何人中何人の確率を知りたいかが明確か |
| 仮定 | 4つの条件、p の出どころを書いたか |
| 方法 | ちょうど・以上・余事象を使い分けたか |
| 検証 | 小さな例やラボで確かめたか |
| 切り分け | 独立でない・確率が一定でない場合を書いたか |
