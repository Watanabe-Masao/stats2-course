### 同じ構造の場面：直線 → 残差 → R² → 範囲内で使う

| 場面 | x → y | 気をつけること |
| --- | --- | --- |
| 気温と売上 | 気温 → 売上 | 季節の外は外挿 |
| 店の面積と売上 | 面積 → 売上 | 残差で店を比べる |
| 広告と来店 | 広告回数 → 来店者 | 因果とは限らない |
| 値引きと販売数 | 値引き率 → 販売数 | 曲がりを残差で確かめる |

^ どの場面も「散布図 → 最小二乗の直線 → 残差と R² → 観測した範囲で使う」の順。傾きは y の単位で読む。

::: toggle 読み取りの例
- **気温と売上（20〜28℃の5日）**：ŷ＝6.2＋1.2x、R²＝0.9。25℃の予測は36.2万円。40℃は観測した範囲の外なので予測しない。
- **店の面積と売上（5店）**：ŷ＝6.6＋2.1x。残差が＋2.1 の店は「面積から見込むより売れている」、−2 の店は「見込みより売れていない」と読める。
:::

### 仕事の場面で

- 売上の予測式は、作ったデータの範囲（気温・店の広さ・価格帯）を一緒に書いて渡す。範囲の外では使わない。
- 残差は「見込みとの差」。面積から見込む売上より大きく外れた店を、良い例・悪い例として調べる手がかりになる。
- 報告には傾き（単位つき）・R²・残差の標準偏差（予測のずれの目安）・データの数を書く。
