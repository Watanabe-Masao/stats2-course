### なぜ？｜なぜ回帰直線は、標準偏差の比の直線より寝ているのか

例題Aの5週 (1,3)(2,5)(3,4)(4,6)(5,7) では、x と y の標準偏差が等しい（偏差平方和はどちらも10）。だから、平均の点 (3, 5) を通る傾き1 の直線（x が標準偏差1つ分動くと y も1つ分動く直線）が、点の並びの軸のように見える。ところが最小二乗の傾きは0.9 だった（初学）。ラボで、平均の点を通る傾き0.8・0.9・1.0 の直線の残差平方和を読み、なぜ1 ではなく r 倍の0.9 で最小になるのかを考えてから開く。

::: toggle 動かしてから開く
残差平方和は、傾き0.8 で2.0、0.9 で1.9、1.0 で2.0。

平均の点を通る傾き c の直線の残差平方和は、Σ(y−ȳ)²−2cΣ(x−x̄)(y−ȳ)＋c²Σ(x−x̄)²＝10−18c＋10c²。両方を z得点（{{unit:U08}}）にそろえて n で割ると 1−2cr＋c² になり、これを最小にする c はちょうど r（r が z の積の平均であることは {{unit:U28}} の発展）。z の単位で見ると、回帰直線は「x が平均から標準偏差1つ分離れると、y は平均から標準偏差 r 個分だけ離れると見込む」直線。

図で言えば、x の値が同じ点だけを縦に切って取り出すと、その y は散らばっていて、真ん中は x ほど端には寄っていない。回帰直線は、この縦に切った点の群の真ん中を通ろうとするので、|r|＜1 なら、x の位置より平均の側に寄った見込みになる。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

同じ関係 ŷ＝2＋x のまわりに同じように散らばった点を、狭い範囲（x＝1〜5：(1,2)(2,5)(3,5)(4,7)(5,6)）と広い範囲（x＝1〜9：(1,2)(3,6)(5,7)(7,10)(9,10)）で5つずつ観測した。ラボで、それぞれの回帰直線・R²・残差の標準偏差 s_e＝√(SSE÷(n−2)) を読む。R² が違うとき、予測の外れ方も違うか。

::: toggle 動かしてから開く
どちらも回帰直線は ŷ＝2＋x、残差は −1, 1, 0, 1, −1 で同じ、s_e も約1.15（十万円）で同じ。ところが R² は、狭い範囲で約0.71、広い範囲で約0.91。

R² は、y のばらつきのうち直線で説明できた分の「割合」。広い範囲で観測すると、x が動く分だけ y のばらつき（SST）が大きくなり、同じ残差でも割合は大きく出る。R² からは、**予測がどれだけ外れるか（y の単位の大きさ）**と、x をどれだけ広く観測したかの区別が消える。予測の外れ方は s_e で言い、R² を比べるときは x の観測の範囲をそろえる（{{unit:U28}} の応用の「範囲の制限」と同じ仕組み）。
:::

### 本当に？｜上位の店の売上が翌月に下がったら、表彰で気がゆるんだのか

5店の先月の売上 x と今月の売上 y（百万円）は (8,8)(9,11)(10,10)(11,9)(12,12)。先月の上位2店（11・12）を表彰したところ、今月の2店の平均は先月の11.5 から10.5 に下がった。本部は「表彰で気がゆるんだ」と書いた。ラボで、y を x で見込む直線と、x を y で見込む点線を読む。今月の上位2店（12・11）の先月の値も見る。

::: toggle 動かしてから開く
先月と今月の平均はどちらも10、標準偏差も等しく、相関係数は0.6。y を x で見込む直線は ŷ＝4＋0.6x で、傾き0.6。先月の上位2店の今月の平均は 10.5 で、先月より1 下がった（下がったのは先月11 の店で、先月12 の店は今月も12）。下位2店は先月8.5 から今月9.5 へ1 上がった。

逆の向きも見る。今月の上位2店（12 と11）の先月の平均は (12＋9)÷2＝10.5 で、今月の11.5 より平均の側にある。x を y で見込む点線も、傾き0.6 で寝ている。表彰は先月の値で選んだので、今月から先月をふり返る向きには効きようがないのに、同じだけ平均の側に寄っている。

全体の平均と散らばりが月で変わらないとすれば、r が1より小さいかぎり、どちらの月の値で選んでも、選んだ店は他方の月では平均して平均の側に寄りやすい（平均への回帰）。ただし5店・2店ずつでは、1店の上下で平均が大きく動く。表彰の効き目を言うには、先月の売上が同じくらいで表彰しなかった店と比べるか、表彰する店をくじで決める（{{unit:U32}}）。
:::

### ほかでは？｜つながり

- **z の積と直線へのそろい方**：相関係数（{{unit:U28}}）
- **説明変数を増やす・傾きの検定**：重回帰と係数の t 検定（{{unit:U30}}）
- **平方和を分ける**：分散分析（{{unit:U32}}）、2乗の和の分かれ方（{{unit:U07}} の発展）
- **時間の順に並んだ残差**：自己相関（{{unit:U05T}}）
- **くじで比べる相手を作る**：無作為化（{{unit:U32}}）

### 説明してみる

::: task
6店のチラシの枚数 x（千枚）と月の売上 y（十万円）は (1,1)(1,9)(2,3)(2,27)(3,9)(3,81)。店の規模がまちまちなので、担当者は売上を底3の対数（0, 2, 1, 3, 2, 4）に直して直線を当てはめ、「対数の見込み＝x」を得た。そこから「チラシ2千枚の店の売上は 3²＝9（十万円）と見込む」と書き、6店の見込みの合計を 2×(3＋9＋27)＝78 とした。実際の6店の合計は130。回帰直線が何の「見込み」なのかから、合計が小さく出た理由を説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（6店の記録が正しいとみて）**：回帰直線は、x ごとの y の平均の見込み。対数に直して引いた直線は、x ごとの「対数の平均」を見込む。x＝2 の2店の対数は1 と3 で、平均は2。これを戻した 3²＝9 は、2店の売上 3 と27 の平均15 ではなく、幾何平均（{{unit:U05T}}）にあたる。散らばりのある値の幾何平均は平均より小さいので、どの x でも戻した見込みは平均より低く、合計は 78 対 130 と下回る。目盛りを変えると、直線がよく合うかどうか（{{unit:U28}} の発展）だけでなく、直線が何の平均を見込むかも変わる。

**解釈の例**：
- 規模の大きい店ほどチラシに反応する客の数そのものが多い（割合で効く）ので、対数の目盛りの方が仕組みに近い
- 規模の違いはチラシとは別の理由（商圏の人口）から来ていて、チラシの見込みに使うなら、規模をもう1つの説明変数にした方がよい

どちらかは、6店の数字だけからは決められない。

**統計の外で決めること**：見込みを何に使うか。店ごとの「ふつうの売上」を言いたいなら対数で引いた見込みでもよいが、全店の合計の予算を立てるなら、もとの目盛りの平均の見込みに直して使う。
:::
