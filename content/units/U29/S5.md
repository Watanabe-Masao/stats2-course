### なぜ？｜なぜ傾きは、相関係数が1より小さいと控えめになるのか

例題Aの5週 (1,3)(2,5)(3,4)(4,6)(5,7) では、x と y の標準偏差が等しい（偏差平方和はどちらも10）。平均の点 (3, 5) を通る直線の傾きを 0.8・0.9・1.0 にして、残差平方和を読む。点の並びは右上がりの45度（傾き1）に見えるのに、最小になるのはどの傾きか。なぜかを考えてから開く。

::: toggle 動かしてから開く
残差平方和は、傾き0.8 で2.0、0.9 で1.9、1.0 で2.0。最小は傾き0.9 で、相関係数 r＝0.9 と同じ値。

平均の点を通る傾き c の直線の残差平方和は、Σ(y−ȳ)²−2cΣ(x−x̄)(y−ȳ)＋c²Σ(x−x̄)²＝10−18c＋10c²。両方を z得点（{{unit:U08}}）にそろえて n で割ると、1−2cr＋c² になり、これを最小にする c はちょうど r。z の単位で見ると、回帰直線は「x が平均から標準偏差1つ分離れると、y は平均から標準偏差 r 個分だけ離れると見込む」直線になる。|r|＜1 なら、見込みはいつも x の位置より平均の側に寄る。点が直線のまわりに散らばっているかぎり、縦のずれを小さくするには、傾きを少し寝かせて平均の側に寄せる方がよいから。
:::

### 1つの数で何が消えるか

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

例題Aの5週と、店Bの5週 (1,1)(2,5)(3,3)(4,7)(5,9) で、ラボの R² と、残差の標準偏差 s_e＝√(SSE÷(n−2)) を読む。R² が同じとき、予測の外れ方も同じか。

::: toggle 動かしてから開く
どちらも R²＝0.81。ところが s_e は、例題Aが約0.80（百人）、店Bが約1.59（百人）で、店Bの予測は2倍ほど外れる。店Bは y の偏差平方和が40 と例題Aの4倍で、残差平方和も 7.6 と4倍になっている。

R² は、y のばらつきのうち直線で説明できた分の「割合」なので、もとのばらつきの大きさが消えている。同じ R² でも、もとの y が大きく散らばっていれば、残った外れ（残差）も大きい。予測がどれだけ外れるかは、R² ではなく s_e（y の単位）で言う。
:::

### 本当に？｜上位の店の売上が翌月に下がったら、表彰で気がゆるんだのか

5店の先月の売上 x と今月の売上 y（百万円）は (8,8)(9,11)(10,10)(11,9)(12,12)。先月の上位2店（11・12）を表彰したところ、今月の2店の平均は先月の11.5 から10.5 に下がった。本部は「表彰で気がゆるんだ」と書いた。ラボで y を x で回帰した直線を読み、先月の下位2店（8・9）の今月も見る。

::: toggle 動かしてから開く
先月と今月の平均はどちらも10、標準偏差も等しく、相関係数は0.6。回帰直線は ŷ＝4＋0.6x で、傾きは0.6。先月の上位2店の今月の平均は 10.5 で、先月より1 下がった。下位2店は先月8.5 から今月9.5 へ、1 上がった。表彰していない下位の店も、同じだけ平均の側に寄っている。

先月の売上には、その店のふだんの力と、その月だけの上下の両方が入っている。先月に上位だった店は、その月だけの上下も上に出ていた店が多く、今月はその分がなくなりやすい。r が1より小さいかぎり、先月の値で選んだ上位・下位は、今月は平均の側に寄る（平均への回帰）。表彰の効き目を言うには、表彰しなかった店のうち先月の売上が同じくらいだった店と比べるか、表彰する店をくじで決める（{{unit:U32}}）。
:::

### ほかでは？｜つながり

- **z の積と直線へのそろい方**：相関係数（{{unit:U28}}）
- **説明変数を増やす・傾きの検定**：重回帰と係数の t 検定（{{unit:U30}}）
- **平方和を分ける**：分散分析（{{unit:U32}}）、2乗の和の分かれ方（{{unit:U07}} の発展）
- **時間の順に並んだ残差**：自己相関（{{unit:U05T}}）
- **くじで比べる相手を作る**：無作為化（{{unit:U32}}）

### 説明してみる

::: task
6店のチラシの枚数 x（千枚）と月の売上 y（万円）は (1,1)(1,9)(2,3)(2,27)(3,9)(3,81)。店の規模がまちまちなので、担当者は売上を「3を何回掛けたか」（0, 2, 1, 3, 2, 4）に直して直線を当てはめ、ŷ の対数＝x を得た。そこから「チラシ2千枚の店の売上は 3²＝9万円と見込む」と書き、6店の売上の見込みの合計を 2×(3＋9＋27)＝78万円とした。実際の6店の合計は130万円。なぜ合計がこんなに小さく出たのかを説明する。
:::

::: toggle 1つの考え方の例（自分で書いてから開く）
**統計で言えること（6店の記録が正しいとみて）**：x＝2 の2店の売上は3万円と27万円で、平均は15万円。対数に直すと1 と3 で、その平均2 を戻した 3²＝9万円は、2店の幾何平均（{{unit:U05T}}）。対数の目盛りで引いた直線は、各 x での「対数の平均」を通るので、もとの目盛りに戻すと、平均ではなく幾何平均の見込みになる。散らばりのある値の幾何平均は算術平均より小さいので、どの x でも見込みは平均より低く、合計すると 78万円 対 130万円 と大きく下回る。対数に直すと直線はよく合う（この例では各 x の対数の平均にちょうど乗る）が、それは「対数の目盛りでの平均」がよく合うということ。

**解釈の例**：
- 規模の大きい店ほど、チラシに反応する客の数そのものが多い（割合で効く）ので、対数の目盛りの方が仕組みに近い
- 6店のうち2店（27万円・81万円）は駅前で、規模の違いはチラシとは別の理由から来ている

どちらかは、6店の数字だけからは決められない。

**統計の外で決めること**：見込みを何に使うか。店ごとの「ふつうの売上」を言いたいなら幾何平均の見込みでもよいが、全店の合計の予算を立てるなら、算術平均の見込みに直して使う。
:::
