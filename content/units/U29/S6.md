### 探究｜客数から売上を予測してよいか

2店の120日分の日販（架空）で、客数を横軸・売上を縦軸にした散布図を、店ごと・前半と後半に分けて見る。1本の直線で予測してよいか。

{{lab:LAB-explore@s6-reg}}

分け方を「店」「前半／後半」に変え、絞り方で特別な日を除く。点の並び方（傾き・ばらつき）が群でどう違うかを見る。

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること**：客数と売上は直線に近く並ぶが、店によって点の位置（客単価）が違う。B店は後半に客数が増えている（改装）。特別な日の点は直線から大きく外れる。

**解釈の例1**：店ごとに別の直線を引けば、予測に使える。特別な日は予測から外して別に扱う。

**解釈の例2**：改装の前後で店の性格が変わったなら、前半のデータで作った式は後半には使えない。過去のデータから予測するときは、「同じ仕組みが続いているか」をまず確かめる。

直線の当てはまりは統計で言える。その式を未来に使ってよいかは、店に何が起きたかという知識で判断する。
:::

### 課題A｜売上の予測式を作る

自分の売場の数字（気温と売上、来店客数と売上など）で、次を作る。

| 項目 | 書くこと |
| --- | --- |
| 向き | 何を何で予測するか、その理由 |
| 直線 | 最小二乗の ŷ＝a＋bx、傾きの読み方 |
| 当てはまり | R²、残差の標準偏差、残差の形 |
| 使える範囲 | 観測した x の範囲、外挿しないこと |

### 課題B｜残差で店を比べる

**問い**　面積の違う店の売上を「広さのわりに売れているか」で比べたい。どう比べ、どう報告するか。

::: toggle 1つの考え方の例（自分で決めてから開く）
**考え方**：面積 x から売上 y を予測する回帰直線を最小二乗で作り、各店の残差 e＝y−ŷ を「面積から見込む売上との差」として並べる。残差の大きい店と小さい店の違い（立地・品ぞろえ・人員）を調べる。

**小さな例で検証**：ラボの「回帰直線」で、5店 (2,10)(3,15)(4,13)(5,18)(6,19) の残差を見る。x＝3 の店が最大（＋2.1）、x＝4 の店が最小（−2）。

**成り立たない条件と、その先の判断**：面積以外の要因（立地など）が面積と一緒に動いていると、残差の読み方が変わる。5店ほどでは直線そのものが不確か。曲がりがあれば残差の大小も変わる。
:::

### 課題C｜外挿しない予測の計画

新しい施策で x がこれまでの範囲を超える（たとえば広告回数を倍にする）とき、予測式をそのまま使わずにどう確かめるか（小さく試す、範囲を広げたデータを集める）を書く。
