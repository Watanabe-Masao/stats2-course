### 探究｜残差で店長を評価してよいか

本部は今月から、店長の評価に「面積のわりに売れているか」を使うことにした。8店の売場面積 x（百m²）と今月の売上 y（百万円）に最小二乗の直線を当てはめ、残差 y−ŷ の大きい順に並べる。

| 店 | 面積 x | 今月の売上 y |
| --- | --- | --- |
| A | 2 | 7 |
| B（駅前） | 3 | 13 |
| C | 4 | 11 |
| D | 5 | 14 |
| E | 6 | 15 |
| F（改装） | 7 | 16 |
| G | 8 | 21 |
| H | 9 | 23 |

聞き取ると、次のことが分かった。
- B店は駅前にあり、ほかの7店は郊外
- F店は今月の半ばまで改装で売場の一部を閉めていた
- 先月も同じ方法で並べると、残差の1位は G店（＋3）で、B店は＋2 だった

{{lab:LAB-reg@s6-stores}}

::: pattern
**複雑さを説明する型**　{{shared:complex_pattern}}
:::

1. 本部の評価のどこを確かめるかを、自分で問いにする（例：残差に何が入っているか）
2. ラボで、回帰直線と8店の残差を読む
3. 残差の大きい店・小さい店について、面積のほかに何が効いていそうかを書き出す
4. 統計で言えることと言えないことを分ける
5. 残差の読み方を2つ以上書く

::: toggle 統計で言えることと、解釈を分けた例（自分で動かしてから開く）
**統計で言えること（8店の今月の記録が正しいとみて）**：回帰直線は ŷ＝4＋2x、R² は約0.90。残差は A −1、B ＋3、C −1、D 0、E −1、F −2、G ＋1、H ＋1 で、合計は0。最小二乗の直線を引くと、残差の合計はいつも0 になるので、どんな月でも、半分ほどの店は「面積のわりに売れていない」側に来る。残差に入っているのは、面積で見込めなかった分の全部で、店長の働きのほか、立地（B）・改装（F）・その月だけの上下も混ざっている。先月1位の G店が今月＋1 に下がったのは、本当に店の力が落ちたのか、その月だけの上下がなくなったのか、8店の2か月の数字からは分けられない（発展の平均への回帰）。

**解釈の例**：
- B店の＋3 は駅前の立地の分で、店長の働きとは別。駅前かどうかを、面積と並ぶもう1つの説明変数にすれば、B店の残差は小さくなるかもしれない
- F店の −2 は改装で売場を閉めた分で、来月には0 に戻るかもしれない。1か月の残差で評価すると、店長が決められない出来事が評価に入る
- 8店の残差の差の多くは、その月だけの上下で、店の順位は月ごとに入れ替わる。毎月1位を表彰すると、翌月は下がって見えることが多い

**統計の外で決めること**：店長の評価に、何を入れて何を外すか（立地・改装は店長の責任か）。
:::

### 課題｜評価の式に、説明変数をもう1つ足すなら何を足すか

**問い**　来月から、評価の回帰式に説明変数をもう1つだけ足せる（重回帰。{{unit:U30}}）。何を足すか。足すと、残差の意味はどう変わるか。

**判断の材料**：手元にある記録は、駅前かどうか・改装の日数・店長の勤続年数・チラシの枚数・近くの競合店の数。店は8店。

::: toggle 1つの考え方の例（自分で決めてから開く）
**統計で言えること（記録が正しいとみて）**：説明変数を足すと、残差は「面積とその変数をそろえたうえで、見込みとの差」に変わる。駅前かどうかを足せば、立地の分が残差から抜け、B店の＋3 は小さくなりうる。改装の日数を足せば、F店の −2 が抜けうる。店長の勤続年数やチラシの枚数を足すと、店長の働きの一部まで「見込める分」に入り、残差から抜けてしまう。店が8店しかないので、説明変数を増やすほど、残差はその月の上下だけが残る小さな数になり、直線の係数そのものも不確かになる（自由度調整済み決定係数で比べる。{{unit:U30}}）。

**統計の外で決めること**：評価で店長の働きとして残したいものと、店長のせいにしないもの（立地・改装・競合店）を決め、後者だけを説明変数に入れる。何を説明変数に入れるかで、同じ店の残差が「よく売れている」にも「ふつう」にもなるので、評価の式に何を入れたかを、評価と一緒に店長に示す。1か月だけで決めず、何か月かの残差の平均で見る。
:::

### 振り返りの観点（任意）

到達の基準や点数にはしない。自分の探究を見直すときに使う。

| 観点 | 見ること |
| --- | --- |
| 問い | 自分の問いが、残差に何が入っているかを確かめるものになっていたか |
| 仮定 | 面積と売上の関係を直線とみたこと、1か月の記録で評価することを書いたか |
| 方法 | 回帰直線と8店の残差を出し、面積のほかに効いていそうなことを書き出したか |
| 検証 | ラボで B店・F店の点を動かすと、ほかの店の残差もどう動くかを確かめたか |
| 切り分け | 言えること（面積で見込めなかった分）と、言えないこと（それが店長の働きか）を分けたか |
| 解釈 | 残差の読み方を2つ以上並べ、足す説明変数とその理由を書いたか |
