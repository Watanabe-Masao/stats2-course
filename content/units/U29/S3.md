### 判断の手順（毎回これを書く）　{{power:P3}}

1. **向きを決める**：何を何で予測するか（y を x で）。逆向きなら別の直線を求める
2. **散布図を見る**：直線で表せそうか、外れ値・曲がり・群の混ざりはないか
3. **係数を求める**：b＝Σ(x−x̄)(y−ȳ)÷Σ(x−x̄)²（または r×s_y÷s_x）、a＝ȳ−b x̄
4. **当てはまりと残差**：R²＝1−SSE÷SST、残差プロットに形がないか
5. **使い方と結論**：予測は観測した x の範囲内で。傾きは「〜の傾向」と書き、因果とは書かない

### 似た場面を見分ける

「広告回数から来店者数を予測」は y を x で回帰。「来店者数から必要な広告回数を逆算」は向きが逆で、ŷ の式を解くのではなく x を y で回帰する。「R² が0.9 なのに残差が山形」は直線が合っていない（曲がりがある）。「1〜5回のデータで20回を予測」は外挿。「平均と r と標準偏差だけ分かる」なら b＝r×s_y÷s_x。

### 使えない例と比べる　{{power:P3}}

- R² を「予測が当たる確率」と読む → ✕。y のばらつきのうち直線で説明できる割合。
- 観測した x の範囲の外で予測する → ✕。外挿は直線が続く保証がない。
- y を x で予測する式を、x について解いて逆向きの予測に使う → ✕。x を y で回帰した直線は別。
- R² が高いので直線で十分と決める → ✕。残差プロットに山形・谷形があれば曲がりがある。
- 傾きを因果の効果と書く → ✕。観察データでは「〜の傾向」。共通の原因があるかもしれない。
- 目分量で「だいたい合う」直線を引く → ✕。人によって違う。最小二乗で決める。

傾きが偶然でないかの検定（t 検定）と、説明変数を増やす重回帰は {{unit:U30}}。回帰の分散分析表（SSR と SSE を自由度で割って比べる F）は、3群以上の平均を比べる分散分析（{{unit:U32}}）と同じ考え方。
