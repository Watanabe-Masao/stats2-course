### 言葉にする練習　{{power:P3}}

::: pattern
{{shared:explain_pattern}}

**お手本：回帰直線の傾き b＝0.9 の意味**

- **条件**：5週間の広告回数 x と来店者数 y（百人）に最小二乗で直線を引き、ŷ＝2.3＋0.9x を得たとき
- **対象と結論**：傾き0.9 は「広告が1回多い週は、来店者が平均して0.9百人（90人）多い傾向」を表す
- **根拠**：傾きは偏差の積の和9 を x の偏差平方和10 で割ったもので、x の1単位あたりの y の動きを表すから
- **成り立たない場合**：観測した x＝1〜5 の外では直線が続く保証はない。季節など別の原因があれば、広告を増やしても来店が増えるとは限らない（因果ではない）

::: toggle つなげると（お手本の文）
「5週間の広告回数と来店者数に最小二乗で直線を引き ŷ＝2.3＋0.9x を得たとき、傾き0.9 は、広告が1回多い週は来店者が平均して90人多い傾向を表す。傾きは偏差の積の和を x の偏差平方和で割った、x の1単位あたりの y の動きだからである。ただし観測した1〜5回の外では直線が続く保証はなく、ほかの原因があれば因果の効果とは言えない。」
:::

**練習**　次の説明を、説明の型で正確に言い直す。

::: task
「R² が0.81 なので、この式で予測すると81%の確率で当たります。広告を20回にすれば ŷ＝2.3＋0.9×20＝20.3 百人来ます。来店者数から広告回数を知りたいときは、式を x について解けばよいです。」
:::

::: toggle 直す点と言い直しの例（書いてから開く）
**直す点**

- R² は「y のばらつきのうち直線で説明できる割合」。予測が当たる確率ではない。
- 広告20回は観測した1〜5回の外（外挿）。直線がそこまで続く保証はない。
- 回帰直線は y の縦のずれを最小にしたもの。x を y で予測するなら、x を y で回帰した別の直線を求める（向きで直線が違う）。

**言い直しの例**

「R²＝0.81 は、来店者数のばらつきの81%を広告回数の直線で説明できるという意味。予測は観測した1〜5回の範囲で使い、20回のような外挿はしない。来店者数から広告回数を予測するなら、x を y で回帰した直線を別に求める。」
:::

::: toggle 取り違えやすい言葉
- **「残差」と「誤差」**：残差はデータと推定した直線のずれ（計算できる）。誤差は真の直線とのずれ（見えない）
- **「回帰係数（傾き）」と「相関係数」**：傾きは y の単位で「x が1増えたときの変化」。r は単位のない −1〜1。b＝r×s_y÷s_x
- **「R²」と「当たる確率」**：R² は説明できるばらつきの割合
- **「内挿」と「外挿」**：観測した x の範囲の中か外か
- **「y を x で回帰」と「x を y で回帰」**：最小にするずれの向きが違い、直線も違う
:::

- [ ] R² を「説明できるばらつきの割合」として書いた
- [ ] 観測した x の範囲を書き、外挿しなかった

### 回帰の早見

| 量 | 式 |
| --- | --- |
| 傾き b | Σ(x−x̄)(y−ȳ)÷Σ(x−x̄)²＝r×s_y÷s_x |
| 切片 a | ȳ−b x̄ |
| 決定係数 R² | 1−SSE÷SST（＝r²） |
| 残差の標準偏差 | √(SSE÷(n−2)) |

^ 直線は必ず (x̄, ȳ) を通る。残差の合計は0。
