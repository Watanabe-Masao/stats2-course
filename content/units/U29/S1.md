### 0｜入口の問い

::: task
5週間の広告回数と来店者数の散布図には、強い正の相関（r＝0.9）があった（{{unit:U28}}）。では「広告を1回増やすと来店者は何人くらい増える傾向か」「広告を6回にしたら何人来そうか」に答えるには、点の間にどんな直線を引けばよいか。人によって引く直線が違ってしまわない、決まった引き方はあるか。
:::

^ まだ答えなくてよい。残差（点と直線の縦のずれ）の2乗の合計がいちばん小さくなる直線（最小二乗法）を求め、傾き・予測値・残差・決定係数 R² を読み、外挿や残差の形の落とし穴を言えるようになるのが初学のゴール。

### 2｜意味をつかむ：縦のずれの2乗を最小にする　{{power:P3}}

::: ask どんな直線を引く？
→ 直線 ŷ＝a＋bx で予測したとき、実際の y との縦のずれ e＝y−ŷ を**残差**という。残差の2乗の合計（**残差平方和** SSE）がいちばん小さくなるように a と b を決めるのが**最小二乗法**。図では、残差を1辺とする正方形の面積の合計を最小にする。
:::

::: ask 傾き b と切片 a はどう決まる？
→ b＝Σ(x−x̄)(y−ȳ)÷Σ(x−x̄)²（偏差の積の和÷x の偏差平方和）。a＝ȳ−b x̄。直線は必ず平均の点 (x̄, ȳ) を通り、残差の合計は0になる。b は「x が1増えると、y は平均して b 増える傾向」と読む（**回帰係数**）。
:::

::: ask 直線の当てはまりはどう測る？
→ y のばらつき SST＝Σ(y−ȳ)² のうち、残差として残った SSE を引いた割合が**決定係数** R²＝1−SSE÷SST。単回帰では R²＝r²。「予測が当たる割合」ではない。また、観測した x の範囲の外で予測する（**外挿**）と、直線がそこまで続く保証はない。
:::

### 3｜式の構造を読む　{{power:P1}}

$$
b=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2},\qquad a=\bar y-b\bar x,\qquad R^2=1-\frac{SSE}{SST}
$$

| 記号 | 意味（例題の数） |
| --- | --- |
| b（傾き） | 広告1回あたりの来店者数の増え方 |
| a（切片） | x＝0 の予測（範囲外なので参考値） |
| 分子・分母 | 偏差の積の和9・x の偏差平方和10 |
| e＝y−ŷ | 残差：実際の値−直線の予測値 |

**式を言葉で読む**：分子は相関と同じ「x と y が一緒に動く量」、分母は「x の散らばり」。x の散らばり1あたり、y がどれだけ一緒に動くかが傾き。a は直線を (x̄, ȳ) に通すための位置合わせ。

| 平方和 | 中身 |
| --- | --- |
| SST＝Σ(y−ȳ)² | y 全体のばらつき |
| SSR＝SST−SSE | 直線で説明できたばらつき |
| SSE＝Σe² | 残差として残ったばらつき |

```txt
ŷ＝a＋bx、e＝y−ŷ
b＝Σ(x−x̄)(y−ȳ)/Σ(x−x̄)²、a＝ȳ−b x̄
SST＝SSR＋SSE、R²＝1−SSE/SST（単回帰では r²）
残差の標準偏差 s_e＝√(SSE/(n−2))（a と b の2つを推定するので n−2）
```

### 4｜例題：補助を少しずつ減らす　{{power:P1}}

**例題A（全部解説）**　5週間の広告回数 x と来店者数 y（百人）は (1,3)(2,5)(3,4)(4,6)(5,7)。① 回帰直線を求めよ。② 広告5回のときの予測値と残差は？ ③ 決定係数 R² は？

1. x̄＝3、ȳ＝5。偏差の積の和9、x の偏差平方和10 → b＝9÷10＝**0.9**、a＝5−0.9×3＝**2.3** → ŷ＝2.3＋0.9x
2. x＝5：ŷ＝2.3＋4.5＝**6.8**、残差＝7−6.8＝**0.2**
3. 各週の予測 ŷ は 3.2, 4.1, 5.0, 5.9, 6.8。残差：−0.2, 0.9, −1.0, 0.1, 0.2（合計0）→ SSE＝0.04＋0.81＋1＋0.01＋0.04＝**1.9**
4. SST＝10 → R²＝1−1.9÷10＝**0.81**（＝r²＝0.9²）

{{lab:LAB-reg@s1-fit}}

::: warn
R²＝0.81 は「予測が81%当たる」ではなく「y のばらつきの81%を直線で説明できる」。x＝1〜5 の範囲外（たとえば広告20回）の予測は外挿で、信頼できない。
:::

::: key
広告を1回増やすごとに、来店者は平均0.9百人（90人）多い傾向。ただし観察データの傾きで、因果の効果とは限らない。傾きが偶然でないかの検定は {{unit:U30}} で扱う。
:::

### 5｜実験：{{shared:lab_protocol}}　{{icon:lab}}

{{lab:LAB-reg@s1-line}}

1. **予想**：ラボの課題カードで、目分量の直線 ŷ＝4＋0.5x の残差平方和を予想する。
2. **操作**：結果を見たら、傾きと切片を動かして、正方形の面積の合計をできるだけ小さくする。
3. **観察**：どこまで小さくできたか。そのときの傾きと切片は、点線（最小二乗の直線）と比べてどうか。
4. **説明**：「最小二乗の直線は、残差の□の合計を最小にする。だから、どう引いても残差平方和は□より小さくならない」を1文で書く。
5. **ラボなしで**：ŷ＝4＋0.5x で x＝1〜5 の予測（4.5, 5, 5.5, 6, 6.5）を出し、残差を求める。

::: toggle 答え（書いてから開く）
- **観察**：ŷ＝4＋0.5x の残差平方和は4.75。傾きを0.9、切片を2.3 に近づけると1.9 まで下がり、それより小さくはならない。傾きだけ合っていても切片がずれると大きくなる。
- **説明の例**：「最小二乗の直線は、残差の2乗の合計を最小にする。だから、どう引いても残差平方和は1.9 より小さくならない」
- **ラボなしで**：残差は −1.5, 0, −1.5, 0, 0.5。2乗の合計＝2.25＋0＋2.25＋0＋0.25＝**4.75**。
:::
