## 何を知りたいか → どの手法か

問題文から「何について知りたいか」を決め、データの形で手法を選ぶ。くわしい使い方は各単元の応用にある。

**平均について**

| データの形 | 手法（単元） |
| --- | --- |
| 1群・σ が分かる | z 検定・z 区間（{{unit:U22}}・{{unit:U25}}） |
| 1群・σ が分からない | t 検定・t 区間、t(n−1)（{{unit:U22}}・{{unit:U25}}） |
| 同じ対象を2回測る | 差をとって1標本の t（{{unit:U25}}） |
| 独立2群・等分散を仮定しない | ウェルチの t（{{unit:U25}}） |
| 独立2群・等分散 | プールした t、t(n₁＋n₂−2)（{{unit:U25}}） |
| 3群以上 | 一元配置の分散分析、F(a−1, N−a)（{{unit:U32}}） |

**比率について**

| データの形 | 手法（単元） |
| --- | --- |
| 1群 | 比率の z（大標本の正規近似）（{{unit:U22}}・{{unit:U26}}） |
| 独立2群の差 | 2標本の比率の z（{{unit:U23}}・{{unit:U26}}） |

**ばらつき（分散）について**

| データの形 | 手法（単元） |
| --- | --- |
| 1群・正規母集団 | χ² 検定・区間、χ²(n−1)（{{unit:U23}}・{{unit:U26}}） |
| 2群の比 | F 検定、F(n₁−1, n₂−1)（{{unit:U23}}・{{unit:U26}}） |

**度数・カテゴリについて**

| データの形 | 手法（単元） |
| --- | --- |
| 度数が理論どおりか | 適合度検定、χ²(区分の数−1−推定した母数の数)（{{unit:U27}}） |
| 2つのカテゴリの関連 | クロス集計表のカイ二乗検定、χ²((行の数−1)(列の数−1))（{{unit:U27}}） |

**2つの量の関係について**

| データの形 | 手法（単元） |
| --- | --- |
| 関連の強さ | 相関係数 r（{{unit:U28}}） |
| 一方から他方を予測 | 回帰。係数は t(n−k−1)、全体は F（{{unit:U29}}・{{unit:U30}}） |
| ほかの条件をそろえた効果 | 重回帰の偏回帰係数（{{unit:U30}}） |

^ よく使う z の点：両側5%（95%区間）1.96、両側1%（99%区間）2.576、片側5% 1.645、片側1% 2.326。t・χ²・F は自由度で変わるので分布表で引く（{{unit:U20}}）。
