# 関係図の骨格（最小版）

2026-11-06 に渡辺さんが決めた（#228）。**現行の仕様はこの文書だけ**。型（v2）と画面（M3）は、この文書を土台に作る。

設計文書「関係図の骨格：設計案の比較と評価」と #228 の 11-05 の案は、検討の履歴として残している。そこに出てくる「全体ともの」「所有」「穴」「種類の木を中心にした骨格」は取り下げたので、実装では参照しない。

## 何のためのものか

関係図は、概念どうしの関係を見せる地図。答える問いは次の4つ。

1. 何の仲間か：まとまり（はっきりしていれば種類も）
2. 何でできているか：材料
3. いつ成り立つか：成り立つ条件
4. 何とどう違うか、どう移るか：対比・変換などの線

次のものは説明しない。

- 学ぶ順。学習経路として別に作る（M4）。
- 計算の手順。作業台と問題集で扱う。
- 統計の外の解釈。創造の問いで扱う。
- 実験の操作。実験室で扱う。
- その概念に関わることの全部。語のページで扱う。

関係図は辞書を作るためのものではない。

## 1語が持つもの

| 欄 | 答える問い | 必須か |
| --- | --- | --- |
| まとまり | 何の仲間か | 必須（教材が宣言した一覧から1つ） |
| 種類 | 何の一種か | 「A は B の一種」と迷わず言えるときだけ |
| 材料 | 何でできているか | 定義に名前で出る語があるときだけ |
| 対比 | 何とどう違うか | 取り違えやすいときだけ。違いの1文を必ず書く |

- このほかに、名前・定義1文・成り立つ条件（今の `conditions`）を持つ。
- 変換・一般化・導出・応用の線は、今の決まりのまま使う。
- 型（全体とものの区別）・所有・穴・分類ごとの軸は持たない。

## 規則（2つだけ）

1. 関係の相手（種類の親・材料・対比の相手）が教材にないときは、関係を書かない。上の語でも代わりにしない。たとえば二項分布の親「離散分布」は教材にないので、二項分布の種類は空にする。何の仲間かには、まとまりが答える。
2. 材料は、定義1文か式に名前で出る語だけにする。次のものは材料にしない。
   - 言い換え（「棄却する誤り」など）
   - その語が使われる場（帰無仮説の定義にある「検定で」など）
   - 計算の近道の式

   名前で出ることは、材料にするための必要条件で、十分条件ではない。材料にするのは「A は何でできているか」に答える語だけ。B がなければ A を作れないとき、B は A の材料になる。名前で出ていても、次のものは材料にしない。
   - 操作の対象（最小二乗法が係数を決める回帰式、外挿で当てはめる回帰式）
   - 求める結果（単回帰が求める回帰式）

   たとえば残差の定義は「観測した値 − 回帰式で予測した値」なので、回帰式は残差の材料になる。ここを分けないと、前の「前提」で起きた意味の混ざりが、今度は「材料」で起きる。

例外の規則は足さない。どの規則にも合わない語が出てきたら、規則を足す前に、その語が2つの意味を持っていないかを確かめる（#105）。

## 概念を足すとき

関係図のために概念を増やさない。概念の意味を正しく表すのに要るときだけ増やす。

| 語 | 決定 | 理由 |
| --- | --- | --- |
| 分散 | 「確率変数の分散」と「データの分散」に分ける。ID を分け、表示名は文脈で選ぶ | 対象が違う（確率分布／観測したデータ）。今の定義は確率変数の分散だが、REL-dev-var の説明「偏差の2乗の平均」はデータの分散を指していて、食い違っている。標本分散と不偏分散にさらに分けるかは別に決める |
| 回帰式 | 足す | 最小二乗法・回帰係数・残差・決定係数・外挿の5語が、定義の中で回帰式を名前で使っている。これがないと、単回帰のまとまりで「何でできているか」に答えられない。材料になるかは語ごとに規則2で分ける（残差は材料、最小二乗法と外挿は操作の対象）。単回帰・重回帰分析にとっての回帰式は、求める結果で材料ではない |
| 離散分布・連続分布・カイ二乗検定 | 足さない | 階層を整えるためだけの語になる。種類は空にし、何の仲間かにはまとまりが答える |

## 画面が作るもの（データに書かない）

- **たたむ：** 使う語がみな同じまとまりにある材料は、そのまとまりの中にたたむ（期待度数・事前確率など）。これは表示だけの決まりで、データに所有の関係を作らない。同じまとまりにあるからといって、構成の親子になるわけではない。画面には「このまとまりの中で使われる語」として収め、ほかの語と一体のもの、またはその部品に見せない。
- **受け継ぎ：** 種類の親の材料を、子にも出す。
- **木：** 柱 → 分類 → まとまり →（あれば種類）の順で出す。データの形は木でなくてよい。
- **掘り下げ：** 材料の材料を、その場で1段ずつたどる。
- **線の強さ：** 確率のような基礎の語へ多くの線が集まるときは、その線を薄くする。

build が警告するもの：

- 材料の輪
- まとまりのない語

## 関係図の外で担うもの

仮説検定の構成（帰無仮説・検定統計量・有意水準がそれぞれ何の役をするか）は、関係図のデータでは示さない。部品の語はまとまりの中に並ぶので、仲間としては見える。役割は、実験室と作業台が体験の中で説明する。
