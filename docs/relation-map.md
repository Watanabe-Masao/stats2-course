# 関係図の定義書

2026-11-06 に渡辺さんが決めた関係図の骨格（最小版。#228）の定義。**書き方・画面・移し方の現行の仕様はこの文書と、設計書（docs/relation-map-design.md）・計画書（docs/relation-map-plan.md）だけ（意味の判断は製本。下）。** 型（v2）・教材の原本・画面は、この3つを土台に作る。

- この定義書：何を表し、何を書き、何を書かないか（型 v1 での書き方）
- 設計書：それをどの型・データ・画面で持つか
- 計画書：どの順で作り、何を先に決めるか

**2026-11-08 から、関係の意味・成立条件の区分・学ぶ順の判断の正本は製本（docs/rules/ の ③⑤⑥）。** この定義書の 3〜5 は、型 v1 で書くときの書き方として使う。製本と違う所は製本に従い、v1 の種類へは docs/rules/migration.md の対応表で写す（#256）。

設計文書「関係図の骨格：設計案の比較と評価」と、#228 の 11-05 の案は、検討の履歴として残している。そこに出てくる「全体ともの」「所有」「穴」「種類の木を中心にした骨格」は取り下げたので、実装では参照しない。

## 1. 何のためのものか

関係図は、概念どうしの関係を見せる地図。答える問いは次の4つ。

| 問い | 答えるもの |
| --- | --- |
| 何の仲間か | まとまり（はっきりしていれば種類も） |
| 何でできているか | 定義に使う概念（型の名前は材料） |
| いつ成り立つか | 成立条件（要件・仮定・目安。線にしない） |
| 何とどう違うか、どう移るか | 対比・変換・一般化・導出・応用の線 |

次のものは説明しない。

- 前提知識（学ぶ順）。学習経路として別に作る（M4）。
- 計算の手順。作業台と問題集で扱う。
- 統計の外の解釈。創造の問いで扱う。
- 実験の操作。実験室で扱う。
- その概念に関わることの全部。概念のページで扱う。

関係図は辞書を作るためのものではない。

## 2. 概念が持つもの

| 欄 | 中身 | 必須か |
| --- | --- | --- |
| 名前・定義1文 | 今の `name`・`short`（説明ありの概念は `definition` も） | 必須 |
| 分類 | 今の `category`（12種） | 必須 |
| まとまり | 分類の中の、教材が宣言した一覧から1つ | 必須 |
| 成立条件 | 今の `conditions`。行ごとに要件・仮定・目安（5 の後の「成立条件」） | あれば |

概念の型（全体ともの、性質・現象など）・所有・穴・分類ごとの軸は持たない。

### まとまり

- **意味：** 同じ分類の中で、いっしょに見ると分かりやすい概念の組。何の仲間かに答える。
- **書き方：** 分類ごとに教材がまとまりの一覧（名前と1文）を宣言し、概念はそのどれか1つに属する。
- **書かないこと：** まとまりは関係ではない。同じまとまりにいても、一方が他方の一種や部品になるわけではない。
- **目安：** 1つのまとまりに、2〜6個。

## 3. 関係

関係図に出す関係は、次の7つ。矢印は from → to で、読み方の □ に from、■ に to を入れる。

| 関係 | 読み方 | 書く条件 |
| --- | --- | --- |
| 種類 | □ は ■ の一種 | 迷わず言えるときだけ |
| 材料 | □ は ■ の定義に使われる（画面の呼び名は「定義に使う概念」） | 定義の構成要素のときだけ（規則2） |
| 対比 | □ と ■ を比べる | 取り違えやすいときだけ。比べる軸と違いの1文を書く |
| 一般化 | □ を一般化すると ■ | 今の決まりのまま |
| 変換 | □ を変換すると ■ | 今の決まりのまま（厳密・近似・極限を分ける） |
| 導出 | □ から ■ が導ける | 今の決まりのまま |
| 応用 | □ を ■ に使う | 今の決まりのまま |

### 種類

- **意味：** B の定義をすべて満たし、そのうえで B の中の1つとして区別できるのが A。
- **該当する例：** 適合度検定 → カイ二乗検定（カイ二乗検定が教材にあるとき）。標準正規分布 → 正規分布は、固定の仕方（μ＝0・σ＝1）で言えるので、製本 ⑤ では特別な場合（v1 では一般化）。
- **該当しない例：**
  - ベルヌーイ分布 → 二項分布：1回を n 回に広げたもの。一般化で書く。
  - 標本平均 → 平均：平均の計算は、標本平均の材料で表す。
  - 第1種の過誤 → 検出力：同じまとまりにいるだけ。
- **数：** 1つの概念の種類の親は、多くて1つ。
- **相手がない：** 親の概念が教材にないときは書かない（規則1）。

### 材料

- **意味：** A がなければ B を作れない、B の定義の構成要素。「B は何でできているか」に答える。定義の式は、その概念を定める式（確率分布なら確率関数・確率密度関数）で、期待値・分散の式は入れない。
- **該当する例：**
  - 偏差 → データの分散
  - 事前確率 → ベイズの定理
  - 期待度数 → 適合度検定
  - 回帰式 → 残差（残差＝観測した値 − 回帰式で予測した値）
- **該当しない例：**
  - 言い換え：「棄却する誤り」と書いてあっても、棄却域を材料にしない。
  - 使われる場：帰無仮説の定義にある「検定で」。
  - 計算の近道の式：V(X)＝E(X²)−{E(X)}² の材料は、導出の側に書く。
  - 操作の対象：最小二乗法が係数を決める回帰式、外挿で当てはめる回帰式。
  - 求める結果：単回帰が求める回帰式。
  - 成立条件：幾何分布の定義の「独立な試行」の独立は、成立条件（`conditions` の仮定）に書く。
  - 学ぶのに要るだけの知識：確率変数 → ベルヌーイ分布（定義に確率変数の名前が出ない）は、前提知識（4）で書く。
- **数：** 直接の材料だけを書く。材料の材料は、画面がたどって出す。
- **呼び名と向き（#249 ④。2026-11-07）：** 画面では「定義に使う概念」と呼ぶ。線の向きは「使われる概念 → それを使う概念」で、B → A は「B は A の定義に使われる」と読む。A のページの見出しは「定義に使う概念」、B のページは「これを定義に使う概念」。型の種類の名前（材料）は v2（S7）まで変えない。
- **基準にする定義（#249 ③。2026-11-08）：** 概念ごとに、基準にする定義を1つ決める。確率分布は確率関数・確率密度の式（`basis_formula`）を基準にし、定義1文（「独立な試行の成功回数」などの生まれ方）は学習者向けの導入として残す。材料はこの基準の定義の直接の構成要素だけ。定義の依存の輪は build が止める。

### 対比

- **意味：** 似ていて取り違えやすい2つを、違いが分かるように並べる。向きは問わない。
- **書くもの：**
  - 比べる軸：何について違うのか（例：「帰無仮説が正しいか × 検定の判断」）
  - 違いの1文
- **該当しない例：**
  - 一方が他方の一種：種類で書く。
  - 同じまとまりにいるだけ：第1種の過誤と検出力など。

## 4. 前提知識（関係図に出さない）

学ぶのに要る知識（確率変数 → ベルヌーイ分布、二項分布 → 連続修正など）は、関係図の線にしない。学習経路（M4）のために、教材の原本に今の「前提（learning）」として残す。

前提知識も直接の1段だけを書く（#249 ③）。A → B → C → D なら、D は C だけを持ち、A・B は C をたどって出す。たどれば着く前提知識を重ねて書くと build が止める。

### 成立条件（線にしない。#249 ①）

成立条件は線にせず、概念・関係に添える。行ごとに区分を持ち、外れたときに何が言えなくなるかを書く。区分の意味と掛かる先の判断の正本は製本 ③。下の表は書くときの要約。文に出る概念は、画面が文の下に押せる札で並べる。

| 区分 | 意味 | 外れたとき |
| --- | --- | --- |
| 要件 | 採用している定義の条件（母数の範囲など） | この定義のものとして扱えない |
| 仮定 | その定理・モデルによる保証の条件（独立な試行の成功回数が二項分布に従う など） | 保証が使えない。結論が偽とは限らない |
| 目安 | 近似を勧める数の基準（出典と対象の近似を持つ） | この目安では勧められない。精度を別に確かめる |

- 定義そのものと手順（連続修正）は成立条件に書かない。
- 現実のデータで確かめる手掛かり（`conditions.data` の区分のない行）は、成立条件とは別に「データで確かめる手掛かり」として出す。
- 定理の主張に出る概念（中心極限定理の主張の標本平均など）は「主張に使う概念」として、前提知識とは別に記録する（#249 ②）。確率分布の分類にはないので、型には主張の分類を移すとき（S6）に足す。

## 5. 規則（2つだけ）

1. **関係の相手（種類の親・材料・対比の相手）が教材にないときは、関係を書かない。** 上の概念でも代わりにしない。
   - たとえば二項分布の親「離散分布」は教材にない。だから二項分布の種類は空にし、何の仲間かにはまとまりが答える。
2. **材料は、定義1文か式に名前で出る概念のうち、「何でできているか」に答えるものだけにする。**
   - 名前で出ることは、材料にするための必要条件で、十分条件ではない。
   - ここを分けないと、前の「前提」で起きた意味の混ざりが、今度は「材料」で起きる。
   - 順序は、正しく分かりやすい定義1文を先に決め、そこから材料を判定する。関係を残すために定義へ名前を足さない（渡辺さん 2026-11-07）。

例外の規則は足さない。どの規則にも合わない概念が出てきたら、規則を足す前に、その概念が2つの意味を持っていないかを確かめる（#105）。

## 6. 概念を足すとき・分けるとき

関係図のために概念を増やさない。概念の意味を正しく表すのに要るときだけ増やす。

| 概念 | 決定 | 理由 |
| --- | --- | --- |
| 分散 | 「確率変数の分散」と「データの分散」に分ける | 対象が違う（確率分布／観測したデータ）。今の定義は確率変数の分散だが、REL-dev-var の説明「偏差の2乗の平均」はデータの分散を指していて、食い違っている。標本分散と不偏分散にさらに分けるかは別に決める |
| 回帰式 | 足す | 最小二乗法・回帰係数・残差・決定係数・外挿の5個が、定義の中で回帰式を名前で使っている。材料になるかは概念ごとに規則2で分ける |
| 離散分布・連続分布・カイ二乗検定 | 足さない | 階層を整えるためだけの概念になる |

## 7. 画面が作るもの（データに書かない）

- **木：** 柱 → 分類 → まとまり →（あれば種類）の順で出す。データの形は木でなくてよい。
- **共通の印：** まとまりの全部の概念に共通する材料・成立条件の概念は、まとまりの見出しに1つだけ印で出し、概念からは外す。表示の要約で、まとまりの材料・条件としてデータに書かない（まとまりは概念ではない）。
- **たたむ：** 使う概念がみな同じまとまりにある材料は、そのまとまりの中にたたむ（期待度数・事前確率など）。
  - これは表示だけの決まりで、データに所有の関係を作らない。
  - 画面には「このまとまりの中で使われる概念」として収める。ほかの概念と一体のものや、その部品には見せない。
- **受け継ぎ：** 種類の親の材料を、子にも出す。
- **掘り下げ：** 材料の材料を、その場で1段ずつたどる。
- **線の強さ：** 確率のような基礎の概念へ多くの線が集まるときは、その線を薄くする。

## 8. 関係図の外で担うもの

仮説検定の構成（帰無仮説・検定統計量・有意水準がそれぞれ何の役をするか）は、関係図のデータでは示さない。部品の概念はまとまりの中に並ぶので、仲間としては見える。役割は、実験室と作業台が体験の中で説明する。
