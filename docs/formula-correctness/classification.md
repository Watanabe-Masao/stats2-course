# 式の種類と性質の分類（#118）

式 ID は仮の呼び方 `<概念ID>#<番号>`（README の 2.1）。分類は案で、式の原本にはまだ書かない（置き場所はフェーズ0で決める。README の D6）。

## 1. 式の種類（1つの式に複数可）

| 種類 | 何か | 確かめ方の中心 |
| --- | --- | --- |
| 定義 | 記号・量の意味を決める（E(X)＝Σ x p(x)、σ＝√V(X)） | 正しさは数では決まらない。**レビュー**（定義が教科書と同じか）と、他の式との整合（性質のテスト） |
| 恒等式 | 前提のもとで両辺がいつも等しい（V(aX+b)＝a²V(X)） | 定義域の中の範囲で両辺を照らす（性質のテスト）＋独立な見本。導き方はレビュー |
| 変換 | 量を別の尺度・形に移す（Z＝(X−μ)/σ） | 変換の前後で保たれるもの・変わるもの（不変・線形） |
| 確率モデル | 起き方の仮定から分布を決める（二項分布の P(X＝k)） | 非負・正規化・平均と分散が恒等式と一致。モデルの仮定（独立・同じ p）は**レビュー**と反例の実験（層2） |
| 推定 | データから母数を見積もる（回帰係数・不偏分散） | 見本のデータで値（オラクル）、不偏性・一致性は乱数の実験（層2）。教材の式には今ない |
| 近似 | 条件のもとで近い（二項→正規） | 近さの尺度と条件（n・p）の範囲で差を測る。どこから「近い」かは**レビュー**。教材では関係（REL-binom-normal）にある |
| 判定 | 条件が成り立つかを決める（独立の定義 P(A∩B)＝P(A)P(B)、検定） | 成り立つ例と成り立たない例の両方。境目の扱いはレビュー |

近似・極限は今の教材では式ではなく関係の変換（mode: approximation・limit）にある。契約の対象は式 ID だけでなく関係 ID（REL-…）も取れるようにする。

## 2. 性質と、性質ごとの確かめ方

層は #118 の5層（1 計算・2 実験・3 原本の数・4 概念と条件・5 画面）。「方法」は 性質＝性質のテスト（乱数の入力で範囲を）、見本＝独立な見本と照らす、レビュー＝個別の数学のレビュー。

| 性質 | 当てはまる式（例） | 要る前提 | 方法と層 | 限界（数のテストで保証できないこと） |
| --- | --- | --- | --- | --- |
| 非負 | 確率・密度・分散・σ・nCk | 定義域の中 | 性質（層1）。端の値を必ず混ぜる | 浮動小数の −1e−17 のような丸めと本当の負を分ける幅が要る。定義域の外では言えない |
| 正規化 | 確率の和・密度の積分＝1、E(Z)＝0・V(Z)＝1 | 定義域の中、無限の和は打ち切りの幅 | 性質＋見本（層1） | 無限の和・積分は打ち切るので「1に近い」まで。打ち切りの誤差の評価はレビュー |
| 線形 | E(aX+b)＝aE(X)+b、Z は X の1次 | 期待値が有限 | 性質（層1）。見本は表の値を置き換えた別の表で（式を使わない） | 「どの分布でも」は有限の表でしか試せない。無限の台・裾の重い分布はレビュー |
| 対称 | nCk＝nCn−k、二項の p↔1−p、Cov(X,Y)＝Cov(Y,X) | — | 性質（層1） | 対称でない誤り（片側だけの符号の誤り）は対称な入力では見えない。入力を対称な組にしない |
| 不変 | V(X+b)＝V(X)、Z は正の a の尺度で変わらない、指数分布の無記憶性 | a＞0 など | 性質（層1） | 不変の「群」（何に対して不変か）を書かないと、確かめた変換以外は保証しない |
| 単調 | 幾何の E＝1/p は p で減る、P(a≦X≦b) は b で増える | 定義域の中 | 性質（層1） | 隣どうしの比べでは細かい振れを見落とす。単調の主張そのものはレビュー |
| 有界 | 0≦確率≦1、二項の V≦n/4、0≦R²≦1 | — | 性質（層1・層5 の画面の数） | 境界にちょうど届く入力（p＝0・1）を混ぜないと端の誤りが通る |
| 同値 | ＝が続く式の各辺、開いた式と元の式、式と定義の和 | 両辺の定義域の共通部分 | 性質＋見本（層1）。開いた式は #109 の open | ランダムな同値は「どこでも等しい」の証明ではない（#109）。記号の意味の取り違え（μ の所属）は値が同じでも起きる → スコープ・of の検査とレビュー |
| 再現 | 回帰直線が (x̄, ȳ) を通る、同じ種なら同じ乱数 | — | 性質（層1・層2） | 種の方式を変えると崩れる（math-lab の決まり 2） |
| 収束 | 二項→ポアソン・正規、大数の法則 | 条件（np 一定・n→∞） | 実験（層2：標準誤差の5倍）＋見本（差の大きさ） | 有限の n でしか試せない。「近い」の基準と収束の速さはレビュー |
| 単位の整合 | 分散は元の単位の2乗、σ・E は元の単位、Z は単位なし、λ は 1/時間 | 記号に単位の情報 | **今は確かめられない**（記号に単位の項目がない）。レビュー | 数のテストでは見えない（どの単位でも数は計算できる） |
| 条件しだい | 前提が崩れると成り立たない（σ＝0、独立でない、p が回ごとに違う） | 崩す条件が概念の conditions.math にある | 前提の崩れの入力で止まるか（層1）、反例の実験（層2・層3 effect）、条件と反例の対応（層4） | 文の条件（conditions.math）は機械が読めない。条件を全部挙げたかはレビュー |

### 2.1 性質ごとのテストの選択規則（最小十分）

README の 0 の原則で、契約に書いた性質から次のように選ぶ。件数を増やすためにテストを足さない。

1. **共通テスト（C1〜C6、test-plan.md）は全部の式にかける**。式ごとには足さない。
2. **性質のテストは「その式で起きやすく重い故障」があるものだけ**選ぶ。目安：
   - 確率モデル → 非負・正規化・（平均・分散の恒等式があれば）同値。この3つは1つのテスト（和を取る1回の走査）でまとめて確かめる（今の correctness.test.ts の形）。
   - 恒等式・変換 → 同値（両辺）。線形・不変は同値の入力に a・b の範囲を含めれば同じテストで見つかるので別に足さない。
   - 定義 → 数のテストは他の式との同値（定義の和と恒等式の右辺）だけ。定義そのものはレビュー。
   - 対称・単調・有界 → 契約で「主張」として本文に出している式（例：二項の V≦n/4 を本文で言う）に限る。言っていない性質はテストしない。
   - 単位の整合・近似の基準・モデルの仮定 → テストではなくレビュー。
3. **同じ故障を見つける既存のテストがあれば足さない**（既存の名前を契約に書いて参照する）。
4. **独立な見本は代表の式と、性質のテストで期待値が同じ写しから作られる式（両辺とも同じ fixtures の木から計算するもの）に限る**。
5. **入力の範囲**：端（p＝0・1、n＝1、k＝0・n、σ が小さい）を必ず混ぜる。範囲は記号の domain から作る（domain の外は「前提の崩れ」の別のテスト）。
