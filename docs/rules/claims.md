## 1. 主張の書き方
- 主張は、真か偽かが決まる1文で書く。概念が命題でない（分布・統計量・性質・手続き）ときは、当てはめて命題にする（「X と Y が独立なら Cov(X, Y)＝0」）。
- 1文は、記号で書けて数学的に示せるものに限る。経験的な効果（無作為化すると交絡が減る、の言い方）は、示せる形（割り付けと共変量が独立になる）に絞る。
- 何についての主張か（主語）を1文の中で名指しする。関係（⑤）の端が主張の主語と食い違わないこと。

## 2. 主張の種類
| 種類 | 何を言うか | 例 |
| --- | --- | --- |
| 等しい | 2つの量・分布が（条件のもとで）等しい | 単回帰で R²＝r²、F＝t²（等分散の独立2標本の両側） |
| 従う | 確率変数の分布が何か | (n−1)s²/σ² が χ²(n−1) に従う（正規母集団） |
| 極限 | 何が（分布か値か）、どう進めると、何に近づくか | 標準化した二項分布の分布は、n→∞ で標準正規分布に近づく |
| ならば・同値 | 条件つきの含意・同値 | 独立なら無相関。p 値≦α ⇔ 統計量が棄却域に入る |
| 手続きの保証 | 手続きが約束する性質 | 第1種の過誤の確率が α、信頼係数が 1−α |
| 推定量の性質 | 推定量と行き先の組についての性質 | E(s²)＝σ²（不偏）、標本平均は母平均に確率収束する（一致） |
| 重なり | 2つの族の一部が一致する | 自由度2のカイ二乗分布＝平均2の指数分布 |

## 3. 定理の構造
- 定理は、前提・結論・仮定に分けて書く。仮定は ③ の書き方（区分・掛かる先・主語）に従う。
- 名前のある定理（中心極限定理・大数の法則・ベイズの定理）と、前提の命題が2つ以上いる主張は、定理として1つの単位で持つ（関係図での表し方は ⑤）。
- 定理の結論が2つの概念の関係そのもの（標本平均の分布が近づく）のときは、その主張を1つだけ持ち、⑤ はそれを参照する。

## 4. 逆と反例
- 逆の主張は、元の主張とは別の主張として書く。逆が成り立つ条件は ③（何についての条件か）。
- 逆が成り立たないことは反例で示す。反例は、何の主張の、どの部分が成り立たないかを書く（X が 0 を中心に対称で Y＝X² なら無相関だが独立でない）。

## 5. 導出
- 導出は段に分け、各段で使う前提・定義・条件を書く。
- 前提が2つ以上の導出（期待値・分散・独立 → E＝np・V＝np(1−p)）は、1つの導出として持つ。
