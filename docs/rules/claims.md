## 1. 主張の書き方
- 主張は、真か偽かが決まる1文で書く。概念が命題でない（分布・統計量・性質・手続き）ときは、当てはめて命題にする（「X と Y が独立なら Cov(X, Y)＝0」）。
- 1文は、記号で書けて数学的に示せるものに限る。経験的な効果（無作為化すると交絡が減る、の言い方）は、示せる形（完全無作為化では、各個体が処置群に入る確率がどれも等しい（n₁/(n₁＋n₀)。Z の値によらない））に絞る。
- 何についての主張か（主語）を1文の中で名指しする。関係（⑤）の端が主張の主語と食い違わないこと。

## 2. 主張の種類
| 種類 | 何を言うか | 例 |
| --- | --- | --- |
| 等しい | 2つの量・分布が（条件のもとで）等しい | 切片を含む単回帰で R²＝r²、2群の一元配置分散分析の F＝プールした t の2乗（データの値についての恒等式） |
| 従う | 確率変数の分布が何か | (n−1)s²/σ² が χ²(n−1) に従う（正規母集団） |
| 極限 | 何が（分布か値か）、どう進めると、何に近づくか | 標準化した二項分布の分布は、n→∞ で標準正規分布に近づく |
| ならば・同値 | 条件つきの含意・同値 | 独立なら無相関。p 値≦α ⇔ 統計量が棄却域に入る |
| 手続きの保証 | 手続きが約束する性質 | 第1種の過誤の確率が α 以下（連続分布の単純仮説では α）、信頼係数が 1−α 以上（連続で正確なら 1−α） |
| 推定量の性質 | 推定量と行き先の組についての性質 | E(s²)＝σ²（不偏）、標本平均は母平均に確率収束する（一致） |
| 重なり | 2つの族の一部が一致する | 自由度2のカイ二乗分布＝平均2の指数分布 |

## 3. 定理の構造
- 定理は、前提・結論・仮定に分けて書く。仮定は ③ の書き方（区分・掛かる先・主語）に従う。
- 名前のある定理（中心極限定理・大数の法則・ベイズの定理）と、前提の命題が2つ以上いる主張は、定理として1つの単位で持つ（関係図での表し方は ⑤）。
- 定理の結論が2つの概念の関係そのもの（標本平均の分布が近づく）のときは、その主張を1つだけ持ち、⑤ はそれを参照する。

## 4. 逆と反例
- 逆の主張は、元の主張とは別の主張として書く。逆が成り立つ条件は ③（何についての条件か）。
- 逆が成り立たないことは反例で示す。反例は、何の主張の、どの部分が成り立たないかを書く（X が N(0, 1) に従い Y＝X² なら無相関だが独立でない。6 の 13の反例）。

## 5. 導出
- 導出は段に分け、各段で使う前提・定義・条件を書く。
- 前提が2つ以上の導出（期待値・分散・独立 → E＝np・V＝np(1−p)）は、1つの導出として持つ。

## 7. 主張の単位（決定 2026-11-08）

主張は、概念と別の単位として持つ（渡辺さん）。

| 保証すること | 保証しないこと |
| --- | --- |
| 主張ごとに、条件・根拠・検証の状況・教材での扱いを追える | 単位として登録すれば、その主張が正しいこと |

1つの主張に、最低限次を持たせる。

| 項目 | 中身 |
| --- | --- |
| 本文 | 主張の1文（主語・条件・結論）と、対象・変数の範囲 |
| 成立条件 | ③ の書き方（区分・掛かる先・主語・外れたとき） |
| 根拠 | 根拠となる主張（名指し）・文献・導出 |
| 検証の状況 | 確認済み／未確認、どう確かめたか（独立な確かめ・数の確かめ・出典との照合）と日付 |
| 教材での扱い | 教材の中で説明する範囲（結論を扱うか、証明を扱うか）と、外部の結果に頼る部分 |

- 「結論は2級の教材で扱うが、証明は範囲外」を、教材での扱いとして表せるようにする。
- 外部の結果への依存は、根拠をたどって受け継ぐ。教材での扱いは受け継がない（主張ごとに決める）。
- 項目の名前と、データでの持ち方は設計書で決める。
- 主張の識別子は ④-番号（④-25、④-28b）。原本のデータの id は同じ番号の CLM-番号（README の運用の決まり 5。#277）。番号は変えない・消さない・使い回さない。今の主張ごとの検証の状況は §9。

## 8. 根拠の記録：Wald の区間の目安

文献の根拠と、数の確かめは、別々の根拠として残す。

### 文献（2026-11-08 に根拠として採ると決めた。本文は照合していない）

Brown, L. D., Cai, T. T., DasGupta, A. (2001). Interval Estimation for a Binomial Proportion. *Statistical Science*, 16(2), 101–133.

- 何の根拠か（記憶による要約。本文で確かめるまで確定に数えない）：Wald の区間の被覆確率が、n と p によって不安定に揺れること。従来の目安（np≧5 など）で被覆確率が保たれるとは言えないこと。
- 保証すること（本文の照合が済むまで未確認）：Wald の区間の限界を説明する、文献上の根拠を示せる。
- 保証しないこと：「np≧5」などの目安で、一定の被覆確率が保証されること。

### 数の確かめ（2026-11-08 の計算）

- 区間の式：p̂ ± z·√(p̂(1−p̂)/n)、p̂＝X/n、z＝1.959964（標準正規分布の上側 2.5％ 点）。名目の信頼係数は 95％。
