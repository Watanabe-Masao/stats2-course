# ③ 成立条件（成立条件の製本）

概念・主張・変換・手続きが、どんな条件のもとで使え、外れると何が言えなくなるか、の決まり。①の上に立ち、⑤から使う（条件は関係の線にしない）。

## 0. この本の器

| 項目 | 中身 |
| --- | --- |
| 答える問い | 概念・主張・変換・手続きは、どんな条件のもとで使え、外れると何が言えなくなるか |
| 決めること | 下の節（1 から） |
| 保証すること | どの条件のもとで何を主張しており、外れると何が保証されなくなるかが分かる |
| 確かめ方 | 条件の行ごとに、区分・掛かる先・主語・外れたときがある（3）。逆が成り立つ条件は 4 の4つを持つ |
| 例・反例・未決 | 4 の例（独立と無相関）、check-pairs.md |

保証しないことと、その引き受け先：

| 保証しないこと | 引き受け先 |
| --- | --- |
| 現実のデータが条件を満たしていること | ⑧ |
| 条件を満たせば主張が正しいこと自体 | ④ |
| 条件の札の並べ方・画面 | 設計書 |

## 1. 条件の3つの区分

| 区分 | 意味 |
| --- | --- |
| 要件 | 定義の条件。満たさないと、その定義のものにならない |
| 仮定 | 保証の条件。満たすと、主張・変換・手続きの保証が使える |
| 適用の目安 | 近似・極限を有限のまま使ってよいかの数の基準。出典と、何の近似かを持つ |

- 要件は「それが何か」に、仮定は「それについて何が言えるか」に掛かる。目安は数学の条件ではなく、使うときの判断の基準。
- 仮定が外れても、結論が偽とは限らない（独立でなくても、成功回数がたまたま二項分布になることはある）。

## 2. 条件が掛かる先

1つの条件は、掛かる先を1つ持つ。掛かる先が違えば、同じ文の条件でも別の条件として書く（独立は、二項分布のモデルの主張にも、中心極限定理にも仮定として出る）。

| 掛かる先 | 何か | 書ける区分 |
| --- | --- | --- |
| 概念の定義 | 概念の基準の定義（①） | 要件 |
| 主張 | 命題・定理・導ける・同値の1文、従う・推定するの1文 | 仮定（主張の中の対象の要件は、その概念の側に書く） |
| 変換 | 移る（厳密・極限・近似） | 仮定、適用の目安 |
| 手続き | 検定・推定・データの取り方の手順 | 要件、仮定、適用の目安 |

### 外れたときの意味（掛かる先ごと）

| 掛かる先 | 要件が外れたとき | 仮定が外れたとき | 適用の目安を外れたとき |
| --- | --- | --- | --- |
| 概念の定義 | この定義のものとして扱えない（母数が範囲の外なら、この定義の二項分布ではない） | — | — |
| 主張 | — | その主張は保証されない（偽とは限らない） | — |
| 変換 | — | 移る・近づくとは保証されない | この目安では使うことを勧められない。精度を別に確かめる |
| 手続き | この手続きとして定まらない（ほかの手続きを選ぶ。対応のないデータに対応のある t 検定は使えない） | 手続きが約束する性質（第1種の過誤の確率が α、信頼係数が 1−α）が保証されない | この目安では勧められない。正確な方法か、精度を別に確かめる |

### 分布の概念に書く「仮定」の掛かる先

二項分布の「各回が独立・p が同じ・回数が決まっている・2値」は、二項分布の定義（確率関数）の条件ではない。「成功回数 X は B(n, p) に従う」というモデルの主張の仮定である。分布の概念のページに出すときも、掛かる先はこの主張とし、1文を添える（2026-11-08 の決定：分布は式を基準の定義にする、と同じ考え）。

## 3. 書くもの

条件の1行ごとに次を書く。

| 項目 | 中身 |
| --- | --- |
| 文 | 条件そのもの（「各回が独立」「np≧5 かつ n(1−p)≧5」） |
| 区分 | 要件・仮定・適用の目安 |
| 掛かる先 | 概念の定義／どの主張（1文）／どの変換／どの手続き |
| 何についての条件か | 条件の主語（各回の試行、(X, Y) の同時分布、母集団、標本の大きさ） |
| 外れたとき | 2 の表の意味を、その場合の言葉で |
| 範囲 | すべての値で要るか（不偏性は「すべての母数の値で」）、ある値で足りるか |
| 目安だけ | 何の近似か、数の基準、出典、どこまでの精度か。文献の根拠と数の確かめは別々に添える（例：Wald の区間の目安 np≧5 は、文献 Brown・Cai・DasGupta 2001 と、④ の 8 の計算。目安は被覆確率を保証しない） |

- 文に出る概念（独立・分散 など）は、関係の線にしない（画面での並べ方は設計書）。
- 現実のデータで仮定を確かめる手掛かり（時間帯で割合が変わらないか、など）は条件ではない。判断は ⑧ が持ち、確かめる仮定の行に添える。
- 定義そのもの（「確率密度が f(x) の式で表される」）と手順（連続修正で境目を 0.5 ずらす）は、条件に書かない。
- 条件付き確率の「｜」は概念を作る記号で、成立条件ではない。

## 4. 逆が成り立つ条件

③ が持つのは、逆が成り立つ条件とその主語。元の主張・逆の主張・反例そのものは ④ が持つ（ここでは読めるように並べて書く）。

「P ならば Q」が成り立ち、逆「Q ならば P」が条件つきで成り立つときは、関係を2つにせず、元の主張に「逆が成り立つ条件」を添える。次の4つを必ず書き、何についての条件か・どの主張の逆かを読めるようにする。

| 書くもの | 例 |
| --- | --- |
| 元の主張 | X と Y が独立なら、Cov(X, Y)＝0（X・Y の分散が有限のとき） |
| 逆の主張 | Cov(X, Y)＝0 なら、X と Y は独立 |
| 逆が成り立つ条件と、その主語 | (X, Y) の同時分布が2変量正規分布のとき（仮定。X・Y がそれぞれ正規分布に従うだけでは足りない） |
| 逆が成り立たない例 | X が N(0, 1) に従い Y＝X² のとき、Cov(X, Y)＝0 だが独立ではない（「0 を中心に対称」だけでは足りない。X が ±1 の2点なら Y は定数で、X と独立になる） |

逆が条件なしに成り立つなら、それは同値（⑤）。
