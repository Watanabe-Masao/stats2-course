# ② 式と記号

## 0. この本の器

- **答える問い**：その式は何を表し、各記号は何を指すか。
- **決めること**：下の節（1 から）
- 保証すること：式が何を表し、各記号が何を指すかを、あいまいさなく読める。
- 確かめ方：
  - 各記号に、指すものと範囲がある。
  - 式の種類（定義式・等式・近似式・極限・分布の式）が分かる。
  - 式の木の検査（CLAUDE.md の式の決まり：記号の範囲・確率変数の対応・変数のスコープ）が通る。

保証しないことと、その引き受け先：

| 保証しないこと | 引き受け先 |
| --- | --- |
| 等式・近似が成り立つこと、導出の正しさ | ④（条件は ③） |
| 画面での読みやすさ | 設計書と、実物の確かめ |

## 例・反例・未決

- 例：check-pairs.md の 2・5・6・9・10・12・16（8組が ② に頼る）。
- 未決（案を添える）：
  1. 記号の範囲を、式ごとに持つか、概念ごとに持つか。案：式ごと（今の形）。同じ記号でも式によって範囲が違う（二項分布の n と標本の大きさ n）。
  2. 近似式を、極限の主張（④）の中に持つか、式として別に持つか。案：④ の主張の中に「使う形」として持ち、式としては持たない。近似式だけが単独で出ると、近似であることと目安が落ちる。

## 1. 式の種類
| 種類 | 何か | 例 |
| --- | --- | --- |
| 定義式 | 左の名前を右で定める | V(X)＝E((X−μ)²) |
| 等式（性質） | 定義から導ける等しさ | V(X)＝E(X²)−{E(X)}² |
| 近似式（使う形） | 極限の定理などを有限のまま使う形 | 二項分布を N(np, np(1−p)) で近似する |
| 極限 | 何かが近づく先 | 自由度→∞ で t 分布 → N(0, 1) |
| 分布の式 | 確率変数がどの分布に従うかの式 | X ～ B(n, p) |

- 定義式とそれ以外を混ぜない。概念の基準の定義（①）は定義式で書く。
- 近似式は、それが近似であることと、元にした極限・目安（③）を一緒に読めるようにする。

## 2. 記号
- 記号ごとに、何を指すか（概念・確率変数・母数・定数）と、範囲（とる値）を持つ。
- 同じ記号が式によって違うものを指すときは、式ごとに書く（p は二項分布の成功確率、p 値の p とは別）。
- 条件付き確率の「｜」、分布に従うの「～」は、概念・関係を作る記号で、成立条件ではない（③）。

## 3. 式の言い換え（関係の端と式）
- 確率変数を、決まった式に言い換えて主張するとき（(n−1)s²/σ² が χ²(n−1) に従う）、その式が元の確率変数の分布を1つに決めるのは、次の3つを全部満たすときだけ。
  - 式が元の確率変数の1対1の変換である（2乗などは入らない）
  - 式にほかの確率変数が入らない
  - 係数・ずらしは、定数か母数だけ
- 満たさない式（t＝(X̄−μ)/(s/√n)：2つの確率変数を使う）は、その式を定める別の概念（t 統計量）の式として読む。
- この判断を、⑤ の「従う」の端（何が従うか）が使う。

## 4. 記号の書き方の約束

| もの | 書き方 | 例 |
| --- | --- | --- |
| 確率変数 | 大文字 | X、X̄、T |
| 確率変数のとった値（観測値） | 小文字 | x、x̄、t |
| 母数（母集団の分からない数） | ギリシャ文字 | μ、σ²、p（二項分布の p は慣用でラテン文字） |
| 推定量 | 母数の記号にハット、または慣用の記号 | p̂、s² |
| 分布 | 名前と母数 | B(n, p)、N(μ, σ²)、t(ν)、χ²(ν) |

- 確率変数とその値を同じ記号で書かない（P(X＝x) の X と x）。
- 母数と推定量を同じ記号で書かない（μ と x̄、σ² と s²）。教材の中で慣用が混ざるとき（不偏分散と標本分散の s² の流儀）は、式ごとにどちらかを書く。
- 定義式は「定める」と読めるようにする（式の種類を書く）。等号だけでは、定義か性質か分からない。

## 5. 式と概念の対応

- 1つの式の元は、1つの概念に持つ。ほかの概念に同じ式を出すときは、元を参照する（今の CLAUDE.md の ref の決まり）。
- 式の記号は、指す概念を持つ（X̄ は標本平均、s² は不偏分散）。指す概念がない記号は、その式の中だけの記号として範囲を書く。
