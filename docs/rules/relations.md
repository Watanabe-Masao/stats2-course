# 関係のルール（関係図の製本）

概念どうしの関係を、何を関係とし、どの種類に分け、どう書くかの決まり。2026-11-08 に渡辺さんと決めた方向（数学の記号の意味から決め直す。今の実装に引っ張られない）で作った。今の型・原本・画面との対応と移し方は、この製本の外（計画書）で扱う。

## 1. 何を扱うか

- 扱う：**概念どうしの数学的・統計的な関係**。2つの概念について「何で定まるか・何の一部か・どう移るか・何に従うか・何を推定するか・何が言えるか・何の根拠か・どこが違うか」に答える。
- 扱わない：
  - 学ぶ順（何を先に知っておくとよいか）→ 学ぶ順のルール（docs/rules/learning-order.md）
  - 概念が成り立つための条件（要件・仮定・目安）→ 概念・関係に添える（6）
  - 計算の手順、統計の外の解釈、実験の操作

出発点は数学的な意味・統計的な意味。そこから外れる関係を足すときは、なぜ要るのかを先に議論する（渡辺さん 2026-11-07）。

## 2. 関係にするもの（3つのふるい）

2つの概念の間の何かを関係として書くのは、次の3つを全部満たすときだけ。

1. **両端が概念**である（具体的な値・観測・例ではない）。
2. **いつでも成り立つ**（ある場面・ある問題だけで成り立つのではない）。成り立つための条件があるなら、それを条件として添えられる。
3. **どちらの概念の定義を読んでも分からない情報を足す**（推移で出るもの・言い換えは足さない）。

## 3. 関係にしないもの

| もの | 例 | 扱い |
| --- | --- | --- |
| 同じ意味（どの文脈でも置き換えられる） | — | 1つの概念にまとめ、別の名前は別名にする |
| 同値な別の定義 | 独立の積の形と条件付きの形 | 1つの概念の「別の定義」（同値の条件と導き方を添える） |
| 値がある条件で一致するだけ（意味は別） | 単回帰の決定係数 ＝ 相関係数の2乗 | 関係にする（移る・厳密）。まとめない |
| 1つの概念の中の式・性質 | 比例（σ/√n）・大小（不等式）・集合の演算（∩・∪）・論理の結合（∧・∨） | 概念の中身（定義・性質） |
| 成り立つための条件 | 独立（⊥）・条件付き（｜）・範囲（∀・∃） | 条件として添える（6） |
| 学ぶ順 | 確率変数を知ってからベルヌーイ分布 | 学ぶ順のルール |
| 当てはめの判断 | データを正規分布とみなす | 概念の「データで確かめる手掛かり」 |

## 4. 関係の種類

5つの族、9つの種類。矢印は from → to。

| 族 | 種類 | 意味（from → to） |
| --- | --- | --- |
| 構成 | 定める | from は to の基準の定義の直接の構成要素 |
| 包含 | 一種 | from は to の定義をすべて満たし、性質・目的で区別したもの |
| 包含 | 特別な場合 | to の母数に値を入れる・2つの変数を同じにする・個数を減らす、のどれかだけで from になる |
| 対応 | 移る | from（対象）に操作・極限をとると to（対象）になる。厳密・近似・極限を分ける |
| 確率 | 従う | 統計量 from の分布は、仮定のもとで to |
| 確率 | 推定する | 統計量 from は母数 to を推定する |
| 帰結 | 導ける | 命題 from から命題 to が導ける（一方向） |
| 帰結 | 同値 | 命題 from と to は互いに導ける |
| 帰結 | 根拠 | 定理 from が、手続き to（推定・検定の方法）の根拠になる |
| 比べる | 比べる | 似ていて取り違えやすい2つを、比べる軸で並べる |

### 族ごとの決まり

**構成（定める）**
- 概念ごとに基準にする定義を1つ決め、その直接の構成要素だけを書く。構成要素の構成要素は書かない（たどって出す）。
- 確率分布の基準の定義は確率関数・確率密度の式。標本分布の族（カイ二乗分布・t 分布・F 分布）は、既知の分布に従う確率変数の関数として定めてもよい。
- 定義の依存は輪にならない。
- 名前が定義に出ることは必要条件で、十分条件ではない（言い換え・使われる場・計算の近道・求める結果・成り立つ条件は構成要素ではない）。

**包含（一種・特別な場合）**
- 一種：性質・目的で区別する（推定量は統計量の一種、適合度検定は仮説検定の一種）。親は多くて1つ。
- 特別な場合：値で区別する（ベルヌーイ分布＝二項分布の n＝1、標準正規分布＝正規分布の μ＝0・σ＝1）。どの値に決めたか（`fix`）を必ず書く。`fix` に書けるのは、母数の値・2つの変数を同じにする・個数を減らす、の3つだけ。
- 極限でしか届かないもの（t 分布の自由度→∞）は特別な場合ではない（移る・極限）。
- 一般化（逆向き）は書かない。

**対応（移る）**
- 両端は対象（分布・確率変数・統計量・手続き）。
- 厳密：決まった操作で誤差なく移る（二項分布 → 標本比率：n で割る。正規分布 → 標準正規分布：標準化。仮説検定 ↔ 信頼区間：棄却されない値を集める）。
- 極限：条件を保って進めると近づく（二項分布 → ポアソン分布）。保つ条件と進め方を条件に書く。
- 近似：有限のままで使う。極限の定理があるときは極限の関係に「目安」を添え、近似の関係は極限の定理がないもの（Welch の自由度など）にだけ使う。
- 操作に使う概念（標準化・ベイズの定理など）は線にせず、移る関係の `via` に書く。

**確率（従う・推定する）**
- 従う：統計量とその標本分布（t 統計量 → t 分布）。仮定（正規母集団・独立・等分散）を条件に、厳密か極限か（中心極限定理による近似）を書く。
- 推定する：推定量と母数（標本平均 → 母平均）。不偏・一致などの性質は、その関係に添える（性質の概念へは線にしない）。

**帰結（導ける・同値・根拠）**
- 両端は命題。概念が命題でない（分布・統計量など）ときは、**何が言えるかの1文（`claim`）を必ず書く**（独立 → 共分散：「Cov(X, Y)＝0」）。1文がないと読めない。
- 導ける：一方向。逆が成り立たないことは反例として添える（線を増やさない）。
- 同値：両方向。同じ概念の別の定義どうしなら関係にしない（3）。
- 根拠：結論が命題でなく手続き（推定・検定の方法）のとき（中心極限定理 → 母比率の区間推定）。

**比べる**
- 比べる軸と、同じ所・違う所を書く。
- 比べる軸が、ほかの関係の条件で言い尽くせるときは書かない（その関係の条件で見せる）。言い尽くせないときは、ほかの関係があっても書く（二項分布とポアソン分布は移る関係でつながるが、「回数の上限と、分散と平均の関係」は移る条件では言えない）。
- 同じ親の一種どうしは、親の分け方以外の軸があるときだけ書く。

## 5. 判定の順

上から当てはめ、最初に合ったものにする。

0. 同じ意味か → まとめる（関係にしない）
1. from が to の基準の定義の直接の構成要素か → 定める
2. 一方が他方に含まれるか → 値で言えれば特別な場合、性質で言えれば一種
3. 両端が対象で、操作・極限で移るか → 移る
4. 統計量とその分布か → 従う
5. 統計量と母数か → 推定する
6. 両端が命題か（1文を書けば命題になるか）→ 導ける・同値
7. to が手続きで、from がその根拠の定理か → 根拠
8. 取り違えやすく、比べる軸がほかの関係の条件で言い尽くせないか → 比べる
9. どれでもない → 関係にしない

### 重なりやすい組

| 組 | 判定 |
| --- | --- |
| 一種と特別な場合 | 値で言えるなら特別な場合（情報が多い） |
| 特別な場合と極限 | 母数の範囲の中なら特別な場合、極限でしか届かないなら移る |
| 定めると一種 | 一種の線があれば、親への定めるは書かない（親は必ず定義に出る） |
| 定めると、定理の主張に出る | 定理は点にし、主張に出る概念はその点の結論としてつなぐ（7）。定めるにしない |
| 導けると移る | 両端が対象なら移る、命題なら導ける |
| 移ると同じ意味 | 意味が違い、条件のもとで値が一致するなら移る（厳密）。どの文脈でも同じならまとめる |
| 導けると根拠 | 結論が命題なら導ける、手続きなら根拠 |
| 導けると比べる | 一方向の導きがあれば導ける。比べるは足さない |

## 6. 条件（線にしない）

概念・関係が成り立つための条件は、線にせず、その概念・関係に添える。

| 区分 | 意味 | 外れたとき |
| --- | --- | --- |
| 要件 | 採用している定義の条件（母数の範囲など） | この定義のものとして扱えない |
| 仮定 | 定理・モデルによる保証の条件 | 保証が使えない。結論が偽とは限らない |
| 目安 | 近似・極限を有限で使うときの数の基準（出典と対象を持つ） | この目安では勧められない。精度を別に確かめる |

- 条件の文に出る概念は、押せる札で並べる（線にしない）。
- 定義そのもの・手順（連続修正）は条件に書かない。

## 7. 線で表さないもの

- **定理**（前提が2つ以上の主張）は点にする。前提・結論・仮定をその点に集め、点から各概念へは役（前提・結論）を付けてつなぐ。前提の概念と結論の概念を直接は結ばない。
- **3つ以上の概念の関係**（交絡・偏相関・シンプソンのパラドックス・平方和の分解）は、概念か定理の点にする。2つを結ぶ線では表せない。
- **推移で出るもの**（A → B → C の A → C）は書かない。

## 8. 1つの組に書く関係の数

- 1つの組に関係は1つ。
- ただし、包含（一種・特別な場合）と対応（移る）は別の軸なので、同じ組に両方を書いてよい（ベルヌーイ分布 → 二項分布：n＝1 の特別な場合であり、独立な n 個の和という移る関係でもある）。

## 9. 規則

1. 関係の相手が教材にないときは、関係を書かない。上の概念で代わりにしない（t 分布が近づく先は標準正規分布で、正規分布一般ではない）。
2. 関係のために概念を足さない。概念の意味を正しく表すのに要るときだけ足す。
3. 例外の規則は足さない。どの種類にも合わない関係が出てきたら、規則を足す前に、その概念が2つの意味を持っていないかを確かめる（#105）。
