# ⑤ 関係（関係図の製本）

2つの概念が数学的・統計的にどう関係するか、の決まり。何を関係とし、どの種類に分けるかを決める。概念のルール（concepts.md）の上に立ち、条件は成立条件のルール（conditions.md）に従う。型・原本・画面でどう持つか（項目の名前を含む）は設計書で、どの順で移すかは計画書で決める。

2026-11-08 に渡辺さんと決めた方向（数学の記号の意味から決め直す。今の実装に引っ張られない）で作った。

| 決めること | 下の節（1 から） |
| 保証すること | 線が何を意味し、何と何を結んでいるかを正確に読める |

| 例・反例・未決 | check-pairs.md、placement.md（⑤ だけで判断できる組は1つ） |

## 1. 何を扱うか

- 扱う：**概念どうしの数学的・統計的な関係**。2つの概念について、次の問いに答える。
  - 何で定まるか・何の一部か・どう移るか
  - 何に従うか・何を推定するか
  - 何が言えるか・何の根拠か・どこが違うか
- 扱わない：
  - 学ぶ順 → 学ぶ順のルール（learning-order.md）
  - 成り立つための条件 → 成立条件のルール。線にせず、掛かる先に添える
  - 使い道（何に使うか） → 問いと実験、単元の本文
  - 計算の手順、統計の外の解釈、実験の操作

出発点は数学的な意味・統計的な意味。そこから外れる関係を足すときは、なぜ要るのかを先に議論する（渡辺さん 2026-11-07）。

## 2. 関係にするもの

2つの概念の間の何かを関係として書くのは、次の3つを全部満たすときだけ。

1. **両端が概念である**。具体的な値・観測・例ではない。
2. **いつでも成り立つ**。成り立つための条件があるなら、条件として添えられる。
3. **推移で出るものではなく、言い換えでもない**。
   - A → B → C の A → C は書かない。
   - 1つの概念の別の名前・別の定義は、関係にしない（概念のルール 2）。
   - 定める・一種は、定義を読めば分かる情報だが、定義の依存を見せるために書く。

## 3. 関係にしないもの

| もの | 例 | 扱い |
| --- | --- | --- |
| 同じ意味・別の定義・文脈の見出し | 母平均と期待値 | 概念のルール 2 |
| 1つの概念の中の式・性質 | 比例（σ/√n）・大小（不等式）・集合の演算・論理の結合 | 概念の中身 |
| 成り立つための条件 | 独立を前提に置く・範囲（すべての値で） | 成立条件のルール |
| 学ぶ順 | 独立を知ってから二項分布 | 学ぶ順のルール |
| 当てはめの判断 | データを正規分布とみなす | 仮定の行に添える、データで確かめる手掛かり |

## 4. 関係の種類

5つの族と比べる。矢印は from → to。両端に置けるものは、概念の姿（概念のルール 3）で決める。役割（統計量・推定量・母数）では決めない。

| 族 | 種類 | 意味（from → to） | from の姿 | to の姿 |
| --- | --- | --- | --- | --- |
| 構成 | 定める | from は to の基準の定義の直接の構成要素 | どれでも | 定義を持つ概念 |
| 包含 | 一種 | from は to の定義を満たし、性質・目的で区別したもの | to と同じ姿 | — |
| 包含 | 特別な場合 | to の自由に選べる部分を固定するだけで、from と同じものになる | to と同じ姿 | — |
| 対応 | 移る | from に操作・極限をとると to になる（厳密・極限・近似） | 分布・確率変数・数・手続き | from と同じ姿 |
| 確率 | 従う | 確率変数 from の分布は to（を決まった尺度・位置に変えたもの） | 確率変数 | 分布 |
| 確率 | 推定する | 標本から作る from は、母集団の数・関数 to を推定する | 確率変数（数を推定するとき）・偶然で決まる関数（関数を推定するとき） | 数・関数（from に対応する方） |
| 帰結 | 導ける | from から to が導ける（一方向） | 命題、または当てはめて命題にできるもの | 同じ |
| 帰結 | 同値 | from と to は互いに導ける | 同じ | 同じ |
| 帰結 | 根拠 | 定理 from が、手続き to の根拠になる | 命題（定理） | 手続き |
| 比べる | 比べる | 同じ問いに答える2つが、ある軸で違う | to と同じ姿 | — |

手続きと分布は直接結ばない。手続きを定める確率変数を通してつなぐ（母平均の t 検定 ← 定める ― t 統計量 ― 従う → t 分布）。

### 構成（定める）
- 基準にする定義（何を基準の定義にするか）は ① が決める。⑤ は、その基準の定義の直接の構成要素だけを書く。構成要素の構成要素は書かず、たどって出す。
- 定義の依存は輪にならない。
- 名前が定義に出ることは必要条件で、十分条件ではない。次のものは構成要素にしない。
  - 言い換え
  - 使われる場
  - 計算の近道の式
  - 求める結果
  - 成り立つための条件

### 包含（一種・特別な場合）
- **一種**：性質・目的で区別する。
  - 例：推定量は統計量の一種、適合度検定は仮説検定の一種、事後確率は条件付き確率の一種。
  - 親は多くて1つ。
  - 一種の線があれば、親への定めるは書かない（親は必ず定義に出るので）。
- **特別な場合**：固定の仕方を必ず書く。固定の仕方は次の3つだけ。
  - 母数を値にする：ベルヌーイ分布＝二項分布の n＝1、標準正規分布＝正規分布の μ＝0・σ＝1、幾何分布＝負の二項分布の r＝1
  - 2つの母数か2つの変数を等しくする：共分散で Y＝X とすると分散
  - 個数（群・カテゴリ・説明変数の数）を決める：重回帰の説明変数を1つにすると単回帰
- 固定したあと、統計量の形や判定が一致するだけのものは、特別な場合ではない。移る（厳密）にする。
  - 例：等分散を仮定する独立2標本の両側 t 検定と、2群の一元配置分散分析（別の概念か：①。一致の主張：④）。線は移る（厳密）。
- 極限でしか届かないもの（t 分布の自由度→∞）は、特別な場合ではない。移る（極限）にする。
- 2つの族の一部が重なるだけのもの（自由度2のカイ二乗分布と平均2の指数分布）は、包含ではない。線にしない（重なりの主張は ④）。
- 逆向き（一般化）は書かない。

### 対応（移る）
- 両端は同じ姿のもの（分布・確率変数・数・手続き）。
- 操作に使う概念（標準化・ベイズの定理など）は線にしない。通す操作として、移る関係に添える。
- **厳密**：決まった操作で、誤差なく移る。
  - 正規分布 → 標準正規分布：標準化
  - t 分布 → F 分布：2乗すると F(1, ν)
  - 相関係数 → 単回帰の決定係数：2乗する（仮定：切片を含む最小二乗）
  - 事前確率 → 事後確率：ベイズの定理で更新する
  - 母平均の両側 t 検定 → 母平均の t 区間：棄却されない値を集める（同じ統計量・同じ水準の対だけ。一般の「仮説検定」「信頼区間」の間には書かない）
  - 等分散を仮定する独立2標本の両側 t 検定 → 2群の一元配置分散分析：検定統計量が F＝t² で対応し、同じ水準で判定が一致する（片側・等分散を仮定しない t 検定では一致しない）
  - 標本分散 → 不偏分散：n/(n−1) を掛ける
- **極限**：条件を保って進めると近づく。
  - 行き先は極限そのもの。二項分布そのものは n→∞ で正規分布に近づかない。近づくのは、標準化した二項分布が標準正規分布へ、である。
  - 何が近づくか・保つ条件・進め方は ④ の極限の主張と ③ の仮定を参照する。有限のまま使う形の式は ②、その適用の目安は ③。
- **近似**：極限の定理によらない、有限のままの近似にだけ使う（Welch の自由度）。
- 操作が逆にたどれるとき（標準化とその逆）は、関係は1つのまま「逆向きもたどれる」と添える。

### 確率（従う・推定する）
- **従う**：確率変数とその分布。
  - 端が指すもの：from は、分布を述べる確率変数そのもの。to は、行き先の分布（母数つき）。関係が言うのは「from の分布は to である」か、「from の分布は to を決まった尺度・位置に変えたものである」のどちらか。
  - 何が従うかを式に言い換えてよい範囲は ② の「式の言い換え」。⑤ は、言い換えた式が端を置き換えないこと（端は from のまま）だけを持つ。
    - 例：不偏分散 → カイ二乗分布（(n−1)s²/σ² が従う）。端は不偏分散のまま。
    - 例：t＝(X̄−μ)/(s/√n) は ② で言い換えにならないので、標本平均・不偏分散から t 分布へは書かない。t 統計量 → t 分布 と書く。
  - 従うの主張（行き先の母数・厳密か極限か）は ④、仮定（正規母集団・帰無仮説が正しいとき）は ③。
  - 成り立つ場合が2つあり、行き先が違うときは、行き先ごとに別の組にする（標本平均：正規母集団なら N(μ, σ²/n)、一般の母集団なら中心極限定理で、標準化したものが標準正規分布へ）。
- **推定する**：標本から作るもの（推定量）と、母集団の数・関数。
  - 端の姿をそろえる：数を推定するのは確率変数（標本平均 → 母平均）、関数を推定するのは偶然で決まる関数（ヒストグラム → 確率密度関数。概念のルール 3）。
  - 行き先は文脈の見出しでよい（標本平均 → 母平均）。
  - 不偏・一致などの性質は、この関係に添える。性質の主張と根拠（E(s²)＝σ²、一致の根拠の大数の法則）は ④。
  - 個々の推定量から「不偏推定量」への一種は書かない。

### 帰結（導ける・同値・根拠）
- 両端は命題。性質・手続きなど、当てはめて命題にできるものは、④ の主張（言えることの1文）を必ず参照する。1文の書き方と、示せるかの基準は ④。
  - 例：独立 → 無相関（④ の主張：X と Y が独立なら Cov(X, Y)＝0）
- **導ける**：一方向。
  - 逆が条件つきで成り立つときも、関係は1つ。逆の主張と反例は ④、逆が成り立つ条件は ③。
  - 例：無作為割り付け → 交絡：「無作為に割り付けると、割り付けは共変量と独立になり、共変量による交絡は（期待として）入らない」（仮定：割り付けの手順が守られる）。
  - 例：ポアソン分布 → 指数分布：「出来事がポアソン過程で起きるとき、待ち時間は Exp(λ) に従う」。ポアソン過程は教材にない概念なので、概念にせず仮定の中で言う。
- **同値**：互いに導ける。
  - 別の対象についての命題どうしにだけ使う（p 値≦α と、統計量が棄却域に入る）。
  - 同じ対象を別の式で言うなら、別の定義（概念のルール 2）。
- **根拠**：結論が命題でなく手続き（推定・検定の方法）のとき（中心極限定理 → 母比率の区間推定）。

### 比べる
- 同じ姿の2つが同じ問いに答え、ある軸（値・前提・意味）で違うときに書く。
- 比べる軸と、同じ所・違う所を書く。
- どの比べるを学ぶ人に見せるか（取り違えやすさ）は ⑦ が決める。関係が成り立つかの条件にはしない。
- 比べる軸が、ほかの関係の条件で言い尽くせるときは書かない。言い尽くせないときは、ほかの関係があっても重ねて書く（二項分布とポアソン分布は移る・極限でつながるが、「回数の上限と、分散と平均の関係」は移る条件では言えない）。
- 同じ親の一種どうしは、親の分け方以外の軸があるときだけ書く。

## 5. 判定の順

上から当てはめ、最初に合ったものにする。比べるだけは、ほかの関係と重ねてよい（7）。

0. 同じ意味・別の定義・文脈の見出しか → 概念のルール 2（関係にしない）
1. from が to の基準の定義の直接の構成要素か → 定める
2. 一方が他方に含まれるか → 固定の仕方で言えれば特別な場合、性質・目的で言えれば一種
3. 同じ姿で、操作・極限で移るか → 移る
4. 確率変数とその分布か → 従う
5. 標本から作るもの（確率変数・偶然で決まる関数）と、母集団の数・関数か → 推定する
6. 命題か、1文を書けば命題になるか → 導ける・同値
7. to が手続きで、from がその根拠の定理か → 根拠
8. 同じ問いに答え、軸がほかの関係の条件で言い尽くせないか → 比べる
9. どれでもない → 関係にしない

### 重なりやすい組

| 組 | 判定 |
| --- | --- |
| 一種と特別な場合 | 固定の仕方で言えるなら特別な場合（情報が多い） |
| 特別な場合と極限 | 固定の仕方の範囲の中なら特別な場合。極限でしか届かないなら移る |
| 特別な場合と、判定が一致するだけ | 同じものにならないなら移る（厳密） |
| 定めると一種 | 一種があれば、親への定めるは書かない |
| 定めると、定理の主張に出る | 定理は点にする（6）。主張に出る概念は、その点の結論としてつなぐ |
| 導けると移る | 両端が同じ姿の対象で、操作で移るなら移る。言えることが命題なら導ける |
| 移ると同じ意味 | 意味が違い、条件のもとで値が一致するなら移る（厳密）。どの文脈でも同じなら概念のルール 2 |
| 導けると根拠 | 結論が命題なら導ける、手続きなら根拠 |
| 導けると比べる | 一方向の導きがあれば導ける。比べるは足さない |

## 6. 線で表さないもの

- **定理の点**：何を1つの定理として持つかと、定理の構造（前提・結論・仮定）は ④。⑤ は、定理を線でなく点で表すことと、点のつなぎ方を決める。
  - 定理の点は、姿が命題の概念として扱い、根拠・導けるの端になれる。
  - 点と概念をつなぐ役（前提・結論）は、種類とは別のつなぎで、推移をとるときに数えない。
  - 定理の結論が2つの概念の関係そのもの（標本平均の分布が近づく）なら、その関係（従う・極限）に通す定理として添える。定理の点から同じ2つを結論として重ねてつながない。
- **3つ以上の概念の関係**（交絡・シンプソンのパラドックス・平方和の分解）は、概念か定理の点にする。2つを結ぶ線では表せない。
- **推移で出るもの**は書かない。

## 7. 1つの組に書く関係の数

- 1つの組に関係は1つ。
- ただし、次の組み合わせは別の軸なので、同じ組に重ねてよい。
  - 包含（一種・特別な場合）と、対応（移る）。例：ベルヌーイ分布 → 二項分布 は、n＝1 の特別な場合であり、独立な n 個の和という移る関係でもある。
  - 比べると、ほかの関係。比べる軸が、ほかの関係の条件で言い尽くせないときに限る。

## 8. 規則

1. 関係の相手が教材にないときは、関係を書かない。上の概念で代わりにしない（t 分布が近づく先は標準正規分布で、正規分布一般ではない）。
2. 関係のために概念を足さない。概念の意味を正しく表すのに要るときだけ足す。教材にない概念（ポアソン過程など）は、仮定や1文の中で言う。
3. 例外の規則は足さない。どの種類にも合わない関係が出てきたら、規則を足す前に、その概念が2つの意味を持っていないか（概念のルール 2）と、姿の一覧に足りないものがないか（概念のルール 3）を確かめる。
