2026-11-08。製本を判断の基準として採った版（PR #257 のマージ）と、教材・実装がその基準に移った状態は、別のものとして記録する。ここに書くのは後者。

- **採った版**：PR #257 をマージした main のコミット。この版から、意味の判断は製本に従う。
- **移った状態**：教材の原本（content/）・型 v1・build・画面は、まだ製本に移していない（2026-11-08）。製本に合っているとは扱わない。
- **移す順**：docs/rulebook-migration-plan.md（M0〜M8）。

## 1. 併存の決まり

- 意味の判断（何と何をどう結ぶか、どの条件か、何を主張するか）は、製本に従う。
- 原本の書き方（YAML の項目・型 v1 の種類の名前・build の止め）は、移すまで今の形式に従う（CLAUDE.md・docs/authoring.md・関係図の定義書と設計書）。
- 製本の意味を今の形式で書くときは、下の対応表で写す。対応表にない意味（今の形式で書けないもの）は、新しく書かない。今ある行は、移すときに振り分け直す。
- 同じ作業に、製本と CLAUDE.md・設計書が反対の判断を求めたら、それは誤りとして直す（下の 3 に、今回直したものを書いた）。
