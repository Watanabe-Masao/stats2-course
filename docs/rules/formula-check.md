## 3. 見つかったこと

1. **定義式と等式が1つの式に混ざっている**（② の 1「定義式とそれ以外を混ぜない」と反対）：F-var-def（V(X)＝E((X−μ)²)＝E(X²)−{E(X)}²）、F-cov-def（Cov(X, Y)＝E((X−μ_X)(Y−μ_Y))＝E(XY)−E(X)E(Y)）。どちらも左の等号が定義、右の等号が性質。F-cov-def は TERM-cov の basis_formula でもあり、② の 1「概念の基準の定義は定義式で書く」にも反する。分けると式のレビューの fingerprint が変わるので、それぞれの分類を移すとき（#265。分散は要約、共分散は相関・回帰）に分ける。
2. **確率変数の範囲（とる値）を書く所がない**：確率変数の記号（X など）には範囲がなく、とる値は値の記号（k・x）の domain に書いてある。記号の of（どの確率変数の記号か）は今、母数から確率変数を指す9行（F-var-def の μ、F-sd-def の σ、F-std-def の μ・σ、F-normal-pdf の μ・σ、F-expect-mu の μ、F-cov-def の μ_X・μ_Y）にしか使っておらず、値の記号には使っていない。値の記号に使ってよいかは型で決まっていない。② の 2 の「記号ごとに範囲を持つ」を確率変数にどう当てるか（確率変数の範囲を値の記号で持つと書くか、確率変数に台を持たせるか）は、#262 で型と合わせて決める。② の未決1（範囲を式ごとに持つか、概念ごとに持つか）ともつながる。
3. **domain も range もない記号がある**：μ（F-var-def・F-std-def・F-normal-pdf・F-expect-mu）、μ_X・μ_Y、一様分布の a、添え字 i・x（和・積分の変数）、F-pdf-interval の a・b、F-normal-pdf の x、定数 a・b（F-var-linear・F-expect-linear）、F-rv-pmf の x、F-indep-def の A・B（3 の 4）。range だけあって domain がない行は 6（F-expo-pdf・F-expo-surv の x、関数 p の3行、F-pdf-interval の f）。μ の「実数全体」のように範囲を書かない約束にするか、書くかを決めていない。#262 で、範囲を書かなくてよい記号（実数全体・和の変数）の約束を決める。
4. **事象を指す記号の種類がない**：F-indep-def の A・B・A∩B は事象だが、記号の kind（value・data・rv・param・index・const）に事象がなく value になっている。② の 2 の「何を指すか」が kind で読めない。#262 で kind に事象を足すかを決める。
