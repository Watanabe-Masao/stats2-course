## 1. 式の種類と、契約の kinds の対応

② の 1 の式の種類（定義式・等式・近似式・極限・分布の式）と、契約の kinds（定義・恒等式・変換・確率モデル・推定・近似・判定）は、分けている軸が違う。

- ② の種類：式が何を言うか（定める・等しい・近い・近づく・従う）。1つの式に1つ。
- 契約の kinds：式の役目と主題が混ざっている。定義・恒等式・近似は ② の種類にあたり、変換・確率モデル・推定・判定は、何についての式か（主題）にあたる。1つの式に2つ付くのは、ほとんどが「種類＋主題」の組（定義＋変換、恒等式＋変換、定義＋判定）。

## 3. 見つかったこと

1. **定義式と等式が1つの式に混ざっている**（② の 1「定義式とそれ以外を混ぜない」と反対）：F-var-def（V(X)＝E((X−μ)²)＝E(X²)−{E(X)}²）、F-cov-def（Cov(X, Y)＝E((X−μ_X)(Y−μ_Y))＝E(XY)−E(X)E(Y)）。どちらも左の等号が定義、右の等号が性質。分けると式のレビューの fingerprint が変わるので、それぞれの分類を移すとき（#265。分散は要約、共分散は相関・回帰）に分ける。
2. **確率変数の範囲（とる値）を書く所がない**：確率変数の記号（X など）には範囲がなく、とる値は値の記号（k・x）の domain に書いてある。値の記号と確率変数を結ぶ項目（値の記号の of など）もない。② の 2 の「記号ごとに範囲を持つ」を確率変数にどう当てるか（確率変数の範囲を値の記号で持つと書くか、確率変数に台を持たせるか）は、#262 で型と合わせて決める。② の未決1（範囲を式ごとに持つか、概念ごとに持つか）ともつながる。
3. **値・母数・添え字の範囲がない記号がある**：μ（F-var-def・F-std-def・F-normal-pdf・F-expect-mu）、μ_X・μ_Y、一様分布の a、添え字 i・x（和・積分の変数）、F-pdf-interval の a・b、F-normal-pdf の x など。μ の「実数全体」のように範囲を書かない約束にするか、書くかを決めていない。#262 で、範囲を書かなくてよい記号（実数全体・和の変数）の約束を決める。
4. **事象を指す記号の種類がない**：F-indep-def の A・B・A∩B は事象だが、記号の kind（value・data・rv・param・index・const）に事象がなく value になっている。② の 2 の「何を指すか」が kind で読めない。#262 で kind に事象を足すかを決める。
