# ⑧ 適用・解釈

骨格（2026-11-08）。器だけを先に作った。中身は CLAUDE.md の段階の定義（発展・創造）と「統計とデータの解釈は別の力」から、判断の基準だけを移していく。

## 1. 答える問い

現実の問いにモデルをどう対応させ、結果から何が言え、それを判断にどうつなぐか。

## 2. 決めること

- 計算結果・統計的な主張・現実の解釈・意思決定の4つを分けて書く（今は CLAUDE.md「統計とデータの解釈は別の力として書く」）。
- 現実のデータが仮定（③）を満たすかを確かめる手掛かり（時間帯で割合が変わらないか、など）は、確かめる仮定の行に添える（③ から移した判断）。
- 当てはめの判断（データを正規分布とみなす）は数学の関係ではなく、ここで扱う。
- 「成り立たない場合」は統計の弱点ではなく境目。そのとき何で判断するか（取り方を変える・現場の知識・費用や価値判断）まで考える（今は CLAUDE.md）。
- 交絡・シンプソンのパラドックスなど、3つ以上の要因の関係の現実での読み方（⑤ は点として表すだけ）。

## 3. 保証することと、確かめ方

- 保証すること：計算結果・統計的な主張・現実の解釈・意思決定を区別できる。
- 確かめ方：（未決）解釈の例が、統計の結果と解釈を分けて書いてあるか。解釈が2つ以上の筋の通った読み方を並べているか。

## 4. 保証しないことと、引き受け先

| 保証しないこと | 引き受け先 |
| --- | --- |
| モデルが現実を完全に表すこと | 全体でも保証しない |
| 因果や施策の成功を無条件に保証すること | 全体でも保証しない |
