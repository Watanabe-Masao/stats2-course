## 0. この本の器

- **答える問い**：現実の問いにモデルをどう対応させ、結果から何が言え、それを判断にどうつなぐか。
- **決めること**：下の節（1 から）
- 保証すること：計算結果・統計的な主張・現実の解釈・意思決定を区別できる。
- 確かめ方：5 に書いた。

保証しないことと、その引き受け先：

| 保証しないこと | 引き受け先 |
| --- | --- |
| モデルが現実を完全に表すこと | 全体でも保証しない |
| 因果や施策の成功を無条件に保証すること | 全体でも保証しない |

## 1. 4つを分ける

計算結果・統計的な主張・現実の解釈・意思決定を分けて書く。

| もの | 何か | 例（売場の購入件数） |
| --- | --- | --- |
| 計算結果 | 式に数を入れて出た値 | P(X≧8) の値（たとえば約5％） |
| 統計的な主張 | 前提（③）のもとで言えること。誤差の幅を持つ | 来店した客の購入が独立で確率 p が一定なら、8件以上はその程度の確率でしか起きない |
| 現実の解釈 | 文脈・現場の知識・因果の見立てと合わせた読み | 今日の8件は、特売で購入の確率が上がったからかもしれない |
| 意思決定 | 費用・価値判断を入れた判断 | 特売を続けるか |

- 統計は、前提のもとで言えることまで。解釈は、学ぶ人に委ねる（正解を書かない）。
- 「1つの考え方の例」は、統計の結果と解釈を分け、筋の通った読み方を2つ以上並べてよい。
- 教材での名指し（2026-11-11。#351）：見出し「統計で言えること」（計算結果と統計的な主張）・「解釈の例」（現実の解釈）・「統計の外で決めること」（意思決定。決めることがなければ「統計の外で確かめること」）を、4つの名指しとする。計算結果を統計的な主張から分けて書くかは、その例で取り違えが起きるときだけ分ける。
- 解釈の例には、意思決定（〜するのがよい・〜を優先する）を書かない。判断は「統計の外で決めること」の段に置く。
- 設計・方法を決める課題（調べ方・発注数・基準を決める）は意思決定として名指しし、読み方2つの代わりに、選び肢2つ以上と判断の材料を並べる。
- 統計的な主張の前提は、主張ごとに添える（問いの文にだけ置かない）。数値の元にした母数（分布の形・σ など）は、計算の設定として本文に書く。

## 2. 当てはめの判断

- 現実のデータをモデルに当てはめてよいか（データを正規分布とみなす・購入を独立とみなす）は、数学の関係ではなく、ここで判断する。
- 仮定（③）を確かめる手掛かり（時間帯で割合が変わらないか、客どうしで影響しないか）は、確かめる仮定の行に添える（③ から移した判断）。
- 手掛かりで分かるのは「仮定に反する兆しがあるか」まで。仮定が成り立つことは確かめられない。

## 3. 成り立たない場合

- 「成り立たない場合」は統計の弱点ではなく境目。そのとき何で判断するか（データの取り方を変える・現場の知識・費用や価値判断）まで考える。
- きれいに説明できない複雑なデータも載せ、統計でどこまで整理でき、どこからが解釈かを見せる。

## 4. 3つ以上の要因

- 交絡・シンプソンのパラドックス・擬相関など、3つ以上の要因の関係は、統計で言えること（層ごとの数・偏相関の値）と、因果の見立て（どれが原因か）を分ける。⑤ はこれらを点として表すだけ。
- 無作為割り付けで数学的に言えるのは、完全無作為化で各個体が処置群に入る確率が等しいこと（無作為に選んだ1個体の T と Z の独立）と、平均の差の期待値が 0 になること（④ の 29）まで。「交絡の原因にならない」はこの結果の解釈で、ここで扱う。1回の実験で偶然に偏ることはある。⑤ では無作為割り付けと交絡を線で結ばない。

## 5. 確かめ方（器の「確かめ方」の中身）

- 解釈の例が、計算結果・統計的な主張・解釈・意思決定のどれかを名指しして書いてある（名指しの形は 1）。
- 統計的な主張に、前提（③）が添えてある。
- 解釈が、筋の通った読み方を2つ以上並べている（1つに決めつけていない）。解釈の例に意思決定が混ざっていない。
- 成り立たない場合に、その先何で判断するか（3）が書いてある。
- 3つ以上の要因が出るなら、統計で言える数と因果の見立てを分けている（4）。
- 当てる範囲（2026-11-11。#351）：上の全部は、解釈の例を置く所（創造の探究・課題の考え方の例、発展の「説明してみる」）に当てる。解説だけの発展の節には「統計的な主張に前提が添えてある」だけを当てる。数え上げ・道具の単元の創造に、混ざったデータを無理に置かない（CLAUDE.md の考え方の枠組み）。
