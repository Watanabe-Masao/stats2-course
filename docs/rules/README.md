# 製本（決まりの本）の一覧

1冊の製本は、1つの問いだけに答える。前提が変わったときに、どの製本を見直せばよいかが分かるようにするため（2026-11-08。関係の種類「前提」が、関係・学ぶ順・成立条件の3つを1つで抱えて意味が混ざったことから）。

製本には意味の決まりだけを書く。型・原本・画面でどう持つか（設計）と、どの順で作るか（計画）は、それぞれの設計書・計画書に書く。

| 製本 | 答える問い | 先に読む製本 |
| --- | --- | --- |
| [概念のルール](concepts.md) | 何を1つの概念とし、それは何であるか（姿）。役割は関係から出る | — |
| [成立条件のルール](conditions.md) | 概念・主張・変換・手続きは、どんな条件で使え、外れると何が言えなくなるか | 概念 |
| [関係のルール](relations.md) | 2つの概念は、数学的・統計的にどう関係するか | 概念・成立条件 |
| [学ぶ順のルール](learning-order.md) | 何を先に知っておくと理解しやすいか | 概念・関係 |

確かめの材料：[確かめの組](check-pairs.md)。製本を直すたびに振り分け直し、残った迷いを記録する。

まだ作っていない候補：定理・導出（主張が何から、どの手順で、どの条件を使って導けるか）、問いと実験（何を発見させ、何ができれば理解したとするか）、式、統計で言えることと解釈の境目。
