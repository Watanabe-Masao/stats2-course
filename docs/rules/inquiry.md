# ⑦ 問い・実験・理解判定

骨格（2026-11-08）。器だけを先に作った。中身は CLAUDE.md の実験室の決まり（#163・#169・反例の方針）から、判断の基準だけを移していく。

## 0. この本の器

- **答える問い**：学ぶ人に何を発見させ、何を操作・観察させ、何ができれば理解したとするか。
- **決めること**：下の節（1 から）
- 保証すること：学習目標・体験・判定が対応し、何を確かめたかが分かる。
- 確かめ方：（未決）問いごとに、目標・操作・観察・判定の4つがそろっているか。

保証しないことと、その引き受け先：

| 保証しないこと | 引き受け先 |
| --- | --- |
| 正解だけで深い理解を証明すること、長期の定着 | 全体でも保証しない |
| 実験結果だけで定理を証明すること | ④ |

## 例・反例・未決

- 例：check-pairs.md の 3・4・12・16・21（比べるを載せるかが ⑦ に頼る）。
- 未決：CLAUDE.md の実験室の決まりのうち、判断の基準と、仕組み（画面・データ）を分けて移す。

## 1. 決めること

- 問いは、発見させたい性質の数だけ作る（概念の数だけではない）。主は発見させたい性質で決める（今は CLAUDE.md #163・#169）。
- 理解判定は、何ができれば理解したと判定するかを、問いを作るときに最低限書く（今は CLAUDE.md）。
- 応用の段は、予測〜理由とは別の考え方（逆算・評価・設計・変換・反証・モデル選択）を求める（今は CLAUDE.md #169）。
- 反例は、何を確かめるかを先に書き、比べる条件をそろえ、理論と実験のゆれを分ける（今は CLAUDE.md の反例の方針）。
- 何を学ぶ人に見せるか：
  - 関係図・概念のページで、どの比べるを載せるか（取り違えやすさを理由として持つ。⑤ から移した判断）。
  - 使い道（その概念を何に使うか）を問いの本文で見せる（外した「応用」の行き先）。
- 学ぶ順（⑥）とは往復して調整する（問いが使っている概念が、学ぶ順の前提知識の根拠になる）。
