## 0. この本の器

- **答える問い**：学ぶ人に何を発見させ、何を操作・観察させ、何ができれば理解したとするか。
- **決めること**：下の節（1 から）
- 保証すること：学習目標・体験・判定が対応し、何を確かめたかが分かる。
- 確かめ方：5 に書いた。

保証しないことと、その引き受け先：

| 保証しないこと | 引き受け先 |
| --- | --- |
| 正解だけで深い理解を証明すること、長期の定着 | 全体でも保証しない |
| 実験結果だけで定理を証明すること | ④ |

## 1. 問いの単位

- 問いは、学ぶ人に発見させたい性質の数だけ作る。概念の数だけ作らない（CLAUDE.md #163）。
- 問いの主は、発見させたい性質で決める。2つの概念のつながりそのものを発見させる問いは、関係（⑤）を主にする。関連は、その問いを理解するのに実際に使う概念だけ（#169）。
- 同じ現象・同じ図でも、注目するもの（平均・散らばり・分布全体）が違えば別の問い。
- 同じ実験をして、同じ発見をして、同じ問題で理解を判定できるなら、別の問いにしない。言葉を替えただけの問いは作らない。

## 2. 体験の形（予測 → 実験 → 観察 → 考察 → 応用 → 比較）

- 予測は、答えが理論から決まる問いにだけ置く。発展・創造の段には置かない（答えの決まらない「説明する・切り分ける」形にする）。
- 実験は、前の条件と変えた条件の両方を、同じ回数ずつ起こして比べる。
- 反例は、次の5つをそろえる（#118 の反例の方針。元は CLAUDE.md）。種類は「成り立つ条件を外す実験」「誤解を正す例」「指標の限界を示す比較」。
  1. 何を確かめるかを先に書く
  2. 比べる条件をそろえる
  3. 成り立つ範囲と、差が出ない端を示す
  4. 理論の関係と、実験のゆれを分ける
  5. 観察のあとの理解（どの分布・概念で考えるか）までつなぐ
- 反例の文章・実験の仕組み・比べる理論・検証が、同じ主張（④）を指すこと。
- 実験の結果は、主張（④）の確かめであって証明ではない。

## 3. 理解判定

- 問いを作るときに、何ができれば理解したと判定するかを最低限書く。実験の目的と理解判定がずれないようにするため。
- 応用の段は、予測〜理由で練習したのとは別の考え方を求める（逆算・評価・設計・変換・反証・モデル選択など）。場面の言葉や数を替えて同じ計算をさせるだけにしない（#169）。
- 段階（初学・応用・発展・創造）で、身に付ける力と判定の形を変える（CLAUDE.md の段階の定義）。発展・創造の答えは「1つの考え方の例」で、正解にしない。

## 4. 何を学ぶ人に見せるか

- 関係図・概念のページで、どの比べるを載せるか。取り違えやすさ（学ぶ人がよく取り違える組か）を理由として持つ（⑤ から移した判断）。
- 使い道（その概念を何に使うか）は、問いの本文や単元の本文で見せる（外した「応用」の行き先）。
- 学ぶ順（⑥）とは往復して調整する。問いや説明が使っている概念が、学ぶ順の前提知識の根拠になる。

## 5. 確かめ方（器の「確かめ方」の中身）

- 問いごとに、目標（発見させたい性質）・操作・観察・判定の4つがそろっている。
- 判定が、目標の性質を確かめている（別の計算の練習になっていない）。
- 反例は 2 の5つがそろい、同じ主張を指している。
