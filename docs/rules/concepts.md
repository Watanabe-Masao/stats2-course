# 概念のルール（概念の単位と種類の製本）

1つの概念とは何か、それは何であるか、の決まり。関係のルール・成立条件のルール・学ぶ順のルールは、この製本の上に立つ。2026-11-08 に渡辺さんと決めた方向（数学の意味から決める。今の実装に引っ張られない）で作った。

## 1. 3つの問いを分ける

概念について、次の3つを別々に決める。混ぜると、型を決めるために概念を不自然に分けたり、文脈で変わる役割を概念の性質として固定したりしてしまう。

| 問い | 決めること | 例（標本平均） |
| --- | --- | --- |
| 同一性：何を同じ概念とするか | 1つの点にするか、分けるか（2） | 標本平均は1つの概念 |
| 何であるか：数学的にどんなものか | 対象の姿（3）。仮置きの一覧から、1つか2つ | 標本の関数である確率変数（その値も同じ名前で呼ぶ） |
| 役割：文脈の中で何の役をするか | 概念には書かない。関係から出る（4） | 母平均に対して推定量、検定の中では検定統計量の材料 |

## 2. 同一性：何を同じ概念とするか

概念にするかは、その語が固有の意味・役割・操作・確かめ方を持つかで決める（渡辺さん 2026-10-31、#105）。そのうえで次のように扱う。

| 場合 | 扱い | 例 |
| --- | --- | --- |
| どの文脈でも置き換えられる | 1つの概念。ほかの名前は別名 | 片側検定・両側検定（対で初めて意味を持つ） |
| 同じ名前で、指すものが違う | 分ける | 分散（データの分散／確率変数の分散）、事前確率と事後確率 |
| 意味を共有し、対象と文脈が違う | 1つの意味を共有し、文脈の見出しを分ける（下） | 母平均と期待値 |
| 値がある条件で一致するだけ | 分ける。一致は関係（移る・厳密）で書く | 単回帰の決定係数と相関係数の2乗 |
| 同じものを別の式で言う | 1つの概念の「別の定義」 | 独立の積の形と条件付きの形 |

### 意味を共有し、文脈の見出しを分ける（母平均と期待値。渡辺さん 2026-11-08）

- 「同じ概念か、別の概念か」の2択で処理しない。意味は1つ（共有する概念）に持ち、文脈ごとの見出しを別に持つ。
- 共有する概念：期待値（確率分布の重み付きの平均）。定義はここだけに持つ。
- 文脈の見出し：母平均。見出しは自分の定義を持たず、共有する概念との対応と、対象・文脈の違いを書く。
  - 対応：母平均は、母集団の分布の期待値（μ＝E(X)。X は母集団から1つ取り出した値）。
  - 対象の違い：期待値は確率分布（確率変数）について言う。母平均は母集団について言う。
  - 文脈の違い：母平均は推測統計の中で「標本から知りたい、決まっているが分からない数」として出る。期待値は確率の計算の中で「分布から決まる数」として出る。
- 学ぶ画面では、見出しごとに別のページ・別の入口にしてよい。同じ意味なので、定義・式・成立条件は共有する概念から読む（重ねて管理しない）。
- 同じ形のもの（候補）：母分散と確率変数の分散、母比率とベルヌーイ分布の p。採るかは、その分類を移すときに決める。

## 3. 何であるか（仮置きの一覧）

数学的にどんなものかの姿。**排他的な分類として固定しない**。1つの概念が2つの姿を持ってよい（期待値は演算でもあり、その値でもある）。姿を1つに決めるために概念を分けない。一覧は仮置きで、確かめの組（check-pairs.md）で説明できるかを見て直す。

| 姿 | 何か | 例 |
| --- | --- | --- |
| 数 | 決まった1つの値（分布・母集団・データから決まるものを含む） | 母平均、相関係数、有意水準、検出力 |
| 事象・集合 | 起こりうる結果の集まり | 事象、棄却域、第1種の過誤（判定の誤りという事象） |
| 確率変数 | 偶然で値が決まる量（標本の関数を含む） | 標本平均、不偏分散、t 統計量、p 値 |
| 分布 | 確率の割り当て。母数で区別される族か、その1つ | 二項分布（族）、標準正規分布（1つ） |
| 関数 | 値から値を決める規則 | 確率密度関数、回帰式 |
| 演算 | 分布・確率変数・データから、数や別のものを作る規則 | 期待値、分散、標準化 |
| 性質 | 対象が満たすか満たさないかが決まるもの | 独立、排反、無相関、不偏性、一致性、交絡 |
| 命題 | 真か偽かが決まる主張。示されたものは定理 | 中心極限定理、大数の法則、ベイズの定理、加法定理 |
| 手続き | データから値・区間・判断を出す、またはデータの取り方を決める手順 | 仮説検定、区間推定、最小二乗法、無作為割り付け |

- 2つの姿を持つ例：期待値（演算と値）、信頼区間（区間推定の手続きが出す、偶然で決まる区間）、p 値（確率変数とその値）、第1種の過誤（事象とその確率を同じ名前で呼ぶ）。
- 性質は、対象に当てはめると命題になる（「X と Y は独立」）。関係のルールで、性質が「導ける」の端になれるのはこのため。

## 4. 役割：文脈の中で何の役をするか

役割は概念に書かない。**関係から出る**。同じ概念が、文脈によって違う役をする。

| 役割 | どの関係から出るか | 例 |
| --- | --- | --- |
| 推定量 | 推定する（その母数に対して） | 標本平均は母平均の推定量 |
| 検定統計量 | 手続きを定める（その検定に対して）と、従う | t 統計量は t 検定の検定統計量 |
| 母数 | 分布の族を区別する数として定める | 二項分布の n と p |
| 前提・結論・仮定 | 定理の点の中での役（関係のルール） | 独立は中心極限定理の仮定 |
| 構成要素 | 定める | 組合せは二項分布の確率関数の構成要素 |

- 役割の名前そのものが概念として要る（推定量・統計量・検定統計量）ときは、その概念は「その役をする対象の一種」として定める（推定量は、母数を推定する目的で使う統計量）。
- 統計量（標本の関数で、分からない母数を含まないもの）は、確率変数に性質を足して区別した一種で、役割ではない。推定量・検定統計量は、統計量が文脈の中で持つ役割。

## 6. 決めること

1. 3の一覧の「数」と「演算」を、演算の値まで含めて「数」にまとめるか（期待値などは今は2つの姿を持つ）。
2. 「意味を共有し、文脈の見出しを分ける」形を、母分散と確率変数の分散・母比率と p に広げるか。
3. 手続きどうしの同一性：どのデータでも同じ判定（同じ値）を出す2つの手続きを、同じものとみなすか（check-pairs 18：2群の両側 t 検定と、2群の一元配置分散分析）。
4. 個別の手続き（母平均の t 検定・t 区間）と検定統計量（t 統計量・カイ二乗統計量）を、概念として持つか（check-pairs 17・28）。持たないと、検定と信頼区間の対応・検定と分布のつながりを、関係として書けない。
