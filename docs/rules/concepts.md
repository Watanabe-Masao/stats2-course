## 1. 3つの問いを分ける

概念について、次の3つを別々に決める。混ぜると、型を決めるために概念を不自然に分けたり、文脈で変わる役割を概念の性質として固定したりしてしまう。

| 問い | 決めること | 例（標本平均） |
| --- | --- | --- |
| 同一性：何を同じ概念とするか | 1つの点にするか、分けるか（2） | 標本平均は1つの概念 |
| 何であるか：数学的にどんなものか | 対象の姿（3）。仮置きの一覧から、1つか2つ | 標本の関数である確率変数（その値も同じ名前で呼ぶ） |
| 役割：文脈の中で何の役をするか | 概念には書かない。関係から出る（4） | 母平均に対して推定量、検定の中では検定統計量の材料 |

## 2. 同一性：何を同じ概念とするか

概念にするかは、その語が固有の意味・役割・操作・確かめ方を持つかで決める（渡辺さん 2026-10-31、#105）。そのうえで次のように扱う。

| 場合 | 扱い | 例 |
| --- | --- | --- |
| どの文脈でも置き換えられる | 1つの概念。ほかの名前は別名 | 確率関数と確率質量関数（同じものの別の呼び名） |
| 対で初めて意味を持つ | 1つの概念の中に、2つの場合として持つ。互いの別名ではない（置き換えられない） | 片側検定・両側検定（対立仮説の向きの2つの場合） |
| 同じ名前で、指すものが違う | 分ける | 分散（データの分散／確率変数の分散）、事前確率と事後確率 |
| 意味を共有し、対象と文脈が違う | 1つの意味を共有し、文脈の見出しを分ける（下） | 母平均と期待値 |
| 値がある条件で一致するだけ | 分ける。一致は関係（移る・厳密）で書く | 単回帰の決定係数と相関係数の2乗 |
| 同じものを別の式で言う | 1つの概念の「別の定義」 | 独立の積の形と条件付きの形 |
| 判定が一致する、別の手続き | 分ける。統計量の対応と判定の一致は関係（移る・厳密）で書く（下） | 等分散を仮定する独立2標本の両側 t 検定と、2群の一元配置分散分析 |
| 重なって見えるが、意味・役割が違う（#105） | まとめない。関係でつなぐ（種類は ⑤ の判定の順で決める。比べるは同じ姿のときだけ） | 偏差と残差、標本誤差と標準誤差（どの関係で結ぶかは、まだ ⑤ と照らしていない） |
| 一緒に学ぶと分かりやすいだけ（学習上のまとまり。#105） | 概念は分ける。まとまりは単元・分類・画面で扱い、学ぶ画面では一緒に見せてよい | — |

### 意味を共有し、文脈の見出しを分ける（母平均と期待値。渡辺さん 2026-11-08）

- 「同じ概念か、別の概念か」の2択で処理しない。意味は1つ（共有する概念）に持ち、文脈ごとの見出しを別に持つ。
- 共有する概念：期待値（確率分布の重み付きの平均）。定義はここだけに持つ。
- 文脈の見出し：母平均。見出しは自分の定義を持たず、共有する概念との対応と、対象・文脈の違いを書く。
  - 対応：母平均は、母集団の分布の期待値（μ＝E(X)。X は母集団から1つ取り出した値）。
  - 対象の違い：期待値は確率分布（確率変数）について言う。母平均は母集団について言う。
  - 文脈の違い：母平均は推測統計の中で「標本から知りたい、決まっているが分からない数」として出る。期待値は確率の計算の中で「分布から決まる数」として出る。
- 学ぶ画面では、見出しごとに別のページ・別の入口にしてよい。同じ意味なので、定義・式・成立条件は共有する概念から読む（重ねて管理しない）。
- 同じ形のもの（候補）：母分散と確率変数の分散、母比率とベルヌーイ分布の p。採るかは、その分類を移すときに決める。

### 手続きの同一性（渡辺さん 2026-11-08）

- 手続きが同じ概念かは、最終的な判定の一致だけでは決めない。何を問うか・入力（どんなデータか）・出力（何を出すか）・手続きの定義（どの統計量をどう使うか）まで見て決める。
- 等分散を仮定する独立2標本の両側 t 検定と、2群の一元配置分散分析は、対応する条件で結果が一致する（F＝t²、同じ水準で判定が一致する）。それでも問い（2つの平均の差／群の間のばらつき）と定義が違うので、別の概念にする。統計量の対応と判定の一致は、関係（移る・厳密）に書く。
- 一致を書くときは、一致する手続きを狭く特定する。「t 検定一般」のように広く書かない（片側の t 検定・等分散を仮定しない t 検定では一致しない）。

### 個別の手続き・検定統計量を概念にする基準（渡辺さん 2026-11-08）

- 個別の手続き（母平均の t 検定・母平均の t 区間など）と検定統計量（t 統計量・カイ二乗統計量など）は、要るものを概念として持つ。
- 採る理由は、それぞれが固有の問い・定義・成立条件・結果の読み方を持ち、それを説明する必要があること。関係をつなぐ都合だけでは足さない（⑤ の 8 の規則2）。

### 基準にする定義（⑤ から移した。2026-11-08）

- 概念ごとに、基準にする定義を1つ決める。定義1文（学習者向けの導入）は別に残してよい。
- 確率分布の基準の定義は、確率関数・確率密度の式。生まれ方（独立な試行の成功回数）は、その分布に従うための仮定（③）と主張（④）。
- 標本分布の族（カイ二乗分布・t 分布・F 分布）は、既知の分布に従う確率変数の関数として定めてもよい。どちらを基準にしたかは概念ごとに1つに決める。

## 3. 何であるか（仮置きの一覧）

数学的にどんなものかの姿。**排他的な分類として固定しない**。1つの概念が2つの姿を持ってよい（期待値は演算でもあり、その値でもある）。姿を1つに決めるために概念を分けない。一覧は仮置きで、確かめの組（check-pairs.md）で説明できるかを見て直す。

| 姿 | 何か | 例 |
| --- | --- | --- |
| 数 | 決まった1つの値（分布・母集団・データから決まるものを含む） | 母平均、相関係数、有意水準、検出力 |
| 事象・集合 | 起こりうる結果の集まり | 事象、棄却域、第1種の過誤（判定の誤りという事象） |
| 確率変数 | 偶然で値が決まる数（標本の関数を含む） | 標本平均、不偏分散、t 統計量、p 値 |
| 偶然で決まる区間・関数 | 標本から作る、偶然で決まる区間や関数（値が数ではないもの） | 信頼区間、ヒストグラム |
| 分布 | 確率の割り当て。母数で区別される族か、その1つ | 二項分布（族）、標準正規分布（1つ） |
| 関数 | 値から値を決める規則 | 確率密度関数、回帰式 |
| 演算 | 分布・確率変数・データから、数や別のものを作る規則 | 期待値、分散、標準化 |
| 性質 | 対象が満たすか満たさないかが決まるもの | 独立、排反、無相関、不偏性、一致性、交絡 |
| 命題 | 真か偽かが決まる主張。示されたものは定理 | 中心極限定理、大数の法則、ベイズの定理、加法定理 |
| 手続き | データから値・区間・判断を出す、またはデータの取り方を決める手順 | 仮説検定、区間推定、最小二乗法、無作為割り付け |

- 2つの姿を持つ例：期待値（演算と値）、p 値（確率変数とその値）、第1種の過誤（事象とその確率を同じ名前で呼ぶ）。
- 標本から作るもの（標本の関数）は、値が数なら確率変数、区間・関数なら「偶然で決まる区間・関数」。どちらも、観測したあとの値（データから作った1つの区間・1つのヒストグラム）を同じ名前で呼ぶ。
- 性質は、対象に当てはめると命題になる（「X と Y は独立」）。⑤で、性質が「導ける」の端になれるのはこのため。

## 4. 役割：文脈の中で何の役をするか

役割は概念に書かない。**関係から出る**。同じ概念が、文脈によって違う役をする。

| 役割 | どの関係から出るか | 例 |
| --- | --- | --- |
| 推定量 | 推定する（その母数に対して） | 標本平均は母平均の推定量 |
| 検定統計量 | 手続きを定める（その検定に対して）と、従う | t 統計量は母平均の t 検定の検定統計量 |
| 母数 | 分布の族を区別する数として定める | 二項分布の n と p |
| 前提・結論・仮定 | 定理の中での役（構造は ④） | 独立は中心極限定理の仮定 |
| 構成要素 | 定める | 組合せは二項分布の確率関数の構成要素 |

- 統計量（標本の関数で、分からない母数を含まないもの）は役割ではない。姿の側の概念で、確率変数（または偶然で決まる区間・関数）に性質を足して区別した一種。
- 推定量・検定統計量・母数は役割。役割の名前そのものが概念として要る（推定量・検定統計量）ときは、その概念を「その役をする対象の一種」として定める（推定量は、母数を推定する目的で使う統計量）。

## 6. 決めること

未決。暫定は、決まるまで使ってよい方針（README の運用の決まり 2）。


1. 3の一覧の「数」と「演算」を、演算の値まで含めて「数」にまとめるか（期待値などは今は2つの姿を持つ）。暫定：まとめない（2つの姿のまま）。
2. 「意味を共有し、文脈の見出しを分ける」形を、母比率と p に広げるか。暫定：広げない。ほかの組は、それぞれ ① の 2 で判断する（母分散は 2026-11-09 に広げると決めた。下の決まったこと）。
3. 尤度：教材の尤度（1つの仮説 H のもとの P(D|H)。数）は、条件付き確率の一種にした（#295）。H を替えて見ると、H について足しても1にならず、確率分布ではない。推定の分類で最尤法の尤度 L(θ)（母数の関数）を扱うとき、同じ概念の別の姿（関数）にするか、別の概念にするか。暫定：確率の分類では数で、条件付き確率の一種。推定の移行で決める。
4. 独立の基準の定義は事象の式（P(A∩B)＝P(A)P(B)）で、確率変数の独立は「値の事象 {X∈A}・{Y∈B} のどの組も独立」と要件の文に書いた（#295）。④-13 の端（確率変数の独立）をこの書き方で読んでよいか。暫定：この書き方で読む。
5. 自由度は「制約のもとで自由に動ける値の個数」と「t・カイ二乗・F 分布の族を区別する母数の呼び名」の2つを指す（#298 の2人の判定がどちらも挙げた）。2つが一致するのは従うの主張（④-10 など）の中だけ。暫定：1つの概念のまま（基準の定義は個数、母数は同じ名前で呼ぶと書く）で、自由度 → カイ二乗分布 を定める。
6. 偏り（TERM-bias）は、調査の偏り（取り方で結果が一方にずれること）と、推定量の偏り E(θ̂)−θ の2つを指す（#301 の2人の判定がどちらも挙げた）。暫定：1つの概念のまま。推定量の性質（不偏性・平均二乗誤差）の基準の定義には偏りの語を入れず、E(θ̂)＝θ・E[(θ̂−θ)²] で書く。調査・実験の分類の移行で決める。

決まったこと（2026-11-08）：手続きの同一性は判定の一致だけで決めない（2「手続きの同一性」）。個別の手続き・検定統計量は、要るものを概念として持つ（2「個別の手続き・検定統計量を概念にする基準」）。

決まったこと（2026-11-09。渡辺さん、#310）：母分散も、母平均と同じく確率変数の分散（TERM-var）の文脈の見出しにする（6 の 2 から外した。足すのは #302）。分散・標準偏差は、確率変数のもの（TERM-var・TERM-sd）とデータのもの（データの分散・データの標準偏差）を別の概念に分ける（2 の表の「同じ名前で、指すものが違う」）。
