# 関係図の設計書

定義書（docs/relation-map.md）の決まりを、どの型・データ・画面で持つかを書く。教材は今、二項分布を中心に作っていて、全部の分類を一度に移すことはできない。そこで次の形にする。

- **分類ごとに移す。** 移し終えた分類から関係図に出す。
- **型は足すだけにする。** 移していない分類のデータは、今のまま読める（v1 の改訂）。
- **最初の見本は確率分布の分類（13語）。** この文書の 4 に、見本を語ごとに書いた。ほかの分類を移すときは、4 と同じ形で表を作ってから原本を直す。

## 1. 型（knowledge-net の schema。v1 の改訂）

| 所 | 今（rev35） | 変えた後 |
| --- | --- | --- |
| 関係の種類 | 8種類 | 「種類」「材料」を足す |
| 対比の関係 | 違いは `description` | 比べる軸 `axis` を足す（任意。移した分類では build が必須にする） |
| 前提の関係 | premise が learning か mathematical | 今のまま。移した分類では learning だけ（学ぶ順） |
| まとまり | `course.groups`・`concept.group`（任意） | 今のまま（移した分類では build が必須にする） |

- 種類が増えると、今の画面は知らない種類のデータを読めない（型の enum で止まる）。そのため、**画面を先に**新しい種類が読めるようにし、公開してから、教材が新しい種類を書く。
- `x-revision` を1つ上げ、CHANGELOG に書く。relation-types.yaml に「種類」「材料」の定義・読み方・該当する例・該当しない例を、定義書の 3 から写す。
- 種類・材料の `trace`（前提をさかのぼる）は true にする。学ぶ順の見方（今の経路）は、M4 で作り直すまで、前提と材料・種類をあわせてたどる。
- 特殊化・統合（0本）は型に残す。外すのは、全部の分類を移し終えて v2 にするときにまとめて行う。
- **v2 にするとき：** 全部の分類を移し終えたら、次をまとめて行う。
  - まとまりを必須にする。
  - 前提を学ぶ順だけにし、premise の欄を外す。
  - 特殊化・統合を外す。

## 2. 教材の原本（stats2-course）

### 移した印

shared.yaml に、移し終えた分類の一覧を置く。

```yaml
relation_map_ready: [確率分布]   # 関係図の決まりで書き終えた分類（docs/relation-map.md）
```

build は、この一覧に入った分類にだけ、次を**止める**（入っていない分類は今のまま）。

| 止めること | 理由 |
| --- | --- |
| まとまりのない語 | 何の仲間かに答えられない |
| その分類の語を to にした、premise が mathematical の前提 | 材料か学ぶ順に分け終えていない |
| 種類の親が2つ以上の語 | 木が1つに決まらない |
| axis のない対比 | 何が違うかの軸が書かれていない |

**警告**にするのは、材料の輪だけ（どの分類も）。

### 関係をどの分類で移すか

- 種類・材料：to（定義される側）の語の分類で移す。
- 対比・変換・一般化・導出・応用：どちらかの語の分類を先に移すときに、いっしょに見直す。
- 学ぶ順（前提 learning）：to の分類で移す。中身は変えない。

### ID と版

- 関係の ID は変えない・消さない。
  - 種類を変えるときは、`version` を1つ上げ、`description` を新しい意味に直す。
  - 向きが逆だったときは、from と to を入れ替えてよい（ID はそのまま）。
- 語を分けるときは、元の ID を、今の定義の意味の側に残す。新しい意味の側に新しい ID を付ける。

## 3. 画面（knowledge-net）

### 関係図（M3）

- **出す範囲：** 移した分類（`relation_map_ready` を公開の JSON に出す）だけを、まとまりの関係図で開く。移していない分類は、今の分類のライブラリ（まとまりの節つきの一覧）のまま。
- **形：** 1枚の大きなキャンバス（前後左右に動かす・拡大）。柱 → 分類 → まとまり → 語 を入れ子の枠で置き、押すとその場で1段ずつ開く。
  - 入れ子なので、段を飛ばした線はできない。
  - 線は、直線と直角の曲がりだけ。
- **語を押したとき：**
  - 材料：語の中に1段だけ開く。掘り下げは、その材料をさらに押して開く。
  - 種類：親を語の上に、子を下に示す。
  - 対比・変換・一般化・導出・応用：横の線で示す。押した語の線だけを濃くし、ほかは薄くする。
- **たたむ：** 使う語がみな同じまとまりにある材料は、まとまりの枠の下に「このまとまりの中で使われる語」として収める。部品の印は付けない。
- **線を薄くする：** 確率・組合せのような、ほかの分類の基礎の語へ向かう線は、初めは薄くする。
- **語のページ：**
  - 中の材料（掘り下げ。道筋を上に残す）
  - これを材料にする概念（一覧。その先を開ける）
  - 種類
  - 横のつながり
  - 見本は #228 のモック（分散の語のページ）。

### 置き換えるもの

| 今 | 変えた後 |
| --- | --- |
| 島の地図・分類の地図・フォーカス | 移した分類では関係図。全部の分類を移したら消す |
| 見方の切り替え（フォーカス／経路／俯瞰） | 関係図と経路の2つにする |
| 経路（前提をさかのぼる） | M4 まで今のまま（前提・材料・種類をたどる） |

### 確かめるテスト（リスクから）

| 想定する故障 | 見つけ方 |
| --- | --- |
| 開いた語の線が、閉じている枠へ伸びる（段を飛ばす） | 語を開いたとき、線の両端がどちらも見えている枠の中にあることを、全部の語で確かめる |
| たたむ語を取り違える（ほかのまとまりでも使う語をたたむ） | 見本のデータで、たたむ語の集合を、手で数えた答えと照らす |
| 受け継ぎで材料が2回出る | 種類の親と子が同じ材料を持つ見本で、1回だけ出ることを確かめる |
| 新しい種類のデータを読めない | 種類・材料・axis を含む見本を、型で読み込めることを確かめる（ないと全体が出ない） |
| スマホで横にはみ出す・押せない | 380px と埋め込み（360×320）で、横スクロールなし・押す所が 44px 以上 |

## 4. 見本：確率分布の分類（13語）

定義書の規則で、確率分布の分類の13語を書いた。今の関係（REL-…）の行き先も並べる。この表が、ほかの分類を移すときの形になる。

### まとまり

| まとまり | 語 |
| --- | --- |
| 分布のしくみ | 確率変数・確率分布・確率密度関数・共分散 |
| くり返して数える | ベルヌーイ分布・二項分布・超幾何分布 |
| 待つ・まれに起こる | ポアソン分布・幾何分布・負の二項分布 |
| 連続の分布 | 一様分布・正規分布・指数分布 |

### 種類

なし。二項分布などは確率分布の一種だが、間の「離散分布」「連続分布」が教材にない。規則1により、上の語（確率分布）で代わりにしない。何の仲間かには、まとまりが答える。

### 材料（定義1文と、定義の式。期待値・分散の式は定義の式に入れない）

| 語 | 材料 | 定義のどこに出るか |
| --- | --- | --- |
| 確率変数 | 確率 | 「確率で表される量」 |
| 確率分布 | 確率変数・確率・確率密度関数 | 「確率変数がとる値と…確率（連続なら確率密度）の対応」 |
| 確率密度関数 | 確率変数・確率 | 「連続な確率変数で、区間に入る確率を…」 |
| 共分散 | 確率変数・期待値 | 「2つの確率変数が…ずれの積の期待値」 |
| ベルヌーイ分布 | 確率 | 「成功（1）を確率 p」 |
| 二項分布 | 確率・組合せ | 文の「確率」と、式 ₙCₖ pᵏ(1−p)ⁿ⁻ᵏ |
| 超幾何分布 | 組合せ | 式（組合せ3つの比） |
| ポアソン分布 | 階乗 | 式 e^(−λ)λᵏ／k! |
| 幾何分布 | 確率 | 「成功確率 p」 |
| 負の二項分布 | 確率・組合せ | 文の「成功確率 p」と式 |
| 一様分布 | 確率密度関数 | 「同じ密度で」・式 1／(b−a) |
| 正規分布 | 確率密度関数 | 「確率密度が f(x) の式で」 |
| 指数分布 | 確率密度関数 | 式 λe^(−λx) |

材料にしないもの：

- 「独立な試行」（幾何分布・負の二項分布・指数分布）の独立は、成り立つ条件。材料でも学ぶ順でもなく、`conditions` に書く。
- ポアソン分布の「平均 λ 回」の平均は、期待値の言い換え。

### 対比（比べる軸と違いの1文）

| 組 | 比べる軸 | 違い |
| --- | --- | --- |
| 二項分布 ⇄ ポアソン分布 | 回数の上限と、分散と平均の関係 | 二項は上限 n があり分散が平均より小さい。ポアソンは上限がなく分散と平均が等しい |
| 二項分布 ⇄ 幾何分布 | 何を決めて、何を数えるか | 二項は回数を決めて成功を数える。幾何は成功1回を決めて回数を数える |
| 二項分布 ⇄ 超幾何分布 | 取り出し方 | 二項は戻す（確率が一定）。超幾何は戻さない（確率が変わる） |

### 今の関係の行き先

| 関係 | 今 | 行き先 |
| --- | --- | --- |
| REL-rv-dist | 前提（mathematical） | 材料 |
| REL-dist-pdf | 前提（mathematical）確率分布 → 確率密度関数 | 向きを逆にして材料（確率密度関数 → 確率分布） |
| REL-pdf-normal・REL-pdf-uniform・REL-pdf-expo | 前提（mathematical） | 材料 |
| REL-comb-binom | 前提（mathematical） | 材料 |
| REL-rv-bernoulli | 前提（mathematical） | 学ぶ順（定義に確率変数の名前が出ない） |
| REL-indep-binom・REL-indep-geom | 前提（mathematical） | 学ぶ順（独立は成り立つ条件。`conditions` に書く） |
| 対比3本 | 対比 | axis を足す |
| 変換3本・一般化2本・導出1本 | そのまま | そのまま |

新しく足す材料の関係は13本：

- 確率 → 確率変数・確率分布・確率密度関数（3本）
- 確率変数 → 確率密度関数・共分散（2本）
- 期待値 → 共分散
- 確率 → ベルヌーイ分布・二項分布・幾何分布・負の二項分布（4本）
- 組合せ → 超幾何分布・負の二項分布（2本）
- 階乗 → ポアソン分布

ほかの分類にある語への関係（REL-rv-expect・REL-dist-expect・REL-cov-corr など）は、to の語の分類を移すときに扱う。

まとまり（D4）・材料にしない条件（D2）・種類0本（D3）・対比の軸（D1）は決まった（2026-11-06）。材料と行き先の表は、S3 で2人が別々に判定し、食い違いを渡辺さんが決めて確定する。
