# 品質基準（単元ごとに全部満たしてから公開する）

旧版を「移す」のではなく、この基準まで「引き上げる」。旧版の作り込み（例題・誤解・言い直し・仕事の場面）は全て残し、足りないものを足す。

## 0. 共通

- [ ] ゴールは1文で、**できたかどうかを判定できる行動**で書く（「理解する」ではなく「〜を見分けて言える」）
- [ ] 冒頭は「ナビ＋ゴール＋タブ」だけ
- [ ] 表は2〜3列。スマホ幅で横にはみ出さない
- [ ] **全段階に図かラボが1つ以上**ある（段階ごとに使い方の指示が違う）
- [ ] 本文と問題の数値は全て `checks` で検算され、build が通る
- [ ] 旧版との突き合わせ（`build/audit.py`）で、落とした項目は全て理由付きで記録
- [ ] 用語は ID でリンク。単元は `{{unit:}}` で参照（番号を直書きしない）
- [ ] 定義・主張は教科書的に正確。条件付きで成り立つことは条件を書く（「必ず」「常に」を安易に使わない）
- [ ] 問題は難度順。易は1ステップ、中は2ステップ、やや難は条件判断か説明を含む

## 1. 初学（知る・理解する）

- [ ] 0｜入口の問い：実務の場面で、まだ解けない問い
- [ ] 1｜前提チェック：3問以内、答えと戻り先付き
- [ ] 2｜意味：判断の質問（❓）と図。図には「何を読み取るか」を添える
- [ ] 3｜式の構造：記号・意味・この例の値の対応表。式を言葉で読む1文
- [ ] 4｜例題：全部解説 → 穴埋め → 自力 の3段
- [ ] 5｜実験：予想→操作→観察→説明→ラボなしで解く。答えは開閉
- [ ] 6｜自力確認：易・中・やや難の3問以上。力の印付き
- [ ] 7｜振り返り＋まとめ3行

## 2. 復習（定着させる）

- [ ] 翌日：思い出す3項目（答え付き）と図の再現
- [ ] 言葉にする練習：説明の型・お手本（条件／対象と結論／根拠／成り立たない場合）・言い直し練習・取り違えやすい言葉・自己チェック
- [ ] 約1週間後：問い方を変えた別問と計算練習
- [ ] 約1か月後：他の単元と混ぜた問題
- [ ] 早見表、ラボで確かめる課題、さらに解く（旧版の確認問題・本番形式への入口）

## 3. 応用（条件に合わせて使う）

- [ ] 判断の手順（毎回書く3点）
- [ ] 公式名を伏せた問題 5問以上（条件変更・少なくとも／含む・逆向きの問い・確率や推定への接続）
- [ ] 本番形式の5択 1問以上。**全ての誤答選択肢に「どう誤解したか」**
- [ ] 該当する章ではソフトの出力や図表の読み取り問題
- [ ] 使えない例と比べる（旧版の「よくある誤解」は全てここか復習に残す）

## 4. 転用（別の領域へ広げる）

- [ ] 同じ構造の場面の表 5場面以上（小売2つ以上、他の領域3つ以上）
- [ ] 図かラボで構造を見る課題
- [ ] 転用の問題 3問（うち仕事の場面1問）
- [ ] 転用チェック（3項目）

## 5. 発展（試験の外へ）

- [ ] 1級・大学数学への接続 2つ以上
- [ ] 他の学問との組み合わせ 2つ以上
- [ ] 確かめ問題 1問以上、ラボの使い方

## 6. 創造（新しい方法を生む）

- [ ] 課題 3つ以上（売場・判定の道具・新しい方法・他分野のうち3つ）
- [ ] 1つは「考え方の例」付き（開閉）で、小さい例での検証を見せる
- [ ] 検証に使うラボ、評価の観点、ChatGPT への批評依頼文

## 7. ラボ（シミュレーター）

- [ ] 旧版のラボの機能を下回らない
- [ ] モードを分け、段階ごとに使う場面がある
- [ ] 予想してから表示できる（答えを先に見せない）
- [ ] 乱数を使うものは「押すたびに揺れる」ことと理論値を並べて示す
- [ ] 380px 幅・ライト／ダークで崩れない。エラーが出ない（自動テスト）
- [ ] 表示する数値は別計算と一致する（自動テスト）
