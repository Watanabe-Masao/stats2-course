# 関係の種類の修正案（定義書 3 の改訂案）

2026-11-08 の案。#249・#256。採用が決まったら定義書（docs/relation-map.md）の 1・3・4 と relation-types.yaml を書き直し、この文書は検討の履歴として残す。型は v2（S7）。

## 0. 出発点

- 関係図とその関係の種類は、**概念どうしの関係**だけを表す。学ぶ順（何を先に知っておくとよいか）は表さない。学ぶ順は別に作る（渡辺さん 2026-11-08。#256）。
- 種類は、記号で書けるような**数学的・統計的な意味**から決める。1つの種類は1つの意味だけを持つ（画面の原則 8）。迷ったら「その線を書くと、何が数学的に言えるか」を問う。
- 記号（→・＝・≒・∴・∩ など）は意味を考えるための例えで、画面やデータの記号ではない。

## 1. 種類の一覧（案）

矢印は from → to で、読み方の □ に from、■ に to を入れる。

| 種類 | 意味 | 読み方 |
| --- | --- | --- |
| 種類 | A は B の一種（B の定義を満たし、性質や目的で B の中から区別したもの） | □ は ■ の一種 |
| 特別な場合 | A は B の母数・引数を決めた場合（B の式に値を入れると A になる） | □ は ■ の特別な場合 |
| 定義に使う | A は B の基準の定義の直接の構成要素 | □ は ■ の定義に使われる |
| 主張に使う | A は定理・性質 B の主張の中に出る（B が何を言っているかに A が要る） | □ は ■ の主張に使われる |
| 導出 | A（と成立条件）から B が導ける | □ から ■ が導ける |
| 変換 | A に決まった操作・極限をとると B に移る（厳密・近似・極限を分ける） | □ を変換すると ■ |
| 対比 | A と B は似ていて取り違えやすい。比べる軸で違う | □ と ■ を比べる |

7種類。今の定義書の7種類からの差は、一般化 → 特別な場合（意味を狭めて言い直す）・応用を外す・主張に使うを足す、の3つ。

### 線にしないもの

| もの | 理由 | 置き場所 |
| --- | --- | --- |
| 同じ意味の2つ（A＝B） | 本当に同じなら、2つの点にしない | 1つの概念にまとめ、別の名前は別名にする |
| 同値な別の定義 | 1つの概念の、言い換えた定義 | 概念の「別の定義」（必要になったら概念の欄に足す） |
| 成立条件（B は C のもとで成り立つ） | 概念・関係の性質で、2つの概念のつながりではない | 概念・関係に添える（要件・仮定・目安） |
| 学ぶ順（A を知ってから B） | 関係ではなく学び方 | 学ぶ順の画面（#256） |
| 仲間（同じまとまり） | 関係ではなく、分類の中の組 | まとまり |

## 2. 種類ごとの決まり

### 種類
- **意味：** B の定義をすべて満たし、性質や目的で B の中の1つとして区別できるのが A。
- **該当する例：** 推定量 → 統計量（母数を推定する目的の統計量）、適合度検定 → カイ二乗検定（カイ二乗検定が教材にあるとき）。
- **該当しない例：** 母数に値を入れただけのもの（ベルヌーイ分布 → 二項分布）は特別な場合。
- **数：** 1つの概念の種類の親は、多くて1つ。

### 特別な場合（今の一般化）
- **意味：** B の式の母数・引数に値を入れる（決める）と A になる。A は B に含まれるが、性質や目的で区別したものではない。
- **該当する例：** ベルヌーイ分布 → 二項分布（n＝1）、幾何分布 → 負の二項分布（r＝1）、分散 → 共分散（Y＝X）、単回帰 → 重回帰分析（説明変数が1つ）、平均 → 期待値（データの出た割合を確率とする分布の期待値）。
- **書くもの：** どの母数・引数を何に決めるか（`fix`。例：n＝1）。
- **向き：** 特別な場合 → 一般の形。逆向き（一般化）は書かない（今の特殊化は外す）。
- **種類との違い：** 種類は「どんな性質・目的のものか」で区別する。特別な場合は「どの値に決めたか」で区別する。

### 定義に使う（型の名前は材料）
- 今の定義書 3 の材料のまま（基準の定義の直接の構成要素だけ・1段だけ・定義の依存の輪は build が止める）。
- 応用から移るもの：推定量 → 点推定、期待値 → 期待度数。

### 主張に使う（新しく足す。#249 ②）
- **意味：** 定理・性質 B の主張（何を言っているか）の中に A が出る。A がなければ B の主張を言えない。
- **該当する例：** 正規分布 → 中心極限定理（和や平均の分布が正規分布に近づく、と言う）、不偏性 → 不偏分散（不偏分散の期待値は母分散に等しい、と言う）。
- **該当しない例：** 主張が成り立つための条件（独立・分散が有限）は、成立条件（仮定）に書く。
- **定義に使うとの違い：** 定義に使うは「B とは何か」の構成要素。主張に使うは「B について何が言えるか」の構成要素。
- **向き：** 定義に使うと同じ（使われる概念 → それを使う定理・性質）。

### 導出
- 今の決まりのまま。前提が2つ以上なら導出の点（DER-…）にする。成り立つための条件は成立条件（仮定）に書く。
- **該当する例：** 独立 → 共分散（独立なら共分散は0。逆は成り立たない）、条件付き確率 → 乗法定理、確率 → 加法定理、ポアソン分布 → 指数分布。

### 変換
- 今の決まりのまま（`mode`）。画面の札の言い方を直す。
  - **厳密：** 決まった操作で、誤差なくちょうど移る（二項分布 → 標本比率：X を n で割る。事前確率 → 事後確率：ベイズの定理）。
  - **近似：** 有限のままで近い。近いと言える目安を成立条件（目安）に書く（二項分布 → 正規分布）。
  - **極限：** 条件を保って進めると近づく。保つ条件と進め方を成立条件（仮定）に書く（二項分布 → ポアソン分布）。
- **行き先：** 近づく先が教材にない概念のとき（t 分布 → 標準正規分布）は、行き先を札の文で言う（正規分布一般とは書かない）。

### 対比
- 今の決まりのまま（比べる軸・同じ所・違う所）。

## 5. 決めること

1. **手段（A は B をするための道具）を種類として持つか。** 応用の4本（標準化・標本比率・偏相関係数・ダミー変数）は「定義に使う」「主張に使う」のどちらとも言い切れず、「A を使うと B ができる・分かる」という関係。
   - 案 a：手段を8つ目の種類にする（□ は ■ に使う手段）。
   - 案 b：持たない。概念のページの本文（説明・例）で書き、線にしない。
2. **同値な別の定義を、概念の欄に持つか。**（今は該当がないので、要るときに足す、でよいか）
3. **一般化の名前を「特別な場合」に変えるか。** 意味は「母数を決めた場合」に狭める。画面の呼び名は、受ける側（一般の形のページ）が「特別な場合」、出す側が「一般の形」。
