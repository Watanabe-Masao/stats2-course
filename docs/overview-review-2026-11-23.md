- 新つまり：4日の売上 10・10・10・30（万円）を1つの箱に集めて、4日に同じだけ配り直す。配り直したあとの1日分と、もとの4日の値を比べる。
- 問いで考えてほしいこと：同じだけ分けたら1つあたりいくつか
- つまりで渡す手掛かり：集めて配り直す・もとの値と比べる
- 読んだあとも残る判断：1日分の求め方・大きな値に引っぱられること
- 直後の定義で初めて分かること：x̄＝合計÷n の形
- 削ると失われる説明と、残る場所：旧文の「1つの大きな値にも引っぱられる」は誤解の欄で追える
- 成立条件を1つ外した例と、読み取られ方：足すことに意味のない値：文案は売上なので当たらない
- 判定と理由：要修正 → 文案に差し替え。レビューで直した：例の欄と同じ場面だったので変え、大きな値に引っぱられることが見える数にした

## 尺度（TERM-scale）

- 問い：その値では、差や比を計算してよい？
- 旧つまり：値について、どの比べ方・計算に意味があるかで分けた4つの段階。名義（同じか違うか）・順序（大小）・間隔（差）・比例（比）で、上の段階は下の段階の比べ方を全部含む。
- 新つまり：会員番号、満足度（1〜5の5段階）、気温（℃）、来店客数が1つの表に並んでいる。どれも数字で書けるが、差や「2倍」が意味をもつかは列ごとに違う。
- 問いで考えてほしいこと：その値で差や比を計算してよいか
- つまりで渡す手掛かり：4つの列・数字でも意味が違う
- 読んだあとも残る判断：列ごとにどの計算に意味があるか
- 直後の定義で初めて分かること：名義・順序・間隔・比例の4つの段階
- 削ると失われる説明と、残る場所：旧文の4段階の一覧は定義の欄で追える
- 成立条件を1つ外した例と、読み取られ方：0 が「無い」でない量（℃）：文案は気温を入れたので、比に意味がない例を考えられる
- 判定と理由：要修正 → 文案に差し替え（例の欄の店番・鮮度ランクと変えた）

## データの標準偏差（TERM-data-sd）

- 問い：データの散らばりを、元の単位で言うと？
- 旧つまり：データの分散の平方根で、平均からおよそどれくらい離れるかを元の単位で表す。
- 新つまり：店の7日の来店客数で分散を出すと、単位は「人の2乗」になる。平均のまわりの散らばりを、何人くらいと言いたい。
- 問いで考えてほしいこと：データの散らばりを元の単位で言うには
- つまりで渡す手掛かり：分散の単位が2乗
- 読んだあとも残る判断：どう戻すか（平方根）
- 直後の定義で初めて分かること：データの分散の正の平方根と呼ぶこと
- 削ると失われる説明と、残る場所：旧文は定義の言い換えで、失われる説明はない
- 成立条件を1つ外した例と、読み取られ方：差に意味のない値：文案は販売数なので当たらない
- 判定と理由：要修正 → 文案に差し替え。レビューで直した：例の欄（売場の5日）と同じ場面だったので変えた

## 母数（TERM-parameter）

- 問い：標本を取り直すと、母集団の平均も変わる？
- 旧つまり：母集団の性質を表す数（母平均・母分散・母比率など）。母集団の全部の値から1つに決まる数で、標本を取り直しても変わらないが、全部を調べない限り分からない。
- 新つまり：今月の全レシートから50枚を選んで平均購入額を出し、別の50枚を選んでもう一度出す。2つの平均と、全レシートを集計したら出る平均が、それぞれ何で決まるかを考える。
- 問いで考えてほしいこと：標本を取り直すと母集団の平均も変わるか
- つまりで渡す手掛かり：選び直す2つの平均・全部を集計した平均
- 読んだあとも残る判断：どれが変わり、どれが変わらないか
- 直後の定義で初めて分かること：母集団の性質を表す数で、全部を調べない限り分からないこと
- 削ると失われる説明と、残る場所：旧文の「取り直しても変わらない」は答えにあたるので外した。誤解の欄で追える
- 成立条件を1つ外した例と、読み取られ方：どの母集団か決まっていない：文案は今月の全レシートと決めるので当たらない
- 判定と理由：要修正 → 文案に差し替え（例の欄の 1万枚・100枚と変えた）
