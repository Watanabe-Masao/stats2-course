| 語 | 理由 |
| --- | --- |
| 四分位数 | 区切り方を決めないと値が1つに定まらない語。1つの決め方で描いた箱は、その違いを隠す |
| クロス集計表 | 表そのものが図。棒にすると行・列の比べ方が消える |
