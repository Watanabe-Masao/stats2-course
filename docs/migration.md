# 旧版からの移行手順

旧版（Notion の教科書ページ）を、品質基準（docs/quality.md）を満たす原本に作り直す。1単元ずつ、次の順で進める。

## 手順

1. **旧版を保存**：Notion から取得した本文を `migration/old/<ID>.md` に保存する（突き合わせの基準）。
2. **棚卸し**：`migration/<ID>.yaml` に、旧版の素材（図・ラボ・問題・誤解・言い直し・仕事の場面・リンク）と、新しい段階のどこに置くかを書く。
3. **設計**：段階ごとに「何ができるようになるか」と「置くもの」を決め、足りないもの（転用・発展・創造・ラボのモード）を洗い出す。
4. **原本を書く**：本文（S1〜S6）・問題（ID・検算式・誤答の理由）・unit.yaml。
5. **ラボ**：旧版の機能を下回らない新ラボを tools/ に作り、自動テストを通す。
6. **検査**：`python3 build/build.py`（検証・検算）→ `python3 build/audit.py <ID>`（旧版の数値・太字・誤解が残っているか）→ 品質基準のチェック。
7. **公開**：Notion の「教材 v2」に生成し、publish/notion.yaml に登録。旧版ページは消さない。
8. **記録**：単元一覧（content/units/index.yaml）の migrated を true にし、コミット。

## 旧版の構成と新しい段階の対応

| 旧版 | 新しい置き場 |
| --- | --- |
| 🌱 はじめて | 初学（前提チェック・式の構造・例題の段階化・実験の手順を追加） |
| 🔁 復習 | 復習（翌日／1週間後／1か月後に分ける） |
| 🔍 深める | 復習の「言葉にする練習」。「もう一段深く」「よくある誤解」は応用か復習へ |
| 🚀 応用 | 試験に出る問題→応用、仕事の場面→転用、発展的な話題→発展 |
| （なし） | 転用・発展・創造は新しく作る |
| 16章以降の節構成 | 内容ごとに段階へ割り振る（節の本文は初学、例題は初学か応用、自力確認は復習か応用） |
