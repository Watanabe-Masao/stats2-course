# 教科書31｜標本調査・調査誤差・バイアス

## 学習の目標

抽出方法・標本誤差・非標本誤差を区別し、調査の偏りを診断する。

## ✨ 例題で式を読み解く

**この式を使う場面**　大きさの違うグループ（層）から別々に調べた結果を、**全体の平均**にまとめるとき。層ごとの人数の比で重みを付ける。

### 📝 例題

全100店のうち大規模店20店・小規模店80店。各層から10店ずつ調べると、平均売上は大規模200万円、小規模50万円だった。全店の平均売上を推定せよ。

### 🧩 式のどこに何を入れる？

$$
\bar x_{st}=\sum_h\frac{N_h}{N}\bar x_h
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **h** | 層の番号：大規模・小規模 |
| **N_h** | 各層の**母集団**の店数：20店、80店（調べた10店ではない） |
| **N** | 全店数：100 |
| **x̄_h** | 各層の標本平均：200、50 |

### 🧮 計算

1. 重み：20/100＝0.2、80/100＝0.8
2. 0.2×200＋0.8×50＝40＋40＝**80万円**
3. 誤り：調べた20店をそのまま平均 (200＋50)/2＝125 → 大規模店を過大評価

横幅＝層の構成比。面積を全体にならした高さが全体平均

| 誤差の種類 | 原因の例 | n を増やすと |
| --- | --- | --- |
| 標本誤差 | たまたま選ばれた標本の違い | 小さくなる |
| カバレッジ誤差 | 抽出枠の漏れ（17） | 変わらない |
| 無回答・自己選択 | 答える人が偏る | 変わらない |
| 測定誤差 | 設問の誘導・記入ミス | 変わらない |

**混同注意**　層化抽出＝**全ての層**から少しずつ選ぶ。集落抽出＝**いくつかの集団**を選んで中を全部調べる。また、回答数1万人でも自己選択なら偏りは消えない。

**答えの読み方**　全店の平均売上は約80万円。層化して重みを正しく付けると、少ない調査数でも層の構成を反映した推定ができる。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。そのあと確認問題へ。

層の割合 w を動かすと、正しい加重平均と「無重みの平均」のずれが変わります。

もう一つ：抽出枠の漏れ（カバレッジ誤差）は非標本誤差。標本を増やしても偏りは残り、総合誤差（RMSE）の下限になります。

## 1｜まず意味をつかむ

標本誤差は標本を取り直すことで統計量が変わること。非標本誤差はカバー漏れ、無回答、測定、設問、転記等による誤り。回答数を増やせば全ての誤りが小さくなるわけではない。

単純無作為以外にも、目的・費用・集団構造に応じた抽出法がある。層化は各層から取る、クラスターは集団を選ぶという違いを押さえる。多段は複数段階で抽出し、重みや依存構造を解析へ反映する。

## 2｜式と記号を読む

$$
\bar x_{st}=\sum_h\frac{N_h}{N}\bar x_h
$$

```txt
抽出設計・包含確率・回答率・重みを確認
異なる層の母平均μ=Σ_h (N_h/N) μ_h
標本誤差の小ささ ≠ 偏りの小ささ
```

## 3｜表で関係を整理する

| 方法 | 基本動作 | 注意 |
| --- | --- | --- |
| 系統抽出 | 無作為な開始点から一定間隔 | 名簿の周期と一致しないか |
| 層化抽出 | 層を作り各層から抽出 | 全体集計で層の重み |
| クラスター抽出 | 店舗・地域等の集団を抽出 | 集団内の類似による依存 |
| 多段抽出 | 地域→店舗→顧客等 | 各段の確率と重み |

## 4｜例題を途中から追う

大規模店20店・小規模店80店で、それぞれ平均売上200と50なら全体平均は0.2×200+0.8×50=80。各層から同じ数を調査し、無重みで平均125とすると構成を取り違える。

ネット調査で80%賛成でも、自己選択・無回答・対象のカバー範囲を確認する。人数が1万人でも対象全体の80%と直結しない。

## 5｜誤解と適用条件を確認する

系統抽出を最初から固定の1番目で始めるだけでは無作為開始ではない。観察研究と実験研究を区別。公的統計では調査票・定義・対象期間・集計単位・改定を読む。
