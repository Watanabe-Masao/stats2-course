# 教科書01｜割合・分数・式の変形

この章で答えられるようになること：「何%」と言われたとき、何を基準（分母）にした割合かを言え、基準量の逆算・増減の重ね合わせ・簡単な式の変形ができる。

このページの用語：割合・パーセントポイント

## はじめて

### ステップ1｜まず「何の」を探す

<b>「〇〇の何%」</b>と書いてあったら → <b>〇〇が分母（基準量）</b>
<b>「何%増えた／減った」</b>と書いてあったら → <b>倍率</b>（20%増＝1.2倍、20%減＝0.8倍）に直す

### ステップ2｜割合の式

割合＝部分÷基準量 ⇒ 基準量＝部分÷割合

| 表現 | 意味 |
| --- | --- |
| 30パック中6パック | 6÷30＝0.2＝20% |
| 20%増 | 1.2倍 |
| 20%減 | 0.8倍 |
| 10%→12% | 2ポイント増（相対的には20%増） |

### ステップ3｜例題で逆算する

原価800円の商品。原価が「売価の80%」になるように売価を決めたい。売価はいくらか。また、その売価を20%上げた後に20%下げるといくらか。

1. 「売価<b>の</b>80%が原価」→ 基準量は売価 P：0.8×P＝800
2. 両辺を0.8で割る：P＝800÷0.8＝<b>1,000円</b>
3. 20%上げる：1,000×1.2＝1,200円
4. そこから20%下げる：1,200×0.8＝<b>960円</b>（元に戻らない）

（図：下げるときの基準は1,200円。増減を重ねるときは倍率を掛け続ける）

<b>ここが一番大事</b>　800×1.2＝960円 としてしまうのは「原価の120%」で、基準が違う。割合を読むときは、<b>まず分母が何かを確かめる</b>。

### ステップ4｜動かして確かめる

（ラボ：ratio.html）

<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「＋20%→−20% にすると 1.2×0.8＝0.96 で、元より4%少なくなった」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　客200人のうち50人が購入した。購入率は何%か。
答え：50÷200＝0.25＝<b>25%</b>。基準量は来店客200人。

<b>問2（中）</b>　原価900円が売価の75%になるとき、売価はいくらか。
答え：0.75×P＝900 → P＝900÷0.75＝<b>1,200円</b>。

<b>問3（やや難）</b>　数量が 200→180→198 と変わった。各期の増減率と累計の増減率を求めよ。
答え：200→180：<b>−10%</b>（基準200）。180→198：18÷180＝<b>＋10%</b>（基準180）。累計 198÷200−1＝<b>−1%</b>（0.9×1.1＝0.99）。分母が違うので−10%と＋10%は打ち消し合わない。

<b>まとめ（3行）</b>
1. 割合＝部分÷基準量。「〇〇の」の〇〇が基準量。
2. 基準量＝部分÷割合 で逆算できる。
3. 増減を重ねるときは倍率を掛ける。足し算はしない。

## 復習

### 思い出す（何も見ずに答える）

- 「売価の80%」の基準量を言える
- ＋20%→−20% の結果を倍率で言える
- 「%」と「ポイント」の違いを言える

答え：
1. 売価。
2. 1.2×0.8＝0.96 で4%減。
3. 10%→12% は2ポイント増。相対的には (12−10)÷10＝20%増。

### 式の早見

| 求めるもの | 式 |
| --- | --- |
| 割合 | 部分÷基準量 |
| 基準量 | 部分÷割合 |
| 増減後 | 元×(1＋増減率) |
| 式の変形 | a÷b＝c なら a＝b×c（b≠0） |

### 1問で確かめる

<b>問</b>　3x＋6＝21 を解け。
答え：両辺から6を引いて 3x＝15、両辺を3で割って <b>x＝5</b>。両辺に同じ操作をすれば等式は保たれる。

## 深める

### お手本：20%上げて20%下げても戻らない理由

- <b>条件</b>：ある値を20%上げ、その後20%下げるとき
- <b>対象と結論</b>：結果は元の値より4%小さくなる
- <b>根拠</b>：下げるときの基準は上げた後の値（元の1.2倍）なので、倍率で 1.2×0.8＝0.96 になるから
- <b>成り立たない場合</b>：「元の値の20%分」を足して引く（基準を固定する）なら元に戻る

つなげると：「20%上げてから20%下げると、元の値の96%になる。下げるときの基準は上げた後の大きい値なので、倍率は 1.2×0.8＝0.96 だからである。ただし両方とも元の値を基準にするなら元に戻る。」

### 言葉の使い分け

<b>「%」と「ポイント」</b>
- %（相対的な変化）：10%→12% は20%増
- ポイント（差）：10%→12% は2ポイント増

<b>「原価率」と「値入率」</b>
- 原価率：原価÷売価
- 値入率（マークアップ）：利益÷原価 など、基準の取り方は場面で違うので必ず確かめる

### 言い直し練習

「購入率が10%から12%になったので、2%改善しました。」

<b>直す点</b>
- 「2%」だと、10%の2%（＝0.2ポイント）と誤解される。
- 差なら「ポイント」、相対的な変化なら「20%」。

<b>言い直しの例</b>
「購入率が10%から12%になり、2ポイント改善した。元の購入率に対しては20%の改善である。」

### 自己チェック（説明を書いたら）

- 割合の分母（基準量）を明記した
- 増減を重ねるとき倍率を掛けた
- % とポイントを区別した
- 分母が0になる場合を考えた

### よくある誤解

- 割合だけ分かれば十分 → ✕。分子・分母（件数）も記録しないと比較を誤る。
- 基準が0でも増減率は計算できる → ✕。0では割れないので「10個増」のように差で表す。

## 応用

### 統計の式でも「何で割っているか」

| 式 | 割っているもの |
| --- | --- |
| 平均 Σx÷n | 件数 |
| z得点 (x−μ)÷σ | 標準偏差 |
| 検定統計量 (x̄−μ)÷SE | 標準誤差 |
| 変動係数 s÷x̄ | 平均 |

統計の式で分数が出てきたら、分母が何かを最初に確かめる。それがこの章の一番の応用。

### 仕事の場面で

- 粗利率＝粗利÷売上。「売上の何%が粗利か」を表す。値入率と分母が違うので、会議では式を一緒に示す。
- 前年比120%と「20%増」は同じ意味。前年比80%なら20%減。
