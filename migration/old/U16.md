# 教科書16｜連続分布・正規分布・標準化

## 学習の目標

連続型の確率を面積として読み、正規・一様・指数を使い分ける。

## ✨ 例題で式を読み解く

**この式を使う場面**　重さ・時間・客数などの量が「**〇〇以上**」「**〇〇の間**」になる確率。正規分布なら「標準化して表を引く」が基本の流れ。

### 📝 例題

1日の来店客数は平均100人・標準偏差10人の正規分布に従う。① 90人以上110人以下の確率　② 120人を超える確率　を求めよ。

### 🧩 式のどこに何を入れる？

$$
Z=\frac{X-\mu}{\sigma}\qquad P(a\le X\le b)=\Phi(z_b)-\Phi(z_a)
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **μ** | 平均100人 |
| **σ** | 標準偏差10人 |
| **a, b** | 区間の端：90人、110人（②は120人） |
| **Φ(z)** | 標準正規分布で z 以下になる確率（分布表で引く） |

### 🧮 計算

1. 標準化：90 → (90−100)/10＝−1、110 → ＋1
2. 表より Φ(1)＝0.8413、Φ(−1)＝0.1587
3. ① 0.8413−0.1587＝**0.6827（約68%）**
4. ② 120 → z＝2、P(Z>2)＝1−Φ(2)＝1−0.9772＝**0.0228（約2.3%）**

図：連続分布では「面積＝確率」。曲線の高さそのものは確率ではない

| 平均からの幅 | 入る確率（正規分布） |
| --- | --- |
| ±1σ | 約68.3% |
| ±1.96σ | 95% |
| ±2σ | 約95.4% |
| ±3σ | 約99.7% |

**答えの読み方**　だいたい3日に2日は90〜110人。120人を超える日は50日に1日程度。ただし実際の客数が正規分布に従うかは、ヒストグラム（05）で確かめる。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。

（正規分布のシミュレーター、指数分布のシミュレーター）

もう一つ：連続型のもう一つの代表、指数分布。すでに待った時間 s を増やしても、そこから先の確率は変わりません（無記憶性）。

## 1｜まず意味をつかむ

連続型では確率密度f(x)の高さ自体は確率でなく、区間の面積が確率。密度の全積分は1、単一点の確率は0。累積分布F(x)=P(X≤x)から、区間確率F(b)−F(a)を求める。

正規分布は平均μを中心に左右対称で、分散σ²が広がりを決める。Z=(X−μ)/σで標準正規へ変換し、分布表のどの面積が記載されているかを確認する。

## 2｜式と記号を読む

$$
P(a<X\le b)=F(b)-F(a)
$$

```txt
X~N(μ,σ²)なら Z=(X−μ)/σ~N(0,1)
一様U(a,b): f(x)=1/(b−a)、E=(a+b)/2、Var=(b−a)²/12
指数（率λ）: P(X>t)=e^(−λt)、E=1/λ、Var=1/λ²
```

## 3｜表で関係を整理する

| 分布 | 主なモデル | 注意 |
| --- | --- | --- |
| 正規 | 対称な連続量 | 左右に無限の範囲 |
| 一様 | 区間で同じ密度 | 区間幅で確率が決まる |
| 指数 | 一定率での待ち時間 | 0以上、無記憶性を持つ |

## 4｜例題を途中から追う

平均100・SD10の正規で90≤X≤110なら−1≤Z≤1。Φ(1)=0.84134、Φ(−1)=0.15866を与えると確率0.68268。

一様U(0,10)で2〜5の確率は幅3/10=0.3。指数率2/時間で1時間超の待ちはe^(−2)≒0.135335。率が一定でない待ち時間へ無条件に使わない。

### 関連する公式範囲の内容

2変量正規は2変数を同時に正規モデル化し、2つの平均・分散と相関ρで関係を表す。各変数が正規であるだけで同時正規とは限らない。同時正規では無相関ρ=0なら独立。一般の分布にこの含意を広げない。

## 5｜誤解と適用条件を確認する

分散とSDの引数を取り違えない。標準化だけで元の分布は正規にならない。指数分布の率λと尺度1/λを区別する。

## 6｜自力で確かめる

X~N(50,5²)の60のz得点は。一様U(2,8)で3〜5の確率は。

解答：z=2。区間の幅2/全幅6=1/3。
