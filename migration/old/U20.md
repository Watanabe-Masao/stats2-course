# 教科書20｜標準誤差・t分布・カイ二乗分布・F分布

## 学習の目標

z・t・χ²・Fを、統計量と自由度から使い分ける。

## ✨ 例題で式を読み解く

**この式を使う場面**　母集団の標準偏差 σ が**分からない**ので、データから計算した s で代用して平均を標準化するとき。

### 🧭 どの分布を使う？

| 調べたいもの | 統計量 | 分布 |
| --- | --- | --- |
| 平均（σ既知） | z | 標準正規 |
| 平均（σ未知） | t | t(n−1) |
| 分散 | (n−1)s²/σ² | χ²(n−1) |
| 2つの分散の比 | s₁²/s₂² | F(n₁−1, n₂−1) |

### 📝 例題

新レイアウトの16店舗で客単価の平均は52百円、不偏分散から求めた標準偏差 s は8百円。従来の平均は50百円。t値と自由度を求め、両側5%の基準と比べよ。

### 🧩 式のどこに何を入れる？

$$
T=\frac{\bar x-\mu_0}{s/\sqrt n}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **x̄** | 16店舗の平均：52 |
| **μ₀** | 比べる基準（従来の平均）：50 |
| **s** | データから計算した標準偏差：8 |
| **n** | 店舗数：16 → 自由度 n−1＝15 |
| **s/√n** | 平均の標準誤差 |

### 🧮 計算

1. SE＝8/√16＝8/4＝**2**
2. t＝(52−50)/2＝**1.0**、自由度 **15**
3. 両側5%の点：t(15) の左累積0.975 ＝ **2.131**
4. |1.0| < 2.131 → 差は誤差の範囲内と判断

図：自由度が小さいほど裾が厚く、基準値（確率点）が大きくなる

**よくある間違い**　分母に s＝8 をそのまま入れて t＝0.25 としない（SEは s/√n）。また本教材の確率点は**左側累積**：z₀.₉₇₅＝1.96 が「上側2.5%点」。

**答えの読み方**　2百円の差はSE（2百円）のちょうど1つ分。16店ではこの程度の差は偶然でも十分起こる。差を検出したいならnを増やす。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。

t・χ²・F を切り替え、自由度を動かすと分布の形と基準値（確率点）が変わります。23・25・26の基準値もここで確かめられます。

## 1｜まず意味をつかむ

標準誤差SEは統計量の標本間変動の大きさ。母SDが未知ならデータからSEを推定する。正規母集団で平均を標準化すると、母SD既知ならz、未知なら推定SDを使ったtになる。tは小自由度で正規より裾が厚い。

χ²は独立な標準正規の2乗和、Fは独立なχ²をそれぞれ自由度で割った比。平均・分散・分散比で異なる統計量を使う理由をつなぐ。

## 2｜式と記号を読む

$$
T=\frac{\bar X-\mu}{s/\sqrt n}\sim t_{n-1}
$$

```txt
Z=(X̄−μ)/(σ/√n)
T=(X̄−μ)/(s/√n) ~ t(n−1)
Q=(n−1)s²/σ² ~ χ²(n−1)
独立2群で (s1²/σ1²)/(s2²/σ2²) ~ F(n1−1,n2−1)
```

## 3｜表で関係を整理する

| 分布 | 範囲・形 | 主な用途 |
| --- | --- | --- |
| 標準正規 | 左右対称 | 母SD既知の平均など |
| t | 対称・厚い裾 | 母SD未知の平均 |
| χ² | 0以上・非対称 | 母分散 |
| F | 0以上・非対称 | 分散比・分散分析 |

## 4｜例題を途中から追う

n=16、標本平均52、s=8、母平均50の検定統計量はt=(52−50)/(8/4)=1、自由度15。SEは2で、s=8とは違う。nを4倍にすると、同じ母分散の下で平均のSEは半分。

本教材では分位点q_pを『左側累積確率p』で定義する。標準正規q_0.975≈1.96は上側確率0.025の点。『上側5%点』ならq_0.95。表の見出しを確認する。

## 5｜誤解と適用条件を確認する

tは母SDが未知なら全状況で厳密、ではない。正規性等の条件や大標本近似を確認。Fの分子・分母の自由度を逆にしない。χ²やFは左右対称ではない。

## 6｜自力で確かめる

n=25、x̄=12、s=5、H0:μ=10のt値と自由度は。両側5%検定で参照するtの左累積確率は。

解答：t=2、自由度24、左累積0.975の点と|t|を比較。
