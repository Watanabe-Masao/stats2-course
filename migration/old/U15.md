# 教科書15｜ポアソン分布・離散分布の判断

この章で答えられるようになること：「何を数えているか」から、二項・ポアソン・幾何・超幾何の中で使う分布を選べる。「1時間に何件」の確率をポアソン分布で求められる。

このページの用語：ポアソン分布・幾何分布・超幾何分布・二項分布・期待値

## はじめて

### ステップ1｜何を数えるかで分布を選ぶ

<b>n 回中の成功回数</b>（回数が決まっている） → <b>二項分布</b>（教科書14）
<b>一定時間・範囲の発生件数</b>（上限なし、独立に起きる） → <b>ポアソン分布</b>
<b>初めて成功するまでの回数</b> → <b>幾何分布</b>
<b>戻さずに引いたときの当たり数</b> → <b>超幾何分布</b>

### ステップ2｜ポアソン分布の式

P(X＝k)＝e^(−λ)λᵏ÷k!

| 記号 | 意味 |
| --- | --- |
| λ | その区間の平均件数（1時間なら2、30分なら1） |
| k | 確率を知りたい件数 |
| e | 約2.718の定数（e⁻²≒0.135） |

平均も分散も λ になるのが特徴。

### ステップ3｜例題で計算する

問い合わせは1時間に平均2件。① ある1時間に0件の確率　② 30分間に0件の確率　③ 1時間に3件以上の確率　を求めよ。

1. ① λ＝2、k＝0：e⁻²×2⁰÷0!＝<b>0.135</b>
2. ② 30分なので λ＝1：e⁻¹＝<b>0.368</b>（λは区間の長さに合わせて変える）
3. ③ 1件：e⁻²×2÷1＝0.271、2件：e⁻²×4÷2＝0.271
4. 3件以上＝1−(0.135＋0.271＋0.271)＝1−0.677＝<b>0.323</b>

（図：平均2件なので 1件・2件が最も起こりやすく、右に裾が伸びる）

<b>ここが一番大事</b>　平均2件でも、約14%の時間は0件、約32%の時間は3件以上。人員配置は「平均」ではなく「多い時間帯の確率」で考える。

### ステップ4｜動かして確かめる

（ラボ：sim_poisson.html）

<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「時間 t を2倍にすると λ も2倍になり、0件の確率は e⁻² から e⁻⁴ に下がった」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　次の数え方に合う分布は？　(a) 1日に届く苦情の件数　(b) 10人中の購入者数　(c) 初めて当たりが出るまでのくじの回数
答え：(a) <b>ポアソン分布</b>、(b) <b>二項分布</b>、(c) <b>幾何分布</b>。

<b>問2（中）</b>　1日に平均3件の返品がある（ポアソン分布）。ある日に返品が1件以下の確率は？（e⁻³≒0.0498）
答え：P(0)＝0.0498、P(1)＝0.0498×3＝0.1494。合計 <b>0.199</b>（約20%）。

<b>問3（やや難）</b>　不良率0.2%の商品を1000個検品する。不良がちょうど2個の確率を、ポアソン近似で求めよ（e⁻²≒0.135）。
答え：二項分布 B(1000, 0.002) は n が大きく p が小さいので、λ＝np＝<b>2</b> のポアソン分布で近似できる。P(2)＝e⁻²×2²÷2!＝0.135×2＝<b>0.271</b>。

<b>まとめ（3行）</b>
1. 「何を数えるか」で分布を選ぶ：回数固定→二項、区間の件数→ポアソン、初成功まで→幾何、戻さない→超幾何。
2. ポアソン：P(X＝k)＝e^(−λ)λᵏ÷k!。平均＝分散＝λ。
3. λ は区間の長さに比例させる。n大・p小の二項は λ＝np で近似。

## 復習

### 思い出す（何も見ずに答える）

- ポアソン分布の平均と分散を言える
- 1時間平均2件のとき、30分の λ を言える
- 幾何分布の期待値を言える

答え：
1. どちらも λ。
2. 1。
3. 1/p（成功した回も数える場合）。

### 分布の早見

| 分布 | 固定する量 | 数えるもの |
| --- | --- | --- |
| 二項 | 試行回数 n | 成功回数 |
| ポアソン | 時間・面積などの区間 | 発生件数 |
| 幾何 | 成功1回 | そこまでの試行回数 |
| 負の二項 | 成功 r 回 | そこまでの試行回数 |
| 超幾何 | 母集団の構成と抽出数 | 戻さず引いた成功数 |

### 1問で確かめる

<b>問</b>　1時間平均2件で、1時間にちょうど1件の確率は？
答え：e⁻²×2÷1!＝0.135×2＝<b>0.271</b>。

## 深める

### お手本：問い合わせ件数にポアソン分布を使う理由

- <b>条件</b>：問い合わせが互いに独立に、一定の平均率で起きるとき
- <b>対象と結論</b>：一定時間の問い合わせ件数は、平均 λ のポアソン分布で表せる
- <b>根拠</b>：時間を細かく区切ると、各瞬間に1件起きるかどうかの小さな確率の試行が非常に多く並んだもの（n大・p小の二項分布）とみなせるから
- <b>成り立たない場合</b>：時間帯で平均率が大きく変わる、または1件が次の件を呼ぶ（まとめて来る）ときは当てはまりにくい

つなげると：「問い合わせが独立に一定の平均率で起きるなら、一定時間の件数はポアソン分布で表せる。時間を細かく区切ると、小さな確率の試行がたくさん並んだ二項分布とみなせるからである。ただし時間帯で率が変わったり、まとめて起きたりする場合は当てはまりにくい。」

### 言葉の使い分け

<b>「二項分布」と「ポアソン分布」</b>
- 二項：回数 n が決まっていて、成功回数に上限 n がある
- ポアソン：区間を決めて数え、件数に上限がない

<b>「試行回数」と「失敗回数」</b>
- 幾何分布は「成功した回も含めた試行回数」で数える流儀と、「失敗の回数」で数える流儀がある
- 平均の式が 1/p と (1−p)/p でずれるので、問題文の定義を確かめる

### 言い直し練習

「1時間に平均2件なので、30分でも平均2件です。1時間に3件以上来ることはめったにありません。」

<b>直す点</b>
- λ は区間の長さに比例する。30分なら平均1件。
- 3件以上の確率は約32%で、「めったにない」とは言えない。

<b>言い直しの例</b>
「1時間に平均2件なら、30分では平均1件である。1時間に3件以上来る確率は約32%あり、3回に1回ほどは起きるので、その時間帯の人員を考えておく必要がある。」

### 自己チェック（説明を書いたら）

- 何を数えているか（回数・件数・試行数）を書いた
- λ を区間の長さに合わせた
- 独立・一定の率という前提に触れた
- 戻さず引く場合は超幾何を検討した

### よくある誤解

- 平均と分散が同じならポアソン分布だと証明できる → ✕。診断の手がかりの1つにすぎない。
- 戻さずに引いても二項分布で正確に計算できる → ✕。有限の袋なら一般に超幾何分布。

## 応用

### 幾何分布・負の二項分布

幾何：P(X＝k)＝(1−p)^(k−1)p、E＝1/p　負の二項：E＝r/p、V＝r(1−p)/p²

<b>問</b>　成功率0.5で、2回目の成功がちょうど3回目の試行で起きる確率は？
答え：最初の2回で成功1回（どちらか ₂C₁＝2通り）、3回目に成功。2×0.5²×0.5＝<b>0.25</b>。

p＝0.25 の幾何分布なら期待試行回数は4。r＝3 回目の成功までなら期待12回、分散36。

### 超幾何分布

（ラボ：hyper.html）

<b>問</b>　10個中2個が不良。戻さずに3個取り出すとき、不良がちょうど1個の確率は？
答え：₂C₁×₈C₂÷₁₀C₃＝2×28÷120＝56÷120＝<b>7/15</b>（約0.467）。母集団 N が大きければ二項分布とほぼ同じになる。

超幾何分布の式：母集団 N、成功 K、抽出 n のとき P(X＝k)＝C(K,k)×C(N−K,n−k)÷C(N,n)。平均 nK/N、分散 np(1−p)(N−n)/(N−1)（p＝K/N）。(N−n)/(N−1) は「戻さないことによる補正」。

### 待ち時間は指数分布

（ラボ：expo.html）

到着がポアソン分布なら、次の到着までの待ち時間は指数分布。P(待ち＞t)＝e^(−λt) は「t 時間に0件」の確率と同じ。詳しくは教科書17。

### 仕事の場面で

- レジの来店数（1時間あたり）をポアソン分布で考え、「4人以上来る確率」で応援の基準を作る。
- 抜き取り検査（ロットから戻さず数個取り出す）は超幾何分布の典型。
