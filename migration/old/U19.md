# 教科書19｜大数の法則・中心極限定理

## 学習の目標

大数の法則と中心極限定理を区別し、正規近似の条件を読む。

## ✨ 例題で式を読み解く

**この式を使う場面**　二項分布で n が大きく、一つずつ足すのが大変なとき。「◯回以下」「◯回以上」の確率を正規分布の表で近似する。

### 📝 例題

キャンペーンの当選率は0.5。100人が応募したとき、当選者が55人以下になる確率を正規近似で求めよ。

### 🧩 式のどこに何を入れる？

$$
Z=\frac{(k+0.5)-np}{\sqrt{np(1-p)}}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **n** | 応募者 100人 |
| **p** | 当選率 0.5 |
| **k** | 「55人以下」の55 |
| **＋0.5** | 連続修正：「以下」なので棒の右端55.5まで含める |
| **np, √np(1−p)** | 二項の平均50とSD5 |

### 🧮 計算

1. 平均 np＝100×0.5＝50、SD＝√(100×0.5×0.5)＝5
2. 条件確認：np＝50、n(1−p)＝50 ともに十分大きい
3. 連続修正：X≤55 → Y≤55.5
4. z＝(55.5−50)/5＝**1.1**
5. Φ(1.1)＝**0.8643**（正確な二項計算でも0.8644）

図：二項の棒グラフの形が正規曲線とほぼ重なる＝中心極限定理

| 聞かれ方 | 連続修正 |
| --- | --- |
| k 以下 | k＋0.5 以下 |
| k 以上 | k−0.5 以上 |
| a〜b | a−0.5〜b＋0.5 |

**混同注意**　大数の法則＝平均の**値**が μ に近づく。中心極限定理＝平均の**分布の形**が正規に近づく。「n＝30なら何でも正規」という一律ルールはない。

**答えの読み方**　約86%の確率で当選は55人以内。賞品を55個用意すると、約14%の確率で足りなくなる、と読める。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。

中心極限定理：歪んだ母集団でも n を増やすと標本平均の分布が正規曲線に重なっていきます。

二項分布の正規近似：n を大きくして「正規分布の近似を重ねる」をオンにすると、例題の考え方が見えます。

もう一つ：大数の法則。試行を重ねると当たりの割合は p に落ち着き、ずれの目安（±2SE）は √N に反比例して細くなります。

## 1｜まず意味をつかむ

大数の法則は標本平均の値が母平均に近づく性質。中心極限定理は適切に標準化した標本平均の分布が正規分布へ近づく性質。『平均が近づく』と『分布の形が近づく』を分ける。

この章では独立同分布・有限な母分散を持つ代表的な条件を使う。n=30ならどんなデータでも問題ない、という一律の規則ではない。強い歪み・重い裾・依存の影響を点検する。

## 2｜式と記号を読む

$$
\frac{\sqrt n(\bar X-\mu)}{\sigma}\ \xrightarrow{d}\ N(0,1)
$$

```txt
チェビシェフ：P(|X−μ|≥kσ)≤1/k²（有限分散、k>0）
√n(X̄−μ)/σ → 標準正規の分布（σ>0）
Bin(n,p) ≈ N(np,np(1−p))
```

## 3｜表で関係を整理する

| 性質 | 何が近づくか |
| --- | --- |
| 大数の法則 | 標本平均の値→母平均 |
| 中心極限定理 | 標準化した平均の分布→標準正規 |
| 二項の正規近似 | 回数の分布を連続分布で近似 |

## 4｜例題を途中から追う

二項n=100,p=0.5は平均50・SD5。P(X≤55)を連続修正すると、正規変数Yに対してP(Y≤55.5)としてz=1.1。修正なしのz=1より、離散区間の面積を適切に対応させる。

有限分散の変数なら、平均から2SD以上離れる確率はチェビシェフで高々1/4。正規を仮定しない粗い上限で、実際に25%という意味ではない。

## 5｜誤解と適用条件を確認する

二項のnpとn(1−p)が十分大きいかを確認（各10以上等は目安で厳密な一律保証ではない）。少なくともk、k以下、a〜bで連続修正の向きを変える。

## 6｜自力で確かめる

二項平均40、SD4のP(X≥45)を連続修正すると正規の何以上か。標準化の値は。

解答：44.5以上としてz=(44.5−40)/4=1.125。

## 7｜つまずいたら戻る

18の標本分布、16の正規確率へ戻る。
