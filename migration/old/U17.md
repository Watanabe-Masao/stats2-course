# 教科書17｜母集団・標本・無作為抽出

## 学習の目標

推測対象と実際に抽出できる範囲を区別し、無作為抽出の意味を理解する。

## ✨ 例題で式を読み解く

**この式を使う場面**　「N個の中からn個を無作為に選ぶとき、ある1個が選ばれる確率は？」と聞かれたとき。あわせて「その結論はどこまで広げてよいか」を判断する。

### 📝 例題

店舗台帳に載っている100店舗から、10店舗を単純無作為抽出で調査する。ただし実際には台帳に載っていない新店が5店舗ある。① 台帳上の各店舗が選ばれる確率は？　② 新店が選ばれる確率は？　③ 調査結果を「全105店舗」の結論にしてよいか。

### 🧩 式のどこに何を入れる？

$$
\pi_i=\frac{n}{N}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **π_i** | 店舗 i が標本に入る確率（包含確率） |
| **n** | 選ぶ数：10店舗 |
| **N** | **抽出枠**（台帳）の数：100店舗 ※母集団の105ではない |

### 🧮 計算

1. ① π＝10/100＝**0.1**（どの店も同じ）
2. ② 台帳に無いので選ばれようがない → **0**
3. ③ 結論が言えるのは「台帳に載る100店舗」まで。新店5店は別途確認が必要

図：母集団（推測したい範囲）と抽出枠（選べる範囲）のずれが偏りの原因になる

**混同注意**　「無作為」＝担当者が適当に選ぶ、ではない。乱数などで全員に決まった確率を与えること。また「標本が大きい」ことと「偏りがない」ことは別。

**答えの読み方**　計算の精密さより先に「誰に結論を広げたいか（母集団）」と「誰を選べたか（抽出枠）」を書き出す。ずれていれば、その差は無作為化では埋まらない。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。

（抽出枠のシミュレーター）

無作為抽出でも、抽出枠（台帳）に漏れがあると推定は偏ります。n で小さくなるのは「ぶれ（SE）」だけ。

## 1｜まず意味をつかむ

母集団は結論を広げたい対象、標本は観測した一部、抽出枠は選ぶために使う名簿等。3つがずれると、精密に計算しても目的の集団へ推測できない。

全数調査は対象全体、標本調査は一部を調べる。全数でも測定・記録・欠測などの誤りは残る。単純無作為抽出は、決めた大きさの全標本が同じ確率で選ばれる設計。担当者が『適当に選ぶ』ことや、希望者を募ることとは違う。

## 2｜式と記号を読む

$$
\pi_i=\frac{n}{N}
$$

```txt
標本サイズn = 観測した単位の数
母集団サイズN = 推測対象全体の単位数
抽出率 = n/N
```

## 3｜表で関係を整理する

| 対象 | 例 |
| --- | --- |
| 母集団 | 指定日時点の全対象店舗 |
| 抽出枠 | 実際に選択に使う店舗台帳 |
| 標本 | その台帳から選び調査した店舗 |

## 4｜例題を途中から追う

100店舗から10店舗を単純無作為に選ぶ。各店舗の包含確率は10/100=0.1。台帳に新店5店舗が載っていなければ、その5店舗は抽出されず、無作為化だけでカバー漏れは修復できない。

全国の身長を調べるのに1つのジムの会員名簿から無作為に選んでも、全住民の標本とは言えない。

## 5｜誤解と適用条件を確認する

標本が大きいこと、無作為であること、対象に代表的であることを混同しない。個々の抽出確率と標本全体の等確率性を区別する。

## 6｜自力で確かめる

200店舗から20店舗を単純無作為抽出する包含確率は。台帳に載らない店舗への結論をそのまま広げられるか。

解答：0.1。台帳のカバー漏れを確認し、無条件に広げない。
