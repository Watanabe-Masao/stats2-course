# 教科書02｜関数・総和記号・階乗

この章で答えられるようになること：統計の式に出てくる関数 f(x)・添字 xᵢ・Σ（全部足す）・n!（階乗）を、具体的な足し算・掛け算に書き下して計算できる。

このページの用語：総和記号（Σ）・階乗・偏差

## はじめて

### ステップ1｜記号を見たら書き下す

<b>Σ</b> が出てきたら → 「i＝1 から n まで、中身を全部<b>足す</b>」
<b>n!</b> が出てきたら → 「n から 1 まで全部<b>掛ける</b>」（4!＝4×3×2×1＝24）
<b>xᵢ</b> が出てきたら → 「<b>i 番目</b>のデータ」（掛け算ではない）

### ステップ2｜記号の読み方

x̄＝(1/n)Σxᵢ、n!＝n×(n−1)×…×1

| 記号 | 読み方（2, 4, 6 の例） |
| --- | --- |
| i | 何番目か（1, 2, 3） |
| xᵢ | i 番目の値（x₁＝2, x₂＝4, x₃＝6） |
| n | データの個数（3） |
| Σxᵢ | 2＋4＋6＝12 |

### ステップ3｜例題で書き下す

3日間の販売数が 2, 4, 6 個だった。Σxᵢ、Σxᵢ²、(Σxᵢ)²、平均、偏差平方和を求めよ。

| xᵢ | xᵢ² | (xᵢ−x̄)² |
| --- | --- | --- |
| 2 | 4 | 4 |
| 4 | 16 | 0 |
| 6 | 36 | 4 |
| <b>12</b> | <b>56</b> | <b>8</b> |

1. Σxᵢ＝<b>12</b> → 平均 x̄＝12÷3＝<b>4</b>
2. Σxᵢ²＝4＋16＋36＝<b>56</b>（2乗してから足す）
3. (Σxᵢ)²＝12²＝<b>144</b>（足してから2乗）
4. 偏差平方和 Σ(xᵢ−x̄)²＝4＋0＋4＝<b>8</b>

<b>ここが一番大事</b>　Σの中で<b>先に何をするか</b>を見る。56 と 144 のように、順番で答えが変わる。偏差の合計は必ず0なので、散らばりは2乗してから足す（教科書07で使う）。

### ステップ4｜動かして確かめる

（ラボ：sigma.html）

<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「値を1つ大きくすると、(Σx)² の正方形は Σx² の小さな正方形の合計より速く大きくなった」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　f(x)＝2x＋1 のとき f(3) はいくつか。
答え：2×3＋1＝<b>7</b>。f(3) は「x に3を入れた結果」で、f×3 ではない。

<b>問2（中）</b>　x＝1, 3, 5 について Σx、Σx²、偏差平方和を求めよ。
答え：Σx＝<b>9</b>、Σx²＝1＋9＋25＝<b>35</b>。平均3なので偏差平方和＝4＋0＋4＝<b>8</b>。

<b>問3（やや難）</b>　4!、0!、₅C₂＝5!÷(2!×3!) を求めよ。
答え：4!＝<b>24</b>、0!＝<b>1</b>（定義）、₅C₂＝120÷(2×6)＝<b>10</b>。なぜ 2! で割るかは教科書09で学ぶ。

<b>まとめ（3行）</b>
1. Σは「全部足す」、n! は「n から1まで全部掛ける」。まず書き下す。
2. Σx² と (Σx)² は計算の順番が違い、値も違う。
3. 偏差の合計は0。散らばりは2乗してから足す。

## 復習

### 思い出す（何も見ずに答える）

- Σx² と (Σx)² の違いを言える
- 0! の値を言える
- Σ(xᵢ−x̄) がいくつになるか言える

答え：
1. Σx² は2乗してから足す。(Σx)² は足してから2乗。
2. 1。
3. 必ず0。

### 記号の早見

| 記号 | 意味 |
| --- | --- |
| f(x) | x を入れたときの出力 |
| xᵢ | i 番目のデータ |
| Σ | 範囲の中身を全部足す |
| Π | 範囲の中身を全部掛ける |
| n! | n×(n−1)×…×1、0!＝1 |

### 1問で確かめる

<b>問</b>　5! はいくつか。
答え：5×4×3×2×1＝<b>120</b>。

## 深める

### お手本：偏差の合計が0になる理由

- <b>条件</b>：平均 x̄ を、そのデータ自身から計算したとき
- <b>対象と結論</b>：偏差の合計 Σ(xᵢ−x̄) は必ず0になる
- <b>根拠</b>：Σ(xᵢ−x̄)＝Σxᵢ−n×x̄ で、n×x̄＝Σxᵢ だから
- <b>成り立たない場合</b>：x̄ ではない別の値（例えば母平均 μ）との差を足すと、一般に0にならない

つなげると：「データ自身の平均からの偏差を合計すると、必ず0になる。Σ(xᵢ−x̄)＝Σxᵢ−n×x̄ で、平均の定義から n×x̄＝Σxᵢ だからである。ただし平均以外の値との差を足した場合は0になるとは限らない。」

### 言葉の使い分け

<b>「添字」と「掛け算」</b>
- xᵢ：i 番目のデータ（添字）
- 2x：2 と x の掛け算

<b>「Σ」と「Π」</b>
- Σ：全部足す（平均・分散）
- Π：全部掛ける（成長率の幾何平均・独立な確率の積）

### 言い直し練習

「Σx² は、合計を2乗したものです。」

<b>直す点</b>
- 「合計を2乗」は (Σx)²。Σx² は各値を2乗してから足す。

<b>言い直しの例</b>
「Σx² は、各データを2乗してから合計したものである。合計してから2乗する (Σx)² とは違う。2, 4, 6 なら Σx²＝56、(Σx)²＝144。」

### 自己チェック（説明を書いたら）

- 足す範囲（i＝1 から n まで）を書いた
- 2乗と足し算の順番を明記した
- 具体的な数で書き下して確かめた

### よくある誤解

- Σ(xᵢ−x̄)＝0 なら Σ(xᵢ−x̄)²＝0 → ✕。全部同じ値のときだけ0。
- f(x) は f×x → ✕。関数の括弧は掛け算ではない。

## 応用

### Σの計算ルール

| ルール | 例（2, 4, 6） |
| --- | --- |
| Σ(c×xᵢ)＝c×Σxᵢ | Σ3xᵢ＝3×12＝36 |
| Σ(xᵢ＋c)＝Σxᵢ＋n×c | Σ(xᵢ＋1)＝12＋3＝15 |
| Σc＝n×c | Σ5＝15 |

<b>問</b>　この3つのルールを使って、Σ(xᵢ−x̄)²＝Σxᵢ²−n x̄² を 2, 4, 6 で確かめよ。
答え：左辺は8。右辺は 56−3×4²＝56−48＝<b>8</b>。一致する。教科書07の「計算の近道」はこの式。
