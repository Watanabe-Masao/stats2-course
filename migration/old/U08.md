# 教科書08｜標準化・外れ値・歪度

この章で答えられるようになること：平均もばらつきも違う2つの値を、z得点（平均から標準偏差いくつ分か）で同じ物差しに乗せて比べられる。外れ値・歪度・尖度から分布の特徴を言葉で言える。

このページの用語：標準化・標準偏差・外れ値・歪度・尖度・正規分布

## はじめて

### ステップ1｜こんなときに標準化する

<b>平均やばらつきが違うものどうしを比べたい</b>（別の店・別の科目）→ <b>z得点</b>
<b>「どれくらい珍しい値か」を知りたい</b> → <b>|z| の大きさ</b>（2を超えると珍しい、3を超えるとかなり珍しい目安）
<b>分布の左右の偏りや裾の重さを数で表したい</b> → <b>歪度・尖度</b>

### ステップ2｜z得点の意味

z＝(x−μ)÷σ。「調べたい値 x が、平均 μ から<b>標準偏差 σ いくつ分</b>離れているか」。z＝2 なら平均より標準偏差2つ分上、z＝−1 なら1つ分下。

### ステップ3｜例題で比べる

店舗Aは日販の平均50万円・標準偏差10万円、店舗Bは平均80万円・標準偏差5万円。Aの70万円の日とBの90万円の日、その店にとって「珍しく良い日」なのはどちらか。

1. 店舗A：z＝(70−50)÷10＝<b>2</b>
2. 店舗B：z＝(90−80)÷5＝<b>2</b>
3. どちらも「平均より標準偏差2つ分上」で、<b>同じくらい珍しい</b>

（図：金額の差（20万円と10万円）は違うが、それぞれの店の中での位置は同じ）

<b>ここが一番大事</b>　金額の差だけ見るとAの方が「よく伸びた」ように見えるが、その店の普段のばらつきで割ると同じ位置。<b>標準化は「その集団の中での位置」をそろえる</b>。ただし分布の形（歪み）は変わらない。

### ステップ4｜動かして確かめる

（ラボ）
<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「μ＝50, σ＝10, x＝70 で z＝2。σ を20に広げると同じ70でも z＝1 になり、珍しさが下がった」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　平均100・標準偏差20の分布で、130のz得点はいくらか。
答え：(130−100)÷20＝<b>1.5</b>。

<b>問2（中）</b>　数学は平均60点・標準偏差10点で75点、英語は平均70点・標準偏差5点で80点だった。クラスの中で相対的に良い成績はどちらか。
答え：数学 z＝(75−60)÷10＝1.5、英語 z＝(80−70)÷5＝<b>2</b>。点数の差は数学の方が大きいが、<b>英語の方が相対的に良い</b>。

<b>問3（やや難）</b>　箱ひげ図で Q₁＝10、Q₃＝14 のデータに 21 が含まれる。21 は外れ値候補か。また「外れ値候補だから削除してよい」と言えるか。
答え：IQR＝4、上の柵＝14＋1.5×4＝20。21＞20 なので<b>外れ値候補</b>。ただし削除してよいとは<b>言えない</b>。入力ミス・別条件・本当にまれな出来事のどれかを確認し、除くなら理由と結果への影響を残す。

<b>まとめ（3行）</b>
1. z＝(x−平均)÷標準偏差。平均から標準偏差いくつ分かを表す。
2. 平均やばらつきの違うものも、z得点なら同じ物差しで比べられる。
3. 標準化しても分布の形は変わらない。外れ値は削除前に原因を確認する。

## 復習

- z得点の式と意味を言える
- 標準化したデータの平均と標準偏差を言える
- 右に裾が長い分布の歪度の符号を言える

答え：
1. z＝(x−μ)÷σ。平均から標準偏差いくつ分離れているか。
2. 平均0、標準偏差1。
3. 正（プラス）。左に裾が長ければ負。

### 指標の早見

| z得点 | 平均から標準偏差いくつ分か。単位なし |
| 歪度 | 正：右に裾が長い／負：左に裾が長い |
| 尖度 | 裾の重さ。正規分布は3（超過尖度なら0） |
| 外れ値の柵 | Q₁−1.5IQR 未満、Q₃＋1.5IQR 超 |

### 1問で確かめる

<b>問</b>　平均30・標準偏差6の分布で、z＝−1.5 に当たる値は？
答え：x＝μ＋zσ＝30＋(−1.5)×6＝<b>21</b>。

## 深める

### お手本：z得点で比べる理由

- <b>条件</b>：平均やばらつきが違う2つの集団の値を比べるとき
- <b>対象と結論</b>：元の値ではなく z得点で比べると、それぞれの集団の中での位置を公平に比べられる
- <b>根拠</b>：平均を引くことで中心をそろえ、標準偏差で割ることでばらつきの物差しをそろえるから
- <b>成り立たない場合</b>：分布の形が大きく違う（片方だけ強く歪んでいる）と、同じ z でも珍しさ（割合）は同じとは限らない

<b>つなげると</b>
「平均やばらつきの違う集団の値を比べるときは、z得点にすると集団の中での位置を公平に比べられる。平均を引いて中心をそろえ、標準偏差で割って物差しをそろえるからである。ただし分布の形が大きく違えば、同じ z でも珍しさは同じとは限らない。」

### 言葉の使い分け

<b>「標準化」と「正規化（正規分布にする）」</b>
- 標準化：平均0・標準偏差1にそろえる。形は変わらない
- 標準化しても正規分布になるわけではない

<b>「外れ値」と「誤り」</b>
- 外れ値：他から飛び抜けた値
- 誤り：入力ミスなど。外れ値の原因の1つにすぎない

<b>「z得点」と「指数（基準＝100）」</b>
- z得点：平均と標準偏差で位置を表す
- 指数：基準の値を100とした比。ばらつきは考えない

### 言い直し練習

「データを標準化したので、正規分布として確率を計算できます。」
<b>直す点</b>
- 標準化は平均0・標準偏差1にそろえるだけで、分布の形は変わらない。
- 正規分布の確率を使えるのは、元の分布が正規分布に近いときだけ。
<b>言い直しの例</b>
「データを標準化して平均0・標準偏差1にそろえた。元の分布が正規分布に近ければ、標準正規分布表で確率を求められる。歪みが大きい場合は、その確率は当てはまらない。」

### 自己チェック（説明を書いたら）

- z得点の符号（平均より上か下か）を言った
- 標準化で形は変わらないことに触れた
- 外れ値を削除する前の確認に触れた
- 尖度の定義（3が基準か、0が基準か）を確かめた

### もう一段深く：歪度と尖度の式

g₁＝m₃÷m₂^(3/2)、g₂＝m₄÷m₂²、m_k＝Σ(xᵢ−x̄)^k÷n
- 3乗すると符号が残るので、右に飛び出た値が多いと歪度は正になる。
- 4乗すると大きな偏差が強調されるので、尖度は主に<b>裾の重さ</b>を表す。山の高さだけの指標ではない。
- ソフトは「超過尖度」（g₂−3）を出すことが多い。出力が0なら正規分布と同じ程度。

### よくある誤解

- 歪度0なら左右対称 → ✕。0でも非対称なことがある。
- 左右対称なら正規分布 → ✕。一様分布も対称。
- 標本歪度・尖度の式はどのソフトも同じ → ✕。補正の有無で値が違う。

## 応用

### 正規分布の確率へ（教科書16）

分布が正規分布に近ければ、z≥2 の割合は約2.3%、|z|≤1 は約68%、|z|≤2 は約95%。例題の「珍しく良い日」は、正規分布なら約43日に1回ほど。

### 偏差値

偏差値＝50＋10×z。z＝2 なら偏差値70、z＝−1 なら40。平均50・標準偏差10になるよう変換した値。

<b>問</b>　平均62点・標準偏差8点の試験で74点。偏差値は？
答え：z＝(74−62)÷8＝1.5。偏差値＝50＋10×1.5＝<b>65</b>。

### 仕事の場面で

- 日販を店ごとに標準化すると、規模の違う店でも「その店にとって異常な日」を同じ基準（|z|＞2 など）で見つけられる。
- 異常値の自動検知を作るときも、外れた日を自動で削除せず、原因（天候・イベント・入力ミス）を記録してから扱う。
