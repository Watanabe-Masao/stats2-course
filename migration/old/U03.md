# 教科書03｜データと確率の基本用語

この章で答えられるようになること：問題文の数字が「全体（母集団）」のものか「調べた一部（標本）」から計算したものかを見分け、母数と統計量を区別して言える。

用語：母集団・標本・母数・統計量・標本空間・事象（用語辞典 405b7cd539a181a1af22c1469b5048bf 405b7cd539a181c89c78dd03e0aff365 405b7cd539a181dbac4ffc0e5eb81d7c 405b7cd539a1816aaefffafd39bb617b 405b7cd539a181f981cace263f9b23e0 405b7cd539a181a0870fe1a8729f5050）

## はじめて

### ステップ1｜「全体」と「調べた一部」を分ける

統計の問題では、最初に次の2つを確かめる。

<b>質問1：本当に知りたいのは、どの集まり全体？</b> → それが<b>母集団</b>。その全体の本当の値（平均など）が<b>母数</b>。ふつうは分からない。

<b>質問2：実際に調べたのは、どの一部？</b> → それが<b>標本</b>。標本から計算した値（平均など）が<b>統計量</b>。取り直すたびに変わる。

### ステップ2｜図で見る

| 全体の側 | 調べた一部の側 |
| 母集団（大きさ N） | 標本（大きさ n） |
| 母数：母平均 μ（未知・固定） | 統計量：標本平均 x̄（計算できる・取り直すと変わる） |

### ステップ3｜例題を1つ解く

全100店舗の平均廃棄率を知りたい。10店舗を選んで調べたところ、平均は2.4%だった。母集団・標本・母数・統計量はそれぞれ何か。

1. <b>知りたい全体は？</b> → 全100店舗＝<b>母集団</b>（N＝100）
2. <b>実際に調べたのは？</b> → 10店舗＝<b>標本</b>（n＝10）
3. <b>2.4% はどちらから計算した？</b> → 10店舗から＝<b>統計量 x̄</b>
4. 全100店舗の本当の平均廃棄率＝<b>母数 μ</b>（分からない）

x̄ = (1/n) Σ x_i

<b>ここが一番大事</b>　2.4% は「全店の平均」ではなく「全店の平均を推測する材料」。どのくらい前後するかは22（信頼区間）で求める。

### ステップ5｜確認問題

問1（易）　ある県の全世帯のうち500世帯を調べ、1世帯あたりの平均の食費を計算した。母集団と標本はそれぞれ何か。
答え：母集団＝<b>その県の全世帯</b>、標本＝<b>調べた500世帯</b>。500世帯の平均食費は統計量。

問2（中）　次のうち母数はどれか。「① 調べた30人の平均年齢」「② 全社員の本当の平均年齢」「③ 調べた30人の年齢の標準偏差」
答え：<b>②</b>。母集団（全社員）の値なので母数。①③は調べた30人（標本）から計算した統計量。

問3（やや難）　全従業員の残業時間を知るため、自分から回答してくれた20人の平均を出した。母集団・標本・統計量を答え、この平均だけでは分からないことを1つ挙げる。
答え：母集団＝<b>全従業員</b>、標本＝<b>回答した20人</b>、統計量＝<b>20人の平均残業時間</b>。分からないこと（例）：自分から回答した人は残業が多い（少ない）人に偏っているかもしれない。人数が多くても、選ばれ方が偏っていれば全体の推測は崩れる。期間や「残業」の定義も確認が必要。

まとめ：1. 知りたい全体＝母集団、その本当の値＝母数（未知・固定）。2. 調べた一部＝標本、そこから計算した値＝統計量（取り直すと変わる）。3. 統計量は母数を推測する材料で、選び方が偏ると推測が崩れる。

## 復習

思い出す：母集団と標本の違いを1文で言える／母数と統計量の違いを「固定か、変わるか」で言える／「標本」と「標本空間」の違いを言える
答え：1. 母集団は知りたい対象の全体、標本は実際に調べた一部。2. 母数は母集団の値で、決まっているが普通は分からない。統計量は標本から計算する値で、標本を取り直すと変わる。3. 標本は調べたデータの集まり。標本空間は、確率の試行で起こりうる結果の全部（10章）。

記号の早見：母平均 μ／標本平均 x̄、母分散 σ²／不偏分散 s²、母比率 p／標本比率 p̂、大きさ N／大きさ n。ギリシャ文字は母数、上に記号（¯ ^）が付いたら統計量。

1問で確かめる：スーパーの全来店客のうち、ある日の午前中に来た客120人にアンケートし、満足と答えた割合は75%だった。この75%は母数か統計量か。注意点を1つ。
答え：<b>統計量</b>（標本比率 p̂）。注意点：午前中の客だけなので、午後や休日の客と満足度が違うかもしれない（時間帯の偏り）。

## 深める

説明の型。お手本：統計量で母数を推測できる理由
- <b>条件</b>：母集団から<b>偏りのない方法（無作為）</b>で標本を選んだとき
- <b>対象と結論</b>：標本平均 x̄ は母平均 μ を推測する材料として使える
- <b>根拠</b>：無作為に選べば、標本の中身が特定の方向に偏らず、x̄ は μ のまわりにばらつくから
- <b>成り立たない場合</b>：自分から回答した人だけ、台帳に載った店だけなど、選ばれ方が偏ると、標本を大きくしても x̄ は μ からずれたままになる
つなげると：「母集団から無作為に標本を選んだとき、標本平均は母平均を推測する材料として使える。なぜなら選び方に偏りがなければ、標本平均は母平均のまわりにばらつくから。ただし選ばれ方が偏っていると、標本を大きくしてもずれは消えない。」

言葉の使い分け
- 「標本」：統計の標本＝実際に調べたデータの集まり（10店舗）／標本空間＝確率の試行で起こりうる結果の全部（サイコロなら1〜6）→ 名前が似ているだけで別の言葉
- 「平均」：母平均 μ＝全体の本当の平均（未知）／標本平均 x̄＝調べた一部の平均（計算できる）→ 説明では必ずどちらの平均か言う
- 「データがある」：数字が手元にある、ということと、知りたい問いに答えられる、ということは別。対象・期間・定義が問いに合っているかを確かめる

言い直し練習：「10店舗調べて平均2.4%だったので、全店の廃棄率は2.4%です。」
直す点：2.4% は標本（10店舗）の統計量で、母数（全店の平均）そのものではない。選び方（無作為か）に触れていない。
言い直しの例：「無作為に選んだ10店舗の平均廃棄率は2.4%だった。これは全100店舗の平均廃棄率を推測する材料で、全店の平均は2.4%前後と考えられる。どのくらい前後するかは信頼区間で示す必要がある。」

自己チェック：数字が母集団・標本のどちらのものか書いた／「平均」を母平均か標本平均か分かる言い方にした／標本の選び方（無作為か、偏りはないか）に触れた／言えないこと（断定できないこと）を1つ以上書いた

もう一段深く：データから結論までの流れ（PPDAC）
- 問題（Problem）：何を知りたいか（新売場で廃棄率は下がるか）
- 計画（Plan）：誰を・いつ・どう測るか、比較の相手と分母を決める
- データ（Data）：集める。欠測や定義の違いを記録する
- 分析（Analysis）：率・ばらつき・差を計算する
- 結論（Conclusion）：分かったことと、まだ言えないことを分けて書く

よくある誤解
- 回答数が多ければ代表性がある → ✕。自分から答えた人だけなら、何千人でも偏る。
- 公的統計なら何とでも比べてよい → ✕。対象・用語の定義・時点・集計単位を確認する。
- 統計ソフトで計算すれば正しい → ✕。集め方の偏りは計算では直らない。

## 応用

推定へ（教科書17・22）：この章の「母数は未知・統計量は変わる」が、推定と検定の土台になる。17で「標本平均がどれくらい変わるか」、22で「母平均はどの範囲か（信頼区間）」を学ぶ。

調査の設計へ（教科書31）：問　会員アプリの利用者だけにアンケートを送り、「全来店客の満足度」を調べようとした。何が問題か。
答え：調べたい母集団（全来店客）と、標本を選ぶ元の名簿（アプリ会員）がずれている。アプリを使わない客は選ばれる可能性がなく、満足度が違えば結果が偏る（抽出枠の偏り）。

仕事の場面で
- 「売れ筋上位20品目の値入率」は、全品目の値入率の推測には使えない（売れ筋だけを選んでいる）。
- 全店の数字を知りたいのに、協力的な数店だけのデータで判断していないかを、数字を見る前に確かめる。

確率の言葉へ（教科書10）：<b>試行</b>（結果が偶然で決まる手続き）、<b>標本空間</b>（起こりうる結果の全部）、<b>事象</b>（標本空間の一部）。サイコロを1回振る試行の標本空間は {1, 2, 3, 4, 5, 6}、「偶数が出る」事象は {2, 4, 6}。
