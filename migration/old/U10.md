# 教科書10｜事象・確率の公理・加法則

この章で答えられるようになること：「AまたはB」「少なくとも1回」の確率を、重なりを二重に数えずに求められる。排反と独立の違いを言える。

このページの用語：標本空間・事象・余事象・排反・独立

## はじめて

### ステップ1｜問題文の言葉で式を選ぶ

<b>「AまたはB」</b> → 足して、<b>重なりを1回引く</b>（加法定理）
<b>「少なくとも1回」</b> → 反対の「1回もない」を求めて、<b>1から引く</b>（余事象）
<b>結果がどれも同じくらい起こりやすい</b>（公平なサイコロなど） → <b>数えて割る</b>：該当する数÷全部の数

### ステップ2｜図で重なりを見る

（図：重なり（4と6）を一度だけ数えると {2,4,5,6} の4個）

| サイコロ | 結果 |
| --- | --- |
| A：偶数 | 2, 4, 6 |
| B：4以上 | 4, 5, 6 |
| AかつB（重なり） | 4, 6 |
| AまたはB | 2, 4, 5, 6 |

### ステップ3｜例題で計算する

① サイコロを1回投げる。A＝偶数、B＝4以上。「AまたはB」の確率は？　② 2回投げて、少なくとも1回6が出る確率は？

P(A∪B)＝P(A)＋P(B)−P(A∩B)、P(Aᶜ)＝1−P(A)

1. ① 3/6＋3/6−2/6＝4/6＝<b>2/3</b>（4と6を2回数えた分を引く）
2. ② 「2回とも6以外」＝5/6×5/6＝25/36
3. ② 少なくとも1回6＝1−25/36＝<b>11/36</b>（約30.6%）

<b>ここが一番大事</b>　「または」は重なりを1回引く。重なりがない（<b>排反</b>）ならそのまま足せる。「少なくとも」は反対側から計算すると楽。

### ステップ4｜動かして確かめる

（ラボ：union.html）

<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「重なりを0にすると、P(A∪B) は P(A)＋P(B) と同じになった（排反）」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　箱に赤玉2個・青玉3個。1個取り出すとき赤の確率は？
答え：<b>2/5</b>。「赤か青の2択だから1/2」は誤り。等しく起こりやすいのは「色」ではなく「玉1個1個」。

<b>問2（中）</b>　サイコロ1回で「奇数または3以下」の確率は？
答え：奇数 {1,3,5}、3以下 {1,2,3}、重なり {1,3}。3/6＋3/6−2/6＝<b>2/3</b>。

<b>問3（やや難）</b>　サイコロを3回投げて、少なくとも1回6が出る確率は？
答え：1−(5/6)³＝1−125/216＝<b>91/216</b>（約42.1%）。「1/6×3＝1/2」は、重なり（2回以上6）を何度も数えた誤り。

<b>まとめ（3行）</b>
1. P(A∪B)＝P(A)＋P(B)−P(A∩B)。重なりを1回引く。
2. 「少なくとも1回」は 1−P(1回もない)。
3. 「数えて割る」は、結果が等しく起こりやすいときだけ使える。

## 復習

### 思い出す（何も見ずに答える）

- 加法定理を書ける
- 余事象を使う場面を言える
- 排反と独立の違いを言える

答え：
1. P(A∪B)＝P(A)＋P(B)−P(A∩B)。
2. 「少なくとも1つ」「1回以上」など、反対側が簡単なとき。
3. 排反＝同時に起きない（P(A∩B)＝0）。独立＝片方が起きても他方の確率が変わらない（P(A∩B)＝P(A)P(B)）。

### 式の早見

| 求めるもの | 式 |
| --- | --- |
| AまたはB | P(A)＋P(B)−P(A∩B) |
| 排反なとき | P(A)＋P(B) |
| Aでない | 1−P(A) |
| 等確率のとき | 該当数÷全体数 |

### 1問で確かめる

<b>問</b>　P(A)＝0.5、P(B)＝0.4、P(A∩B)＝0.2 のとき P(A∪B) と「AもBも起きない」確率は？
答え：P(A∪B)＝0.5＋0.4−0.2＝<b>0.7</b>。どちらも起きない＝1−0.7＝<b>0.3</b>。

## 深める

### お手本：「または」で重なりを引く理由

- <b>条件</b>：「AまたはB」の確率を求めるとき
- <b>対象と結論</b>：P(A) と P(B) を足して、P(A∩B) を1回引く
- <b>根拠</b>：AとBの両方に入る結果は、P(A) にも P(B) にも含まれ、2回数えられているから
- <b>成り立たない場合</b>：AとBが排反（重なりがない）なら引く必要はなく、そのまま足せる

つなげると：「AまたはBの確率は、P(A) と P(B) を足してから、両方に入る部分 P(A∩B) を1回引いて求める。重なりの部分は P(A) と P(B) の両方で数えられ、2回数えられているからである。ただし排反なら重なりがないので、そのまま足せばよい。」

### 言葉の使い分け

<b>「排反」と「独立」</b>
- 排反：同時に起きない（重なりが0）
- 独立：片方が起きても、もう片方の確率が変わらない
- 確率が正の2つの事象が排反なら、独立ではない（片方が起きると、もう片方は確率0になるから）

<b>「または」と「かつ」</b>
- または（∪）：少なくとも一方が起きる
- かつ（∩）：両方が起きる

### 言い直し練習

「AとBは排反なので独立です。だから P(A∩B)＝P(A)×P(B) で計算できます。」

<b>直す点</b>
- 排反なら P(A∩B)＝0。P(A)，P(B) がどちらも正なら P(A)×P(B)＞0 なので独立ではない。

<b>言い直しの例</b>
「AとBは排反なので、同時に起きる確率 P(A∩B) は0である。P(A) と P(B) がどちらも正なら P(A)×P(B) は0にならないので、AとBは独立ではない。」

### 自己チェック（説明を書いたら）

- 重なり（∩）の有無を確かめた
- 排反と独立を区別して書いた
- 「数えて割る」とき等確率の前提を書いた
- 「少なくとも」で余事象を検討した

### もう一段深く：確率の3つのルール（公理）

1. どんな事象の確率も0以上
2. 全ての結果をまとめた事象（標本空間 Ω）の確率は1
3. 互いに重ならない事象の「または」の確率は、それぞれの確率の和

加法定理も余事象の式も、この3つから導ける。例えば A と Aᶜ は排反で合わせると Ω なので、P(A)＋P(Aᶜ)＝1。

### よくある誤解

- 2択なら確率は1/2 → ✕。選択肢の数ではなく、等しく起こりやすい結果の数で数える。
- 「少なくとも1回」は 1回の確率×回数 → ✕。重なりを何度も数えてしまう。

## 応用

### 併買の分析で

<b>問</b>　来店客のうちパンを買う人が40%、牛乳を買う人が30%、両方買う人が10%。「パンか牛乳の少なくとも一方を買う人」と「どちらも買わない人」の割合は？
答え：0.4＋0.3−0.1＝<b>0.6（60%）</b>。どちらも買わない＝1−0.6＝<b>0.4（40%）</b>。

### 条件付き確率へ（教科書11）

同じ例で「パンを買った人のうち牛乳も買う割合」は 0.1÷0.4＝0.25。全体の30%より低いので、パン購入と牛乳購入は独立ではない。

### 仕事の場面で

- 「キャンペーン期間中に1回以上来店する確率」は、1−(1回も来ない確率)で考える。
- 会員と非会員、平日と休日のように排反な区分に分ければ、全体の確率は区分の確率を足して求められる。
