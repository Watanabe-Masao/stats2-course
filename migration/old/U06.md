# 教科書06｜平均・中央値・最頻値・分位点

この章で答えられるようになること：「代表的な値はいくつ？」と聞かれたとき、分布の形と目的に合わせて平均・中央値・最頻値を選び、件数の違うグループは重み付き平均でまとめられる。

このページの用語：中央値・最頻値・四分位数・外れ値・期待値

## はじめて

### ステップ1｜何を伝えたいかで代表値を選ぶ

<b>合計を均したい</b>（売上見込み・予算・1人あたり）→ <b>平均</b>
<b>典型的な1人・1日を言いたい</b>（裾が長い・外れ値がある）→ <b>中央値</b>
<b>一番よく出る値・売れ筋を知りたい</b>（サイズ・価格帯）→ <b>最頻値</b>

### ステップ2｜3つの代表値の違いを見る

| 代表値 | 求め方 | 外れ値の影響 |
| 平均 | 合計÷件数 | 大きい |
| 中央値 | 小さい順の真ん中 | 小さい |
| 最頻値 | 最も多く出る値 | 小さい |

中央値は件数が偶数なら真ん中2つの平均。最頻値は複数あったり、ないこともある。

### ステップ3｜例題で求める

10人の購入額（千円）は 1, 1, 2, 2, 2, 3, 3, 4, 5, 17。平均・中央値・最頻値を求めよ。

1. <b>平均</b>：合計40÷10人＝<b>4千円</b>
2. <b>中央値</b>：5番目（2）と6番目（3）の平均 → <b>2.5千円</b>
3. <b>最頻値</b>：3人いる2 → <b>2千円</b>

（図：17千円の1人が平均を右に引っ張る。中央値はほとんど動かない）

<b>ここが一番大事</b>　「典型的な客」は2〜3千円（中央値・最頻値）。一方、10人分の売上見込みは平均×人数＝40千円。<b>目的によって正しい代表値が変わる</b>。

### ステップ4｜動かして確かめる

（ラボ：平均と中央値）
<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「x₆ を大きくして外れ値にすると、平均は大きく動くが、中央値はほとんど動かない」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　3, 5, 5, 7, 10 の平均・中央値・最頻値を求めよ。
答え：合計30÷5＝<b>平均6</b>、3番目の<b>中央値5</b>、2回出る<b>最頻値5</b>。

<b>問2（中）</b>　A店は客20人で平均客単価3,000円、B店は客80人で平均客単価2,000円。2店を合わせた客1人あたりの平均はいくらか。
答え：(20×3000＋80×2000)÷100＝220,000÷100＝<b>2,200円</b>。(3000＋2000)÷2＝2,500円は、客数の違い（重み）を無視した誤り。

<b>問3（やや難）</b>　1, 2, 2, 3, 22 の平均・中央値・最頻値を求め、「典型的な値」を伝えるならどれを使うか説明せよ。
答え：平均<b>6</b>、中央値<b>2</b>、最頻値<b>2</b>。22が平均を引っ張り、5つのうち4つが平均より小さい。典型的な値を伝えるなら中央値（または最頻値）が向く。ただし合計（30）や予算を扱うなら平均が必要。

<b>まとめ（3行）</b>
1. 平均は合計を均した値で、外れ値に強く引っ張られる。
2. 裾が長い・外れ値があるとき、典型的な値は中央値で伝える。
3. 件数の違うグループの平均は、件数で重み付けしてまとめる。

## 復習

- データが偶数個のときの中央値の求め方を言える
- 右に裾が長い分布で、平均と中央値の大小を言える
- 重み付き平均の式を書ける

答え：
1. 小さい順に並べ、真ん中の2つの平均をとる。
2. 平均＞中央値になりやすい（大きい値に平均が引っ張られる）。
3. Σ(wᵢxᵢ)÷Σwᵢ。重みwᵢは件数・個数など。

### 式の早見

| 平均 | Σxᵢ÷n |
| 重み付き平均 | Σ(wᵢxᵢ)÷Σwᵢ |
| 度数表の近似平均 | Σ(階級値×度数)÷n |
| 四分位数 Q₁, Q₂, Q₃ | 小さい順で 25%, 50%, 75% の位置（Q₂＝中央値） |

### 1問で確かめる

<b>問</b>　100円の商品を10個、200円の商品を30個売った。1個あたりの平均単価は？
答え：(10×100＋30×200)÷40＝7,000÷40＝<b>175円</b>。150円は個数を無視した誤り。

## 深める

### お手本：裾の長い分布で中央値を選ぶ理由

- <b>条件</b>：分布が右に裾が長い（少数の大きい値がある）とき
- <b>対象と結論</b>：平均は中央値より大きくなり、典型的な値としては中央値が適している
- <b>根拠</b>：平均は全ての値の合計を使うので大きい値に引っ張られるが、中央値は順番の真ん中なので端の値の大きさに影響されにくいから
- <b>成り立たない場合</b>：合計や総額（売上見込み・予算）を知りたいときは、平均×件数が必要なので平均を使う

<b>つなげると</b>
「右に裾が長い分布では、平均が中央値より大きくなるので、典型的な値は中央値で伝えるのがよい。平均は合計を使うため大きな値に引っ張られるが、中央値は順番の真ん中なので影響を受けにくいからである。ただし総額を見積もるときは平均を使う。」

### 言葉の使い分け

<b>「平均」と「中央値」</b>
- 平均：合計を件数で均した値。合計を保つ
- 中央値：小さい順の真ん中。半数ずつに分ける位置

<b>「単純平均」と「重み付き平均」</b>
- 単純平均：値をそのまま平均（店舗平均を店の数で割る）
- 重み付き平均：件数などで重み付け（全客の平均）

<b>「算術平均」と「幾何平均」</b>
- 算術平均：足して割る。量の平均
- 幾何平均：掛けて累乗根。倍率・成長率の平均

### 言い直し練習

「平均年収が600万円なので、社員の多くは600万円くらいもらっています。」
<b>直す点</b>
- 年収は右に裾が長いことが多く、少数の高い年収が平均を引き上げる。
- 「多くの人」を言いたいなら、中央値や最頻値を確かめる必要がある。
<b>言い直しの例</b>
「平均年収は600万円である。ただし年収の分布は右に裾が長いことが多いので、平均は一部の高い年収に引き上げられている可能性がある。典型的な社員の年収を知るには中央値を確かめる。」

### 自己チェック（説明を書いたら）

- どの代表値か（平均・中央値・最頻値）を明記した
- 分布の形（対称か、裾が長いか）に触れた
- 目的（典型値か、合計か）を書いた
- 件数が違うグループの平均で、重みを確かめた

### もう一段深く：分布の形と3つの大小

| 左右対称・単峰 | 平均 ≒ 中央値 ≒ 最頻値 |
| 右に裾が長い | 最頻値 ＜ 中央値 ＜ 平均 |
| 左に裾が長い | 平均 ＜ 中央値 ＜ 最頻値 |

あくまで目安で、例外もある。試験では「裾の向き → 平均が引っ張られる向き」で判断する。

### よくある誤解

- 中央値の方が常に良い代表値 → ✕。総額や予算を扱うなら平均が必要。
- 店舗ごとの平均をさらに平均すれば全体平均 → ✕。客数が違えば重み付き平均にする。
- 最頻値は必ず1つ → ✕。複数あったり、全て1回ずつで決まらないこともある。

## 応用

### 成長率の平均（補講 05-T）

数量が 100→110→121 と増えたとき、平均成長率は10%（1.1倍ずつ）。一方、＋20%のあと−20%なら 1.2×0.8＝0.96 で、算術平均の0%ではなく、1期あたり約−2.0%（√0.96≒0.980）。倍率の平均は<b>幾何平均</b>で求める。

（ラボ：平均成長率）算術平均では実際の推移を再現できないことを確かめる。

### 度数表からの平均

<b>問</b>　階級「0〜10」が2人、「10〜20」が5人、「20〜30」が3人。平均の近似値は？
答え：階級値（真ん中の値）5, 15, 25 を使う。(5×2＋15×5＋25×3)÷10＝160÷10＝<b>16</b>。各階級の値が真ん中に集まっていると見なした近似なので、元データの平均とは少しずれることがある。

### 仕事の場面で

- 全店の平均客単価は、各店の平均客単価を足して店の数で割るのではなく、全店の売上合計÷全店の客数で出す。
- 「平均来店間隔」のように裾が長いデータは、平均だけで報告せず中央値も併記する。
