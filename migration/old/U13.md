# 教科書13｜確率変数・期待値・分散

この章で答えられるようになること：「値」と「その確率」の一覧（確率分布）から、1回あたりの平均（期待値）とばらつき（分散・標準偏差）を計算できる。aX＋b や X＋Y にしたときの変化も求められる。

このページの用語：確率変数・確率分布・期待値・分散・標準偏差・共分散・独立

## はじめて

### ステップ1｜こんなときに使う

<b>「1回（1人）あたり平均どれだけ？」</b> → <b>期待値</b>：値×確率を全部足す
<b>「どれくらいばらつく？読みにくさは？」</b> → <b>分散・標準偏差</b>
<b>単価を掛けた・固定額を足した</b>（Y＝aX＋b） → <b>E(aX＋b)＝aE(X)＋b、V(aX＋b)＝a²V(X)</b>

### ステップ2｜期待値は分布の「重心」

ある売場で、1人の客が買う個数 X の確率は次のとおり。1人あたり平均何個買うか。また分散・標準偏差はいくらか。

| 買う個数 x | 確率 P(X＝x) |
| --- | --- |
| 0個 | 0.2 |
| 1個 | 0.5 |
| 2個 | 0.3 |

（図：期待値は分布の「重心」。薄い帯が±標準偏差の範囲）

### ステップ3｜表に列を足して計算する

E(X)＝Σ x P(X＝x)、V(X)＝E(X²)−{E(X)}²

| x | x×確率 | x²×確率 |
| --- | --- | --- |
| 0 | 0 | 0 |
| 1 | 0.5 | 0.5 |
| 2 | 0.6 | 1.2 |
| <b>合計</b> | <b>1.1</b> | <b>1.7</b> |

1. <b>期待値</b>　E(X)＝<b>1.1個</b>
2. <b>2乗の期待値</b>　E(X²)＝1.7
3. <b>分散</b>　V(X)＝1.7−1.1²＝1.7−1.21＝<b>0.49</b>
4. <b>標準偏差</b>　√0.49＝<b>0.7個</b>

（図：平均はどちらも1.1個。売場Bは0個か2個に分かれていて読みにくい）

売場B（0個 0.45、2個 0.55）：E(X)＝1.1、E(X²)＝2.2、V＝2.2−1.21＝0.99。平均が同じでも、値が平均から離れているほど分散は大きい。

<b>ここが一番大事</b>　期待値は「確率で重み付けした平均」。100人来ればおよそ110個売れる見込み。1人あたりは1.1個から±0.7個くらいぶれる。

### ステップ4｜動かして確かめる

（ラボ：sim_expect.html）

<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「b（固定額）を増やすと支払額の平均だけ上がり、標準偏差は変わらなかった。a を2倍にすると標準偏差も2倍になった」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　X＝0, 1 の確率が 0.7, 0.3 のとき、期待値と分散は？
答え：E(X)＝0.3、E(X²)＝0.3、V(X)＝0.3−0.09＝<b>0.21</b>。期待値は<b>0.3</b>（実際には取らない値でもよい）。

<b>問2（中）</b>　例題の X で、1人の支払額 Y＝200X＋50（1個200円、固定分50円）の平均と標準偏差は？
答え：E(Y)＝200×1.1＋50＝<b>270円</b>。V(Y)＝200²×0.49＝19,600、標準偏差＝200×0.7＝<b>140円</b>。固定分50円はばらつきに効かない。

<b>問3（やや難）</b>　X と Y の分散が4と9、共分散が1のとき、X＋Y と X−Y の分散は？ 独立ならどうなるか。
答え：V(X＋Y)＝4＋9＋2×1＝<b>15</b>、V(X−Y)＝4＋9−2×1＝<b>11</b>。独立なら共分散0で、どちらも<b>13</b>。差でも分散は「足す」。

<b>まとめ（3行）</b>
1. 期待値 E(X)＝Σ x×確率。分散 V(X)＝E(X²)−{E(X)}²。
2. E(aX＋b)＝aE(X)＋b、V(aX＋b)＝a²V(X)。足した定数はばらつきに効かない。
3. V(X±Y)＝V(X)＋V(Y)±2Cov(X,Y)。独立なら共分散0。

## 復習

### 思い出す（何も見ずに答える）

- 分散の計算の近道（E(X²)−{E(X)}²）を書ける
- V(aX＋b) を言える
- 独立な X, Y で V(X−Y) を言える

答え：
1. V(X)＝E(X²)−{E(X)}²。
2. a²V(X)。b は関係ない。
3. V(X)＋V(Y)。差でも足す。

### 式の早見

| 求めるもの | 式 |
| --- | --- |
| 期待値 | Σ x P(X＝x) |
| 分散 | E(X²)−{E(X)}² |
| 1次変換 | E(aX＋b)＝aE(X)＋b、V(aX＋b)＝a²V(X) |
| 和の期待値 | E(X＋Y)＝E(X)＋E(Y)（独立でなくてもよい） |
| 和・差の分散 | V(X)＋V(Y)±2Cov(X,Y) |
| 共分散 | E(XY)−E(X)E(Y) |

### 1問で確かめる

<b>問</b>　例題の X（E＝1.1、V＝0.49）で、2X＋3 の期待値と分散は？
答え：E＝2×1.1＋3＝<b>5.2</b>、V＝2²×0.49＝<b>1.96</b>。

## 深める

### お手本：X−Y の分散も「足す」理由

- <b>条件</b>：X と Y が独立なとき
- <b>対象と結論</b>：X−Y の分散は V(X)＋V(Y) で、引き算にはならない
- <b>根拠</b>：分散はずれの2乗の平均で、−Y のずれも2乗すると正になり、V(−Y)＝(−1)²V(Y)＝V(Y) だから。両方のばらつきが重なって大きくなる
- <b>成り立たない場合</b>：独立でない（共分散が0でない）ときは −2Cov(X,Y) の項が付く

つなげると：「X と Y が独立なら、X−Y の分散は V(X)＋V(Y) になる。−Y のずれも2乗すれば正になり、V(−Y)＝V(Y) なので、両方のばらつきが足し合わされるからである。ただし独立でないときは、共分散の項 −2Cov(X,Y) を加える。」

### 言葉の使い分け

<b>「期待値」と「平均（標本平均）」</b>
- 期待値：確率分布から計算する理論上の平均
- 標本平均：実際のデータから計算する平均

<b>「無相関」と「独立」</b>
- 無相関：共分散が0（直線的な関係がない）
- 独立：どんな関係もない
- 独立なら無相関だが、無相関でも独立とは限らない

### 言い直し練習

「1人あたり平均1.1個買うので、ほとんどの客が1個か2個買います。」

<b>直す点</b>
- 期待値は重み付き平均で、個々の客の典型的な値とは限らない。
- この分布では20%の客が0個。売場Bなら1個買う客は0人。

<b>言い直しの例</b>
「1人あたりの期待値は1.1個で、100人来ればおよそ110個売れる見込みである。ただし20%の客は何も買わず、標準偏差は0.7個なので、個々の客の買う数はばらつく。」

### 自己チェック（説明を書いたら）

- 確率の合計が1になることを確かめた
- E(X²) と {E(X)}² を区別した
- 定数 b が分散に影響しないことに触れた
- 和・差の分散で独立（共分散）を確かめた

### よくある誤解

- 期待値は実際に起こる値 → ✕。1.1個のように実際には取らない値でもよい。
- V(X−Y)＝V(X)−V(Y) → ✕。足す。
- 共分散0なら独立 → ✕。無相関なだけ。

## 応用

### 同時分布と共分散

<b>問</b>　X＝弁当購入（1/0）、Y＝お茶購入（1/0）の同時確率が次のとき、共分散と独立かどうかを求めよ。

| (X, Y) | 確率 |
| --- | --- |
| (0, 0) | 0.4 |
| (0, 1) | 0.1 |
| (1, 0) | 0.2 |
| (1, 1) | 0.3 |

答え：周辺確率：P(X＝1)＝0.2＋0.3＝0.5、P(Y＝1)＝0.1＋0.3＝0.4。E(XY)＝P(1,1)＝0.3。Cov＝0.3−0.5×0.4＝<b>0.1</b>（正）。P(1,1)＝0.3 ≠ 0.5×0.4＝0.2 なので<b>独立ではない</b>。弁当を買う人はお茶も買いやすい。

### 売上見込みで

- 1日の来店客 300人、1人あたり期待値1.1個なら、見込み 330個。和の期待値は独立でなくても足せる。
- 客どうしが独立なら、合計の分散は 300×0.49＝147、標準偏差は約12.1個。発注の余裕を考える目安になる。
