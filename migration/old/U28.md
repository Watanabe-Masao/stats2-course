# 教科書28｜共分散・相関係数と散布図

## 学習の目標

散布図・共分散・相関を使い、層別や調整後の関係まで読む。

## ✨ 例題で式を読み解く

**この式を使う場面**　2つの量（広告回数と来店者数、気温と売上…）が「一緒に増える／減る」関係の強さを、単位に関係なく −1〜1 で表したいとき。

### 📝 例題

5週間の広告回数 x と来店者数 y（百人）は、(1,3)(2,5)(3,4)(4,6)(5,7)。共分散と相関係数を求めよ。

### 🧩 式のどこに何を入れる？

$$
r=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum(x_i-\bar x)^2}\sqrt{\sum(y_i-\bar y)^2}}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **x_i, y_i** | 各週の (広告回数, 来店者数) の組 |
| **x̄, ȳ** | 広告回数の平均3、来店者数の平均5 |
| **分子** | 偏差の積の合計（同じ向きなら＋） |
| **分母** | x と y それぞれの偏差平方和の平方根 → 単位が消える |

### 🧮 計算

1. 平均：x̄＝15/5＝3、ȳ＝25/5＝5
2. x偏差：−2, −1, 0, 1, 2　y偏差：−2, 0, −1, 1, 2
3. 偏差の積の和＝4＋0＋0＋1＋4＝**9** → 共分散 s_xy＝9/4＝**2.25**
4. 偏差平方和：x は10、y は10
5. r＝9/√(10×10)＝**0.9**

右上（積＋）と左下（積＋）に点が多いほど r は大きくなる

| r の値 | 読み方の目安 |
| --- | --- |
| 0.7〜1 | 強い正の相関 |
| 0.4〜0.7 | 中程度の正の相関 |
| −0.2〜0.2 | 直線的な関係はほぼない |
| −1〜−0.7 | 強い負の相関 |

**混同注意**　相関≠因果（気温が共通原因なら擬相関）。r は傾きの大きさではない。r＝0でも曲線の関係はありうるので、必ず散布図を見る。

**答えの読み方**　広告回数と来店者数には強い正の直線関係（r＝0.9）。ただし「広告を増やせば来店が増える」と言うには、季節など他の要因を29〜32の方法で検討する。

## 1｜まず意味をつかむ

散布図は2量の組を点で示す。相関係数は直線的な関係の強さと向きを−1〜1で表す。共分散は平均との差の積を平均する量で、単位の影響を受ける。相関は共分散を両SDで割って単位を取り除く。

r=0でも曲線の関係はあり得る。外れ値、層、観測範囲の狭さでrは変わる。相関行列は複数変数の全てのペアを並べる。層別散布図は曜日・店舗規模等で分けた関係を確認し、集計した見かけの相関と比較する。

## 2｜式と記号を読む

$$
r=\frac{s_{xy}}{s_xs_y}
$$

```txt
s_xy=Σ(x_i−x̄)(y_i−ȳ)/(n−1)
r=s_xy/(s_x s_y)
r_xy・z=(r_xy−r_xz r_yz)/√{(1−r_xz²)(1−r_yz²)}
```

## 3｜表で関係を整理する

| x | 1 | 2 | 3 |
| --- | --- | --- | --- |
| y | 2 | 4 | 5 |
| x偏差 | −1 | 0 | 1 |
| y偏差 | −5/3 | 1/3 | 4/3 |

## 4｜例題を途中から追う

上の平均はx̄=2、ȳ=11/3。共偏差和3、s_xy=1.5。s_x=1、s_y=√(7/3)なのでr≈0.982。強い正の直線関係だが因果の証明ではない。

r_xy=0.8、r_xz=0.8、r_yz=0.8なら偏相関は(0.8−0.64)/0.36≈0.444。第3変数との関係を線形に調整すると、見える関連が変わる。

## 5｜誤解と適用条件を確認する

rは勾配の大きさではない。分散0なら通常の相関は定義できない。偏相関が残ることは交絡が全て解決した証明ではない。擬相関は共通要因等で生じる。
