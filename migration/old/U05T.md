# 補講05-T｜時系列：変化・平均・繰返しを読む

この章で答えられるようになること：売上の「増えた・減った」を、基準・期間・時間の順番をはっきりさせて説明できる。増減率を重ねる計算、平均成長率（幾何平均）、移動平均、自己相関の意味が分かる。

T1〜T3は教科書06の平均の後、T4は教科書28の相関の後に学ぶとよい。

このページの用語：割合・パーセントポイント・幾何平均・移動平均・自己相関・相関係数

## はじめて

### ステップ1｜何を知りたいかで計算を選ぶ

<b>前の時点からどれだけ増えた？</b> → <b>増減率</b>（T1）。重ねるときは倍率を掛ける
<b>毎期平均で何%ずつ増えた？</b> → <b>幾何平均による平均成長率</b>（T2）
<b>細かい上下をならして傾向を見たい</b> → <b>移動平均</b>（T3）

### ステップ2｜T1 増減率は「基準」が毎回変わる

80パックが100パックに増え、その後90パックになった。「25%増えて10%減ったから15%増えた」でよいか。

1. 80→100：倍率 100÷80＝<b>1.25</b>（25%増、基準は80）
2. 100→90：倍率 90÷100＝<b>0.90</b>（10%減、基準は100）
3. 全体の倍率：1.25×0.90＝1.125 → <b>12.5%増</b>（15%ではない）
4. 80を100とする指数：100 → 125 → 112.5

（ラボ：増減率を重ねる）
＋20%→−20% で元に戻らないことを確かめる。累計の増減率＝(1＋r₁)(1＋r₂)−1。

<b>ここが一番大事</b>　増減率は分母（基準）が毎回違うので<b>足せない</b>。「20%増は1.2倍、20%減は0.8倍」と倍率に直して掛ける。

### ステップ3｜T2 平均成長率は幾何平均

aⱼ は各期の倍率、Π は「全部掛ける」記号、m は期間の数（観測点の数ではない）。

1. 80→100→90 は2期間、累計倍率 1.125
2. 平均倍率＝√1.125≒<b>1.0607</b> → 平均成長率 約<b>6.07%</b>
3. 確かめ：80×1.0607×1.0607≒90 ✓
4. 算術平均 (25%−10%)÷2＝7.5% だと 80×1.075²＝92.45 で、90を再現しない

（ラボ：平均成長率）
<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「4期の増減率を動かしても、実際の推移を再現するのは幾何平均の線だけだった」

### ステップ4｜T3 移動平均で傾向を見る

月別数量 10, 14, 12, 18, 16 の中央3点移動平均：

| 2月 | (10＋14＋12)÷3 | 12 |
| 3月 | (14＋12＋18)÷3 | 14.67 |
| 4月 | (12＋18＋16)÷3 | 15.33 |

1月と5月は片側のデータがなく計算できない。今が4月末なら5月の値はまだ無いので、4月の中央移動平均は確定できない。

（ラボ：移動平均）
<b>動かしたら書く</b>　例：「窓を3日→7日にすると曜日の波が消え、トレンドだけが残った」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　200個が250個になり、その後200個に戻った。それぞれの増減率は？
答え：200→250：50÷200＝<b>＋25%</b>。250→200：−50÷250＝<b>−20%</b>。同じ50個の変化でも基準が違うので率は違う。

<b>問2（中）</b>　1期目に＋20%、2期目に−20%だった。累計の増減率と、1期あたりの平均成長率を求めよ（√0.96≒0.980）。
答え：累計倍率 1.2×0.8＝0.96 → <b>−4%</b>。平均倍率 √0.96≒0.980 → 平均成長率 約<b>−2.0%</b>。算術平均の0%ではない。

<b>問3（やや難）</b>　月別売上 20, 26, 23, 29, 32 の中央3点移動平均を、計算できる月すべてについて求めよ。
答え：2月 (20＋26＋23)÷3＝<b>23</b>、3月 (26＋23＋29)÷3＝<b>26</b>、4月 (23＋29＋32)÷3＝<b>28</b>。上下はあるが、ならすと増加傾向が見える。

<b>まとめ（3行）</b>
1. 増減率は基準が毎回違うので足さず、倍率に直して掛ける。
2. 平均成長率は倍率の幾何平均から1を引く。
3. 移動平均は短い上下をならして傾向を見る。中央か後方かで置く位置と使える時点が違う。

## 復習

- ＋10%と−10%を続けると元に戻るか言える
- 平均成長率の求め方を言える
- 中央移動平均と後方移動平均の違いを言える

答え：
1. 戻らない。1.1×0.9＝0.99 で1%減。
2. 各期の倍率を掛けて、期間数の累乗根をとり、1を引く。
3. 中央は前後の値を使い当月に置く（最新月は計算できない）。後方は過去の値だけを使う（最新月も計算できるが、変化への追随が遅れる）。

### 式の早見

| 増減率 | (今期−前期)÷前期 |
| 累計の増減率 | (1＋r₁)(1＋r₂)…−1 |
| 指数 | 100×今期÷基準時点 |
| 平均成長率 | (倍率の積)^(1/m)−1 |
| 中央3点移動平均 | (前＋当＋後)÷3 |

### 1問で確かめる

<b>問</b>　売上が3年で 100→121 になった（2期間ではなく3時点で2期間）。平均成長率は？
答え：累計倍率 1.21、2期間なので √1.21＝1.1 → <b>10%</b>。

## 深める

### お手本：成長率の平均に幾何平均を使う理由

- <b>条件</b>：毎期の増減率から「平均して毎期何%ずつ増えたか」を求めるとき
- <b>対象と結論</b>：増減率の算術平均ではなく、倍率の幾何平均から1を引いた値を使う
- <b>根拠</b>：成長は倍率が次々に掛かるので、同じ倍率を期間数だけ掛けて実際の最終値を再現できるのは幾何平均だから
- <b>成り立たない場合</b>：途中で値が0や負になると倍率を作れないので、この式は使えない

<b>つなげると</b>
「毎期の平均成長率を求めるときは、増減率を足して割るのではなく、倍率の幾何平均から1を引く。成長は倍率が掛け算で重なるので、最終値を再現できるのは幾何平均だからである。ただし途中で値が0や負になる場合は使えない。」

### 言葉の使い分け

<b>「増減率」と「ポイント」</b>
- 増減率：前の値を基準にした変化の割合（10%→12% は20%増）
- ポイント：割合どうしの差（10%→12% は2ポイント増）

<b>「指数」と「実数」</b>
- 指数125：基準の1.25倍という意味
- 125個という意味ではない

<b>「トレンド」と「予測」</b>
- トレンド：過去の持続的な傾向
- 移動平均の線を延ばしても、将来の予測になるとは限らない

### 言い直し練習

「昨年は30%増、今年は30%減だったので、2年前と同じ売上に戻りました。」
<b>直す点</b>
- 30%増と30%減は基準が違う（2年目の基準は増えた後の値）。
- 倍率で 1.3×0.7＝0.91 なので、元より9%少ない。
<b>言い直しの例</b>
「昨年30%増、今年30%減なので、2年前と比べた倍率は 1.3×0.7＝0.91 となり、売上は2年前より9%少ない。減少率は増えた後の売上を基準にするため、同じ30%でも金額は大きい。」

### 自己チェック（説明を書いたら）

- 何を基準（分母）にした率かを書いた
- 率とポイントを区別した
- 期間の数（観測点の数ではない）を正しく数えた
- 移動平均の窓と置く位置（中央・後方）を書いた

### よくある誤解

- 増減率は足して累計できる → ✕。倍率を掛ける。
- 3時点のデータは3期間 → ✕。変化の区間は2つ。
- 移動平均の窓は広いほど良い → ✕。滑らかになる一方、急な変化を見落とし、後方平均では遅れる。

## 応用

### 寄与度（どの部門が全体の伸びに効いたか）

全体の増減率を、部門ごとの「全体への寄与」に分ける。寄与度＝その部門の増減額÷<b>全体の前期の値</b>。部門の寄与度を足すと全体の増減率になる。

<b>問</b>　A部門 60→66、B部門 40→38（合計 100→104）。全体の増減率と各部門の寄与度は？
答え：全体：4÷100＝<b>＋4%</b>。A：(66−60)÷100＝<b>＋6ポイント</b>、B：(38−40)÷100＝<b>−2ポイント</b>。合計＋4で全体と一致する。A部門自体の増減率（6÷60＝10%）とは別物。

### T4 自己相関で繰り返しを探す（教科書28の後に）

同じ系列を k 期ずらして、自分自身との相関をとる。日次データでラグ7が高ければ、7日おきに似た動き（曜日の波）がある可能性。

（ラボ：自己相関）
ラグ k を動かして自己相関の棒を見る。曜日の波を0にするとラグ7の山が消え、トレンドを大きくすると全ラグが正に寄る。

自己相関を読むときの注意
- ラグ1が0.10、ラグ7が0.75なら「7日間隔で似た動き」が示唆されるが、曜日が原因と確定したわけではない。
- 信頼限界のない図で、棒が高いだけで有意と断定しない。
- 独立を仮定した検定を時系列にそのまま当てると、標準誤差やp値が不適切になりうる。
- 計算式には流儀の違いがあるので、ソフトの定義を確認する。

### 仕事の場面で

- 前年同月比で見ると、季節の波をそろえて比べられる。前月比は季節の影響を受ける。
- 日販の7日移動平均は曜日の波を消して傾向を見るのに向く。最新日まで見たいなら後方7日平均を使い、遅れがあることを前提にする。
