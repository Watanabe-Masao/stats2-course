# 教科書24｜帰無仮説・対立仮説・p値・過誤

## 学習の目標

仮説・p値・過誤・検出力を区別し、検定の結論を正しく書く。

## ✨ 例題で式を読み解く

**この流れを使う場面**　「変化があったと言えるか？」を判断するすべての検定。① 仮説を立てる → ② 統計量を計算 → ③ p値（または棄却域）で判断 → ④ 結論を言葉にする、の4段階は25〜27・30・32でも同じ。

### 📝 例題

従来の平均客単価は100百円・標準偏差10百円。新施策後に25人を調べると平均104.4百円だった。上がっても下がっても「変化した」とみなす（両側）。有意水準5%で検定せよ。

### 🧩 式のどこに何を入れる？

$$
z=\frac{\bar x-\mu_0}{\sigma/\sqrt n}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **H0: μ＝μ₀** | 「変化していない」：μ＝100 |
| **H1: μ≠μ₀** | 「上でも下でも変化」→ 両側 |
| **x̄** | 25人の平均：104.4 |
| **σ** | 既知の標準偏差：10 |
| **α** | 有意水準 0.05（両側なので各側2.5%） |

### 🧮 計算

1. 仮説：H0: μ＝100、H1: μ≠100、α＝0.05
2. SE＝10/√25＝2 → z＝(104.4−100)/2＝**2.2**
3. p値＝2×P(Z≥2.2)＝2×0.0139＝**0.028**
4. p＝0.028 ≤ 0.05（|z|＝2.2 ＞ 1.96）→ **H0を棄却**
5. 結論：「客単価は変化したと判断できる（有意水準5%）」

図：p値＝H0が正しいとして、今回以上に極端な値が出る確率（両側なので左右の面積の合計）

**よくある誤解**　p＝0.028 は「H0が正しい確率が2.8%」ではない。また棄却できなかったときは「差がないと証明」ではなく「差があるとは言えない」。

**答えの読み方**　統計的に有意でも、4.4百円の差が実務的に大きいかは別に判断する。検定は「偶然で説明できるか」を見るもので、効果の大きさは区間推定（22）で示す。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。

x̄・σ・n を動かすと z と p 値が、本当の平均 μ₁ を動かすと検出力（1−β）が変わります。α と両側／片側も切り替えられます。

## 1｜まず意味をつかむ

帰無仮説H0は検討の基準となる主張、対立仮説H1はその対案。先に有意水準αと片側・両側を決め、H0とモデルの仮定の下で観測結果以上に極端な統計量が出る確率pを計算する。p≤αなら棄却、そうでなければ棄却しない。

第1種過誤は正しいH0を棄却、第2種過誤は誤ったH0を棄却しないこと。検出力は1−βで、特定の対立値に依存する。標本数、効果の大きさ、分散、αによって変わる。

## 2｜式と記号を読む

$$
\operatorname{Power}=1-\beta
$$

```txt
第1種過誤：P(棄却|H0が真)=α（設計した上限等）
第2種過誤：β=P(非棄却|指定した対立値)
検出力=1−β
```

## 3｜表で関係を整理する

| 実際／判断 | 棄却 | 棄却しない |
| --- | --- | --- |
| H0が真 | 第1種過誤 | 正しい非棄却 |
| H0が偽 | 検出 | 第2種過誤 |

## 4｜例題を途中から追う

両側の平均検定でH0:μ=100、H1:μ≠100、p=0.03、α=0.05なら棄却する。p=0.03は『H0が真の確率3%』ではない。p=0.20なら、差がないと証明されたのでなく、この検定では棄却できなかったという結論。

上昇だけを問題にする片側検定ならH1:μ>100。結果を見てから都合のよい片側へ変えると、予定した過誤制御が崩れる。

## 5｜誤解と適用条件を確認する

統計的有意と実務的な大きさは別。多くの検定を無調整で繰り返すと全体の誤棄却を増やし得る。p値単独で効果の大きさや再現性を保証しない。

## 6｜自力で確かめる

H0が誤っているのに棄却しなかったのは何種の過誤か。検出力0.8なら、その指定対立値でβはいくつか。

解答：第2種過誤、β=0.2。αを0.05にしたことからβも0.05とは言えない。

## 7｜つまずいたら戻る

18の標本間変動、20の参照分布を確認し、25〜27で具体的な統計量を選ぶ。
