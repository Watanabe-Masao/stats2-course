# 教科書05｜度数分布・ヒストグラム・箱ひげ図

この章で答えられるようになること：たくさんの数字を度数分布表・ヒストグラム・箱ひげ図にまとめ、分布の形（どこに集まり、どちらに裾が伸びるか）と外れ値を読み取れる。

このページの用語：度数分布表・ヒストグラム・箱ひげ図・四分位数・四分位範囲・外れ値・中央値

## はじめて

### ステップ1｜何を知りたいかで図を選ぶ

<b>分布の「形」を見たい</b>（どこに集まり、どちらに裾が伸びるか）→ <b>度数分布表・ヒストグラム</b>
<b>真ん中と散らばり・外れ値を手早く比べたい</b>（店舗別・月別など）→ <b>箱ひげ図</b>
<b>個々の値も残したい</b>（データが少ない）→ <b>幹葉図</b>（12, 15, 21 なら「1｜2 5」「2｜1」）

### ステップ2｜例題のデータで表を作る

20日分の売上（万円）を小さい順に並べると次のとおり。度数分布表を作り、四分位数・四分位範囲・外れ値の柵を求めよ。
12, 15, 18, 19, 21, 22, 22, 24, 25, 26, 27, 28, 29, 30, 31, 33, 35, 38, 42, 55

| 階級（万円） | 度数 | 相対度数（累積） |
| 10以上20未満 | 4 | 0.20（0.20） |
| 20〜30 | 9 | 0.45（0.65） |
| 30〜40 | 5 | 0.25（0.90） |
| 40〜50 | 1 | 0.05（0.95） |
| 50〜60 | 1 | 0.05（1.00） |

相対度数＝度数÷20。かっこ内の累積相対度数は上から足していった値。

### ステップ3｜四分位数と外れ値を求める

IQR＝Q₃−Q₁、柵＝Q₁−1.5IQR、Q₃＋1.5IQR

1. 中央値 Q₂＝10番目と11番目の平均＝(26＋27)÷2＝<b>26.5</b>
2. Q₁＝下半分10個の真ん中＝(21＋22)÷2＝<b>21.5</b>
3. Q₃＝上半分10個の真ん中＝(31＋33)÷2＝<b>32</b>
4. IQR＝32−21.5＝<b>10.5</b>、1.5×IQR＝15.75
5. 柵は 21.5−15.75＝5.75 と 32＋15.75＝47.75 → <b>55は外れ値候補</b>

図：上：ヒストグラム（度数分布表を図にしたもの）。下：箱ひげ図（ひげは柵の内側の最大値 42 まで）

<b>ここが一番大事</b>　売上は20万円台に集まり、右（大きい側）に裾が伸びている。55万円の日は「誤り」と決めつけず、理由（イベントなど）を確かめる。

### ステップ4｜動かして確かめる

（ラボ：平均と中央値のシミュレーター）
<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「1つの値を大きな外れ値にすると、平均は大きく動くが中央値はほとんど動かない」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　ステップ2の表で、売上が30万円未満の日の割合はいくらか。
答え：<b>0.65（65%）</b>。「20〜30」の行の累積相対度数を読む。

<b>問2（中）</b>　9個のデータ 3, 5, 6, 7, 8, 9, 10, 12, 30 の中央値・Q₁・Q₃・IQRを求め、外れ値候補を答えよ（Q₁・Q₃は中央値を除いた下半分・上半分の中央値とする）。
答え：中央値＝<b>8</b>（5番目）。Q₁＝(5＋6)÷2＝<b>5.5</b>、Q₃＝(10＋12)÷2＝<b>11</b>、IQR＝<b>5.5</b>。上の柵は 11＋1.5×5.5＝19.25 なので<b>30が外れ値候補</b>。

<b>問3（やや難）</b>　「0〜5」に10個、「5〜15」に10個のデータがある。ヒストグラムで2つの棒の高さは同じにしてよいか。また、箱ひげ図で中央値が同じ2つの店は、同じ分布と言えるか。
答え：<b>同じにしてはいけない</b>。階級の幅が違うので、高さは度数密度（度数÷幅）にする：10÷5＝2 と 10÷10＝1。こうすると面積（高さ×幅）がどちらも10で、度数を正しく表す。
<b>同じ分布とは言えない</b>。中央値が同じでも、散らばり・裾の向き・山の数は違うことがある。

<b>まとめ（3行）</b>
1. 形を見るならヒストグラム、真ん中と散らばりを比べるなら箱ひげ図。
2. 四分位範囲 IQR＝Q₃−Q₁。Q₁−1.5IQR 未満、Q₃＋1.5IQR 超が外れ値候補。
3. 階級の幅が違うときは、高さを度数密度にして面積で度数を表す。

## 復習

### 思い出す（何も見ずに答える）

- 相対度数と累積相対度数の求め方を言える
- 外れ値の柵の式を書ける
- 箱ひげ図だけでは分からないことを1つ言える

答え：
1. 相対度数＝度数÷全体の数。累積相対度数は、小さい階級から相対度数を足していった値。
2. Q₁−1.5×IQR と Q₃＋1.5×IQR（IQR＝Q₃−Q₁）。
3. 山の数（単峰か多峰か）。箱ひげ図は5つの数だけを示すため。

### 図の早見

| ヒストグラム | 量的データの分布の形 |
| 箱ひげ図 | 中央値・散らばり・外れ値を複数グループで比較 |
| 幹葉図 | 少ないデータで、個々の値も残す |
| 棒グラフ | 質的データ（カテゴリ）の度数 |
| 累積度数グラフ | 「○以下が何%」を読む |

### 1問で確かめる

<b>問</b>　階級「0以上10未満」が度数4、「10以上30未満」が度数6のヒストグラムを描く。それぞれの棒の高さ（度数密度）はいくらか。
答え：4÷10＝<b>0.4</b>、6÷20＝<b>0.3</b>。幅の広い階級を高さ6にすると、面積が実際より大きく見えてしまう。

## 深める

### お手本：外れ値の判断を説明する

- <b>条件</b>：Q₁−1.5×IQR 未満、または Q₃＋1.5×IQR を超える値があるとき
- <b>対象と結論</b>：その値は「外れ値候補」として扱う
- <b>根拠</b>：真ん中50%の幅（IQR）の1.5倍よりも、さらに外側に離れていて、他の大多数から飛び抜けているから
- <b>成り立たない場合</b>：この基準は目安で、外れ値候補でも正しい値のことがある（イベント日など）。誤りと決めつけて削らず、理由を確認する

<b>つなげると</b>
「Q₃＋1.5×IQR を超える値は外れ値候補として扱う。真ん中50%の幅の1.5倍よりさらに外側にあり、他から飛び抜けているからである。ただしこれは目安で、正しい値のこともあるので、理由を確かめずに削除しない。」

### 言葉の使い分け

<b>「度数」「相対度数」「累積度数」</b>
- 度数：その階級に入る個数（9日）
- 相対度数：全体に対する割合（9÷20＝0.45）
- 累積度数：小さい階級からの合計（30万円未満は13日）

<b>「ヒストグラム」と「棒グラフ」</b>
- ヒストグラム：量的データ。棒をすき間なく並べ、<b>面積</b>が度数を表す
- 棒グラフ：質的データ。棒の<b>高さ</b>が度数を表し、並べる順番は自由

<b>「外れ値」と「異常値」</b>
- 外れ値：他から飛び抜けた値（統計的な目安で判定）
- 誤った値：入力ミスなど。外れ値がすべて誤りとは限らない

### 言い直し練習

「A店とB店は箱ひげ図の真ん中の線が同じなので、売上の分布は同じです。」
<b>直す点</b>
- 「真ん中の線」は中央値。中央値が同じでも、箱の幅（IQR）やひげの長さ（散らばり・裾）は違うことがある。
- 山の数は箱ひげ図からは分からない。
<b>言い直しの例</b>
「A店とB店は中央値が同じなので、売上の真ん中の水準は同じである。ただし箱の幅やひげの長さを比べないと、散らばりや裾の伸び方が同じかは分からない。山の数まで確かめるにはヒストグラムを見る。」

### 自己チェック（説明を書いたら）

- 「真ん中」「散らばり」「形」のどれについて言っているか明確にした
- 外れ値の判定基準（柵の式）を書いた
- 外れ値を「誤り」と決めつけていない
- その図から言えないことを1つ以上書いた

### もう一段深く：分布の形の名前

| 右に裾が長い | 大きい値の側に少数が伸びる（売上・所得に多い）。平均＞中央値になりやすい |
| 左に裾が長い | 小さい値の側に伸びる（簡単なテストの点数など） |
| 左右対称・単峰 | 真ん中に山が1つ（身長など） |
| 多峰 | 山が2つ以上。性質の違う集団が混ざっている可能性（平日と休日など） |

### よくある誤解

- 四分位数はどこで計算しても同じ → ✕。求め方が複数あり、ソフトや問題で少し違う。試験では問題文の定義に従う。
- 箱ひげ図のひげは必ず最小値・最大値まで → ✕。柵の内側の端まで伸ばし、外れ値を点で描く流儀もある。凡例を確かめる。
- 階級の幅を変えても形は同じ → ✕。幅の取り方で見え方が変わる。

## 応用

### 平均と中央値の選び方へ（教科書06）

ステップ2の売上は右に裾が長い。平均は 552÷20＝27.6、中央値は26.5。大きい値に引っ張られて平均＞中央値になっている。「典型的な1日」を言いたいなら中央値が向く。

### 店舗の比較で

<b>問</b>　5店舗の日販を箱ひげ図で並べた。C店だけ箱が長く、上のひげも長い。C店について何が言えるか。
答え：C店は日販の散らばりが大きく、特に売上の多い日の側に裾が伸びている。日によって売上が大きく変わる（天候・イベントの影響が大きい）可能性がある。発注量を決めるときは、平均だけでなく散らばりも考える必要がある。

### 仕事の場面で

- 客単価のヒストグラムを見ると、「1,000円前後」と「3,000円前後」の二山になることがある。単身客と家族客が混ざっているサイン。平均だけで判断すると、どちらの客にも合わない施策になりやすい。
- 時間の順番があるデータ（日別売上の推移）は、ヒストグラムでは順番が消える。推移を見るなら補講 05-T の折れ線・移動平均を使う。
