# 教科書25｜1標本・2標本の平均検定

## 学習の目標

1標本・独立2標本・対応2標本から、平均の検定を選ぶ。

## ✨ 例題で式を読み解く

**この式を使う場面**　「平均が基準値と違うか」「2つの平均が違うか」。まず**データの取り方**で式を選ぶ。

### 🧭 どのt検定？

| データの取り方 | 使う式 | 自由度 |
| --- | --- | --- |
| 1つの集団 vs 基準値 | 1標本t | n−1 |
| **同じ**店舗の前後 | 差 D を作って1標本t（対応あり） | n−1 |
| **別々**の2群・分散が等しいと仮定 | 併合分散のt | n₁＋n₂−2 |
| **別々**の2群・等分散を仮定しない | Welchのt | Welchの式 |

### 📝 例題

新しい陳列を導入した16店舗の売上指数の平均は104、標準偏差 s は8。基準は100。両側5%で「基準と異なる」と言えるか。

### 🧩 式のどこに何を入れる？

$$
t=\frac{\bar x-\mu_0}{s/\sqrt n}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **x̄** | 16店舗の平均：104 |
| **μ₀** | 基準：100 |
| **s** | データの標準偏差：8（σが未知なので t） |
| **n** | 16店舗 → 自由度15 |

### 🧮 計算

1. SE＝8/√16＝**2**
2. t＝(104−100)/2＝**2.0**、自由度15
3. 両側5%の点 t₀.₉₇₅(15)＝**2.131**
4. |2.0| ＜ 2.131 → **棄却しない**

図：t＝2は正規なら棄却域（1.96）だが、t(15)では届かない

**よくある間違い**　同じ店舗の前後データを「別々の2群」として計算しない（対応ありは差 D の1標本t）。また、σ既知の z の基準1.96を t にそのまま使わない。

**答えの読み方**　「16店舗では、平均が100と異なるとは言えない（5%水準）」。効果がないと証明されたわけではないので、店舗数を増やして再確認する選択肢がある。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。そのあと確認問題へ。

t分布で ν₁＝15 にすると例題の基準値 2.131 が出ます。自由度を下げると基準値が大きくなり、棄却しにくくなります。

検定の流れ（z・p値・検出力）は24と同じ道具で確かめられます。

もう一つ：2群の t 検定。平均の差・標準偏差・日数を動かし、t と p値がどう変わるかを確かめます。

## 1｜まず意味をつかむ

検定の前に、比較対象、帰無仮説、独立性、対応の有無を決める。1標本では母平均を基準値と比較。独立2群では平均差、対応ありでは各組の差Dの平均を検討する。

母分散既知の正規平均はz、未知の正規平均はt。独立2群で未知分散の場合、等分散を置くなら併合分散のt、置かないならWelchのtを使う。対応のある観測を独立2群として扱うと、必要な共分散構造を無視する。

## 2｜式と記号を読む

$$
t=\frac{\bar D-\Delta_0}{s_D/\sqrt n}
$$

```txt
1標本：t=(x̄−μ0)/(s/√n)、df=n−1
対応：t=(D̄−Δ0)/(s_D/√n)、df=n−1
Welch：t={(x̄1−x̄2)−Δ0}/√(s1²/n1+s2²/n2)
等分散：sp²={(n1−1)s1²+(n2−1)s2²}/(n1+n2−2)
```

## 3｜表で関係を整理する

| 設計 | 使うデータ | 代表的な未知分散法 |
| --- | --- | --- |
| 1集団と基準 | 元の標本 | 1標本t |
| 同じ店舗の前後 | 各店の差 | 対応t |
| 別店舗の2群 | 各群の平均と分散 | Welch又は等分散t |

## 4｜例題を途中から追う

n=16、平均104、s=8、H0:μ=100ならt=4/(8/4)=2、df15。両側5%点2.131より小さく非棄却。『平均104だから差が有意』とは言えない。

独立2群でn1=n2=10、平均12と10、s1²=s2²=4ならSE=√0.8≈0.8944、t≈2.236。等分散法のdfは18。対応ありなら、この式ではなく差のSDを用意する。

### 関連する公式範囲の内容

Welchの自由度はa=s1²/n1,b=s2²/n2としてν=(a+b)²/{a²/(n1−1)+b²/(n2−1)}。母分散既知なら平均差を√(σ1²/n1+σ2²/n2)で標準化しzを使う。通常の独立正規モデルでの式である。

## 5｜誤解と適用条件を確認する

片側・両側はデータを見る前に決める。等分散の仮定を黙って追加しない。観測単位の重複・時系列依存・極端な非正規性を点検する。
