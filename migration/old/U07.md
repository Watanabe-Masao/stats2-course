# 教科書07｜分散・標準偏差・変動係数

この章で答えられるようになること：「どちらが安定している？」と聞かれたとき、分散・標準偏差で散らばりを数で示し、平均の大きさが違うものは変動係数で比べられる。nで割るか n−1 で割るかを目的で選べる。

このページの用語：偏差・分散・不偏分散・標準偏差・変動係数・四分位範囲

## はじめて

### ステップ1｜何を比べたいかで指標を選ぶ

<b>ばらつきの大きさを元の単位で言いたい</b>（「±何個ぶれる」）→ <b>標準偏差</b>
<b>平均の大きさが違うものどうしを比べたい</b>（高額商品と低額商品）→ <b>変動係数 CV＝標準偏差÷平均</b>
<b>手元のデータを記述したいのか、母集団を推定したいのか</b> → 記述なら <b>n</b> で割る、推定なら <b>n−1</b> で割る（不偏分散）

### ステップ2｜「平均からのずれ」を図で見る

（図：点線の長さ＝偏差。売場Bは点線が長く、分散が9倍）

偏差（各値−平均）を足すと必ず0になる。だから<b>2乗してから足す</b>。これが偏差平方和で、件数で割ると分散になる。

### ステップ3｜例題で計算する

売場Bの5日間の販売数は 4, 7, 10, 13, 16 個。n で割る分散 v、不偏分散 s²、標準偏差 s、変動係数を求めよ。売場A（8, 9, 10, 11, 12）と比べよ。

| xᵢ | xᵢ−x̄ | (xᵢ−x̄)² |
| 4 | −6 | 36 |
| 7 | −3 | 9 |
| 10 | 0 | 0 |
| 13 | 3 | 9 |
| 16 | 6 | 36 |
| <b>合計</b> | 0 | <b>90</b> |

1. 平均 x̄＝50÷5＝10
2. 偏差平方和＝<b>90</b>
3. n で割る分散 v＝90÷5＝<b>18</b>
4. 不偏分散 s²＝90÷4＝<b>22.5</b>
5. 標準偏差 s＝√22.5≒<b>4.74個</b>、CV＝4.74÷10≒<b>0.47</b>

売場Aは偏差平方和10、s²＝2.5、s≒1.58個、CV≒0.16。

<b>ここが一番大事</b>　平均は同じ10個でも、売場Bは±5個ほどぶれるのが普通。発注や在庫は売場Bのほうが余裕が必要。分散の単位は「個²」なので、大きさを語るときは標準偏差を使う。

### ステップ4｜動かして確かめる

（ラボ）
<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「散らばり倍率 c を2倍にすると、標準偏差は約2倍、分散は約4倍になった。全データに同じ数を足しても分散は変わらない」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　2, 4, 6 の平均・偏差平方和・不偏分散・標準偏差（不偏分散の平方根）を求めよ。
答え：平均<b>4</b>、偏差平方和 4＋0＋4＝<b>8</b>、不偏分散 8÷2＝<b>4</b>、標準偏差<b>2</b>。（n で割る分散は 8÷3≒2.67）

<b>問2（中）</b>　1, 3, 5, 7 の偏差平方和、n で割る分散、不偏分散を求めよ。また、全てのデータを2倍にすると不偏分散はどうなるか。
答え：平均4、偏差平方和 9＋1＋1＋9＝<b>20</b>、n で割る分散＝<b>5</b>、不偏分散＝20÷3≒<b>6.67</b>。2倍にすると偏差も2倍、2乗するので分散は<b>4倍</b>（標準偏差は2倍）。

<b>問3（やや難）</b>　商品Pは日販の平均100個・標準偏差10個、商品Qは平均20個・標準偏差4個。相対的にばらつきが大きいのはどちらか。
答え：CV は P＝10÷100＝0.10、Q＝4÷20＝0.20。標準偏差だけなら P のほうが大きいが、平均に対する<b>相対的なばらつきは Q のほうが大きい</b>。

<b>まとめ（3行）</b>
1. 分散は偏差の2乗の平均。標準偏差はその平方根で、元の単位に戻る。
2. 手元のデータの記述は n、母集団の推定（不偏分散）は n−1 で割る。
3. 平均の大きさが違うものは変動係数（標準偏差÷平均）で比べる。

## 復習

- 偏差をそのまま足さずに2乗する理由を言える
- 全データに a を足す・b 倍するときの分散の変化を言える
- 変動係数を使う場面を言える

答え：
1. 偏差の合計は必ず0になり、散らばりを表せないから。
2. a を足しても分散は変わらない。b 倍すると分散は b² 倍（標準偏差は |b| 倍）。
3. 平均の大きさが違うものの散らばりを、相対的に比べるとき（正の量のみ）。

### 式の早見

| n で割る分散 | Σ(xᵢ−x̄)²÷n |
| 不偏分散 | Σ(xᵢ−x̄)²÷(n−1) |
| 計算の近道 | Σ(xᵢ−x̄)²＝Σxᵢ²−(Σxᵢ)²÷n |
| 標準偏差 | 分散の平方根 |
| 変動係数 | 標準偏差÷平均 |

### 1問で確かめる

<b>問</b>　4, 7, 10, 13, 16 の偏差平方和を「計算の近道」で求めよ。
答え：Σx²＝16＋49＋100＋169＋256＝590、(Σx)²÷n＝50²÷5＝500。590−500＝<b>90</b>（表で求めた値と一致）。

## 深める

### お手本：不偏分散で n−1 で割る理由

- <b>条件</b>：標本から母集団の分散を推定するとき
- <b>対象と結論</b>：偏差平方和を n−1 で割った不偏分散を使う
- <b>根拠</b>：平均を標本自身から計算するため、偏差の合計が0という制約が1つかかり、自由に動ける偏差は n−1 個になる。n で割ると母分散を平均的に小さく見積もってしまうから
- <b>成り立たない場合</b>：手元のデータそのものの散らばりを記述するだけなら、n で割ってよい

<b>つなげると</b>
「標本から母分散を推定するときは、偏差平方和を n−1 で割る。平均を標本から求めるので偏差の合計が0という制約がかかり、n で割ると母分散を平均的に小さく見積もるからである。ただし手元のデータを記述するだけなら n で割る。」

### 言葉の使い分け

<b>「分散」と「標準偏差」</b>
- 分散：偏差の2乗の平均。単位は元の2乗（個²）
- 標準偏差：分散の平方根。単位は元と同じ（個）

<b>「標本分散」と「不偏分散」</b>
- 本や流儀により「標本分散」が n で割る場合と n−1 で割る場合がある
- 試験では式（分母）を見て判断する

<b>「標準偏差」と「変動係数」</b>
- 標準偏差：絶対的なばらつき（単位あり）
- 変動係数：平均に対する相対的なばらつき（単位なし）

### 言い直し練習

「高額商品の売上は標準偏差が大きいので、低額商品より売上が不安定です。」
<b>直す点</b>
- 平均が大きいと、標準偏差も大きくなりやすい。平均の違いを考えていない。
- 「不安定」を比べるなら、変動係数で相対的なばらつきを見る。
<b>言い直しの例</b>
「高額商品は標準偏差が大きいが、売上の平均も大きいので、それだけで不安定とは言えない。変動係数（標準偏差÷平均）で比べると、平均に対するばらつきの大きさが分かる。」

### 自己チェック（説明を書いたら）

- n で割ったか n−1 で割ったか、理由とともに書いた
- 分散と標準偏差の単位を区別した
- 平均が違うものの比較で変動係数を検討した
- 変動係数が使えない場合（平均が0付近・負、摂氏温度など）を意識した

### もう一段深く：変換と分散

| 変換 | 平均 | 分散 |
| x＋a | x̄＋a | 変わらない |
| bx | bx̄ | b² 倍 |
| bx＋a | bx̄＋a | b² 倍 |

「円」を「千円」にする（b＝1/1000）と分散は 1/1000000 倍。教科書08の標準化はこの性質を使う。

### よくある誤解

- 不偏分散の平方根 s は母標準偏差の不偏推定量 → ✕。分散は不偏だが、平方根をとると少し小さめに偏る。
- 範囲（最大−最小）があれば散らばりは十分 → ✕。両端の2つしか使わず、外れ値に左右される。四分位範囲や標準偏差も見る。
- 変動係数はどんなデータにも使える → ✕。0に意味がある正の量で使う。

### n で割るか n−1 で割るか

（ラボ）n で割った分散は、標本を何度も取り直して<b>平均すると</b>母分散より小さくなり、n が小さいほどその差が大きい。1回の標本では母分散より大きくなることもある。詳しくは 教科書21 で。

### ローレンツ曲線とジニ係数（不平等の度合い）

非負の量（所得・売上）を小さい順に並べ、横軸に「累積の人数割合」、縦軸に「累積の量の割合」をとった曲線がローレンツ曲線。全員同じなら対角線になる。ジニ係数＝対角線と曲線の間の面積×2 で、0に近いほど均等、1に近いほど偏っている。

<b>問</b>　4店の売上が 1, 1, 2, 6（合計10）。ローレンツ曲線の点と、ジニ係数を求めよ。
答え：累積の店割合 0.25, 0.5, 0.75, 1 に対し、累積売上割合は 0.1, 0.2, 0.4, 1.0。曲線の下の面積を台形で足す：0.25×{(0＋0.1)＋(0.1＋0.2)＋(0.2＋0.4)＋(0.4＋1.0)}÷2＝0.25×2.4÷2＝<b>0.3</b>。ジニ係数＝2×(0.5−0.3)＝<b>0.4</b>。

### 仕事の場面で

- 商品ごとの日販のばらつきを変動係数で並べると、「欠品・廃棄が起きやすい商品」の候補が分かる。
- 店舗間の売上の偏りはローレンツ曲線・ジニ係数で表せる（上位何%の店で売上の何%か）。
