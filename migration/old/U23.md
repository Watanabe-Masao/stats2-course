# 教科書23｜分散・2群の推定

## 学習の目標

母分散・2群の差と比・相関の区間推定で、対象を取り違えない。

## ✨ 例題で式を読み解く

**この式を使う場面**　平均ではなく**ばらつき（母分散）**の範囲を推定したいとき。品質の安定性、作業時間のばらつきなど。正規母集団が前提。

### 🧭 何の区間？ → 使う分布

| 推定したいもの | 中心 | 分布 |
| --- | --- | --- |
| 母分散 | s² | χ²(n−1)・左右非対称 |
| 平均の差（独立） | x̄₁−x̄₂ | t（Welch等） |
| 平均の差（対応あり） | 差の平均 D̄ | t(n−1) |
| 分散の比 | s₁²/s₂² | F |
| 比率の差 | p̂₁−p̂₂ | 正規近似 |

### 📝 例題

袋詰め作業10回の重さの不偏分散は s²＝4（g²）。χ²(9) の左累積0.025点は2.700、0.975点は19.023。母分散の95%信頼区間を求めよ。

### 🧩 式のどこに何を入れる？

$$
\frac{(n-1)s^2}{\chi^2_{0.975}(n-1)}\le\sigma^2\le\frac{(n-1)s^2}{\chi^2_{0.025}(n-1)}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **n** | 作業回数：10 → 自由度9 |
| **s²** | 不偏分散：4 |
| **χ²₀.₉₇₅** | 大きい方の点 19.023 → **下限**の分母 |
| **χ²₀.₀₂₅** | 小さい方の点 2.700 → **上限**の分母 |

### 🧮 計算

1. (n−1)s²＝9×4＝**36**
2. 下限＝36/19.023＝**1.892**
3. 上限＝36/2.700＝**13.333**
4. SDの区間にするなら平方根：約 **1.38〜3.65 g**

図：χ²分布は右に長い。だから区間も s² を中心にした±にはならない

**よくある間違い**　大きい点で割ると小さい値になる→下限。分母を逆にすると上限と下限が入れ替わる。また「s²±◯」の形では作れない。

**答えの読み方**　10回だけではばらつきの推定はかなり不確か（分散で約2〜13、7倍の幅）。安定性を評価するなら回数を増やす。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。

「χ²分布」を選び ν₁＝9 にすると、例題の 2.700 と 19.023 が出ます。自由度を変えると左右の点の非対称さが変わります。

もう一つ：2つの平均の差。点線（データのばらつき）と実線（平均のぶれ）を見比べ、Welch と等分散で自由度がどう変わるか確かめます。

## 1｜まず意味をつかむ

分散は0以上で、正規母集団では不偏分散をχ²に結びつけた区間を使う。左右非対称なので平均のような単純な±ではない。独立な正規2母集団の分散比はF分布を使う。

平均差は独立2群か同じ対象の対応ありかを先に決める。独立・等分散なら併合分散、等分散を仮定しないならWelch。同じ人の前後なら差Dを作って1標本のt区間にする。

## 2｜式と記号を読む

$$
\left[\frac{(n-1)s^2}{\chi^2_{1-\alpha/2,n-1}},\frac{(n-1)s^2}{\chi^2_{\alpha/2,n-1}}\right]
$$

```txt
正規母分散：[(n−1)s²/qχ²_(1−α/2), (n−1)s²/qχ²_(α/2)]
独立平均差：(x̄1−x̄2) ± t*√(s1²/n1+s2²/n2)（Welchの自由度）
比率差近似：(p̂1−p̂2) ± z*√{p̂1(1−p̂1)/n1+p̂2(1−p̂2)/n2}
分散比R=s1²/s2²：[R/qF_(1−α/2),R/qF_(α/2)]
```

## 3｜表で関係を整理する

| 対象 | 中心 | 参照 |
| --- | --- | --- |
| 母分散 | s² | χ²（正規） |
| 母平均差 | x̄1−x̄2／D̄ | t又はz |
| 母分散比 | s1²/s2² | F（独立正規） |
| 母比率差 | p̂1−p̂2 | 大標本正規 |

## 4｜例題を途中から追う

n=10、s²=4で、χ²自由度9の左累積0.025点2.700、0.975点19.023を与える。分散区間は36/19.023〜36/2.700≒1.892〜13.333。SD区間なら両端の平方根を取る。

対応差n=16、D̄=3、s_D=4、t_0.975,15=2.131なら、平均差の区間は3±2.131×1=0.869〜5.131。

### 関連する公式範囲の内容

相関係数ρの区間は、独立な2変量正規標本でn>3の場合、Fisher変換z_r=atanh(r)=0.5log((1+r)/(1−r))を使い、z_r±z*/√(n−3)の両端をtanhで戻す近似がある。r=0.5,n=100ならz_r≈0.5493、95%の変換尺度区間約0.3503〜0.7483、元尺度は約0.337〜0.634。r=±1ではこの変換をそのまま計算しない。

## 5｜誤解と適用条件を確認する

分位点は左側累積で定義。Fの自由度はn1−1,n2−1。比率差の区間では通常各群のp̂をSEへ使う。検定で使うプール比率と区別する。

## 6｜自力で確かめる

対応差n=25、平均差2、差のSD5、t*=2.064なら95%区間は。母分散の区間をそのまま母SDの区間と呼べるか。

解答：2±2.064×1=−0.064〜4.064。SDなら分散区間の平方根を取る。
