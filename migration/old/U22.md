# 教科書22｜平均・割合の信頼区間

## 学習の目標

平均・比率の信頼区間を、仮定・標準誤差・確率点から構成する。

## ✨ 例題で式を読み解く

**この式を使う場面**　「母平均（または母比率）はだいたいどの範囲か」を幅で答えるとき。形はいつも **推定値 ± 確率点 × SE**。

### 📝 例題

① 客単価の母標準偏差は10百円と分かっている。100人を調べた平均が50百円のとき、母平均の95%信頼区間は？　② 400人中80人が購入したとき、購入率の95%信頼区間は？

### 🧩 式のどこに何を入れる？

$$
\bar x\pm z_{0.975}\frac{\sigma}{\sqrt n}\qquad \hat p\pm z_{0.975}\sqrt{\frac{\hat p(1-\hat p)}{n}}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **x̄** | 標本平均：50 |
| **σ** | 既知の母SD：10（未知なら s と t を使う） |
| **n** | 調べた人数：100 / 400 |
| **z₀.₉₇₅** | 95%なので 1.96（99%なら 2.576） |
| **p̂** | 標本比率：80/400＝0.2 |

### 🧮 計算

1. ① SE＝10/√100＝1 → 誤差幅 1.96×1＝1.96
2. 50±1.96 → **48.04〜51.96**
3. ② p̂＝0.2、SE＝√(0.2×0.8/400)＝0.02 → 誤差幅 1.96×0.02＝0.0392
4. 0.2±0.0392 → **0.161〜0.239**（約16%〜24%）

図：同じ手順で20回つくると、平均して19本が真の値を含む＝95%の意味

| 変えると | 幅は |
| --- | --- |
| n を4倍 | 約半分 |
| 95%→99% | 広がる（1.96→2.576） |
| σ が大きい | 広がる |

**よくある誤解**　「μ が95%の確率でこの区間に入る」ではない（μ は動かない）。また「個々の客の95%がこの範囲」でもない。区間は平均についての幅。

**答えの読み方**　「客単価の母平均は48〜52百円程度と推定（95%信頼）」。誤差幅を半分にしたいなら、調査人数は4倍の400人が必要。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く（例：n を4倍 → 幅が半分）。

σ・n・信頼係数を動かすと、誤差幅と30本の区間のうち μ を外す本数が変わります。

もう一つ：比率の信頼区間。同じ比率のまま n を 4 倍にすると区間の幅は半分になります（26の検定と同じ画面で比べられます）。

## 1｜まず意味をつかむ

点推定だけでは不確実性が見えない。区間推定は『推定値±誤差幅』の形で、標本の取り直しによる変動を表す。95%信頼区間は同じ作り方を繰り返したとき母数を覆う区間の割合を95%にするという手順の性質。

母平均は母SD既知ならz、未知の正規標本ならtを使う。比率は二項モデルの大標本近似を使う代表式がある。極端な比率や小標本ではこの単純式の精度が悪く、Wilson等の別法を検討する。

## 2｜式と記号を読む

$$
\bar x\pm t_{1-\alpha/2,n-1}\frac{s}{\sqrt n}
$$

```txt
平均σ既知：x̄ ± z_(1−α/2) σ/√n
平均σ未知：x̄ ± t_(1−α/2,n−1) s/√n
比率のWald近似：p̂ ± z_(1−α/2)√{p̂(1−p̂)/n}
```

## 3｜表で関係を整理する

| 変更 | 他条件一定のときの幅 |
| --- | --- |
| nを4倍 | おおむね半分 |
| 信頼係数を95→99% | 広くなる |
| SDが大きい | 広くなる |

## 4｜例題を途中から追う

母SD10既知、n=100、x̄=50なら95%区間は50±1.96×1=48.04〜51.96。

独立400件中80件成功ならp̂=0.2、SE=√(0.2×0.8/400)=0.02。近似95%区間0.2±0.0392=0.1608〜0.2392。割合の区間は数量の区間ではない。

誤差幅dを目標にする既知σの平均の概算必要数はn≥(zσ/d)²、整数へ切り上げる。

## 5｜誤解と適用条件を確認する

この区間に個々の観測値の95%が入るとは限らない。観測後の固定区間に母数が95%で動くという説明をしない。対応やクラスター依存を無視しない。

## 6｜自力で確かめる

母SD12既知、n=36、平均100の95%区間を求める。誤差幅を半分にするにはnを何倍にするか。

解答：100±1.96×2=96.08〜103.92。nは4倍。
