# 教科書04｜データの種類・測定尺度

この章で答えられるようになること：データの種類（質的・量的）と尺度（名義・順序・間隔・比例）を判定し、「平均してよいか」「何倍と言えるか」「どのグラフを使うか」を決められる。

このページの用語：変数の種類・測定尺度・離散と連続（用語集）

## はじめて

### ステップ1｜4つの質問で尺度を決める

上から順に「はい」になった所で止める。

<b>質問1：区別するためのラベルだけ？</b>　→ はい：<b>名義尺度</b>（店番、性別）
<b>質問2：順番に意味はあるが、間隔はそろっていない？</b>　→ はい：<b>順序尺度</b>（満足度、順位）
<b>質問3：差に同じ意味があるが、0が「無い」ではない？</b>　→ はい：<b>間隔尺度</b>（気温℃、西暦）
<b>質問4：0が「無い」を表し、何倍と言える？</b>　→ はい：<b>比例尺度</b>（販売個数、重さ、売上）

名義・順序は<b>質的変数</b>、間隔・比例は<b>量的変数</b>。量的変数のうち、個数のように数え上げる値は<b>離散型</b>、重さや時間のように途中の値も取れる値は<b>連続型</b>。

### ステップ2｜使える計算を図で見る

<b>尺度が上がるほど、使える計算が増える</b>
名義（＝ ≠）→ 順序（＜ ＞）→ 間隔（＋ −）→ 比例（× ÷）

### ステップ3｜例題を1つ解く

次の4つのデータの尺度を判定し、「平均」と「何倍」を使ってよいか答えよ。①店番　②満足度（不満/普通/満足）　③気温（℃）　④販売個数

| データ | 尺度 | 平均・何倍 |
| ①店番 | 名義 | 平均✕・何倍✕ |
| ②満足度 | 順序 | 平均△（等間隔とみなすときだけ）・何倍✕ |
| ③気温℃ | 間隔 | 平均◯・何倍✕ |
| ④販売個数 | 比例 | 平均◯・何倍◯ |

<b>ここが一番大事</b>　数字が書いてあることと、その計算をしてよいことは別。店番305の平均には意味がなく、20℃は10℃の「2倍暑い」とは言えない（0℃は「温度が無い」ではないから）。

### ステップ4｜動かして確かめる

（ラボ scale.html）
<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「同じ2つの気温を℃からKに直すと、差は同じだが『何倍』の値は変わる」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　「血液型（A・B・O・AB）」の尺度は何か。
答え：<b>名義尺度</b>。区別するためのラベルで、順番も差もない。

<b>問2（中）</b>　売上ランキングの「1位・2位・3位」の尺度は何か。「1位と2位の差」と「2位と3位の差」は同じと言えるか。
答え：<b>順序尺度</b>。順番には意味があるが、1位と2位の売上差と、2位と3位の売上差が同じとは限らない。

<b>問3（やや難）</b>　郵便番号・顧客満足の順位・気温（℃）・購入個数を分類し、それぞれ平均や「何倍」を使うときの注意点を1つずつ述べる。
答え：
- 郵便番号：名義。平均は意味がない。
- 満足の順位：順序。平均を使うなら「順位の間隔は等しい」とみなす仮定を明示する。
- 気温（℃）：間隔。差は比べられるが「何倍」は言えない。
- 購入個数：比例（離散型）。平均も何倍も使える。

<b>まとめ（3行）</b>
1. 名義（区別）→ 順序（順番）→ 間隔（差）→ 比例（比）の順に、使える計算が増える。
2. 「何倍」と言えるのは、0が「無い」を表す比例尺度だけ。
3. 数字が付いていても、尺度を確かめてから平均や比を使う。

## 復習

### 思い出す（何も見ずに答える）

- 4つの尺度を、使える計算が少ない順に言える
- 間隔尺度と比例尺度の違いを「0」の意味で言える
- 離散型と連続型の違いを例とともに言える

答え：
1. 名義 → 順序 → 間隔 → 比例。
2. 間隔尺度の0は「無い」ではない（0℃でも温度はある）ので何倍と言えない。比例尺度の0は「無い」なので何倍と言える。
3. 離散型は数え上げる値（個数・人数）、連続型は途中の値も取れる値（重さ・時間）。

### 早見表

| 尺度 | 例 | 合うグラフ・代表値 |
| 名義 | 店番・性別 | 棒グラフ・円グラフ／最頻値 |
| 順序 | 満足度・順位 | 棒グラフ／中央値・最頻値 |
| 間隔 | 気温℃ | ヒストグラム／平均・中央値 |
| 比例 | 個数・重さ・売上 | ヒストグラム／平均・中央値 |

### 1問で確かめる

<b>問</b>　「去年の平均気温は10℃、今年は15℃だったので、今年は1.5倍暖かかった」という説明の誤りを指摘し、正しい言い方に直す。
答え：気温（℃）は間隔尺度で、0℃は「温度が無い」ではないため「何倍」とは言えない。正しくは「今年は去年より平均気温が5℃高かった」。

## 深める

### 説明の型

「<b>〈条件〉</b>のとき、<b>〈対象〉</b>は<b>〈結論〉</b>になる。なぜなら<b>〈根拠〉</b>。ただし<b>〈成り立たない場合〉</b>は別。」

### お手本：「何倍」と言える条件を説明する

- <b>条件</b>：0が「その量が無い」ことを表すデータ（比例尺度）のとき
- <b>対象と結論</b>：2つの値の比（何倍か）に意味がある
- <b>根拠</b>：0が共通の出発点なので、単位を変えても（kg→g）比は変わらないから
- <b>成り立たない場合</b>：気温℃のように0が任意の位置にある間隔尺度では、単位を変えると比が変わる（℃とKで「何倍」が違う）ので比は意味を持たない

<b>つなげると</b>
「0が『無い』を表す比例尺度のデータなら、何倍と言える。なぜなら0が共通の出発点なので、単位を変えても比が変わらないから。ただし気温℃のような間隔尺度では、単位によって比が変わるので何倍とは言えない。」

### 言葉の使い分け

<b>「数値データ」</b>
- 数字で書かれたデータ（店番・郵便番号も含む）
- 量を表すデータ（量的変数）→ 「数字で書かれている」ことと「量である」ことを分けて言う

<b>「平均できる」</b>
- 計算はできる（どんな数字でも足して割れる）
- 意味がある（尺度が間隔以上）→ 説明では「意味のある平均か」を言う

<b>「離散」と「整数」</b>
- 離散型：数え上げる量（個数）
- 整数で表示されているだけ：体重を「65kg」と丸めても、元は連続型

### 言い直し練習

「満足度は1〜5の数字なので量的変数で、平均を出して比べられる。」

<b>直す点</b>
- 数字で記録しても、満足度の元の性質は順序尺度（質的）。
- 平均を使うには「1と2の差」と「4と5の差」が等しいとみなす仮定が必要。

<b>言い直しの例</b>
「満足度は1〜5の数字で記録しているが、元は順序尺度の質的変数である。平均を出すなら、各段階の間隔が等しいとみなす仮定を置いていることを明示する。仮定を置かないなら、中央値や各段階の割合で比べる。」

### 自己チェック（説明を書いたら）

- 尺度の名前と、その判断理由（0の意味・差の意味）を書いた
- 「計算できる」と「意味がある」を区別した
- 平均や比を使うときに置いている仮定を書いた
- 使えない計算の例を1つ以上書いた

### もう一段深く：階級にまとめると情報が減る

年齢（比例尺度）を「20代・30代・40代」に分けると、順序尺度のように扱うことになる。同じ「30代」の31歳と39歳の差は見えなくなる。集計の目的に合わせて、どこまで細かく残すかを決める。

### よくある誤解

- 数字なら量的変数 → ✕。郵便番号・店番・背番号は名義尺度。
- 順位は平均してよい → △。等間隔とみなす仮定を明示したときだけ。
- 西暦2020年は1010年の2倍 → ✕。西暦は間隔尺度（0年は「時間が無い」ではない）。

## 応用

### グラフ・代表値の選び方へ（教科書05・06）

尺度が決まると、使うグラフと代表値が決まる。質的変数は度数の棒グラフ・円グラフ、量的変数はヒストグラム・箱ひげ図。代表値は、名義なら最頻値、順序なら中央値、量的なら平均と中央値。

### アンケート集計で

<b>問</b>　「満足度（5段階）」の結果を店舗間で比べたい。平均点の比較と、「4以上の割合」の比較では何が違うか。
答え：平均点は「各段階の間隔が等しい」とみなす仮定の上に立つ。「4以上の割合」は順序だけを使うので、仮定が少なくて済む。割合は26章の比率の検定、2つの店の比較は27章の独立性の検定につながる。

### 仕事の場面で

- 店番・部門コード・JANコードは名義尺度。足したり平均したりしない。
- 売上・客数・数量は比例尺度。「前年比110%」のように比で比べられる。
- 気温と売上の関係を見るときは、気温℃の「差」で考える（「気温が5℃上がると売上がどう変わるか」）。
