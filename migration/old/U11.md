# 教科書11｜条件付き確率・独立・乗法則

この章で答えられるようになること：「〇〇だと分かったうえで」の確率を、分母が変わることから求められる。続けて起こる確率を掛け継いで計算し、2つの出来事が独立かどうか判定できる。

このページの用語：条件付き確率・独立・排反・事象

## はじめて

### ステップ1｜問題文の言葉で式を選ぶ

<b>「〇〇だと分かったうえで」「〇〇の中で」</b> → <b>条件付き確率</b>。〇〇が分母になる
<b>「戻さずに引く」「続けて起こる」</b> → <b>乗法定理</b>：確率を順に掛け継ぐ
<b>「一方が他方に影響するか」</b> → <b>独立の判定</b>：P(A∩B)＝P(A)P(B) か確かめる

### ステップ2｜樹形図で流れを見る

（図：分岐の確率を掛けると各経路の確率。太線が「2回とも赤」）

条件が付くと、比べる「世界」が狭くなる。1回目に赤を引いたら、2回目は残り4個の中での確率になる。

### ステップ3｜例題で計算する

赤2個・青3個の袋から、戻さずに2回引く。① 1回目が赤だったとき、2回目も赤の確率は？　② 2回とも赤の確率は？

P(A｜B)＝P(A∩B)÷P(B) ⇔ P(A∩B)＝P(B)P(A｜B)

1. ① 1回目赤の後、残りは赤1・青3 → P(2回目赤｜1回目赤)＝<b>1/4</b>
2. ② P(2回とも赤)＝2/5×1/4＝<b>1/10</b>
3. 比較：毎回戻すなら 2/5×2/5＝4/25（1回目が2回目に影響しない＝独立）

<b>ここが一番大事</b>　「〇〇の中で」の〇〇が分母。<b>条件が付くと分母が変わる</b>。条件を付けても確率が変わらなければ独立、変われば独立ではない。

### ステップ4｜動かして確かめる

（ラボ：cond.html）

<b>動かしたら書く</b>　「何を変えたら、何がどう変わったか」を1文で書く。
例：「雨の日と晴れの日の購入率を同じにすると、P(購入｜雨)＝P(購入) になり独立になった」

### ステップ5｜確認問題（易→難）

<b>問1（易）</b>　雨の日の客40人のうち12人が傘を買った。P(傘を買う｜雨) は？
答え：12÷40＝<b>0.3</b>。分母は全客ではなく「雨の日の客」。

<b>問2（中）</b>　赤3個・青2個の袋から戻さずに2回引く。1回目が赤のとき2回目も赤の確率と、2回とも赤の確率は？
答え：残りは赤2・青2なので <b>1/2</b>。2回とも赤＝3/5×1/2＝<b>3/10</b>。

<b>問3（やや難）</b>　P(A)＝0.4、P(B)＝0.5 とする。P(A∩B)＝0.2 のときと 0.25 のとき、A と B は独立か。
答え：P(A)P(B)＝0.2。P(A∩B)＝0.2 なら<b>独立</b>。0.25 なら<b>独立ではない</b>（P(A｜B)＝0.25÷0.5＝0.5 で、P(A)＝0.4 より高い。B が起きると A が起きやすい）。

<b>まとめ（3行）</b>
1. P(A｜B)＝P(A∩B)÷P(B)。条件 B が分母になる。
2. 続けて起こる確率は P(B)×P(A｜B) と掛け継ぐ。
3. 独立 ⇔ P(A∩B)＝P(A)P(B) ⇔ P(A｜B)＝P(A)。

## 復習

### 思い出す（何も見ずに答える）

- 条件付き確率の式を書ける
- 独立の判定方法を2通り言える
- P(A｜B) と P(B｜A) が違う例を言える

答え：
1. P(A｜B)＝P(A∩B)÷P(B)（P(B)＞0）。
2. P(A∩B)＝P(A)P(B) か、P(A｜B)＝P(A) か。
3. P(傘を買う｜雨) と P(雨｜傘を買う)。分母（雨の日の客／傘を買った客）が違う。

### 式の早見

| 求めるもの | 式 |
| --- | --- |
| 条件付き確率 | P(A∩B)÷P(B) |
| 乗法定理 | P(A∩B)＝P(B)P(A｜B) |
| 独立なとき | P(A∩B)＝P(A)P(B) |
| 戻さない2回とも赤（赤2青3） | 2/5×1/4＝1/10 |
| 戻す2回とも赤 | 2/5×2/5＝4/25 |

### 1問で確かめる

<b>問</b>　赤2・青3から戻さず2回引く。条件なしで「2回目が赤」の確率は？
答え：赤→赤 2/5×1/4＝2/20、青→赤 3/5×2/4＝6/20。合計 8/20＝<b>2/5</b>。条件付きの 1/4 とは違う。

## 深める

### お手本：戻さずに引くと独立でない理由

- <b>条件</b>：袋から玉を戻さずに続けて引くとき
- <b>対象と結論</b>：1回目と2回目の結果は独立ではない
- <b>根拠</b>：1回目に何を引いたかで、袋に残る玉の構成が変わり、2回目の確率が変わるから（赤2青3なら、1回目赤の後は1/4、青の後は2/4）
- <b>成り立たない場合</b>：毎回戻す（復元抽出）なら袋の中身は変わらないので独立。袋の中がとても多いときも、ほぼ独立とみなせる

つなげると：「戻さずに引くと、1回目と2回目の結果は独立ではない。1回目に何を引いたかで残りの構成が変わり、2回目の確率が変わるからである。ただし毎回戻すなら中身が変わらないので独立になる。」

### 言葉の使い分け

<b>「P(A｜B)」と「P(B｜A)」</b>
- P(購入｜来店)：来店した人のうち購入した割合
- P(来店｜購入)：購入した人のうち来店した割合（通販がある店なら1ではない）
- 分母が違うので、一般に値は違う

<b>「条件付き確率」と「同時確率」</b>
- 条件付き：Bの中でのAの割合 P(A｜B)
- 同時：全体の中でAとBが両方起きる割合 P(A∩B)

### 言い直し練習

「会員の80%がリピーターなので、リピーターの80%は会員です。」

<b>直す点</b>
- P(リピーター｜会員)＝0.8 から P(会員｜リピーター) は分からない。分母が違う。
- 会員の割合や、非会員のリピーター率が必要。

<b>言い直しの例</b>
「会員のうち80%がリピーターである。リピーターのうち会員が何%かは、会員の割合と非会員のリピーター率が分からないと求められない（教科書12のベイズの定理で求める）。」

### 自己チェック（説明を書いたら）

- 「何の中で」の割合か（分母）を書いた
- P(A｜B) と P(B｜A) を取り違えていない
- 独立を「確率が変わらないこと」で説明した
- 排反と独立を混同していない

### よくある誤解

- 独立と排反は同じ → ✕。排反は「同時に起きない」、独立は「影響しない」。
- 条件付き確率は P(A∩B) と同じ → ✕。P(A∩B) を P(B) で割ったもの。

## 応用

### クロス集計表で独立を確かめる

<b>問</b>　客100人を「ポイントカード提示の有無」と「デザート購入の有無」で集計した。提示あり40人のうちデザート購入16人、提示なし60人のうち購入18人。提示と購入は独立か。
答え：P(購入｜提示あり)＝16÷40＝0.40、P(購入｜提示なし)＝18÷60＝0.30、全体 34÷100＝0.34。条件で率が変わるので<b>独立ではない</b>。ただしこれは標本の割合なので、偶然の差かどうかはカイ二乗検定（教科書27）で調べる。また提示が購入の<b>原因</b>とは限らない。

### ベイズの定理へ（教科書12）

P(B｜A) を P(A｜B) から逆算するのがベイズの定理。

### 仕事の場面で

- 「雨の日の客単価」「会員の購入率」のように、条件で分けて集計するのは条件付き確率を見ていること。
- 条件付きの率が全体の率と大きく違う区分は、販促の狙い目の候補になる（ただし因果は別に確かめる）。
