# 教科書26｜割合・分散の検定

## 学習の目標

比率・分散・分散比の検定を、帰無仮説に合う標準化で行う。

## ✨ 例題で式を読み解く

**この式を使う場面**　「購入率が基準と違うか」「2店舗の購入率に差があるか」など、**はい/いいえ**のデータの割合を比べるとき。

### 📝 例題

① 例年の購入率は20%。今年100人中30人が購入した。購入率は変わったか（両側5%）。　② A店は100人中20人、B店は100人中30人が購入。購入率に差があるか（両側5%）。

### 🧩 式のどこに何を入れる？

$$
① \ z=\frac{\hat p-p_0}{\sqrt{p_0(1-p_0)/n}}\qquad ② \ z=\frac{\hat p_1-\hat p_2}{\sqrt{\bar p(1-\bar p)\left(\frac{1}{n_1}+\frac{1}{n_2}\right)}}
$$

| 記号 | 問題文のどこ |
| --- | --- |
| **p̂** | 今年の購入率：30/100＝0.3 |
| **p₀** | H0で決めた比率：0.2（SEにも p₀ を使う） |
| **p̂₁, p̂₂** | A店0.2、B店0.3 |
| **p̄** | H0「差なし」の下の共通比率＝(20＋30)/(100＋100)＝0.25 |

### 🧮 計算

1. ① SE＝√(0.2×0.8/100)＝0.04 → z＝(0.3−0.2)/0.04＝**2.5**
2. |2.5| ＞ 1.96（p≈0.012）→ **棄却**：購入率は変わった
3. ② p̄＝0.25、SE＝√(0.25×0.75×0.02)＝**0.0612**
4. z＝(0.2−0.3)/0.0612＝**−1.63** → |z| ＜ 1.96 → **棄却しない**

10ポイントの差も、各100人では偶然の範囲に収まる

| 何を検定？ | 統計量 | 分布 |
| --- | --- | --- |
| 比率（1標本・2標本） | z | 標準正規（近似） |
| 母分散 | (n−1)s²/σ₀² | χ²(n−1) |
| 分散比 | s₁²/s₂² | F(n₁−1, n₂−1) |

**混同注意**　検定のSEは H0 の値（p₀ や p̄）で作る。区間推定（22・23）のSEは観測した p̂ で作る。同じ「比率のSE」でも中身が違う。

**答えの読み方**　②は「差がない」ではなく「この人数では差があるとは言えない」。同じ20%と30%でも各200人なら有意になる（下の確認問題）。

### 🎛️ 動かして確かめる

**動かしたら書く**　「何を変えたら、何がどう変わったか」を1文で、下の「6｜自力で確かめる」の**計算・根拠**欄に書く。そのあと確認問題へ。

比率の検定も「(観測値−H₀の値)÷SE」で同じ形。n を増やすと同じ差でも z が大きくなり、p 値が小さくなります。

もう一つ：比率の検定。検定の SE は p₀、区間の SE は p̂ から計算する違いを式で見比べます。赤い面積が p値。

## 1｜まず意味をつかむ

母比率の検定は成功/失敗の二項データを扱う。1標本の正規近似SEでは、H0で指定するp0を使う。独立2群でH0:p1=p2なら、帰無仮説下の共通比率を両群でプールしてSEを作る。

正規母集団の母分散の検定はχ²、独立な正規2群の母分散比はFを使う。分布の左右非対称性と自由度を考えてp値・棄却域を選ぶ。比率の差、分散の差、平均の差は別の問い。

## 2｜式と記号を読む

$$
z=\frac{\hat p-p_0}{\sqrt{p_0(1-p_0)/n}}
$$

```txt
1比率：z=(p̂−p0)/√{p0(1−p0)/n}
2比率：p_pool=(x1+x2)/(n1+n2)
z=(p̂1−p̂2)/√{p_pool(1−p_pool)(1/n1+1/n2)}
母分散：Q=(n−1)s²/σ0²
分散比H0:σ1²/σ2²=R0ならF=(s1²/s2²)/R0
```

## 3｜表で関係を整理する

| 対象 | 参照分布 | 主な条件 |
| --- | --- | --- |
| 母比率・比率差 | 大標本の正規近似 | 独立・期待件数十分 |
| 母分散 | χ²(n−1) | 正規母集団 |
| 母分散比 | F(n1−1,n2−1) | 独立した正規2群 |

## 4｜例題を途中から追う

n=100、成功30、H0:p=0.2ならSE=√0.0016=0.04、z=(0.3−0.2)/0.04=2.5。両側正規近似p≈0.0124。区間推定で使うp̂由来のSEと区別する。

n=10、s²=16、H0:σ²=9ならQ=9×16/9=16、df9。この値だけで有意とせず分布表で両側又は片側の基準を確認する。2群のs1²=16,s2²=4なら分散比統計量4。

## 5｜誤解と適用条件を確認する

小標本・極端な比率で正規近似を機械適用しない。対応した比率データは独立2群式と異なる。Fの両側検定で下側を忘れない。非正規な分散の検定には頑健性の問題がある。
